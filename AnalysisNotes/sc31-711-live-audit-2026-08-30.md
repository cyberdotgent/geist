### Method corrections made during the audit

Two of these changed the result by more than the findings did, so they are
recorded rather than quietly fixed:

- The first run reported 4.06% loss and *zero* clean topics. The cause was
  reader chrome counted as book content: the `<head>` title bar
  (`2.4.1 "LAN Network Manager for AIX Reference" via IBM BookManager
  BookServer`), the navigation banner, and the `<h6>` BookServer copyright
  line the server appends to every page.
- Stripping `<cite>` as chrome then produced a false *win* of 492 words we
  supposedly emitted beyond hosted. `<cite>` carries the publication titles in
  the `BACK_1.x` bibliography topics as well as the page's copyright footer;
  only a `<cite>` containing `©`/`Copyright` is chrome. Corrected, the excess
  falls to 21 words.

## 2. Heuristic-flag inspection

Every item in `m9-heuristic-inventory.md` (written at `c82c0ed`) re-checked
against the tree.

- **A — string-search admission prefilters (12 items).** All gone. The
  surviving `*_source_candidate` functions in `topic_document_lowering.cpp`
  decide on typed `ControlSegmentIR::kind`, not on lowercased record text,
  which is the replacement the inventory names.
- **B — all-C / CFONT-as-semantics.** Gone; the publication recognizer's
  `saw_title && font_segments` admission constraint no longer exists.
- **C — post-render / rendered-text repair.** Gone with the legacy renderer,
  except one cluster that kept external linkage so the compiler could not warn
  about it: 23 of `toc.cpp`'s 31 definitions were unreachable from its only
  two exports. Deleted at `6684553` (1,011 -> 327 lines), corpus byte-identical.
- **D — dual ownership paths.** Gone. Every `*_gml` projector was deleted with
  `markup.cpp`, and `VerifiedOwnershipIR`'s private constructor leaves no
  second path: no caller of the unverified `build_ownership_ir` exists outside
  `ownership_ir.cpp`.
- **E — `message_ir.cpp` TODOs.** **Still present**, and the only heuristic
  flags left in the tree. Six sites keep an "observed compact alphabet"
  (encoded width 1, value 19..43) to recognize marker slots, plus the
  `encoded_value == 4` decoder sentinel that separates a soft wrap from
  punctuation. They are waiting on `OwnershipIR` growing positioned and
  supplemental field roles. These are the same code paths the `5.0` row-join
  defect above runs through.

`contains_srmsg_control`, the last string search for a control, was deleted at
`c8aeff2`.
