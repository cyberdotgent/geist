Geist APT repository

Packages for reading IBM BookManager BOO books.

Add the repository

Replace stable with unstable to track every push to main instead of tagged releases.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://cyberdotgent.github.io/geist/geist-archive-keyring.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/geist-archive-keyring.gpg

echo "deb [signed-by=/etc/apt/keyrings/geist-archive-keyring.gpg] \
https://cyberdotgent.github.io/geist $(. /etc/os-release && echo $VERSION_CODENAME) stable" \
  | sudo tee /etc/apt/sources.list.d/geist.list

sudo apt update

Tracks

stable is built from git tags and is never pruned. unstable is built from every push to main; the five most recent builds of each package are kept. An unstable version sorts below the release it precedes, so a machine on unstable upgrades onto stable when the release lands.
