## 5.4.1.10 Filing a Local Document on a Remote System

<a id="HDRFILLOC"></a>

#### Filing a Local Document on a Remote System

To file a local document on a remote system, the remote system must have document library support. To file a document on a remote system, do the following:

1. On the Work with Documents and Folders display, type option **4** (Work with document lists). Press the Enter key. 2. The Work with Owned Document Lists display appears. On this display, move the cursor next to the description that contains the document you want to work with and type a 5 (W**o**rk with documents in list). Press the Enter key. 3. The Work with Documents in a List display appears. On this display, move the cursor next to the description of the document you want to file on a remote system and in the Opt *col*umn, type a 12 (**Fi**le remote). Press the Enter key.

4. The File Document on Remote System display appears.
