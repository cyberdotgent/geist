#### 5.4.1.11 Changing Authority to a Local Document

This task shows how to change the authority that someone has to a local

document. The **authority** is the type of security associated with the document. To verify or change the type of authority that someone has to a local document, do the following: 1. On the Work with Documents and Folders display, type option **4** (Work with document lists). Press the Enter key. 2. The Work with Owned Document Lists display appears. On this display, move the cursor next to the description that contains the document you want to work with and type a 5 (W**o**rk with documents in list). Press the Enter key. 3. The Work with Documents in a List display appears. On this display, move the cursor next to the description of the document that you want to verify or change the authority of, and in the Opt *col*umn, type a 14 (Change authority).
