#### 5.4.1.4 Viewing a Local Document

To view a document filed on the local system, do the following:

1. On the Work with Documents and Folders display, type option **4** (Work with document lists). Press the Enter key. 2. The Work with Owned Document Lists display appears. On this display, move the cursor next to the description that contains the document you want to work with and type a 5 (W**o**rk with documents in list). Press the Enter key. 3. The Work with Documents in a List display appears. On this display, move the cursor next to the description of the document you want to view and in the Opt *col*umn, type a 5 (V**i**ew). 4. Press the Enter key. The document you want to view appears on the display. 5. When you have finished viewing the document, press F3 (Exit). The Work with Documents in a List display appears. 6. Press F3 (Exit).
