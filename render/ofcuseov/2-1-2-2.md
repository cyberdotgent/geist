#### 2\.1\.2\.2 Printing a Mail Item without Options

How a mail item is printed when options are not specified is controlled by the mail item\.

To print a mail item without specifying the print options, do the following:

1\. On the Work with Mail display, move the cursor down to the mail item you want to print\. Type a **6** \(Print\) and press the Enter key\.

```
        __________________________________________________________________________________
       |                                                                                  |
       |                                   Work with Mail                                 |
       |                                                                                  |
       |   Working with mail for . . . . . . : HANSON   ROCH                              |
       |                                                                                  |
       |                                                                                  |
       |   Type options, press Enter.                                                     |
       |     2=Revise a copy         4=Delete              5=View           6=Print       |
       |     8=Change details        9=Print options       10=Forward       11=Reply      |
       |     12=File remote          13=File local         14=Change authority            |
       |                                                                                  |
       |                    ------From-------                                    Date     |
       |   Opt  Status      User ID  Address   Description                       Received |
       |   __   NEW         SJONES   ROCH      BUDGET REVIEW                     04/21/88 |
       |   __   NEW         PETERSON ROCH      DEPT MEETING                      04/20/88 |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                           Bottom |
       |   F3=Exit           F5=Refresh   F6=Outgoing mail status                         |
       |   F9=Action items   F12=Cancel   F24=More keys                                   |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

2\. The mail item prints on the printer device specified in your user profile\. The other print options used when printing the mail item \(number of copies, form type, and print quality\) are determined by your active text profile\.

3\. Press F3 \(Exit\)\.
