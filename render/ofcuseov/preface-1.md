## PREFACE\.1 Who Should Use This Manual

<a id="HDRWHO"></a>

This manual is for the OfficeVision/400 user and can be used as a reference to complete office tasks\. If you are not familiar with OfficeVision/400, it is recommended that you complete the exercises in the manual *Office: Learning about OfficeVision/400*, SC21\-9615, before using this manual\.
