### 7\.4\.2 Displaying the Folder Path

You can display the folder path of an object to determine its location within folders by doing the following:

1\. On the Work with Objects by Owner display, move the cursor next to each object for which you want to display the folder path and type a **10** \(Display folder path\) in the *Opt* column\. Press the Enter key\. 2\. The Display Folder Path display appears\.

```
        __________________________________________________________________________________
       |                                                                                  |
 |     |                                Display Folder Path                               |
       |                                                                                  |
 |     |     Object . . :   CPYR5034.60                                                   |
       |                                                                                  |
 |     |     Path . . . :   HANSON                                                        |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
 |     |   Press Enter to continue.                                                       |
       |                                                                                  |
 |     |   F3=Exit   F12=Cancel   F19=Display messages                                    |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

3\. Press F3 \(Exit\)\.
