 | 5.  Decide which type of calendar you want to see.  For the Calendar view
       prompt, you can:
       Note:  A prompt is a request for information on a display that you can
              type a response to.
       °   Type a 1 to see a daily calendar.  This calendar shows all the
           events scheduled for a day for someone or something.
       °   Type a 2 to see a weekly calendar.  This calendar shows all the
           events scheduled for a week for someone or something.
       °   Type a 3 to see a group calendar.  This calendar shows all the
           events scheduled in a day for a group of individual calendars.
       °   Type a 4 to see a composite calendar.  This calendar shows the
           scheduled and available times for a group of individual calendars.
       °   Type a 5 to see a six month calendar.  This calendar shows six
           individual monthly calendars on one display.
 | 6.  The information you type for the Calendar prompt must be compatible

 |     For the Calendar prompt, type one of the following:
 |     °   A user ID and address (the address is optional).
 |     °   A user ID and address followed by *USER (the address and *USER is
 |         optional).
 |     °   A nickname of a user or a distribution list.
 |     °   A calendar name followed by the user ID and address of the owner
 |         of the calendar (the user ID and address is optional).
 |     °   A calendar name followed by *CAL (*CAL is optional).
 |     °   A group name followed by the user ID and address of the owner of
 |         the group (the user ID and address is optional).
 |     °   A group name followed by *GROUP (*GROUP is optional).
 |     °   A distribution list ID and list ID qualifier (list ID qualifier is
 |         optional).
 |     °   A distribution list ID and list ID qualifier followed by *DIST

 |     A group name or a distribution list name is allowed only for the
 |     Calendar prompt when certain operations that allow multiple calendars
 |     are specified.  For example, on the Composite Calendar display and in
 |     the invitee list of the meeting displays.
 |     For only one calendar, the calendar name, user ID, and address are
 |     shown for the Calendar prompt unless the calendar is the user's
 |     scheduling calendar.  If the calendar is the user's scheduling
 |     calendar, only the user's ID and address is shown.
 |     The Calendar prompt also accepts a colon (:) as the separator
 |     character between the different parts.  For example, USER:ADDRESS is
 |     the same as USER ADDRESS.
 |     Note:  If you are not sure of the name of the calendar you want to
 |            see, press F4 (List) with the cursor in this prompt.  The
 |            Select Calendars display appears with a list of calendars you
 |            can select.  If the calendar you want to see is a group
 |            calendar, press F14 (Select group) on the Select Calendar
 |            display.  The Select Group display appears with a list of group
 |            calendars you can select.
   7.  For the Date prompt, type the date you want the calendar to start on.
       Depending on the type of calendar you selected for the Calendar view
       prompt, the date you type has the following effect:
       °   If you select 1 (Daily), the daily calendar for this date appears
           for the name of the calendar you typed.
       °   If you select 2 (Weekly), the week which includes this date
           appears with the start day as indicated in the enrollment record
           of the user whose calendar name you typed.
       °   If you select 3 (Group), the calendar that appears shows the
           individual calendars in that group for the date you type.
       °   If you select 4 (Composite), the week that includes this date
           appears showing the busy and available times for a group of
           individual calendars for that week.
       °   If you select 5 (Six month), the six month calendar display that
           appears has this date in a month on the top row of the display.
   8.  Press the Enter key.  One of the following types of calendar displays
       appears:
       Note:  Function keys may be shown on the bottom of the display.  To

              If the word More... follows the last time period shown on the
              display, you can also see additional time periods by pressing
              the Page Down key.  To return to the display with the earlier
              time periods, press the Page Up key.
