### C\.2 System Distribution Directory Function Displays

The following prompts are DBCS input\-capable:

- Building
- Company
- Department description
- Department title
- First name
- Full name
- Job title
- Last name
- Location
- Mailing address \(lines 1 to 4\)
- Middle name
- Nickname
- Nickname description
- Office
- Position to
- Preferred name
- Reports to department
- Text
- User description
