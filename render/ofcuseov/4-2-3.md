### 4\.2\.3 Changing Note Details

<a id="HDRNOTEDET"></a>

Note details include the note description, subject, reference, date written, authors, date action due, project, keywords, and document class\.

To change your note details, do the following:

1\. On the Send a Note display, press F11 \(Change details\)\. 2\. The Change Note Details display appears\.

```
        __________________________________________________________________________________
       |                                                                                  |
       |                                Change Note Details                               |
       |                                                                                  |
       |   Type information, press Enter.                                                 |
       |                                                                                  |
       |     Document description  . . . .   Ordering Paper                               |
       |     Subject . . . . . . . . . . .   Ordering Paper                               |
       |  _______________                                                                 |
       |     Reference . . . . . . . . . .   Weekly Paper Request                         |
       |  _______________                                                                 |
       |     Date written  . . . . . . . .   04/18/88               MM/DD/YY              |
       |     Authors . . . . . . . . . . .   HANSON                ____________________   |
       |     Date action due . . . . . . .   ________               MM/DD/YY              |
       |     Project . . . . . . . . . . .   __________                                   |
       |     Keywords  . . . . . . . . . .   _____________________________________________|
       |  ________________________________________________________________________________|
       |  _______________________________________________________   F4 for list           |
       |     Document class  . . . . . . .   NOTE                   F4 for list           |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |   F3=Exit   F4=Prompt   F5=Refresh   F12=Cancel   F19=Display messages           |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

3\. Change the information in the following prompts as necessary\. The value shown for each prompt varies depending on the function used to reach this display:

a\. **Document description**\. If the *Subject* prompt was completed on the Send a Note display, this prompt contains the subject of the note; otherwise, it contains the word `Note` and the current date\.

b\. **Subject**\. This prompt contains the subject of the note from the Send a Note display\.

c\. **Reference**\. This prompt contains the reference of the note from the Send a Note display\.

d\. **Date written**\. This prompt is used to indicate when the note was written and shows a default of the current date\. Change it if necessary\.

e\. **Authors**\. This is who wrote the note\. Up to two authors can be typed for this prompt\. The first entry for this prompt shows a default of the person sending the note\.

f\. **Date action due**\. By this date you expect someone to take action\. By typing a date here, the note becomes an action item\.

g\. **Project**\. This is an overall note category and can be anything, including a number assigned to the note\.

h\. **Keywords**\. These are the search values used to identify a note filed in a library\. You can specify any of these words when searching for the note\.

You can type keywords in this prompt until you run out of space\. Up to 24 keywords are allowed\. Keywords must be separated by a semicolon \(;\)\. On a DISOSS System/38, and a Release 1\.0 or 1\.2 AS/400 system, the maximum length for a keyword is 35 characters\. On a Release 2\.0 or later AS/400 system, the maximum length for a keyword is 60 characters\. If you are not sure what to type in this prompt, press F4 \(List\) with the cursor in this prompt for a list of suggested entries\.

i\. **Document class**\. This prompt is a classification category used to describe documents or notes that are stored in a document library and defaults to `NOTE`\. To see a list of suggested entries for this prompt, press F4 \(List\) with the cursor in this prompt\.

4\. Press the Enter key\. The details that are now on the Change Note Details display apply only to the current note you are in the process of sending\. The Send a Note display appears\.

5\. Press F3 \(Exit\)\.
