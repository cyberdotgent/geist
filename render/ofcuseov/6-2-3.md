### 6\.2\.3 Changing a Distribution List

Changing a distribution list consists of adding or deleting distribution list entries\.

To change a distribution list, do the following:

1\. On the Directories and Distribution Lists display, type option **3** \(Distribution lists\)\. Press the Enter key\.

2\. The Work with Distribution Lists display appears\.

```
        __________________________________________________________________________________
       |                                                                                  |
 |     |                            Work with Distribution Lists                          |
       |                                                                                  |
 |     |   Position to  . . . . .   ________   List ID                                    |
       |                                                                                  |
 |     |   Type options, press Enter.                                                     |
 |     |     4=Delete list   5=Display entries   6=Print entries   8=Work with entries    |
       |                                                                                  |
 |     |   Opt   ------List ID------   Description                                        |
 |     |    _    ACCDSTL    ACCTG      Distribution list for accounting                   |
 |     |    _    DEPT248    DLIST      Members of Department 248                          |
 |     |    _    D543       PSPECS     Paper specifications reviewers in Dept 543         |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
 |     |                                                                          Bottom  |
 |     |   F3=Exit   F5=Refresh   F6=Create new lists   F9=Work with nicknames            |
 |     |   F12=Cancel             F13=Display departments                                 |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

3\. Move the cursor next to the name of the distribution list you want to change and type an **8** \(Work with distribution list entries\) in the *Opt* column\. Press the Enter key\.

**Note:** If you are not authorized to change the list, an error message appears on the Work with Distribution Lists display\. Press F3 to exit this function\.

4\. The Work with Distribution List Entries display appears\.

```
        __________________________________________________________________________________
       |                                                                                  |
       |                        Work with Distribution List Entries                       |
       |                                                                                  |
       |   List ID . . . . . . . . :   D543      PSPECS                                   |
       |   Description . . . . . . :   Paper specifications reviewers in Dept 543         |
       |                                                                                  |
       |   Position to . . . . . . .   ________   User ID                                 |
       |                                                                                  |
       |   Type options, press Enter.                                                     |
       |     4=Delete entry    5=Display details    6=Print details                       |
       |                                                                                  |
       |   Opt   User ID    Address    Description                                        |
       |    _    HANSON     ROCH       Hanson E G                                         |
       |    _    HENKE      ROCH       Henke, S K                                         |
       |    _    PETERSON   ROCH       Peterson, R N                                      |
       |    _    SJONES     ROCH       Jones, Sharon                                      |
       |    _    TOM        ROCH       Dixon, T F                                         |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                          Bottom  |
       |   F3=Exit   F5=Refresh   F6=Add entries   F12=Cancel                             |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

5\. If you want *to delete* an entry, move the cursor down to the entry you want to delete and type option **4** \(Delete entry\)\. Press the Enter key\. A display appears to let you confirm the deletion\. Press the Enter key again to confirm the deletion, or press F12 \(Cancel\) to return to the Work with Distribution List Entries display where you can change the option for this entry\. Then go to step 6 if you have an entry to add, or press F3 \(Exit\)\. 6\. If you want *to add* an entry, do the following:

a\. Press F6 \(Add entries\)\. The Add Distribution List Entries display appears\.

```
            __________________________________________________________________________________
           |                                                                                  |
           |                           Add Distribution List Entries                          |
           |                                                                                  |
           |   Distribution list:                                                             |
           |     List ID . . . . . . . :   D543      PSPECS                                   |
           |     Description . . . . . :   Paper specifications reviewers in Dept 543         |
           |                                                                                  |
           |   Type distribution list ID to copy entries, or type user ID/Address to add,     |
           |     press Enter.                                                                 |
           |                                                                                  |
           |   From list ID  . . . . . . . . . . . . .   ________   F4 for list               |
           |   From list ID qualifier  . . . . . . . .   ________                             |
           |                                                                                  |
           |   User ID   Address          User ID   Address          User ID   Address        |
           |   ________  ________         ________  ________         ________  ________       |
           |   ________  ________         ________  ________         ________  ________       |
           |   ________  ________         ________  ________         ________  ________       |
           |   ________  ________         ________  ________         ________  ________       |
           |   ________  ________         ________  ________         ________  ________       |
           |   ________  ________         ________  ________         ________  ________       |
           |   ________  ________         ________  ________         ________  ________       |
           |   ________  ________         ________  ________         ________  ________       |
           |                                                                          More... |
           |   F3=Exit   F4=Prompt   F5=Refresh   F12=Cancel                                  |
           |                                                                                  |
           |                                                                                  |
           |__________________________________________________________________________________|
```

b\. Add entries to the distribution list by doing any or a combination of the following methods:

- Type the user ID and address, user ID only, or nickname for each person you want to add to the distribution list\.
- For the *From list ID* and *From list ID qualifier* prompts, type the name or nickname of another distribution list containing the entries you want added to this distribution list and press the Enter key\. If a valid name is typed, all entries in that list are added to this list\. If duplicate entries are in the distribution list you select, they also appear in the distribution list\.

If you are not sure of the name of the distribution list or want to see the names of other distribution lists you can select, press F4 \(List\) with the cursor in the *From list ID* prompt\.

- Press F4 \(List\) with the cursor in either the *User ID* or *Address* columns to see a list of everyone \(all user IDs and addresses\) in the system distribution directory\. Then, by following the information on the display, add the users you want to the distribution list\. The entries that you select appear on the Add Distribution List Entries display\.

c\. Press the Enter key\.

If there is more than one address for a user ID \(or qualifier with this list ID\), a list appears from which you can choose one or more\.

After you have added the entries, a message appears at the bottom of the display indicating the number of entries added to the distribution list\.

d\. Press the Enter key again\. The Work with Distribution List Entries display appears\.

e\. Press F3 \(Exit\)\.
