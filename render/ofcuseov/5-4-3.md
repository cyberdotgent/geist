## 5.4.3 Changing Search Criteria

<a id="HDRCHGCRIT"></a>

This task shows you how to change the search criteria for a list. A local

search may be run in batch mode (processing is done by the system with little or no interaction between the user and the system) or interactive

mode (while you wait for completion). All remote searches run in batch mode. To change the search criteria for the list, do the following:

1. On the Work with Documents and Folders display, type option **4** (Work with document lists). Press the Enter key. 2. The Work with Owned Document Lists display appears.
