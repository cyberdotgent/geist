## 6\.1 Viewing the System Distribution Directory

<a id="LISst"></a>
<a id="ELISst"></a>
<a id="LISstr"></a>

```text
   The system distribution directory contains information that is used to
   distribute electronic mail.  It identifies someone as either a local, a
   remote, or an indirect user.  (An indirect user is someone who receives
   electronic mail as printed copy rather than signing on the system to
   receive mail.  Because the system only checks mail for an indirect user
   periodically, mail for an indirect user may be delayed.)  In addition, the
   system distribution directory may contain information about each user,
   such as the mailing address and telephone number.
   Only an administrator has full-update authority to the system distribution
   directory.  However, if you are not an administrator, you can view the
   system distribution directory and change some parts of your own directory
   entry.  For more information about changing parts of your directory entry,
   see the topic "Changing Your System Distribution Directory Information" in
   topic 7.1.1.
   To view the system distribution directory, do the following:
   1.  On the AS/400 Main Menu, type option 2 (Office tasks) and press the
       Enter key.  The Office Tasks menu appears.
```
