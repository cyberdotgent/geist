### 5.4.9 Running a Search

**Note:** A local (not remote) search can run interactively (while you wait for completion). To do this, on the Work with Owned Document Lists display, move the cursor down to the list you want to search and

type a 5 (Work with documents in list). Press the Enter key. The Work with Documents in a List display appears. Press F10 (Run search). The search runs while you wait. During this time you cannot do any other work on your display station. To run a search in a batch type of operation, do the following: 1. On the Work with Documents and Folders display, type option **4** (Work with document lists). Press the Enter key. 2. The Work with Owned Document Lists display appears. A message appears at the bottom of the display stating that the search request was sent to the system.

**Note:** You receive a message when the search is completed. You can then work with the results of the search by selecting the document list on the Work with Owned Document Lists display. 4. Press F3 (Exit).
