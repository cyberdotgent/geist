# 2.0 Chapter 2.  Using Mail Functions

<a id="HDRUSEMAIL"></a>

This chapter describes how to use the mail functions included with OfficeVision/400. You can work with mail items (view, print, revise, delete, forward, reply, file, and change the authority), create a hard-copy (printed) reference, work with the mail of another user, review the status of outgoing mail and action items, select mail by status, work with action items, and print an action item or a mail report.
