### 6.3.2 Changing a Nickname

You can change the description, user ID, or address (list ID or qualifier) for a nickname you created. To change the information about a nickname, do the following:

1. On the Directories and Distribution Lists display, type option **4** (Nicknames). Press the Enter key.

2. The Work with Nicknames display appears. T**his is the name you gave to an existing user ID or distribution list. b. Desc**ription. T**his is the description for the nickname. c. User **ID** a**nd** Addr**ess. T**his is the user ID and address for the nickname. If you change the user ID and use the spacebar to remove the address for the Address *prompt,* the system finds the address for that user ID. d. List **ID** a**nd** Qual**ifier. T**his is the list ID and qualifier information of the distribution list for the nickname. If you change the list ID but not the qualifier, the system finds the qualifier information. 6. Press the Enter key. If a user ID (or qualifier with this list ID) has more than one address, a list appears from which you can choose one. After you complete the changes, a message appears at the bottom of the display indicating that the nickname changes were made. 7. Press the Enter key again. The Work with Nicknames display appears. 8. Press F3 (Exit).
