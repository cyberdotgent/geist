## 6\.6 Working with the Department Function

You can use the department function to display all the members in a department of your office or to identify the management levels for a department or an individual\. You can do the following procedures using the Department Function:

- Change department details
- Remove department details
- Display department details
- Print department details
- Add a department

Only an administrator can maintain the department information\. If you are an administrator, you can use *Work with* displays to add, and change department information\. However, if you are not an administrator, you can use only the view or print displays for department information\.

Displaying and printing department details are described below\. For information on working with the Department Function as an administrator using the other functions previously mentioned, see the *Managing OfficeVision/400* manual\.
