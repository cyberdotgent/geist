### 7\.4\.1 Changing the Owner of an Object

You can change the owner of an object by doing the following:

1\. On the Administration display, type option **4** \(Work with objects by owner\) and press the Enter key\. 2\. The Work with Objects by Owner display appears\.

```
        __________________________________________________________________________________
       |                                                                                  |
 |     |                            Work with Objects by Owner                            |
       |                                                                                  |
 |     |  User ID/Address  . . . . . . :   HANSON   ROCH                                  |
       |                                                                                  |
 |     |  Type options, press Enter.                                                      |
 |     |    2=Edit authority      4=Delete        5=Display authority     7=Rename        |
 |     |    8=Display description 9=Change owner  10=Display folder path                  |
       |                                                                                  |
 |     |  Opt  Object             Library       Type             Attribute                |
 |     |   _   HANSCAL                          CALENDAR                                  |
 |     |   _   INVENTORY                        DIRECTORY                                 |
 |     |   _   HANSON                           *FLR                                      |
 |     |   _   HANSON             QUSRSYS       *MSGQ                                     |
 |     |   _   HANSON             QSYS          *LIB             PROD                     |
 |     |   _   HANSON             HANSON        *OUTQ                                     |
       |                                                                                  |
       |                                                                                  |
 |     |                                                                           Bottom |
 |     |  Command                                                                         |
 |     |  ===>___________________________________________________________________________ |
       |                                                                                  |
 |     |  F3=Exit   F5=Refresh     F11=Display text   F12=Cancel   F16=Delete all         |
 |     |  F20=Change owner of all  F24=More keys                                          |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

3\. On the Work with Objects by Owner display, move the cursor next to the object for which you want to change the owner and type a **9** \(Change owner\) in the *Opt* column\. Press the Enter key\.

4\. The Change Object Ownership display appears\.

```
        __________________________________________________________________________________
       |                                                                                  |
 |     |                      Change Object Ownership                                     |
       |                                                                                  |
 |     |   User ID/Address  . . . . . . :   HANSON   ROCH                                 |
       |                                                                                  |
 |     |   Type choice, press Enter.                                                      |
       |                                                                                  |
 |     |     New owner  . . . . . . . . .   ________ ________   User ID/Address           |
 |     |                                                        F4 for list               |
       |                                                                                  |
 |     |   Opt  Object             Library       Type                  Attribute          |
 |     |    9   CPYR5034.60        HANSON        *DOC                                     |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
 |     |                                                                          Bottom  |
 |     |   F3=Exit   F4=Prompt   F5=Refresh   F11=Display text   F12=Cancel               |
 |     |   F19=Display messages                                                           |
       |                                                                                  |
       |__________________________________________________________________________________|
```

5\. For the *New owner* prompt, type the user ID of the new owner and press the Enter key\. A message appears confirming that the ownership of the object has changed\.

6\. Press F3 \(Exit\)\.
