## 5.3.2 Searching for a Remote Document

<a id="HDRSCHREM"></a>

To search for a document located on a remote system, do the following:

1. On the Work with Documents and Folders display, type option **3** (Search for documents). 2. The *Work* *on* *behalf* *of* prompt for a local user is displayed if you have authority to work on behalf of another user on the local system. If you want to work on the behalf of another user, type the user ID/address or nickname for that user in this prompt. If you are not sure of the user ID, press F4 (List) with the cursor in this field. A list of the user IDs you are authorized to work for appears.

**Note:** Working on behalf of a local user is not active when doing a remote search. If you do a search for a remote document while working on behalf of a local user, the results of the search come back to you, not the local user you are working on behalf of.

3. For the *Document* *library* *to* *use* *for* *search* prompt, type the name of the library on the remote system you want to search. If this prompt does not appear on your display, it means that your system does not have document library services support to a remote system. Note**s:** a. If the local library has the same name as a remote library and you specify that name in this prompt, the local library is searched instead of the remote library. b. If you are not sure of the name, press F4 (List) with the cursor in this prompt. A list of document libraries appears.. c.cp 4. Press the Enter key. **Note:** If the remote system has DISOSS installed, the maximum number of documents to be returned was already determined when DISOSS was configured. The maximum number of documents to be returned is either the number you type for this prompt, or a number not exceeding the configured DISOSS amount, whichever is less.

e. Docu**ment des**c**ription. T**his is the description of the document you want to find and can be up to 44 characters long. You can type the exact description, or you can do a generic or contextual search on this prompt. You can type search values in either uppercase or lowercase characters. A **generic** **search** is a search where you type a few characters and then follow them with an asterisk (*). For example, if you type SM*, you `ge`t a match if that field starts with the letters SM, such as SMith or SMall. A contextu**al search** i**s simi**lar to a generic search except the string of characters specified can occur anywhere in the field being searched. To indicate a contextual search, put an apostrophe (') before and after the string of characters you type. For example, if you type 'WAY', y`ou wo`uld get matches on such things as highWAY, sWAY, WAYside, and WAY station.

**Note:** Contextual searching is not supported on a remote system that has DISOSS installed.
