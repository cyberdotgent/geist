#### 5\.4\.1\.5 Printing a Local Document

To print a local document, do the following:

1\. On the Work with Documents and Folders display, type option **4** \(Work with document lists\)\. Press the Enter key\.

2\. The Work with Owned Document Lists display appears\. On this display, move the cursor next to the description that contains the document you want to work with and type a **5** \(Work with documents in list\)\. Press the Enter key\.

3\. The Work with Documents in a List display appears\. On this display, move the cursor next to the description of the document you want to print and in the *Opt* column do one of the following:

- Type a **6** \(Print\) to print your document without options \(the system controls the printing\)\.
- Type a **9** \(Print options\) to print your document with options \(you control the printing\)\. For information about the printing options, see ["Printing a Mail Item with Options" in topic 2\.1\.2\.1](2-1-2-1.md)\.

4\. Press the Enter key\. Your print request is sent to the system\.

5\. Press F3 \(Exit\)\.
