## 1\.30 Printing a Calendar or Calendar Group

You can print a calendar in a format similar to the Weekly Calendar display, or print the items on a calendar in a daily format similar to the Daily Calendar display\. When you are completing the prompts to print a calendar, you can select either or both formats\. You can also print a calendar group or each calendar in a group\.

To print a calendar, or each calendar in a group, do the following:

1\. On the Daily, Weekly, Group, Composite, or Six Month Calendar display, press F15 \(Print\), or type **PRT** in the *Function* and press the Enter key\. 2\. The Print Calendar display appears\.

3\. For the *Calendar* prompt, type the name of the calendar or calendar group you want to print\.

4\. Press the Enter key\. The Print Calendar display appears with additional prompts\.

```
        __________________________________________________________________________________
       |                                                                                  |
 |     |                                    Print Calendar                                |
       |                                                                                  |
 |     |   Type choices, press Enter.                                                     |
       |                                                                                  |
 |     |     Calendar . . . . . . . . .    HANSON ROCH                                    |
 |     |     Start date . . . . . . . .    10/18/89          MM/DD/YY                     |
 |     |     Output format  . . . . . .    1                 1=Weekly format              |
 |     |                                                     2=Daily format, 3=Both       |
 |     |         From/To  . . . . . . .     8:00a   5:00p    hh:mmA, hh:mmP...            |
 |     |         Time interval  . . . .    30                5-60 minutes                 |
 |     |         Columns  . . . . . . .    5                 5-7                          |

 |     |     Printer file . . . . . . .    QPOOCAL           Name                         |

       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
 |     |   F3=Exit   F4=Prompt   F5=Refresh   F9=Six month calendar   F12=Cancel          |
 |     |   F19=Display messages                                                           |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

5\. If you specified a group calendar or distribution list for the *Calendar* prompt, do the following:

a\. For the *Calendar type* prompt, type a **1** \(Individual\) if you want each calendar in the group to print one right after the other\. Each is the same as printing a single calendar\. Type a **2** \(Group\) if you want to print the calendar similar to the Group Calendar display\. Each column printed represents one calendar and the number of columns that were selected for printing \(5, 6, or 7\) will be printed across a page for the weekly format\.

b\. The *Start Calendar* prompt shows the name of the first calendar in the group\. This is the first calendar printed\. If you want another calendar in the group printed first, type the name of that calendar for this prompt\. Any calendar listed in the group before the calendar specified is not printed\.

**Note:** Calendars on remote systems cannot be printed\.

c\. The *End Calendar* prompt shows the name of the last calendar in the group\. This is the last calendar printed\. If you want another calendar in the group printed last, type the name of that calendar for this prompt\. Any calendar listed in the group after the calendar specified is not printed\.

6\. For the *Start date* prompt, type the starting date for the calendar\.

7\. For the *Output format* prompt, do one of the following:

- Type a **1** \(Weekly format\) if you want to print the calendar in a column format similar to the Weekly Calendar display\.
- Type a **2** \(Daily format\) if you want to print the calendar in a format similar to the Daily Calendar display\.
- Type a **3** \(Both\) if you want to print the calendar in both a weekly and daily format\.

8\. If you changed the *Output format* prompt, press the Enter key\. The prompts now shown on your display vary according to what you typed for the *Output format* prompt\.

9\. If you typed a `1` \(Weekly format\) or `3` \(Both\) for the *Output format* prompt, do the following:

a\. For the *From/To* prompts, type the starting and ending times you want to print for the calendar\.

b\. For the *Time interval* prompt, type the time interval you want between calendar items\. If the default time interval is satisfactory, do not change it\. If you decide to change the time interval, type a number between 5 and 60 to specify the number of minutes per time slot in the day\.

**Note:** A maximum of 60 time slots can be printed\.

c\. For the *Columns* prompt, type how many columns you want on the calendar\. This number can be `5` through `7`\. Specify one column for each day you want to view\.

10\. If you typed a `2` \(Daily format\) or a `3` \(Both\) for the *Output format* prompt, then for the *End date* prompt, type the ending date of the calendar\.

11\. For the *Printer* prompt, type the printer ID that you want to print your printer output\. This prompt defaults to `*USRPRF` and indicates that the printer specified in your user profile will print your printer output\. If you want another printer to print your printer output, type the identification for that printer for this prompt\. If you are not sure of the identification of a printer, ask your administrator\.

12\. For the *Output queue* prompt, type the name of the output queue where you want the calendar listing to wait for printing\. If you specify `*DEV` for the output queue, then the output queue with the same name as the printer specified for the *Printer* prompt is used\. If you specify `*FILE`, then the output queue and library found in the printer file you specified for the *Printer file* prompt is used\.

13\. For the *Library* prompts, type the name of the library where the output queue or printer file is located\. If you specify `*LIBL`, your job's library list that indicates the libraries and the order in which to search them is used\.

14\. For the *Printer file* prompt, you can specify the name of the printer you are using\. The default for this prompt is IBM\-supplied printer file `QPOOCAL`\.

15\. Press the Enter key\. A message is shown on the message line of your display that your print job has been submitted to the system\.

16\. Press F3 \(Exit\)\.
