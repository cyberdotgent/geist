### PREFACE\.5\.5 Help for Control Language Commands

To see prompts for parameters for a control language command, type the command, then press F4 \(Prompt\) instead of the Enter key\. To see extended help for the command, type the command and press the Help key\. You can see contextual help for CL commands also\.
