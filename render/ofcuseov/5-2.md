doing the following: 1. On the Work with Documents and Folders display, type option **2** (Work with folders). 2. The *Work* *on* *behalf* *of* prompt for a local user is displayed if you have | authority to work on behalf of another user on the local system. If | you want to work on behalf of another user, type the user ID/address | or nickname of that person for this prompt. If you are not sure of the user ID, press F4 (List) with the cursor in this field. A list of the user IDs you are authorized to work for appears. 3. The *Document* *library* *to* *use* *for* *search* prompt is shown only if the system has document library services support to one or more remote systems. The information for this prompt shows a default of the name of the local document library unless you have changed this prompt to the name of another document library. Do not change the information for this prompt. 4. Press the Enter key.
