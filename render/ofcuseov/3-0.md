# 3\.0 Chapter 3\. Sending and Receiving Messages

<a id="HDRMESS"></a>

This chapter describes how to send and receive messages using OfficeVision/400\. You can also forward and reply to messages, but you cannot file or print them\.

A **message** is usually a few lines of text sent immediately from one user to another user or users\. The maximum length of a message is 256 characters of text\.
