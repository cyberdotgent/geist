#### 5.4.1.8 Sending a Local Document to Another User

1. On the Work with Documents and Folders display, type option **4** (Work with document lists). Press the Enter key. 2. The Work with Owned Document Lists display appears. On this display, move the cursor next to the description that contains the document you want to work with and type a 5 (W**o**rk with documents in list). Press the Enter key. 3. The Work with Documents in a List display appears. On this display, move the cursor next to the description of the document you want to send to someone and in the Opt *col*umn, type a 10 (**Se**nd). Press the Enter key. 4. The Send a Document display appears with the name of the document you want to send at the top of the display.
