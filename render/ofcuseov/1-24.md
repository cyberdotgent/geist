If you type a day, type MON, **TU**E, **WE**D THU, **FR**I, **SA**T, **or** SUN. **W**hen you type a day and the date of that day | is shown on the calendar, then that date is the date on which the item is copied. If the day is not shown, then the item is copied to the next occurrence of that day. If you type a date, type the date in the format shown for the Date*/day pro*mpt. 5. Change the times for the *From* and *To* prompts to the starting and ending times for the new item you want to schedule. 6. Press the Enter key. The new item is added to the calendar specified. 7.
