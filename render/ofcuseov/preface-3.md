## PREFACE.3 How This Manual Is Organized

<a id="HDRABTHOW"></a>

This manual is organized as follows:

Chapt [er 1 desc](1-0.md) ribes how to use the calendar functions included with | OfficeVision/400. Chapt [er 2 desc](2-0.md) ribes how to use the mail functions included with | OfficeVision/400. Chapt [er 3 desc](3-0.md) ribes how to send and receive messages using | OfficeVision/400. [Chapter 4](4-0.md) describes the note function of OfficeVision/400. [Chapter 5](5-0.md) describes how to handle filed documents using the documents | and folders function of OfficeVision/400. [Chapter 6](6-0.md) describes how to use the directories and distribution lists | functions of OfficeVision/400. [Chapter 7](7-0.md) describes how a user that is not an administrator can use | the administrative functions of OfficeVision/400. [Appendix A](a-0.md) describes the differences between OfficeVision/400 and Personal Services/36. [Appendix B](b-0.md) describes the differences between OfficeVision/400 and Personal Services/38. [Appendix C](c-0.md) lists the double-byte input capable prompts for the | calendar, system distribution directory, and administration functions | of OfficeVision/400. | In the back of this manual is a glossary and an index. Use the glossary | to find the meaning of an unfamiliar term. Use the index to look up a | topic and to see on which pages the topic is covered.
