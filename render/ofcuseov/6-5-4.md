### 6.5.4 Performing the Search Function

| To search the system distribution directory, do the following:

1. On the OfficeVision/400 menu, type option **7** (Directories and distribution lists) and press the Enter key.. c.cp

2. The Directories and Distribution Lists display appears. | Directories and Distribution Lists | Select one of the following: | 1. Personal directories | 2. System directory | 3. Distribution lists | 4. Nicknames | 5. Search system directory | 6. Departments | Selection

| _ | F3=Exit F12=Cancel F19=Display messages

3. For the *Selection* prompt, type a **5** (Search system directory). Press

the Enter key. The Search System Directory display appears. | Search System Directory

| Type choices, press Enter. | Last name . . . . . ______________________________________________ | First name. . . . . ________________________ | Middle name . . . . ________________________ | Department . . . _______________ | F3=Exit F5=Refresh F12=Cancel

4. For the *Last* *name* prompt, type the last name of the user for whom you are searching.

5. For the *First* *name* prompt, type the first name of the user for whom you are searching. The system searches for both the first name and the preferred name of the user.

6. For the *Middle* *name* prompt, type the middle name of the user for whom you are searching.

7. For the *Department* prompt, type the department of the user for whom you are searching. 8. After you type the information, press the Enter key. If no matches are found, a message appears at the bottom of your display indicating no matches were found. Any matches found are shown alphabetically by full name on the

| following display: | Display Names from Search Results | Type options, press Enter. | 5=Display directory entry details 6=Print directory entry details | 8=Display department members | Opt Name Telephone Number | _ Mark Allen Smith (123)976-1234 | _ Mark Allen Smith (123)976-0000 __ | F3=Exit F5=Refresh F11=Display user IDs and departments F12=Cancel | F15=Print list | You can move the cursor down to a name and in th*e O*pt prompt, type **a** 5 | (Display directory entry details) to display more details, or you can

type a **6** (Print directory entry details) to print the results of your search request. Pressing the Enter key without typing any options returns you to the Search System Directory display. To display department details, you can move the cursor down to a name
