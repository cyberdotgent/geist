### 7\.5\.2 Restoring Calendar Items

Restoring calendar items lets you put back on the system any calendar items you previously saved on diskette or tape\. To restore calendar items, do the following:

1\. On the Administration display, type option **5** \(Work with Office files\) and press the Enter key\.

2\. The Specify Office Files display appears\. For the *Type of file* prompt, type a **1** \(Calendar\), and for the *Option* prompt, type a **2** \(Restore\)\. Press the Enter key\. 3\. The Restore Calendar Items display appears\.

```
        __________________________________________________________________________________
       |                                                                                  |
 |     |                              Restore Calendar Items                              |
       |                                                                                  |
 |     |  Type choices, press Enter.                                                      |
       |                                                                                  |
 |     |    Calendar . . . . . . . .   __________   Name                                  |
       |                                                                                  |
 |     |    Start date . . . . . . .   __________   MM/DD/YY                              |
       |                                                                                  |
 |     |    End date . . . . . . . .   __________   MM/DD/YY                              |
       |                                                                                  |
 |     |    Calendar to restore to     __________   Name, F4 for list                     |
       |                                                                                  |
 |     |    Device . . . . . . . . .   __________   Name                                  |
       |                                                                                  |
 |     |    Print items  . . . . . .   Y            Y=Yes, N=No                           |
       |                                                                                  |
 |     |    Wait for completion  . .   N            Y=Yes, N=No                           |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
 |     |  F3=Exit   F4=Prompt   F5=Refresh   F12=Cancel   F19=Display messages            |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

4\. For the *Calendar* prompt, type the name of the calendar where the items are\.

5\. If you want to restore calendar items for a specific range of time, specify the date to start for the *Start date* prompt and the date to end for the *End date* prompt\. When typing each date, use the same format as in the date prompt on your display\. To restore all items type **\*ALL** for the *Start date* prompt and leave the *End date* prompt blank\.

6\. For the *Calendar to restore to* prompt, type the name of the calendar where the items are to go\. If you do not know the name, press F4 \(Prompt\) with the cursor in this prompt for a list of existing calendar names\.

7\. For the *Device* prompt, type the name of the device that you want to restore the calendar from\. This can be the name of either a diskette or tape device\.

8\. For the *Print items* prompt, leave the `Y` \(Yes\) if you want to print the calendar items you are restoring, or type an **N** \(No\) if you do not\.

9\. For the *Wait for completion* prompt, type a **Y** \(Yes\) to run the job interactively, which means you wait while the calendar items are being restored\. If you leave the `N` \(No\), the job runs in batch mode, which means you can continue working on something else at your display station\.

10\. Press the Enter key\. The calendar items are restored\.

11\. The Restore Calendar Items display appears again\. You can continue restoring other calendar items by repeating this procedure, or press F3 \(Exit\)\.
