## 2.4 Working with the Someone Else's Mail

This topic shows you how to work with the mail of another user. To work with the mail of another user, do the following: 1. On the Work with Mail display, type the user ID or nickname of the

person whose mail you want to work with for the Work*ing wit*h *mai*l *for* prompt and press the Enter key. If you are not sure of the user ID, press F4 (Prompt) with the cursor in this prompt. A list of the user

IDs that you are authorized to work with is shown.
