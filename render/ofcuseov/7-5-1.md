### 7.5.1 Saving Calendar Items

By saving calendar items, you can remove items from a calendar that you do not need at the present time but may need for later use and place them on a diskette or tape. To save calendar items, do the following:

1. On the Administration display, type option **5** (Work with Office files) and press the Enter key. 2. The Specify Office Files display appears. For the *Type* *of* *file* prompt, type a 1 (C**a**lendar), and for the Opti*on pro*mpt, type a 1 (Save). Press the Enter key.

For the *Calendar* prompt, type the name of the calendar that contains the items you want to save. If you do not know the name, press F4 (List) with the cursor in this prompt for a list of existing calendar names. If you want to save the calendar items for a specific range of time, specify the date to start for the Star*t dat*e *pro*mpt and the date to end for the End *dat*e *pro*mpt. For the *Device* prompt, type the name of the device that you want to save the calendar items on. This can be the name of either a diskette or tape device. If you typed the name of a tape device, you also need to specify what should be done with the tape after the calendar items are saved. For *the* End *of* *tape* *option* prompt, do one of the following: Type a 1 (Rewin**d**) if you want the tape rewound after the save but left loaded in the tape device. Type a 2 (Leave**)** if you want the tape left where it is after the save. Select this option if you are saving several calendars on a tape. Type a 3 (Unloa**d**) if you want the tape rewound and unloaded after the save. 6. For the *Delete* *items* prompt, type a **Y** (Yes) if you want to have the items you are saving deleted from the system after they are saved; otherwise, leave the N (N`o`). 7. For the *Print* *items* prompt, leave the `Y` (Yes) if you want to print the calendar items you are saving or type an N (N**o**) if you do not. 8. For the *Wait* *for* *completion* prompt, type a **Y** (Yes) to run the job interactively, which means you wait while the calendar items are being .. saved. If you leav`e` the N (No), the job runs in batch mode, which means you can continue working on something else at your display station. 9. Press the Enter key. The calendar items are saved. 10. The Save Calendar Items display appears again. You can continue saving other calendar items by repeating this procedure, or press F3 (Exit).
