### 7\.1\.1 Changing Your System Distribution Directory Information

<a id="HDRCHGDIR"></a>

You can change information about yourself in the system distribution directory by doing the following:

1\. On the AS/400 Main Menu, type option **2** \(Office tasks\) and press the Enter key\. The Office Tasks menu appears\.

**Note:** If the AS/400 Main Menu does not appear after you sign on, type the Start Office \(STROFC\) command on the command line of the display and press the Enter key\. The OfficeVision/400 menu appears\. Skip step [2](7-1-1.md) and go to step [3](7-1-1.md)\.

<a id="LIScys"></a>

2\. On the Office Tasks menu, type option **1** \(OfficeVision/400\) and press

<a id="ELIScys"></a>

the Enter key\. The OfficeVision/400 menu appears\.

<a id="LIScyd"></a>

3\. On the OfficeVision/400 menu, type option **9** \(Administration\) and press

<a id="ELIScyd"></a>
