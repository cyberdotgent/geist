### 1.18.1 Viewing an Item

You can see the details of a calendar item that you or someone else has scheduled on your calendar by doing the following: 1. Move the cursor to an item on the Daily or Weekly Calendar display and press F9 (Display item).

**Note:** On the Weekly or Daily Calendar display, you may also type the

reference number of the item for the Function pr*ompt to* view an item. The reference n**umber is** t**he num**ber the system assigns to a calendar item. These numbers are in numeric order on the display and show which item it is for the week or day displayed. On the Weekly Calendar display, this number is to the right of the time for an event, meeting, job, or procedure. However, because reminders are indicated at the top of the display for a day, a number for each of these is not shown even though one is assigned to it. On the Daily Calendar, each calendar item has a reference number. This number is in the Nbr column *to* the left of the description for the item. 2. The details about the calendar item appear on the bottom half of the display. This display shows how an item for an event appears when the reference number for it is typed for the Func*tion pro*mpt.
