### 7.5.4 Deleting Calendar Items

1. On the Administration display, type option **5** (Work with Office files) and press the Enter key. 2. The Specify Office Files display appears. For the *Type* *of* *file* prompt, type a 1 (C**a**lendar), and for the Opti*on pro*mpt, type a 4 (Delete). For the *Calendar* prompt, type the name of the calendar that you want the system to delete items from. If you do not know the name, press F4 (List) with the cursor in this prompt for a list of existing calendar names. 5. If you want to delete calendar items for a specific range of time, specify the date to start for the Star*t dat*e *pro*mpt and the date to end for the End *dat*e *pro*mpt. To delete all items, type *ALL **for** the Star*t dat*e *pro*mpt and leave the End *dat*e *pro*mpt blank. When typing each date, use the same format as in the date prompt on your display. 6. For the *Print* *items* prompt, leave the `Y` (Yes) if you want to print the calendar items you are deleting, or type an N (N**o**) if you do not. 7. For the *Wait* *for* *completion* prompt, type a **Y** (Yes) to run the job interactively, which means you wait while the calendar items are being .. deleted. If you leav`e` the N (No), the job runs in batch mode, which means you can continue working on something else at your display station. 8. Press the Enter key. The calendar items are deleted. 9. The Delete Calendar Items display appears again. You can continue deleting other calendar items by repeating this procedure, or press F3 (Exit).
