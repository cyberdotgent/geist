# 7\.0 Chapter 7\. Handling Administrative Functions

<a id="HDRADMFUN"></a>

This chapter describes how you can use the administrative functions of OfficeVision/400 if you are not an administrator\. The functions include such things as changing your enrollment, displaying access codes, giving and removing authority, working with owned objects, and changing calendar and personal directory information\.

For information about administrative functions for an administrator, see the *Managing OfficeVision/400* manual\.
