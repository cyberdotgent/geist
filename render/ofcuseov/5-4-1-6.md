#### 5\.4\.1\.6 Viewing Details of a Local Document

To view the details of a local document, do the following:

1\. On the Work with Documents and Folders display, type option **4** \(Work with document lists\)\. Press the Enter key\.

2\. The Work with Owned Document Lists display appears\. On this display, move the cursor next to the description that contains the document you want to work with and type a **5** \(Work with documents in list\)\. Press the Enter key\.

3\. The Work with Documents in a List display appears\. On this display, move the cursor next to the description of the document you want to see the details of and, in the *Opt* column, type a **7** \(View details\)\.

4\. Press the Enter key\. The View Document Details \(Page 1 of 2\) display appears\. To see the View Document Details \(Page 2 of 2\) display, press the Page Down key\.

5\. If you need an explanation for a prompt on either display, see ["Changing Details of a Local Document" in topic 5\.4\.1\.7](5-4-1-7.md)\.

6\. When you have finished viewing the details, press F3 \(Exit\)\.
