### 3.1.1 Sending a Message Specifying the User ID

This topic shows you how to send a message to another user. To send a message specifying the user ID, do the following:

1. On the AS/400 Main Menu, type option **2** (Office tasks) and press the Enter key. The Office Tasks menu appears. .. Note: If the AS/400 Main Menu does not appear after you sign on, type the Start Office (STROFC) command on the command line of the | display and press the Enter key. The OfficeVision/400 menu appears. Skip step [2](3-1-1.md) and go to step [3.](3-1-1.md)
