### 4\.2\.2 Completing and Sending an Unfinished Note

<a id="HDRCOMNO"></a>

You can complete an unfinished note \(that you saved to work on later\) and then send it by doing the following:

1\. On the Send a Note display, press F16 \(Work with saved notes\)\.

2\. The Work with Saved Notes display appears showing a list of the notes you have saved\.

```
        __________________________________________________________________________________
       |                                                                                  |
       |                               Work with Saved Notes                              |
       |                                                                                  |
       |   Type options, press Enter.                                                     |
       |     1=Continue note    4=Delete                                                  |
       |                                                                                  |
       |   Option    Name           Description                                           |
       |     _       AKPC5322.12    Paper specifications review                           |
       |     _       AKDF3791.42    Presentation for department meeting                   |
       |     _       AKLM1253.33    Project status                                        |
       |     _       AKGJ4834.22    Request for new furniture                             |
       |     _       AKTP6915.54    Vacation schedules                                    |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                           Bottom |
       |   F3=Exit   F5=Refresh   F12=Cancel   F19=Display messages                       |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

3\. Move the cursor next to the note you want to complete and type a **1** \(Continue note\)\. Press the Enter key and your note appears\. If you need information on how to complete the note, see ["Creating and](4-2.md) [Sending a Note" in topic 4\.2](4-2.md)\.

4\. After you complete your note, press F10 \(Send\)\. The Work with Saved Notes display appears again\. On this display, you can complete another unfinished note, or if you want to delete any unfinished note, move the cursor next to each of those notes and type a **4** \(Delete\)\. Press the Enter key\.

5\. The Confirm Delete of Notes display appears showing what you have selected to delete\.

```
        __________________________________________________________________________________
       |                                                                                  |
       |                               Confirm Delete of Notes                            |
       |                                                                                  |
       |   Press Enter to confirm your choices for 4=Delete.                              |
       |   Press F12 to return to change your choices.                                    |
       |                                                                                  |
       |   Option    Name           Description                                           |
       |     4       AKDF3791.42    Presentation for department meeting                   |
       |     4       AKGJ4834.22    Request for new furniture                             |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                                  |
       |                                                                           Bottom |
       |   F12=Cancel                                                                     |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

6\. Press the Enter key to confirm the deletion or F12 \(Cancel\) to return to the Work with Saved Notes display, where you can change your selection\.

7\. Press F3 \(Exit\)\.
