### 2.3.1 Creating a Local Hard-Copy Reference

This procedure shows you how to create references for hard-copy mail, which are then filed on your local system. To create a local reference to hard-copy mail, do the following: 1. On the Work with Mail display, press F13 (More mail tasks).

2. The More Mail Tasks display appears. More Mail Tasks Select one of the following: 1. Create local hard-copy reference 2. Create remote hard-copy reference 3. Select mail by status 4. Print mail reports
