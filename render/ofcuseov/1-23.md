## 1\.23 Deleting Multiple Occurrences of a Meeting

To delete multiple occurrences of a meeting, do the following:

1\. On the Daily or Weekly Calendar display, move the cursor to the meeting you want to delete\. Press F16 \(Remove item\)\. The Confirm Remove of Calendar Item display appears\.

2\. Press F11 \(Delete meeting\)\. The Confirm Delete of Meeting display appears\.

 |     |   From/To . . . . . . . . :   10:00a  7:00p                                      |
       |                                                                                  |

       |                                                                                  |

 |     |   F19=Display messages                                                           |
 |     |   Multiple occurrences exist. Press F16 to delete all.                           |
       |                                                                                  |

```

3\. On the Confirm Delete of Meeting display, press F16 \(Delete multiple meetings\)\.

The Confirm Delete of Multiple Meetings display appears\.

       |                                                                                  |

 |     |   10/27/89     10:00a  7:00p  Status review meeting                              |
 |     |   11/03/89     10:00a  7:00p  Status review meeting                              |

       |                                                                                  |

 |     |                                                                     Bottom       |
       |                                                                                  |
 |     |   F9=Six month calendar   F11=Display places   F12=Cancel                        |
 |     |   F19=Display messages                                                           |
       |                                                                                  |
       |                                                                                  |
       |__________________________________________________________________________________|
```

**Note:** If you want to display the meeting owner \(user ID and address\) and the place of the meeting, press F11 \(Display places\)\.

4\. To delete the multiple meetings, press the Enter key\. The Daily or Weekly Calendar display reappears\. If you press F12 \(Cancel\), the multiple meetings are not deleted, and the Confirm Remove of Calendar Item display appears again\.

5\. Press F3 \(exit\)\.
