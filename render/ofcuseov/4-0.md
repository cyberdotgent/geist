# 4.0 Chapter 4.  Working with Notes

<a id="HDRNOTES"></a>

This chapter describes the note function of OfficeVision/400. A **note** is a small, formatted document used for informal correspondence. You can either create a note and send it right away, or you can start creating a note which you can finish and send at a later time.
