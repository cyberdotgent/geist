#### 5.4.2.4 Displaying Details of a Remote Document

To display the details of a remote document, do the following:

1. On the Work with Documents and Folders display, type option **4** (Work with document lists). Press the Enter key. 2. The Work with Owned Document Lists display appears. On this display, move the cursor next to the description that contains the document you want to work with and type a 5 (W**o**rk with documents in list). Press the Enter key. 3. The Work with Documents in a List display appears. On this display, move the cursor next to the description of the document you want to see the details of and in the Opt *col*umn, type a 7 (V**i**ew details). Press the Enter key. 4. The first page of the View Document Details display appears. The prompts that appear on both pages of the View Document Details display depend on what kind of system the remote document library is on and the type of document.
