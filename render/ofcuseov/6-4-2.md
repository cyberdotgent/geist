### 6\.4\.2 Changing or Deleting a Personal Directory

Sometimes you may need to change information about a personal directory you own\. For example, you may want to change the type of authority that users have to a personal directory or the way it looks\. Also, you may decide to delete a personal directory you own that is no longer needed\. If you want to change or delete entries in a personal directory, see the topic ["Viewing, Changing, or Deleting a Personal Directory Entry" in](6-4-5.md) [topic 6\.4\.5](6-4-5.md)\.

To change or delete a personal directory, do the following:

1\. On the Directories and Distribution Lists display, type option **1** \(Personal directories\)\. Press the Enter key\.

2\. The Specify Personal Directory Criteria display appears\. If your administrator has specified a default personal directory for you, your display appears slightly different from the following display\. Press F13 \(More tasks\)\.

4\. For the *Selection* prompt, type a **1** \(Work with personal directory\)\.

5\. For the *Personal directory* prompt, type the name of the personal directory that you want to change or delete\. Press the Enter key\.

6\. The Work with Personal Directory display appears for the name you specified on the More Personal Directory Tasks display\.

7\. Do one of the following:

- Change any information for the *Owner, Authority*, and *Description* prompts and for the *Field Name* column as needed\. If you need more information about any of the prompts, press the Help key, or see the description of each one under the topic ["Creating a Personal](6-4-1.md) [Directory" in topic 6\.4\.1](6-4-1.md)\. Press the Enter key\. The changes are made\.

**Note:** You can change the information for the *Owner* prompt only if you are an administrator\.

- If you want to delete this personal directory, press F16 \(Delete\)\. At the bottom of the display, the following message appears:

`REMOVE request. Press Enter to remove, F5 to cancel.`

If you are deleting the wrong personal directory, press F5\. If you want to delete this personal directory, press the Enter key\. The personal directory is deleted\.

8\. Press F3 \(Exit\)\.
