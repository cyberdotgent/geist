## 5.4.1.1 Revising a Local Document

<a id="HDRREVLOC"></a>

#### Revising a Local Document

To revise a local document, do the following:

1. On the Work with Documents and Folders display, type option **4** (Work with document lists). Press the Enter key. 2. The Work with Owned Document Lists display appears. On this display, move the cursor next to the description that contains the document you want to work with and type a 5 (W**o**rk with documents in list). Press the Enter key. 3. The Work with Documents in a List display appears. On this display, move the cursor next to the description of the document you want to

revise and in the Opt column, type a 2 (Revise). Press the Enter key. 4. One of the following displays appears:
