### 4\.3\.1 Setting up Communications

<a id="HDRSWINSC2"></a>

In this chapter we assume that the Microsoft SNA Server \(Server software\) is installed in a server gateway machine, and we will install only the Microsoft SNA Server Client version to connect the IBM CICS Transaction Server for Windows NT to the CICS/VSE system\.

The installation of Microsoft SNA Server \(Server software\) was described in ["Setting up Communications" in topic 4\.2\.1](4-2-1.md)\.

The installation of the Microsoft SNA Server \(Client software\) is described in **Microsoft SNA SERVER*****\- Getting Started***\. Please follow all the steps described in this book, but first read the following information about system requirements to install the product, and procedures for installation\.
