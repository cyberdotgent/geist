### 3\.3\.2 Defining Connection and Sessions Parameters to CICS/VSE

<a id="HDRCICSCON"></a>

For each Transaction Server and for each client you connect to CICS/VSE directly you should define a CICS connection and session\. This has to be done for clients and servers on an OS/2 platform as well as for those on a Windows platform\.

Below we show the definitions used for the CICS Transaction Server for OS/2\. Definitions for the Transaction Server for Windows NT and for the clients are the same, except for the NetNames used and, of course, the connection and session name itself\.
