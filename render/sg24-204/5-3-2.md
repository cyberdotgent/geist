### 5\.3\.2 Connecting to Transaction Server for OS/2 Warp

<a id="HDRCOS2OSC"></a>

To connect a CICS Client for Windows to Transaction Server for OS/2 you need to:

- Configure a protocol to communicate with the OS/2 Server
- Set up the CICSCLI\.INI file on the workstation
- Set up the Transaction Server for OS/2

The simplest way to connect a Windows CICS Client workstation to a Transaction Server for OS/2 is to use the TCP/IP protocol\.

TCP/IP support is provided by the Windows/95 and Windows/NT operating systems\. Refer to the appropriate Windows documentation for information on configuring TCP/IP\.

To configure TCT/IP for communication with CICS servers, you need to know the following:

- The IP address/host name of the CICS clients
- The IP address/host name of the CICS servers
- The IP address/name of any domain nameserver
- The subnet mask \(if required\)
- The port number of the CICS servers

Your system administrator can supply this information, which is also used in preparing the CICS client initialization file\. \>\> ***CICSCLI\.INI File Definitions*** \<\<

To set up the CICS client you need to edit the **CICSCLI\.INI** file \.\.***\\cicscli\\bin***\) and change the required parameters\.

Below are shown the important parts of our CICSCLI\.INI file \(the whole file is listed in ["CICS Client File for Windows" in topic B\.2](b-2.md)\)\.

<a id="FIGCLNT52"></a>

```
    __________________________________________________________________________ 
   |                                                                          |
   |   Client = *                      ; Auto-install client on the server    |
   |      MaxServers = 1               ; Only allow one server connection     |
   |      MaxRequests = 20             ; Limit the maximum server interaction |
   |      MaxBufferSize = 32           ; Allow for a 32K maximum COMMAREA     |
   |      LogFile = CICSCLI.LOG        ; Set the error log file name          |
   |      TraceFile = CICSCLI.TRC      ; Set the trace log file name          |
   |      DumpFile = CICSCLI.DMP       ; Set the memory trace dump file name  |
   |      DumpMemSize = 16             ; Allow for 16K of trace in memory     |
   |      DosMemory = 48               ; The DOS client's memory pool size    |
   |                                                                          |
   |__________________________________________________________________________|
```

*Figure 111\. CICS Client for WIndows INI File: Client Section*

<a id="FIGCLNT53"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   Server = CICSTCP               ; Arbitrary name for the server          |
   |      Description = TCP/IP Server ; Arbitrary description for the server   |
   |      Protocol = TCPIP            ; Matches with a Driver section below    |
   |      NetName = 9.164.180.140     ; The server's TCP/IP address            |
   |      Port = 0                    ; Use the default TCP/IP CICS port       |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 112\. CICS Client for Windows INI File: Server Section*

- The **NetName** address must be the TCP/IP address of your OS/2 Transaction Server machine and must match the **TCP/IP Local Host**

**Name** defined in CICS shown in [Figure 51 in topic 4\.1\.2](61.png)\.

<a id="FIGCLNT54"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   Driver = TCPIP                 ; Matches the Server's Protocol value    |
   |      DriverName = CCLWNTIP       ; Use the WinNT TCP/IP communications DLL|
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 113\. CICS Client for Windows INI File: Driver Section*

- The TCPIP driver **CCLWNTIP** is required\.

\>\> ***CICS Transaction Server Definitions*** \<\<

To set up the Transaction Server for OS/2 to receive requests from CICS clients using a TCP/IP connection, you need to define the TCP/IP parameters in the **SIT** table as shown on [Figure 51 in topic 4\.1\.2](61.png)\.

If your Transaction Server is set up as described in [Chapter 4,](4-0.md) ["Transaction Servers" in topic 4\.0](4-0.md) it can access CICS for VSE/ESA\. In this case, your CICS client can, through the Transaction Server, connect to CICS for VSE/ESA\.
