        Setting up Communications
       The installation of SNA Server 3.0 is very easy and is documented in
       Microsoft SNA SERVER- Getting Started. Please follow all the steps
       described in that book. But first check the system requirements to
       install the product:
       &diam. Minimum of 20MB of total system RAM (recommended).
       &diam. Minimum of 11MB free hard-disk space.
       After you have completed the installation, select the Manager icon
       from the Microsoft SNA Server menu as shown below.

       &diam. From the Microsoft SNA Server Manager Window select the icon
           with the name of the workstation where you have installed the SNA
           Server (right mouse button).
       &diam. Select Properties to set up the common definitions for the SNA
           Server (left mouse button).
                                    PICTURE 67
   Figure 57. Server Properties - General
       &diam. The Network Name field must match the NETID field shown in
           Figure 17 in topic 3.2.1.
       &diam. Type a name in the Control Point Name field.  It must be unique
           for each server within the same network.
       &diam. Select the Server Configuration panel.
                                    PICTURE 68
   Figure 58. Server Properties - Server Configuration
       &diam. Please consult HELP for information about the settings.
       &diam. Click on the  PICTURE 69 button.
       &diam. You will return to Figure 56.
       &diam. Select the same SNA Server workstation again (right button).
       &diam. Select Insert and Link Service...  (left button).
                                    PICTURE 70
   Figure 59. Link Service
       This will give you a list of link services from which you can select
       the one you need.
                                    PICTURE 71
   Figure 60. Insert Link Service
       &diam. Select from the list DLC 802.2 Link Service for Token-Ring.
       &diam. Click on the  PICTURE 72 button.
                                    PICTURE 73
   Figure 61. DLC 802.2 Link Service Properties
       &diam. Click on the  PICTURE 74 button.
       &diam. Click on the  PICTURE 75 button.
       &diam. You will return to Figure 56.
       &diam. Select the same SNA Server workstation again (right button).
       &diam. Select Insert and Connections and 802.2 (left button).
                                    PICTURE 76
   Figure 62. Connection Properties - General
       &diam. Type the Connection Name in the Name field.
       &diam. Select the SnaDlc1 line in the Link Service list.
       &diam. Select Host System option.
       &diam. Select Both Directions option.
       &diam. Select the Address panel.
                                    PICTURE 77
   Figure 63. Connection Properties - Address
c.cp
       &diam. You need to ask your systems programmer or your network
           administrator for information about the Remote Network Address.
           In our case, the Remote Network Address is the MAC address of the
           3172 communications controller.
       &diam. Select the System Identification panel.
                                    PICTURE 78
   Figure 64. Connection Properties - System Identification
       &diam.  Check the following:
           >   Network Name field (inserted automatically).
           >   Control Point Name field (inserted automatically).
       &diam. The two fields in Local node ID (hex) must be unique for each
           server within the same network. This parameter must match the
           IDBLK and IDNUM in the VTMSWNET Switched Major node shown on
           Figure 21 in topic 3.2.6.
       &diam. Select the 802.2 DLC tab.
                                    PICTURE 79
   Figure 65. Connection Properties - 802.2 DLC
c.cp
       &diam. You should normally not need to change anything here. Please
           use HELP for information about the settings.
       &diam. Click on the  PICTURE 80 button.
       &diam. You will return to Figure 56.
       &diam. Select the same SNA Server workstation again (right button).
       &diam. Select Insert and APPC and Local LU (left button).
                                    PICTURE 81
   Figure 66. Local APPC LU Properties - General
       &diam. The LU Alias field is a name that identifies an APPC LU to
           Local Transactions Programs.
       &diam. The Network Name field must match the NETID name shown on
           Figure 17 in topic 3.2.1.
       &diam. The LU Name field must match the Independent LU definition
           shown on Figure 21 in topic 3.2.6 and the Netname in the session
           definition of CICS/VSE (see "Defining Connection and Sessions
           Parameters to CICS/VSE" in topic 3.3.2).
           Note:  In the tested version of SNA Server, the LU Alias and the
                  LU Name must match.
       &diam. Select the Advanced panel.
                                    PICTURE 82
   Figure 67. Local APPC LU Properties - Advanced
       &diam. Select the Independent LU 6.2 Type.
       &diam. Click on the  PICTURE 83 button.
       &diam. You will return to Figure 56.
       &diam. Select the same SNA Server workstation again (right button).
       &diam. Select Insert and APPC and Remote LU (left button).
                                    PICTURE 84
   Figure 68. Remote APPC LU Properties - General
       &diam. Select the appropriate Connection from the listbox.
       &diam. The LU Alias field is the name under which the application
           program uses this connection.
       &diam. The Network Name field must match the NETID name shown on
           Figure 17 in topic 3.2.1.
       &diam. The LU Name field must match the LU Name under which CICS/VSE
           is known in the Network shown on Figure 19 in topic 3.2.4.
       &diam. Select the Options panel.
                                    PICTURE 85
   Figure 69. Local Remote APPC LU Properties - Options
       &diam. Tick the Supports Parallel Sessions.
       &diam. Click on the  PICTURE 86 button.
       &diam. You will return to Figure 56.
       &diam. Select the SNA Server folder (right button).
       &diam. Select Insert and APPC and Mode Definition (left button).
                                    PICTURE 87
   Figure 70. APPC Mode Properties - General
       &diam. Type in the Mode Name field the same Modename as defined in the
           CICS Session definition shown in Figure 27 in topic 3.3.2.1.
       &diam. Select the Limits panel.
                                    PICTURE 88
   Figure 71. APPC Mode Properties - Limits
       &diam. The Parallel Session Limit and the Minimum Contention Winner
           Limit must match the MAximum field definition in the CICS Session
           definition shown in Figure 27 in topic 3.3.2.1.
       &diam. Select the Characteristics panel.
                                    PICTURE 89
   Figure 72. APPC Mode Properties - Characteristics
       &diam. The Max Send RU Size and the Max Receive RU Size must match the
           SENDSize and the RECEIVESize field definition in the CICS Session
           definition shown in Figure 27 in topic 3.3.2.1.
       &diam. Click on the  PICTURE 90 button.
       &diam. You will return to Figure 56.
       &diam. Select the SNA Server workstation again (right button).
       Your definitions are now complete. You can now start the SNA Server:
       &diam. Select Start to start the server to activate the communication
           (left button).
   PICTURE 91
   Figure 73. SNA Server Start
