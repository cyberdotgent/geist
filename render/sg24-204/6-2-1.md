### 6\.2\.1 Session\-level LU\-LU Verification

If session\-level security is in operation, a request to bind a session \(between a communications LU and a remote LU\) activates the APPC session\-level LU\-LU verification protocol\.

To set up LU\-LU verification, the LU\-LU bind password must be defined in each of the partner systems\. To set this up, in Communications Server setup, select LU to LU Security from the Additional SNA Features window to define the required bind passwords\.
