### 5\.3\.3 Connecting to Transaction Server for Windows/NT

<a id="HDRCSWIN2"></a>
<a id="FIGCLNT55"></a>
<a id="EFIG"></a>
<a id="FIGCLNT56"></a>
<a id="FIGCLNT57"></a>

<pre>
       To connect a CICS Client for Windows to Windows/NT Transaction Server
       you need to:
       °   Configure a protocol to communicate with the server
       °   Set up the CICSCLI.INI file on the workstation
       °   Set up the Windows/NT Transaction Server
       The simplest way to connect a Windows CICS Client workstation to a
       Transaction Server for Windows/NT is to use the TCP/IP protocol.
       TCP/IP support is provided by the Windows/95 and Windows/NT operating
       systems. Refer to the appropriate Windows documentation for
       information on configuring TCP/IP.
       To configure TCT/IP for communication with CICS servers, you need to
       know the following:
       °   The IP address/host name of the CICS clients
       °   The IP address/host name of the CICS servers
       °   The IP address/name of any domain nameserver
       °   The subnet mask (if required)
       °   The port number of the CICS servers
       Your system administrator can supply this information, which is also
       used in preparing the CICS client initialization file.
       &gt;&gt;  CICSCLI.INI File Definitions  &lt;&lt;
       To set up the CICS client you need to edit the CICSCLI.INI file
       (..\cicscli\bin) and change the required parameters.
       Below are shown the important parts of our CICSCLI.INI file (the whole
       file is listed in <a href="b-2.md">"CICS Client File for Windows" in topic B.2</a>).
    __________________________________________________________________________
   |                                                                          |
   |   Client = *                      ; Auto-install client on the server    |
   |      MaxServers = 1               ; Only allow one server connection     |
   |      MaxRequests = 20             ; Limit the maximum server interaction |
   |      MaxBufferSize = 32           ; Allow for a 32K maximum COMMAREA     |
   |      LogFile = CICSCLI.LOG        ; Set the error log file name          |
   |      TraceFile = CICSCLI.TRC      ; Set the trace log file name          |
   |      DumpFile = CICSCLI.DMP       ; Set the memory trace dump file name  |
   |      DumpMemSize = 16             ; Allow for 16K of trace in memory     |
   |      DosMemory = 48               ; The DOS client's memory pool size    |
   |                                                                          |
   |__________________________________________________________________________|
   Figure 114. CICS Client for Windows INI File: Client Section
    ___________________________________________________________________________
   |                                                                           |
   |   Server = CICSTCP               ; Arbitrary name for the server          |
   |      Description = TCP/IP Server ; Arbitrary description for the server   |
   |      Protocol = TCPIP            ; Matches with a Driver section below    |
   |      NetName = 9.164.180.141     ; The server's TCP/IP address            |
   |      Port = 0                    ; Use the default TCP/IP CICS port       |
   |                                                                           |
   |___________________________________________________________________________|
   Figure 115. CICS Client for Windows INI File: Server Section
       °   The NetName address must be the TCP/IP address of your Windows/NT
           Transaction Server machine.
    ___________________________________________________________________________
   |                                                                           |
   |   Driver = TCPIP                 ; Matches the Server's Protocol value    |
   |      DriverName = CCLWNTIP       ; Use the WinNT TCP/IP communications DLL|
   |                                                                           |
   |___________________________________________________________________________|
   Figure 116. CICS Client for Windows INI File: Driver Section
       °   The TCPIP driver CCLWNTIP is required.
       &gt;&gt;  CICS Transaction Server Definitions  &lt;&lt;
       To set up the Transaction Server for Windows/NT to receive requests
       from CICS clients using TCP/IP connections, you need to define a
       TCP/IP Listener Definition as shown inFigure 90 in topic 4.2.2.4.
       If your Transaction Server is set up as described in <a href="4-0.md">Chapter 4,</a>
       <a href="4-0.md">"Transaction Servers" in topic 4.0</a> it can access CICS for VSE/ESA. In
       this case, your CICS client can, through the Transaction Server,
       connect to CICS for VSE/ESA.
</pre>
