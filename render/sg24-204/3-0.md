# 3\.0 Chapter 3\. VSE/ESA as a Server

<a id="HDRVSE"></a>

This topic describes the definitions in VSE/ESA, CICS/VSE and VSE/VTAM which are used to implement our environment\.

In our installation the VSE/ESA system runs under VM/ESA\. A 3172 communications controller is defined to VM/ESA and dedicated to the VSE/ESA system\. Since this is the only part that VM plays and since this has no further impact on the VSE/ESA, VSE/VTAM and CICS/VSE definitions, no further details relating to the VM guest definitions of the VSE system are given here\.

We describe in detail in the following topics:

- ASI procedure
- VTAM definitions
- CICS definitions\.
