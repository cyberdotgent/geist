# 1\.0 Chapter 1\. The CICS Family

CICS is a family of modern transaction processing products that enables your business to exploit applications and data on many different hardware and software platforms\. CICS is the de facto standard for transaction processing in the enterprise\.

You can use a single, standalone system with CICS to handle all your business transactions and own all your enterprise data\. But you can also interconnect various members of the CICS family, running all on the same or on different operating system platforms, to distribute data and processing across your operating environments according to your needs\.

CICS servers and IBM Transaction Servers support the functions of Intersystem Communication which allow you to distribute data and processing between systems on which CICS or Transaction Servers run\.

CICS clients on workstations offer the External Call Interface \(ECI\) and External Presentation Interface \(EPI\), which can be used to access CICS server applications and data from non\-CICS based workstation applications\.
