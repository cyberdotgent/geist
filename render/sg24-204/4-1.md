## 4\.1 The Transaction Server for OS/2 Warp

<a id="HDRSERVOS2"></a>

In this section we explain in detail how to install and set up the Communications Server for OS/2 and the CICS Transaction Server for OS/2\. The installation is based on OS/2 Warp version 4\.0, assuming that MPTS with Token\-Ring drivers are already set up\.

The following setup is based on the VSE/ESA definitions described in the previous chapter\. In particular, we make use of the fact that VTAM 4\.2 for VSE/ESA includes APPN support\. With APPN on the host, some settings for Communications Server/2 change\. But, more important, fewer definitions need to have matching values between Communication Server/2 and VTAM\. It makes the setup easier and simplifies both on the workstation and VSE/ESA sides\.

```
        ___ Warning ________________________________________________________
       |                                                                    |
       | Make sure your entries are in upper case. In some cases matching   |
       | of parameters is case sensitive.                                   |
       |                                                                    |
       |____________________________________________________________________|
```

If you already have the Communications Server for OS/2 installed, for testing purpose, we recommend that you use a new configuration file because adding values to an existing configuration file may cause conflicts with existing, installed definitions\. After testing you can merge the new configuration to the old one\.
