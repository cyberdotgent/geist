## 4\.2 The Transaction Server for Windows NT

<a id="HDRSERVWIN"></a>

In this section we explain in detail how to install and set up the Microsoft SNA Server and the IBM Transaction Server for Windows/NT\. The installation is based on Windows/NT version 4\.0, assuming that MPTS with Token\-Ring drivers are already set up\.

The following sample installation and setup is based on the VSE/ESA definitions described in the previous chapter\. In particular, we use the PU definition **SNASVR1** and the Independent LU **NTLOCLU1**, both defined in the **VTMSWNET** Switched Major node\.

**Notes:**

1\. Microsoft SNA Server does not support APPN connections to VTAM\. So, unlike the OS/2 case, for links defined through the SNA Server we needed to define an independent LU in VTAM under VSE/ESA, because APPN support is necessary to be able to make use of the dynamic LU definition facility on the VTAM system\.

2\. Instead of Microsoft's SNA Server you could also use the IBM Communication Server for Windows NT to establish SNA connections to VSE/ESA\.

In this case your APPN connections to VTAM are supported in the same way as they are through IBM Communication Server for OS/2\.

But you would not have the a client facility equivalent to the one described in ["Using the Client Facility of the Microsoft SNA](4-3.md) [Sever" in topic 4\.3](4-3.md)\.
