### 3\.2\.5 VTAM CDRM Major Node

The following diagram shows our Cross Domain Resource Manager \(CDRM\) Major node\.

<a id="FIGVSEVTM4"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   CATALOG VTMCDRM.B                                                       |
   |   VTMCDRM  VBUILD TYPE=CRDM                                               |
   |   SSCP0001 CDRM  SUBAREA=01,CDRDYN=YES,ISTATUS=INACTIVE                   |
   |   /+                                                                      |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 20\. VSE/VTAM CDRM Major Node*

**SSCP0001** Use the same name for the host CDRM and for the SSCPNAME start option when NODETYPE start option is specified\.

**CDRDYN=YES** This parameter authorizes dynamic definition of cross\-domain or cross\-network resources by the host CDRM, eliminating the need to predefine certain CDRSCs\. Both origin logical units and destination logical units can be dynamically defined\.
