### 3\.3\.3 How to Query your Session from CICS/VSE

Once you have installed your GROUP and activated the Major node definition, you can query your connection using the following command:

**CEMT I CONN**

Below is a sample output from this command\.

<a id="FIGVSECIC7"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   STATUS:  RESULTS - OVERTYPE TO MODIFY                                   |
   |    CONN(CCO2) NET(LOCLU01)    INS REL                                     |
   |    CONN(CCNT) NET(NTLOCLU1)   INS REL                                     |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 28\. CEMT Query of Connection*

At this stage the defined connections are released \(REL\)\. They can be acquired only when the corresponding definition on the workstation is made and activated\. 'ACQ' will then replace the 'REL' in the CEMT display for the specific session\. This may happen automatically when the workstation side starts up\. If it doesn't you can overtype the 'REL' by 'ACQ' to manually start the session\.
