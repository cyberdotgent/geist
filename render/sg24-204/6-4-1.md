### 6\.4\.1 Security for Transaction Server for OS/2 in a LAN Environment

security If you want to protect CICS/VSE resources in a LAN environment you have to transmit user IDs and passwords of workstation end\-users to the mainframe\. A straightforward approach is to use direct connections and define each Transaction Server for OS/2 to VTAM and CICS on the System/390\. In a large LAN, this requires a considerable effort for resource definitions in VTAM and CICS on VSE/ESA\.

To reduce the setup to a single TCS entry in the LAN and a single connection definition in the mainframe, use LAN connections between the CICS for OS/2 systems and CICS/VSE with one Transaction Server for OS/2 acting as a gateway between the LAN and the mainframe\.

```
        ___ Note ___________________________________________________________
       |                                                                    |
       | The Communications Server/2 does not support the transmission of   |
       | the user ID and password through a CICS gateway on to CICS/VSE.    |
       | The connection between the Transaction Server for OS/2 systems     |
       | therefore must be through NetBIOS or TCP/IP to enable user ID and  |
       | password transmission.                                             |
       |                                                                    |
       |____________________________________________________________________|
```

In a TCS entry for the CICS gateway system, each of the non\-gateway Transaction Servers for OS/2 systems should specify:

- NetBIOS or TCP/IP in the Type field, and
- V in the Attach security field \(to indicate that conversation security is required\)

In a TCS entry for the CICS/VSE system, the CICS for OS/2 gateway system should specify:

- APPC in the Type field, and
- V in the Attach security field \(to indicate that conversation security is required\)

In a Connection definition for the Transaction Server for a OS/2 gateway system, CICS on the System/390 should specify ATTACHSEC\(VERIFY\)\.

Each user ID and password should be defined in its initial Transaction Server for OS/2 system, the gateway Transaction Server for OS/2 system, and in the CICS on the System/390 system\.
