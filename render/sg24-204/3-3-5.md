### 3\.3\.5 ECI Related Definitions in CICS/VSE

For each CICS/VSE program which is called through ECI you need an entry in the Conversion Table \(DFHCNV\) to trigger ASCII/EBCDIC translation\.

If the COMMAREA contains only character data a TYPE=ENTRY is sufficient\. If the COMMAREA contains also non\-character data, the individual fields have to be defined\.

Here is an example:

<a id="FIGFIGUNIQ15"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   DFHCNV TYPE=ENTRY,RTYPE=PC,RNAME=ECIPROG                                |
   |   DFHCNV TYPE=SELECT,OPTION=DEFAULT                                       |
   |   DFHCNV TYPE=FIELD,OFFSET=0000,DATATYPE=CHARACTER,                      C|
   |          DATALEN=2                                                        |
   |   DFHCNV TYPE=FIELD,OFFSET=0002,DATATYPE=BINARY,                         C|
   |          DATALEN=2                                                        |
   |   DFHCNV TYPE=FIELD,OFFSET=0004,DATATYPE=CHARACTER,                      C|
   |          DATALEN=76,LAST=YES                                              |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 32\. Example of a Conversion Table*

This defines that the program ECIPROG uses a COMMAREA of 80 bytes where the first two bytes are character data, followed by a halfword, followed by another 76 bytes of character data\.
