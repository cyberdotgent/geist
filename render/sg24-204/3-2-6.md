### 3\.2\.6 VSE/VTAM Switched Major Node Definition

A Switched Major node definition is required to define the physical and logical units to which VTAM may communicate through the 3172\. The following diagram shows the definitions we used to connect to Microsoft SNA Server 3\.0\.

<a id="FIGSWMJ01"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   CATALOG VTMSWNET.B                                                      |
   |   *                                                                       |
   |   * 3172 Switched Major Node for Windows/NT Connection                    |
   |   *                                                                       |
   |   VTMSWNET VBUILD TYPE=SWNET,AMXGRP=20,MAXNO=20                           |
   |   *                                                                       |
   |   SNASVR1  PU    ADDR=61,LANSW=YES,                                      C|
   |                  IDBLK=05D,                                              C|
   |                  IDNUM=E001F,                                            C|
   |                  DISCNT=NO,ISTATUS=ACTIVE,PACING=1,VPACING=2,PUTYPE=2,   C|
   |                  MAXDATA=256,MAXOUT=1,MAXPATH=1,                         C|
   |                  SAPADDR=4                                                |
   |   *                                                                       |
   |   NTLOCLU1 LU    LOCADDR=0,DLOGMOD=SNALU62,ISTATUS=ACTIVE                 |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 21\. VSE/VTAM SWNET Major Node for 3172*

**IDBLK** 05D is the IDBLK used for communication with the Microsoft SNA Server\.

**IDNUM** E001F is assigned locally and will be used in the configuration of SNA Server shown on [Figure 64 in topic 4\.2\.1](4-2-1.md#FIGSNAS6)\.

**NTLOCLU1** This is the LU definition\. It will be required in the Microsoft SNA Server setup shown in [Figure 66 in topic 4\.2\.1](4-2-1.md#FIGSNAS10)\.

**LOCADDR=0** This parameter implies independent logical unit definition\.

**DLOGMOD=SNALU62** This is the default logmode table entry that sets up the APPC conversations between CICS/VSE and CICS/OS2 or CICS/NT\.
