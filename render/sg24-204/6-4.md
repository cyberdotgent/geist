## 6\.4 Security for Access from Transaction Server for OS/2 to CICS/VSE

<a id="HDRSEC0000"></a>

Using the facilities described in this topic, you can implement security in the following way:

- To protect a remote system from unauthorized access by users of the Transaction Server for OS/2, you can use the TCS of the Transaction Server for OS/2 and the Partner LU definition of the Communications Server/2 together with the remote system's conversation security\. For CICS/VSE you specify conversation security through the connection definition\.
- To protect the Transaction Server for OS/2 from unauthorized access by a remote system, use the Partner LU definition in the Communications Server/2 together with the remote system's conversation security, for example, the already verified \(AV\) flag from a CICS/VSE based system\.

To restrict resource access to individually authorized remote users, CICS/VSE uses the SNT\.

The Transaction Server for OS/2 does not directly support resource\-level security, but the external security interface enables the user to extend security facilities\. For example, a user can create the equivalent of remote SNT entries, that is, a file with remote user IDs and their resource\-access authorization\. A user\-replaceable program can then provide resource\-level security\.
