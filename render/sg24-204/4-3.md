## 4\.3 Using the Client Facility of the Microsoft SNA Sever

<a id="HDRSNASC"></a>

In this section we explain how to install and set up the Microsoft SNA Server Client and the IBM Transaction Server for Windows/NT\.

This installation is different from the previous chapter, because here we have one computer running Windows/NT, CICS Transaction Server and the Microsoft SNA Server Client connecting to another computer where the Microsoft SNA Server \(server software\) is installed\.

This kind of configuration is very interesting because you can connect many CICS Transaction Servers for Windows/NT to CICS/VSE using only one SNA Server gateway computer\. Of course you can then connect many CICS clients to CICS/VSE through these Transaction Servers\.

The installation is based on Windows/NT version 4\.0, assuming that MPTS with Token\-Ring drivers are already set up\.

The following sample installation and setup is based on the VSE/ESA definitions described in the previous chapter\. In particular, we use the PU definition **SNASVR1** and the Independent LU **NTLOCLU1**, both defined in the **VTMSWNET** Switched Major node\.

**Note:** Microsoft SNA Server does not support APPN connections to VTAM\. So, with SNA Server you need to define an independent LU in the VTAM of your VSE/ESA system\.
