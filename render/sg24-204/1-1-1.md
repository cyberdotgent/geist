### 1\.1\.1 CICS/VSE as a Server

CICS/VSE is a member of the CICS family of transaction processing monitors\. It supports the common application programming interface \(EXEC CICS API\) and Intersystem Communication \(ISC\) between the CICS server products\. For some details on ISC, please refer to ["InterProduct](1-3-1.md) [Communication" in topic 1\.3\.1](1-3-1.md)\.

The latest CICS/VSE release is CICS/VSE Version 2 Release 3\. It provides enhanced functionality to CICS users in the VSE environment and is a major base product component of VSE/ESA Version 2 Release 2\.

This latest release provides a platform that has enhanced programmer interfaces as well as support for Language Environment \(LE\) for VSE/ESA and associated languages\. In addition it provides a tool to aid in the migration of customers from the use of internal CICS security to an external security manager \(ESM\) that will be required in subsequent versions\. CICS/VSE fully supports all ISC functions for CICS to CICS communication\. For CICS client connections CICS/VSE 2\.3 supports the External Call Interface \(ECI\)\. The service level of CICS/VSE 2\.3 which is shipped with VSE/ESA 2\.2 also supports the External Presentation Interface \(EPI\)\. If you run CICS/VSE on a lower service level you can install the PTF PN87445 to add EPI support to your CICS/VSE\.

For details on the CICS external interfaces please refer to ["The External](1-3-2.md) [Interfaces" in topic 1\.3\.2](1-3-2.md)\.
