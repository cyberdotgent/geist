### 5\.3\.1 Connecting Directly to CICS/VSE

<a id="HDRCLIWIN"></a>

To connect CICS Client for Windows directly to CICS/VSE, you need to:

- Set up the Microsoft SNA Server:

Server Version with the following operating systems:

Windows/NT Server Windows/NT Workstation

Client Version \(any Windows operating system\)

- Set up the CICSCLI\.INI file on the workstation
- Set up the CICS/VSE system

The Installation and configuration for the Microsoft SNA Server \(Server Version\) is exactly the same as for the Transaction Server for Windows/NT\. Please refer to ["Setting up Communications" in topic 4\.2\.1](4-2-1.md) and follow the description in detail\.

The installation of the SNA Server \(Client Version\) is very easy and is also documented in **Microsoft SNA SERVER*****\- Getting Started***\.

Please follow all the steps described in this book, but first have a look at the system requirements to install the product:

- Windows/NT \(Workstation Version\):

Minimum of 14MB of total system RAM \(recommended\)\. Minimum of 7MB free hard\-disk space\.

- Windows/95:

Minimum of 8MB of total system RAM \(recommended\)\. Minimum of 6MB free hard\-disk space\.

\>\> ***CICSCLI\.INI File Definitions*** \<\<

To set up the CICS client you need to edit the **CICSCLI\.INI** file \.\.***\\cicscli\\bin***\) and change the required parameters\.

Below are shown the important parts of our CICSCLI\.INI file \(the whole file is listed in ["CICS Client File for Windows" in topic B\.2](b-2.md)\)\.

<a id="FIGCLNT49"></a>

```
    __________________________________________________________________________ 
   |                                                                          |
   |   Client = *                      ; Auto-install client on the server    |
   |      MaxServers = 1               ; Only allow one server connection     |
   |      MaxRequests = 20             ; Limit the maximum server interaction |
   |      MaxBufferSize = 32           ; Allow for a 32K maximum COMMAREA     |
   |      LogFile = CICSCLI.LOG        ; Set the error log file name          |
   |      TraceFile = CICSCLI.TRC      ; Set the trace log file name          |
   |      DumpFile = CICSCLI.DMP       ; Set the memory trace dump file name  |
   |      DumpMemSize = 16             ; Allow for 16K of trace in memory     |
   |      DosMemory = 48               ; The DOS client's memory pool size    |
   |                                                                          |
   |__________________________________________________________________________|
```

*Figure 108\. CICS Client for Windows INI File: Client Section*

<a id="FIGCINI2"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   Server = CICSSNA                ; Arbitrary name for the server         |
   |      Description = SNA Server     ; Arbitrary description for the server  |
   |      Protocol = SNA               ; Matches with a Driver section below   |
   |      NetName = VTAM1.PRODCICS     ; The server's fully qualified LU name  |
   |      LocalLUName = NTLOCLU1       ; The client's local LU name            |
   |      ModeName = SNALU62           ; The SNA communication mode name       |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 109\. CICS Client for Windows INI File: Server Section*

**NetName** The first part should match the **NETID** defined in VTAM shown in [Figure 17 in topic 3\.2\.1](3-2-1.md#FIGVSEVTM1), and second part should match the **APPLID** defined in the VTAM Application Major node shown in [Figure 19 in topic 3\.2\.4](3-2-4.md#FIGVSEVTM3)\.

**Local LU Name** Should match the **L****U Name** defined in Local APPC LU Properties shown in [Figure 66 in topic 4\.2\.1](81.png) and the **Netname** defined in the Connection definition shown in [Figure 26 in](<#FIGVSECIC3>) [topic 3\.3\.2\.1](<#FIGVSECIC3>)\.

**ModeName** Should match the **Modename** defined in Session definition shown in [Figure 27 in topic 3\.3\.2\.1](<#FIGCICSSES>)\.

<a id="FIGCLNT51"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   Driver = SNA                    ; Matches the Server's Protocol value   |
   |      DriverName = CCLWNTSN        ; Use the WinNT SNA communications DLL  |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 110\. CICS Client for Windows INI File: Driver Section*

- The SNA driver **CCLWNTSN** is required\.

\>\> ***CICS/VSE Definitions*** \<\<

For the CICS/VSE system you need to do the following:

- Include the **VTPRFX** definition in the **SIT** table as shown on [Figure 25 in topic 3\.3\.1](3-3-1.md#FIGSIT)\.
- Define the **Connection** as shown in [Figure 26 in topic 3\.3\.2\.1](<#FIGVSECIC3>)\.
- Define the **Session** as shown in [Figure 27 in topic 3\.3\.2\.1](<#FIGCICSSES>)\.
- You must be sure that the **DFHLU2** \(TYPETERM\) and **LU2** \(TERMINAL\) are already created and installed in your CICS/VSE system or you must define static TERMINAL \- TYPETERM definitions as shown in [Figure 30 in topic 3\.3\.4\.3](<#FIGVSECIC5>) and [Figure 31 in topic 3\.3\.4\.3](<#FIGVSECIC6>) and start the CICS client terminal with the command:

***CICSTERM /M=typeterm*** or ***CICSTERM /N=terminal***\.
