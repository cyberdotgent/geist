### 4\.2\.2 Setting up the IBM Transaction Server for Windows NT

<a id="HDRSWINSTR"></a>

The Transaction Server uses the services of the following products:

- Windows NT operation system
- DCE \(Distributed Computing Environment\)
- Encina
- CICS

The Transaction Server uses the following components of DCE, Encina and CICS:

- DCE Remote Procedure Call \(RPC\) \(mandatory\) Cell Directory Service \(RPC\) Client \(optional\) Security Client \(optional\) Distributed Time Service \(DTS\) Clerk
- Encina

Encina Executive and Encina Server Core Encina Structured File Server \(SFS\) Encina Peer\-to\-Peer Communication \(PPC\) Executive

- CICS

Application Services Communication Services Presentation Services Data Management Services Security functions Intercommunications Services\.

The CICS for Windows NT Server can run in an RPC\-Only environment or it can be installed in a DCE environment\.
