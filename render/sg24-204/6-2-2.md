### 6\.2\.2 Conversation\-level Security

Communications Server/2 supports inbound and outbound conversation\-level security\.

An entry of Conversation security\(Yes\) in the Partner LU definition specifies that an inbound allocation request should include at least a user ID with the already\-verified \(AV\) flag set on\. The AV flag indicates that the remote LU has verified the password before transmitting the request\. When the user ID has the AV flag on, there is no security checking, and the request is accepted even if the user ID is not locally defined\.

When a request contains a user ID and password, the security information is checked even if Conversation security\(No\) is specified in the Partner LU definition\. If the check fails, the request is rejected\.
