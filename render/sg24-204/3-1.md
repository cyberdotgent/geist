## 3\.1 VSE/ESA Communication Controller

<a id="HDRVSEHW"></a>

An entry for the 3172 communication controller is added to the IPL procedure as shown below\. The device is not to be sensed at IPL time \(EML\)\. This guarantees that the device characteristics implied by CTCA are not changed dynamically at IPL time by VSE/ESA\.

<a id="FIGVSEHW1"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |      CATALOG $IPLESA.PROC  REPLACE=YES                                    |
   |   01F,$$A$SUPX,VSIZE=180M,VIO=512K,VPOOL=64K,LOG                          |
   |   ADD 01F,3277                                                            |
   |   ADD 00C,2540R                                                           |
   |         .                                                                 |
   |         .                                                                 |
   |         .                                                                 |
   |   ADD 960,CTCA,EML           3172 GATEWAY                                 |
   |         .                                                                 |
   |         .                                                                 |
   |   ADD FFF,CONS               DUMMY CONSOLE, DO NOR DELETE                 |
   |         .                                                                 |
   |         .                                                                 |
   |   SVA SDL=600,GETVIS=(128K,256K)PSIZE=(372K,5000K)                        |
   |   /+                                                                      |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 16\. VSE IPL Procedure*
