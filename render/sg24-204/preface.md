# PREFACE Preface

To fully exploit the great functionality offered by CICS/VSE you can use your CICS/VSE as a server within the CICS family\. This allows you the option to utilize the CICS Interproduct Communication facilities between Transaction Servers as well as the client/server facilities known as the CICS external interfaces\.

This redbook outlines these CICS interfaces and describes environments in which they can easily be used together with CICS/VSE\.

It also shows in detail and in a step\-by\-step manner how to set up all the communication software and CICS client and server products to connect Transaction Servers and CICS clients running under OS/2 Warp or Windows NT and Windows 95 to CICS/VSE\.
