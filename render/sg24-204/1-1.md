## 1\.1 CICS Servers

CICS servers exist on many platforms\. Below is a list of CICS server products\.

- IBM Transaction Server platforms, including:

OS/2 AIX Windows NT MVS/ESA AS/400 OS/390

- CICS for Solaris Operating Environment V 2\.1\.1
- CICS for HP\-UX V2\.1\.1
- CICS for AIX
- CICS for OS/2
- CICS for OS/400 Version 3\.6 and CICS for AS/400 Version 3\.1
- CICS for VSE/ESA Version 2\.3
- CICS for MVS/ESA Version 4\.1
