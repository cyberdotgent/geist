### 3\.2\.7 VTAM XCA Major Node Definition

An External Communication Adapter \(XCA\) Major node is required to enable VTAM to use a 3172\. The following definitions describe our 3172 XCA Major node\.

*Figure 22\. VSE/VTAM XCA Major Node for 3172*

**CUADDR** This parameter matches the virtual address which we have added in our VSE/ESA IPL procedure\. This can be found in [Figure 16](3-1.md#FIGVSEHW1) [in topic 3\.1](3-1.md#FIGVSEHW1)\.

**VNGROUP** This parameter specifies the name of the GROUP containing dial\-out links available for use on the connection network name on the VNNAME operand\. With this parameter coded you obtain a better performance\.

**VNNAME** This parameter specifies a network\-qualified CPNAME for the connection network\.

**DYNPU=YES** Specifies that a PU is to be dynamically allocated by workstation during a call\-in operation\.
