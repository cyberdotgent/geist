*Figure 25\. System Initialization Table*

**APPLID** This parameter represents the CICS/VSE application ID and must match the APPL macro in the VSE VTAM Major node definition\. This can be found in [Figure 19 in topic 3\.2\.4](3-2-4.md#FIGVSEVTM3)\.

**VTPRFX** This parameter allow you to specify a prefix for autoinstalled terminals\. It is used to ensure that terminal ids for autoinstalled client virtual terminals are unique within your network\.
