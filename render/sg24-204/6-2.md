## 6\.2 OS/2 Intercommunication Security

<a id="HDROS2SEC"></a>

If you use SNA connections from OS/2 to other systems together with CICS or CICS clients, Communication Server/2 \(CS/2\) is used\. CS/2 then is involved in setting up intercommunication security\.

Communications Server/2 supports APPC intercommunication security at two levels:

- session\-level LU\-LU verification, which enables each LU to verify the identity of its partner before allowing the session to proceed
- conversation\-level security, which enables each LU to verify the identity of a remote user before a conversation starts\.

Communications Server/2 enhances the performance of conversation\-level security by providing send\-persistent verification\. This is a partial implementation of the APPC persistent verification protocol\. Persistent verification allows one user ID authentication to remain in effect for subsequent allocate requests from the same user ID and LU\. It improves performance as compared with repeated authentication\.
