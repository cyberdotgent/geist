# 4\.0 Chapter 4\. Transaction Servers

<a id="HDRSERVERS"></a>

This chapter covers what you need to do to connect the Transaction Servers for OS/2 and Windows NT to CICS/VSE\. In each case this involves two tasks:

1\. the communications setup

2\. the tailoring of the Transaction Server\.

Both are covered in the following two sections\.

The third section covers the setup of an indirect communication connection between a Windows NT system and VSE/ESA: It is possible to use the Microsoft SNA Server to build an SNA connection to VTAM on VSE once and connect to the SNA Server from multiple workstations using for example TCP/IP through the client facility of the SNA Server\. This is described in ["The Transaction Server for Windows NT" in topic 4\.2](4-2.md)\.
