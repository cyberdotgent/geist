## 5\.3 CICS Client for Windows/NT or Windows/95

<a id="HDRCOS2CLI"></a>

Having installed the CICS Client for Windows/NT or Windows 95 you can connect it to CICS for VSE/ESA in various ways:

- directly
- through IBM Transaction Server for OS/2
- through IBM Transaction Server for Windows NT

These options are discussed in detail below\.
