### 5\.2\.3 Connecting to Transaction Server for Windows/NT

<a id="HDRCSWIN1"></a>

To connect CICS Client for OS/2 to Transaction Server for Windows/NT you need to:

- Configure a protocol to communicate with the Windows/NT Server
- Set up the CICSCLI\.INI file on the workstation
- Define a TCP/IP Listener Definition on the Transaction Server for Windows/NT

The simplest way to connect a CICS client workstation to a Transaction Server for Windows/NT is to use the TCP/IP protocol\. For information how to install and configure IBM TCP/IP for OS/2, see, for example, the *IBM TCP/IP Version 2\.0 for OS/2 Installation and Maintenance* manual\.

\>\> ***CICSCLI\.INI File Definitions*** \<\<

To set up the CICS client you need to edit the **CICSCLI\.INI** file \.\.***\\cicscli\\bin***\) and change the required parameters\.

Below are shown the important parts of our CICSCLI\.INI file \(the whole file is listed in ["CICS Client File for OS/2" in topic B\.1](b-1.md)\)\.

<a id="FIGCLNT46"></a>

```
    __________________________________________________________________________ 
   |                                                                          |
   |   Client = *                      ; Auto-install client on the server    |
   |      MaxServers = 1               ; Only allow one server connection     |
   |      MaxRequests = 20             ; Limit the maximum server interaction |
   |      MaxBufferSize = 32           ; Allow for a 32K maximum COMMAREA     |
   |      LogFile = CICSCLI.LOG        ; Set the error log file name          |
   |      TraceFile = CICSCLI.TRC      ; Set the trace log file name          |
   |      DumpFile = CICSCLI.DMP       ; Set the memory trace dump file name  |
   |      DumpMemSize = 16             ; Allow for 16K of trace in memory     |
   |      DosMemory = 48               ; The DOS client's memory pool size    |
   |                                                                          |
   |__________________________________________________________________________|
```

*Figure 105\. CICS Client for OS/2 INI File: Client Section*

<a id="FIGCLNT47"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   Server = CICSTCP               ; Arbitrary name for the server          |
   |      Description = TCP/IP Server ; Arbitrary description for the server   |
   |      Protocol = TCPIP            ; Matches with a Driver section below    |
   |      NetName = 9.164.180.141     ; The server's TCP/IP address            |
   |      Port = 0                    ; Use the default TCP/IP CICS port       |
   |                                                                           |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 106\. CICS Client for OS/2 INI File: Server Section*

- The **NetName** address must be the TCP/IP address of your Windows/NT Transaction Server machine\.

<a id="FIGCLNT48"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   Driver = TCPIP                 ; Matches the Server's Protocol value    |
   |      DriverName = CCLIBMIP       ; Use the IBM TCP/IP communications DLL  |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 107\. CICS Client for OS/2 INI File: Driver Section*

- The TCPIP driver **CCLIBMIP** is required\.

\>\> ***CICS Transaction Server Definitions*** \<\<

To set up Transaction Server for Windows/NT to receive requests from CICS clients using TCP/IP connections, you need to define a TCP/IP Listener Definition as shown on [Figure 90 in topic 4\.2\.2\.4](<#FIGTRASR07>)\.

If your Transaction Server is set up as described in [Chapter 4,](4-0.md) ["Transaction Servers" in topic 4\.0](4-0.md) it can access CICS for VSE/ESA\. In this case, your CICS client can, through the Transaction Server, connect to CICS for VSE/ESA\.
