## 2\.1 Direct Connections to CICS/VSE

<a id="HDRENV1"></a>

With the appropriate communication software installed and set up on the workstations you can connect

- Transaction Server for OS/2
- Transaction Server for Windows NT

*and*

- CICS Clients for OS/2
- CICS Clients for Windows NT

directly to CICS/VSE\.

To link to CICS/VSE you must be able to establish an SNA connection\.

Direct SNA connections to VSE can be set up using the following products for Warp or OS/2 based workstations

- Communication Manager/2
- Communication Server/2 \(starting with Warp V\.4\)

In the later chapters we cover this case in detail\.

- SNA Server from Microsoft

In the later chapters we cover this case in detail\.

- IBM Communications Server for Windows NT

You cannot install the full SNA Server on a Windows 95 workstation\. Since this is required for an SNA connection to a host you cannot connect a CICS Client for Windows 95 directly to CICS/VSE\.
