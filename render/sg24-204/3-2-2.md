### 3\.2\.2 VTAM CONFIG Definition

The following figure lists the najor nodes we called in our CONFIG file\.

<a id="FIGVSEVTM2"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   CATALOG ATCCONMI.B                                                      |
   |            COSAPPN,                                                      C|
   |            IBMTGPS,                                                      C|
   |            VTMAPPL,                                                      C|
   |            VTMSNA,                                                       C|
   |            VTMNSNA,                                                      C|
   |            VTMCTCA,                                                      C|
   |            VTMPATH,                                                      C|
   |            VTMCA1,                                                       C|
   |            VTMCA2,                                                       C|
   |            VTMCA3,                                                       C|
   |            VTMCDRM,                                                      C|
   |            VTMSWNET,                                                     C|
   |            VTMCDRS,                                                      C|
   |            VTMSW1,                                                       C|
   |            VTM3172A,                                                     C|
   |   /+                                                                      |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 18\. VSE/VTAM ATCCONMI File*

**COSAPPN** This is the IBM\-supplied APPN Class of Service Definition\.

**IBMTGPS** This is the IBM\-supplied Transmission Group profiles\. **VTMAPPL** This is the Application Major node used to describe some of the characteristics of our CICS/VSE system\.

**VTMCDRM** This is the Cross Domain Resource Manager Major node used to define our host CDRM\. **VTMSWNET** This is the Switched Major node including the independent LU for the Microsoft SNA Server 3\.0\. **VTM3172A** This is the External Communication Adapater \(XCA\) Major node that we created to enable VTAM to use a 3172\.
