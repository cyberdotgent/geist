## 3\.3 Setting up CICS/VSE

<a id="HDRVSECICS"></a>

This section covers the definitions in CICS/VSE which enable Transaction Servers and CICS clients to communicate with CICS/VSE\.

There are two ways to define CICS resources in CICS/VSE:

- Resource Definition Macro \(RDM\) using CICS tables
- Resource Definition Online \(RDO\) using the CEDA transaction\.

In CICS/VSE, Macro Definition must be used for the System Initialization Table \(DFHSIT\) and the Destination Control Table \(DFHDCT\)\.

The recommended way to define transactions, programs, connections, sessions, typeterms and terminals is to use RDO\. This is also what we used and what is documented in this chapter\.
