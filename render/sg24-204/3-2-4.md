### 3\.2\.4 VTAM Application Major Node Definition

The VTAM Application Major node describes some of the characteristics of our CICS/VSE system\. The following figure shows our definition\.

<a id="FIGVSEVTM3"></a>

```
    ___________________________________________________________________________ 
   |                                                                           |
   |   CATALOG VTMAPPL.B                                                       |
   |   VTMAPPL  VBUILD TYPE=APPL                                               |
   |   DBDCCICS APPL  AUTH=(PASS,ACQ),MODETAB=IESINCLM,PARSESS=YES             |
   |   PRODCICS APPL  AUTH=(PASS,ACQ),MODETAB=IESINCLM,PARSESS=YES,APPC=NO,   C|
   |                  SONSCIP=YES                                              |
   |   POWER    APPL  AUTH=(ACQ)                                               |
   |   PNET     APPL  AUTH=(PASS,ACQ),VAPACING=3,MODETAB=VTMLOGTB,DLOGMOD=PNET |
   |   IESWAITT APPL  AUTH=(NOACQ)                                             |
   |   /+                                                                      |
   |                                                                           |
   |___________________________________________________________________________|
```

*Figure 19\. VSE/VTAM Application Major Node*

**PRODCICS** This is the application name that must match the APPLID of DFHSIT\. This can be found in [Figure 25 in topic 3\.3\.1](3-3-1.md#FIGSIT)\.

**PARSESS=YES** This parameter tells VTAM that CICS can have parallel sessions with an independent LU\.

**APPC=NO** This parameter tells VTAM that CICS/VSE will generate its own conversation streams to converse via LU6\.2\.
