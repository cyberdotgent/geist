### 8.2.1 Ending and Printing the Document

After you have created or changed a document, you can save your changes

and print your document.

To save your changes and print the entire document: 1. Press F3 (Exit/Save) on the Edit display.

| The Exit Document display is shown.

2. Type a Y (Yes) for the Print document prompt and a Y (Yes) for the

Display print options prompt.

(If you type an N (No) for the Display print options prompt, the print

options are not shown and your document is printed using the current

print option settings.

Page 1 of 4 of the Print Options display is shown. The Print Options consists of four pages (or three pages if your document is already resolved). The most commonly used options are on the first page, and

the less commonly used options are on the following pages. If you need more information about any of the Print Option prompts, press the

Help key.

7. It is best to leave the Printer prompt value at *USRPRF. If you specify *USRPRF, the printer that is specified in your user profile is

used. If you specify *SYSVAL, the printer that is specified in the system

value QPRTDEV is used.

If you specify a printer (for example, P3), your document is printed | on that printer. Do not change the output for the printed document to

| a different type of printer. 8. Type the name of the output queue where you want to hold your output

until it is ready to print for the Output queue prompt. If you specify *DEV, the output queue associated with the printer

specified in the Printer prompt is used. If you specify *FILE, the output queue and output queue library

specified in the Printer file prompt are used.

9. If you specified *FILE on the Output queue prompt, leave the Library prompt blank. If you leave this prompt blank, the output queue and

output queue library specified in the Printer file prompt are used. If the output queue is not in the default library QUSRSYS, type the

name of the library where the output queue is stored for the Library

prompt. If you specify *LIBL, your library list is searched for the output

queue., c.cp

10. Type the name of the output file where you want the output stored

while it is in the output queue for the Output file prompt.

If you specify *DOC on the Output file prompt, the document name is used. If the document name is longer than 10 characters or contains a period (.), then the output file name is the same name as the name of

the printer file specified for the Printer file prompt (in this case,

QSYSPRT).

If you specify *FILE, the output file name specified for the Printer

file prompt is used. For more information about output files and

[HDRAPD](d-0.md)

queues, see Appendix D. 11. If you do not want to print your document on the standard form type

(paper), type the name of the form for the Form type prompt. For example, if you specify *STD as the form type, the output is printed

on the standard form (paper) used for your printer. 12. If you do not want to use the default values in the system printer

[HDRAPD](d-0.md)

file. If you created a new printer file, type the name of the library in

which this file is located. 14. Press the Page Down key to see page 2 of the Print Options display.

18. If you type a Y (Yes) for the Place on job queue prompt, the document is resolved on the job queue and your work station is available for

other work while your job is processing. (Yes is the default.) Jobs

are processed in the order submitted.

19. If you type an N (No) for the Send completion message prompt, you are

not interrupted by a message when your document has completed processing on the job queue. Otherwise, you will receive a message

when your document has completed processing on the job queue and is

ready to print. 20. Type the name of the job description that describes how you want the

job to be run for the Job description prompt. The default is the

system job description, QBATCH. 21. Type the library name that contains the job description for the

Library prompt. The default is *LIBL; therefore, your library list is

searched for the job description., c.cp 22. Press the Page Down key to go to Page 4 of 4 on the Print Options

display.

23. If you want your document to be printed on one side of the paper, type

a 1 (Single-sided) for the Type of page printing prompt. If you want your document to be printed on both sides of the paper

type a 2 (Double-sided) for the Type of page printing prompt. If you want your document to be printed on both sides of the paper but

bound at the top, type a 2 (Double-sided tumble) for the Type of page

printing prompt. If you need more information about this prompt, press the Help key.

If the Printer ID you specify does not support double-sided

printing, you receive a message on page 1 of the Print Options

display that the printer for double-sided printing is not

correct.

24. If you are printing your document on both sides of the paper, type a Y

(Yes) for the Automatic page binding prompt. When your document is

printed, the margins are automatically adjusted to allow for page binding on the left margin of odd-numbered pages and the right margin

of even-numbered pages. If you specify N (No) for this prompt, the

margins that you have already defined are used

25. After selecting the options you want, press the Enter key. Your document is submitted for printing. You receive a message that

your request is being processed.

If you want to check the status of your job on the print queue, press F9 (Work with) from the Work with Documents in Folders display and then

select option 2 (Work with documents to be printed).
