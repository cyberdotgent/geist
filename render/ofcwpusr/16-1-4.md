### Using Merged Information for Label Text

To create labels using merged information from data fields in a file,

query, or fill-in document

1. On the Edit display, move the cursor to the position you want the

<a id="ELISdata"></a>

first data field printed on.

2. Press F5 (Goto), then type .& (data field) in the Goto prompt, and

press the Enter key. The Data Field Instruction display is shown.

3. Type the name of the data field for the Data field prompt. 4. If you want to specify the name of a query, file, or document now,

type a 1 (From Merge Data Options) for the Data field source prompt.

If you want to specify the name of the query, file, or document when

you print your document, type a 2 (*PRINT). You cannot use option 3 (*NOTE) when printing labels.

5. Select option 1 (Multiple letters) for the Letters or list prompt.

6. Press the Enter key.

If you selected option 2 for the Data field source prompt, go to step

9.

If you selected option 1 for the Data field source prompt, the Merge

Data Options display is shown. 7. On the Merge Data Options display, do one of the following:

If you want to merge data from a query, select option 1 (Query).

Additional prompts are shown. Type the query name and library

name.

If you want to merge data from a document, select option 2 (Document). Additional prompts are shown. Type the document name

and folder name., c.cp

If you want to merge data from a file, select option 3 (File).

Additional prompts are shown. Type the file name, library name

(optional), and member name.

If the member name is the same name as the file name, type *FILE

for the Member prompt.

If the member is the first member in the file, type *FIRST for the

Member prompt.

If the member is the last member in the file, type *LAST for the

Member prompt

8. Press the Enter key and the Data Field instruction is inserted into

<a id="ELISkey"></a>

your document

<a id="LISlabel"></a>

[LISKEY](16-1-4.md)

9. Repeat steps 1 through 8 for each data field you want printed on the

<a id="ELISlabel"></a>

label.

10. Save and print the labels.

[More information on merging can be found in "Using Data/Text Merge" in](14-3.md)

topic 14.3.

To highlight lines in a label, use the Begin Bold (Alt B) and End Bold (Alt J) control characters on each line of the label. To underline lines in a label, use the Begin Underline (Alt U) and End Underline (Alt J) control characters on each line of the label.
