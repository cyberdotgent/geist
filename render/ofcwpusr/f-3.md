## F.3 Command Differences

| The OfficeVision/400 word processing function uses the Work with Documents (WRKDOC) command as equivalent to the System/38 Edit Text (EDTTXT)

command. The Edit a Document (EDTDOC) and Print a Document (PRTDOC) commands used with System/38 text management have the same command names on the AS/400 system, but these commands may have different functions and parameters.

For more information on these commands, see the online information for

each command.
