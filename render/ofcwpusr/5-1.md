After you create a user dictionary, you must add the name of the

dictionary to the dictionary list on the Specify Dictionary Options display. The dictionary name is then used by the system to check the spelling in your document. You can add the name of the dictionary to the dictionary list in a text profile, or in the document you are editing. After a dictionary is created, other users who have authority to use the dictionary can add the dictionary name to a dictionary list for their text

profile or document
