### 3.3.2 Moving Text

To use F2 to move text:

1. Place the cursor under the first character of the text you want to

move.

2. Press F2 (Move). A prompt is shown on the message line at the bottom of your display:

Move what

Move cursor, press Enter.

3. Move the cursor to the last character of the text you want to move. Make sure you include the last two spaces at the end of a sentence. A fast way to move the cursor is to type the last character you want to

move; the cursor moves to that character. 4. Press the Enter key. A prompt is shown on the message line at the

bottom of your display:

To where

Move cursor, press Enter. 5. Move the cursor to the location in your document where you want the

text moved.

Using F5 (Goto) to go to a specific page or line number is faster than

using the page keys.

6. Press the Enter key. The text is moved to the new location and the cursor is under the

first character of the moved text.
