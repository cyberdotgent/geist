### 7.5.1 Typing or Changing Headers or Footers for the Entire Document

To type or change a header or footer for the entire document:

1. Press F5 (Goto) to show the Goto prompt.

2. Type one of the following abbreviations in the prompt:

aef alternate even footer

aeh alternate even header

aeo alternate even/odd header/footer

af alternate footer

ah alternate header

aof alternate odd footer

aoh alternate odd header

df document footer

dh document header

def document even footer

deh document even header

deo document even/odd header/footer

dof document odd footer

doh document odd header 3. Press the Enter key and an Edit display is shown where you can create

or revise the header or footer.

4. Type your header or footer text. 5. Press F3 (Exit/Save) to return to the Edit display.

Notes: a. After you have typed header or footer text, information about the first typing line for a header or footer and what pages they are

printed on can be specified on the Page Layout/Paper Options

display. b. To have page numbers printed in a document header or footer, or alternate header or footer, use the Page Number instruction (.pn).

[See "Using Page Numbers in a Header or Footer" in topic 7.5.3 for](7-5-3.md)

more information. Other instructions may be used in headers and footers; to see those allowed in headers and footers, press F9

(Instructions) on the Edit display for headers and footers
