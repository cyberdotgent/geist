#### 17.4.4.1 Paginating Flowing Text Columns

Whenever you copy, move, or delete text within flowing columns, it is best to paginate the document (adjust page endings) before you print it. Changes made to a column may cause part of the column to spill over to the

next column when the document is printed. You must paginate your document to see the same results that were displayed when you viewed them using F19 (Print/View function). Any Next Text Column instructions that were not

used are removed during pagination. For more information about

[pagination, see "Paginating" in topic 3.16.](3-16.md)
