#### 3.4.3.1 Deleting a Single Line of Text

1. Press the Home key to move the cursor to the line command area (five

blank spaces to the left of the typing area).

2. Type a D in the line command area next to the line you want to delete.

3. Press the Enter key and the line is deleted. 4. Press the Home key to return the cursor from the line command area to

the text area. 5. Press the Enter key to remove the line command area from your display.
