#### 3.4.2.3 Moving Different Lines of Text to the Same Location

You can move several different lines of text from various locations to the

same location in your document using line commands. 1. Press the Home key to move the cursor to the line command area (five

blank spaces to the left of the typing area).

2. Type AR in the line command area if you want the moved lines placed

after the line next to the AR line command. Or, type BR in the line

command area if you want the moved lines placed before the line next

to the BR line command.

3. Type an M in the line command area next to each line you want to move. 4. Press the Enter key. After you press the Enter key or a page key, the

lines you specified (with an M) are moved after or before the location

you specified and the AR or BR is shown next to the last line moved.

5. Press F8 (Reset) or space over AR or BR to remove AR or BR. 6. Press the Home key to return the cursor from the line command area to

the text area. 7. Press the Enter key to remove the line command area from your display.
