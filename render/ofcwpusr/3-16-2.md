# Paginating While Editing the Document

<a id="HDRPAGEDIT"></a>

### Paginating While Editing the Document

the entire document is paginated. 1. Press F16 (Adjust/Paginate) while on the Edit display.

The Select Adjust/Paginate Option display is shown. 2. Select option 2 (Adjust line and page endings).

3. Press the Enter key. All your lines are adjusted and the entire document is paginated. If

there are multiple text columns in the document, Next Text Column

(ntc) instructions are inserted where the columns should end. After the document is paginated, the first page of the document is shown.
