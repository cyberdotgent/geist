### 7.7.6 Deleting a Text Profile

To delete a text profile: 1. Select option 4 (Delete text profile) on the Work with Text Profiles

display and press the Enter key.

The Delete Text Profile display is shown.

2. Type the name of the text profile to be deleted for the Profile

prompt. If you cannot remember the name of the profile to be deleted, move the

cursor to the Profile prompt and press F4 (Prompt). A list of existing text profile names is shown. Select a profile name from the

list.

Note: You cannot delete the text profile SYSTEM. A prompt is shown on the message line at the bottom of your display:

Press Enter to delete profile.

3. Press the Enter key to confirm your request. 4. Press the Enter key again and you are returned to the Work with Text

Profiles display.
