#### 7.3.3.1 Changing the Type Style or Ink Color for the Entire Document

1. Press F5 (Goto) to show the Goto prompt.

2. Type dt to change the document type style/color and press the Enter

key.

The Typestyle/Color Options display is shown.

3. Type the desired type style in the Typestyle prompt.

If you need more information about this prompt, position your cursor

next to the prompt and press the Help key. 4. If you want to change the ink color, type the desired color number for

the Color prompt. If you need more information about this prompt,

position your cursor next to the prompt and press the Help key.

5. Press the Enter key to return to the Edit display.
