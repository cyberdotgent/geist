### Describing a Document

The Create Document Details display is shown whenever you create a new

you find the document. All of the information on the Create Document

Details display is optional. If you do not need a description, press the Enter key on this display and the Edit display (typing area) is shown. There are two pages of the Create Document Details display. Use the page

keys to go from one page to another.

The following prompts are on the Create Document Details display:

Document description*

Subject*

Document to copy

From folder

Change formats/options

Authors*

Keywords*

Document class*

Print as labels

Project*

Reference*

Document date*

Expiration date*

Sent to*

Date action due*

Date action completed*

Mark for offline storage

You can specify the items marked with an asterisk (*) on the Search

for Documents display to find a document.

For additional information about a particular prompt, place the cursor

next to the prompt and press the Help key.
