display is shown. If you want a prompt, such as salutation or name, to

appear at the bottom of the display when the variable information for the

word Dear is typed, complete the Stop code prompt on this display and

press the Enter key. If you do not want a prompt to appear, just press

the Enter key. You can locate stop codes in your document by pressing the Alt key plus the N key. Each time Alt N is pressed, the cursor advances to the next stop code and is placed one position to the right of the stop code so you can insert your information. If a prompted stop code is found, the prompt is shown at the bottom of the Edit display. Prompted stop codes can only

be deleted by using the Delete key. A stop code that is not associated with a prompt is shown on the Edit display as a high dash. It can be deleted using the Erasing Backspace key. A stop code that is associated with a prompt is shown on the Edit display as a blank. It can be deleted using the Delete key.
