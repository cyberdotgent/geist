### 8.3.1 Printing a Document Using the Print Options Display

1. Type the following on the command line:

PRTDOC DOC(document name) FLR(folder name) OPTIONS(*YES) If you specify *PRV for the document or folder name, the name of the

document or folder used in your last edit session is used. 2. Press the Enter key. The Print Options displays are shown with the

values you previously specified filled in on the display.
