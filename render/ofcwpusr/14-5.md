A query can also create new fields called result fields. For example, you could define a new field called PROFIT by subtracting an existing field

Overhead from the Price field and get a result field. Or you could create

If the data to be merged into a document is not likely to change between the time the document is created and the time it is printed, it is better to copy the data into your document. You can copy the data directly into your document by using option 6 (Direct merge) on

the Work with Queries display.

If the data to be merged into a document is likely to change between the time the document is created and the time it is printed, it is better to use the Data Field instructions in your document. When you print the document, use data/text merge to merge the current data for those fields into the shell document. You can use data/text merge

with a query by creating a shell document with Data Field

instructions, then specify a query as the data field source when you

print the document. The variable data in the query is merged with the

constant text in the shell document.

You can copy the Data Field instructions into your document by using option 7 (Column list merge) or option 8 (Multicopy merge) on the Work

with Queries display.
