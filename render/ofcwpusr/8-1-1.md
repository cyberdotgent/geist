### 8.1.1 Ending a Document Without Printing

To end your document without printing it:( | 1. On the Edit display, press F3 (Exit/Save) or F12 (Cancel). The Exit

| Document display is shown with the default choices. | 2. On the Exit Document display, specify the following options:

a. Type a Y (Yes) for the Save document prompt.

b. Type an N (No) for the Display save options prompt.

c. Type an N (No) for the Print document prompt.

d. Type an N (No) for the Display print options prompt.

3. Press the Enter key.

You receive a message that your document has been saved.
