#### 1.2.2 Using the WRKFLR (Work with Folders) Command

and describe folders or work with documents in a folder.

To go directly to the Work with Folders display, type WRKFLR on the

command line and press the Enter key. The Work with Folders display is

shown with all first-level folders on the system.

To use a particular folder on the Work with Folders display:

1. Type WRKFLR FLR(folder name) on the command line. If *ALL is specified for the folder name, a list of folders is shown

from which you can select a folder.

2. Press the Enter key.

The Work with Folders display is shown with a list of all folders in the

folder specified by folder name.
