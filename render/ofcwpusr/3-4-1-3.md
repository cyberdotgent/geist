#### 3.4.1.3 Copying a Line of Text to Several Locations

You can copy a line of text to several locations in your document at one

time using line commands. 1. Press the Home key to move the cursor to the line command area (five

blank spaces to the left of the typing area).

2. Type CR in the line command area next to the line you want to copy.

3. Type an A in the line command area next to each line you want the

copied line placed after. Or, type a B in the line command area next

to each line you want the copied line placed before.
