## PREFACE.4 How This Manual Has Changed

| The following changes have been made since the last edition of this

| manual: |

The Spell Options display is now shown by pressing F22 (Spell | functions) on the Edit display, and then selecting option 1 (Spell | options). Other function keys have also changed on the Edit display. |

Information about using and understanding the error log has been added

| to Chapter 8. |

Performance considerations for merging information have been added to

| Chapter 14. Changes since the previous edition of the manual are indicated by a

vertical line to the left of the change.
