To create a footnote: 1. On the Edit display, move the cursor to the position where you want the footnote reference placed (after the last letter of the word or

phrase that you want the footnote text to explain).

2. Press F5 (Goto) and the Goto prompt is shown.

3. Type .fn and press the Enter key. The Footnote Instruction display is

shown.

4. Type a Y (Yes) in the Type footnote text prompt., c.cp

5. Leave the System page number prompt blank. The system uses the first

available system page (at or above number 9000) to store the footnote

text.

6. Leave the Document and Folder prompts blank. The system stores the

footnote text in the current document and folder. For additional

[information about these prompts, see "Storing Footnotes for Repeated](10-4.md)
