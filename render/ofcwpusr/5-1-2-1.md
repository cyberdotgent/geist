#### 5.1.2.1 Creating a Source Physical File

To create a source physical file for your user dictionary:

1. Type the following on the command line:

CRTSRCPF FILE(library name/source physical file name)

If you do not remember the values, you can type CRTSCRPF on the command line and press F4 (Prompt). You are prompted for the

parameters.

2. Press the Enter key. 3. Add the words to the source file member using the STRSEU command.
