## Deleting a Footnote

associated footnote text.

When a Footnote instruction is deleted, the system does not immediately

delete the formatted text that is associated with that footnote. The document must be paginated in order to remove the formatted text for a

deleted Footnote instruction and renumber the remaining footnotes.

To delete a footnote: 1. On the Edit display, move the cursor to the control character of the

Footnote instruction to be deleted. 2. Press the Enter key. The Footnote Instruction display is shown with

the page number for this footnote.

3. Write down the page number shown in the System page number prompt. You will need this number to delete the system-controlled page in step

6. 4. Press F16 (Delete instruction). The instruction is deleted, but the

text for the footnote is not deleted until the document is paginated.

You are returned to the Edit display.

5. Paginate the document: a. Press F16 (Adjust/Paginate). The Select Adjust/Paginate Option

display is shown.

b. Type a 2 (Adjust line and page endings). c. Press the Enter key. The document is paginated and the formatted

text for that footnote is deleted

6. When the document is paginated, the system does not delete the system-controlled page that contains the footnote text. To delete the | system-controlled page, you must go to the system-controlled page and delete the entire page. If you are getting this footnote text from a document other than the one you are editing, you must go to the

document you specified for the Document and Folder prompts and delete

the footnote text.
