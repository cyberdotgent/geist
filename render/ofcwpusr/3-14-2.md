Select Adjust/Paginate Option

Select one of the following:

Selection

_

F3=Exit F12=Cancel

2. Select option 1 (Adjust line endings) if you want to adjust only the

line endings. Select option 2 (Adjust line and page endings) if you want to adjust

both the line and page endings. Select option 3 (Adjust to end of paragraph) if you want to adjust the

line endings to the end of a paragraph.

3. Press the Enter key.

If you select option 1 (Adjust line endings), the line endings in the

entire document are adjusted. If you select option 2 (Adjust line and page endings), all your lines

are adjusted and the entire document is paginated. If you select option 3 (Adjust to end of paragraph), your lines are adjusted from the current cursor location to the end of the paragraph. If you select option 2 (Adjust line and page endings), you are returned to

the first page in the document.
