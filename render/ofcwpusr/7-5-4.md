2. Press F5 (Goto) to show the Goto prompt. 3. Type one of the following abbreviations for the header or footer you

want to print the outline heading text for:

A Part of the Document

h header

f footer

ef even footer

eh even header

eo even/odd header/footer

of odd footer

oh odd header

The Document Format

dh document header

df document footer

def document even footer

deh document even header

deo document even/odd header/footer

dof document odd footer

doh document odd header

The Alternate Format

af alternate footer

ah alternate header

aef alternate even footer

aeh alternate even header

aof alternate odd footer

aoh alternate odd header

aeo alternate even/odd header/footer 4. Press the Enter key and the Header (or Footer) Edit display is shown. 5. Move the cursor where you want the outline heading text to be printed. (You can also type other text in the header or footer.)

6. Press F5 (Goto) to show the Goto prompt.

7. Type .ht and press the Enter key. The Select Outline Heading display

is shown., c.cp 8. Type the level of the outline heading text you want printed for the

Outline heading level prompt. 9. Press the Enter key to create the instruction. When your document is

printed, the text associated with the current outline heading with the

level number specified by the .ht instruction is printed. 10. Press F3 (Exit/Save) when you have completed typing the header or

footer. You are returned to the Edit display.
