#### 17.4.1.3 Adding a Column

If you begin typing text and decide you would like to add another column,

move the cursor to the text column format change (tc), press the Enter key and change the definition of the columns. If you do not increase the

number of columns within this text column format change, the column that you add will be added to the next set of columns. For example, if you

defined two columns and added another column without increasing the number

of columns within this text column format change, that column would be

added to the next set of columns as shown in the following:
