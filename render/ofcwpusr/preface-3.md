## PREFACE.3 How This Manual Is Organized

This manual is divided into chapters, appendixes, a glossary, and an

index.

Chapters 1 through 3 explain how to create documents, name documents and folders, how to find documents, and type and edit documents.

Chapters 4 and 5 discuss how to use spelling dictionaries and check

the spelling of text.

Chapter 6 explains what text instructions are and how to use them.

Chapter 7 supplies information about changing the format for the

entire document or for a section in the document and about describing

the document format in a text profile.

Chapter 8 supplies the information you need to end, save, and print a document. It also explains how to manage the print queue from your work station if you have several jobs waiting to be printed.

Chapters 9 through 11 explain how to create a table of contents, an

index, footnotes, tables, and multiple text columns.

Chapter 12 describes how to use math calculations with rows and

columns.

Chapter 13 describes all the different ways you can store variables.

Chapter 14 discusses how to create documents that are tailored for

each person receiving the document. You can tailor a document by typing in the variable information (using stop codes or a paragraphs

document) or by merging stored information into the document from a fill-in document, a file, or a query report.

Chapter 15 describes how to insert graphics into your document as well as how to copy, delete, view, rename, and print images and graphics.

Chapter 16 discusses how to create and print labels and envelopes.

Chapter 17 discusses how to use folders within folders and the PC

text-assist function. |

Chapter 18 describes the differences between OfficeVision/400 word

| processing and the adapted word processing function.

Appendixes: - Appendix A summarizes printers that may be used with the AS/400

system and the word processing functions they support. - Appendix B describes the options that are saved and remembered

each time you use the word processing function. - Appendix C is a chart that summarizes word, line, and paragraph

definitions. - Appendix D is a chart that summarizes how the parameters in the

printer file specified on the Print Options display relate to the

values you specify in your document.

| - Appendix E describes the differences between OfficeVision/400 word

| processing and DisplayWrite/36. | - Appendix F describes the differences between OfficeVision/400 word

| processing and System/38 text management. In the back of this manual is a glossary and an index. Use the glossary to find the meaning of an unfamiliar term. Use the index to look up a topic and to see on which pages the topic is covered.
