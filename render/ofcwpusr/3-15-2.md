### Using Page End Control Characters

To insert a Page End control character in your document: 1. Move the cursor to the place where you want the current page to end. 2. Press the Alt key plus the P key to insert a Page End control

character. This ends the page on the display and puts you at the top of a new

display.

Notes:

1. Page End control characters are rearranged or deleted when the document is paginated. Pagination inserts its own Page End control

characters according to the First typing line and the Last typing line that were specified in the formats for the document. Pagination does

not delete the Page End control character before a page format change. 2. You can delete any Page End control character (except the last one in a document or before a page format) the same way you delete any other

character.
