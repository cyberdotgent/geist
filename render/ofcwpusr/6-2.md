After you have created a document that contains Help Text Label

instructions, you must define a link to this information from the display.

The H specification identifies that part of the display that finds your

document. The label name you assign in the H specification must be the same label as you use in the Help Text Label instruction. For information

about the H specifications, see the SDA User's Guide/Reference.

Help Text Label instructions are not allowed in multiple text

columns.
