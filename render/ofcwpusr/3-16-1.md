<a id="HDRPAGDOC"></a>

#### Using the PAGDOC (Paginate a Document) Command

To paginate a document using the PAGDOC command:

1. Type the following on the command line:

PAGDOC DOC(document name) FLR(folder name)

2. Press the Enter key. The document is paginated on the job queue and you receive a message

when the job is completed.

If *PRV is specified for the document or folder name, the name of

the document or folder used in your last edit session is used.

If you do not remember the parameters, you can type PAGDOC on the command line and press F4 (Prompt). You are then prompted for the

parameters.
