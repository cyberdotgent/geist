### 8.3.4 Overriding the Print Options Using the Print Document (PRTDOC) Command

You can override one or more of the print options that are stored with the

document, by specifying the parameter you want to override. For example, if you want to print a document with a cover page, type:

PRTDOC DOC(document name) FLR(folder name)

OPTIONS(*NO) COVERPAGE(*YES)

If you want to print a document on a different printer, type:

PRTDOC DOC(document name) FLR(folder name)

OPTIONS(*NO) DEV(printerID) OUTQ(*DEV, c.cp

If you want to print a document with an error page, type:

PRTDOC DOC(document name) FLR(folder name)

OPTIONS(*NO) PRTERRLOG(*YES)

If you want to print a document using the printer file, type:

PRTDOC DOC(document name) FLR(folder name)

OPTIONS(*PRTFILE) PRTFILE(library/file name)

For more information about how to override parameters, see Application

Development by Example or the CL Reference manual.
