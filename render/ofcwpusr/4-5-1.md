1. Type the following on the command line:

CHKDOC DOC(document name) FLR(folder name) TYPE(*GRADE)

STRPAGE(starting page number) ENDPAGE(ending page number)

2. Press the Enter key.

If *PRV is specified for the document or folder name, the name of

the document or folder used in your last edit session is used.

If *BEGIN is specified for the starting page number, the spelling

is checked starting on the first page of the document.

If *END is specified for the ending page number, the spelling is

checked to the end of the last page of the document.

If you do not remember what to type, type CHKDOC on the command line and

press F4 (Prompt) to see a prompt display. The grade level is checked on the job queue and you receive a message when

the checking is completed.
