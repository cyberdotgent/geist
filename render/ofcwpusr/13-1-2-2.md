#### 13.1.2.2 Using Summary Math and Set Variable Instructions Together

Using the summary math instructions, you can define a variable and use

that variable as the first value or second value in a Set Variable instruction. For example, using a Summary Math instruction, a total was

calculated and its result was stored in the variable SUB. Set Variable

instructions are used later in the document to perform other math

operations using the variable SU
