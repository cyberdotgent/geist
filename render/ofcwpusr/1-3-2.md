#### 1.3.2 Creating a First-Level Folder Using the CRTFLR (Create Folder) Command

1. Type the following on the command line:

CRTFLR FLR(folder name)

If you do not remember the parameters, type CRTFLR on the command line and press F4 (Prompt). You are prompted for the parameters. 2. Press the Enter key and a message appears telling you that the folder

has been created.

You cannot assign a text profile to a folder using the CRTFLR

command. If you want to create a folder with a text profile

assigned, create the folder from the Work with Folders display

or the Work with Documents in Folders display.
