#### 3.4.2.2 Moving a Block of Lines

1. Press the Home key to move the cursor to the line command area (five

blank spaces to the left of the typing area). 2. Specify a block of text to be moved in one of two ways:

Type MM in the line command area next to the first and last lines of the block of text you want to move, as shown below. This way

is faster when you have to page through your document searching

for the last line of the block of text you want to move., c.cp

Type an M followed by the number of lines in the block (for

example, M3 to move three lines) next to the first line of the block of text you want to move. This way is faster when you know exactly how many lines are in the block of text you want to move

3. Type an A in the line command area next to the line you want the moved

block of text placed after. Or, type a B in the line command area

next to the line you want the moved block of text placed before. 4. Press the Enter key, and the block of text is moved to the specified

location. 5. Press the Home key to return the cursor from the line command area to

the text area. 6. Press the Enter key to remove the line command area from your display.
