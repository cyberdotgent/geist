2. Type a Y (Yes) for the Print error log prompt. Specify a different form number for the error log if you want to avoid

printing the error log on your label forms. 3. Press the Enter key. The error log is printed after the labels are

printed.

4. Determine the type of problem from the error log. 5. Use the error log to determine the solution to your problem and to

correct the problem.

6. Repeat the above steps until the labels print correctly.

7. Print the labels.
