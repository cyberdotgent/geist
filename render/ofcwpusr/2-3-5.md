### Underlining Boldface Type

To underline bold text: 1. Complete the steps to make the character, word, or phrase bold.

2. Move the cursor to the Begin Bold control character. 3. Press the Alt key plus the U key to underline the bold text. You do not need to end the underline because the End Bold control character (which is already typed) ends both the underline and the bold. However, if you want to end the bold but continue the underline, press the Alt key plus the U key after the End Bold control

character. If you want to end the underline but continue the bold, press the Alt key plus the B key after the End Bold control character

2. Move the cursor to the Begin Bold control character. 3. Press the Alt key plus the U key to underline the bold text. 4. To end the bold and the underline, move the cursor to the position where you want to end the underline and press the Alt key plus the J

key. 5. To end the bold and continue the underline, press the Alt key plus the

B key. 6. To end the underline and continue the bold, press the Alt key plus the

U key.
