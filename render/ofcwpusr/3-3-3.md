### 3.3.3 Deleting Text

To delete text:

1. Place the cursor under the first character of the text you want to

delete.

2. Press the Delete (Del) key. A prompt is shown on the message line at the bottom of your display:

Delete what

Move cursor, press Enter.

3. Move the cursor under the last character of the text you want to

delete.

4. Press the Enter key. The text is deleted.

If you specified Y (Yes) for the Highlight text to delete prompt on

the Change Editing Options display, the text is shown in reverse image

and a message asks you to confirm or cancel the delete.

When using the PC text-assist function, text is automatically

highlighted as the cursor is moved.
