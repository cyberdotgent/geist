### 14.2.3 Printing a Reference Copy of the Paragraphs Document

makes it easier to print a tailored document with a combination of

paragraphs.

To print a reference copy of the paragraphs document: 1. On the Work with Documents in Folders display, select option 9 (Print

options) in the Option prompt. Type the name of the paragraphs

document and the name of the folder it is stored in for the Document

and Folder prompts. Press the Enter key.

Page 1 of the Print Options display is shown.

2. Type a 1 (Printer) for the Output device prompt. Additional prompts

are shown. Specify the printer you want the reference copy to be

printed on for the Printer prompt.

Page down to page 2 of the Print Options display.

Type an N (No) for the Resolve instructions prompt. Type an N (No)

for the Adjust page endings prompt so the document will not be

paginated.

3. Press the Enter key to print the reference copy., c.cp 4. Write the correct page number beside each paragraph on your printed

reference cop
