### 7.2.2 Changing a Format Change

To change an existing format change: 1. Move your cursor on the format change symbol you want to change.

2. Press the Enter key.

The Select Format display is shown. The items on the Select Format

display vary depending on the type of format change you are changing. 3. Select the items you wish to change, go to the display for each item,

and make the necessary changes.

Selecting option 1 (Format for the entire document) does not

change the existing format change, a highlighted F.

4. Press the Enter key to return to the Edit display.
