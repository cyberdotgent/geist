In addition to text, a notepad can contain:

Text instructions

Control characters such as underline, bold, stop codes, page ends, or

tabs.

Line format changes such as line spacing or type style.

Page format changes such as headers, footers, or page layout.

You specify the notepad option on the Select Notepad Option menu or by

using F5 (Goto). You can get to the Select Notepad Option menu from the Edit display in one

of the following ways:

By pressing F17 (Functions) and selecting option 2 (Notepad). When the Select Notepad Option menu is shown, you can select to move or

copy text to a notepad, or recall text from a notepad.
