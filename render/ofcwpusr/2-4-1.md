### 2.4.1 Typing Paragraphs

Paragraphs contain a Carrier Return or a syllable hyphen on the end of

each line and a Required Carrier Return on the end of the last line of the

paragraph. The Carrier Returns are automatically inserted as you type when the end of a line is reached. The Required Carrier Return is inserted when you press the Field Exit key to end the paragraph. You must press the Field Exit key a second time to put a blank line between

paragraphs.
