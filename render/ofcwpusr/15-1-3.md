### 15.1.3 Using the #$@INCLGRPH Function

[| steps to get the graphics into the document (as explained in "Using the](15-1-2.md)

[| Get Graphic Function" in topic 15.1.2). The #$@INCLGRPH function can be](15-1-2.md)

| used instead of the get graphic function.

| The #$@INCLGRPH function can be used to: |

Print a graphic without having to get the the graphic into the

| document. |

Print a graphic and print text to the left, right, above, below, or on

| the graphic.

|

Print more than one graphic on a page or on a line of a page. | The #$@INCLGRPH function is provided by the Operating System/400* . | (OS/400*) licensed program rather than OfficeVision/400; however, you can | use the OfficeVision/400 office editor to enter one or more #$@INCLGRPH | command strings into a document. When a document containing this command

| string prints, special processing in the OS/400 program includes the | graphics at the location on the page and at the size specified by the

| #$@INCLGRPH command string.

| To include the #$@INCLGRPH command in a document, type #$@INCLGRPH

. | FILENAME,x,y,w,l at the top of the page on which the graphic should print. | The #$@INCLGRPH command and the file name must be all uppercase | characters. For the FILENAME, x, y, w, and l, complete as follows: |

Type the BGU graph object file name for the FILENAME. The library | that contains this BGU graph object file must be in your library list | at the time the document prints in order for the BGU graph object file | to be found. The last member in this file is always used. |

x is the distance in inches from the left edge of the paper. |

y is the distance in inches from the top edge of the paper.

|

w is the width of the graphic in inches.

|

l is the length of the graphic in inches., c.cp

| Notes:

| 1. The printed graphic is enlarged or reduced to fit within the

| length and width specified.

| 2. Specify the values for x, y, w, l in the format aa.aa. For

| example, the value for x could be specified as 2.20 (inches). Any

| value not specified defaults to 0. | 3. The document must be printed on an IPDS printer in order for the | graphic to print (for example, a 3812 Printer). | The #$@INCLGRPH command string must be first in a line of data processed | by the OS/400 program. Because of the specific printer data streams that | the OfficeVision/400 print function creates, you must be careful where you

| place the command string in a document. Consider the following

| information when placing the command string in a document. |

If the document contains more than 1 left margin value, make sure that | the #$@INCLGRPH command string is located at the smallest left margin | specified in the entire document. For example, if you used a format | change to change the left margin from 19 to 10, make sure that the

| active left margin is 10 at the point where the #$@INCLGRPH command

| string is located. |

Justification cannot be active at the point where the #$@INCLGRPH | command string is located. If justification is active, the printer | data stream created by OfficeVision/400 contains some control | characters at the start of each line. This causes the #$@INCLGRPH | command string to be unrecognized. If the text on the page must be | justified, insert a format change that turns justification off (off | means left justification), before the #$@INCLGRPH command string. | After the #$@INCLGRPH string, insert another format change to reset

| justification to the desired value. |

If the page containing the graphic is part of a multiple text columns | set, use the multiple text columns function to return to single column | mode before the #$@INCLGRPH command string. Then return to multiple

| text column mode following the #$@INCLGRPH command string. | The position of the #$@INCLGRPH command string in the document has no | relation to where the graphic actually prints. Therefore, if you place | all #$@INCLGRPH command strings together at the top of the page on which

| the graphics will print, you minimize the number of format changes that | may be necessary to ensure that the #$@INCLGRPH command string is

| recognized by the OS/400 program.
