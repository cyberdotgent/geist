#### 17.4.1.4 Viewing Text in Multiple Columns

It is a good idea to paginate the document and view the columns on the

display before you print them. You can view multiple text columns by pressing F19 (View/Print). For you to view the text in multiple columns,

the Next Text Column instructions must be inserted to indicate where the one column ends and the next column begins. You can manually insert the Next Text Column instructions or you can let pagination put them in for

you if you are using flowing and balanced columns.
