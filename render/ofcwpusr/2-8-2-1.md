#### 2.8.2.1 Copying Keyboard Changes

To copy a keyboard change: 1. Place the cursor under the Begin Keyboard Change control character. 2. Press F1 (Copy). The following message is shown:

Copy what

Move cursor, press Enter. 3. Move the cursor to the End Keyboard Change control character.

4. Press the Enter key. A prompt is shown on the message line at the bottom of your display:

To where

Move cursor, press Enter. 5. Move the cursor to the location in the document where you want the

keyboard change copied. This location must not be within an existing keyboard change unless you are using the PC text-assist function where

the system automatically inserts any needed keyboard change control

characters. 6. Press the Enter key. The keyboard change is copied to the new

location.
