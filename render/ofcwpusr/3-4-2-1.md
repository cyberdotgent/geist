#### 3.4.2.1 Moving a Single Line of Text

1. Press the Home key to move the cursor to the line command area (five

blank spaces to the left of the typing area).

2. Type an M in the line command area next to the line you want to move.

3. Type an A in the line command area next to the line you want the line

moved after. Or, type a B in the line command area next to the line

you want the line moved before. 4. Press the Enter key and the line is moved to the specified location. 5. Press the Home key to return the cursor from the line command area to

the text area. 6. Press the Enter key to remove the line command area from your display.
