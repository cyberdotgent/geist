### Typing Label Text

To type label text: 1. On the Edit display, type the information for the first label. 2. If you want more than one label in the document, type each label on a

separate page., c.cp 3. To separate the labels, use the Alt key plus the P key or a Start New Page instruction (.pa). If you use a Start New Page instruction, insert a Carrier Return after each (.pa). To highlight lines in a label, use the Begin Bold (Alt B) and End Bold (Alt J) control characters on each line of the label. To underline lines in a label, use the Begin Underline (Alt U) and End Underline (Alt J) control characters on each line of the label.

4. Continue by saving and printing the labels.
