### Working with the Document Format

know about the document format. The document format describes how the

document looks when it is printed. The document format includes such things as margin settings, tab settings, line spacing, left and right alignment, lines per inch vertically, type style and color, paper size, and page layout (blank lines at the top and bottom of the page). You can

use the format supplied by the system for your documents, or you can make

changes to the format.

You can store a document format in a text profile. Besides format options, a text profile also contains options for editing and printing a

document. The system provides a text profile named SYSTEM, which contains the default format settings. It is used for every document you create unless

[you create and activate a different text profile. (See "Using Text](7-7.md)

[HDRPROF](7-7.md)

Profiles" in topic 7.7.)

The characteristics of the default format settings are:

Margins of 19 and 91

Flush left tab setting every 5 spaces

Lines aligned at the left

12-pitch type style (type style 86)

6 lines per inch

Line endings are adjusted

6-space hyphenation zone width 8-1/2 x 11-inch paper size

6 blank lines at the top of the printed page

6 blank lines at the bottom of the printed page

You can start typing your document using this default format. If you would like to change one or more of these characteristics for a line, page, section, or an entire document, you can change it before you type or print the document. For more information about formats, see

[HDRFORM](index.md)

Chapter 7, "Formatting a Document."
