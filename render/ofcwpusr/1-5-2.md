### 1.5.2 Creating a Document Using the CRTDOC (Create Document) Command

To create a document using the CRTDOC command:

1. Type the following on the command line:

CRTDOC DOC(document name) FLR(folder name)

If *PRV is specified for the folder name, the name of the folder

used in your last edit session is used.

If you do not remember the parameters, type CRTDOC on the command line and press F4 (Prompt). Then you are prompted for the

parameters. 2. Press the Enter key, and the first page of the Create Document Details

display is shown.
