You can insert text in one of the following ways: 1. Using the get function. The get function immediately gets the text into the document you are editing. You can get text from any document

or source physical file. 2. Using the Include instruction. The text is not included in your

document until you print the document. You can include text from any document, but you cannot include text from a source physical file.

Note: The document you are getting or including assumes the format of

your original document unless specific format changes are in the

text you are getting or including
