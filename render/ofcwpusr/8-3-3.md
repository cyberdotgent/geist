### 8.3.3 Printing a Document to a File

To print a document to a file using the PRTDOC command:

1. Type the following on the command line:

PRTDOC DOC(document name) FLR(folder name)

( OPTIONS(*OUTFILE) OUTFILE(library/file name) OUTMBR(*FIRST)

2. Press the Enter key. Your resolved output is stored in the specified file and member. If this file already exists, the output is added to the file. If this is a new file, the file is created and the output is stored in the

specified member.
