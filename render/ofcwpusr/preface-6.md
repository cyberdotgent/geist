## PREFACE.6 Related Printed Information

The manuals below are listed with their full title and base order number. When these manuals are referred to in this manual, a shortened version of

the title is used. If you need more information, refer to the following AS/400 office

manuals:

|

Office: Planning For and Setting Up OfficeVision/400, SC21-9626. | This manual has information on how to plan and set up your office

| environment.

|

| to best use the different functions.

|

Office: Learning about OfficeVision/400 Word Processing, SC21-9617. | This manual provides office users with information to help them learn | how to use the word processing functions of OfficeVision/400.

|

| quick reference information.

|

| processing tasks with the adapted word processing function of

| OfficeVision/400.

Information Directory, GC21-9678. This manual contains information

about all manuals for the AS/400 system.

Programming: Command Reference Summary, SC21-8076. This manual is

designed to help the programmer quickly refer to the AS/400 command syntax. This manual contains an alphabetic list of all AS/400

commands.

Programming: Control Language Reference, SBOF-0481. This manual

describes the AS/400 control language (CL) commands. Each command is defined, including its syntax diagram, parameters, default values, and

keywords.
