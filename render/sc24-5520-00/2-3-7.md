## 2.3.7 Establishing IUCV Paths

<a id="HDRIUCVS2"></a>

After enabling IUCV, your program must establish a path, or paths, to each virtual machine with which you communicate. When you establish a path, you also define various characteristics of the path; for example, whether the path can handle priority messages, or the number of messages that can be outstanding on the path. For IUCV to complete a path between two virtual machines, two IUCV functions must be used: the ACCEPT function and the CONNECT function. [Figure 10](2-3-7.md#C92FIG2) shows how two users, SOURCE and TARGET, might establish paths between their virtual machines.

<a id="C92FIG2"></a>

```text
    ________________________________________________________________________ 
   |                                                                                  |
   |  SOURCE's Virtual Machine               TARGET's Virtual Machine                 |
   |                                                                                  |
   |  Issues the CONNECT function                                                     |
   |  specifying TARGET as the ID                                                     |
   |  of the virtual machine with                                                     |
   |  which a path is to be                                                           |
   |                                         external interrupt indicating            |
   |                                         that SOURCE wants to establish           |
   |                                         path                                     |
   |                                         Issues the ACCEPT function to            |
   | complete" external interrupt                                                     |
   | indicating that the path                                                         |
   | is complete.                                                                     |
   |                                                                                  |
   |________________________________________________________________________|
```

For more information on the ACCEPT and CONNECT functions see ["ACCEPT" in](2-4-1.md) [topic 2.4.1](2-4-1.md) and ["CONNECT" in topic 2.4.2](2-4-2.md).
