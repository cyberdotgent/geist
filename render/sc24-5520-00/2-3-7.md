## 2.3.7 Establishing IUCV Paths

<a id="HDRIUCVS2"></a>

After enabling IUCV, your program must establish a path, or paths, to each virtual machine with which you communicate. When you establish a path, you also define various characteristics of the path; for example, whether the path can handle priority messages, or the number of messages that can be outstanding on the path. For IUCV to complete a path between two virtual machines, two IUCV functions must be used: the ACCEPT function and the CONNECT function.
