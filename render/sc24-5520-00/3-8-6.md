## 3\.8\.6 APPCVM SENDDATA

<a id="HDRTSFSDA"></a>

Use the SENDDATA function to send data from your program to your communication partner\. You can also use this function to switch the conversation state from the Send state to the Receive state and to define an answer area for your partner's SENDDATA\.
