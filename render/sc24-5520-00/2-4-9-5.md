#### 2\.4\.9\.5 REJECT Parameter List Input Fields

`IPPATHID` contains the path identification number of the message you are rejecting\.

`IPFLAGS1` specifies options for the REJECT function\. IUCV treats each bit in IPFLAGS1 separately\. Make sure that bits you are not using to define input are set to 0\.

`IPFGMCL flag (bit X'01')` indicates, when set to 1, that you have specified a message class for the message you are rejecting\.

`IPFGPID flag (bit X'02')` indicates, when set to 1, that you have specified a path identification number for the message you are rejecting\.

`IPFGMID flag (bit X'04')` indicates, when set to 1, that you have specified a message identification number for the message you are rejecting\.

`IPMSGID` contains the message identification number of the message you are rejecting\.

`IPTRGCLS` contains the message class of the message you are rejecting\.
