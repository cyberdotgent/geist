## 2\.6\.4 IUCV Audit Trails

IUCV maintains an audit trail for each message that records the status of each message\. IUCV stores the audit trail information in the IPAUDIT field of \(1\) the PURGE function, \(2\) the TESTCMPL function, and \(3\) message\-complete IUCV external interrupts\. The significance of the bits in the IPAUDIT field are as follows:

<a id="TBLTBLUNIQ94"></a>

```
   Bit               Code         Meaning

   IPADRPLE          X'8000'      Reply too long for buffer
   IPADSNPX          X'4000'      Protection exception on send buffer
   IPADSNAX          X'2000'      Addressing exception on send buffer
   IPADANPX          X'1000'      Protection exception on answer buffer
   IPADANAX          X'0800'      Addressing exception on answer buffer
   IPADRJCT          X'0400'      Message was rejected
   IPADPRMD          X'0200'      Reply data in parameter list not allowed by the originator
                     X'0100'      Reserved
   IPADRCPX          X'0080'      Protection exception on receive buffer
   IPADRCAX          X'0040'      Addressing exception on receive buffer
   IPADRPPX          X'0020'      Protection exception on reply buffer
   IPADRPAX          X'0010'      Addressing exception on reply buffer
   IPADSVRD          X'0008'      Path was severed
                     X'0004'      Reserved
                     X'0002'      Reserved
                     X'0001'      Reserved
   IPADRLST          X'0004'      Invalid RECEIVE/REPLY list
                     X'0002'      Reserved
                     X'0001'      Reserved
   IPADBLEN          X'000080'    Bad length in SEND buffer list
   IPADALEN          X'000040'    Bad length in SEND answer list
   IPADBTOT          X'000020'    Invalid total SEND buffer list
   IPADATOT          X'000010'    Invalid total SEND answer length
                     X'000008'    Reserved
                     X'000004'    Reserved
                     X'000002'    Reserved
                     X'000001'    Reserved
```
