#### 2.4.9.2 Identifying the Message You Want to Reject

As just mentioned, to reject a message, you must identify it.  You can ??????????????    identify a message in any of the following ways:?????????????????    1.  By message identification number, path identification number, and ?        message class.  In this case, IUCV rejects a specific message.?    2.  By path identification number and message class.  IUCV rejects the ???????????????        first message with the correct path identification and message class.?    3.  By path identification number.  IUCV rejects the first message with ?        the correct path identification.?    4.  By message class.  IUCV rejects the first message with the correct ?        message class.

**Note:** IUCV stores message identification values in the RECEIVE and DESCRIBE parameter lists, as well as in a message-pending external interrupt. IUCV stores the message identification number in the IPMSGID field, the path identification number in the IPPATHID field, and the message class in the IPSRCCLS field.

Specifying a Message Identification Number: Specify the message identification number in one of the following ways: 1. Use the MSGID=parameter. Specify the message identifier as (a) the relocatable label of a fullword containing the message identifier, or (b) the number of a register that contains the message identifier. 2. Store the message identification number in the IPMSGID field of the REJECT parameter list. Also, set the IPFGMID bit (X'04') to 1 in the IPFLAGS1 field.

**Note:** If you use the MSGID=parameter, IUCV stores the message ID and sets the IPFGMID flag automatically. Remember that whenever you specify a message identification number, you must also specify the message's path ID and target message class.

Specifying a Message Path Identification Number: Specify the path identification number of a message in one of the following ways: 1. Use the PATHID=parameter. Specify the path identification as (a) the relocatable label of a halfword that contains the path ID, or (b) the number of a register that contains the path ID in the low-order halfword. 2. Store the path identification number in the IPPATHID field of the REJECT parameter list. Also, set the IPFGPID bit (X'02') to 1 in the IPFLAGS1 field. Note**: If** you use the PATHID=parameter, IUCV stores the path ID and sets the IPFGPID flag automatically. Specifying a Message Class: Specify the class of a message in one of the following ways: 1. Use the TRGCLS=parameter. Specify the message class as (1) the relocatable label of a fullword containing the message class, or (2) the number of a register containing the message class. 2. Store the message class in the IPTRGCLS field of the REJECT parameter list. Also, set the IPFGMCL bit (X'01') to 1 in the IPFLAGS1 field.

**Note:** If you use the TRGCLS=parameter, IUCV stores the message class and sets the IPFGMCL flag automatically.
