#### 2.4.10.9 Program Exceptions

The following program exceptions can occur if you invoke the REPLY function incorrectly: Specification. You did not define your parameter list on a doubleword boundary. Operation. IUCV is inactive; you have not used the DCLBFR function to declare an external interrupt buffer. Addressing: Your parameter list address is invalid; the address you specified is outside of your virtual machine's storage. The buffer address you specified is invalid.
