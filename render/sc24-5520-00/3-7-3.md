## 3\.7\.3 Invoking APPC/VM Communication Functions

VM/ESA programs at each end of an APPC/VM path use APPC/VM functions to communicate with each other\. Most APPC/VM communications functions are provided as parameters of the APPCVM macro\. The APPC/VM communications functions used with the APPCVM macro are listed in the following table, with the page numbers where the functions are described\.

<a id="TBLTBLUNIQ95"></a>

```
    ______________ _______________________________________________ __________
   | Function     | Description                                   | Topic    |
   |______________|_______________________________________________|__________|
   | CONNECT      | Establishes and reserves a path to            | 3.8.1    |
   |              | communicate with another program              |          |
   |______________|_______________________________________________|__________|
   | QRYSTATE     | Determines the current state of a path        | 3.8.2    |
   |______________|_______________________________________________|__________|
   | RECEIVE      | Receives data and information sent to your    | 3.8.3    |
   |              | program                                       |          |
   |______________|_______________________________________________|__________|
   | SENDCNF      | Sends a confirmation request to your          | 3.8.4    |
   |              | communications partner                        |          |
   |______________|_______________________________________________|__________|
   | SENDCNFD     | Sends a response to a confirmation request    | 3.8.5    |
   |______________|_______________________________________________|__________|
   | SENDDATA     | Sends data to your communications partner     | 3.8.6    |
   |______________|_______________________________________________|__________|
   | SENDERR      | Sends notice to your communications partner   | 3.8.7    |
   |              | that your program has detected an error       |          |
   |______________|_______________________________________________|__________|
   | SENDREQ      | Requests permission to send data              | 3.8.8    |
   |______________|_______________________________________________|__________|
   | SETMODFY     | Sets the state to Defer_Receive or            | 3.8.9    |
   |              | Defer_Sever and sets the sync-point control   |          |
   |              | modifier                                      |          |
   |______________|_______________________________________________|__________|
   | SEVER        | Ends communications with another program      | 3.8.10   |
   |______________|_______________________________________________|__________|
```

In addition, some APPC/VM functions are provided as parameters on the IUCV macro\. The APPC/VM communications functions used with the IUCV macro are:

- ACCEPT
- QUERY
- SEVER\.

The IUCV macro functions relate to both APPC/VM and IUCV paths\. The IUCV functions are not defined by the SNA LU 6\.2 \(APPC architecture\) verb interface, but they are a necessary complement for APPC programs executing in a VM/ESA processor\. The IUCV macro functions that relate to APPC/VM are listed in the following table, with the page numbers where the functions are described\.

<a id="TBLTBLUNIQ96"></a>

```
    ______________ _______________________________________________ __________
   | Function     | Description                                   | Topic    |
   |______________|_______________________________________________|__________|
   | ACCEPT       | Accepts a connection from another virtual     | 5.10.4   |
   |              | machine or from your own virtual machine      |          |
   |______________|_______________________________________________|__________|
   | CONNECT      | Establishes a path to the IDENTIFY system     | 5.10.5   |
   |              | service (*IDENT)                              |          |
   |______________|_______________________________________________|__________|

   |              | IUCV message                                  |          |

   | QUERY        | Determines the maximum number of              | 5.10.8   |
   |              | communications paths that can be established  |          |
   |              | for your virtual machine                      |          |
   |______________|_______________________________________________|__________|

   |              | ending communications                         |          |

   |______________|_______________________________________________|__________|

   |              | interrupt handling                            |          |
   |______________|_______________________________________________|__________|
```

**Note:** Other IUCV macro functions can be used from APPC/VM, but are not recommended for use by APPC/VM programs running in CMS\. For information about APPC/VM and IUCV macro functions that you can use in CMS, see *VM/ESA CMS Application Development Guide for Assembler*\.
