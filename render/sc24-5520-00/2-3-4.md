## 2\.3\.4 Planning to Use IUCV

<a id="HDRIUCVS0A"></a>

Before you begin to code an IUCV program, you and all of the users who plan to use IUCV to communicate must establish a protocol\. For example, here are some questions you might want to consider:

1\. Who is authorized to communicate with whom? To authorize a virtual machine to establish a communication path with another virtual machine, you must code the IUCV directory control statement in at least one of the virtual machine's user directory entries\. For information on the IUCV directory control statement, see the *VM/ESA CP Planning and Administration* manual\.

2\. How is message data to be sent? A program can store message data

a\. In a storage buffer b\. In the IUCV parameter list \(for example, the SEND parameter list or the REPLY parameter list\)\.

3\. How are messages to be identified or classified? IUCV assigns all messages a message identification number and all paths a path identification number\. Additionally, when you use the SEND function, you can specify a message class, a message tag, and a 16\-byte user data area \(IUCV attaches no specific meaning to these identifiers; your installation must decide what, if anything, each one is to mean\)\.

4\. How are interrupts to be handled? To pass information from one virtual machine to another, IUCV reflects external interrupts\. An IUCV application program must be able to handle certain kinds of interrupts\. On the other hand, a virtual machine can field incoming messages or replies in one of the following ways:

- By enabling the virtual machine for message\-pending and message\-complete interrupts, and then handling these interrupts as they occur\.
- By disabling the virtual machine for message\-pending and message\-complete interrupts, and then periodically interrogating the message queues for incoming messages and replies\. \(Use the SETMASK and SETCMASK functions to disable your virtual machine for interrupts; use the DESCRIBE, TESTCMPL, and TESTMSG functions to interrogate message and reply queues\.\)
