## 3.8.7.11 Error Codes That CP and Communication Servers Can Issue

<a id="HDRSRRCOD"></a>

#### Error Codes That CP and Communication Servers Can Issue

[Table 54](#TBLAPPCSC) shows the codes that CP or a communication server can issue on an APPCVM SENDERR. This table also shows the APPC error condition associated with each error code. Refer to SNA Format and Protocol Reference Manual: Architectural Logic for LU Type 6.2 for an explanation of what these APPC conditions mean and when to use these error codes.

**Note:** A communication server within a TSAF collection can specify only codes X'0410', X'0420', and X'0430'.

<a id="APPCSC"></a>

Table 54. APPC/VM-Defined SENDERR Codes

| APPC/VM Code | APPC Error Condition |
| --- | --- |
| PROG_ERROR_TRUNC |  |
| X'0430' | PROG_ERROR_PURGING |
| X'0510' | SVC_ERROR_NO_TRUNC |
| X'0520' | SVC_ERROR_TRUNC |
