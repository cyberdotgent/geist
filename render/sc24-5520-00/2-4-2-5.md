#### 2.4.2.5 CONNECT Parameter List Output Fields

IPPATHID contains the path identification that IUCV assigns the path you are establishing. IPFLAGS1 specifies values that IUCV returns for the CONNECT function. IPPRTY (X'20') indicates, when set to 1, that you want to establish a path that can handle priority communications. IPRCODE contains one of the following return codes: Code **M**ean**ing** 00 Normal return 11 The virtual machine with which you are establishing a path is not logged on. 12 The virtual machine with which you are establishing a path has not declared an external interrupt buffer. 13 You have exceeded the number of paths that you can establish. 14 The virtual machine or CP system service with which you are establishing a path has exceeded the number of paths it can establish. 15 You are not authorized to establish a path. 16 The CP system service with which you are establishing a path is not valid. 28 You must create a control buffer. 48 The CP system service you specified does not support this IUCV function. IPMSGLIM contains the message limit for this path.
