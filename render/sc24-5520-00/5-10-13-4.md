#### 5\.10\.13\.4 TESTCMPL Input Parameter List

<a id="HDRTCMPPL"></a>

The IUCV TESTCMPL parameter list has the format shown in [Figure 71](5-10-13-4.md#FIGTCIPL)\.

<a id="FIGTCIPL"></a>

```
      IPARML DSECT

      0       1       2        3       4       5      6      7
      ________________ ________ ______________________________________ 
    0|    IPPATHID    |IPFLAGS1| //////////////////////////////////// |
     |________________|________|______________________________________|
    8| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
   10| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
   18| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
   20| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
```

*Figure 71\. IUCV TESTCMPL Input Parameter List*

`IPPATHID` contains the path ID on which you want to complete the function\. This parameter is only valid when the IPFGPID flag is set\.

`IPFLAGS1` contains the following input bit flag:

`IPFGPID (X'02')` You specified a path ID\.
