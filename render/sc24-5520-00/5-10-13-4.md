## 5.10.13.4 TESTCMPL Input Parameter List

<a id="HDRTCMPPL"></a>

#### TESTCMPL Input Parameter List

The IUCV TESTCMPL parameter list has the format shown in [Figure 71](#FIGTCIPL).

<a id="TCIPL IPARML DSECT 0 1 2 3 4 5 6 7 0 IPPATHID IPFLAGS1 //////////////////////////////////// 8 ////////////////////////////////////////////////////////////// 10 ////////////////////////////////////////////////////////////// 18 ////////////////////////////////////////////////////////////// 20 ////////////////////////////////////////////////////////////// Figure 71. IUCV TESTCMPL Input Parameter List"></a>

IPPATHID contains the path ID on which you want to complete the function. This parameter is only valid when the IPFGPID flag is set. IPFLAGS1 contains the following input bit flag: IPFGPID (X'02') You specified a path ID.
