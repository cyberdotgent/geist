#### 2\.4\.16\.4 SEVER Parameter List Input Fields

`IPPATHID` contains the path identification of the path you are trying to sever\.

`IPFLAGS1` specifies options for the SEVER function\. IUCV treats each bit in IPFLAGS1 separately\. Make sure bits you are not using to define input are set to 0\.

`IPALL flag (bit X'80')` when set to 1, tells CP to reactivate all of your paths\.

`IPUSER` contains the 16\-byte user data area IUCV reflects to the virtual machine at the other end of the path you sever\.
