## 3.8.8.4 SENDREQ Input Parameter List

<a id="HDRSREQPL"></a>

#### SENDREQ Input Parameter List

The APPCVM SENDREQ parameter list has the input format shown in [Figure 50](3-8-8-4.md#SRQIPL).

<a id="SRQIPL"></a>

```text
   |       0        1        2        3        4        5        6        7           |
   |_______________________________________________________________________|
   |_______________________________________________________________________|
   | /////////////////////////////////////////////////////////////////////            |
   |_______________________________________________________________________|
   | /////////////////////////////////////////////////////////////////////            |
   |_______________________________________________________________________|
   | /////////////////////////////////////////////////////////////////////            |
   |_______________________________________________________________________|
   | /////////////////////////////////////////////////////////////////////            |
   |_____________________________________________________________________________________|
```

**IPPATHID** contains the path ID on which the request to send is sent. **IPFLAGS1** contains the following input bit flag: IPAPPCSN (X'02') The APPC SEND function is issued. **IPSENDOP** contains the SEND option code: IPREQSND (X'07') indicates the request to send.
