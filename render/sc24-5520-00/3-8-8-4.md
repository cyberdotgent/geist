#### 3\.8\.8\.4 SENDREQ Input Parameter List

<a id="HDRSREQPL"></a>

The APPCVM SENDREQ parameter list has the input format shown in [Figure 50](3-8-8-4.md#FIGSRQIPL)\.

<a id="FIGSRQIPL"></a>

```
      IPARML DSECT

      0        1        2        3        4        5        6        7
       _________________ ________ ___________________________________ ________ 
    0 |    IPPATHID     |IPFLAGS1| ///////////////////////////////// |IPSENDOP|
      |_________________|________|___________________________________|________|
    8 | ///////////////////////////////////////////////////////////////////// |
      |_______________________________________________________________________|
   10 | ///////////////////////////////////////////////////////////////////// |
      |_______________________________________________________________________|
   18 | ///////////////////////////////////////////////////////////////////// |
      |_______________________________________________________________________|
   20 | ///////////////////////////////////////////////////////////////////// |
      |_______________________________________________________________________|
```

*Figure 50\. APPCVM SENDREQ Input Parameter List*

**IPPATHID** contains the path ID on which the request to send is sent\.

**IPFLAGS1** contains the following input bit flag:

IPAPPCSN \(X'02'\) The APPC SEND function is issued\.

**IPSENDOP** contains the SEND option code:

IPREQSND \(X'07'\) indicates the request to send\.
