## 2.4.10 REPLY

<a id="HDRREPLY"></a>

Use the REPLY function to respond to messages that you receive. Please

note the following: You can only reply to 2-way messages that you receive; you cannot reply to 1-way messages. The RECEIVE function can fill in most of the REPLY input parameter

list. The fields that RECEIVE does not fill in are IPBFADR2 (which

contains the address of the reply you are sending) and IPBFLN2/IPBFLN2F (which contains the length of the reply you are sending). The? format of the REPLY function is:

<a id="TBLTBLUNIQ70"></a>

[Table: lab lIUCV REPLY,PRMLIST={label|(reg)} [,ANSBUF={label|(reg)}] ,ANSLEN= label|(label,2)|(label,4)]

(reg)|((reg),2)|((reg),4)<br>[,MSGID={label|(reg)}]<br>[,PATHID={label|(reg)}]<br>[,PRTY={YES|NO}]<br>[,TRGCLS={label|(reg)}]<br>[,DATA={PRMMSG|BUFFER}]
