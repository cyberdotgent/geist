## 1\.1\.2 An Example

The example in [Figure 1](1-1-2.md#FIGINXMP) demonstrates the use of a DIAGNOSE code in a small Assembler program\. This example happens to use DIAGNOSE code X'00', which stores the VM/ESA extended identification code at a specified location in guest storage\.

<a id="FIGINXMP"></a>

```
     DIAG00   CSECT
     *This demonstrates the use of DIAGNOSE code X'00', which
     *stores the VM/ESA Identification Code at a specified address.
              BALR 12,0
              USING *,12
              LA   2,LOC                     STORAGE ADDRESS IN R2 (Rx)
              L    3,L'LOC'                  # BYTES TO BE STORED IN R3 (Ry)
              DC   X'83',X'23',XL2'0000'     PIECE TOGETHER THE DIAG. CODE
              BR   14
              DS   0D                        FORCE DOUBLEWORD BOUNDARY
     LOC      DS   XL64                      STORAGE LOCATION
              END
```

*Figure 1\. Example of a DIAGNOSE Code in an Assembler Program*

The DC \(Declare Constant\) line in this program is the actual DIAGNOSE code\.

where:

`X'83'` is the machine language operation code for the DIAGNOSE instruction\.

`X'23'` is the specification of the Rx/Ry general purpose register pair\. Here, Rx is 2 and Ry is 3\.

`XL2'0000'` is the base register and the displacement\. The base register \(0\) is the first halfbyte\. The remaining bits are the displacement, which \(for the DIAGNOSE instruction\) is the 3\-digit hexadecimal DIAGNOSE code \(000\)\.
