#### 2.4.10.2 Required Inputs for Sending Response Data From a Buffer

If you store the response data you are going to send in a buffer, rather than in your parameter list, you must do the following:

1. *Specify* *the* *address* *of* *the* *buffer*. Do this in one of the following ways: a. Use the ANSBUF=parameter. Specify the buffer as (1) the relocatable label of the buffer, or (2) the number of a register that contains the address of the buffer. b. Store the address of the buffer in the IPBFADR2 field of the REPLY parameter list.

**Note:** If you use the the ANSBUF=parameter, IUCV stores this value automatically.

2. Specify the length of the buffer. If you did not specify ANSLIST=YES, the ANSLEN=operand specifies the

length? of? the area specified on the ANSBUF parameter. If you did specify ANSLIST=YES, specify with the ANSLEN=operand the sum of the individual buffer lengths in the list pointed to by the ANSBUF=operand. Specify the answer buffer length in one of the following ways: a. Use the ANSLEN=parameter. Specify the length as (1) the relocatable label of the location containing the buffer length, or (2) the number of a register that contains the length of the buffer. IUCV assumes a halfword value for the length at the storage location specified, or in the low-order halfword of the register specified. If a length modifier of 4 is used, IUCV uses the fullword value for the length at the storage location or in the register specified. b. Store the length of the buffer in the IPBFLN2 field of the REPLY parameter list.

**Note:** If you use the ANSLEN=parameter, IUCV stores this value automatically.
