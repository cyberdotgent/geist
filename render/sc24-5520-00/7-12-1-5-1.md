#### 7\.12\.1\.5\.1 Parameter Lists Passed for Commands

<a id="HDRPARPC"></a>

For the AUTOLOG and XAUTOLOG commands, the following parameter list is passed:

`BYTE OFFSET`

`LABEL FIELD DEC(HEX) BYTES CONTENTS --------------------------------------------------------------------- ACIFCN Function 0(00) 1 ACILOG Request code`

`ACICODE Return code 1(01) 1 ACI sets this field to indicate completion of the request.`

`ACILEN Length of 2(02) 2 This field is set to the ACIPARMS total length of ACIPARMS in bytes.`

`ACIBMAPA ACI audit set- 4(04) 1 ACI bit settings are obtain- tings. Bits ed from the command entry 0-7 contain the for the command. audit setting for versions A-H, respectively.`

`ACIBMAPP ACI protect 5(05) 1 ACI bit settings are obtain- settings. Bits ed from the command entry 0-7 contain the for the command. protect settings for versions A-H, respectively.`

`ACIENV Type of event 6(06) 1 ACIXAC`

`ACIRGRP Requestor 8(08) 8 Blanks group name`

`ACIRUSR Requestor 16(10) 8 The user ID of the user who user ID is being automatically logged on`

`ACIFLAG Flag byte 68(44) 1 ACIGOOD`

`ACICMDTP Command ver- 69(45) 1 X'C0' sion that is being executed`

`ACIEVENT 72(48) AUTOLOG or XAUTOLOG`

`ACIDATA Additional 120(78) 8 Command line data`

The command processor initializes ACIPARMS to pass the following information to HCPRPW\.

For the LOGON command, the following parameter list is passed:

`BYTE OFFSET`

`LABEL FIELD DEC(HEX) BYTES CONTENTS --------------------------------------------------------------------- ACIFCN Function 0(00) 1 ACILOG request code`

`ACICODE Return code 1(01) 1 ACI sets this field to indicate completion of the request.`

`ACILEN Length of 2(02) 2 This field is set to the ACIPARMS total length of ACIPARMS in bytes.`

`ACIBMAPA ACI audit set- 4(04) 1 ACI bit settings are obtain- tings. Bits ed from the command entry 0-7 contain the for the command. audit setting for versions A-H, respectively.`

`ACIBMAPP ACI protect 5(05) 1 ACI bit settings are obtain- settings. Bits ed from the command entry 0-7 contain the for the command. protect settings for versions A-H, respectively.`

`ACIENV Type of Event 6(06) 1 ACIXAC`

`ACIRGRP Requestor 8(08) 8 Blanks group name`

`ACIRUSR Requestor 16(10) 8 The user ID of the user who user ID is being logged on`

`ACIFLAG Flag byte 68(44) 1 ACINOREC - on if this is not a reconnect ACIANY - unconditionally on`

`ACICMDTP Command ver- 69(45) 1 X'C0' sion that is being executed`

`ACIEVENT 72(48) LOGON`

`ACIDATA Additional 120(78) 8 Command line data`

**Note:** The ACNMDBK field is an unnamed, reserved space\.

<a id="HDRPWCC"></a>

*Return Codes*: The command processor for LOGON, AUTOLOG, and XAUTOLOG recognizes the following return codes: Any return code greater than X'16' is treated as X'08':

<a id="TBLTBLUNIQ213"></a>

```
    _________________ _____________________________________
   |   Return Code   | Status                              |
   |_________________|_____________________________________|
   |        0        | Request authorized                  |
   |_________________|_____________________________________|
   |        4        | Request not verified, deferred to   |
   |                 | CP                                  |
   |_________________|_____________________________________|
   |        8        | Request failed                      |
   |_________________|_____________________________________|
   |       12        | User forced off the system          |
   |_________________|_____________________________________|
   |       16        | Terminal error                      |
   |_________________|_____________________________________|
```
