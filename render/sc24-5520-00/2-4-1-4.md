#### 2\.4\.1\.4 ACCEPT Parameter List Input Fields

`IPPATHID` contains the path identification number of the path you are establishing\.

`IPFLAGS1` specifies options for the ACCEPT function\. IUCV treats each bit in IPFLAGS1 separately\. Make sure that bits you are not using to define input are set to 0\.

`IPPRTY flag (bit X'20')` indicates, when set to 1, that you want to establish a path which can handle priority communications\.

`IPQUSCE flag (bit X'40')` indicates, when set to 1, that you want to establish a quiescent path\.

`IPRMDATA flag (bit X'80')` indicates, when set to 1, that you are prepared to handle messages sent you using the DATA=PRMMSG parameter\.

`IPMSGLIM` contains the number of outstanding messages that IUCV allows on the path you are establishing\.

`IPUSER` contains the 16\-byte user data area IUCV reflects to the virtual machine with which you are establishing\.
