#### 2.4.2.1 CONNECT Required Input

1.? The address of the CONNECT parameter list. Use the PRMLIST=parameter

to identify to IUCV the address of your parameter list. The address of the parameter list must be a guest real address (an address that is real to your virtual machine), and it must be on a doubleword boundary. Specify the address of the parameter list as (a) a relocatable label, or (b) the number of a register that contains the address.:H4 2. *The* *user* *ID* *of* *the* *virtual* *machine* *to* *which* *you* *are* *establishing* *a* path*. S*pecify this value in one of the following ways: a. Use the USERID= parameter. Specify the user ID as (1) the relocatable label of the storage area containing the user ID, or (2) the number of a register that contains the address of the user ID. b. Store the user ID in the IPVMID field of the CONNECT parameter list.

**Note:** If you use the USERID=parameter, IUCV stores this value automatically.
