### 4.9.4.1 Shared Functions That Can Be Used in CMS

Shared Functions That Can Be Used in CMS The following two functions are documented in [Chapter 8, "APPCVM Macro](3-8.md) [Functions" in topic 3.8](3-8.md) and can be safely used in a CMS environment: ACCE**PT** When ACCEPT is issued to establish an APPC path: ACCEPT does not have a message limit parameter, whereas non-APPC ACCEPT does. This is because the message limit is always one on APPC/VM paths. ACCEPT does not have a user data field. QUER**Y** QUERY gives you the following information about a virtual machine: The size of the external interrupt buffer The maximum number of communication paths that can be established for the virtual machine. The maximum length of the interrupt buffer extension used in CMS and GCS.
