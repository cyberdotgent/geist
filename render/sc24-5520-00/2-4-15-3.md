#### 2\.4\.15\.3 SETMASK Parameter List Format

The format of the SETMASK parameter list is:

<a id="FIGFIGUNIQ81"></a>

```
      IPARML DSECT

      0      1        2         3         4         5         6       7
      _____________ ______________________________________________________ 
    0| IPMASK      |///////////////////////////////////////////////////// |
     |_____________|______________________________________________________|
    8| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   10| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   18| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   20| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
```
