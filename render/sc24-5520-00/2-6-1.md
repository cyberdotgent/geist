## 2.6.1 IUCV Function to Parameter Cross Reference

Figure 22 shows what IUCV parameters are associated with what IUCV [functions](2-6-1.md#AP1FIG1). Note that in the table of symbol meanings in [Figure 22](2-6-1.md#AP1FIG1), a blank means that the parameter is invalid for that function. If you specify an invalid parameter, IUCV generates an assembler macro error message and no code.

**Note:** While the PRMLIST parameter is the only parameter required for most

IUCV functions, most IUCV functions **do** **require** **input**. You can specify this input by (1) using one of the optional parameters or (2) storing data directly into the IUCV parameter list. For complete information on each IUCV function including required and optional inputs for the function, see [Chapter 4, "Inter-User Communication](2-4.md) [Vehicle Function Reference" in topic 2.4](2-4.md).
