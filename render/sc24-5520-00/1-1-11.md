## 1\.1\.11 Diagnose Code X'10'\-\-Release Pages

**Privilege Class:** Any

Use DIAGNOSE code X'10' to release pages of storage in your virtual machine\.

**Entry Values:**

Rx Contains the real address of the first page of storage to be released\. This address must be on a page boundary; otherwise a specification exception is recognized\.

Ry Contains the real address of the last page to be released\. This address must be on a page boundary\.

**Usage Notes:**

1\. The addresses contained in Rx and Ry must be on a page boundary\. A page boundary is a storage address whose low\-order three digits, expressed in hexadecimal, are zero\.

2\. Do not use DIAGNOSE code X'10' to release noncontiguous storage\.

3\. If a virtual machine attempts to release a shared page within its defined virtual storage, the page is not released\. No further action is taken\.

**Responses:**

You may receive one of the following program checks if the DIAGNOSE code X'10' input data is invalid:

```
    ___________________________ _____________________________________________
   | Problem                   |                                             |
   | Encountered               | Cause                                       |
   |___________________________|_____________________________________________|
   | Specification exception   | Any of the the following:                   |
   |                           |                                             |
   |                           | °   The address of the last page (specified |
   |                           |     in Ry) is less than the address of the  |
   |                           |     first page (specified in Rx).           |
   |                           |                                             |
   |                           | °   The virtual machine attempts to release |
   |                           |     page 0.                                 |
   |                           |                                             |
   |                           | °   The addresses contained in Rx and/or Ry |
   |                           |     are not on a page boundary (see Usage   |
   |                           |     Note 1 above).                          |
   |___________________________|_____________________________________________|
   | Addressing exception      | Any of the following:                       |

   |                           |     a page outside its defined virtual      |
   |                           |     storage.                                |
   |                           |                                             |
   |                           | °   The address of the last page (specified |
   |                           |     in Ry) is greater than the storage size |
   |                           |     defined for the virtual machine.        |
   |___________________________|_____________________________________________|
```
