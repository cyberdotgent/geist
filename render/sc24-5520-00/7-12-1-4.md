### 7\.12\.1\.4 HCPRPI

<a id="HDRHCPRPI"></a>

CP's stub, HCPRPI, contains seven entry points\. Five of these entry points comprise the skeleton for the \*RPI system service through which the ACI modules, HCPRPWEP and HCPRPIRA, can communicate with the ESM through IUCV\. These entry points, along with their respective assigned functions \(for example, message and resume\) are defined to CP's IUCV processing in an internal CP data area\. No calls are made from any CP code to these five entry points\.

The ESM may provide replacements of these entry points which contain the code that performs a connect to the ESM, as well as other IUCV services that are required\. For more information concerning IUCV, see [Chapter 3,](2-3.md) ["Using the Inter\-User Communication Vehicle" in topic 2\.3](2-3.md)\.

*Entry Points*: HCPRPI defines the following entry points to support an IUCV interface:

- **HCPRPICN**\-\-called when IUCV CONNECT is complete to \*RPI system service\. \(The stub modules call the CP module, HCPRPJCN, to issue an IUCV sever\.\)

`Input Registers: R1 - Address of input parameter list Output: Return code (IPRCODE) in the IUCV parameter list. Attributes: MP, dynamic Linkage: Call with a dynamic save area Register Usage: R12 - Base register R13 - Address of save work area R14 - Scratch R15 - Scratch`

- **HCPRPIIL**\-\-called for IUCV MESSAGE request\.

`Input Registers: R1 - Address of input parameter list Output: Return code (IPRCODE) in the IUCV parameter list. Attributes: MP, dynamic Linkage: Call with a dynamic save area Register Usage: R12 - Base register R13 - Address of save work area R14 - Scratch R15 - Scratch`

- **HCPRPISV**\-\-called for IUCV SEVER request\.

`Input Registers: R1 - Address of input parameter list Output: Return code (IPRCODE) in the IUCV parameter list. Attributes: MP, dynamic Linkage: Call with a dynamic save area Register Usage: R12 - Base register R13 - Address of save work area R14 - Scratch R15 - Scratch`

- **HCPRPIQS**\-\-called for IUCV QUIESCE request\.

`Input Registers: R1 - address of input parameter list Output: Return code (IPRCODE) in the IUCV parameter list. Attributes: MP, dynamic Linkage: Call with a dynamic save area Register Usage: R12 - Base register R13 - Address of save work area R14 - Scratch R15 - Scratch`

- **HCPRPIRM**\-\-called for IUCV RESUME request\.

`Input Registers: R1 - Address of input parameter list Output: Return code (IPRCODE) in the IUCV parameter list. Attributes: MP, dynamic Linkage: Call with a dynamic save area Register Usage: R12 - Base register R13 - Address of save work area R14 - Scratch R15 - Scratch`

**Note:** The above five entry points allow an ESM service machine to communicate, through IUCV, with ESM code in the CP nucleus\. This ESM\-supplied code becomes the \*RPI system service\.

- **HCPRPIID**\-\-HCPRPI defines the following entry point as a data area to indicate whether the ESM is installed\.

This is a nonexecutable entry point\. CP's stub contains 16 bytes of X'00's'\. The ESM may overlay these 16 bytes with a nonzero value to indicate that it is installed\. DIAGNOSE code X'A0', subcode X'08', checks this data to determine whether the ESM is installed\.

HCPRPI defines the following entry point to support audit and protect requests from CP to the ESM\.

- **HCPRPIRA**\-\-process audit and/or protect requests to the ESM for CP commands, DIAGNOSE codes, and security\-relevant system functions\.

`Input Registers: R1 - Address of input parameter list Output Registers: R1 - ACIPARMS address (return code in ACICODE field). See` ["Return Codes" in topic 7\.12\.1\.5\.7](7-12-1-5-7.md)`.) Attributes: MP, dynamic Linkage: Call with a dynamic save area Register Usage: R12 - Base register R13 - Address of save work area R14 - Scratch R15 - Scratch`

**Information Passed:** The appropriate command or diagnose processor or router initializes ACIPARMS to pass information to HCPRPI\. The information differs for several commands, but a majority of CP commands pass the information described in ["The ACIPARMS Control](7-12-1-3.md) [Block" in topic 7\.12\.1\.3](7-12-1-3.md)\. For the rest of the CP commands, information is passed as described in ["Parameter Lists Passed for](7-12-1-5-1.md) [Commands" in topic 7\.12\.1\.5\.1](7-12-1-5-1.md)\.

HCPRPIRA is called whenever a command, DIAGNOSE code, or one of the security\-relevant system functions is issued, and an audit or protect bit is indicated for that event\.

CP's stub module returns a code of ACIDEFR in ACICODE\.

The ESM replacement module is expected to receive the input parameters in ACIPARMS, to pass the audit and/or protect request to the ESM through the IUCV services provided by the other entry points in HCPRPI, and to send the ESM's response back to the caller in the ACICODE field\.

Return is made to the calling module by the HCPEXIT [\(30\)](<#FTNEXITR>) macro, located in the HCPPSI macro library\.

Return Codes: The ACICODE field contains the return code\. See ["Return Codes" in topic 7\.12\.1\.5\.7](7-12-1-5-7.md)\.

<a id="FTNEXITR"></a>

\(30\) The EXIT macro is coded as:

HCPEXIT EP=\(HCPRPI*xx*\) Return to Caller

\(where *xx* contains the last two letters of the entrypoint\)

and may be invoked by simply coding "EXIT" in your Assembler program as an Assembler statement\.
