## 2.3.6 Enabling IUCV

<a id="HDRIUCVS1"></a>

To enable IUCV, your program must do the following: 1. Use the QUERY function to determine how large your external interrupt buffer needs to be. In response to the QUERY function, CP returns in register 0 the size of the external interrupt buffer you need to declare (size is expressed as a number of bytes). CP returns in register 1 the maximum number of paths your virtual machine can have. 2. Use the facilities of the operating system you run to obtain free storage for your external interrupt buffer. As just mentioned, in response to the QUERY function, CP returns in register 0 the size of the external interrupt buffer you need to declare. 3. Use the DCLBFR function to specify the address of your external interrupt buffer (the address of the free storage you obtain). 4. Enable your virtual machine to handle external interrupts. To do this, you must: a. Set bit 30 to 1 in control register zero. b. Set the external interrupt bit (normally bit 7 in the PSW) to 1. **Note:** Your IUCV program must run in the supervisor state.
