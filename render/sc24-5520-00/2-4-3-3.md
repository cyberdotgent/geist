#### 2\.4\.3\.3 DCLBFR Parameter List Format

The format of the DCLBFR parameter list is:

<a id="FIGFIGUNIQ57"></a>

```
      IPARML DSECT

      0      1        2         3         4         5         6       7
      ____________ ___________ _________ _________________________________ 
    0| ///////////| IPFLAGS1  | IPRCODE | /////////////////////////////// |
     |____________|___________|_________|_________________________________|
    8| /////////////////////////////////|         IPBFADR1                |
     |__________________________________|_________________________________|
   10| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   18| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   20| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
```
