### E\.1 RDEVFTR\-\-Real Device Features

If device class is TERMINAL:

`X'01' = DIAL FEATURE`

If device class is GRAPHICS:

`X'80' = OPERATOR ID CARD READER`

If device class is UNIT RECORD OUTPUT:

`X'01' = UCS FEATURE`

If device class is MAGNETIC TAPE:

`X'80' = 7-TRACK FEATURE X'40' = DUAL DENSITY FEATURE X'20' = TRANSLATE FEATURE X'10' = DATA CONVERSION FEATURE X'08' = 3480 DATA COMPACTION FEATURE`

If device class is DIRECT ACCESS STORAGE:

`X'80' = ROTATIONAL POSITIONAL SENSING X'20' = TOP HALF OF 2314 USED AS 2311 X'10' = BOTTOM HALF OF 2314 USED AS 2311 X'08' = 35 MB DATA MODULE MOUNTED (3340) X'04' = 70 MB DATA MODULE MOUNTED (3340) X'02' = RESERVE/RELEASE ARE VALID CCW OP CODES`

If device class is SPECIAL:

`X'10' = TYPE ONE CHANNEL ADAPTER (3704/5) X'20' = TYPE TWO CHANNEL ADAPTER (370X) X'40' = CTCA IS TYPE 3088`
