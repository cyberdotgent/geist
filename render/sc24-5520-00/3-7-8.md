## 3.7.8 State Table for APPC/VM Functions

<a id="HDRAPPCVMS"></a>

The basic states for APPC/VM assembler programs are: Reset The state for each program before communications begin and after communications end Connect The state for a source program after a connection has been started but before it has completed, or the state for a target program after it has received a connection pending interrupt but before it has accepted Send The state in which a program is allowed to send data Receive The state in which a program is ready to receive data Confirm The state in which a program must respond to its communications partner Sever The state a program is in when its partner stops communications These APPC/VM states are based on the states that APPC defines, but there are two differences: 1. The Connect state is unique to APPC/VM 2. The Sever state is analogous to the APPC Deallocate state.
