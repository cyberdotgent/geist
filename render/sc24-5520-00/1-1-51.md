## 1\.1\.51 Diagnose Code X'F8'\-\-Spool File Origin Information

<a id="TBLTBLUNIQ49"></a>

```text
   Privilege Class:  Any
   Use DIAGNOSE code X'F8' to have your virtual machine associate the
   originating node and the user ID information with a virtual output device,
   or retrieve the stored information for one of your virtual machine's spool
   files.
   Subfunctions:
   °   Use subfunction code X'00' for the privileged subfunction to associate
       originating node and user ID with a virtual output device.  This can
       be done only if you are authorized with the SETORIG operand on the
       OPTION control statement in your virtual machine's directory entry.
   °   Use subfunction code X'01' for the general user function to retrieve
       the stored originating node and user ID information for a spool file.
   Entry Values:
   Rx     Contains the subfunction code.
   Ry     Contains the guest real address of the doubleword-aligned parameter
          list, DF8PARM.  DF8PARM COPY may be found in the HCPGPI macro
          library.  The parameter list is used differently for each
          subfunction code.
   The DF8PARM parameter list for subfunction X'00' is as follows:
            DF8PARM DSECT
         ___________________ ___________________
    0   |  DF8VCODE         |  DF8DVNUM         |
        |___________________|___________________|
    4   |  DF8ONODE                             |
        |                                       |
    8   |                                       |
        |                                       |
        |_______________________________________|
    C   |  DF8OUSER                             |
        |                                       |
   10   |                                       |
        |                                       |
        |_______________________________________|
   DF8VCODE
       is reserved for IBM use.  It must be binary zeros.
   DF8DVNUM
       is the output unit record device number (in hexadecimal).
   DF8ONODE
       is the originating node for the spool file creation (in EBCDIC).  This
       is left-justified and padded on the right with blanks.
   DF8OUSER
       is the originating user ID for the spool file created (in EBCDIC).
       This is left-justified and padded on the right with blanks.
   The DF8PARM parameter list for subfunction X'01' is as follows:
            DF8PARM DSECT
         ___________________ ___________________
    0   |  DF8VCODE         |  DF8SPID          |
        |___________________|___________________|
    4   |  DF8ONODE                             |
        |                                       |
    8   |                                       |
        |                                       |
        |_______________________________________|
    C   |  DF8OUSER                             |
        |                                       |
   10   |                                       |
        |                                       |
        |_______________________________________|
   DF8VCODE
       is reserved for IBM use (must be binary zeros).
   DF8SPID
       is the spool file ID for which the originating node and the user ID
       information is retrieved (in hexadecimal).
   DF8ONODE
       is the originating node for the spool file (to be filled in by CP).
       This is left-justified and padded on the right with blanks.
   DF8OUSER
       is the originating user ID for the spool file (to be filled in by CP).
       This is left-justified and padded on the right with blanks.
   Exit Values:
   Rx     On return, Rx contains the return code for the subfunction.
   Return codes for subfunction X'00':
   Return
   Code    Meaning
   0       Successful completion; the originating node and user ID
           information has been associated with the virtual output device.
   8       Device not found
   12      The device is not a unit record output device.
   Return codes for subfunction X'01':
   Return
   Code    Meaning
   0       Successful completion; the originating node and user ID
           information has been stored in the parameter list.
   4       The originating node and user ID information was not stored for
           this file; DF8OUSER contains the user ID of the originator of the
           spool file on this node.
   Return
   Code    Meaning
   8       Spool file not found
   16      Fatal paging I/O error
   Usage Notes:
   1.  If subfunction X'00' is issued for a virtual output device, all files
       generated on that output device contain the originating node and user
       ID information.  In order to change the originating node and user ID
       information for a virtual output device, subfunction X'00' must be
       issued again.  In order to clear the originating node and user ID
       information, subfunction X'00' must be issued again for the virtual
       output device, specifying blanks for the originating information.
   2.  When subfunction X'00' is issued for a virtual output device, the
       originating node and user ID information is stored with the next file
       to be opened on that device.  If there is an open file on the device
       when subfunction X'00' is issued, that file does not contain the
       originating node and user ID information specified on the DIAGNOSE
       issued after the file is opened.  You must issue subfunction X'00',
       then open the file on the specified device.
   Errors:
   You may receive one of the following program checks if the DIAGNOSE code
   X'F8' input data is invalid:
    _________________________ _______________________________________________
   | Problem                 |                                               |
   | Encountered             | Cause                                         |
   |_________________________|_______________________________________________|
   | Addressing exception    | The parameter list is not within addressable  |
   |                         | guest real storage.                           |
   |_________________________|_______________________________________________|
   | Protection exception    | Any of the following:                         |
   |                         |                                               |
   |                         | °   The parameter list is fetch-protected.    |
   |                         | °   The parameter list for subfunction code   |
   |                         |     X'01' is store-protected.                 |
   |_________________________|_______________________________________________|
   | Specification exception | Any of the following:                         |
   |                         |                                               |
   |                         | °   The subfunction code is not defined.      |
   |                         | °   The parameter list is not                 |
   |                         |     doubleword-aligned.                       |
   |                         | °   The DF8VCODE is invalid.                  |
   |                         | °   The issuer of the privileged subfunction  |
   |                         |     code X'00' is not authorized in the CP    |
   |                         |     directory.                                |
   |_________________________|_______________________________________________|
```
