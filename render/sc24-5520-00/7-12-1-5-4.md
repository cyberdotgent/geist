## 7.12.1.5.4 Auditing Communication Among Virtual Machines

<a id="HDRSPOOL"></a>

#### Auditing Communication Among Virtual Machines

```text
   VM/ESA must be able to audit events that permit, accomplish, or terminate
   communication among virtual machines.  These events include:

   ° Enabling a communication path (COUPLE, CONNECT, LINK)
   ° Disabling a communication path (DETACH, SEVER)
   ° Transmitting discrete data objects (MSG, VMCF, SPOOL).

   ° The following sections show SPOOL ACIPARMS, CONNECT, SEVER, and VMCF
```

enhancements.
