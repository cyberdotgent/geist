#### 2.4.13.5 Required Inputs for 2-Way Messages with Data in a Buffer

If you are sending a 2-way message with data in the buffer, you must do the following:/

1. *Specify* *the* *address* *of* *your* *reply* *area* *(the* *location* *where* *IUCV* *stores* repl*ies to* y*ou*r *mes*s*ages). D*o this in one of the following ways: a. Use the ANSBUF=parameter. Specify the address of the reply area as (1) the relocatable label of the buffer, or (2) the number of a register that contains the address of the buffer. b. Store the address of the reply area in the IPBFADR2 field of the SEND parameter list.

**Note:** If you use the ANSBUF=parameter, IUCV stores this value automatically.)

2. *Specify* *the* *length* *of* *your* *reply* *area*. If you did not specify ANSLIST=YES, ANSLEN= specifies the length of the area specified on the ANSBUF parameter. If you did specify ANSLIST=YES, specify with ANSLEN= the sum of the individual buffer lengths in the list pointed to by ANSBUF=. Specify the answer buffer length in one of the following ways: a. Use the ANSLEN=parameter. Specify the length as (1) the relocatable label of the location containing the buffer length, or (2) the number of a register that contains the length of the buffer. IUCV assumes a halfword value for the length at the storage location specified, or in the low-order halfword of the register specified. If a length modifier of 4 is used, IUCV uses the fullword value for the length at the storage location or in the register specified. b. Store the address of the reply area in the IPBFLN2 field of the SEND parameter list. (The ANSLEN=parameter does this automatically.)
