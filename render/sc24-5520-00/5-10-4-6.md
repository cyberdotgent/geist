## 5.10.4.6 ACCEPT Condition Codes and Return Codes

<a id="HDRIUACCRC"></a>

#### ACCEPT Condition Codes and Return Codes

<a id="TBLTBLUNIQ160"></a>

| CC=0 | CC=1<br>Not Possible | CC=2<br>X |
| --- | --- | --- |


**CC=1** an error occurred. The output parameter list is the same as the ACCEPT input parameter list, except one of the following return codes is stored in IPRCODE (byte 3):

<a id="TBLTBLUNIQ161"></a>

| Code | Code | Why the Error OccurredX'01' |
| --- | --- | --- |


**CC=2** accept is complete. The format of the output parameter list is as shown in Figure 60.

<a id="ACCOPL"></a>

```text
    ________________________________________________________________ 
   |________________________________________________________________|
   |________________________________________________________________|
   |________________________________________________________________|
   |________________________________________________________________|
   |______________________________________________________________________________|
```

IPPATHID is the path ID on which the connection was accepted. IPSTATE contains the current state for this path, which may have one of the following values: IPRE [CVST (X'04](5-10-4-6.md#ACCOPL)') the path is in the Receive state. IPBKREQ (X'0E') the path is in the Backout_Required state.
