## 5.10.4.6 ACCEPT Condition Codes and Return Codes

<a id="HDRIUACCRC"></a>

#### ACCEPT Condition Codes and Return Codes

<a id="TBLTBLUNIQ160"></a>

| CC=0 | CC=1 | CC=2 |
| --- | --- | --- |
| Not Possible | X | X |


**CC=1** an error occurred. The output parameter list is the same as the ACCEPT input parameter list, except one of the following return codes is stored in IPRCODE (byte 3):

<a id="TBLTBLUNIQ161"></a>

| Code | Code | Why the Error OccurredX'01' |
| --- | --- | --- |


**CC=2** accept is complete. The format of the output parameter list is as [FIGACCOPL](#FIGACCOPL) shown in Figure 60.

<a id="ACCOPL IPARML DSECT 0 1 2 3 4 5 6 7 0 IPPATHID ////////////////////////////////////////////// 8 ////////////////////////////////////////////////////////////// 10 ////////////////////////////////////////////////////////////// 18 ////////////////////////////////////////////////////////////// 20 ////////////////////////////////////// IPSTATE //////////// Figure 60. IUCV ACCEPT Output Parameter List"></a>

IPPATHID is the path ID on which the connection was accepted. IPSTATE contains the current state for this path, which may have one of the following values: IPRECVST (X'04') the path is in the Receive state. IPBKREQ (X'0E') the path is in the Backout_Required state.
