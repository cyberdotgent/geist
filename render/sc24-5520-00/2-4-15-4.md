#### 2.4.15.4 SETMASK Parameter List Input Fields

IPMASK contains the mask that specifies which, if any, of the IUCV interrupts your virtual machine is enabled for. The bits in the mask byte have been described previously under ["SETMASK Required Input" in](2-4-15-1.md) [topic 2.4.15.1](2-4-15-1.md).
