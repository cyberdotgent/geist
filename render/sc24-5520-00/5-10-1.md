## 5\.10\.1 Shared Functions That Can Be Used in CMS

The following table summarizes each IUCV macro function that can be used in CMS, then points to the section that describes each function in detail\.

<a id="TBLTBLUNIQ157"></a>

```
    ______________ _______________________________________________ __________
   | Function     | Description                                   | Topic    |
   |______________|_______________________________________________|__________|
   | ACCEPT       | Accepts the connection from a requesting      | 5.10.4   |
   |              | program to complete a path.                   |          |
   |______________|_______________________________________________|__________|
   | CONNECT      | Establishes and reserves a path for resource  | 5.10.5   |
   |              | manager programs to communicate with *IDENT.  |          |
   |______________|_______________________________________________|__________|
   | QUERY        | Gets information about the external interrupt | 5.10.8   |
   |              | buffer and finds out how many paths can be    |          |
   |              | established.                                  |          |
   |______________|_______________________________________________|__________|
   | SEVER        | Ends communications with another program when | 5.10.12  |
   |              | APPCVM SEVER is not appropriate.              |          |
   |______________|_______________________________________________|__________|
```

*VM/ESA CMS Application Development Reference for Assembler* contains more information about how to use IUCV macro functions when writing programs\.
