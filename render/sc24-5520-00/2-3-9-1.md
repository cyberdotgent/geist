#### 2.3.9.1 Temporarily Suspending Communications Over an IUCV Path

Use the QUIESCE function to temporarily suspend communication over a path. When you "quiesce" a path, IUCV reflects an interrupt to the virtual machine at the other end of the path, informing it that the path was quiesced. When you quiesce a path, you cannot receive messages over it; you can, however, continue to send messages over a quiescent path. Use the RESUME function to reactivate a path that you have previously "quiesced." IUCV reflects an interrupt to the virtual machine at the other end of the path, informing it that the path has been reactivated.
