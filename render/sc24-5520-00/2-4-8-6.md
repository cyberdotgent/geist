#### 2\.4\.8\.6 RECEIVE Parameter List Output Fields

`IPPATHID` contains the path identification number of the message you are attempting to receive\.

`IPFLAGS1` specifies values that IUCV returns for the RECEIVE function\.

`IPFGMCL flag (bit X'01')` indicates, when set to 1, that there is more information to receive\. IUCV sets this bit so that the resulting parameter list is valid for a subsequent RECEIVE\.

`IPFGPID flag (bit X'02')` indicates, when set to 1, that there is more information to receive\. IUCV sets this bit so that the resulting parameter list is valid for a subsequent RECEIVE\.

`IPFGMID flag (bit X'04')` indicates, when set to 1, that there is more information to receive\. IUCV sets this bit so that the resulting parameter list is valid for a subsequent RECEIVE\.

`IPNORPY flag (bit X'10')` indicates, when set to 1, that the message you receive is a 1\-way message\.

`IPPRTY flag (bit X'20')` indicates that the message you receive is a priority message\.

`IPRMDATA flag (bit X'80')` indicates, when set to 1, that the message you receive was contained in a parameter list, rather than a buffer\.

`IPRCODE` contains one of the following return codes:

**Code Meaning**

00 Normal return

01 You specified an invalid path identification number\.

05 Your storage buffer is too small to contain the message you are receiving\.

06 Fetch protection exception on the send buffer

**Code Meaning**

07 Addressing exception on the send buffer

08 The message class or path identification number you specified does not correspond to the message identification number you specified\.

09 IUCV has purged the message\.

10 You specified a negative message length\.

22 Negative SEND buffer length in list

23 Negative RECEIVE buffer length in list

24 Incorrect total length of buffer list lengths

26 The buffer list is not on a doubleword boundary\.

30 The IPAPPCSN flag in IPFLAGS1 is not zero\.

31 An IUCV function was specified on an APPC/VM path\.

`IPMSGID` contains the message identification number of the message you receive\.

`IPTRGCLS` contains the target message class of the message you receive\.

`IPBFADR1` contains the address of the buffer into which IUCV places data you receive **added to** the number of bytes of data you receive\.

`IPBFLN1/IPBFLN1F` contain one of the following values:

- If the buffer was exactly the correct length, IUCV stores a zero in this field\.
- If the buffer was too long, IUCV stores the number of bytes in this field remaining in the buffer\.
- If the buffer was too short, IUCV stores a residual count in this field \(that is, the number of bytes remaining in the message that would not fit into the buffer\)\. IUCV also sets a nonzero return code\.

`IPBFLN2/IPBFLN2F` contain the length of the area into which IUCV places the information you receive\.

`IPRMMSG1/IPRMMSG2` contain message data that was sent to you from a parameter list, rather than from a buffer\. You can specify IPRMMSG to refer to the combined IPRMMSG1 and IPRMMSG2 fields\.
