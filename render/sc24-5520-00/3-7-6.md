## 3.7.6 Condition Codes and Return Codes

APPCVM macros generate four condition codes and four return codes. This section first gives a summary of the conditions under which each of the four return codes are generated followed by a description of each condition code and return codes that APPCVM macro functions generate. See the individual APPCVM macro details for the specific condition codes and return codes generated by each macro. [Table 47](#TBLYESTAB) summarizes the conditions under which each of the four return code fields listed along the top of the table applies. In the figure, an X indicates that the field applies for the corresponding condition code.

<a id="YESTAB"></a>

Table 47. Applicable Codes Based on CC=

| Condition | Code | IPRCODE IPAUDIT IPCODE |
| --- | --- | --- |
| IPWHATRC | 0 | X X |
| X |  | 2 |
| 3 |  | X |


**Note:** For CC=0; IPAUDIT, IPCODE, and IPWHATRC are meaningful in the

**function** **complete** **interrupt**. (The interrupt signals the completion of the function that started with CC=0.) For CC=**1,** 2**, or** 3**;** I**PR**C**O**DE, IPAUDIT, IPCODE, and IPWHATRC are meaningful in the output **parame**t**er list f**o**r th**e function you issued.
