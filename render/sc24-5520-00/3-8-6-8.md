#### 3\.8\.6\.8 SENDDATA Program Exceptions

The program exceptions for SENDDATA are:

<a id="TBLTBLUNIQ137"></a>

```
    ________________ ________________________________________________________
   | Type           | Description                                            |
   |________________|________________________________________________________|
   | Addressing     | The parameter list address is outside of the virtual   |
   |                | machine.  An addressing exception also occurs for any  |
   |                | of the following:                                      |
   |                |                                                        |
   |                | °   An invalid buffer address in SENDDATA's parameter  |
   |                |     list                                               |
   |                | °   An invalid buffer list address in SENDDATA's       |
   |                |     parameter list                                     |
   |                | °   An invalid buffer address in SENDDATA's buffer     |
   |                |     list.                                              |
   |                |                                                        |
   |                | This only applies if your partner had a receive area   |
   |                | defined when you sent the data.  (Answer areas are     |
   |                | always predefined.)                                    |
   |________________|________________________________________________________|
   | Operation      | Either an external interrupt buffer was not declared,  |
   |                | or the invoking virtual machine is not in the          |
   |                | supervisor state.                                      |
   |________________|________________________________________________________|
   | Protection     | The storage key of the parameter list address does not |
   |                | match the key of the user.  A protection exception     |
   |                | also occurs for any of the following:                  |
   |                |                                                        |
   |                | °   An invalid buffer address in SENDDATA's parameter  |
   |                |     list                                               |
   |                | °   An invalid buffer list address in SENDDATA's       |
   |                |     parameter list                                     |
   |                | °   An invalid buffer address in SENDDATA's buffer     |
   |                |     list.                                              |
   |                |                                                        |
   |                | This only applies if your partner had a receive area   |
   |                | defined when you sent the data.  (Answer areas are     |
   |                | always predefined.)                                    |
   |________________|________________________________________________________|
   | Specification  | The parameter list is not on a doubleword boundary.    |
   |________________|________________________________________________________|
```
