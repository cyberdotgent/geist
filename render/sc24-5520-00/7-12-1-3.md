## 7.12.1.3 The ACIPARMS Control Block

<a id="HDRACIPARM"></a>

CP and the ESM use a parameter list called ACIPARMS to communicate with each other about security-relevant events. An event may be a CP command, a DIAGNOSE code, or one of the predefined security-relevant system functions, for example, IUCV Connect. Each time one of these events occurs, if auditing or protection is indicated for that event, then CP creates a new ACIPARMS parameter list and calls the ESM through HCPRPIRA using an audit and/or protect request. The general format of the ACIPARMS parameter list for audit calls is shown in [Table 57](#TBLGFACB).
