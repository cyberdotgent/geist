## 1.1.41 Diagnose Code X'B8'--Spool File External Attribute Buffer Manipulation

**Privilege** **Class:** Any Use DIAGNOSE code X'B8' to read, write, or erase the external attribute buffer (XAB) [(3)](#FTNB8XAB) of a spool file on the printer queue, or to read the XAB of a file on the reader queue. It also can be used to set user HOLD status or user NOHOLD status. **Entry** **Values:**
