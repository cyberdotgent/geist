## 1\.1\.41 Diagnose Code X'B8'\-\-Spool File External Attribute Buffer Manipulation

**Privilege Class:** Any

Use DIAGNOSE code X'B8' to read, write, or erase the external attribute buffer \(XAB\) [\(3\)](<#FTNB8XAB>) of a spool file on the printer queue, or to read the XAB of a file on the reader queue\. It also can be used to set user HOLD status or user NOHOLD status\.

**Entry Values:**

<a id="TBLTBLUNIQ37"></a>

```
    _________________________ _______________________________________________
   | Rx, bytes 0 through 3:  | The buffer address                            |
   |_________________________|_______________________________________________|
   | Ry, bytes 0 through 1:  | The length of the buffer in bytes (0=ERASE)   |
   |_________________________|_______________________________________________|
   | Ry, bytes 2 through 3:  | The spool file ID                             |
   |_________________________|_______________________________________________|
   | Ry+1, byte 1:           | Flags (see Table 31)                          |
   |_________________________|_______________________________________________|
   | Ry+1, bytes 2 through   | Subcode X'0000' (READ) or X'0004'             |
   | 3:                      | (WRITE/ERASE)                                 |
   |_________________________|_______________________________________________|
```

[Table 31](<#TBLRCEV>) shows the meanings of the user HOLD flags\.

<a id="TBLRCEV"></a>

```
    _________________________________________________________________________
   | Table 31. DIAGNOSE Code X'B8' Meaning for Flags                         |
   |__________ ______________________________________________________________|
   | Flag     | Meaning                                                      |
   |__________|______________________________________________________________|
   | X'00'    | Do not change the user HOLD status                           |
   |__________|______________________________________________________________|
   | X'01'    | Place the spool file in user HOLD status                     |
   |__________|______________________________________________________________|
   | X'02'    | Place the spool file in user NOHOLD status                   |
   |__________|______________________________________________________________|
   | X'04'    | Look for the spool file on the reader queue                  |
   |__________|______________________________________________________________|
```

**Exit Values:**

`READ - Subcode X'0000'` CC=0\-\-Successful

<a id="TBLTBLUNIQ38"></a>

```
    _________________________ _______________________________________________
   | Ry, bytes 0 through 1   | The length of the XAB Read, 0 if there is no  |
   |                         | XAB                                           |
   |_________________________|_______________________________________________|
   | Ry+1, byte 0            | X'00' or X'04'                                |
   |_________________________|_______________________________________________|
```

`READ - Subcode X'0000'` CC=2\-\-Unsuccessful

<a id="TBLTBLUNIQ39"></a>

```
    _________________________ _______________________________________________
   | Ry, bytes 0 through 1   | The length of the XAB if it is too large for  |
   |                         | the buffer                                    |
   |_________________________|_______________________________________________|
   | Ry+1, byte 0            | The return code, see Table 32.                |
   |_________________________|_______________________________________________|
```

`WRITE/ERASE - Subcode X'0004'` CC=0\-\-Successful

<a id="TBLTBLUNIQ40"></a>

```
    _________________________ _______________________________________________
   | Ry+1, byte 0            | X'00'                                         |
   |_________________________|_______________________________________________|
```

`WRITE/ERASE - Subcode X'0004'` CC=2\-\-Unsuccessful

<a id="TBLTBLUNIQ41"></a>

```
    _________________________ _______________________________________________
   | Ry+1, byte 0            | Return code, see Table 32.                    |
   |_________________________|_______________________________________________|
```

**Responses:**

*Exit Normal:* A normal exit condition is a condition code of 0, indicating that the reading, writing, or erasing of the XAB of a spool file on the printer queue \(or the reading of the XAB of a file on the reader queue\) was successful\.

*Exit Error:* An error exit condition is a condition code of 2, indicating that the reading, writing, or erasing of the XAB of a spool file on the printer queue \(or the reading of the XAB of a spool file on the reader queue\) was unsuccessful\. The return code is shown in [Table 32](<#TBLB8ERR>)\.

<a id="TBLB8ERR"></a>

```
    _________________________________________________________________________
   | Table 32. DIAGNOSE Code X'B8' Meaning for Return Codes in Ry+1          |
   |_________________ _______________________________________________________|
   | Return Code     |                                                       |
   | in Ry+1         | Meaning                                               |
   |_________________|_______________________________________________________|
   | X'04'           | The spool ID is invalid or does not exist.            |
   |_________________|_______________________________________________________|
   | X'08'           | The length of the XAB buffer is greater than the user |
   |                 | buffer. (4)                                           |
   |_________________|_______________________________________________________|
   | X'0C'           | The user buffer length is invalid.                    |
   |_________________|_______________________________________________________|
   | X'14'           | CP I/O error                                          |
   |_________________|_______________________________________________________|
   | X'18'           | The specified process flag is invalid.                |
   |_________________|_______________________________________________________|
   | X'1C'           | Invalid subcode                                       |
   |_________________|_______________________________________________________|
   | X'20'           | The user buffer address is invalid.                   |
   |_________________|_______________________________________________________|
   | X'24'           | Not used                                              |
   |_________________|_______________________________________________________|
   | X'28'           | No XAB is to be erased (returned for WRITE/ERASE,     |
   |                 | subcode X'0004', only).                               |
   |_________________|_______________________________________________________|
   | X'2C'           | The XAB is not available because the file is marked   |
   |                 | for purge or has been converted.                      |

   | Table 33. Program Checks Encountered for Invalid Input to DIAGNOSE      |

   | Problem Encountered            | Cause                                  |
   |________________________________|________________________________________|
   | Protection exception           | For subcode X'0000', the buffer is in  |
   |                                | write-protected storage.               |
   |                                |                                        |
   |                                | For subcode X'0004', the buffer is in  |
   |                                | fetch-protected storage.               |
   |________________________________|________________________________________|
   | Specification exception        | Ry = R15                               |
   |________________________________|________________________________________|

   |________________________________|________________________________________|
```

<a id="FTNB8XAB"></a>

\(3\) The external attribute buffer \(XAB\) is a control block that contains data the user creates to specify additional information about a print file\. Each print file has its own XAB, and CP has the facilities to maintain the XABs\. For more information on the XAB, refer to [Appendix D, "External](d-0.md) [Attribute Buffer \(XAB\)" in topic D\.0](d-0.md)\.

<a id="FTNRCX08"></a>

\(4\) Any special processing requested by the flag byte is completed\.
