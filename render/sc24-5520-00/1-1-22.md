## 1.1.22 Diagnose Code X'54'--Control the Function of the PA2 Function Key

**Privilege** **Class:** Any Use DIAGNOSE code X'54' to control the function of the PA2 function key.

You can use the PA2 key to simulate an external interrupt to a virtual machine or to clear the output area of a display screen.

**Entry** **Values:** Rx Contains a value that controls the function of the PA2 key. If Rx

contains a nonzero value, the PA2 key simulates an external interrupt to the virtual machine. If Rx contains a zero, the PA2 key clears the output area of the display screen. Ry Not used. **Usage** **Note:** The external interrupt is simulated only when the display screen is in the VM READ, HOLD, or MORE status and the CP TERMINAL APL ON command has been issued. **Responses:** None.
