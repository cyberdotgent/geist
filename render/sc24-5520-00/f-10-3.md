#### F\.10\.3 Abend Conditions

The parameter check conditions follow:

<a id="TBLTBLUNIQ237"></a>

```
    __________________________________________________________ ______________
   | Parameter Check Condition                                | IPRCODE      |
   |__________________________________________________________|______________|
   | Invalid resource ID                                      | X'01'        |
   |__________________________________________________________|______________|
```

The state check conditions follow:

<a id="TBLTBLUNIQ238"></a>

```
    __________________________________________________________ ______________
   | State Check Condition                                    | IPRCODE      |
   |__________________________________________________________|______________|
   | Conversation not in Send or Receive state                | X'20',       |
   |                                                          | X'23',       |
   |                                                          | X'24',       |
   |                                                          | X'44'-X'4C'  |
   |__________________________________________________________|______________|
   | Conversation started but did not finish sending a        | X'2C' (33)   |
   | logical record                                           |              |
   |__________________________________________________________|______________|
```

<a id="FTNRWFOOT"></a>

\(33\) This condition could also be reported in IPAUDIT by the IPADITRN flag\.
