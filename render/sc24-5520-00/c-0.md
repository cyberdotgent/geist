# C.0 Appendix C.  the MONWRITE Program

<a id="HDRMWF"></a>

MONWRITE is an IBM-supplied program that can serve as the application program required for retrieving monitor data from the monitor saved segment. MONWRITE runs in a virtual machine and is implemented in a CMS module which can be invoked by the MONWRITE command. MONWRITE will: Load the monitor saved segment into its virtual storage. Establish appropriate IUCV communication links with the *MONITOR system service. It connects to *MONITOR in shar**ed mod**e, that is, more than one virtual machine running MONWRITE can connect to *MONITOR at one time. Access the saved segment and retrieve its data. Write the monitor data into a file on a CMS disk or on a tape. An application program can then later read the records from the file and perform data reduction on the performance data found in the records. For a full description of the MONWRITE command, see VM/ESA CP Command and Utility Reference. Refer to VM/ESA CP Planning and Administration for general information on the virtual machine and for a sample of directory entries that a virtual machine running MONWRITE would need.
