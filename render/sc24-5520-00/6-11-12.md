## 6.11.12 *RPI System Service

<a id="HDRRACF"></a>

The access verification (*RPI) system service allows CP to communicate with the Resource Access Control Facility (RACF) service virtual machine if RACF is installed. The *RPI system service is available only if an access control interface program, such as RACF, is installed in the system. When a virtual machine issues an IUCV RESUME to *RPI, for example, HCPRPIRM is invoked. The customer or the external security manager (ESM), such as RACF, may supply the code for HCPRPIRM, and this code determines the parameters passed in IPARML, the IUCV parameter list. For more information on the Access Control Interface to which any external security manager (ESM) may attach, see [Chapter 12, "Using CP's Access](7-12.md) [HDRACI](7-12.md) Control Interface" in topic 7.12 and ["HCPRPI" in topic 7.12.1.4](7-12-1-4.md). For more information on RACF, see Resource Access Control Facility: General Information Manual, GC28-0722.
