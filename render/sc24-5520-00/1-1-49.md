## 1.1.49 Diagnose Code X'E4'--Return Minidisk Real Device Information and Define a Full Pack Overlay Minidisk

**Privilege** **Class:** Any Use DIAGNOSE code X'E4' to get information about a user's minidisk or to

create a full-pack overlay. The functions are:

**Code** **Function** X'00' To get information about the device currently linked by a logged-on

user. X'01' To get information about the device as defined in the directory. X'02' To create for the authorized user a full-pack overlay read/write minidisk of the volume on which a given user's specified minidisk resides. X'03' To create for the authorized user a full-pack overlay read/write minidisk of the volume when given the real device and cylinder number.

**Entry** **Values:**

Rx Contains the address of a parameter list. This must be on a doubleword boundary and cannot cross a page boundary. The format of this parameter list is function-dependent. Ry Is not examined as input. Rx and Ry may be the same register. **Exit** **Values:** Rx Contains the address of the parameter list supplied as input. If sufficient length (LEN) is specified, the parameter list output area contains the output values of the DIAGNOSE function. The format of this parameter list is function dependent. If Rx and Ry are the same register, the address of the parameter list will be overlayed by the return code. Ry Contains a return code. Rx and Ry may be the same register. **Function** **X'****00****'** **and** **Function** **X'****01****'****:** These DIAGNOSE functions allow a user with the RACF DIAG0E4 option or, if RACF is not installed, the DEVInfo or DEVMaint options of the OPTION directory control statement to get relocation and real device information about the minidisk of another user. For more information on the OPTION directory control statement, refer to VM/ESA CP Planning and Administration. This DIAGNOSE also allows a user without authorization to get relocation information about the user's own minidisk. 1. You have to supply the following parameter list: 00 DIAG FCN LEN VDEVNO \\\\\\\\\\\\\\\ 08 USERID 10 Output area 18 Output area 20 Output area DIAG is the halfword DIAGNOSE code. It must contain the halfword X'00E4'. FCN is the byte function code. Code F**unct**ion X'00' To get information about the device currently linked by a logged-on user X'01' To get information about the device as defined in the directory LEN is the byte length, in bytes, of the parameter list. The minimum value is X'10'. The recommended value is X'28' in order to accommodate the output area. VDEVNO is the halfword virtual device number (address) of the minidisk for which information is to be returned. \\\\ is a halfword reserved area. USERID is the user ID of the virtual machine that owns, or has a link to, the minidisk specified in VDEVNO. This is a doubleword of 8 characters. An asterisk (*) implies the issuer's user ID. The asterisk or user ID must be left-justified and padded with blanks. Output area is the 3-doubleword parameter list output areas. It is not checked or used as input. 2. Output: The following information is returned in the parameter list: 00 /////////////////////////////////////////////////////////////// 08 /////////////////////////////////////////////////////////////// 10 VOLSER RDEVNO 18 BEGINNING EXTENT 20 FLAGS \\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\ ////// is the two doublewords of the input area. This area is not used for output and will not be changed from the user's input specified values. VOLSER is the 6-character volume serial number of the real volume that contains the minidisk. RDEVNO is the halfword real device number of the device containing the minidisk. BEGINNING is the fullword relocation factor of the minidisk, in cylinders. The relocation factor is the number of the cylinder where the minidisk starts on the real volume. EXTENT is the fullword number of cylinders allocated to the minidisk. To get the number of the last cylinder, add the beginning cylinder to the total number of cylinders (extent), minus one. `Example` `1:` Beginning 0 (The returned nu`mber` `is a` `Extent` `=` `10` `hexadecimal` `value.)` 0+A-1=X'9' (cylinders 0 `through 9)` `Example` `2:` `Beginning` `=` `440` `Extent` `=` `100` 440+100-1=X'2`1B'` `(cylinders` `440` `through` `539)` FLAGS is the following device information: Code M**eani**ng X'80' The real device associated with the specified virtual device is dedicated. X'40' The specified virtual device is a full-pack minidisk.

**Note:** The relocation factor is zero, and the extent is the number of cylinders apparently available to CP. The number of cylinders might be less than the full number of cylinders on the real volume, if CP is running as a guest on another VM system in which less than a full-pack is defined. X'20' The specified virtual device is a non-full-pack minidisk.

\\\\ is a 7-byte reserved area.

Function X'02':

This DIAGNOSE function creates for the invoker a full-pack overlay read/write minidisk of the volume on which a given user's specified minidisk resides. Authorization is obtained by the RACF DIAG0E4 option in conjunction with the DEVMaint directory option. The DEVMaint directory option is always required to create a full-pack overlay minidisk. 1. You have to supply the following parameter list: 00 DIAG FCN LEN VDEVNO1 VDEVNO2 08 USERID 10 MODE \\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\ 18 OUTPUT AREA DIAG is the halfword DIAGNOSE code. It must contain the halfword X'00E4'. FCN is the byte function code. It must contain the byte X'02'. LEN is the length, in bytes, of the parameter list. The minimum value is X'12'. The recommended value is X'20' in order to accommodate the output area. VDEVNO1 is the halfword virtual device number (address) of the minidisk in the other user's virtual machine configuration. VDEVNO2 is the halfword virtual device number (address) in the invoker's virtual machine configuration that is to be assigned to the full-pack overlay minidisk created by this function. USERID is the user ID of the virtual machine that owns, or has a link to, the minidisk you specified in VDEVNO1. This is a doubleword of eight characters. An asterisk (*) implies the issuer's user ID. The asterisk and user ID must be left justified and padded with blanks. MODE is the halfword access mode for LINK. The valid 2-character modes are: a. "R" specifies Read-Only access. The full-pack overlay request is not granted if any other user has write access to the minidisk identified as VDEVNO1. "R" must be left justified and padded with a blank. b. "W" specifies Write access. The full-pack overlay request is not granted if any other user has read or write access to the minidisk identified as VDEVNO1. "W" must be left justified and padded with a blank. c. "M" specifies Multiple access. The full-pack overlay request is granted as a write link unless another user already has write access to the minidisk identified as VDEVNO1. "M" must be left justified and padded with a blank. d. "RR" specifies Read Only access. The full-pack overlay request is always granted as a read link. e. "WR" specifies Write access desired, Read access acceptable. The full-pack overlay request is granted as a write link unless another user already has read or write access to the minidisk identified as VDEVNO1, in which case the request is granted as a read link. f. "MR" specifies Write access desired, Read access acceptable. The full-pack overlay request is granted as a write link unless another user already has write access to the minidisk identified as VDEVNO1, in which case the request is granted as a read link. g. "MW" specifies Write access. The full-pack overlay request is always granted as a write link. \\\\ is a 6-byte reserved area. OUTPUT AREA is the doubleword parameter list output area. It is not checked or used as input. If VDEVNO1 represents a LINK in the target user's directory, a maximum of two indirect directory iterations are attempted to find the MDISK definition. 2. Output: The following information is returned in the parameter list: 00 /////////////////////////////////////////////////////////////// 08 /////////////////////////////////////////////////////////////// 10 /////////////////////////////////////////////////////////////// 18 USERID ////// contains the three doublewords of the input area. This area is not used for output and is not changed from the user's input specified values. USERID is the user ID of the virtual machine which has a link to the minidisk and is preventing the full-pack overlay from being defined. This is a doubleword of eight characters. The user ID is left-justified and padded to the right with blanks. **FUNCTION** **X'****03****'****:** This DIAGNOSE function creates a full-pack overlay read/write minidisk for the invoker, giving the volume real device number and the CYLINDER number. Authorization is obtained by the RACF DIAG0E4 option in conjunction with the DEVMaint directory option. The DEVMaint directory option is always required to create a full-pack overlay minidisk. 1. You have to supply the following parameter list: 00 DIAG FCN LEN RDEVNO VDEVNO 08 CYLINDER \\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\ 10 MODE \\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\ 18 OUTPUT AREA DIAG is the halfword DIAGNOSE code. The recommended value is X'20' in order to accommodate the output area. RDEVNO is the halfword real device number (address) of the volume. VDEVNO is the halfword virtual device number (address) in the invoker's virtual machine configuration which is assigned to the full-pack overlay minidisk created by this function. "W" specifies Write access. The full-pack overlay request is not granted if any other user has read or write access to the minidisk identified as CYLINDER on volume RDEVNO. "W" must be left justified and padded with a blank. c. "M" specifies Multiple access. The full-pack overlay request is granted as a write link unless another user already has write access to the minidisk identified as CYLINDER on volume RDEVNO. "M" must be left justified and padded with a blank. d. "RR" specifies Read Only access. The full-pack overlay request is always granted as a read link. e. "WR" specifies Write access desired, Read access acceptable. The full-pack overlay request is granted as a write link unless another user already has read or write access to the minidisk identified as CYLINDER on volume RDEVNO, in which case the request is granted as a read link. f. "MR" specifies Write access desired, Read access acceptable. The full-pack overlay request is granted as a write link unless another user already has write access to the minidisk identified as CYLINDER on volume RDEVNO, in which case the request is granted as a read link. g. "MW" specifies Write access. The full-pack overlay request is always granted as a write link. \\\\ are 4-byte and 6-byte reserved areas. OUTPUT AREA is the doubleword parameter list output area. It is not checked or used as input. 2. Output: The following information is returned in the parameter list: 00 /////////////////////////////////////////////////////////////// 08 /////////////////////////////////////////////////////////////// 10 /////////////////////////////////////////////////////////////// 18 USERID ////// contains the three doublewords of the input area. This area is not used for output and is not changed from the user's input specified values. USERID is the user ID of the virtual machine that has a link to the minidisk and is preventing the full-pack overlay from being defined. This is a doubleword of eight characters. The user ID is left justified and padded to the right with blanks. **Responses:** Upon successful completion of DIAGNOSE X'E4', the PSW condition code is set to 0, and Ry is set to 0.
