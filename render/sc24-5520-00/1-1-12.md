## 1\.1\.12 Diagnose Code X'14'\-\-Input Spool File Manipulation

**Privilege Class:** Any

Use DIAGNOSE code X'14' to access and to control input spool files in your reader\. You can access descriptions of files in your reader, change the copy count of a file, read files, backspace to the previous record, or select the next or a specific file to process\.

**Entry Values:**

Rx The first data register \(contents determined by subfunction code\)\.

Ry The second data register \(contents determined by subfunction code\)\.

Ry\+1 Contains the actual subfunction code that was issued \(Ry and Ry\+1 must be an even/odd pair\)\.

**Note:** You can use extended mode only for the subfunctions that read spool file blocks: X'0004', X'0008', X'001C', X'0FFE' and X'0FFF'\. In extended DIAGNOSE mode, you can specify the size of a spool file block in the high order byte of Ry\+1\. If bit 0 is 1, bit 1 must be 0, and bits 2 through 7 define the size of the block in doublewords to be returned\. If a block size of 0 is specified in extended mode, no information from the spool file block will be returned\.

For subfunctions X'0FFE' and X'0FFF', extended mode returns the spool file block information, 40 bytes of 3800 printer information \(such as CHARS, FCB, COPY and FLASH\), and the first record \(generally, the TAG\)\.

For a description of the spool file block information returned, refer to SFBLOK and SPLINK in [Appendix E, "Data Areas Used by](e-0.md) [DIAGNOSE Codes" in topic E\.0](e-0.md)\. DSECTs are provided in the HCPGPI macro library as SFBLOK COPY and SPLINK COPY\.

The subfunctions are as follows:

`Code X'0000'--Read the next spool file buffer (data record)`

Rx = the buffer address \(full page\) Ry = the virtual spool reader address

A page of spool data is returned in the user's buffer\. If there is no active file, this is the first data block of the first file in the user's virtual reader\. Condition code 3 is returned if the file is already active when the DIAGNOSE code X'14' instruction is issued\. Condition code 2 is returned if no more files are found\. If there is an active file, the read spool data commands get the next block of data\. If "continuous read" is not set, condition code 1 is returned at end\-of\-file, and no data passed back\. If "continuous read" is set, processing continues with the first block of the next logical file\. This may be a read of the same file if it is set for multiple copies\. End\-of\-file, condition code 1, is returned if no more files are found for the user when the reader is continuously spooled\.

**Note:** If the virtual buffer specified by using Rx crosses a page boundary, a specification exception occurs\.

`Code X'0004'--Read the next print spool file block`

Rx = the buffer address \(13 doublewords\) Ry = the virtual spool reader address

If DIAGNOSE code X'14' is using the specified device and if this is a repeat call for a printer spool file block, the chain search continues from the point following the last block given to the virtual machine\. In this case, condition code 1 is set when there are no more print files\. If this is the first call for a spool file block, or if there have been intervening calls for file reading, the spool input chain is searched from the beginning\. If no files are found, condition code 2 is set\.

Subfunction code X'0004' only accesses files that were created on a printer or console\.

**Note:** If the virtual buffer specified using Rx crosses a page boundary, a specification exception occurs\.

`Code X'0008'--Read the next punch spool file block`

Rx = the buffer address \(13 doublewords\) Ry = the virtual spool reader address

Processing for subfunction code X'0008' is the same as for subcode X'0004', except that only files created on a punch are processed\.

**Note:** If the virtual buffer specified using Rx crosses a page boundary, a specification exception occurs\.

`Code X'000C'--Order a file to the front of a queue`

Rx = the file ID Ry = unused

The spool input queue is searched for the file specified\. If it is found, the file is moved to the front of the queue\. If the file is not found, condition code 2 is set\.

`Code X'0010'--Repeat the active file a specified number of times`

Rx = the new copy count for the active file Ry = the virtual spool reader address

The count of the active file is set to the specified value, the maximum being 255\. If the count is greater than 255, it is set to 255\. If the count is negative, a specification error occurs\. If there is no active file, condition code 2 is set\.

`Code X'0014'--Restart an active file at the beginning`

Rx = unused Ry = the virtual spool reader address

If the device has an active file, the record pointers are set to the beginning of the file\. Therefore, the next read receives the first file record\. If no file is active, condition code 2 is set\.

`Code X'0018'--Backspace one record`

Rx = the buffer address \(full page\) Ry = the virtual spool reader address

If the device has an active file, the record pointer is set to the previous record unless it is already positioned at the first record\. The record is returned to the user as in a normal X'0000' read subfunction\. If no file is active, condition code 2 is set\.

`Code X'001C'--Read the next monitor spool file block`

Rx = the buffer address \(13 double words\) Ry = the virtual spool reader address

Processing is the same as subfunction code X'0008', except that only monitor spool files are handled\. Condition code 2 is always returned, because monitor spool files are not supported in VM/ESA\.

`Code X'0020'--Read the next monitor spool record`

Rx = the buffer address \(full page\) Ry = the virtual spool reader address

Processing is the same as subfunction code X'0000', except that only monitor spool files are handled\. Condition code 2 is always returned, because monitor spool files are not supported in VM/ESA\.

`Code X'0024'--Read the last spool file buffer`

Rx = the start address of a full\-page virtual buffer Ry = the virtual spool reader address

The last spool buffer \(active file\) is read\. The specified device is checked for an already active file and, if there is one, the last full\-page buffer is made available to the virtual machine\. If there is no active file, the condition code of the virtual machine is set to 2\.

`Code X'002C'--Select a file for processing and read the next spool buffer`

Rx = the start address of a full\-page virtual buffer Ry = the virtual spool reader address Ry\+1 = nnnnyyyy where: nnnn = the file identifier of the requested file yyyy = the function subcode

The spool input chain is searched for the file specified, following the same procedure as subcode X'000C'\. If the file is found, it is moved to the head of the chain, the processing continues, and the file is read as if subcode X'0000' had been issued\.

**Note:** For subcode X'002C', held files are skipped\.

`Code X'0FFE'--Select the next file not previously selected.`

Rx = the virtual address of a 252\-byte buffer Ry = the code to further determine the function

The next spool file is selected that was not previously selected and returns the descriptor \(for Ry code = 0\)\. If Ry code = 1, it first resets the bit indicating a spool file was previously selected for all spool files and returns the descriptor of the first spool file\. If the file isn't found, or if you selected all the files, you receive a condition code of 1 from the virtual machine\. The virtual buffer specified by Rx can cross a page boundary\. The spool file block and the first record \(generally, the TAG\) are placed in the caller's buffer\.

When you invoke subfunction X'0FFE' in extended mode, an additional 40 bytes are returned following the spool file block\. If bit 0 is 0, you cannot specify the size of a spool file block, and 13 doublewords are returned\.

`Code X'0FFF'--Retrieve next file descriptor`

Rx = the buffer address \(252 bytes\) Ry = the spool file ID number

Ry contains a spool file ID or zero and specifies the point at which to begin the search\. Zero identifies the beginning of the chain\. The next file belonging to the user, regardless of class, file type, or current usage is selected\. The spool file block and the first record \(generally, the TAG\) are placed in the caller's buffer\. If there is no subsequent file, condition code 1 is returned\. If a starting file ID is specified and there is no match for this user, condition code 2 is returned\. The virtual buffer specified by Rx can cross a page boundary\.

When you invoke subfunction X'0FFF' in extended mode, an additional 40 bytes are returned following the spool file block\. If bit 0 is 0, you cannot specify the size of a spool file block, and 13 doublewords are returned\.
