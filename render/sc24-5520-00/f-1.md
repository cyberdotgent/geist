## F\.1 APPC Conversations

User programs and resource manager programs in VM/ESA must follow the rules of an APPC conversation\. APPC/VM supports and enforces these rules, as described in the following sections\.

**Note:** An APPC conversation is represented within a TSAF collection as an APPC/VM path\. SNA sessions have no representation in a TSAF collection\. VTAM allocates and ends the SNA session on which APPC/VM conversations are established\.
