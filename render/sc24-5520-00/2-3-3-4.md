#### 2.3.3.4 IUCV Functions

To use IUCV, you and the virtual machine users with whom you use IUCV to communicate, must code application programs that invoke the IUCV macro. By specifying one of the IUCV functions on the IUCV macro, you tell IUCV what to do. [Table 44](#TBLU92FIG0) describes: 1. The basic tasks you can use IUCV to perform 2. The name of the IUCV function that corresponds to the task 3. Where in the next chapter you can find detailed information about the function.
