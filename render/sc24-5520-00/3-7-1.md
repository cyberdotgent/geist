## 3\.7\.1 Overview of APPC/VM Assembler

<a id="HDRAPPCOV"></a>

The assembler programming interface for APPC/VM allows communications between application programs that are written in assembler language\. The APPC/VM assembler interface implements the base set of APPC \(SNA LU 6\.2\) verbs and several APPC option sets\.

The APPC/VM assembler interface provides macros and parameter lists that applications can use to set up and control the communications environment within one VM/ESA system, and among VM/ESA systems in a TSAF collection\. \(For programs communicating outside a TSAF collection to an SNA network, AVS translates APPC/VM protocol into APPC/VTAM, which is the VTAM implementation of APPC\.\)

In addition, VM/ESA has implemented some IUCV functions for an APPC/VM environment\. IUCV functions are not part of the APPC architecture and are unique to VM/ESA\. **Note: The remainder of this book refers to the APPC/VM assembler programming interface as simply APPC/VM\.**
