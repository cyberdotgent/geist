### 7.12.1.2 Interface to the External Security Manager (ESM)

[Figure 78](7-12-1-2.md#HCPESMF) provides an overview of the interfaces to the external security manager (ESM). This figure suggests how an ESM could set up an interface through the stub modules, and perhaps use IUCV and DIAGNOSE code X'A0'.

```text
    ___________________ 
   |___________________|
```

The general security steps are as follows: 1. During system administration, CP provides "stub" versions of modules HCPRPW, HCPRPI, and HCPRPD. The external security manager (ESM) replaces the access control interface (ACI) modules with its own tailored version of these modules.

2. Each time a CP command, DIAGNOSE code, or security-relevant system

function is issued, CP checks whether an audit or a protect is required. If neither is required, the activity continues normally. However, if an audit or protect is required, CP creates an ACIPARMS

parameter list specifically for this request. 3. CP passes the ACIPARMS parameter list to either HCPRPW or HCPRPI. The request is then passed to the ESM. 4. The ESM performs the requested function, records its response to the appropriate ACIPARMS field (ACICODE), and returns the ACIPARMS parameter list back to CP. 5. CP then carries out ESM's security decision. The process continues at

step [2](7-12-1-2.md) for the next user activity.
