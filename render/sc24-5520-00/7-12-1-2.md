2. Each time a CP command, DIAGNOSE code, or security-relevant system

function is issued, CP checks whether an audit or a protect is required. If neither is required, the activity continues normally. However, if an audit or protect is required, CP creates an ACIPARMS

parameter list specifically for this request. 3. CP passes the ACIPARMS parameter list to either HCPRPW or HCPRPI. The request is then passed to the ESM. 4. The ESM performs the requested function, records its response to the appropriate ACIPARMS field (ACICODE), and returns the ACIPARMS parameter list back to CP. 5. CP then carries out ESM's security decision. The process continues at

step 2 fo [r](7-12-1-2.md) the next user activity.
