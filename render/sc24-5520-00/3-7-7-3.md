### 3.7.7.3 Currently-Defined Error Codes

The following table summarizes the error codes that you can get in an

APPC/VM program. For each APPC/VM-defined error code shown in this section, the APPC error condition is given. Refer to SNA Transaction Programmer, for a description of each APPC error condition.

<a id="TBLTBLUNIQ97"></a>

| APPC/VM Code | APPC Error Condition |
| --- | --- |
| X'0410' | PROG_ERROR_NO_TRUNC |
| X'0420' | PROG_ERROR_TRUNC |
| X'0430' | PROG_ERROR_PURGING |
| X'0510' | SVC_ERROR_NO_TRUNC |
| X'0520' | SVC_ERROR_TRUNC |
