#### 2.4.7.4 QUIESCE Parameter List Input Fields

IPPATHID contains the path identification of the path you are trying to quiesce. IPFLAGS1 specifies options for the QUIESCE function. IUCV treats each bit in IPFLAGS1 separately. Make sure that bits you are not using to define input are set to 0. IPALL (X'80') when set to 1, tells CP to quiesce all of your paths. IPUSER contains the 16-byte user data area IUCV reflects to the virtual machine at the other end of the path you quiesce.
