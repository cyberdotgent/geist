#### 2.4.5.2 Identifying the Message You Want to Purge

You can identify a message in any of the following ways:

*1.* By *message* *identification* *number,* *path* *identification* *number,* *and* *message* *class*. In this case, IUCV purges a specific message. 2. *By* *path* *identification* *number* *and* *message* *class*. IUCV purges the first message with the correct path identification and message class. 3. *By* *path* *identification* *number*. IUCV purges the first message with the correct path identification.

**Note:** IUCV stores message identification values in the SEND parameter list. IUCV stores the message identification number in the IPMSGID field, the path identification number in the IPPATHID field, and the message class in the IPSRCCLS field.

Specifying a Message Identification Number: Specify the message identification number in one of the following ways: 1. Use the MSGID=parameter. Specify the message identifier as (a) the relocatable label of a fullword containing the message identifier, or (b) the number of a register that contains the message identifier. 2. Store the message identification number in the IPMSGID field of the PURGE parameter list. Also, set the IPFGMID bit (X'04') to 1 in the IPFLAGS1 field.

**Note:** If you use the MSGID=parameter, IUCV stores the message ID and sets the IPFGMID flag automatically. Remember that whenever you specify a message identification number, you must also specify the message's path ID and target message class.

Specifying a Message's Path Identification Number: Specify a message's path identification number in one of the following ways: 1. Use the IPPATHID=parameter. Specify the path identification as (a) the relocatable label of a halfword that contains the path ID, or (b) the number of a register that contains the path ID in the low-order halfword. 2. Store the path identification number in the IPPATHID field of the PURGE parameter list. Also, set the IPFGPID bit (X'02') to 1 in the IPFLAGS1 field.

**Note:** If you use the PATHID=parameter, IUCV stores the path ID and sets the IPFGPID flag automatically.

Specifying the Class of a Message: Specify the class of a message in one of the following ways: 1. Use the IPSRCCLS=parameter. Specify the message class as (a) the relocatable label of a fullword containing the message class, or (b) the number of a register containing the message class. 2. Store the message class in the IPSRCCLS field of the PURGE parameter list. Also, set the IPFGPID bit (X'02') to 1 in the IPFLAGS1 field.

**Note:** If you use the IPSRCCLS=parameter, IUCV stores the message class and sets the IPFGPID flag automatically.
