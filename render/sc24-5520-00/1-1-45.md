## 1.1.45 Diagnose Code X'D0'--Volume Serial Support

**Privilege** **Class:** Any Use DIAGNOSE code X'D0' to pass CP the volume serial (VOLSER) of a tape volume. CP will include the VOLSER in error recording records it creates for that drive.

**Entry** **Values:**

Rx A general register that contains the address of the tape volume serial passed to the DIAGNOSE interface. The tape volume serial should be six bytes long. Ry A general register that contains the virtual device number passed to the DIAGNOSE interface. X'D0' Execution of code X'D0' provides CP with the virtual device number and the volume serial for tape device. **Exit** **Values:** Return and condition codes are returned for DIAGNOSE code X'D0' as follows: Cond**ition**

**Code** **Meaning**

0 DIAGNOSE complete. Ry is set to zero. 1 Error condition. Ry contains the following return codes: 1 Addressing exception 3 I/O error during paging 4 VOLSER fetch-protected 5 Invalid virtual device number or device not dedicated 6 The VOLSER function does not support this device.

**Usage** **Note:** The volume serial of a tape volume is recorded in the OBR and MDR records whenever DIAGNOSE code X'D0' has been successfully executed for the tape volume. The VOLSER is maintained until the tape volume is unloaded. If a

tape is manually unloaded, CP clears the VOLSER field following the logging of the required ORB record to avoid the possibility of logging future OBR/MDR records with an incorrect VOLSER.
