#### 5\.10\.5\.2 Required Parameter

`PRMLIST=` specifies the address of the IUCV parameter list\. The IUCV instruction is generated to reference the address specified\.

*label* is the relocatable label of the parameter list\.

`(`*reg*`)` is the register number that contains the address of the parameter list\.
