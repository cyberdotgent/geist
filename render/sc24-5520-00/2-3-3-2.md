#### 2.3.3.2 IUCV Message Queues

Each virtual machine can have three message queues: 1. A send queue, which is where IUCV places incoming messages. 2. A receive queue, which is where IUCV places a message after the virtual machine receives it but before a virtual machine replies to it. 3. A reply queue, which is where IUCV places message replies. [Figure 9](2-3-3-2.md#C92FIG1) illustrates how IUCV might move a message among the message queues of two virtual machine users (SOURCE and TARGET).

<a id="C92FIG1"></a>

```text
    ________________________________________________________________________ 
   |                                                                                  |
   | SOURCE Virtual Machine                TARGET Virtual Machine                     |
   |                                                                                  |
   | Invokes the SEND function                                                        |
   |                                       on TARGET's send queue.                    |
   |                                       TARGET uses the RECEIVE function           |
   |                                       to receive the message.                    |
   |                                       IUCV moves the message to                  |
   |                                       TARGET's receive queue.                    |
   |                                       TARGET uses the REPLY function             |
   |    on SOURCE's reply queue                                                       |
   |    so that it can be fetched                                                     |
   |    by SOURCE.                                                                    |
   |                                                                                  |
   |________________________________________________________________________|
```
