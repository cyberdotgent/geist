## 1.1.3 Privilege Classes

Some DIAGNOSE codes, like some CP commands, are reserved for authorized users only. Each DIAGNOSE code description in this section tells you who may issue that particular code. The letter values used in this entry are

discussed in detail in VM/ESA CP Command and Utility Reference.
