## 1.1.20 Diagnose Code X'48'--Second Level SVC 76

VM/ESA (370 Feature) In VM/ESA (370 Feature), the function of DIAGNOSE code X'48' is to distinguish between two or more levels of virtual device numbers in EREP records. In VM/ESA, CP itself provides this function; you do not have to invoke it using the DIAGNOSE instruction.
