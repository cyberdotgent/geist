## BIBLIOGRAPHY\.1 The VM/ESA Release 1 Library

<a id="HDRREL1LIB"></a>

The VM/ESA Release 1 library contains the following groups of publications:

- *ESA Feature* publications, which help you use VM\.

If you order the ESA Feature, your library contains all the ESA Feature and Common publications\. The *VM/ESA Library Guide and Master Index* describes each book\. You can order these books when the ESA Feature becomes generally available\.

- *370 Feature* publications, which help you use VM/ESA \(370 Feature\)\.

If you order the 370 Feature, your library contains all of the 370 Feature and Common books\. The *VM/ESA Library Guide and Master Index for 370* describes these books\.

- *Common* publications, which are provided with each feature, describe the VM/ESA product and help you use the VM/ESA common components\.
