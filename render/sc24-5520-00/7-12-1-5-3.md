#### 7.12.1.5.3 DIAGNOSE Auditing

In general, the system handles the auditing of DIAGNOSE functions the same way it handles the auditing of CP commands. If a user invokes a DIAGNOSE function and if that function's AUDIT bit is on, CP formats the general ACIPARMS parameter list, but with the variations shown in [Table 59](#TBLACBDI).

<a id="ACBDI"></a>

Table 59. ACIPARMS Control Block for DIAGNOSE Auditing

| Byte | Offset | Label<br>Description<br>Dec(Hex) Bytes Contents<br>ACIEVENT<br>Event name<br>78(48) 8 This field is set to the<br>DIAGNOSE name in the<br>justified and padded<br>with blanks.<br>ACIDATA<br>Additional<br>data<br>120(78) 0 This label marks the<br>start of the additional<br>data.<br>ACIRX<br>R[x] Register<br>120(78) 4 This field contains the<br>contents of the R[x]<br>register.<br>ACIRX1<br>R[x+1]<br>Register<br>124(7C) 4 This field contains the<br>contents of the R[x+1]<br>register<br>ACIRY<br>R[y] register<br>128(80) 4 This field contains the<br>contents of the R[y]<br>register.<br>ACIRY1<br>R[y+1]<br>register<br>132(84) 4 This field contains the<br>contents of the R[y+1]<br>register. |
| --- | --- | --- |


**Notes:** AND 1. For DIAGNOSE X'64', the R[x] and R[x+1] slots contain the 8-byte EBCDIC segment name. (The exception to this is the QUERY function for restricted segments, which is not audited.)

2. DIAGNOSE X'68', the VMCF DIAGNOSE, receives special handling. For

details, see ["Auditing Communication Among Virtual Machines" in](7-12-1-5-4.md) [topic 7.12.1.5.4](7-12-1-5-4.md). 3. DIAGNOSE X'D4' and X'E4' are protectable DIAGNOSE functions.

4. DIAGNOSE X'7C' also receives special handling. The INITIATE, TERMINATE, and TERMINATE ALL functions are audited. CP sends to the ACI mostly the same auditing information on these functions as it does when any DIAGNOSE is issued. The only differences are these: The ACIDATA field of the INITIATE function contains the output / from (rather than the input to) the R[x] and R[x+1] registers. The ACIDATA field of the TERMINATE function contains the output / from (rather than the input to) the R[y] and R[y+1] registers.

The ACIDATA field of the TERMINATE ALL function contains the output from (rather than the input to) the R[y] register. VM/ESA can audit any DIAGNOSE function.
