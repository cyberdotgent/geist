#### 2\.4\.13\.1 Required Inputs \(for All SENDs\)

1\. *The address of the SEND parameter list*\. Use the PRMLIST=parameter to identify to IUCV the address of your parameter list\. The address of the parameter list must be a guest real address \(an address that is real to your virtual machine\), and must be on a doubleword boundary\.

Specify the address of the parameter list as \(a\) a relocatable label, or \(b\) the number of a register that contains the address\.

2\. *The path identification of the path over which you are sending the message*\. \(When a path is established, IUCV assigns the path a unique path identification number\. IUCV stores this value in the CONNECT and ACCEPT parameter lists\.\)

Specify the path identification in one of the following ways:

a\. Use the PATHID=parameter\. Specify the path identification as \(1\) the relocatable label of a halfword that contains the path ID, or \(2\) the number of a register that contains the path ID in the low\-order halfword\.

b\. Store the path identification number in the IPPATHID field of the SEND parameter list\.

**Note:** If you use the PATHID=parameter, IUCV stores this value automatically\.
