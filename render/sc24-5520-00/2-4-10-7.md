#### 2.4.10.7 REPLY Parameter List Output Fields

IPRCODE contains one of the following return codes:

**Code** **Meaning** 00 Normal return

01 You specified an invalid path identification number. 05 The reply you sent is too big for the storage buffer of the virtual machine to which you sent the reply. 06 Storage protection exception on the answer buffer

**Code** **Meaning**

07 Addressing exception on the answer buffer 08 The message class or path identification you specified does not correspond to the message identification you specified. 09 IUCV has purged the message. 10 You specified a negative message length. 21 The virtual machine or CP system service to which you sent a reply cannot accept message data in its parameter list. 22 Negative SEND buffer length in list 23 Negative REPLY buffer length in list 24 Incorrect total length of buffer list lengths 25 PRMMSG and BUFLIST/ANSLIST not allowed 26 Buffer list not on a doubleword boundary 27 ANSLIST not on a doubleword boundary 31 IUCV function specified on an APPC/VM path IPBFADR2 contains the address of the response buffer incremented by the length of the response data that IUCV moved. IPBFLN2/IPBFLN2F If the buffer was exactly the correct length, IUCV stores a zero in IPBFLN2. If the buffer was too long, IUCV stores in IPBFLN2 the number of extra bytes remaining in the buffer. If the buffer was too short, IUCV stores in IPBFLN2 the number of bytes remaining in the message that would not fit into the buffer.
