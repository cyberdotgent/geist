#### 2\.4\.3\.4 DCLBFR Parameter List Input Fields

`IPFLAGS1` specifies options for the DCLBFR function\. IUCV treats each bit in IPFLAGS1 separately\. Make sure that bits you are not using to define input are set to zero\.

`IPCNTRL flag (bit X'04')` indicates, when set to 1, that you want to declare a control buffer\.

`IPBFADR1` contains the address of your external interrupt buffer\.
