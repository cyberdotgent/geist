#### F\.3\.3 Abend Conditions

The parameter check condition is as follows:

<a id="TBLTBLUNIQ224"></a>

```
    __________________________________________________________ ______________
   | Parameter Check Condition                                | IPRCODE      |
   |__________________________________________________________|______________|
   | The program is not allowed to specify                    | X'29'        |
   | MODE_NAME(SNASVCMG), or MODE_NAME(SNASVCMG) is not       |              |
   | supported.                                               |              |
   |__________________________________________________________|______________|
```
