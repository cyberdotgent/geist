## 1.1.17 Diagnose Code X'34'--Read System Dump Spool File

**Privilege** **Class:** C, E Use DIAGNOSE code X'34' to read the system dump spool file.

**Entry** **Values:** Rx Contains the guest real address of a page-size buffer that receives

the spool file data. If the buffer crosses a page boundary, a specification program check is returned to your virtual machine. Ry Contains the virtual address of the spool input card reader. Ry must not be register 15. **Exit** **Values:** On return, Ry+1 may contain a return code. See "Responses" below for a description of these codes. **Usage** **Notes:** 1. The format of a VM/ESA dump may change from release to release. 2. The format of the dump data is not part of the programming interface. **Responses:** On return from the DIAGNOSE code X'34' processing, CP sets one of the condition codes listed below. In addition, a return code is placed in Ry+1, as follows:

<a id="TBLTBLUNIQ14"></a>

| Condition | Return Code<br>in Ry+1 | Status |
| --- | --- | --- |
| 0 | None | Data transfer completed successfully |
| 1 | None | End-of-file reached |
| 2 | None | File not found |
| 3 | X'04' | Device address invalid |
| 3 | X'08' | Device type invalid |
| 3 | X'0C' | Device busy |
| 3 | X'10' | Fatal paging I/O error |
