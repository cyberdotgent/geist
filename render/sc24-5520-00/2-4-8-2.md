#### 2\.4\.8\.2 Identifying Messages

<a id="HDRREC1"></a>

As mentioned earlier, there may be times when you need to identify a specific message to receive\. For example, if you are receiving the remainder of a message, you must identify the message by message identification number, path identification number, and message class\. \(If you do not identify a message, IUCV receives the first message on the SEND queue that was not partially received\.\)

Identify a message by one of the following ways:

1\. Message identification number, path identification number, and message class

2\. Path identification number and message class

3\. Path identification number

4\. Message class\.

**Note:** IUCV reflects these values to your virtual machine as part of message\-pending external interrupts and as part of the output to the DESCRIBE function\. \(IUCV stores the message identification number in the IPMSGID field, the path identification number in the IPPATHID field, and the message class in the IPTRGCLS field\.\)

**Specifying a Message Identification Number**: Whenever anyone sends an IUCV message, IUCV assigns the message a unique identification number\. Specify this number in one of the following ways:

1\. Use the MSGID=parameter\. Specify the message identifier as \(a\) the relocatable label of a fullword containing the message identifier, or \(b\) the number of a register that contains the message identifier\.

2\. Store the message identification number in the IPMSGID field of the RECEIVE parameter list\. Also, set the IPFGMID bit \(X'04'\) to 1 in the IPFLAGS1 field\.

**Note:** If you use the MSGID=parameter, IUCV stores the message ID and sets the IPFGMID flag automatically\.

Remember that whenever you specify a message identification number, you must also specify the message's path ID and target message class\.

**Specifying a Message's Path Identification Number**: Specify a message's path identification number in one of the following ways:

1\. Use the PATHID=parameter\. Specify the path identification as \(a\) the relocatable label of a halfword that contains the path ID, or \(b\) the number of a register that contains the path ID in the low\-order halfword\.

2\. Store the path identification number in the IPPATHID field of the RECEIVE parameter list\. Also, set the IPFGPID bit \(X'02'\) to 1 in the IPFLAGS1 field\.

**Note:** If you use the PATHID=parameter, IUCV stores the path ID and sets the IPFGPID flag automatically\.

**Specifying a Message's Target Message Class**: Specify a message's target message class in one of the following ways:

1\. Use the TRGCLS=parameter\. Specify the target message class as \(1\) the relocatable label of a fullword containing the target message class, or \(2\) the number of a register containing the target message class\.

2\. Store the target message class in the IPTRGCLS field of the RECEIVE parameter list\. Also, set the IPFGMCL bit \(X'01'\) to 1 in the IPFLAGS1 field\.

**Note:** If you use the TRGCLS=parameter, IUCV stores the message class and sets the IPFGMCL flag automatically\.
