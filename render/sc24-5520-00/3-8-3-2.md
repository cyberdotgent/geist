#### 3.8.3.2 Required Parameter

PRMLIST= lets you specify the address of the APPC/VM parameter list. The address must be a guest real address, that is, the address is within the virtual machine's real address space (guest=real). Also, the parameter list must be on a doubleword boundary. label is the relocatable label of the parameter list. (reg) is the register number that contains the address of the parameter list.
