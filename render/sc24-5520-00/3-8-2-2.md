#### 3.8.2.2 Required Parameters

PRMLIST= specifies the address of the APPC/VM parameter list. The address must be a guest real address (real to the virtual machine), and the parameter list must be on a doubleword boundary. label is the relocatable label of the parameter list. (reg) is the register number that contains the address of the parameter list.
