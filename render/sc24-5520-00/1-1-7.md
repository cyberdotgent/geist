## 1.1.7 Diagnose Code X'00'--Store Extended-Identification Code

This address must be aligned on a doubleword boundary. Ry Contains the number of bytes that you want to store. This value is an unsigned binary number. **Exit** **Values:** Ry Contains its original value less the number of bytes that were stored. **Usage** **Notes:** 1.
