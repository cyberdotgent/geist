## 1\.1\.7 Diagnose Code X'00'\-\-Store Extended\-Identification Code

<a id="TBLDG00F"></a>
<a id="LIS00ee"></a>
<a id="LIS00bm"></a>
<a id="LIStimzon"></a>
<a id="ELIStimzon"></a>

<pre>
   Privilege Class:  Any
   Use DIAGNOSE code X'00' to examine the VM/ESA extended-identification
   code.
   Entry Values:
   Rx     Contains the second-level (guest real) storage addresses where you
          want to store the VM/ESA extended-identification code.  This
          address must be aligned on a doubleword boundary.
   Ry     Contains the number of bytes that you want to store.  This value is
          an unsigned binary number.
   Exit Values:
   Ry     Contains its original value less the number of bytes that were
          stored.
   Usage Notes:
   1.  For a discussion of how VM/ESA processes addresses, refer to <a href="1-1-5.md">"How</a>
       <a href="1-1-5.md">Addresses Are Processed" in topic 1.1.5</a>.
   2.  Execution of the DIAGNOSE code X'00' instruction makes a copy of the
       information shown in <a href="1-1-7.md#TBLDG00F">Table 1</a> available to your virtual machine at the
       location specified by Rx:
        _________________________________________________________________________
       | Table 1. DIAGNOSE code X'00' -- Bit Map Fields                          |
       |_____________ ______________________ ____________________________________|
       | Field       | Characteristics      | Description                        |
       |_____________|______________________|____________________________________|
       | System      | 8 bytes, EBCDIC      | Contains the name                  |
       | name, in    |                      |                                    |
       | this case,  |                      |                                    |
       | VM/ESA      |                      |                                    |
       |_____________|______________________|____________________________________|
       | Environment | 3 bytes, zeros       | Identifies the VM/ESA execution    |
       |             |                      | environment.  See <a href="1-1-7.md">2a</a> for more      |
       |             |                      | information.                       |
       |_____________|______________________|____________________________________|
       | Version     | 1 byte, hexadecimal  | The version code from the CPUID    |
       | code        |                      |                                    |
       |_____________|______________________|____________________________________|
       | MCEL        | 2 bytes, hexadecimal | VM/ESA stores zeros in the machine |
       |             |                      | check extended logout field        |
       |             |                      | (MCEL).  In a 370 virtual machine  |
       |             |                      | the MCEL length is zero.  In an    |
       |             |                      | ESA/370 or ESA/390 virtual         |
       |             |                      | machine, this field is reserved.   |
       |_____________|______________________|____________________________________|
       | Processor   | 2 bytes, hexadecimal | The address of the processor on    |
       | address     |                      | which VM/ESA is currently running  |
       |_____________|______________________|____________________________________|
       | User ID     | 8 bytes, EBCDIC      | The user ID of the virtual machine |
       |             |                      | issuing the DIAGNOSE               |
       |_____________|______________________|____________________________________|
       | Program     | 8 bytes, hexadecimal | The level of CP that is installed. |
       | product bit |                      | See <a href="1-1-7.md">2b</a> for the bit settings.       |
       | map         |                      |                                    |
       |_____________|______________________|____________________________________|
       | Time zone   | 4 bytes, hexadecimal | Represents the time zone           |
       | differential|                      | differential in seconds from       |
       |             |                      | Greenwich Mean Time (see note <a href="1-1-7.md">2c</a>   |
       |             |                      | below).                            |
       |_____________|______________________|____________________________________|
       | Release     | 4 bytes, hexadecimal | The first byte is the release      |
       | Information |                      | number, the second byte is the     |
       |             |                      | release modification level, and    |
       |             |                      | the third and fourth bytes are the |
       |             |                      | service level.                     |
       |_____________|______________________|____________________________________|
       Notes:
       a.  The VM/ESA execution environment bits contain:
               When bit 0 = 1, VM is running in a logical partition (LPAR
               mode).
               When bit 0 = 0, VM is not running in a logical partition.
               Bits 1 to 23 are reserved and are currently zeros.
       b.  The bit map contains:
             X'0000000000000000' for VM/XA SF 1
             X'4000000000000000' for VM/XA SF 2
             X'6000000000000000' for VM/XA SP 1
             X'7000000000000000' for VM/XA SP 2
             X'7800000000000000' for VM/XA SP 2 with APSS
             X'7C00000000000000' for VM/XA SP 2.1
             X'7E00000000000000' for VM/XA SP 2.1 spool file origin enhancements
             X'7F00000000000000' for VM/ESA with the ESA Feature
           To determine what VM environment you are in and what CP/CMS
           resources are available to you, use the high-order bit from this
           bit map.  Specifically, if the high-order bit is on, the
           environment is VM/370.  If the high-order bit is off, the
           environment is VM/ESA.  Do not try to get this information from
           the first five bytes returned by DIAGNOSE code X'00'.
       c.  The time zone differential is a signed hexadecimal fullword value
           in seconds.  Negative values represent differentials west of
           Greenwich Mean Time, and positive values represent differentials
           east of Greenwich Mean Time.
   3.  If VM/ESA is executing in a virtual machine, up to 40 bytes of
       extended identification data is appended to the first 40 bytes
       described above.  Up to five nested levels of VM/ESA virtual machines
       are supported by this DIAGNOSE instruction.  Thus, a maximum of 200
       bytes of data can be returned to the virtual machine that initially
       issued the DIAGNOSE instruction.
   Responses: None.
</pre>
