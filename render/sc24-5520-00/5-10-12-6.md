#### 5\.10\.12\.6 SEVER Program Exceptions

The program exceptions for SEVER are:

<a id="TBLTBLUNIQ189"></a>

```
    ________________ ________________________________________________________
   | Type           | Description                                            |
   |________________|________________________________________________________|
   | Addressing     | The parameter list address that you specified is       |
   |                | outside the virtual machine's storage.                 |
   |________________|________________________________________________________|
   | Operation      | Either an application interrupt buffer has not been    |
   |                | declared, or the invoking virtual machine is not in    |
   |                | supervisor state.                                      |
   |________________|________________________________________________________|
   | Protection     | The storage key of the specified parameter list        |
   |                | address does not match the key of the user.            |
   |________________|________________________________________________________|
   | Specification  | The parameter list is not on a doubleword boundary.    |
   |________________|________________________________________________________|
```
