## 2\.3\.11 Using Additional IUCV Functions

<a id="HDRIUCVS5"></a>

There are several IUCV functions not described in the previous sections that you may find useful\. The following list briefly describes what these functions do, when you might want to use them, and the page in the next chapter on which the function is described in detail\.

- DESCRIBE\. Use the DESCRIBE function to determine whether you have any messages pending on your send queue\. If IUCV finds a message pending, it returns information about the message in the DESCRIBE parameter list\. For more information, see ["DESCRIBE" in topic 2\.4\.4](2-4-4.md)\.

**Note:** When a virtual machine sends you a message, IUCV automatically informs you of the message by reflecting a message\-pending external interrupt to your virtual machine\. Therefore, unless you disable your virtual machine for IUCV message\-pending external interrupts, do not use the DESCRIBE function\.

- TESTCMPL\. Use the TESTCMPL function to determine whether you have any replies pending on your reply queue\. If IUCV finds a reply pending, it returns information about the message in the TESTCMPL parameter list information and removes the message from your reply queue\. For more information, see ["TESTCMPL \(Test Completion\)" in topic 2\.4\.17](2-4-17.md)\.

**Note:** When you receive a reply, IUCV automatically informs you by reflecting a message\-complete external interrupt to your virtual machine\. Therefore, unless you disable your virtual machine for IUCV message\-complete external interrupts, do not use the TESTCMPL function\.

- TESTMSG\. Use the TESTMSG function to determine whether you have any messages pending on your send queue or replies pending on your reply queue\. For more information, see ["TESTMSG \(Test Message\)" in](2-4-18.md) [topic 2\.4\.18](2-4-18.md)\.

**Note:** When you receive messages and replies, IUCV automatically informs you by reflecting a message\-pending or message\-complete external interrupt to your virtual machine\. Therefore, unless you disable your virtual machine for IUCV message\-pending and message\-complete external interrupts, do not use the TESTMSG function\.

- REJECT\. Use the REJECT function to reject a message that is sent to you\. For more information, see ["REJECT" in topic 2\.4\.9](2-4-9.md)\.
- PURGE\. Use the PURGE function to cancel a message that you have sent\. For more information, see ["PURGE" in topic 2\.4\.5](2-4-5.md)\.
- SETMASK/SETCMASK\. Use the SETMASK and SETCMASK functions to enable or disable IUCV interrupts\.

**Note:** Unless you use the SETMASK and SETCMASK functions to specify otherwise, IUCV enables your virtual machine for all IUCV interrupts\. For more information, see ["SETMASK" in topic 2\.4\.15](2-4-15.md) and ["SETCMASK" in](2-4-14.md) [topic 2\.4\.14](2-4-14.md)\.
