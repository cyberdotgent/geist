### F.1.2 APPC/VM Interrupts

APPC/VM uses external interrupts to signal certain events and can be categorized as follows: 1. Those interrupts that let applications process other paths while waiting for input or a function to complete on other paths: Message pending interrupts Connection pending interrupts Function complete interrupts Connection complete interrupts. 2. Those interrupts that asynchronously indicate your partner has issued a SENDREQ or a SEVER: Request-to-send interrupts Sever interrupts. This asynchronous capability of APPC/VM is a VM-unique asynchronous implementation; it is not based on the APPC architecture functions (POST_ON_RECEIPT, WAIT, and TEST). Programs should be written to handle request-to-send and sever interrupts at any time. APPC/VM supports some IUCV macro functions that do not correspond to any APPC function. A program that wants to avoid non-APPC functions should be enabled only for connection pending interrupts.
