#### 3.8.2.3 Optional Parameters

MF=L generates the instructions necessary to initialize the APPC/VM parameter list as specified, but does not invoke the APPCVM QRYSTATE. PATHID= specifies the path ID on which the state is to be queried. label is the relocatable label of a halfword that contains the path ID. (reg) is the register number that contains the path ID in the low-order halfword.
