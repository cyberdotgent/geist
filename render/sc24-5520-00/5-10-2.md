## 5\.10\.2 Shared Functions That Should Be Avoided in CMS

Other functions are also shared for both APPC/VM and IUCV\. These shared functions should not be used in a CMS environment because they could affect other programs in the same virtual machine; however, they can be used safely in a non\-CMS environment\.

The following table summarizes each IUCV macro function that should be avoided in a CMS environment, then points to the section that describes each function in detail\.

<a id="TBLTBLUNIQ158"></a>

```
    ______________ _______________________________________________ __________
   | Function     | Description                                   | Topic    |
   |______________|_______________________________________________|__________|
   | DCLBFR       | Declares an interrupt buffer.  (This buffer   | 5.10.6   |
   |              | can be used for both APPC/VM and IUCV         |          |
   |              | interrupts.)                                  |          |
   |______________|_______________________________________________|__________|
   | DESCRIBE     | Gives the following information:              | 5.10.7   |
   |              |                                               |          |
   |              | °   The next message pending on non-APPC      |          |
   |              |     paths                                     |          |
   |              | °   The next message pending on an APPC path  |          |
   |              |     that is in the Receive state              |          |
   |              | °   A SENDREQ on an APPC path.                |          |
   |______________|_______________________________________________|__________|
   | RTRVBFR      | Releases an interrupt buffer.  (This buffer   | 5.10.9   |
   |              | can be used for both APPC/VM and IUCV         |          |
   |              | interrupts.)                                  |          |
   |______________|_______________________________________________|__________|
   | SETMASK      | Disables and enables APPC and non-APPC        | 5.10.10  |
   |              | interrupts.                                   |          |
   |______________|_______________________________________________|__________|
   | SETCMASK     | Disables and enables APPC and non-APPC        | 5.10.11  |
   |              | control interrupts                            |          |
   |______________|_______________________________________________|__________|
   | TESTCMPL     | Determines the next APPC or non-APPC function | 5.10.13  |
   |              | that has completed                            |          |
   |______________|_______________________________________________|__________|
   | TESTMSG      | Waits for the following:                      | 5.10.14  |
   |              |                                               |          |
   |              | °   A message-pending or message-complete     |          |
   |              |     interrupt on non-APPC paths               |          |
   |              | °   A message-pending interrupt on an APPC    |          |
   |              |     path that is in the Receive state         |          |
   |              | °   A request-to-send interrupt on an APPC    |          |
   |              |     path                                      |          |
   |              | °   A function-complete interrupt on an APPC  |          |
   |              |     path.                                     |          |
   |______________|_______________________________________________|__________|
```

*VM/ESA CMS Application Development Reference for Assembler* contains more information about how to use IUCV macro functions when writing programs\.
