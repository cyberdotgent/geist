## 6.11.10 *MSG System Service

<a id="HDRMSG"></a>

The *MSG system service lets a virtual machine read messages and responses that come from CP, rather than display these on the terminal. (The texts of CP command responses and messages themselves is not part of the programming interface.) *MSG is actually the Message system service user ID. You establish communication with this user ID by specifying USERID=*MSG in conjunction with IUCV CONNECT. Your virtual machine does not need any special authorization to use the *MSG system service. All you have to do is issue the IUCV macro with the USERID=*MSG. Once you have issued these, you must specify what kind of messages you want the virtual machine to receive. *MSG handles virtual console output if the user has specified the IUCV option on the CP SET command, as shown

in Table 56.

Not [e: When](#TBLMSGSET) full-screen CMS is on, most CMS console output is not passed to CP. In addition, applications that use the IUCV *MSG system service and SET VMCONIO IUCV do not trap all CMS output. Before running such applications, it is recommended that you suspend full-screen CMS. Following is a list of CP SET commands that have IUCV options. All of them assume that you have a connection to IUCV and *MSG.

"user ID" identifies the sender. "text" is the actual data the user would have received on their terminal. For class 1 and class 2 type messages, the standard header is suppressed. If the data is not received by a MSG, WNG, SMSG, or using SCIF, the user ID is that of the recipient. If a virtual machine has both a valid path to *MSG and a secondary user specified in the CONSOLE directory control statement (enabling that virtual machine to use SCIF), incoming messages (except for SMSGs, which are not console messages) are directed to the secondary user instead of the IUCV *MSG. If the secondary user is not available, the message is queued on the *MSG path. Any output generated by the SET LOGMSG and ECHO commands is always sent to the terminal. The output is not sent over *MSG.
