### 7\.12\.1\.6 HCPRPD

HCPRPD is the diagnose processor for DIAGNOSE code X'A0'\.

CP's stub of HCPRPD contains a call to the module, HCPRPE, which handles subcodes X'00' and X'08' of DIAGNOSE code X'A0'\. Subcode X'00' retrieves the group name for a given user ID, and subcode X'08' sets the condition code to indicate whether an ESM is installed\. These subcodes are documented in the material within this book for DIAGNOSE code X'A0'\. Upon return from HCPRPE, HCPRPD stores registers 0 and 15 in the caller's 0 and 15 registers, and returns to the caller\.

The ESM's replacement modules should duplicate the call to HCPRPE for subcodes X'00' and X'08' as it appears in the stub modules so that those subcodes continue to be supported in the same way\. An ESM can provide additional functions by defining additional subcodes for DIAGNOSE code X'A0' and by handling those subcodes in HCPRPD\.

An ESM may call the CP internal module, HCPDA0, through HCPRPD to control the audit and protect attributes of CP's commands, DIAGNOSE codes, and security\-relevant system functions, and to disable the DIAL and MESSAGE commands prior to logon\.

Return is made to the calling module by the HCPEXIT [\(32\)](<#FTNEXITW>) macro, located in the HCPPSI macro library\.

*Entry Point*: HCPRPD defines only one entry point, called HCPRPDEP\.

- **HCPRPDEP**\-\-called for DIAGNOSE code X'A0'\.

`Input Registers: R5 - The address of Rx contents R6 - The address of Ry contents`

`Normal exit conditions for subcode X'00': - The input buffer contains group name - The virtual machine CC=0`

`Error exit conditions for subcode X'00': - The request failed, CC=1 - The specification exception if invalid subcode`

`Register usage: R11 - The Address of the VMDBK R12 - The Base register R13 - The Address of standard save area`

`Attributes: MP, resident, dynamic`

`Linkage: Call with a dynamic save area`

`Serialization: Master CPU only`

*Return Codes*: The return codes in Register 15 that are handled when HCPRPD returns to its caller are:
