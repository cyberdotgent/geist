#### 2.4.17.2 Identifying the Response You Want to Receive

There may be times when you want to check for a response to a specific message or type of message. To do this, you can identify the response you are looking for in any of the following ways: 1. By message identification number, path identification number, and message class. In this case, IUCV looks for a response to a specific message. 2. By path identification number and message class. IUCV looks for the first response with the correct path identification and message class. 3. By path identification number. IUCV looks for the first response with the correct path identification. 4. By message class. IUCV looks for the first response with the correct message class. If you do not identify a message, IUCV receives the first response on your reply queue. Also note that IUCV stores message identification values in the SEND parameter list. IUCV stores the message identification number in the IPMSGID field, the path identification number in the IPPATHID field, and the message class in the IPSRCCLS field.

Specifying a Message Identification Number: Specify the message identification number in one of the following ways: 1. Use the MSGID=parameter. Specify the message identifier as (a) the relocatable label of a fullword containing the message identifier, or (b) the number of a register that contains the message identifier. 2. Store the message identification number in the IPMSGID field of the TESTCMPL parameter list. Also, set the IPFGMID bit (X'04') to 1 in the IPFLAGS1 field.

**Note:** If you use the MSGID=parameter, IUCV stores the message ID and sets the IPFGMID flag automatically. Remember that whenever you specify a message identification number, you must also specify the path ID of the message and target message class.

Specifying a Path Identification Number: Specify a message's path identification number in one of the following ways: 1. Use the PATHID=parameter. Specify the path identification as (a) the relocatable label of a halfword that contains the path ID, or (b) the number of a register that contains the path ID in the low-order halfword. 2. Store the path identification number in the IPPATHID field of the TESTCMPL parameter list. Also, set the IPFGPID bit (X'02') to 1 in the IPFLAGS1 field.

**Note:** If you use the PATHID=parameter, IUCV stores the path ID and sets the IPFGPID flag automatically.

Specifying a Message Class: Specify a message class in one of the following ways: 1. Use the IPSRCCLS=parameter. Specify the message class as (a) the relocatable label of a fullword containing the message class, or (b) the number of a register containing the message class. 2. Store the message class in the IPSRCCLS field of the TESTCMPL parameter list. Also, set the IPFGMCL bit (X'01') to 1 in the IPFLAGS1 field.

**Note:** If you use the IPSRCCLS=parameter, IUCV stores the message class and sets the IPFGMCL flag automatically.
