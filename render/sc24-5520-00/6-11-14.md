## 6\.11\.14 \*SPL System Service

<a id="HDRSPL"></a>

<a id="SPTSPOO"></a>

The \*SPL system service provides an interface using IUCV for communication between CP and virtual machines that provide print services for advanced function printers, and reader services for reader notification\. When the virtual machine connects to the \*SPL system service, for printer service

<a id="SPTPRTIDN"></a>

it passes an identifier, *prtid*, which is used as the external name of that virtual machine\. When the virtual machine connects to the \*SPL system service, for reader service the IPUSER area \(the first eight bytes\) must be blank \(X'40X'\), and the ninth byte defines a flag byte \(IPUFLAG1\)\. A bit is defined in this byte \(IPRDR = X'80'\) to indicate that the connect request is for the reader notification function\.

The term *prtid* is synonymous with print server virtual machine in this document\. The virtual machine has access to the system printer spool files, but these printers, of course, are not supported directly by CP\.

Once communication between the *prtid* and the \*SPL system service has been established, a *prtid* can:

- Select a spool file from the print chain for processing
- Close a selected file
- Send messages or command responses to the operator or other users
- Read the spool file descriptor \(SFBLOK\) [\(26\)](<#FTN1>)\.
- Read the spool file records \(SPLINKs\) [\(27\)](<#FTN2>)\.
- Read an external attribute buffer \(XAB\) [\(28\)](<#FTN3>)\.

Similarly, the \*SPL system service communicates with the *prtid* and can:

- Send commands to the *prtid*
- Notify the *prtid* that a print file is available for processing
- Cancel processing on a print file \(PURGE function\)\.

The pages that follow describe each of these communication functions in more detail\.

<a id="FTN1"></a>

\(26\) For more information about SFBLOK, refer to [Appendix E,](e-0.md) ["Data Areas Used by DIAGNOSE Codes" in topic E\.0](e-0.md)\.

<a id="FTN2"></a>

\(27\) For more information about SPLINK, refer to [Appendix E,](e-0.md) ["Data Areas Used by DIAGNOSE Codes" in topic E\.0](e-0.md)\.

<a id="FTN3"></a>

\(28\) The external attribute buffer \(XAB\) is a control block that contains data the user creates to specify additional information about a print file\. Each print file has its own XAB, and CP has the facilities to maintain the XABs\. For more information about XABs, refer to topic [D\.0](d-0.md)\.
