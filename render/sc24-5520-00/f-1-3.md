### F.1.3 APPC/VM Conversation States

APPC/VM defines several states that a program can be in during a conversation. Most of these are based on states defined by APPC. The following table lists the conversation states for APPC and the APPC/VM counterparts. (Note that several APPC/VM states do not map to an APPC state.)

<a id="TBLTBLUNIQ222"></a>

| APPC State | APPC/VM Implementation |
| --- | --- |
| Backout Required | Backout_Received<br>Backout_Required |
| Confirm | Confirm |
| Confirm Send | Confirm |
| Confirm Deallocate | Confirm |
| Deallocate | Sever |
| Defer Receive | Defer_Receive |
| Defer Deallocate | Defer_Sever |
| Receive | Receive |
| Sync-Point | Prepare_Received<br>or<br>Unsolicited_Request_Commit_Received<br>(if the sync-point control modifier is<br>request send.) |
| Sync-Point Send | Prepare_Received<br>or<br>Unsolicited_Request_Commit_Received<br>(if the sync-point control modifier is<br>request receive.) |
| Sync-Point | Prepare_Received |
| Deallocate | or<br>Unsolicited_Request_Commit_Received<br>(if the sync-point control modifier is<br>request sever) |
| N/A | Committed_Received |
| N/A | Connect |
