#### 3.8.8.3 Optional Parameters

MF=L generates the instructions necessary to initialize the APPC/VM parameter list as specified, but does not invoke the APPCVM SENDREQ. PATHID= specifies the path ID on which to send the request. label is the relocatable label of a halfword that contains the path ID. (reg) is the register number that contains the path ID in the low-order halfword.
