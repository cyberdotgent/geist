#### 2\.3\.3\.1 IUCV Messages

To use IUCV, you and the virtual machine users with whom you use IUCV to communicate must code application programs that invoke the IUCV macro\. By specifying one of eighteen IUCV functions \(one of which is the SEND function\) on the IUCV macro, you tell IUCV what to do\. As mentioned at the beginning of the chapter, IUCV is a facility that enables a virtual machine to communicate with other virtual machines, CP system services, and with itself\. An IUCV communication is called a **message**\. An IUCV message is created when an application program running in a virtual machine specifies the SEND function on the IUCV macro\.

The virtual machine that invokes the SEND function is called the **source** virtual machine\. The message travels to the **target** virtual machine over a predefined linkage called a **path**\. [Figure 8](2-3-3-1.md#FIGC92FIGZ) illustrates how a simple IUCV communication takes place\.

<a id="FIGC92FIGZ"></a>

```
    ________________________________________________________________________ 
   |                                                                        |
   |                                                                        |
   |    Source Virtual Machine                Target Virtual Machine        |
   |                                                                        |
   |    The source virtual machine                                          |
   |    invokes the IUCV macro,                                             |
   |    creating a message that                                             |
   |    IUCV sends over a path.  ---PATH--->  to the target virtual machine.|
   |                                                                        |
   |                                                                        |
   |________________________________________________________________________|
```
