## 6.11.1 What Are CP System Services

<a id="HDRSYS"></a>

CP system services are features of VM/ESA that let IUCV interface with CP. With CP system services, you have a virtual machine-to-CP IUCV interface. This interface lets a virtual machine use the CP system functions.
