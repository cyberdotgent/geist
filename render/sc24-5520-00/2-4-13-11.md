#### 2.4.13.11 Program Exceptions

The following program exceptions can occur if you invoke the SEND function incorrectly: Specification. You did not define your parameter list on a doubleword boundary. Operation. IUCV is inactive; you have not used the DCLBFR function to declare an external interrupt buffer.
