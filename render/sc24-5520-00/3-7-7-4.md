### 3\.7\.7\.4 Currently\-Defined Sense Code

The sense code you can get in an APPCVM program is X'0824' for a BACKOUT APPC error condition\. Refer to the *SNA Transaction Programmer*, for a description of this condition\.

*VM/ESA CMS Application Development Guide for Assembler* contains programming information, scenarios, and sample programs that illustrate how to write APPC/VM programs using these APPCVM macro functions\.
