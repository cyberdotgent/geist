## 3.8.9 APPCVM SETMODFY

<a id="HDRAPSETMO"></a>

sync-point control modifier specifies the state to occur after a subsequent sync-point completes.

**Note:** If SETMODFY is not issued, a program is in the Send state when the sync-point completes.
