#### 2.4.7.5 QUIESCE Parameter List Output Fields

IPRCODE contains one of the following return codes:

**Code** **Meaning** 00 Normal return.

01 You specified an invalid path identification number. 31 An IUCV function was specified on an APPC/VM path. 48 The CP system service you specified does not support the IUCV function.
