## 2.3.10 Permanently Ending IUCV Communications

<a id="HDRIUCVS4B"></a>

To permanently end all IUCV functions, use the RTRVBFR function to terminate all messages and to sever all paths. Additionally, you may want to release the free storage you were using as an external interrupt buffer. Finally, you may want to reset the bits you set when you enabled your virtual machine to handle external interrupts. To do this, you must: 1. Set bit 30 to 0 in control register zero 2. Set the external interrupt bit (normally bit 7 in the PSW) to 0.

**Note:** Resetting PSW bit 7 disables your virtual machine from handling all external interrupts, not just IUCV interrupts. Therefore, you should not reset PSW bit 7 if you want your virtual machine to handle external interrupts other than IUCV interrupts.
