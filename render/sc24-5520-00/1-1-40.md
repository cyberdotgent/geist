## 1\.1\.40 Diagnose Code X'B4'\-\-Reading, Writing, and Erasing the Virtual Printer Extended Attribute Buffer

**Privilege Class:** Any

Use DIAGNOSE code X'B4' to read, write, and erase the extended attribute buffer \(XAB\) for a virtual printer\. A copy of this extended attribute buffer is added to each spool file created on the device\. Specific information about the XAB may be found in [Appendix D, "External Attribute](d-0.md) [Buffer \(XAB\)" in topic D\.0](d-0.md)\.

**Entry Values:**

<a id="TBLTBLUNIQ32"></a>

```
    ___________________________ _____________________________________________
   | Rx, bytes 0 through 3:    | The buffer address                          |
   |___________________________|_____________________________________________|
   | Ry, bytes 0 through 1:    | The length of the buffer in bytes (0=ERASE) |
   |___________________________|_____________________________________________|
   | Ry, bytes 2 through 3:    | The virtual printer address                 |
   |___________________________|_____________________________________________|
   | Ry+1, bytes 2 through 3:  | Subcode X'0000' (Read) or X'0004'           |
   |                           | (Write/Erase)                               |
   |___________________________|_____________________________________________|
```

**Exit Values:**

`READ - Subcode X'0000'` CC=0 \- Successful

<a id="TBLTBLUNIQ33"></a>

```
    _________________________ _______________________________________________
   | Ry, bytes 0 through 1   | The length of the XAB read, 0 if there is no  |
   |                         | XAB                                           |
   |_________________________|_______________________________________________|
   | Ry+1, byte 0            | X'00'                                         |
   |_________________________|_______________________________________________|
```

`READ - Subcode X'0000'` CC=2 \- Unsuccessful

<a id="TBLTBLUNIQ34"></a>

```
    _________________________ _______________________________________________
   | Ry, bytes 0 through 1   | The length of the XAB if it is too large for  |
   |                         | the buffer                                    |
   |_________________________|_______________________________________________|
   | Ry+1, byte 0            | The return code; see Table 29 in              |
   |                         | topic 1.1.40.                                 |
   |_________________________|_______________________________________________|
```

`WRITE/ERASE - Subcode X'0004'` CC=0: Successful

<a id="TBLTBLUNIQ35"></a>

```
    _________________________ _______________________________________________
   | Ry+1, byte 0            | X'00'                                         |
   |_________________________|_______________________________________________|
```

`WRITE/ERASE - Subcode X'0004'` CC=2: Unsuccessful

<a id="TBLTBLUNIQ36"></a>

```
    _________________________ _______________________________________________
   | Ry+1, byte 0            | The return code; see Table 29 in              |
   |                         | topic 1.1.40.                                 |
   |_________________________|_______________________________________________|
```

**Responses:**

**Exit Normal:** The condition code for a normal exit is 0, indicating that the reading, writing, or erasing of the XAB was successful\.

**Exit Error:** The condition code for an error exit is 2, indicating that the reading, writing, or erasing of the XAB was unsuccessful\. The return code is shown in [Table 29](<#TBLB4ERR>)\.

<a id="TBLB4ERR"></a>

```
    _________________________________________________________________________
   | Table 29. DIAGNOSE Code X'B4' Meanings for Return Codes                 |
   |______________________ __________________________________________________|
   | Return Code          |                                                  |
   | in Ry+1              | Meaning                                          |
   |______________________|__________________________________________________|
   | X'04'                | The device is not valid.                         |
   |______________________|__________________________________________________|
   | X'08'                | The buffer is too small.  (returned for READ,    |
   |                      | subcode X'0000', only).                          |
   |______________________|__________________________________________________|
   | X'0C'                | The user buffer length is invalid.               |
   |______________________|__________________________________________________|
   | X'14'                | CP I/O error                                     |
   |______________________|__________________________________________________|
   | X'1C'                | Invalid subcode                                  |
   |______________________|__________________________________________________|
   | X'20'                | The user buffer address is invalid.              |
   |______________________|__________________________________________________|
   | X'24'                | Not used                                         |
   |______________________|__________________________________________________|
   | X'28'                | No XAB is to be erased (returned for             |
   |                      | Write/Erase, subcode X'0004', only).             |
   |______________________|__________________________________________________|
```

*Program Check Errors*: You may receive one of the program checks shown in [Table 30](<#TBLB4PCE>) if the DIAGNOSE code X'B4' input is invalid\.

<a id="TBLB4PCE"></a>

```
    _________________________________________________________________________
   | Table 30. Program Checks Encountered for Invalid Input to DIAGNOSE Code |
   |           X'B4'                                                         |
   |_____________________________________ ___________________________________|
   | Problem Encountered                 | Cause                             |
   |_____________________________________|___________________________________|
   | Protection exception                | For subcode X'0000', the buffer   |
   |                                     | is in write-protected storage.    |
   |                                     |                                   |
   |                                     | For subcode X'0004', the buffer   |
   |                                     | is in fetch-protected storage.    |
   |_____________________________________|___________________________________|
   | Specification exception             | Ry = R15                          |
   |_____________________________________|___________________________________|
   | Addressing exception                | The buffer address is outside the |
   |                                     | range of user storage.            |
   |_____________________________________|___________________________________|
```
