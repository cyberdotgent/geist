## 1.1.40 Diagnose Code X'B4'--Reading, Writing, and Erasing the Virtual Printer Extended Attribute Buffer

**Privilege** **Class:** Any Use DIAGNOSE code X'B4' to read, write, and erase the extended attribute buffer (XAB) for a virtual printer. A copy of this extended attribute buffer is added to each spool file created on the device.
