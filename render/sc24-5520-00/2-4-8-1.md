#### 2\.4\.8\.1 RECEIVE Required Input

1\. *The address of the RECEIVE parameter list*\. Use the PRMLIST=parameter to identify to IUCV the address of your parameter list\. The address of the parameter list must be a guest real address \(an address that is real to your virtual machine\), and it must be on a doubleword boundary\.

Specify the address of the parameter list as \(a\) a relocatable label, or \(b\) the number of a register that contains the address\.

2\. *The address of the buffer area into which IUCV places the data you are receiving*\. Do this in one of the following ways:

a\. Use the BUFFER=parameter\. Specify the buffer as \(1\) the relocatable label of the buffer, or \(2\) the number of a register that contains the address of the buffer\.

b\. Store the address of the buffer in the IPBFADR1 field of the RECEIVE parameter list\.

**Note:** If you use the BUFFER=parameter, IUCV stores this value automatically\.

3\. *The length of the buffer area into which IUCV places the data you are receiving*\. If you did not specify BUFLIST=YES, the BUFLEN=operand specifies the length of the area specified on the BUFFER=parameter\.

If you specify BUFLIST=YES, you must specify with the BUFLEN=operand the sum of the individual buffer lengths in the list pointed to by the BUFFER=operand\.

Specify the buffer length in one of the following ways:

a\. Use the BUFLEN=parameter\. Specify the length as \(1\) the relocatable label of the location containing the buffer length, or \(2\) the number of a register that contains the length of the buffer\. IUCV assumes a halfword value for the length at the storage location specified, or in the low\-order halfword of the register specified\. If a length modifier of 4 is used, IUCV uses the fullword value for the length at the storage location or in the register specified\.

b\. Store the length of the buffer in the IPBFLN1 field of the RECEIVE parameter list\.

**Note:** If you use the BUFLEN=parameter, IUCV stores this value automatically\.

4\. *The identification of the message*\. This is required only if you are receiving the remainder of a message or if you want to receive a particular message\. If you do not specify the message identification, IUCV receives the first message on the SEND queue that was not partially received\. For information on how to identify messages, see the next section\.
