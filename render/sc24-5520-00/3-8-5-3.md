#### 3\.8\.5\.3 Optional Parameters

`MF=L` generates the instructions necessary to initialize the APPC/VM parameter list as specified, but does not invoke the APPCVM SENDCNFD\.

`PATHID=` identifies the path on which to send the confirmation\.

*label* is the relocatable label of a halfword that contains the path ID\.

`(`*reg*`)` is the register number that contains the path ID in the low\-order halfword\.
