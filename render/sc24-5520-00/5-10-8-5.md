#### 5\.10\.8\.5 QUERY Program Exception

The program exception for QUERY is:

<a id="TBLTBLUNIQ176"></a>

```
    ________________ ________________________________________________________
   | Type           | Description                                            |
   |________________|________________________________________________________|
   | Operation      | The invoking virtual machine is not in the supervisor  |
   |                | state.                                                 |
   |________________|________________________________________________________|
   | Specification  | The parameter list is not doubleword aligned.          |
   |________________|________________________________________________________|
   | Addressing     | The parameter list is outside the virtual machine      |
   |                | storage.                                               |
   |________________|________________________________________________________|
   | Protection     | The parameter list storage area key does not match the |
   |                | user's key.                                            |
   |________________|________________________________________________________|
```
