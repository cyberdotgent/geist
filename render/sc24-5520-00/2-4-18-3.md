#### 2\.4\.18\.3 Program Exceptions

An operation program exception can occur if you invoke the TESTMSG function incorrectly, for the following:

- Your virtual machine was not in supervisor state\.
- IUCV is inactive; you have not used the DCLBFR function to declare an external interrupt buffer\.
