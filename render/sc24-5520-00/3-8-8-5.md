IPP**ATHID** contains the path ID on which the function is complete. IPT**YPE co**ntains the function complete interrupt code (IPTYPFCA, X'87'). IPS**ENDOP** contains the SEND option code: IPREQSND (X'07') The SENDREQ is being completed. IPS**TATE** contains one of the following values for the path's state: IPSENDST (X'03') The path is in the Send state. IPRECVST (X'04') The path is in the Receive state. IPCONFRM (X'05') The path is in the Confirm state.
