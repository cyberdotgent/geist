## 1.1.25 Diagnose Code X'60'--Determine Virtual Machine Storage Size

**Privilege** **Class:** Any Use DIAGNOSE code X'60' to determine your virtual machine's storage size.

**Entry** **Values:**

You must specify a register number for Rx.

**Exit** **Values:**

On return, the register specified as Rx contains the virtual machine storage size, in bytes. **Usage** **Notes:** None. **Responses:** None.
