#### 5\.10\.8\.6 QUERY Output Parameter List

The IUCV QUERY output parameter list has the output format shown in [Figure 65](5-10-8-6.md#FIGQUOPL)\.

<a id="FIGQUOPL"></a>

```
      IPARML DSECT

      0      1      2         3        4       5       6       7
      ________________________________________________________________ 
    0| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
    8| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
   10| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
   18| ////////////////////////////////////////////////////////////// |
     |_________________________________ ______________________________|
   20|           IPBFLN2F              | //////////////////////////// |
     |_________________________________|______________________________|
```

*Figure 65\. IUCV QUERY Output Parameter List \(Function Complete Interrupt\)*

`IPBFLN2F` contains the maximum length of data that can be reflected in the interrupt buffer extension\.

**Note:** If no input parameter list has been defined, there will not be an output parameter list\.
