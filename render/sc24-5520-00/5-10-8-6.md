#### 5.10.8.6 QUERY Output Parameter List

The IUCV QUERY output parameter list has the output format shown in

[FIGQUOPL](#FIGQUOPL) Figure 65.

<a id="QUOPL IPARML DSECT 0 1 2 3 4 5 6 7 0 ////////////////////////////////////////////////////////////// 8 ////////////////////////////////////////////////////////////// 10 ////////////////////////////////////////////////////////////// 18 ////////////////////////////////////////////////////////////// 20 IPBFLN2F //////////////////////////// Figure 65. IUCV QUERY Output Parameter List (Function Complete Interrupt)"></a>

IPBFLN2F contains the maximum length of data that can be reflected in the interrupt buffer extension.

**Note:** If no input parameter list has been defined, there will not be an output parameter list.
