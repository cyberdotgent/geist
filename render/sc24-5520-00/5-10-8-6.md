#### 5.10.8.6 QUERY Output Parameter List

The IUCV QUERY output parameter list has the output format shown in

Figure 65.

<a id="QUOPL"></a>

```text
    ________________________________________________________________ 
   |________________________________________________________________|
   |________________________________________________________________|
   |________________________________________________________________|
   |________________________________________________________________|
   |________________________________________________________________|
   |      Figure 65. IUCV QUERY Output Parameter List (Function Complete Interrupt)   |
```

[IPBFLN2F](5-10-8-6.md#QUOPL) contains the maximum length of data that can be reflected in the interrupt buffer extension.

**Note:** If no input parameter list has been defined, there will not be an output parameter list.
