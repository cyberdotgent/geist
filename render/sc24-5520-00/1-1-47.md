## 1.1.47 Diagnose Code X'D8'--Read Spool File Blocks on the System Spool File Queues

**Privilege** **Class:** D Use DIAGNOSE Code X'D8' to read information from the spool file descriptor

block of any file in the system. This diagnose code allows a program to request the first or next spool file block on the specified queue: reader, printer, or punch. Either files for a particular user, or any file within the system, can be specified. The descriptor block information is returned in either DIAGNOSE code X'14' compatibility (old) format, SFBLOKs, or in VM/ESA format, SPFBKs. **Entry** **values**: Rx Points to the parameter list, DD8PARM0. DD8PARM0 COPY is provided in the HCPGPI macro library. DD8PARM0 DSECT 0 DD8PSPID DD8PCODE 4 DD8PBUF 8 DD8PUSER 10 DD8PTYPE DD8PSIZE DD8PCLFG 14 DD8PRSVD where: DD8PSPID is the spool file ID of the previous file when reading the "next" file. It is zero if the first file is to be read. DD8PCODE X'0000' Return SFBLOK format (see [Appendix E, "Data Areas Used by](e-0.md) [DIAGNOSE Codes" in topic E.0](e-0.md) X'0004' Return SPFBK format (see [Appendix E, "Data Areas Used by](e-0.md) [DIAGNOSE Codes" in topic E.0](e-0.md) DD8PBUF is the address of guest real storage buffer. This must be doubleword-aligned, and cannot cross a page boundary. DD8PUSER is the owner of the file if the selection is by the user. This field must be either zero or blank when requesting the first file on a queue. DD8PTYPE is the queue to be searched: X'80' Printer files X'40' Punch files X'20' Reader files DD8PSIZE is the size of the user buffer in double words. If zero, the first 20 doublewords are returned. DD8PCFLG means choose system or individual user files. X'00' Get the next file for the user. X'80' Get the next file regardless of the user. DD8PRSVD is reserved for IBM use and must be zero. **Return** **values**: **PSW** **Condition**

**Code** **Meaning** 0 Successful completion; the spool file block has been copied to the

user's buffer. 1 No files are available after the input file. 2 The starting file is not found. **Errors:** You may receive one of the following program checks if the DIAGNOSE code X'D8' input data is invalid:

| Encountered | Cause |
| --- | --- |
| Addressing exception | The parameter list or buffer is not within |
| exception | D privileges.<br>The buffer is store-protected. |
| Specification exception | Any of the following:<br>The parameter list or buffer is not<br>doubleword-aligned.<br>The parameter list or buffer crosses a<br>page boundary.<br>The reserved fields are not set to zeros.<br>The register specified for Rx is the same<br>as that for Ry.<br>The subfunction code is not defined.<br>The spool file ID is specified without<br>the corresponding user ID. |
