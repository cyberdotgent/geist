## 6\.11\.5 \*IDENT System Service

<a id="HDRIDENSS"></a>

<a id="SPTIDNT"></a>

The \*IDENT \(Identify\) system service is a CP system service, known as \*IDENT, that lets authorized virtual machines connect to it and identify themselves as resource or gateway managers\. The \*IDENT system service also lets authorized virtual machines revoke ownership of a resource or gateway\.

The \*IDENT system service maintains a local system resource/gateway table of all resources and gateways managed on that system\. A virtual machine manages a resource or gateway only while it is connected to \*IDENT\.
