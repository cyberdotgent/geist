#### 2\.4\.3\.1 DCLBFR Required Input

1\. *The address of the DCLBFR parameter list*\. Use the PRMLIST=parameter to identify to IUCV the address of your parameter list\. The address of the parameter list must be a guest real address \(an address that is real to your virtual machine\), and it must be on a doubleword boundary\.

Specify the address of the parameter list as \(a\) a relocatable label, or \(b\) the number of a register that contains the address\.

2\. *The address of your external interrupt buffer*\. Specify the address of your external interrupt buffer in one of the following ways:

a\. Use the BUFFER=parameter\. Specify the address of your external interrupt buffer as \(1\) the relocatable label of the buffer, or \(2\) the number of a register that contains the address of the buffer\.

b\. Store the address of your external interrupt buffer in the IPBFADR1 field of the DCLBFR parameter list\.

**Note:** If you use the BUFFER=parameter, IUCV stores this value automatically\.
