#### 2\.4\.14\.3 SETCMASK Parameter List Format

The format of the SETCMASK parameter list is:

<a id="FIGFIGUNIQ79"></a>

```
      IPARML DSECT

      0      1        2         3         4         5         6       7
      ______________ _____________________________________________________ 
    0| IPCMASK      |/////////////////////////////////////////////////////|
     |______________|_____________________________________________________|
    8| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   10| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   18| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   20| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
```
