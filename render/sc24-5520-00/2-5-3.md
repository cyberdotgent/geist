## 2.5.3 Sever, Quiesce, and Resume (Types X'03', X'04', and X'05') Interrupts

Sever interrupts (type X'03') tell you that IUCV has severed a path. Quiesce interrupts (type X'04') and resume interrupts (type X'05') tell you that IUCV has quiesced or reactivated a path. IUCV generates these interrupts for your information; you do not need to respond.

External Interrupt Buffer Format: The format of the data in the external interrupt buffer is:

<a id="FIGUNIQ89 IPARML DSECT 0 1 2 3 4 5 6 7"></a>

0 IPPATHID /////// IPTYPE /////////////////////////////// 8 ////////////////////////////////////////////////////////////////// 10 IPUSER 18 20 ////////////////////////////////////////////////////////////////// Figure 19. IUCV SEVER, QUIESCE, RESUME External Interrupt Format

IPPATHID contains the path identification number of the path associated with this interrupt. IPTYPE contains one of the following interrupt types: Type **M**ean**ing** X'03' The path has been severed. X'04' The path has been quiesced. X'05' The path has been resumed. IPUSER contains an optional 16 bytes of data specified by the user who severs, quiesces, or resumes the path.
