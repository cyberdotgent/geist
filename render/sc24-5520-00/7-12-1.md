## 7\.12\.1 Access Control Interface

The ***access control interface*** \(ACI\) is a group of modules that mediates between CP and the external security manager \(ESM\)\. An ESM is a service virtual machine that runs outside the primary operating system helping to maintain the latter's security and integrity\. This service virtual machine could be RACF, for example\. Three modules \(HCPRPW, HCPRPI, and HCPRPD\) make up the access control interface\. These modules exist in CP as stub modules and are replaced by an ESM when installed\. In VM/ESA the module, HCPRWA, contains a non\-executable, empty entry point, HCPRWACP, in CP\. This module has no function until RACF or another service virtual machine, overlays it with its own copy\. The following topics are discussed in this chapter:

- Audit and Protect Attributes
- ACIPARMS Control Block
- HCPRPI
- HCPRPW
- HCPRPD
- HCPRWA\.
