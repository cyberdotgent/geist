#### 5\.10\.13\.3 Optional Parameters

`MF=L` expands the IUCV macro to generate the instructions necessary to initialize the parameter list as specified, but not to invoke the TESTCMPL function\.

`PATHID=` identifies the path ID to do the test completion\.

*label* is the relocatable label of a halfword that contains the path ID\.

`(`*reg*`)` is the register number that contains the path ID in the low\-order halfword\.
