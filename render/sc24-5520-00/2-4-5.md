## 2.4.5 PURGE

<a id="HDRPURGE"></a>

you purge a message, one of the following actions takes place: If you purge a message before (1) the target virtual machine describes it (uses the DESCRIBE function to obtain information) or (2) receives a message pending interrupt, the target virtual machine is never aware that you sent the message. If you purge a message after the target virtual machine has described it, but before the target has received or replied to it, IUCV destroys the message and notifies the target that the message has been purged when the target issues the RECEIVE or REPLY function. If you purge a message that is already on your reply queue (the target has received it and, if the message was a 2-way message, replied to it), IUCV immediately deletes the message from your reply queue, thus terminating the message.
