## 1\.1\.36 Diagnose Code X'A0'\-\-Obtain ACI Groupname

**Privilege Class:** Any

Use DIAGNOSE X'A0' to obtain the user ID and groupname of an access control interface \(ACI\), if one is installed\.

**Entry Values:**

Rx Contains the address of two doublewords\. For subcode 0, Rx contains the guest real address of a 16\-byte doubleword aligned buffer\. The first eight bytes of this buffer contains a user ID \(left justified, followed by spaces\) passed as input\. The second eight bytes are used by CP to pass the groupname back to the guest\. For subcode 8, Rx is not used\.

Ry Contains a right\-adjusted subcode value:

- 0 to request the return of the groupname associated with the input user ID
- 8 to request a test to determine if an access control interface is installed\.

**Exit Values:**

EXIT NORMAL

Rx Unchanged

Ry Unchanged

- For subcode 0, the guest condition code is set to 0 on a successful request\.
- For subcode 8, the guest condition code is set to 0 if the ACI program has been installed, or to 1 if it has not been installed\.

EXIT ERROR

Rx Unchanged

Ry Unchanged\.

- For subcode 0, the user ID that was specified is invalid\.
