#### 2\.3\.8\.4 Two\-Way Messages with Data in a Buffer

[Figure 14](2-3-8-4.md#FIGC92FIG6) shows the events that take place when SOURCE sends TARGET a 2\-way message where the message data is stored in a storage buffer, rather than the SEND parameter list\.

<a id="FIGC92FIG6"></a>

```
    ________________________________________________________________________ 
   |                                                                        |
   | SOURCE's Virtual Machine               TARGET's Virtual Machine        |
   |                                                                        |
   | SOURCE uses the SEND function                                          |
   | to send a message to TARGET                                            |
   | specifying that (a) the                                                |
   | message data is contained in                                           |
   | a storage buffer, (b) the                                              |
   | message is a 2_way, and                                                |
   | (c) where the reply data is                                            |
   | to be stored.             _______→  TARGET gets a "message pending"    |
   |                                     interrupt from IUCV.  The data     |
   |                                     in the external interrupt buffer   |
   |                                     informs TARGET that (a) the        |
   |                                     message is a 2_way message,        |
   |                                     (b) SOURCE is sending message data |
   |                                     from a storage buffer, and (c)     |
   |                                     where the reply data is to be      |
   |                                     stored.                            |
   |                                                    |                   |
   |                                                    ↓                   |
   |                                     TARGET issues the RECEIVE          |
   |                                     function, causing IUCV to move     |
   |                                     the message data from SOURCE's     |
   |                                     storage buffer to TARGET's         |
   |                                     storage buffer.                    |
   |                                                    |                   |
   |                                                    ↓                   |
   |                                     TARGET issues the REPLY            |
   |                                     function to respond to SOURCE's    |
   | SOURCE gets a "message    ←________ message, causing IUCV to move      |
   | complete" interrupt from            the REPLY data from the target's   |
   | IUCV that describes                 storage buffer to the source's     |
   | TARGET's response.                  storage buffer.                    |
   |                                                                        |
   |________________________________________________________________________|
```
