## 3.7.7.1 Currently-Defined APPC/VM Sever Codes

<a id="HDRCDSV"></a>

[Table 48](#TBLALLSEV) lists all the APPC/VM sever codes that your application program can get at the current time. Sever codes can come from your communications partner, from your VM system, or from an intermediate communications server. Note that these sever codes can come from VTAM or other SNA network components. (The sever codes that are generated by VM are listed in [Table 49 in topic 3.7.7.2](#TBLVMSVAPC) and are a subset of those listed in [Table 48](#TBLALLSEV).) The corresponding APPC error condition is given for each APPC/VM sever code; refer to the SNA Transaction Programmer for a description of each APPC error condition.

<a id="ALLSEV"></a>

Table 48. Possible APPC/VM Sever Codes

| APPC/VM Sever<br>Code | APPC Error Condition |
| --- | --- |
| X'0301'<br>X'0302' | Invalid LU name<br>Invalid mode name<br>ALLOCATION_FAILURE_RETRY |


X'0610' corresponds to RESOURCE_FAILURE_NO_RETRY.
