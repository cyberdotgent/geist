#### 5\.10\.4\.5 ACCEPT Input Parameter List

<a id="HDRACCPL"></a>

The IUCV ACCEPT parameter list has the input format shown in [Figure 59](5-10-4-5.md#FIGACCIPL) when accepting a connection on an APPC path:

<a id="FIGACCIPL"></a>

```
      IPARML DSECT

      0      1      2        3        4       5      6        7
      ______________ ________________________________ ________ _______ 
    0|   IPPATHID   | ////////////////////////////// |IPFLAGS2| ///// |
     |______________|_________________ ______________|________|_______|
    8| ////////////////////////////// |           IPBFADR1            |
     |________________________________|_______________________________|
   10|           IPBFLN1F             | ///////////////////////////// |
     |________________________________|_______________________________|
   18| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
   20| ////////////////////////////////////////////////////////////// |
     |________________________________________________________________|
```

*Figure 59\. IUCV ACCEPT Input Parameter List*

`IPPATHID` is the path ID on which to accept the connection\.

`IPFLAGS2` contains one of the following input bit flags:

`IPCOMSRV (X'20')` the connection is being accepted on behalf of another user\.

`IPLOGDOK (X'04')` the accepting program is specifying LOGDATA=YES\.

`IPBFADR1` specifies the address of the connection complete extended data\.

`IPBFLN1F` specifies the length of the connection complete extended data\.
