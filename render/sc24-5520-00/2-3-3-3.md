#### 2.3.3.3 IUCV External Interrupts

To pass information from one virtual machine to another, IUCV generates external interrupts. For example, assume you want to establish a path to another virtual machine. To do this, you invoke the CONNECT function, storing input into the CONNECT parameter list. IUCV, in turn, generates an external interrupt at your intended partner's virtual machine. IUCV also stores information that describes the interrupt in your intended partner's external interrupt buffer. You can use IUCV functions (SETMASK and SETCMASK) to enable or disable your virtual machine for these interrupts. The application programs you code must include external interrupt handlers for those that are not disabled. For more information on IUCV external interrupts, see ["Handling](2-3-12.md) [External Interrupts" in topic 2.3.12](2-3-12.md).
