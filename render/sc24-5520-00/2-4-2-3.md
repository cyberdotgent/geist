#### 2\.4\.2\.3 CONNECT Parameter List Format

The format of the CONNECT parameter list is:

<a id="FIGFIGUNIQ55"></a>

```
      IPARML DSECT

      0      1        2         3         4      5      6        7
      ______________ _________ _________ _________________________________ 
    0|   IPPATHID   |IPFLAGS1 |IPRCODE  |    IPMSGLIM     /////////////// |
     |______________|_________|_________|_________________________________|
    8|                               IPVMID                               |
     |____________________________________________________________________|
   10|                                                                    |
     |                               IPUSER                               |
     |                                                                    |
     |____________________________________________________________________|
   20| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
```
