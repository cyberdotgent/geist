## 3\.8\.2 APPCVM QRYSTATE \(Query State\)

<a id="HDRAPQST"></a>

The QRYSTATE function gets the current state of any APPC/VM path on the issuing virtual machine\.

**Note:** This is issued only by the CMS Protected Conversation Adapter \(PCA\)\.
