#### 5.10.8.4 QUERY Condition Codes

<a id="TBLTBLUNIQ175"></a>

| CC=0 | CC=1 | CC=2 |
| --- | --- | --- |
| X | Not Possible | X |


**CC=0** QUERY completed with no errors. **CC=2** the user ID issuing the IUCV QUERY was not found in the CP directory. **CC=3** CP found errors when reading the CP user directory.
