#### 2.4.2.6 CONNECT Condition Codes

**Code** **Meaning**

0 Normal completion. IUCV has reflected an external interrupt to notify the virtual machine with which you are communicating that you have issued the CONNECT function. 1 IUCV stored a nonzero return code at IPRCODE.
