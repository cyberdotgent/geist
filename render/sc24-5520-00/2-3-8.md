## 2.3.8 Passing Data

<a id="HDRIUCVS3"></a>

While there is only one IUCV function for sending messages (the SEND function), an IUCV message can be one of several types, depending on such things as: Whether the message requires a response from the target virtual machine. (A message that requires a response is called a 2-way message. A message that doesn't require a response is a 1-way message.) Whether the source virtual machine stores the data to be sent in the SEND parameter list or in a storage buffer. Whether the message is a priority or non-priority message. The following sections provide an overview of how to send the basic types of IUCV messages: One-way messages with data in a parameter list One-way messages with data in a buffer Two-way messages with data in a parameter list Two-way messages with data in a buffer. **Notes:** 1. In all of the following examples, SOURCE is the sender of the message; TARGET is the receiver of the message. 2. For a complete description of the IUCV functions listed below, including details about available options, see: ["SEND" in topic 2.4.13](2-4-13.md) ["RECEIVE" in topic 2.4.8](2-4-8.md) ["REPLY" in topic 2.4.10](2-4-10.md).
