#### 3\.8\.4\.1 Format

```
    _________ ___________ ___________________________________________________
   |         |           |                                                   |
   | [label] | APPCVM    | SENDCNF     ,PRMLIST= {label}                     |
   |         |           |                       {(reg)}                     |
   |         |           |                                                   |
   |         |           |             ,TYPE=  {NORMAL  }                    |
   |         |           |                     {SEVER   }                    |
   |         |           |                     {PREPRECV}                    |
   |         |           |                                                   |
   |         |           |                                                   |
   |         |           |                                                   |
   |         |           |            |,MF=L|                                |
   |         |           |            |     |                                |
   |         |           |                                                   |
   |         |           |            |,PATHID=  {label}|                    |
   |         |           |            |          {(reg)}|                    |
   |         |           |            |                 |                    |
   |         |           |                                                   |
   |         |           |            |,WAIT=  {YES}|                        |
   |         |           |            |        {NO }|                        |
   |         |           |            |             |                        |
   |         |           |                                                   |
   |         |           |                                                   |
   |_________|___________|___________________________________________________|
```
