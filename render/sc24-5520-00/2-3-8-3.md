#### 2\.3\.8\.3 Two\-Way Messages with Data in a Parameter List

[Figure 13](2-3-8-3.md#FIGC92FIG5) shows the events that take place when SOURCE sends TARGET a two\-way message, where the message data is stored in the SEND parameter list\. Again, note that before SOURCE sends message data from within the SEND parameter list, SOURCE and TARGET must establish a path that can handle data sent from within a parameter list\.

<a id="FIGC92FIG5"></a>

```
    ________________________________________________________________________ 
   |                                                                        |
   | SOURCE's Virtual Machine                TARGET's Virtual Machine       |
   |                                                                        |
   | SOURCE uses the SEND function                                          |
   | to send a message to TARGET                                            |
   | specifying that (a) the                                                |
   | message data is contained in                                           |
   | SOURCE's parameter list and (b)                                        |
   | the message is a 2_way                                                 |
   | message.                     _______→  TARGET gets a "message pending" |
   |                                        interrupt from IUCV.  The data  |
   |                                        in the external interrupt buffer|
   |                                        (a) informs TARGET that the     |
   |                                        message is a 2_way message and  |
   |                                        (b) contains the message data   |
   |                                        that SOURCE sent.               |
   |                                                       |                |
   |                                                       ↓                |
   |                                        TARGET issues the REPLY function|
   | SOURCE gets a "message      ←________  to respond to SOURCE's message. |
   | complete" interrupt from                                               |
   | IUCV that describes                                                    |
   | TARGET's response.                                                     |
   |                                                                        |
   |________________________________________________________________________|
```
