#### 2\.4\.4\.5 DESCRIBE Parameter List Output Fields

`IPPATHID` contains the path identification number of the message\.

`IPFLAGS1` specifies values that IUCV returns for the DESCRIBE function\.

`IPFGMCL (X'01')` is always set to 1, so that you can use the DESCRIBE parameter list as input to the RECEIVE or REPLY function\.

`IPFGPID (X'02')` is always set to 1, so that you can use the DESCRIBE parameter list as input to the RECEIVE or REPLY function\.

`IPFGMID (X'04')` is always set to 1, so that you can use the DESCRIBE parameter list as input to the RECEIVE or REPLY function\.

`IPNORPY flag (bit X'10')` indicates, when set to 1, that the message is a 1\-way message\.

`IPPRTY flag (bit X'20')` indicates, when set to 1, that the message is a priority message\.

`IPRMDATA flag (bit X'80')` indicates, when set to 1, that the message data is in the parameter list\.

`IPRCODE` contains 00 for a normal return\.

`IPMSGID` contains the identification number of the message\.

`IPTRGCLS` contains the class of the message\.

`IPRMMSG1/IPRMMSG2` contains message data that was sent to you in a parameter list, rather than in a buffer\. You can specify IPRMMSG to refer to the combined IPRMMSG1 and IPRMMSG2 fields\.

`IPBFLN1/IPBFLN1F` contains the length of the message\.

`IPBFLN2/IPBFLN2F` contains the length of the reply area\.
