## 2\.4\.13 SEND

<a id="HDRSEND"></a>

Use the SEND function to initiate a communication with another virtual machine\.

The format of the SEND function is:

<a id="TBLTBLUNIQ76"></a>

```
    ____ _____ ______________________________________________________________
   | lab|lIUCV|                                                              |
   |    |     | SEND,PRMLIST={label|(reg)}                                   |
   |    |     |          [,BUFFER={label|(reg)}]                             |
   |    |     |           ,BUFLEN= label|(label,2)|(label,4)                 |
   |    |     |                (reg)|((reg),2)|((reg),4)                     |
   |    |     |          [,ANSBUF={label|(reg)}]                             |
   |    |     |           ,ANSLEN= label|(label,2)|(label,4)                 |
   |    |     |                (reg)|((reg),2)|((reg),4)                     |
   |    |     |          [,TYPE={1WAY|2WAY}]                                 |
   |    |     |          [,PRTY={YES|NO}]                                    |
   |    |     |          [,MSGTAG={label|(reg)}]                             |
   |    |     |          [,PATHID={label|(reg)}]                             |
   |    |     |          [,SRCCLS={label|(reg)}]                             |
   |    |     |          [,TRGCLS={label|(reg)}]                             |
   |    |     |          [,PRMMSG={label|(reg)}]                             |
   |    |     |          [,DATA={PRMMSG|BUFFER}]                             |
   |    |     |          [,MF=L]                                             |
   |    |     |          [,ANSLIST={YES|NO}]                                 |
   |    |     |          [,BUFLIST={YES|NO}]                                 |
   |    |     |          [,SYNC   ={YES|NO}]                                 |
   |    |     |                                                              |
   |____|_____|______________________________________________________________|
```
