### 7.12.1.5 HCPRPW

HCPRPW is called when: The LOGON command is entered AUTOLOG or XAUTOLOG is entered, and it requires a prompt for the password. Entry Point: HCPRPW defines only one entry point, called HCPRPWEP. Control should then be returned to the caller of HCPRPWEP with a return code in the ACICODE field of ACIPARMS.
