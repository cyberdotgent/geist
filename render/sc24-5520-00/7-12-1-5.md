### 7\.12\.1\.5 HCPRPW

HCPRPW is called when:

- The LOGON command is entered
- AUTOLOG or XAUTOLOG is entered, and it requires a prompt for the password\.

*Entry Point*: HCPRPW defines only one entry point, called HCPRPWEP\.

- **HCPRPWEP**\-\-called during LOGON/AUTOLOG/XAUTOLOG processing for authorization \(control\) and for audit, if audit is enabled for the corresponding event\. Return is made to the calling module by the HCPEXIT [\(31\)](<#FTNEXITM>) macro, located in the HCPPSI macro library\.

The ESM's HCPRPWEP is expected to prompt the user for a password and then to pass control to the ESM to verify that the password is correct\. Control should then be returned to the caller of HCPRPWEP with a return code in the ACICODE field of ACIPARMS\.

HCPRPWEP may use the \*RPI system service provided in the exit module, HCPRPI, to communicate with the ESM through IUCV\.

CP's stub module sets ACICODE to ACIDEFR and returns to the caller\.

`Input Registers: R1 - ACIPARMS parameter list address R11 - Command issuer's VMDBK address`

`Output Registers: R1 - ACIPARMS address (Return code in ACICODE field). See` ["Return Codes" in topic 7\.12\.1\.5\.1](7-12-1-5-1.md)`.`

`Register Usage: R12 - Base register R13 - Address of standard save area R14 - Scratch R15 - Scratch`

`Attributes: MP, pageable, and dynamic`

`Linkage: Call with a dynamic save area`

*Information Passed*: The command processor initializes ACIPARMS to pass the following information to HCPRPW\.

<a id="FTNEXITM"></a>

\(31\) The EXIT macro is coded in HCPRPWEP as:

HCPEXIT EP=\(HCPRPWEP\) Return to Caller

and may be invoked by simply coding "EXIT" in your Assembler program as an Assembler statement\.
