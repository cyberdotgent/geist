## 2\.3\.5 Setting Up an IUCV Parameter List

<a id="HDRCIPARML"></a>

Nearly all IUCV functions require you to specify the address of an IUCV parameter list to hold input to the function\. It is up to you to make sure that your IUCV program sets up a parameter list IUCV can use\.

Setting up an IUCV parameter list requires your program to:

1\. Declare 40 bytes of storage to be used as a parameter list\.

2\. Issue a USING statement similar to the following:

`USING IPARML,`*reg*

IPARML is the name of the IUCV mapping macro that tells IUCV how to interpret the parameter list\. IPARML COPY is provided in the HCPGPI macro library\.

*reg* is the number of a register that contains the address of the storage area you use for the IUCV parameter list\.

When you need to specify the address of the parameter list for an IUCV function \(for example, the CONNECT function\), you can code the PRMLIST keyword parameter in two ways as follows:

`IUCV CONNECT,PRMLIST=`*reg*`,...`

*reg* is the number of a register that contains the guest real address of the storage area you use for the IUCV parameter list\.

You may also code the PRMLIST keyword parameter in the following way:

`IUCV CONNECT,PRMLIST=`*label*`,...`

*label* is a relocatable label of the parameter list\.
