#### 2\.3\.9\.2 Permanently Ending Communications Over an IUCV Path

Use the SEVER function to terminate a path or paths without disabling IUCV\. IUCV reflects an interrupt to the virtual machine at the other end of the path, informing it that the path was severed\. When you sever a path, you lose any messages that were pending on the path\. The external interrupt buffer, however, may still contain some information\. Any messages sent to you on the severed path are automatically rejected by IUCV\.
