#### 2.4.1.1 ACCEPT Required Input

1. *The* *address* *of* *the* *ACCEPT* *parameter* *list*. Use the PRMLIST=parameter to identify the address of your parameter list to IUCV. The address of the parameter list must be a guest real address (an address that is real to your virtual machine), and it must be on a doubleword boundary. Specify the address of the parameter list as (a) a relocatable label, or (b) the number of a register that contains the address. 2. *The* *path* *identification* *of* *the* *path* *you* *are* *establishing*. When a user issues the CONNECT function to establish a path to your virtual machine, IUCV assigns the path a unique path identification number. IUCV reflects this value to your virtual machine in the IPPATHID field of a connection-pending external interrupt. When you issue the ACCEPT function to complete a path, specify the path identification number in one of the following ways: a. Use the PATHID=parameter. Specify the path identification as (a) the relocatable label of a halfword that contains the path ID, or (b) the number of a register that contains the path ID in the low-order halfword. b. Store the path identification number in the IPPATHID field of the ACCEPT parameter list.

**Note:** The PATHID=parameter does this automatically.
