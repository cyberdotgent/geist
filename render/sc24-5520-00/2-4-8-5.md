#### 2\.4\.8\.5 RECEIVE Parameter List Input Fields

`IPPATHID` contains the path identification number of the message you are attempting to receive\.

`IPFLAGS1` specifies options for the RECEIVE function\. IUCV treats each bit in IPFLAGS1 separately\. Make sure that bits you are not using to define input are set to 0\.

`IPFGMCL flag (bit X'01')` indicates, when set to 1, that you have specified a target message class for the message you are attempting to receive\.

`IPFGPID flag (bit X'02')` indicates, when set to 1, that you have specified a path identification number for the message you are attempting to receive\.

`IPFGMID flag (bit X'04')` indicates, when set to 1, that you have specified a message identification number for the message you are attempting to receive\.

`IPBUFLST flag (bit X'40')` indicates, when set to 1, that the address specified in IPBFADR1 is the address of a list of buffers and their respective lengths\. It also shows that the IPBFLN1F is the total length in the list\.

`IPMSGID` contains the message identification number of the message you are attempting to receive\.

`IPTRGCLS` contains the target message class of the message you are attempting to receive\.

`IPBFADR1` contains the address of the area into which IUCV places the message text\.

`IPBFLN1/IPBFLN1F` contains the length of the buffer into which IUCV places the data you are receiving\. Use IPBFLN1 to specify a halfword; IPBFLN1F to specify a fullword\. If you specify IPBFLN1, make sure you clear to zeros the high\-order bits of IPBFLN1F\.

**Note:** If you use the BUFLEN parameter to specify the buffer length, IUCV automatically clears the high\-order bits of IPBFLN1F\.
