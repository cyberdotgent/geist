#### 3.8.9.7 State Checks and State Changes

A state check occurs (see above IPRCODEs) if the path is not in the Send state. The state change depends on the value of the TYPE= parameter: When TYPE=RECEIVE, the state changes to the Defer_Receive state. When TYPE=SEVER, the state changes to the Defer_Sever state.
