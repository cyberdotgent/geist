#### 2.4.17.8 Program Exceptions

The following program exceptions can occur if you invoke the TESTCMPL function incorrectly: Specification You did not define your parameter list on a doubleword boundary. You specified a message identification without specifying a path identification and message class. Operation. IUCV is inactive; you have not used the DCLBFR function to declare an external interrupt buffer. Addressing. Your parameter list address is invalid; the address you specified is outside of your virtual machine's storage.
