### 8\.13\.2\.7 Symptom Strings\-\-SDB Format

The symptom strings placed in sections 3 and 4 of the symptom record must be in the SDB \(structured data base\) format\. In this format, the individual symptoms in sections 3 and 4 of the symptom record consist of a prefix and its associated data\. Examples of typical prefixes are:

**Prefix Data**

PIDS/ A component name

RIDS/ A routine name

AB/ An abend code

PRCS/ A return code
