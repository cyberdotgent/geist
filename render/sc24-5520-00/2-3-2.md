## 2.3.2 How IUCV Information Is Organized

Information on how to use IUCV is organized as follows: VM/ESA Installation describes how to code user directory entries for virtual machines that use IUCV. VM/ESA CP Command and Utility Reference lists CP trace table entries for IUCV under the SET CPTRACE command.
