#### 2.4.10.3 Required Inputs for Sending Response Data From a Parameter List

If you store the response data you are going to send in the parameter list, rather than in a buffer, you must do the following:

1. *Specify* *that* *you* *are* *sending* *data* *from* *your* *parameter* *list*. Do this in one of the following ways: a. Use the DATA=parameter. DATA=PRMMSG indicates that your message data is in the parameter list. DATA=BUFFER, the default value, specifies that your message data is in a buffer. If you specify DATA=PRMMSG, do not use the ANSBUF or ANSLEN parameters. b. Set the IPPRMDTA flag (bit X'80') to 1 in the IPFLAGS1 field of the ACCEPT parameter list.

**Note:** If you specify the DATA=PRMMSG parameter, IUCV sets this flag automatically.

2. *Specify* *the* *address* *of* *the* *data*. Do this in one of the following ways: a. Use the PRMMSG=parameter. Specify the address of the message data as (1) the relocatable label of 8 bytes containing the data or (2) the number of a register that contains the address of the data. b. Store the address of the message data in the IPBFADR1 field of the SEND parameter list.

**Note:** If you use the PRMMSG=parameter, IUCV stores this value automatically.
