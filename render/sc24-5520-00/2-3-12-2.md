#### 2\.3\.12\.2 Examining the Interrupt

After gaining control, your external interrupt handler must determine if the external interrupt was generated by IUCV\. To do this, your external interrupt handler should:

1\. Examine the external old PSW to determine the interrupt code\.

Save the external new PSW\.

2\. If the interrupt code is X'4000', the interrupt is an IUCV interrupt\. The next section, ["Responding to IUCV Interrupts" in topic 2\.3\.12\.3](2-3-12-3.md), describes how to determine what type of IUCV interrupt you have received, and some possible responses to each type of interrupt\.

3\. If the interrupt is not an IUCV interrupt \(the interrupt code is something other than X'4000'\), you must pass the interrupt to the operating system you are running\. To do this, issue the LPSW instruction, specifying the external new PSW you saved during the first step\.
