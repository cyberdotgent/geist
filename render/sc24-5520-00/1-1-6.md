## 1\.1\.6 Condition Codes, Return Codes, and Exceptions

<a id="HDRRESP"></a>

Once CP executes a DIAGNOSE code, certain responses may be sent back to you in order to indicate whether or not the execution was successful\. Three types of responses that you may receive are:

- **Condition codes** \(sometimes referred to as **completion codes**\), which appear in the PSW \(program status word\)\.
- **Return codes**, which appear in a register\. The exact register where they appear is specified in the "Responses" section of the documentation for each DIAGNOSE code\.
- **Exceptions**, which are program interruptions\.

The "Responses" section of each DIAGNOSE code explains the significance of all applicable condition codes and return codes\.
