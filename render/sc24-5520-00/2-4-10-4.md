#### 2\.4\.10\.4 Optional Input

1\. *The priority of the response*\. To send a priority response, do one of the following\.

a\. Use the PRTY=parameter\. PRTY=YES specifies that a path can handle priority communications\.

**Note:** For your virtual machine to handle priority communications, your user directory entry must include the appropriate statement\.

PRTY=NO, the default value, specifies that a path cannot handle priority communications\.

b\. Set the IPPRTY flag \(bit X'20'\) to 1 in the IPFLAGS1 field of the CONNECT parameter list\.

**Note:** If you specify PRTY=YES, IUCV sets the flag automatically\.

2\. *MF=L*\. Specify MF=L if you want to build an IUCV parameter list without issuing the IUCV instruction\. This option allows programs to build an IUCV parameter list and pass that parameter list to an operating system that provides an IUCV interface\. The IUCV macro fills in the parameter list in the same manner as if the MF=L option was not specified\. The macro does not initialize any registers, and does not generate the IUCV instruction\.

3\. *If you are specifying a list of discontiguous buffers insteadof a single contiguous buffer*, do one of the following:

a\. Use ANSLIST=YES to indicate that the address on the ANSBUF parameter identifies a list of addresses and lengths of discontiguous buffers that contains the reply data\.

b\. Use ANSLIST=NO to indicate that the list format is not being used\. The ANSBUF parameter is the address of the complete reply\.

If you specify ANSLIST=YES, you must build the corresponding buffer address/length list on a doubleword boundary in the following format:

<a id="FIGFIGUNIQ71"></a>

```
      ______________ ________________ 
     |   address1   |   length1      |
     |______________|________________|
     |   address2   |   length2      |
     |______________|________________|
     |      .             .          |
     |_______________________________|
     |      .             .          |
     |_______________________________|
     |      .             .          |
     |______________ ________________|
     |   addressn   |   lengthn      |
     |______________|________________|
```

Each address plus length entry in this list is two fullwords\. The first fullword points to the data area to be transferred\. The second fullword contains the number of bytes to be transferred\. A list of one entry is valid\.
