#### 2.4.17.5 TESTCMPL Parameter List Input Fields

IPPATHID contains the path identification number of the response you are receiving. IPFLAGS1 specifies options for the TESTCMPL function. IUCV treats each bit in IPFLAGS1 separately. Make sure bits you are not using to define input are set to 0. IPFGMCL (X'01') indicates, when set to 1, that you have specified a message class for the response you are receiving. IPFGPID (X'02') indicates, when set to 1, that you have specified a path identification number for the response you are receiving. IPFGMID (X'04') indicates, when set to 1, that you have specified a message identification number for the response you are receiving. IPMSGID contains the message identification number of the response you are receiving. IPSRCCLS contains the source message class of the response you are receiving.
