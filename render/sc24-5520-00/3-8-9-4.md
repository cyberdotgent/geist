## 3.8.9.4 SETMODFY Input Parameter List

<a id="HDRSMDPL"></a>

#### SETMODFY Input Parameter List

The APPCVM SETMODFY parameter list has the input format shown in [Figure 53](3-8-9-4.md#SMDIPL).

<a id="SMDIPL"></a>

```text
   |      +--------------+--------+------------------------------------------+        |
   |     0|   IPPATHID   |IPFLAGS1| //////////////////////////////////////// |        |
   |      +--------------+--------+------------------------------------------+        |
   |     8| //////////////////////////////////////////////////////////////// |        |
   |      +------------------------------------------------------------------+        |
   |    10| //////////////////////////////////////////////////////////////// |        |
   |      +------------------------------------------------------------------+        |
   |    18| //////////////////////////////////////////////////////////////// |        |
   |      +---------------------------------------------------------+--------+        |
   |    20| /////////////////////////////////////////////////////// |IPSNDOP2|        |
   |      +---------------------------------------------------------+--------+        |
```

**IPPATHID** contains the path ID on which the sync-point control modifier is being specified. **IPFLAGS1** contains the following input bit flag: IPAPPC (X'08') specifies that this is an APPC function. **IPSNDOP2** contains one of the following SEND option codes: IPTPRECV (X'04') a Receive state was requested when the sync-point sequence completes. IPTPSEVR (X'06') a Sever state was requested when the sync-point sequence completes.
