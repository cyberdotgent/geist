## 5.10.7 IUCV DESCRIBE

<a id="HDRXDES"></a>

Use the DESCRIBE function to get the following: A description of a pending APPC/VM or IUCV message without receiving, it A request-to-send indication. DESCRIBE returns information about a message only once--the next time you invoke DESCRIBE, you get a description of the next "undescribed" message. You can issue a RECEIVE on a message after you have described it. However, it is not necessary to describe a message before receiving it.
