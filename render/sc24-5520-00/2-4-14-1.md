## 2.4.14.1 SETCMASK Required Input

<a id="HDRSETCRI"></a>

#### SETCMASK Required Input

1.? The address of the SETCMASK parameter list. Use the PRMLIST=parameter

to identify to IUCV the address of your parameter list. The address of the parameter list must be a guest real address (an address that is real to your virtual machine), and it must be on a doubleword boundary. Specify the address of the parameter list as (a) a relocatable label, or (b) the number of a register that contains the address. 2. *The* *mask* *byte* *that* *specifies* *the* *IUCV* *external* *interrupts* *for* *which* *if* *any,* *your* *virtual* *machine* *is* *enabled*. The bits in the mask byte are defined as follows: **Bit** **Code** **Interrupts** **Enabled** **For** IPCLPC X'80' Pending connection IPCLCC X'40' Connection complete IPCLPS X'20' Path severed IPCLPQ X'10' Path quiesced IPCLPR X'08' Path resumed Specify the mask in one of the following ways: a. Use the MASK=parameter. Specify the mask as: the relocatable label of a byte containing the mask; the number of a register that contains the mask in its low-order byte (label, 2); or the number of a register that contains a fullword mask (label, 4). b. Set the specific bits in the IPCMASK field of the SETCMASK parameter list.

**Note:** If you specify the MASK=parameter, IUCV sets these bits automatically.
