#### 6\.11\.4\.1 IUCV CONNECT to \*BLOCKIO

An IUCV CONNECT is issued by the virtual machine with USERID specified as \*BLOCKIO and PRMDATA=YES specified in the IUCV CONNECT parameter list\. The IPARML DSECT and IPARML COPY files are located in the HCPGPI macro library\. The user data field \(IPUSER\) in the IUCV parameter list must have the following format\.

<a id="FIGFIGUNIQ198"></a>

```
      IPARML DSECT

      0      1        2         3         4         5         6       7
      ___________________________________ ________________________________ 
    8|         Block size                |       Offset                   |
     |_____________ _____________________|________________________________|
   10|  Vdevaddr   |///////////////////////////////////////////////////// |
     |_____________|______________________________________________________|
```

`block size` contains the block size of the specified disk; the block size can be 512, 1K, 2K, or 4KB bytes\.

`offset` contains the number of sequential blocks on the disk used by the CMS file system to implement its structure\. blksize associates a physical block number to the first user data block of a unique file on the disk\. \*BLOCKIO does not check the validity of this number; therefore the application can change the number if desired\.

`vdevaddr` contains the virtual device address of the disk on which the block I/O is to be performed\.

**Note:** All reserved fields must be set to zero\.
