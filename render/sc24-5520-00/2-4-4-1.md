#### 2\.4\.4\.1 DESCRIBE Required Input

*The address of the DESCRIBE parameter list*\. Use the PRMLIST=parameter to identify to IUCV the address of your parameter list\. The address of the parameter list must be a guest real address \(an address that is real to your virtual machine\), and it must be on a doubleword boundary\.

Specify the address of the parameter list as \(1\) a relocatable label, or \(2\) the number of a register that contains the address\.
