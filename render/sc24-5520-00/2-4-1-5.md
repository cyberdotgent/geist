#### 2\.4\.1\.5 ACCEPT Parameter List Output Fields

`IPFLAGS1` specifies values that IUCV returns for the ACCEPT function\.

`IPPRTY (X'20')` indicates, when set to 1, that you want to establish a path that can handle priority communication\.

`IPRCODE` contains one of the following return codes:

**Code Meaning**

00 Normal return

01 You specified an invalid path identification number\.

20 IUCV cannot complete the path; the virtual machine that issued the CONNECT function has severed the path\.

30 The IPAPPC flag in IPFLAGS1 not zero\.

`IPMSGLIM` contains the message limit for this path\.
