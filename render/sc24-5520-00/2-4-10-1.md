#### 2\.4\.10\.1 REPLY Required Input

1\. *The address of the REPLY parameter list*\. Use the PRMLIST=parameter to identify the address of your parameter list to IUCV\. The address of the parameter list must be a guest real address \(an address that is real to your virtual machine\), and it must be on a doubleword boundary\.

Specify the address of the parameter list as \(a\) a relocatable label, or \(b\) the number of a register that contains the address\.

2\. *The message identification number of the message to which you are replying*\. Specify this number in one of the following ways:

a\. Use the MSGID=parameter\. Specify the message identifier as \(a\) the relocatable label of a fullword containing the message identifier, or \(b\) the number of a register that contains the message identifier\.

b\. Store the message identification number in the IPMSGID field of the REPLY parameter list\. Also, set the IPFGMID bit \(X'04'\) to 1 in the IPFLAGS1 field\.

**Note:** If you use the MSGID=parameter, IUCV stores the message ID and sets the IPFGMID flag automatically\.

3\. *The path identification number of the message to which you are replying*\. Specify this number in one of the following ways:

a\. Use the PATHID=parameter\. Specify the path identification as \(1\) the relocatable label of a halfword that contains the path ID, or \(2\) the number of a register that contains the path ID in the low\-order halfword\.

b\. Store the path identification number in the IPPATHID field of the REPLY parameter list\. Also, set the IPFGPID bit \(X'02'\) to 1 in the IPFLAGS1 field\.

**Note:** If you use the PATHID=parameter, IUCV stores the path ID and sets the IPFGPID flag automatically\.

4\. *The message class of the message to which you are replying*\. Specify this in one of the following ways:

a\. Use the TRGCLS=parameter\. Specify the message class as \(1\) the relocatable label of a fullword containing the message class, or \(2\) the number of a register containing the message class\.

b\. Store the message class in the IPTRGCLS field of the REPLY parameter list\. Also, set the IPFGMCL bit \(X'01'\) to 1 in the IPFLAGS1 field\.

**Note:** If you use the TRGCLS=parameter, IUCV stores the message class and sets the IPFGMCL flag automatically\.
