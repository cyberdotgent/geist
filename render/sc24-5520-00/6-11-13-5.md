#### 6.11.13.5 Leaving the *SIGNAL System Service

When all communications with the *SIGNAL system service are completed, you can terminate communication by issuing either an IUCV SEVER or an IUCV RETRIEVE BUFFER. The user data field on a SEVER must have the following format:

<a id="FIGUNIQ212 0 1 2 3 4 5 6 7 0 Signal data 8 /////////////////////////////////////////////////////////////"></a>

*where:* **Signal** **data** is the 8-byte signal you want passed to other members of the group. Only group members that have specified the signal-out flag when they connected to the *SIGNAL system service will receive the data. If a SEVER is generated by the CP system, as on a RETRIEVE BUFFER or a virtual machine reset, the signal data is set to all zeros.
