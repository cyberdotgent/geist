## 5.10.8 IUCV QUERY

<a id="HDRIUQUE"></a>

Use the QUERY function to determine the maximum number of communication paths that can be established for your virtual machine. The value is returned in register 1. In addition, CMS and GCS can use IUCV QUERY during initialization to determine the following: 1. The size of the external interrupt buffer. This value is returned in register 0. 2. The maximum length of data that can be returned in the external interrupt buffer extension, if you specify the PRMLIST=parameter. This value is returned in the output parameter list.

**Note:** The IUCV QUERY function: Causes no state changes Completes immediately Does not involve a communication partner.
