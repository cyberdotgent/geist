**CC=1** An error occurred before the SETMODFY was initiated. The output parameter list is the same as the input shown in ["SETMODFY Input](3-8-9-4.md) Par [ameter List" in topic 3.8.9.4, e](3-8-9-4.md) xcept that one of the following return codes is stored in IPRCODE (byte 3):

**CC=2** SETMODFY completed with no error caused by the invoker. The output parameter list when CC=2 is shown in [Figure 54](3-8-9-5.md#SMDOPL).

<a id="SMDOPL"></a>

```text
   |      +--------------+---------------------------------------------------+        |
   |     0|   IPPATHID   | ///////////////////////////////////////////////// |        |
   |      +--------------+---------------------------------------------------+        |
   |     8| //////////////////////////////////////////////////////////////// |        |
   |      +------------------------------------------------------------------+        |
   |    10| //////////////////////////////////////////////////////////////// |        |
   |    18| //////////////////////////////////////////////////////////////// |        |
   |      +----------------------------------------+---------+---------------+        |
   |    20| ////////////////////////////////////// | IPSTATE | ///////////// |        |
   |      +--------------------------------------------------+---------------+        |
```

IPP**ATHID** contains the path ID on which SETMODFY completed. IPS**TATE** contains the current state for this path, which may have one of the following values: IPDEFRCV (X'07') The path is in the Defer_Receive state. IPDEFSEV (X'08') The path is in the Defer_Sever state.
