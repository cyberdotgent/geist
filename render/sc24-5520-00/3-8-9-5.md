#### 3\.8\.9\.5 SETMODFY Condition Codes and Return Codes

<a id="TBLTBLUNIQ149"></a>

```
    _________________ __________________ __________________ _________________
   | CC=0            | CC=1             | CC=2             | CC=3            |
   |_________________|__________________|__________________|_________________|
   | Not possible    | X                | X                | Not possible    |
   |_________________|__________________|__________________|_________________|
```

SETMODFY always completes immediately\.

**CC=1** An error occurred before the SETMODFY was initiated\. The output parameter list is the same as the input shown in ["SETMODFY Input](3-8-9-4.md) [Parameter List" in topic 3\.8\.9\.4](3-8-9-4.md), except that one of the following return codes is stored in IPRCODE \(byte 3\):

<a id="TBLTBLUNIQ150"></a>

```
       ______ ________ _________________________________________________________
      | Hex  | Decimal|                                                         |
      | Code | Code   | Why the Error Occurred                                  |
      |______|________|_________________________________________________________|
      | X'01'| 1      | The specified path ID is not yet established.           |
      |______|________|_________________________________________________________|
      | X'03'| 3      | A function is pending on this path.                     |
      |______|________|_________________________________________________________|
      | X'1E'| 30     | This is a non-APPC path.                                |
      |______|________|_________________________________________________________|
      | X'20'| 32     | SETMODFY is invalid from the Connect state.             |
      |______|________|_________________________________________________________|
      | X'22'| 34     | SETMODFY is invalid from the Receive state.             |
      |______|________|_________________________________________________________|
      | X'23'| 35     | SETMODFY is invalid from the Confirm state.             |
      |______|________|_________________________________________________________|
      | X'24'| 36     | SETMODFY is invalid from the Sever state.               |
      |______|________|_________________________________________________________|
      | X'25'| 37     | The connection was established with SYNCLVL=NONE or     |
      |      |        | CONFIRM.                                                |
```

**CC=2** SETMODFY completed with no error caused by the invoker\. The output parameter list when CC=2 is shown in [Figure 54](3-8-9-5.md#FIGSMDOPL)\.

<a id="FIGSMDOPL"></a>

```
      IPARML DSECT

      0      1      2        3        4       5        6        7
     +--------------+---------------------------------------------------+
    0|   IPPATHID   | ///////////////////////////////////////////////// |
     +--------------+---------------------------------------------------+
    8| //////////////////////////////////////////////////////////////// |
     +------------------------------------------------------------------+
   10| //////////////////////////////////////////////////////////////// |
     +------------------------------------------------------------------+
   18| //////////////////////////////////////////////////////////////// |
     +----------------------------------------+---------+---------------+
   20| ////////////////////////////////////// | IPSTATE | ///////////// |
     +--------------------------------------------------+---------------+
```

*Figure 54\. APPCVM SETMODFY Output Parameter List*

**IPPATHID** contains the path ID on which SETMODFY completed\.

**IPSTATE** contains the current state for this path, which may have one of the following values:

IPDEFRCV \(X'07'\) The path is in the Defer\_Receive state\. IPDEFSEV \(X'08'\) The path is in the Defer\_Sever state\.
