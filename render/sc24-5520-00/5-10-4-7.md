#### 5\.10\.4\.7 ACCEPT Program Exceptions

The program exceptions for ACCEPT are:

<a id="TBLTBLUNIQ162"></a>

```
    ________________ ________________________________________________________
   | Type           | Description                                            |
   |________________|________________________________________________________|
   | Addressing     | The parameter list address is outside of the virtual   |
   |                | machine, the CCED buffer is outside the virtual        |
   |                | machine, or the CCED buffer address is 0.              |
   |________________|________________________________________________________|
   | Operation      | Either an application interrupt buffer is not          |
   |                | declared, or the invoking virtual machine is not in    |
   |                | the supervisor state.                                  |
   |________________|________________________________________________________|
   | Protection     | The storage key of the parameter list address does not |
   |                | match the key of the user.                             |
   |________________|________________________________________________________|
   | Specification  | The parameter list is not on a doubleword boundary.    |
   |________________|________________________________________________________|
```
