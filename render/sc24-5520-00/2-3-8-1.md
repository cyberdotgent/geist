#### 2\.3\.8\.1 One\-Way Messages with Data in a Parameter List

[Figure 11](2-3-8-1.md#FIGC92FIG3) shows the events that take place when SOURCE sends TARGET a 1\-way message, where the message data is stored in the SEND parameter list\. Note that before SOURCE sends message data from within the SEND parameter list, SOURCE and TARGET must establish a path that can handle data sent from within a parameter list\.

<a id="FIGC92FIG3"></a>

```
    ________________________________________________________________________ 
   |                                                                        |
   | SOURCE's Virtual Machine              TARGET's Virtual Machine         |
   |                                                                        |
   | SOURCE uses the SEND function                                          |
   | to send a message to TARGET                                            |
   | specifying that (a) the                                                |
   | message data is contained in                                           |
   | SOURCE's parameter list and                                            |
   | (b) the message is a 1_way                                             |
   | message.                     _______→ TARGET gets a "message pending"  |
   |                                       interrupt from IUCV.  The data   |
   |                                       in the external interrupt buffer |
   |                                       (a) informs TARGET that the      |
   |                                       message is a 1_way message and   |
   |                                       (b) contains the message data    |
   |                                       that SOURCE sent.                |
   |                                                                        |
   |________________________________________________________________________|
```
