#### 2.4.7.1 QUIESCE Required Input

1. *The* *address* *of* *the* *QUIESCE* *parameter* *list*. Use the PRMLIST=parameter to identify to IUCV the address of your parameter list. The address of the parameter list must be a guest real address (an address that is real to your virtual machine), and it must be on a doubleword boundary. Specify the address of the parameter list as (a) a relocatable label, or (b) the number of a register that contains the address.* 2. *The* *identification* *of* *the* *path* *or* *paths* *you* *want* *to* *quiesce*. If you want to quiesce a specific path, do so in one of the following ways: a. Use the PATHID=parameter. Specify the path identification as (1) the relocatable label of a halfword that contains the path ID, or (2) the number of a register that contains the path ID in the low-order halfword. b. Store the path identification number in the IPPATHID field of the QUIESCE parameter list.

**Note:** If you use the PATHID=parameter, IUCV stores this value automatically. If you want to quiesce all of your paths, do so in one of the following ways: a. Use the ALL=parameter. If you specify ALL=YES, IUCV quiesces all of your paths. ALL=NO, the default value, tells IUCV not to quiesce all of your paths. b. Set the IPALL bit (X'80') to 1 in the IPFLAGS1 field of the QUIESCE parameter list.

**Note:** If you use the ALL=YES parameter, IUCV sets this bit automatically.
