IPPATHID contains the path ID on w [hich the](3-8-4-5.md#SFOPL) function is complete. IPT**YPE** contains the function complete interrupt code (IPTYPFCA, X'87'). IPC**ODE** contains the error code from the partner's SENDERR or sever code from the partner's SEVER. IPCODE is only valid when IPWHATRC=IPERROR or IPSABEND. IPS**ENDOP** contains one of the following SEND option codes: IPCNFRM (X'04') The SENDCNF TYPE=NORMAL is being completed. IPCNFSEV (X'05') The SENDCNF TYPE=SEVER is being completed. IPSEVER (X'06') The path is in the Sever state. IPBKOUT (X'0D') The path is in the Backout_Received state. IPBKREQ (X'0E') The path is in the Backout_Required state.
