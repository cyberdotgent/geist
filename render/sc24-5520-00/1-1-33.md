## 1.1.33 Diagnose Code X'90'--Read Symbol Table

PSPI **Privilege** **Class:** Any Use DIAGNOSE X'90' to find the address of a specific symbol contained in the symbol table for diagnosis, monitoring, or tuning activities only. See the Special Notices in topic [NOTICES](notices.md) for a warning on the use of product-sensitive programming interfaces. The loader creates a symbol table at load time that contains all the external symbols in the system. This symbol table does not have a maximum size.

**Entry** **Values:**

Rx Contains the length of the symbol. Trailing blanks are not counted. The value contained in Rx must be greater than or equal to 6, and less than or equal to 8; otherwise, you will get a specification error. Ry Contains the address of the symbol. **Usage** **Note:** See ["How Addresses Are Processed" in topic 1.1.5](1-1-5.md) for VM/ESA address processing conventions. **Responses:** After executing DIAGNOSE X'90', you receive a condition code indicating the success or failure of the instruction.
