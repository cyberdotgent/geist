#### 7.12.1.5.7 Auditing VMCF Commands

If the AUDIT bit for DIAGNOSE code X'68' is on, the system audits the following VMCF functions: SEND SEND/RECEIVE SENDX RECEIVE REPLY IDENTIFY.

CP formats the general ACIPARMS parameter list, but with the variations shown in [Table 62](#TBLACICB)
