#### 7\.12\.1\.5\.5 Auditing SPOOL File Activity

CP invokes and audits the following SPOOL file activity user commands:

- CHANGE
- CLOSE
- SPOOL
- SPTAPE
- TRANSFER\.

Furthermore, it invokes and audits the opening, creation and deletion of all user spool files\. CP formats the general ACIPARMS parameter list, but with the variations shown in [Table 60](<#TBLABSTC>)\.
