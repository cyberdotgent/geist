## 1\.1\.43 Diagnose Code X'C8'\-\-Set Language

**Privilege Class:** Any

DIAGNOSE Code X'C8' initiates the SET of the national language for the virtual machine session\. It sets only the CP language\. CP uses this language to issue most CP system messages\.

The preferred user interface is the CMS SET LANGUAGE command\.

**Entry Values:**

Rx and Language identifier specifying the language to be set for the virtual Rx\+1 machine and the *langid* specified in the message repository\. The language identifier is specified using the 1\- to 5\-character *langid*, left\-justified \(that is, the first four characters in Rx and fifth character in the high\-order byte of Rx\+1\)\. If the language identifier is less than five characters, it should be padded on the right with blanks\.

Ry X'00xxxxxx'\-the function code \(X'00' in the high\-order byte, with the remaining bytes unused\)\.

**Exit Values:**

When processing of the SET function completes, the first five bytes of the register pair Rx, Rx\+1 contain the language identifier for the language that has been set for CP messages \(this language may or may not be the same as the language set before the DIAGNOSE code was issued\), left\-justified and padded on the right with blanks as required\. The low\-order byte of register Ry contains one of the following return codes \(the contents of the remaining bytes of Ry are unpredictable\):

<a id="TBLTBLUNIQ43"></a>

```
    _________________ _______________________________________________________
   | Return Code     |                                                       |
   | in Ry+1         | Status                                                |
   |_________________|_______________________________________________________|
   | X'00'           | The language requested has been set.                  |
   |_________________|_______________________________________________________|
   | X'14'           | A paging error occurred while an attempt was being    |
   |                 | made to read the first page of the requested message  |
   |                 | repository.  The current language used for CP         |
   |                 | messages is unchanged.                                |
   |_________________|_______________________________________________________|
   | X'1C'           | No message repository could be found for the          |
   |                 | specified language identifier.  The current language  |
   |                 | used for CP messages is unchanged.                    |
   |_________________|_______________________________________________________|
   | X'20'           | The selected repository does not appear to be a valid |
   |                 | message repository.                                   |
   |_________________|_______________________________________________________|
   | X'24'           | Unrecoverable error, causing a soft abend.  The       |
   |                 | current language used for CP messages is unchanged.   |
   |_________________|_______________________________________________________|
```

**Program Checks:**

The virtual machine invoking this function receives a program check if a specification exception occurs because the input registers are set up incorrectly for the DIAGNOSE code\.
