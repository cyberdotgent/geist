#### 2.4.2.4 CONNECT Parameter List Input Fields

IPFLAGS1 specifies options for the CONNECT function. IUCV treats each bit in IPFLAGS1 separately. Make sure that bits you are not using to define input are set to 0. When set to 1: IPPRTY flag (bit X'20') indicates that you want to establish a path that can handle priority communications. IPQUSCE flag (bit X'40') indicates that you want to establish a quiescent path. IPRMDATA flag (bit X'80') indicates that you are prepared to handle messages sent you using the DATA=PRMMSG parameter. IPCNTRL flag (bit X'04') indicates that you want to establish a control path. IPMSGLIM contains the number of outstanding messages that IUCV allows on the path you are establishing. IPVMID contains the 8-character user ID of the virtual machine to which you want to establish this path. IPUSER contains the 16-byte user data area that IUCV reflects to the virtual machine with which you are establishing a path.
