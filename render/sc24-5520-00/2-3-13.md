## 2\.3\.13 Using Defaults with IUCV

<a id="HDRDEFLTS"></a>

With IUCV, defaults are dependent on what was done with the parameter lists\. That is, if someone gives you a parameter list, it contains the options specified by that person, not the items that are listed as defaults in this book\.

Because of this, you should check the parameter lists you are using so that you know what the option settings are\.
