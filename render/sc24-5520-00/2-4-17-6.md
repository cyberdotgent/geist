#### 2.4.17.6 TESTCMPL Parameter List Output Fields

IPPATHID contains the path identification number of the message whose response you are receiving. IPFLAGS1 contains the following values that IUCV returns for the TESTCMPL function: IPNORPY flag (bit X'10') indicates, when set to 1, that the message is a 1-way message. IPPRTY flag (bit X'20') indicates, when set to 1, that the message is a priority message. IPRMDATA flag (bit X'80') indicates, when set to 1, that the message data is in the parameter list. IPRCODE contains one of the following return codes:

**Code** **Meaning** 00 Normal return

01 You specified an invalid path identification number. 08 The message class or path identification number you specified does not correspond to the message identification number you specified. IPMSGID contains the message identification number of the message whose response you are receiving. IPAUDIT contains the audit trail of the message. IUCV sets a condition code of 3 whenever it modifies the audit trail. The meanings of the bits in the audit trail are:

**Bit** **Code** **Meaning** IPADRPLE X'8000' Reply too long for buffer

IPADSNPX X'4000' Protection exception on send buffer IPADSNAX X'2000' Addressing exception on send buffer IPADANPX X'1000' Protection exception on answer buffer IPADANAX X'0800' Addressing exception on answer buffer IPADRJCT X'0400' Message rejected IPADPRMD X'0200' Reply data in parameter list not allowed by the originator X'0100' Reserved IPADRCPX X'0080' Protection exception on receive buffer IPADRCAX X'0040' Addressing exception on receive buffer IPADRPPX X'0020' Protection exception on reply buffer IPADRPAX X'0010' Addressing exception on reply buffer IPADSVRD X'0008' Path severed X'0004' Reserved X'0002' Reserved X'0001' Reserved IPRMMSG1/IPRMMSG2 contains response data that was sent to you in the parameter list rather than in a buffer. You can specify IPRMMSG to refer to the combined IPRMMSG1 and IPRMMSG2 fields. IPSRCCLS contains the message class of the message whose response you are trying to receive. IPMSGTAG contains the tag associated with the message whose response you are looking for. IPBFLN2/IPBFLN2F contains one of the following values: If the buffer was exactly the correct length, IUCV stores a zero in this field. If the buffer was too long, IUCV stores the number of bytes remaining in the buffer (the amount that the buffer exceeded the length of the data) in this field. If the buffer was too short, IUCV stores a residual count in this field (that is, the number of bytes remaining in the message that would not fit into the buffer) and sets the IPADRPLE bit in the audit trail.
