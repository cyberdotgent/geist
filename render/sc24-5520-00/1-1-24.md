## 1\.1\.24 Diagnose Code X'5C'\-\-Error Message Editing

**Privilege Class:** Any

Use DIAGNOSE code X'5C' to edit error messages according to your setting of the EMSG function, as determined by the SET EMSG command\.

**Entry Values:**

Rx Contains the address where the first byte of the message to be edited can be found\. If the subcode is X'40', the Rx register cannot be register 15\.

Rx\+1 Contains the length of the message header if the subfunction code is X'40'\.

Ry Consists of *SS*xx*LLLL*

where:

*SS* is the subfunction code

xx is not checked

*LLLL* is the length of the message to be edited

**Subfunction Code Meaning**

00 Indicates that a 10\-byte message header \(code\) is assumed; the actual contents of the message are not checked\.

20 Indicates that the length of the message header must be calculated; DIAGNOSE code X'5C' assumes that the header runs up to, but does not include, the first blank\. It also assumes the text begins at the location following the first blank\.

40 Indicates that the length of the message header is being passed in Rx\+1; the actual contents of the message are not checked\.

**Exit Values:**

CP tests the EMSG setting and returns Rx and Ry to the caller modified as follows:

<a id="TBLTBLUNIQ17"></a>

```
    _________ ______________ ________________________________________________
   | EMSG    |              |                                                |
   | Setting | Rx           | Ry                                             |
   |_________|______________|________________________________________________|
   | ON      | No change    | If the subcode is X'40' or X'20', the subcode  |
   | IUCV    |              | byte is zeroed out.  The rest of the register  |
   |         |              | remains unchanged.                             |
   |_________|______________|________________________________________________|
   | CODE    | No change    | The length of the header, as determined by the |
   |         |              | subfunction code.                              |
   |_________|______________|________________________________________________|
   | TEXT    | The pointer  | The length of the text alone                   |
   |         | to the text  |                                                |
   |         | part of the  |                                                |
   |         | message      |                                                |
   |_________|______________|________________________________________________|
   | OFF     | No change    | 0                                              |
   |_________|______________|________________________________________________|
```

**Usage Note:**

DIAGNOSE code X'5C' does not write the message; it merely rearranges the starting pointer and length\.

**Responses:**

None\.
