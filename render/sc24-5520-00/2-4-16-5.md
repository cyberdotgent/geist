#### 2\.4\.16\.5 SEVER Parameter List Output Fields

`IPRCODE` contains one of the following return codes:

**Code Meaning**

00 Normal return

01 You specified an invalid path identification number\.

30 IPAPPCSN flag in IPFLAGS1 not zero
