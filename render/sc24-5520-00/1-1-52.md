## 1.1.52 Diagnose Code X'210'--Retrieve Device Information

<a id="HDRDIAG210"></a>

**Privilege** **Class:** G Use DIAGNOSE X'210' to request identifying information and status information about a particular virtual device. DIAGNOSE code X'210' replaces DIAGNOSE code X'24' for new applications. Your virtual machine must specify the I/O address of the virtual device for which information is requested. The device information is returned in a buffer provided by the caller and is set up as follows: **Entry** **Values:** Rx Is the general purpose register that contains the virtual address of a buffer. This buffer is used both as an input parameter passing area and as an output data buffer. The I/O address of the virtual device (bytes 1 and 2) and the length of the buffer (bytes 3 and 4) must be **spe**cified in the buffer prior to the DIAGNOSE call. Virtual/Real Device Characteristics Block (VRDCBLOK) Is the buffer that DIAGNOSE code X'210' uses in returning device information. It must be on a fullword boundary, or a program-check specification exception is returned. **Exit** **Values:** Virtual/Real Device Characteristics Block Contains virtual device, real device, and control unit information, as well as real device characteristics data as shown in Figure [6. **Program** **Exceptions:** The VRDCBLOK address must be on a fullword boundary; otherwise, a program check or a specification exception is returned. The VRDCBLOK length must be eight bytes or greater; otherwise, a program check or a specification exception is returned. **Usage** **Notes:**

1. The device information in bytes X'004' through X'009', and X'00B', is returned in a format consistent with DIAGNOSE code X'24'. However, the RDEVDVMD field in DIAGNOSE code X'24' and the corresponding byte (X'00A') in DIAGNOSE code X'210' returns different information. For a 3380 DASD, DIAGNOSE code X'24' returns the high-order 4 bits of the control unit model number in its high-order 4 bits, and the low-order 4 bits of the device model number in its low-order 4 bits in the RDEVDVMD field. For a 3390 DASD, the model number does not apply for

DIAGNOSE code X'24'. Instead, Byte X'00A' in DIAGNOSE code X'210'

contains only device model information for all devices. 2. Refer to the hardware manuals for content descriptions of the sense ID or the Read Device Characteristics channel command results. 3. If DIAGNOSE code X'210' is issued for a device that does not support RDC, the RDC data bytes starting with byte X'015' show the static device information and do not necessarily conform to the format given. 4. DIAGNOSE code X'210' is issued for any virtual device. 5. When DIAGNOSE code X'210' is issued for a minidisk, the number of primary cylinders or blocks is set to the size of the minidisk. The alternate, diagnostic, and device support cylinder or block addresses, and number of tracks, are all set to zero. 6. DIAGNOSE code X'210' returns as much information to the virtual machine as possible in the VRDCBLOK. For example, if the length is only eight bytes, then only the virtual device information is returned.
