## 1\.1\.46 Diagnose Code X'D4'\-\-Set Alternate User ID

<a id="TBLD4ERR"></a>

<pre>
   Privilege Class:  B
   DIAGNOSE Code X'D4' is used by a master virtual machine when scheduling
   work on one of its worker virtual machines on behalf of an end user.  It
   establishes the end user's user ID as the originator of spool files
   created while the worker machine is processing the end user's request.
   Special files such as VMDUMP files are not affected, as they rightly
   belong to the worker machine.  When the worker virtual machine is finished
   with the end user's request, the master virtual machine can set a new
   alternate user ID for the next job, or cancel alternate user ID processing
   for the worker.
   Note:  The parameter list containing the user IDs may cross a page
          boundary.
   Entry values:
   Rx     Zero
   Ry     Points to the parameter list, DD4PARM0.  DD4PARM0 COPY is provided
          in the HCPGPI macro library.
           DD4PARM0 DSECT
         _______________________________________
    0   |  DD4PTGT                              |
        |                                       |
        |_______________________________________|
    8   |  DD4PALT                              |
        |                                       |
        |                                       |
   10   |_______________________________________|
   DD4PTGT
       is the user ID of the worker virtual machine that will run with an
       alternate user ID.  If the ID is less than eight characters, it must
       be padded on the right with blanks.
   DD4PALT
       is the user ID of the end user requesting the work from the
       master/worker service.  This user ID appears as the originator of the
       spool files.  If specified and less than eight characters, it must be
       padded on the right with blanks.  If set to zero (not specified), then
       the alternate user ID function is set off.
   Exit values:
   Return
   Code (Rx) Meaning
   0         Successful completion
   4         I/O error while paging in the parameter list
   8         Worker virtual machine not found
   12        RACF authorization denied
   16        Alternate user ID currently set with APPC/VM.
   Errors:
   You may receive one of the following program checks if the DIAGNOSE code
   X'D4' input data is invalid:

   | Privileged operation    | The issuer does not have class B privileges   |
