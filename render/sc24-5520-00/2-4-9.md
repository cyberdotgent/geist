## 2\.4\.9 REJECT

<a id="HDRREJECT"></a>

Use the REJECT function to refuse a specified message\. When you "reject" a message, IUCV reflects a message complete interrupt to the virtual machine that sent you the message \(the source virtual machine\)\. The source virtual machine must examine the audit trail of the message \(IPAUDIT\) to determine that the message was rejected\.

The format of the REJECT function is:

<a id="TBLTBLUNIQ68"></a>

```
    ____ _____ ______________________________________________________________
   | lab|lIUCV|                                                              |
   |    |     | REJECT,PRMLIST={label|(reg)}                                 |
   |    |     |             [,MSGID={label|(reg)}]                           |
   |    |     |             [,PATHID={label|(reg)}]                          |
   |    |     |             [,TRGCLS={label|(reg)}]                          |
   |    |     |             [,MF=L]                                          |
   |    |     |                                                              |
   |____|_____|______________________________________________________________|
```
