## 2.4.8 RECEIVE

<a id="HDRRECEIVE"></a>

Use the RECEIVE function to receive messages. When you issue the RECEIVE

function, IUCV moves the message data from the source virtual machine's send area to your receive area.

**Note:** If the receive area cannot contain the complete message, you can issue another RECEIVE to obtain the remainder of the message. As part of the RECEIVE output parameter list, the IPBFLN1 field tells you if your receive area is too small, too big, or just right. If you do need to issue a subsequent RECEIVE, you must identify the message by message ID, path ID, and message class to receive the remainder. The format of the RECEIVE function is:
