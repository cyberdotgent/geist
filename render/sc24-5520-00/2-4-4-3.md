#### 2\.4\.4\.3 DESCRIBE Parameter List Format

The format of the DESCRIBE parameter list is:

<a id="FIGFIGUNIQ59"></a>

```
      IPARML DSECT

      0      1        2         3         4         5         6       7
      _____________ __________ __________ ________________________________ 
    0|   IPPATHID  | IPFLAGS1 | IPRCODE  |                 IPMSGID        |
     |_____________|__________|__________|________________________________|
    8|           IPTRGCLS                |           IPRMMSG1             |
     |___________________________________|________________________________|
   10|       IPBFLN1F/IPRMMSG2           | ////////////////////////////// |
     |___________________________________|________________________________|
   18| ////////////////////////////////////////////////////////////////// |
     |___________________________________ ________________________________|
   20|           IPBFLN2F                | ////////////////////////////// |
     |___________________________________|________________________________|
```
