#### 2.4.3.2 Optional Input

1. *MF=L*. If you want to build an IUCV parameter list without issuing the IUCV instruction, specify MF=L. This option allows programs to build an IUCV parameter list and pass that parameter list to an operating system that provides an IUCV interface. The IUCV macro fills in the parameter list in the same manner as if the MF=L option had not been specified. The macro does not initialize any registers, and does not generate the IUCV instruction.:H4 2. *If* *you* *want* *the* *buffer* *you* *are* *declaring* *to* *be* *a* *control* *buffer*. This function is a mechanism to let a supervisor use IUCV without disturbing an application's use of IUCV along a regular path. Because CONTROL=parameter specifies whether this buffer is for use with control paths or application paths, do one of the following: a. Use CONTROL=YES to indicate that this buffer is for use with control paths. b. Use CONTROL=NO to indicate that this buffer is to be used with application paths.
