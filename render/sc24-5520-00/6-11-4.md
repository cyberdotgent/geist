## 6.11.4 *BLOCKIO System Service

<a id="HDRBLKIO"></a>

The DASD block I/O system service (*BLOCKIO) provides a virtual machine with device-independent access to its virtual disk devices. *BLOCKIO uses the IUCV to set up communication between itself and a virtual machine. The virtual machine issues a DECLARE BUFFER command to initialize for IUCV communication; the IUCV processor initializes the DASD block I/O system service for IUCV communication by issuing the DECLARE BUFFER for the system service. After communication is established with the IUCV, the virtual machine must issue a CONNECT command to establish a path between itself and *BLOCKIO. Only one CONNECT may be issued to *BLOCKIO for each virtual device that is intended to receive I/O requests. No special authorization is required for a virtual machine to use *BLOCKIO. The maximum connection limit (MAXCONN) in the directory can be enlarged to satisfy the user's requirements. *BLOCKIO allows connection from any user. The IUCV macro checks the validity of all the IUCV parameters. Any IUCV

errors are handled according to IUCV specifications. *BLOCKIO checks the validity of all the parameters it requires. Any errors resulting from this check are handled as described in the following sections.
