#### 2.4.13.8 SEND Parameter List Input Fields

IPPATHID contains the path identifiers IUCV associates with a message. IPFLAGS1 specifies options for the SEND function. IUCV treats each bit in IPFLAGS1 separately. Make sure that bits you are not using to define input are set to 0. IPANSLST flag (bit X'08') indicates, when set to 1, that the address specified in IPBFADR2 is the address of a list of answer buffers and their respective lengths. That also shows the IPBFLN2F is the total length of the list. IPNORPY flag (bit X'10') indicates, when set to 1, that this is a 1-way message. IPPRTY flag (bit X'20') indicates, when set to 1, that you are sending a priority message. IPBUFLST flag (bit X'40') indicates, when set to 1, that the address specified in IPFADR1 is the address of a list of buffers and their respective lengths. It also shows that the IPBFLN1F is the total length in the list. IPRMDATA flag (bit X'80') indicates, when set to 1, that the message text is in the parameter list. IPTRGCLS contains the target message class. IPBFADR1 contains the address of the input buffer (the area from which IUCV takes the message text). IPBFLN1/IPBFLN1F specifies the length of the input buffer (IPBFADR1 field). IPMSGTAG contains the tag data of the message. IPBFADR2 contains the address of the area into which IUCV places the reply text. IPBFLN2F contains the length of the area into which IUCV places the reply text (IPBFADR2 field). Use IPBFLN2 to specify a halfword; IPBFLN2F to specify a fullword. If you specify IPBFLN2, make sure you clear to zeros the high order bits of IPBFLN2F.

**Note:** If you use the ANSLEN parameter to specify the length of the reply buffer, IUCV automatically clears the high-order bits of IPBFLN2F.

IPSRCCLS contains the source message class. IPRMMSG1/IPRMMSG2 contains message data that you have stored in your parameter list rather than a buffer. You can specify IPRMMSG to refer to the combined IPRMMSG1 and IPRMMSG2 fields.
