#### 5.10.12.4 SEVER Input Parameter List

[FIGSVIPL](#FIGSVIPL) The IUCV SEVER parameter list has the input format shown in Figure 68.

<a id="SVIPL IPARML DSECT 0 1 2 3 4 5 6 7 0 IPPATHID IPFLAGS1 /////////////////////////////////////// 8 //////////////////////////////////////////////////////////////// 10 IPUSER 18 IPUSER 20 //////////////////////////////////////////////////////////////// Figure 68. IUCV SEVER Input Parameter List"></a>

**IPPATHID** contains the path ID of the path you want to sever. **IPFLAGS1** contains options for the SEVER function. IPAPPC (X'08') indicates the protocol to be used on this path. This bit must be set to 0. IPKEEP (X'10') indicates that the path ID is not to be freed for reuse after the IUCV SEVER completes.

**Note:** This flag is ignored on a non-APPC/VM path, or if the IPALL flag is set on. IPALL (X'80') indicates that you want to sever all paths for this virtual machine.

**IPUSER** contains the user data that IUCV reflects across the path.
