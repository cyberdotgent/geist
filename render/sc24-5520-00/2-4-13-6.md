#### 2.4.13.6 Optional Input

1. *The* *priority* *of* *the* *message*. To send a priority message, do one of the following: a. Use the PRTY=parameter. PRTY=YES specifies that you are sending a priority message.

**Note:** For your virtual machine to handle priority communications, your user directory entry must include the appropriate statement. PRTY=NO, the default value, specifies that the message you are sending is not a priority message. b. Set the IPPRTY flag (bit X'20') to 1 in the IPFLAGS1 field of the SEND parameter list.

**Note:** If you use the PRTY=parameter, IUCV sets this flag automatically.

2. *The* *source* *message* *class* *of* *the* *message*. Do this in one of the following ways: a. Use the IPSRCCLS=parameter. Specify the source message class as (1) the relocatable label of a fullword containing the source message class, or (2) the number of a register containing the source message class. b. Store the source message class in the IPSRCCLS field of the SEND parameter. Also, set the IPFGMCL bit (X'02') to 1 in the IPFLAGS1 field.

**Note:** If you use the

parameter, IUCV stores this value automatically.

3. *The* *target* *message* *class* *of* *the* *message*. Do this in one of the following ways: a. Use the TRGCLS=parameter. Specify the target message class as (1) the relocatable label of a fullword containing the target message class, or (2) the number of a register containing the target message class. b. Store the target message class in the IPTRGCLS field of the SEND parameter. Also, set the IPFGMCL bit (X'02') to 1 in the IPFLAGS1 field.

**Note:** If you use the IPTRGCLS=parameter, IUCV stores this value automatically.

4. *A* *message* *tag* *for* *the* *message* *you* *are* *sending*. Do this in one of the following ways: a. Use the MSGTAG=parameter. Specify the tag as (1) a relocatable label for a fullword containing the tag, or (2) the number of a register that contains the tag. b. Store the message tag in the IPMSGTAG field of the SEND parameter.

**Note:** If you use the MSGTAG=parameter, IUCV stores this value automatically.

5. *MF=L*. Specify MF=L if you want to build an IUCV parameter list without issuing the IUCV instruction. This option allows programs to build an IUCV parameter list and pass that parameter list to an operating system that provides an IUCV interface. The IUCV macro fills in the parameter list in the same manner as if the MF=L option had not been specified. The macro does not initialize any registers, and does not generate the IUCV instruction.
