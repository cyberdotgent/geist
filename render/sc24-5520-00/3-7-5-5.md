### 3.7.5.5 Registers Altered By APPCVM and IUCV Macro Functions

If you specify MF=L on an APPCVM or IUCV macro function, the macro **may** **alter** **R0**. **If** you **do** not specify **MF=L,** R0 is still **altered,** and for IUCV functions only **R1** **may** **be** **altered**. For more information on macro parameter lists, see VM/ESA CMS Application Development Reference for Assembler.
