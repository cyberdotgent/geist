#### 2.3.3.5 Supplying Input to IUCV Functions

As mentioned in the previous section, to use IUCV you invoke the IUCV macro, specifying the name of the function that corresponds to the IUCV task you want to perform. Most IUCV functions require additional input, which you store in a designated IUCV parameter list [. "Setting Up an IUCV](2-3-5.md) [Parameter List" in topic 2.3.5](2-3-5.md) describes how to use the IPARML mapping macro to set up an IUCV parameter list.

**Note:** The IUCV macro checks the parameters you specify. If you code them

incorrectly, the IUCV macro issues error messages [. "IUCV Macro](2-6-5.md) Error M [essages" in topic 2.6.5 explai](2-6-5.md) ns the error messages in detail. There are two basic ways you can store input into the IUCV parameter list: 1. You can code your program to store input directly in an IUCV parameter list before the program invokes the IUCV macro instruction. Make sure that fields and bits you are not **usi**ng to define input are set to zero. 2. You can code keyword parameters on the IUCV macro. The macro then automatically stores values in the parameter list based on the parameter keywords you specify. [Table 44 in topic 2.3.3.4](#TBLU92FIG0) describes where you can find detailed information about each IUCV function. This information includes: 1. Required and optional inputs for the function 2. Keyword parameters you can use to supply input 3. The format of the IUCV parameter list for each function.
