### 7.12.1.1 Audit and Protect Attributes

An interface is provided for ESM auditing for all CP commands and DIAGNOSE codes and for the following security-relevant system functions: IUCV connect IUCV sever APPC connect APPC sever SPOOL file create SPOOL file delete SPOOL file open System data file create System data file delete System data file open. An interface is provided for ESM authorization for a subset of CP commands and DIAGNOSE codes. The following CP commands have an interface for ESM authorization: AUTOLOG

CHANGE.D [(29)](#FTNCMDS) CHANGE.G [(29)](#FTNCMDS) CLOSE (29 [) LIN](#FTNCMDS) K LOGON LOGOFF SPOOL (29 [) STO](#FTNCMDS) RE.C TAG TRSOURCE TRANSFER.D TRANSFER.G XAUTOLOG. The following DIAGNOSE codes have an interface for ESM authorization: DIAGNOSE code X'D4' DIAGNOSE code X'E4'. appropriate version of the TRANSFER command only *if* the command is being used to change the ownership of a spool file.
