#### 2\.4\.1\.3 ACCEPT Parameter List Format

The format of the ACCEPT parameter list is:

<a id="FIGFIGUNIQ53"></a>

```
     IPARML DSECT

      0      1        2         3         4         5         6       7
      ______________ _________ _________ ____________________ ____________ 
    0|   IPPATHID   | IPFLAGS1| IPRCODE |         IPMSGLIM   | ////////// |
     |______________|_________|_________|____________________|____________|
    8| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   10|                                                                    |
     |                             IPUSER                                 |
     |                                                                    |
     |____________________________________________________________________|
   20| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
```
