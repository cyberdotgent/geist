## 2\.4\.4 DESCRIBE

<a id="HDRDESCRIB"></a>

Use the DESCRIBE function to determine whether you have any messages pending on your send queue\. If IUCV finds a message pending, it returns information about the message in the DESCRIBE parameter list\.

**Notes:**

1\. When a virtual machine sends you a message, IUCV automatically informs you of the message by reflecting a message\-pending external interrupt to your virtual machine\. Therefore, unless you disable your virtual machine for IUCV message\-pending external interrupts, do not use the DESCRIBE function\. \(Use the SETMASK function to disable your virtual machine for message\-pending interrupts\)\.

2\. IUCV describes a particular message once\. It is your responsibility to use the RECEIVE or REJECT function to process a message after you request IUCV to describe it\.

The format of the DESCRIBE function is as follows:

<a id="TBLTBLUNIQ58"></a>

```
    ____ _____ ______________________________________________________________
   | lab|lIUCV| DESCRIBE,PRMLIST={label|(reg)}[,MF=L]                        |
   |____|_____|______________________________________________________________|
```
