#### 2\.4\.13\.4 Required Input for 1\-Way Messages

If you want to send a 1\-way message \(the virtual machine to which you are sending data cannot reply\), you must specify so\. Do this in one of the following ways:

1\. Use the TYPE=parameter\. TYPE=1WAY specifies a 1\-way transaction\. In a 1\-way transaction, the virtual machine to which you are sending data cannot reply\.

TYPE=2WAY, the default value, specifies a 2\-way transaction\.

2\. Set the IPNORPY bit \(X'10'\) to 1 of the IPFLAGS1 field of the SEND parameter list\.

**Note:** If you specify the TYPE=1WAY option, IUCV sets this bit automatically\.
