## 3.7.5 Understanding APPC/VM Parameter Lists

**Note:** The information in this section also applies to IUCV macro

functions that can be used on APPC/VM paths. Refer to [Chapter 10,](5-10.md) "IUCV M [acro Functions for Use in APPC/VM" in topic 5.10.](5-10.md) Parameter lists for all APPC/VM functions are 40 bytes. Your program can specify a single 40-byte area in storage to use for all APPC/VM function parameter lists. The address of the 40-byte area must be a guest real address. In other words, the address must be within the virtual machine's real address space (guest=real). The APPCVM and IUCV macros are both in the DMKGPI MACLIB, along with the IPARML DSECT. The APPCVM and IUCV macros use labels defined in IPARML DSECT to complete the parameter list. You need to provide a USING

for the IPARML COPY file when you invoke the macro, and define proper storage for it. To refer to fields in parameter lists for APPCVM and IUCV functions, always use the name defined for that field in the IPARML DSECT, rather than use the displacement within IPARML DSECT. The parameter lists (IPARML DSECT mappings) are shown with each APPCVM and IUCV macro function. All address fields in the APPCVM and IUCV parameter lists are 4-byte reserved fields.
