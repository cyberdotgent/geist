## 2\.6\.5 IUCV Macro Error Messages

<a id="HDRERRMSG"></a>

The IUCV macro checks the parameters you specify\. It verifies that all of the parameters are consistent and that the inputs are meaningful for the function you want to invoke\. If you code the IUCV macro incorrectly, the IUCV macro issues the following messages at assembly time\.

**THE FUNCTION IS NOT SPECIFIED**\.

Meaning The function \(the first parameter\) must be specified\.

Macro Response No further checking is done\. No code is generated\.

Action Required Supply the missing parameter and reassemble the program\.

**THE VALUE** *ffffffff* **IS NOT A VALID FUNCTION**\.

Meaning The parameter *ffffffff* was specified but is not a valid function\.

Macro Response No further checking is done\. No code is generated\.

Action Required Correct the invalid parameter and reassemble the program\.

**THE PARAMETER** *pppppppp* **IS NOT ALLOWED ON THE FUNCTION** *ffffffff*\.

Meaning The parameter *pppppppp* is not allowable input to the function specified *ffffffff*\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Remove the invalid parameter and reassemble the program\.

**THE OPTION** *oooooooo* **IS NOT VALID FOR THE PARAMETER** *pppppppp*\.

Meaning The value *oooooooo* is not a valid value for the parameter *pppppppp*\. The parameter *pppppppp* requires one of a set of keywords\. The value *oooooooo* is not in that set\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Correct the invalid parameter and reassemble the program\. Check which keywords are valid for this parameter\. Check the spelling of the value supplied\.

**THE PARAMETER** *pppppppp* **IS REQUIRED INPUT TO THE FUNCTION** *ffffffff*\.

Meaning The parameter *pppppppp* is a required input to the requested function *ffffffff*\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Supply the missing parameter and reassemble the program\. Check the spelling of the parameters specified\.

**THE PARAMETER** *pppppppp* **IS NOT ALLOWED WITH** *rrrrrrrr=oooooooo*\.

Meaning The parameter specified *pppppppp* is not allowed with the option specified \(*rrrrrrrr=oooooooo*\)\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Remove the invalid parameter and reassemble the program\.

**THE PARAMETER** *pppppppp* **IS ONLY ALLOWED WITH** *rrrrrrrr=oooooooo*\.

Meaning The parameter specified \(*pppppppp*\) can not be specified when the option *rrrrrrrr=oooooooo* is specified\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Remove the invalid parameter and reassemble the program\.

**THE PARAMETER** *pppppppp* **IS REQUIRED WITH** *rrrrrrrr=oooooooo*\.

Meaning The parameter *pppppppp* must be specified when the option *rrrrrrrr=oooooooo* is specified\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Correct the invalid parameter and reassemble the program\.

**THE PARAMETER** *rrrrrrrr=oooooooo* **IS NOT ALLOWED WITH THE FUNCTION** *ffffffff*

Meaning The function specified \(*ffffffff*\) does not allow the option specified \(*rrrrrrrr=oooooooo*\)\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Correct the invalid parameter and reassemble the program\.

**TOO MANY POSITIONAL PARAMETERS WERE SPECIFIED**\.

Meaning More than the number of positional parameters allowed was specified\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Correct the invalid parameter and reassemble the program\.

**THE PARAMETER** *pppppppp* **IS NOT ALLOWED WITH THE PARAMETER** *qqqqqqqq*\.

Meaning Two parameters were specified \(*pppppppp* and *qqqqqqqq*\) which are in conflict\. These two parameters cannot be specified together\.

Macro Response Checking of the remaining parameters for this function continues\. No code is generated\.

Action Required Correct the invalid parameter and reassemble the program\.
