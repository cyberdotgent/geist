#### 2\.4\.11\.3 RESUME Parameter List Format

The format of the RESUME parameter list is:

<a id="FIGFIGUNIQ74"></a>

```
      IPARML DSECT

      0      1        2         3         4         5         6       7
      ______________ _________ _________ _________________________________ 
    0|   IPPATHID   | IPFLAGS1| IPRCODE | /////////////////////////////// |
     |______________|_________|_________|_________________________________|
    8| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   10|                                                                    |
     |                             IPUSER                                 |
     |                                                                    |
     |____________________________________________________________________|
   20| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
```
