#### 2.4.10.6 REPLY Parameter List Input Fields

IPPATHID contains the path identification number of the message to which you are replying. IPFLAGS1 specifies options for the REPLY function. IUCV treats each bit in IPFLAGS1 separately. Make sure bits you are not using to define input are set to 0. IPFGMCL flag (bit X'01') indicates, when set to 1, that you have specified a target message class for the message you are attempting to receive. IPFGPID flag (bit X'02') indicates, when set to 1, that you have specified a path identification number for the message you are attempting to receive. IPFGMID flag (bit X'04') indicates, when set to 1, that you have specified a message identification number for the message you are attempting to receive. IPANSLST flag (bit X'08') indicates, when set to 1, that the address specified in IPBFADR2 is the address of a list of answer buffers and their respective lengths. It also shows that IPBFLN2F is the total length of the list. IPPRTY flag (bit X'20') indicates that the response is a priority response. IPRMDATA flag (bit X'80') indicates, when set to 1, that the response data is in the parameter list. IPMSGID contains the message identification number of the message to which you are replying. IPTRGCLS contains the message class of the message to which you are replying. IPRMMSG1/IPRMMSG2 contains response data if you send data from a parameter list rather than a buffer. IPBFADR2 contains the address of the area from which IUCV takes the reply you are sending. IPBFLN2/IPBFLN2F contains the length of the reply you are sending. Use IPBFLN2 to specify a halfword; IPBFLN2F to specify a fullword. If you specify IPBFLN2, make sure you clear to zeros the high order bits of IPBFLN2F.

**Note:** If you use the ANSLEN parameter to specify the reply length, IUCV automatically clears the high-order bits of IPBFLN2F.
