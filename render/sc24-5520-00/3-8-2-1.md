#### 3\.8\.2\.1 Format

<a id="TBLTBLUNIQ115"></a>

```
    _________ ___________ ___________________________________________________
   |         |           |                                                   |
   | [label] | APPCVM    | QRYSTATE    ,PRMLIST= {label}                     |
   |         |           |                       {(reg)}                     |
   |         |           |                                                   |
   |         |           |                                                   |
   |         |           |                                                   |
   |         |           |            |,MF=L|                                |
   |         |           |            |     |                                |
   |         |           |                                                   |
   |         |           |            |,PATHID=  {label}|                    |
   |         |           |            |          {(reg)}|                    |
   |         |           |            |                 |                    |
   |_________|___________|___________________________________________________|
   | Note:  The following parameter is reserved for IBM use only:            |
   |_________ ___________ ___________________________________________________|
   |         |           |                                                   |
   |         |           |            |,SYNCFLG=  {SYNCON }|                 |
   |         |           |            |           {SYNCOFF}|                 |
   |         |           |            |                    |                 |
   |_________|___________|___________________________________________________|
```
