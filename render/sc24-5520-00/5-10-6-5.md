## 5.10.6.5 DCLBFR Input Parameter List

<a id="HDRDCBFRPL"></a>

#### DCLBFR Input Parameter List

The IUCV DCLBFR parameter list has the input format shown in [Figure 63](#FIGDCIPL).

<a id="DCIPL IPARML DSECT 0 1 2 3 4 5 6 7 0 //////////// IPFLAGS1 ///////////////////////////////////// 8 /////////////////////////////// IPBFADR1 10 ////////////////////////////////////////////////////////////// 18 /////////////////////////////// IPBFADR2 20 IPBFLN2F //////////////////////////// Figure 63. IUCV DCLBFR Input Parameter List"></a>

IPFLAGS1 may contain the following input bit flag: IPCNTRL (X'04') a control buffer is being established. IPBFADR1 identifies the area where information about an APPC/VM or IUCV external interrupt is stored. IPBFADR2 specifies the address of the interrupt buffer extension. IPBFLN2F specifies the length of the interrupt buffer extension.
