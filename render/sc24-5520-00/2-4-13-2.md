#### 2.4.13.2 Required Inputs for Sending Message Data From a Buffer

If you store the message data you are going to send in a buffer, rather than in your parameter list, you must do the following:

1. *Specify* *the* *address* *of* *the* *buffer*. Do this in one of the following ways: a. Use the BUFFER=parameter. Specify the buffer as (1) the relocatable label of the buffer, or (2) the number of a register that contains the address of the buffer. b. Store the address of the buffer in the IPBFADR1 field of the SEND parameter list.

**Note:** If you use the BUFFER=parameter, IUCV stores this value automatically.

2. *Specify* *the* *length* *of* *the* *buffer*. If you did not specify BUFLIST=YES, the BUFLEN=parameter specifies the length of the area specified on the BUFFER=parameter. If you specify BUFLIST=YES, you must specify with BUFLEN= the sum of the individual buffer lengths in the list pointed to by BUFFER=. Specify the buffer length in one of the following ways: a. Use the BUFLEN=parameter. Specify the length as (1) the relocatable label of the location containing the buffer length, or (2) the number of a register that contains the length of the buffer. IUCV assumes a halfword value for the length at the storage location specified, or in the low-order halfword of the register specified. If a length modifier of 4 is used, IUCV uses the fullword value for the length at the storage location or in the register specified. b. Store the length of the buffer in the IPBFLN1 field of the SEND parameter list.

**Note:** If you use the BUFLEN=parameter, IUCV stores this value automatically.
