#### 2.4.7.2 Optional Input

1. *16-bytes* *of* *data* *that* *IUCV* *reflects* *to* *the* *virtual* *machine* *with* *which* you *hav*e *est*a*blished a p*a*t*h*. S*pecify the address of this data area in one of the following ways: a. Use the USERDTA=parameter. Specify the 16-byte user data area as (1) the relocatable label of the 16-byte user data storage area, or (2) the number of a register that contains the address of the 16-byte user data storage area. b. Store the address of the 16-byte data area in the IPUSER field of the CONNECT parameter list.

**Note:** The USERDTA=parameter does this automatically.

2. *MF=L*. Specify MF=L if you want to build an IUCV parameter list without issuing the IUCV instruction. This option allows programs to build an IUCV parameter list and pass that parameter list to an operating system that provides an IUCV interface. The IUCV macro fills in the parameter list in the same manner as if the MF=L option had not been specified. The macro does not initialize any registers, and does not generate the IUCV instruction.
