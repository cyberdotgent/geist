### 3.7.5.1 Setting Defaults for Optional Parameters

If you do not specify a parameter shown as *optional* when you invoke an APPCVM or IUCV macro function, the macro assumes that you have stored a value in the parameter list before invoking the APPCVM macro. **Therefore,** and **you** **should** **set** **to** **0** **all** **fields** **and** **flag** **bits** **in** **the** **parameter** **list** **that** **you** **are** **not** **defining** **for** **a** **particular** **APPCVM** **or** **IUCV** **macro** **function**. This helps ensure that if these fields are defined in the future, applications will continue to work. Note that some parameters shown with APPCVM and IUCV macro functions are underlined to show that they are default values. The underlined value is then used if you set the parameter list to 0 and do not specify the parameter on the macro call.
