## 4\.9\.4 Shared APPC/VM and IUCV Functions

Several functions are shared for both APPC/VM and IUCV\. This section describes these functions as they relate to an APPC/VM environment\. [Chapter 10, "IUCV Macro Functions for Use in APPC/VM" in topic 5\.10](5-10.md) describes the IUCV versions of these functions unrelated to APPC/VM\. Parameters other than those described in this book are available, but have no meaning on APPC/VM paths and are ignored\.
