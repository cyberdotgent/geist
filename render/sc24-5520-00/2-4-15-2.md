#### 2.4.15.2 Optional Input

1. *MF=L*. Specify MF=L if you want to build an IUCV parameter list without issuing the IUCV instruction. This option allows programs to build an IUCV parameter list and pass that parameter list to an operating system that provides an IUCV interface. The IUCV macro fills in the parameter list in the same manner as if the MF=L option had not been specified. The macro does not initialize any registers, and does not generate the IUCV instruction.
