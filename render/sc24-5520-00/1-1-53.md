## 1.1.53 DIAGNOSE Code X'260'--Access Certain Virtual Machine Information

**Privilege** **Class:** Any Use DIAGNOSE code X'260' to access certain virtual machine information. **Entry** **Values:** Ry must be X'00000000'. **Exit** **Values** Rx is equal to the highest addressable byte of virtual storage. **Program** **Check** A specification exception is given if Ry does not contain X'00000000'.
