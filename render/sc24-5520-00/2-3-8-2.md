#### 2\.3\.8\.2 One\-Way Messages with Data in a Buffer

[Figure 12](2-3-8-2.md#FIGC92FIG4) shows the events that take place when SOURCE sends TARGET a 1\-way message where the message data is stored in a storage buffer, rather than the SEND parameter list\.

<a id="FIGC92FIG4"></a>

```
    ________________________________________________________________________ 
   |                                                                        |
   | SOURCE's Virtual Machine            TARGET's Virtual Machine           |
   |                                                                        |
   | SOURCE uses the SEND function                                          |
   | to send a message to TARGET                                            |
   | specifying (a) that the                                                |
   | message data is contained in                                           |
   | a storage buffer and (b) that                                          |
   | the message is a 1_way                                                 |
   | message.                   _______→ TARGET gets a "message pending"    |
   |                                     interrupt from IUCV.  The data     |
   |                                     in the external interrupt buffer   |
   |                                     informs TARGET that (a) the        |
   |                                     message is a 1_way message and     |
   |                                     (b) SOURCE is sending message data |
   |                                     from a storage buffer.             |
   |                                                    |                   |
   |                                                    ↓                   |
   |                                     TARGET issues the RECEIVE          |
   |                                     function, causing IUCV to move     |
   |                                     the message data from SOURCE's     |
   |                                     storage buffer to TARGET's         |
   | SOURCE gets a "message     ←_______ storage buffer.                    |
   | complete" interrupt from                                               |
   | IUCV.                                                                  |
   |                                                                        |
   |________________________________________________________________________|
```

*Figure 12\. One\-Way IUCV Messages with Data in a Storage Buffer*
