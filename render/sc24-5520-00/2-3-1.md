## 2\.3\.1 Who Should Use the IUCV

The inter\-user communication vehicle \(IUCV\) is a facility that enables an application program running in a virtual machine to communicate with other virtual machines, CP system services, and with itself\. IUCV provides a secure method for sending any amount of data\. It's also good for sending test data from one virtual machine to another for processing\.

Before using IUCV, please note that this chapter and the next are intended for experienced applications programmers; they assume that you know how to code an external interrupt handler for whatever operating system you run\.

**Note:** VM/ESA IUCV is compatible with VM/SP and VM/SP HPO IUCV\. However, VM/ESA with the ESA feature supports only the following CP system services: \*ACCOUNT, \*BLOCKIO, \*CRM, \*IDENT, \*LOGREC, \*MONITOR, \*MSG, \*MSGALL, \*RPI, \*SIGNAL, \*SPL, and \*SYMPTOM\.
