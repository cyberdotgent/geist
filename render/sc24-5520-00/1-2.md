# 1\.2 Chapter 2\. Comparing VM/ESA \(370 Feature\) and VM/ESA \(ESA Feature\) DIAGNOSE Codes

<a id="HDRSPXA"></a>

The following table compares the functions that are available for VM/370 DIAGNOSE codes with their counterparts in VM/ESA\.

"Yes" indicates that the function is available in the operating system\. "No" indicates that the function is not available\. The "Notes" column describes in detail how the VM/ESA DIAGNOSE codes differ from those available with VM/ESA \(370 Feature\)\.

The term "available" here does not imply support for customer programming use\. See the individual DIAGNOSE code descriptions for interface information\.
