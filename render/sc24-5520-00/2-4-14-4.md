#### 2.4.14.4 SETCMASK Parameter List Input Fields

IPCMASK contains the mask byte that specifies the IUCV external interrupts for which, if any, your virtual machine is enabled. The bits in the mask byte have been described previously in ["SETCMASK Required Input" in](2-4-14-1.md) t [opic 2.4.14.1.](2-4-14-1.md)
