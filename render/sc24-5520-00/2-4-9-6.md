#### 2\.4\.9\.6 REJECT Parameter List Output Fields

`IPPATHID` contains the path identification number of the message you are rejecting\.

`IPRCODE` contains one of the following return codes:

**Code Meaning**

00 Normal return\.

01 You specified an invalid path identification number\.

08 The message class or path identification number you specified does not correspond to the message identification number you specified\.

31 The \(X'1F'\) IUCV function was specified on an APPC/VM path\.

`IPMSGID` contains the message identification number of the message you are rejecting\.

`IPTRGCLS` contains the message class of the message you are rejecting\.
