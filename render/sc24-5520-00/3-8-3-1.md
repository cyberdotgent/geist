#### 3\.8\.3\.1 Format

```
    _________ ___________ ___________________________________________________
   |         |           |                                                   |
   | [label] | APPCVM    | RECEIVE     ,PRMLIST= {label}                     |
   |         |           |                       {(reg)}                     |
   |         |           |                                                   |
   |         |           |                                                   |
   |         |           |                                                   |
   |         |           |            |,MF=L|                                |
   |         |           |            |     |                                |
   |         |           |                                                   |
   |         |           |            |,PATHID=  {label}|                    |
   |         |           |            |          {(reg)}|                    |
   |         |           |            |                 |                    |
   |         |           |                                                   |
   |         |           |            |,BUFLIST=  {YES}|                     |
   |         |           |            |           {NO }|                     |
   |         |           |            |                |                     |
   |         |           |                                                   |
   |         |           |            |,BUFFER=  {label}|                    |
   |         |           |            |          {(reg)}|                    |
   |         |           |            |                 |                    |
   |         |           |                                                   |
   |         |           |            |,BUFLEN=  {label}|                    |
   |         |           |            |          {(reg)}|                    |
   |         |           |            |                 |                    |
   |         |           |                                                   |
   |         |           |            |,WAIT=  {YES}|                        |
   |         |           |            |        {NO }|                        |
   |         |           |            |             |                        |
   |         |           |                                                   |
   |         |           |            |,PIP=  {YES}|                         |
   |         |           |            |       {NO }|                         |
   |         |           |            |            |                         |
   |         |           |                                                   |
   |         |           |                                                   |
   |_________|___________|___________________________________________________|
```
