## 1\.1\.29 Diagnose Code X'74'\-\-Saving and Loading an Image Library File

**Privilege Class:** A, B, C, or E

**Entry Values:**

Rx Contains the first four characters of the image library filename\.

Rx\+1 Contains the last four characters of the image library filename, where the name is left\-justified and padded with blanks\.

Ry Contains the guest real address of where the data is to start\. Data must start on a page boundary\.

Ry\+1 Contains the number of bytes and a subcode for either loading or saving of the image library file\. This code is located in bits 0 through 7\. The number of bytes may not extend past guest storage size into shared storage\.

**Usage Notes:**

If the number of bytes to save \(in Ry\+1\) is specified as zero, the image library is not created\. If an image library with the same name already existed, it will be unchanged\.

<a id="TBLTBLUNIQ20"></a>

```
    ____________ ______________ _____________________________________________
   | Subcode    | Function     | Description                                 |
   |____________|______________|_____________________________________________|
   | X'00'      | LOAD         | Loads an image library into guest real      |
   |            |              | storage from an image library file.         |
   |____________|______________|_____________________________________________|
   | X'04'      | SAVE         | Saves an image library from the guest's     |
   |            |              | real storage area into an image library     |
   |            |              | file.                                       |
   |____________|______________|_____________________________________________|
```

**Note:** These subcodes are bits 0 through 7 of the Ry\+1 register\.

**Responses:**

*Normal Exit:* Upon a normal exit condition, you receive a condition code of 0 or 1, indicating that the image library file was saved or loaded successfully\. You also receive a return code in Ry\. Refer to the following chart for the meaning:

<a id="TBLTBLUNIQ21"></a>

```
    _________________ _______________ _______________________________________
   | Function and    | Return Code   |                                       |
   | Condition Code  | in Ry (Hex)   | Status                                |
   |_________________|_______________|_______________________________________|
   | LOAD, CC=0      | X'00'         | An image library file was loaded      |
   |                 |               | successfully.                         |
   |_________________|_______________|_______________________________________|
   | SAVE, CC=0      | X'00'         | The new image was saved successfully. |
   |_________________|_______________|_______________________________________|
   | SAVE, CC=1      | X'00'         | An image file of the same name has    |
   |                 |               | been replaced.                        |
   |_________________|_______________|_______________________________________|
```

*Exit with Error:* Upon an error exit condition, you receive a condition code of 3, indicating that the image library file was not saved or loaded successfully\. You will also receive a return code in Ry\. Refer to the following chart for the meaning:

<a id="TBLTBLUNIQ22"></a>

```
    _________________ _______________ _______________________________________
   | Function and    | Return Code   |                                       |
   | Condition Code  | in Ry (Hex)   | Status                                |
   |_________________|_______________|_______________________________________|
   | LOAD            | X'04'         | Image library file not found          |
   |_________________|_______________|_______________________________________|
   | LOAD            | X'14'         | The image length specification is     |
   |                 |               | greater than the actual size of the   |
   |                 |               | image.  The residual byte count is in |
   |                 |               | Ry+1                                  |
   |_________________|_______________|_______________________________________|
   | LOAD            | X'18'         | Paging or spooling error              |
   |_________________|_______________|_______________________________________|
   | LOAD            | X'1C'         | The image length specification is     |
   |                 |               | less than the actual size of the      |
   |                 |               | image.  The residual byte count is in |
   |                 |               | Ry+1                                  |
   |_________________|_______________|_______________________________________|
   | LOAD            | X'24'         | Abnormal termination occurred; an     |
   |                 |               | NSI001 soft abend generated.          |
   |_________________|_______________|_______________________________________|
   | LOAD            | X'28'         | Invalid filename specified            |
   |_________________|_______________|_______________________________________|
   | SAVE            | X'08'         | Image library file currently active   |
   |_________________|_______________|_______________________________________|
   | SAVE            | X'18'         | Paging or spooling error              |
   |_________________|_______________|_______________________________________|

   |_________________|_______________|_______________________________________|
   | SAVE            | X'28'         | Invalid filename specified            |
   |_________________|_______________|_______________________________________|
   | SAVE            | X'2C'         | No spool file IDs available           |
   |_________________|_______________|_______________________________________|
```
