## 1.1.29 Diagnose Code X'74'--Saving and Loading an Image Library File

**Privilege** **Class:** A, B, C, or E

**Entry** **Values:**

Rx Contains the first four characters of the image library filename. Rx+1 Contains the last four characters of the image library filename, where the name is left-justified and padded with blanks. Ry Contains the guest real address of where the data is to start. Data must start on a page boundary. Ry+1 Contains the number of bytes and a subcode for either loading or saving of the image library file. This code is located in bits 0 through 7. The number of bytes may not extend past guest storage size into shared storage.

**Usage** **Notes:** If the number of bytes to save (in Ry+1) is specified as zero, the image library is not created. If an image library with the same name already

existed, it will be unchanged.
