## 5.10.6 IUCV DCLBFR (Declare Buffer)

<a id="HDRXDCL"></a>

and IUCV can use to store external interrupt data. After you receive an external interrupt, this buffer contains information about the message, reply, or control function that caused the interrupt. When you issue DCLBFR, the virtual machine is enabled for all types of APPC/VM and IUCV external interrupts. Use the SETMASK and the SETCMASK functions to change these initial settings. In addition, programs using control paths can set up an interrupt buffer extension. **Note:** The IUCV interrupt mask in control register 0 is not affected by DCLBFR. See " [IUCV SETMASK" in topic 5.10.11](5-10-11.md) for more details. If your program is running in a CMS environment, you can use HNDIUCV SET to do the same job as DCLBFR.
