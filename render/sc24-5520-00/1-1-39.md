## 1\.1\.39 Diagnose Code X'B0'\-\-Access Re\-IPL Data

**Privilege Class:** Any

Use DIAGNOSE Code X'B0' to obtain diagnostic information about the cause of the automatic re\-IPL of your virtual machine\. The data returned by the system also includes the IPL statement from the directory entry for the issuing user\.

**Entry Values:**

Rx Contains the guest real address of the buffer for the output data\.

Ry Contains the length of the buffer\. Any non\-negative length is allowed\. To avoid possible truncation of data, a buffer of at least 90 bytes is recommended\.

**Exit Values:**

Rx Unchanged

Ry Contains a completion code, as follows:

<a id="TBLTBLUNIQ31"></a>

```
    __________ ______________________________________________________________
   | Code     | Meaning                                                      |
   |__________|______________________________________________________________|
   | 0        | Re-IPL information is returned in the buffer.                |
   |__________|______________________________________________________________|
   | 4        | No re-IPL information is available.  Either the protected    |
   |          | application environment is not active, or the IPL was        |
   |          | initiated by the user.                                       |
   |__________|______________________________________________________________|
   | 8        | No information is available.  A paging or storage error has  |
   |          | occurred.                                                    |
   |__________|______________________________________________________________|
```

**Buffer Content:**

Successful completion of the request may result in output consisting of re\-IPL information, IPL statement information from the directory, both types of information, or neither\. Only as much information is returned as fits in the output area supplied\.

**Re\-IPL Information:**

If the completion code is zero, the buffer contains re\-IPL information consisting of the following:

**Byte 0:** Error code

The codes and the errors to which they correspond are shown in [Table 26](<#TBLB0EC>)\.

<a id="TBLB0EC"></a>

```
    _________________________________________________________________________
   | Table 26. DIAGNOSE X'B0' Meanings for Error Codes                       |
   |____________ ____________________________________________________________|
   | Code       | CP Meaning                                                 |
   |____________|____________________________________________________________|
   | X'01'      | CP has been entered; a disabled wait PSW is provided in a  |
   |            | message in the buffer.                                     |
   |____________|____________________________________________________________|
   | X'02'      | CP has been entered; external interrupt loop               |
   |____________|____________________________________________________________|
   | X'03'      | CP has been entered; paging error                          |
   |____________|____________________________________________________________|
   | X'04'      | CP has been entered; program interrupt loop                |
   |____________|____________________________________________________________|
   | X'07'      | CP has been entered; complex interrupt loop                |
   |____________|____________________________________________________________|
   | X'08'      | A system soft abend has occurred; an abend code is         |
   |            | provided in a message in the buffer.                       |
   |____________|____________________________________________________________|
   | X'09'      | The CPU has stopped; a check-stop state has been entered.  |
   |____________|____________________________________________________________|
   | X'0A'      | Page zero has been damaged.                                |
   |____________|____________________________________________________________|
   | X'0B'      | An error occurred, but CP was unable to provide a message  |
   |            | due to a paging error.                                     |
   |____________|____________________________________________________________|
```

**Bytes 1\-n:** Variable data

The additional variable length data, if present, depends on the particular error condition\. The variable length data is shown in [Table 27](<#TBLB0VLD>)\.

<a id="TBLB0VLD"></a>

```
    _________________________________________________________________________
   | Table 27. DIAGNOSE Code X'B0' Variable Length Data                      |
   |____________ ____________________________________________________________|
   | Code       | Variable Data                                              |
   |____________|____________________________________________________________|
   | X'01'      | An 8-byte binary disabled wait state PSW                   |
   |____________|____________________________________________________________|
   | X'02'      | An 8-byte binary external interrupt old PSW                |
   |____________|____________________________________________________________|
   | X'03'      | None                                                       |
   |____________|____________________________________________________________|
   | X'04'      | An 8-byte binary program interrupt old PSW                 |
   |____________|____________________________________________________________|
   | X'07'      | None                                                       |
   |____________|____________________________________________________________|
   | X'08'      | An EBCDIC CPU number                                       |
   |            | An EBCDIC abend code                                       |
   |____________|____________________________________________________________|
   | X'09'      | An EBCDIC CPU number                                       |
   |____________|____________________________________________________________|
   | X'0A'      | None                                                       |
   |____________|____________________________________________________________|
   | X'0B'      | A CP module name                                           |
   |            | An EBCDIC offset into module                               |
   |____________|____________________________________________________________|
```

EBCDIC variable data items \(for codes above X'07'\) are delimited by 1\-byte binary fields\. The field between multiple data items is X'00'\. The field following the final data item is X'01'\. For example, the buffer contents returned for a soft abend is the following \(assuming the buffer is large enough\):

- X'08'
- CPU number
- X'00'
- Abend code
- X'01'

**IPL Statement Information:**

**Byte 0:** The length of the IPL directory statement

This data is present whether or not a re\-IPL occurred\. It is zero if the user has no IPL statement in the directory, or if the output area is too small to contain at least one byte of text\. If the entire IPL statement does not fit in the area, this length is that of the text truncated to fit in the available space\.

**Bytes 1\-m:** The text of the IPL directory statement

This data is present if the preceding length byte is non\-zero\.

**Program checks:**

The virtual machine invoking this function receives program checks as shown in [Table 28](<#TBLB0PC>) if the DIAGNOSE instruction is incorrectly issued\.

<a id="TBLB0PC"></a>

```
    _________________________________________________________________________
   | Table 28. Program Checks for DIAGNOSE Code X'B0'                        |
   |________________________________ ________________________________________|
   | Problem Encountered            | Cause                                  |
   |________________________________|________________________________________|
   | Specification exception        | The buffer length is negative, or the  |
   |                                | buffer crosses a page boundary.        |
   |________________________________|________________________________________|
   | Addressing exception           | The buffer address is outside of the   |
   |                                | virtual machine's storage.             |
   |________________________________|________________________________________|
   | Protection exception           | CP detects a store protect violation   |
   |                                | on the buffer.                         |
   |________________________________|________________________________________|
```

**Usage Notes:**

1\. If Ry specifies a length of zero on entry, the contents of Rx are not examined\. Ry contains the value zero if an automatic re\-IPL has occurred\. Otherwise, Ry contains the value four\.

2\. CP does not guarantee the validity of the IPL statement content for the virtual machine environment issuing DIAGNOSE code X'B0'\. It is the responsibility of the program issuing DIAGNOSE code X'B0' to use the information contained in it appropriately\. The re\-IPL information is first, except when there is no re\-IPL information available\. When both are present, the re\-IPL information precedes the IPL statement\.
