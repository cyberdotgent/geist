#### 2.4.8.8 Program Exceptions

The following program exceptions can occur if you invoke the RECEIVE function incorrectly: Specification: You did not define your parameter list on a doubleword boundary. Either you specified a message identification without specifying a path ID and message class, or you incorrectly set the IPFGMID, IPFGPID, AND IPFGMCL flags. Operation. IUCV is inactive; you have not used the DCLBFR function to declare an external interrupt buffer. Addressing: Your parameter list address is invalid; the address you specified is outside of your virtual machine's storage. The buffer address you specified is invalid.
