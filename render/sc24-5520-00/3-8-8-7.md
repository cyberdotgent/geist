#### 3.8.8.7 SENDREQ State Checks and State Changes

A state check results when APPCVM SENDREQ is issued from an improper state. (You also receive an IPRCODE when you issue a function from an improper state.) See the list of APPCVM SENDREQ return codes for all state check conditions. No state change occurs.
