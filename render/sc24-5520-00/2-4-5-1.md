#### 2\.4\.5\.1 PURGE Required Input

1\. *The address of the PURGE parameter list*\. Use the PRMLIST=parameter to identify to IUCV the address of your parameter list\. The address of the parameter list must be a guest real address \(an address that is real to your virtual machine\), and it must be on a doubleword boundary\.

Specify the address of the parameter list as \(a\) a relocatable label, or \(b\) the number of a register that contains the address\.

2\. *The identification of the message you want to purge*\. You must identify the message you want to purge; the next section describes how\.
