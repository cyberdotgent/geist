#### 2.4.5.6 PURGE Parameter List Output Fields

IPPATHID contains the path identification number of the message you purge. IPFLAGS1 contains the following values that IUCV returns for the PURGE function: IPNORPY (X'10') indicates, when set to 1, that the message is a 1-way message. IPPRTY (X'20') indicates, when set to 1, that the message is a priority message. IPRCODE contains one of the following return codes:

**Code** **Meaning** 00 Normal return.

01 You specified an invalid path identification number. 08 The message class or path identification number you specified does not correspond to the message identification number you specified. 31 IUCV function specified on an APPC/VM path. IPMSGID contains the message identification number of the message you purge. IPAUDIT contains the audit trail of the message. The meanings of the bits in the audit trail are:

<a id="TBLTBLUNIQ62"></a>

| Bit Code Meaning | IPADRPLE X'8000' Reply too long for the buffer | IPADSNPX X'4000' Protection exception on the send buffer |
| --- | --- | --- |
| IPADANPX X'1000' Protection exception on the answer | buffer | IPADANAX X'0800' Addressing exception on the answer |
| IPADRCPX X'0080' Protection exception on the receive | buffer | IPADRCAX X'0040' Addressing exception on the receive |


IPSRCCLS contains the message class of the message you purge. IPMSGTAG contains the message tag of the message you purge.
