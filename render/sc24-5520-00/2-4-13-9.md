#### 2.4.13.9 SEND Parameter List Output Fields

IPRCODE contains one of the following return codes: Code **M**ean**ing** 00 Normal return. 01 You specified an invalid path identification number. 02 The path over which you attempted to send the message is quiescent. 03 You have exceeded the message limit. 04 You attempted to send a priority message over a path that does not handle priority messages. 10 You specified a negative message length. 21 The virtual machine to which you sent a message cannot accept message data in its parameter list. 22 Negative SEND buffer length in list 25 PRMMSG and ANSLIST/BUFLIST not allowed 26 Buffer list not on a doubleword boundary 27 Answer list not on a doubleword boundary 30 IPAPPCSN flag in IPFLAGS1 not zero 31 IUCV function specified on an APPC/VM path 48 The CP system service you specified does not support this IUCV function. IPMSGID contains a message identification number that IUCV assigns the message.
