#### 3\.8\.10\.1 Format

```
    _________ ___________ ___________________________________________________
   |         |           |                                                   |
   | [label] | APPCVM    | SEVER       ,PRMLIST= {label}                     |
   |         |           |                       {(reg)}                     |
   |         |           |                                                   |
   |         |           |             ,TYPE=  {NORMAL}                      |
   |         |           |                     {ABEND }                      |
   |         |           |                                                   |
   |         |           |                                                   |
   |         |           |                                                   |
   |         |           |            |,CODE=  {label}|                      |
   |         |           |            |        {(reg)}|                      |
   |         |           |            |               |                      |
   |         |           |                                                   |
   |         |           |            |,MF=L|                                |
   |         |           |            |     |                                |
   |         |           |                                                   |
   |         |           |            |,PATHID=  {label}|                    |
   |         |           |            |          {(reg)}|                    |
   |         |           |            |                 |                    |
   |         |           |                                                   |
   |         |           |            |,WAIT=  {YES}|                        |
   |         |           |            |        {NO }|                        |
   |         |           |            |             |                        |
   |         |           |                                                   |
   |         |           |            |,BUFLIST=  {YES}|                     |
   |         |           |            |           {NO }|                     |
   |         |           |            |                |                     |
   |         |           |                                                   |
   |         |           |            |,BUFFER=  {label}|                    |
   |         |           |            |          {(reg)}|                    |
   |         |           |            |                 |                    |
   |         |           |                                                   |

   |         |           |            |          {(reg)}|                    |
   |         |           |            |                 |                    |
   |         |           |                                                   |
   |         |           |            |,KEEP=  {YES}|                        |
   |         |           |            |        {NO }|                        |
   |         |           |            |             |                        |
   |         |           |                                                   |
   |         |           |                                                   |
   |_________|___________|___________________________________________________|
```
