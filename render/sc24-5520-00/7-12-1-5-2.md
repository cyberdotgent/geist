#### 7\.12\.1\.5\.2 CP Command Auditing

<a id="HDRCOMAUD"></a>

If a user issues a CP command and if that command's AUDIT bit is on, CP calls the ACI\. CP formats the general ACIPARMS parameter list, but with the variations shown in [Table 58](<#TBLACBCA>)\.

<a id="TBLACBCA"></a>

```
    _________________________________________________________________________
   | Table 58. ACIPARMS Control Block for CP Command Auditing                |
   |____________ ____________ _________ __________ __________________________|
   |            |            | Byte    |          |                          |
   |            |            | Offset  |          |                          |
   | Label      | Description| Dec(Hex)| Bytes    | Contents                 |
   |____________|____________|_________|__________|__________________________|
   | ACIEVENT   | Event Name | 72(48)  | 8        | This field is set to the |
   |            |            |         |          | command name.            |
   |            |            |         |          |                          |
   |            |            | .       |          |                          |
   |            |            | .       |          |                          |
   |            |            | .       |          |                          |
   |            |            |         |          |                          |
   |____________|____________|_________|__________|__________________________|
   | ACIDATA    | Additional | 120(78) | Variable | This field contains the  |
   |            | Data       |         |          | contents of the command  |
   |            |            |         |          | buffer.                  |
   |____________|____________|_________|__________|__________________________|
```

VM/ESA can audit any CP command at any privilege class level\.
