## 7.12.1.5.2 CP Command Auditing

<a id="HDRCOMAUD"></a>

#### CP Command Auditing

If a user issues a CP command and if that command's AUDIT bit is on, CP calls the ACI. CP formats the general ACIPARMS parameter list, but with

the variations shown in [Table 58](#TBLACBCA).

<a id="ACBCA"></a>

Table 58. ACIPARMS Control Block for CP Command Auditing

| Byte | Offset | Label<br>Description<br>Dec(Hex) Bytes Contents<br>ACIEVENT<br>Event Name<br>72(48) 8 This field is set to the<br>command name.<br>.<br>ACIDATA<br>Additional<br>Data<br>120(78) Variable This field contains the<br>contents of the command<br>buffer. |
| --- | --- | --- |
