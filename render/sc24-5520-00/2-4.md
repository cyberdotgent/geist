# 2\.4 Chapter 4\. Inter\-User Communication Vehicle Function Reference

<a id="HDRUG9D"></a>

Using the information in this chapter, you should be able to find the reference information required to code each of the following IUCV functions:

ACCEPT QUIESCE SEND CONNECT RECEIVE SETCMASK DCLBFR REJECT SETMASK DESCRIBE REPLY SEVER PURGE RESUME TESTCMPL QUERY RTRVBFR TESTMSG

For each IUCV function listed above, the following sections describe:

1\. What the function does

2\. All inputs \(required and optional\) that you can specify with the function

3\. The format of the parameter list for the function

4\. The meaning of each field in the parameter list

5\. The outputs \(return codes, condition codes, and program exceptions\) that the function generates\.

The syntax diagrams show the format of each function\. Brackets, \[ and \], indicate that a parameter is optional\. Braces, \{ and \}, indicate a choice\. A vertical bar, \|, means a choice must be made of two or more options\. Default values are underlined\. **Do not** code brackets, braces, or vertical bars as part of the IUCV macro instruction\. **Do** code the parentheses\.

**Note:** While the PRMLIST parameter is the only parameter required for most IUCV functions, most IUCV functions **do require input**\. You can specify this input by \(a\) using one of the optional parameters, or \(b\) storing data directly into the IUCV parameter list\.
