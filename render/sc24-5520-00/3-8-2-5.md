## 3.8.2.5 QRYSTATE Input Parameter List

<a id="HDRSSTPL"></a>

#### QRYSTATE Input Parameter List

The APPCVM QRYSTATE parameter list has the input format shown in [Figure 35](3-8-2-5.md#QSTPL).

<a id="QSTPL"></a>

```text
   |      +--------------+---------+-----------------------------------------+        |
   |     0|   IPPATHID   |IPFLAGS1 | /////////////////////////////////////// |        |
   |      +--------------+---------+-----------------------------------------+        |
   |     8| //////////////////////////////////////////////////////////////// |        |
   |      +------------------------------------------------------------------+        |
   |    10| //////////////////////////////////////////////////////////////// |        |
   |      +------------------------------------------------------------------+        |
   |    18| //////////////////////////////////////////////////////////////// |        |
   |      +---------------------------------+-------+------------------------+        |
   |    20| /////////////////////////////// |IPSIPCD| ////////////////////// |        |
   |      +---------------------------------+-------+------------------------+        |
```

**IPPATHID** contains the path ID on which the state is to be queried. **IPFLAGS1** contains the following input bit flag: IPAPPC (X'08') This is an APPC function. **IPSIPCD** this value is reserved for IBM use only. X'00' this value is reserved for IBM use only. X'01' this value is reserved for IBM use only. X'02' this value is reserved for IBM use only.
