## 2.4.15 SETMASK

<a id="HDRSETMASK"></a>

Use the SETMASK function to enable or disable the following IUCV external

interruptions: Nonpriority message interrupts Priority message interrupts Nonpriority reply interrupts Priority reply interrupts IUCV control interrupts. To enable or disable specific IUCV control interrupts, use the SETCMASK function. The format of the SETMASK function is:
