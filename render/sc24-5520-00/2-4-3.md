## 2\.4\.3 DCLBFR \(Declare Buffer\)

<a id="HDRDCLBFR"></a>

Use the DCLBFR function to specify the address of your external interrupt buffer\. Note that when you invoke the DCLBFR function, IUCV enables your virtual machine for all nine types of IUCV external interrupts\. Use the SETMASK and SETCMASK functions if you need to change the types of IUCV external interrupts for which IUCV enables your virtual machine\.

The format of the DCLBFR function is:

<a id="TBLTBLUNIQ56"></a>

```
    ____ _____ ______________________________________________________________
   | lab|lIUCV| DCLBFR,PRMLIST={label|(reg)}                                 |
   |    |     |                                                              |
   |    |     |                                                              |
   |    |     |              [,BUFFER={label|(reg)}]                         |
   |    |     |              [,MF=L]                                         |
   |    |     |              [,CONTROL={YES|NO}]                             |
   |    |     |                                                              |
   |____|_____|______________________________________________________________|
```
