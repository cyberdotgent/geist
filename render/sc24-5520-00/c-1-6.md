#### C\.1\.6 The MONWRITE Control Record Block \(MWTBK\)

The MONWRITE Control Record Block describes the monitor data stored immediately after this record in the output file created by the MONWRITE program\. [Figure 82](c-1-6.md#FIGMWTBK) gives a description of the HCPMWTBK DSECT:
