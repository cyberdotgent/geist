#### 7\.12\.1\.5\.6 Auditing IUCV CONNECT and SEVER Commands

CP invokes and audits the IUCV CONNECT and SEVER commands\.

CP formats the general ACIPARMS parameter list, but with the variations shown in [Table 61](<#TBLIUCOSE>):

<a id="TBLIUCOSE"></a>

```
    _________________________________________________________________________
   | Table 61. ACIPARMS Control Block for IUCV CONNECT and SEVER Auditing    |
   |____________ ______________ __________ _______ __________________________|
   |            |              | Byte     |       |                          |
   |            |              | Offset   |       |                          |
   | Label      | Description  | Dec(Hex) | Bytes | Contents                 |
   |____________|______________|__________|_______|__________________________|
   | ACIRUSR    | Source user  | 16(10)   |   8   | This field is set to the |
   |            | ID           |          |       | source user ID.          |
   |____________|______________|__________|_______|__________________________|
   | ACITUSR    | Target user  | 32(20)   |   8   | This field is filled in  |
   |            | ID           |          |       | for successful CONNECTs. |
   |            |              |          |       | For IUCV, it contains    |
   |            |              |          |       | the target user ID.      |
   |            |              | .        |       |                          |
   |            |              | .        |       |                          |
   |            |              | .        |       |                          |
   |____________|______________|__________|_______|__________________________|
   | ACIEVENT   | Event name   | 72(48)   |  12   | This field contains:     |
   |            |              |          |       |                          |
   |            |              |          |       |     "IUCVCON" for IUCV   |
   |            |              |          |       |     CONNECTs             |
   |            |              |          |       |                          |
```
