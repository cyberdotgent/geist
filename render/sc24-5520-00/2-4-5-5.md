#### 2.4.5.5 PURGE Parameter List Input Fields

IPPATHID contains the path identification number of the message you are purging. IPFLAGS1 specifies options for the PURGE function. IUCV treats each bit in IPFLAGS1 separately. Make sure that bits you are not using to define input are set to 0. IPFGMCL (X'01') indicates, when set to 1, that you have specified a message class for the message you are purging. IPFGPID (X'02') indicates, when set to 1, that you have specified a path identification number for the message you are purging. IPFGMID (X'04') indicates, when set to 1, that you have specified a message identification number for the message you are purging. IPMSGID contains the message identification number of the message you are purging. IPSRCCLS contains the message class of the message you are purging.
