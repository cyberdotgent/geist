## 1\.1\.44 Diagnose Code X'CC'\-\-Save Message Repository

**Privilege Class:** E

Use DIAGNOSE code X'CC' to initiate the SAVE function for the CP message repository\. If the SAVE operation completes successfully, then DIAGNOSE code X'C8' can be used to set that language\.

The preferred user interface is the CMS LANGGEN command\.

**Entry Values:**

Rx and Are the language identifiers specifying the language to be saved and Rx\+1 the language identifiers specified in the message repository\. The language identifiers are specified using the 1\- to 5\-character language identifier, left\-justified \(that is, the first four characters in Rx and the fifth character in the high\-order byte of Rx\+1\)\. If the language identifiers are less than five characters, they should be padded on the right with blanks\.

Ry X'00xxxxxx'\-\-the function code \(X'00' in the high\-order byte, with the remaining bytes unused\)\.

Ry\+1 The virtual address where the compiled CP message repository that is to be saved has been loaded\. This address must be on a page boundary\.

**Exit Values:**

When processing of the SAVE function completes, the low\-order byte of Ry contains one of the following return codes \(the contents of the remaining bytes being unpredictable\):

<a id="TBLTBLUNIQ44"></a>

```
    _________________ _______________________________________________________
   | Return Code in  |                                                       |
   | Ry+1            | Status                                                |
   |_________________|_______________________________________________________|
   | X'00'           | The entire CP message repository is successfully      |
   |                 | saved.                                                |
   |_________________|_______________________________________________________|
   | X'10'           | The repository cannot be saved due to insufficient    |
   |                 | resources (spool file IDs or spool space).            |
   |_________________|_______________________________________________________|
   | X'18'           | An error occurred while an attempt was being made to  |
   |                 | write a page of the repository to DASD.  This may be  |
   |                 | either a paging error locking the repository into     |
   |                 | real storage, or an attempt to read beyond virtual    |
   |                 | machine storage.                                      |
   |_________________|_______________________________________________________|
   | X'1C'           | The language identifier specified does not match the  |
   |                 | language identifier in the repository at the          |
   |                 | specified virtual address.                            |
   |_________________|_______________________________________________________|
   | X'20'           | The selected repository does not appear to be a valid |
   |                 | message repository.                                   |
   |_________________|_______________________________________________________|
   | X'24'           | The language specified is the same as the default     |
   |                 | message repository.                                   |
   |_________________|_______________________________________________________|
   | X'28'           | An unrecoverable error has occurred.  A soft abend    |
   |                 | has been taken.                                       |
   |_________________|_______________________________________________________|
   | X'2C'           | No system spool file ID is available.                 |
   |_________________|_______________________________________________________|
   | X'30'           | An invalid filename was specified.  The language      |
   |                 | identifier was left blank or contains more than one   |
   |                 | name.                                                 |
   |_________________|_______________________________________________________|
```

**Program Checks:**

The virtual machine invoking this function receives a program check if the following problems occur:

- A privileged operation exception results if the user does not have the privilege class required to issue the DIAGNOSE instruction\.
- A specification exception results if the input registers are set up incorrectly for the DIAGNOSE or if the message repository address specified is not on a page boundary\.
