#### 5\.10\.12\.2 Required Parameter

`PRMLIST=` specifies the address of the IUCV SEVER parameter list\. The IUCV instruction is generated to reference the address specified\.

*label* Is the relocatable label of the parameter list\.

`(`*reg*`)` Is the register number that contains the address of the parameter list\.
