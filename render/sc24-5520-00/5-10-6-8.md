#### 5\.10\.6\.8 DCLBFR Program Exceptions

The program exceptions for DCLBFR are:

<a id="TBLTBLUNIQ170"></a>

```
    ________________ ________________________________________________________
   | Type           | Description                                            |
   |________________|________________________________________________________|
   | Addressing     | The parameter list address or specified buffer address |
   |                | is outside the virtual machine or at virtual address   |
   |                | zero; or, the interrupt buffer extension is outside    |
   |                | the virtual machine storage or at virtual address      |
   |                | zero.                                                  |
   |________________|________________________________________________________|
   | Operation      | The invoking virtual machine is not in the supervisor  |
   |                | state.                                                 |
   |________________|________________________________________________________|
   | Protection     | The storage key of the parameter list address does not |
   |                | match the key of the user.                             |
   |________________|________________________________________________________|
   | Specification  | The parameter list is not on a doubleword boundary.    |
   |________________|________________________________________________________|
```
