## 2\.6\.3 IUCV External Interrupt Types

The following table describes the IUCV external interrupts \(for complete information on these interrupts, see [Chapter 5, "Inter\-User Communication](2-5.md) [Vehicle External Interrupt Formats" in topic 2\.5](2-5.md)\):

<a id="TBLTBLUNIQ93"></a>

```
    ________________________________________________________________________________________
   | Table 46. IUCV External Interrupts                                                     |
   |__________ _____________________________________________________________________________|
   | Interrupt|                                                                             |
   | Type     | Description                                                                 |
   | (Hex)    |                                                                             |
   |__________|_____________________________________________________________________________|
   | X'01'    | Pending connection interrupt.  Another user is attempting to establish a    |
   |          | path to your virtual machine.                                               |
   |__________|_____________________________________________________________________________|
   | X'02'    | Connection complete interrupt.  A virtual machine to which you are          |
   |          | attempting to establish a path has issued the ACCEPT function to complete   |
   |          | the path.                                                                   |
   |__________|_____________________________________________________________________________|
   | X'03'    | Path severed interrupt.  Another user has severed a path to your virtual    |
   |          | machine.                                                                    |
   |__________|_____________________________________________________________________________|
   | X'04'    | Path deactivated (quiesced) interrupt.  Another user has deactivated a path |
   |          | to your virtual machine.                                                    |
   |__________|_____________________________________________________________________________|
   | X'05'    | Path reactivated (resumed) interrupt.  Another user has reactivated a path  |
   |          | to your virtual machine.                                                    |
   |__________|_____________________________________________________________________________|
   | X'06'    | Priority message completion (reply) pending interrupt.  A priority message  |
   |          | you issued has been completed.                                              |
   |__________|_____________________________________________________________________________|
   | X'07'    | Nonpriority message completion (reply) pending interrupt.  A nonpriority    |
   |          | message you issued has been completed.                                      |
   |__________|_____________________________________________________________________________|
   | X'08'    | Priority message pending interrupt.  Another user has sent you a priority   |
   |          | message.                                                                    |
   |__________|_____________________________________________________________________________|
   | X'09'    | Nonpriority message pending interrupt.  Another user has sent you a         |
   |          | nonpriority message.                                                        |
   |__________|_____________________________________________________________________________|
```
