#### F\.12\.3 Abend Conditions

The parameter check conditions follow:

<a id="TBLTBLUNIQ242"></a>

```
    __________________________________________________________ ______________
   | Parameter Check Condition                                | IPRCODE      |
   |__________________________________________________________|______________|
   | Invalid resource ID                                      | X'01'        |
   |__________________________________________________________|______________|
   | Invalid logical record length                            | X'2A' (34)   |
   |__________________________________________________________|______________|
```

The state check conditions follow:

<a id="TBLTBLUNIQ243"></a>

```
    __________________________________________________________ ______________
   | State Check Condition                                    | IPRCODE      |
   |__________________________________________________________|______________|
   | Conversation not in Send state                           | X'20',       |
   |                                                          | X'22',       |
   |                                                          | X'23',       |
   |                                                          | X'24',       |
   |                                                          | X'44'-X'4C'  |
   |__________________________________________________________|______________|
```

<a id="FTNSDFOOT"></a>

\(34\) This condition could also be reported in IPAUDIT by the IPADIINV flag\.
