## 1.1.42 Diagnose Code X'BC'--Open and Query Spool File Characteristics

**Privilege** **Class:** Any DIAGNOSE code X'BC' opens a spool file (if it is not already open) for a spooled reader device and returns all information about the spool file to a user-specified buffer. CP selects the spool file according to the rules governing the CLASS and HOLD status. For these rules, refer to VM/ESA CP Command and Utility Reference and VM/ESA Virtual Machine Operation. This means CP opens only spool files with the same class designation as the virtual reader. **Entry** **Values** Set the input registers up as follows when invoking DIAGNOSE code X'BC': Rx Contains the virtual address of a buffer. Rx+1 Contains the length of the buffer in double words. Ry, bytes 0 and 1 Contains the subcode. Ry, bytes 2 and 3 Contains the device address. **Subcode** **Meaning** **00** This subcode provides information in character format only. This subcode is compatible with VM/ESA (370 Feature). **04** This subcode provides information in character format, where appropriate, and binary format for numeric information. This format is not compatible with VM/ESA (370 Feature). **Exit** **Values:** **Subcode** **X'****00****'** Depending on the specified buffer length, the user's buffer contains as much of the information shown in [Table 34](#TBLBCEV0) as possible.

<a id="BCEV0"></a>

Table 34. Buffer Information Provided with Subcode X'00'.

| (in bytes) | Description4 | Spool file ID (EBCDIC) |
| --- | --- | --- |


**Subcode** **X'****04****'** Depending on the specified buffer length, the user's buffer contains as much of the information shown in [Table 35](#TBLBCEV4) as possible. Note that CP returns character information, where appropriate, and binary format for numeric data.
