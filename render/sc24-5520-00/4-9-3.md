## 4.9.3 APPC/VM Functions Not Supported on IUCV Paths

The following APPC/VM functions are not supported on IUCV paths:

QRYS**TATE** (IUCV does not have any equivalent functions.) SEND**CNF and** SEND**CNFD** (IUCV does not have any equivalent functions.) SEND**ERR** (However, IUCV REJECT is similar to APPCVM SENDERR.) SEND**REQ** (However, APPCVM SENDREQ is similar to an IUCV priority 1WAY parameter data SEND, when that SEND is used as a signal and does not contain any data.) SETM**ODFY** (IUCV does not have any equivalent functions.)
