#### 2\.4\.8\.7 RECEIVE Condition Codes

**Code Meaning**

0 Normal completion

1 IUCV stored a nonzero return code at IPRCODE\.

2 IUCV did not find the messages you specified\.

3 IUCV determined a paging error\.
