## 2\.5\.2 Connection Complete \(Type X'02'\) Interrupts

After you use the CONNECT function to establish a path to another virtual machine, a connection complete interrupt tells you that the other virtual machine has responded\.

IUCV generates this interrupt for your information; no response is required\.

*External Interrupt Buffer Format*: The format of the data in the external interrupt buffer is:

<a id="FIGFIGUNIQ88"></a>

```
      IPARML DSECT

      0      1        2         3         4         5         6       7
      ______________ _________ _________ _____________ ___________________ 
    0|   IPPATHID   | FLAGS1  |IPTYPE   |   IPMSGLIM  |  //////////////// |
     |______________|_________|_________|_____________|___________________|
    8| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
   10|                                                                    |
     |                             IPUSER                                 |
   18|                                                                    |
     |____________________________________________________________________|
   20| ////////////////////////////////////////////////////////////////// |
     |____________________________________________________________________|
```

*Figure 18\. IUCV Connection Complete External Interrupt Format*

`IPPATHID` contains the path identification number that IUCV assigns the path you are establishing\.

`FLAGS1` contains specific information about the path you are establishing\. IUCV treats each bit in FLAGS1 separately\. For a connection complete interrupt, IUCV uses the following bits:

`IPPRTY (X'20')` indicates, when set to 1, that the user who issued the ACCEPT function specified that the path can handle priority messages\.

`IPQUSCE (X'40')` indicates, when set to 1, that the user who issued the ACCEPT function specified that the path is to be quiescent when established\.

`IPRMDATA (X'80')` indicates, when set to 1, that you and the virtual machine with which you established the path are prepared to handle message data sent contained in a parameter list, rather than a buffer\.

`IPCNTRL (X'04')` indicates, when set to 1, that the path established by you and the virtual machine is a control path\.

`IPTYPE` contains the interrupt type \(X'02'\)\.

`IPMSGLIM` contains the message limit for this path\.

`IPUSER` contains an optional 16 bytes of data that the virtual machine with which you established the path can specify\.
