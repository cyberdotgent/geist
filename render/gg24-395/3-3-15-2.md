### 3\.3\.15\.2 Distributed Security Manager for MVS Agent for VM/ESA

Distributed Security Manager for MVS provides support for agents \(clients\) on many different platforms, while the DSM server must reside on the MVS/ESA system\. A DSM agent can be installed on VM/ESA if the following software is installed:

- VM/ESA R1\.1 with APAR VM47212 installed or later
- RACF/VM V1R9
- VM DIRMAINT R4
- ACF/VTAM V3R4, or later
