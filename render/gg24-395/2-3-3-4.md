### 2\.3\.3\.4 Applications and Development Tools

<a id="HDRHDSS115"></a>

In a fundamental sense, a development tool is a type of application\. However, its specific task is to assist the programmer in developing other applications\.

Development tools in an open environment must:

- Enable applications to be split over multiple platforms
- Allow debugging in a distributed environment
- Create a portable application that can interoperate with other environments

The primary importance of these tools is to make it easier for developers to build on the services of the Open Blueprint when creating and maintaining their own applications\. Note that an application developer is not limited to high\-level services from the top of the model\. Lower level services are accessible, if the application designer desires their use\.
