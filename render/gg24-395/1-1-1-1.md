### 1\.1\.1\.1 Client/Server

Client/Server computing is a method of applying computer technology where:

- A client, as the requester of a service, and
- A server, as the provider of a service

can be identified\. Client/Server is often seen to involve a programmable workstation as the client and a minicomputer or mainframe as the server\. The programmable workstation performs two main functions\. The first is to provide an end\-user interface, exploiting the capability of the programmable workstation and its operating systems to provide a Graphical User Interface \(GUI\)\. The second role is one of requesting actions to take place on the server machine\. The server machine's function is to perform actions based on those requests\. It may return a file to the programmable workstation for manipulation in a spreadsheet program\. The server may create, replace, update, or delete a database record\. The server machine may print a document at a central print location\. The server machine may return data for a database query made on the client\. In any case, the server's role is to accept and process requests made by the client\.

An example of such a process may be where, in an object oriented environment, the user of the programmable workstation decides to drag a customer icon from his "Prospective Customers Folder" into his "Existing Customer Folder\." On completing the drag\-drop action, the host may be required to perform some action\. A message could be sent from the programmable workstation to initiate that processing\. The host computer application would then collect the message and perform whatever actions are needed to satisfy the request\. It could simply change a flag on the enterprise customer database to indicate that the customer is now active, and the request is complete\.

While the scenario just described happens to be an interaction between a programmable workstation and a mainframe, Client/Server is not rigid in its applicability\. The client and server could just as easily be two programmable workstations connected by a token\-ring or Ethernet network\. In fact, the client and server could exist within the same programmable workstation\.

It is relatively simple to create such a Client/Server application on a single programmable workstation\. In some cases, a Client/Server approach is included in the operating system itself\. In IBM's OS/2 operating system, an example of a Client/Server implementation is the print spooler\. Applications can send requests to the print spooler and that process handles the request as other requests and system resources permit\.
