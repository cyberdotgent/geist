## 3\.3\.1 APPC

<a id="HDRHAPC100"></a>

<a id="TBLTBLUNIQ8"></a>

![PICTURE 35](35.png)

```
                   Application Program-to-Program Communication (APPC) is IBM's
                   architected solution for program-to-program communications,
                   distributed transaction processing, and remote database access.

                    Each of the SAA participants (MVS, VM, OS/2, OS/400) defined
                   their own extensions to the APPC verbs to better exploit its
                   unique capabilities.  To provide portability, a subset of the
                   common APIs called Common Programming Interface for
                   Communications was set up.  This brought portability to APPC.
```

Besides being on the SAA platforms, IBM also provides CPI\-Communications on, for example, AIX with *AIX SNA Server/6000* and Windows with *IBM APPC Networking Services for Windows*\. CPI\-C has been accepted as a standard by X/Open; in the Open Blueprint model it fits in the conversational subarea of the communication services block\.
