## APPENDIX1\.2\.6 Elements of the CPI

<a id="HDRHCPI100"></a>

The Common Programming Interface \(CPI\) consists of a broad and consistent set of languages and services that programmers employ\. The elements of the CPI include:

- **Languages**

***C*** Based on the draft proposed ASC X3\. C level 2 also includes IBM extensions for record\-level input/output and string manipulation functions for double\-byte characters\.

***COBOL*** Based on American National Standard Programming Language\. COBOL X3\.23 1985, Highest Level \(announced in September 1991\)\.

***FORTRAN*** Based on American National Standard Programming Language\. FORTRAN X3\.9\-1978, FORTRAN 77\.

***PL/I*** Based on OS PL/I V2 product on the System/370\.

***REXX*** Based on the OS/2 2\.0 REXX Language\.

***RPG*** Based on the RPG/400 product on the AS/400\.

***Application Generator*** Based on elements of the interfaces found in the IBM Cross System Product \(CSP\)\.

- **Services**

***Communications Interface*** Provides high\-level interface to SNA LU6\.2 advanced program\-to\-program communications \(APPC\)\.

***Database Interface*** Based on the American National Standard Database Language \(SQL, X3\.135\-1986\) and IBM's SQL \(Structured Query Language\)\. The Database Interface also supports access to relational data distributed among interconnected SAA systems\.

***Dialog Interface*** CUA structure implemented by the OS/2 Dialog Manager\.

***Query Interface*** Based on interfaces in the Query Management Facility \(QMF\) and the OS/2 EE Query Manager

***Presentation Interface*** CUA structure implemented by the OS/2 Presentation Manager\.

***PrintManager Interface*** Defines a consistent means to request print services throughout an enterprise\.

***Resource Recovery Interface*** Defines a consistent interface to sync\-point processing to commit or backout updates in a logical\-unit\-of\-work across multiple local and remote resource managers and to ensure they are made completely or not at all\.

***Repository Interface*** Based on interfaces in the Repository Manager/MVS\.
