### 1\.1\.2\.1 Expectations

<a id="HDRHWIC301"></a>

Many businesses have found that they have to run more efficiently to

continue to be competitive and profitable in today's tougher economy\. Businesses require more productive employees, reduced costs, and shorter production times, while continuing to deliver high quality products and services\. A key to gaining these advantages is using information technology better\. Businesses must re\-evaluate the role of their mainframe, capture the power of their workstations, and give their employees a flexible computing environment\.

Making timely decisions requires access to information at the right time and in the right format, and implementing Client/Server concepts is seen as a means to gain the competitive edge\. A prime benefit that many companies hope to get from Client/Server is to allow the end users to receive the information they require, when they want it\. The overnight, centrally managed production of the monthly sales report is no longer good enough\. To be useful, the information must be current\. The presentation format must be changeable, so that different aspects can be measured\. The information should be able to be manipulated to provide "what\-if" analysis\. Productivity improvements may be gained over time with the use of GUI, available on programmable workstations\. The GUI can provide an easy\-to\-use, easy\-to\-learn view of information, without the user having to know the location of the application, nor of the data\. While there may be updates being performed at a host computer and a LAN server may be managing a print request, the GUI provides a single, user\-oriented view of the network, and in doing so, can help productivity\.

There are several expectations that relate to the possible distribution of applications and data in a Client/Server environment\. If data is to be readily accessible wherever it resides, it follows that the network components should become transparent to the user\. The user should not have to know if the data is on his programmable workstation, a LAN server, or an enterprise mainframe\. The user should not have to know which computer is managing his print request\.

If data is accessible anywhere, then it would seem probable that an enterprise could keep one copy of any file\. There would be no need to have additional copies of the information in other locations, or in other formats\. In that case, management of access to that data should be much simpler\. It would be easy to give any new user access to any existing information\.

The growing importance of UNIX in today's businesses has also fueled the move to distributed computing\. Originally, UNIX was dismissed by the business community as not being appropriate for critical applications\. But as more robust versions of the product appeared and as the UNIX wizards from universities became part of the business world, UNIX came with them\. UNIX is now required to coexist with other systems within a business\.

The arrival of object technology as a viable way to cut application development time is contributing to the decentralization of computing power\. Objects simplify the desktop and distributed computing by shielding the application developer from the complexities of the environment that they are working in\. Also, the structure of the application components should make it very easy to integrate new methods and technology\. If a new product uses a better algorithm for managing a business' stock levels, and that function could be isolated in the information system, then it should be relatively easy to exchange one application with the other\.

By splitting up the function of an application, and moving more processing to the desk top, it is perceived that end\-user response times will decrease\. For a number of clients to be efficiently handled by a single server, it would be expected that the server would have some element of parallelism included in it\. Requests made by any client should not be lost, and requests should be completed without unnecessary delay\.

Often, businesses expect that moving to a programmable workstation environment, where storage and processing capacities have rapidly increased, will save them money\. The pure hardware cost per MIPS is possibly less than for a mainframe, but software and support costs \(installs, updates, help desk\.\.\.\) must be taken into account before the real cost is known\. We can easily picture one of these extra costs when we total the loss a company suffers while most of its high paid professionals invest time in installing their own generic workstation software\. We can see that Client/Server has a number of business expectations to meet\. If we generalize these needs and group them, we could say that business expects Client/Server to solve the following needs:

- Improved staff productivity
- Lower operating costs
- End\-user data access/control
- Consolidated information systems

Add to the list these classical business information systems expectations:

- Reliability
- Security
- Availability
- Improved responsiveness to customers
