### 2\.2\.1\.5 Distributed Management Environment

<a id="HDRHOSF106"></a>

DME provides the management methodology for the DCE distributed computing architecture\. It provides for both development and use of management applications across various platforms and operating systems by providing a common framework with supporting application program interfaces \(APIs\)\. It also provides a common user interface and a set of distributed services which address basic management system functionality\. This product is not currently available for licensing\.
