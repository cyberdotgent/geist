### 3\.3\.4\.4 Multiprotocol Transport Networking Overview

Multiprotocol Transport Networking \(MPTN\) Architecture was announced as

the AnyNet feature for VTAM Version 3 Release 4\.2 for MVS/ESA\. The VTAM Version 4 Release 2 AnyNet Version 2\.0 Feature provides AnyNet/MVS \(MVS host\) and AnyNet/2 \(OS/2 workstation\) functions on the MVS/ESA or OS/2 platforms\. All of the AnyNet feature functions, hosts and workstations, are included on the distribution media\.

The AnyNet functions for VM is addressed through an OS/2 product, IBM AnyNet SNA over TCP/IP Gateway for OS/2\. This implementation will be covered in more detail later\.

Though it is not the normal intention for a VM document to discuss MVS/ESA products, it is our intent to discuss the MVS features of AnyNet because they provide an important addition to those interested in Client/Server computing and heterogeneous system networking\.

Today, applications are written to communicate over a particular networking protocol, or native protocol\.

For example, UNIX or AIX programs are generally written for the TCP/IP transport using the sockets API \(For more information on this subject, see the Section ["TCP/IP" in topic 3\.3\.3](3-3-3.md)\)\. Likewise, most SAA applications were written for SNA using CPI\-C or other APPC interfaces \(information on this topic can be found in Section ["APPC" in topic 3\.3\.1](3-3-1.md)\)\.

In March, 1993, IBM announced the new Multiprotocol Transport Networking \(MPTN\) architecture\. MPTN is a description of a logical structure, formats, protocols, and a set of principals that allow matching applications \(those designed to communicate over a particular protocol\) to use other networks in addition to their native network\.

Thus, referring to the Open Blueprint model \([Figure 11 in topic 2\.3\.3](11.png)\), the MPTN function would exist in the Common Transport Semantics layer separating the application and application transport with the transport provider\.

For example, two socket programs would typically communicate over a TCP/IP network\. MPTN allows them to also communicate over a SNA network\. Conversely, two APPC applications that normally communicated through a SNA network can now communicate over a TCP/IP network as well as their native SNA network\.
