### 3\.3\.5\.2 VM/Pass\-Through \(PVM\)

<a id="HDRHRSC120"></a>

PVM pampers its users by giving so much function to 3270 terminals: terminal networking \(TELNET like\), multiple concurrent sessions, auto\-signon support, a REXX API for terminal session automation, screen capturing, sharing the same CMS session between terminals \(useful for conferencing, end\-user support and education\)\.

Recently, PVM enriched its connectivity options through the following updates:

1\. Supporting PVM to PVM networking over TCP/IP

2\. Enhancement of the PVM to SNA gateway component \(called PVMG\) to run on a VSE guest as a gateway between PVM and VSE/VTAM \(called PVMG/VSE\)

3\. Support for cross system IUCV sessions in PVMG for VM

4\. Ability to use the PVMG selection screen as a concentrator screen where a selected session can reside in either the PVM or SNA network
