### 2\.3\.3\.1 Network Services

<a id="HDRHDSS102"></a>

Network Services provide a common view of the network layer; thus the higher\-level, distributed system services and application enabling services do not need to know the details of the network itself\. The details of Network Services were originally defined in the Networking Blueprint, which was published in March 1992, by IBM's Networking Systems Division\. The Open Blueprint has incorporated the Networking Blueprint into its Network Services layer\.
