### 3\.3\.11\.2 ADSTAR Distributed Storage Manager Environments and Protocols

<a id="HDRHDSM104"></a>

The following operating environments are supported:

- VM \(CMS\) on System/370 or System/390
- MVS \(TSO\) on System/370 or System/390
- VSE on System/370 or System/390

The following administration clients are supported:

- VM \(CMS\) on System/370 or System/390
- MVS \(TSO\) on System/370 or System/390
- VSE on System/370 or System/390
- RISC System/6000, POWERserver, and POWERstation with IBM AIX software
- Personal Computer with DOS software
- Personal Computer or workstation with OS/2 software
- Personal Computer or workstation with Microsoft Windows software
- Sun\-4 with Sun Microsystems SunOS software

The following backup\-archive clients are supported:

- RISC System/6000 with IBM AIX software
- Personal Computer with DOS software
- Personal Computer or workstation with OS/2 software
- Personal Computer or workstation with Microsoft Windows software
- Apple MacIntosh with Apple MacIntosh Operating System software
- Workstation running as a server with Novell NetWare software
- Sun\-3 or Sun\-4 with Sun Microsystems SunOS software \.

The following protocols are supported:

- PC Token\-ring LAN
- Ethernet LAN
- Coaxial cable\-workstation subsystem controllers
- 3270 emulation
- IUCV
- APPC
- TCP/IP
