### 3\.3\.18\.3 Sample Declaratives

To get a better idea of what a ScreenView application code looks like, please consider the following example:

`<CLASS> "OrgChart Work area" General: HelpFile = SMPHELP /* help file for the OrgChart application. */ ContextHelp = 1000 /* help context for the chapter that explains */ /* this UID */ DefaultAction = "Run Orgchart" /* action that starts when object is clicked */ ContView: Icon = SMPRWRK.ICO /* resource for the work area icon */ IconText = "OrgChart" /* text related to icon */ DetailsText = "OrgChart - a ScreenView sample program /* text used for textual view of the object */ <ACTIONS> "Actions against OrgChart" ...`

The declaratives in the example define the structure of the screen\. They connect an ICON image, SMPRWRK\.ICO, with descriptive text, help information, and make the connection to an action; in this case "Run Orgchart\."
