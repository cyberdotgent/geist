### 3\.3\.15\.1 Distributed Security Manager for MVS Overview

The Distributed Security Manager for MVS server resides on MVS/ESA where it benefits from the capability, availability, integrity and security of host systems\. Customers who have a mix of systems can manage the security of all of these systems through this interface\. Here are some of the benefits:

- **Improved User Productivity**

A graphical end\-user interface on OS/2, which is common across all of the systems managed, enhances administrator productivity\. There is a shorter learning curve, and a smaller staff can perform an improved level of administration\.

As well, the number of people involved in processing administrative requests is greatly reduced\. This speeds the cycle time of administrative requests, increases end user satisfaction, reduces delays to the end user, and lowers administrative costs\.

- **Simplified User Registration Process**

From a single common interface on an OS/2 workstation, Distributed Security Manager for MVS performs the following functions for the distributed enterprise:

Add, change and delete user IDs Reset a user's password across the enterprise in a single administrative request Verify users automatically against corporate personnel data Automatically disable user IDs across the managed environment if an employee leaves the company

Administration of users and resources can be performed based on a set of installation defined "roles\." For example, a person can be assigned a set of user IDs and authorizations by assigning that person to the predefined role of bank teller or claims processor\. This is similar to a CP privilege class\.

- **Support for Multiple Platforms**

Interoperability is a key requirement for any cross\-platform security management solution\. Distributed Security Manager for MVS has been developed to manage multiple different platforms, including MVS, VM, OS/400, OS/2, and Novell Netware\. Thus, Distributed Security Manager for MVS allows users and resources to be managed with a single view of the enterprise\. This high degree of flexibility gives customers the ability to provide consistent security management throughout their enterprise, and to extend the support to address new platforms and unique needs\.

RACF, ISPF, and OfficeVision are some of the products supported on the VM/ESA platform\.

- **Open Enterprise Support**

Distributed Security Manager for MVS supports many of the industry security standards\. Of the standards and architectures identified as formal, de facto, and emerging, the following are supported:

SNA LU 6\.2 SQL Common User Access IBM Security Architecture
