### 3\.3\.2\.1 Functions and Protocols

<a id="HDRHOSI101"></a>

The OSI set of protocols map onto the Open Blueprint model \(please refer to [Figure 23 in topic 3\.1\.1\.2](23.png) and [Figure 11 in topic 2\.3\.3](11.png)\) as follows:

- *FTAM and X\.400* \(File Transfer Access and Management\) \- Mailing and file transfer is part of the Mail and File Transfer interfaces in the Application Services section of the Open Blueprint\.
- *OSI TP* \- Distributed Transaction Protocol is part of the Transaction Manager interface in the Distribution Services section of the Open Blueprint\.
- *X\.500 Directory Services* \- is part of the Directory and Naming interface in the Distribution Services section of the Open Blueprint\.
- *VT* \- Virtual terminal is not officially part of the Open Blueprint, but would fit into the user interface in the Presentation Services section\.
- *CMIS/CMIP* \- These network management protocols are part of the Systems Management layer of the Open Blueprint\.
- *OSI* \- Support of lower layer protocols within the Network Services layer of the Open Blueprint\.
