### 3\.2\.2\.6 DCE Interfacing with POSIX

POSIX addresses portability and DCE addresses interoperability\. These concepts were covered earlier in this book in some detail, but the interface and connection between POSIX and DCE needs more discussion\. The best way to explain this relationship is through an example\.

Assume that one customer has an application running in the UNIX environment\. Without POSIX support, this application could not run on a VM platform\. But, if the application is written to POSIX APIs, it becomes portable between POSIX\-compliant machines\.

Assume now that the same customer would like to run an application in the VM platform to access a file in the UNIX machine\. With the portability of POSIX applications, such as DCE, it is possible\. This ability to put together different platforms based on different technologies, or interoperability, is the main goal of the OSF's DCE\.
