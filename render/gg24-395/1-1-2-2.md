### 1\.1\.2\.2 Technical Requirements

<a id="HDRTECHREQ"></a>

From a technical standpoint, these expectations sound like the Utopia of computing\. However, making the best use of the technology that is available can certainly help us make progress on each requirement\.

Obtaining a single view of the enterprise's information systems requires that several hurdles be overcome; namely:

- Data would have to be accessed transparently\. This could readily be hidden by the GUI needed for the single view\.
- In order to access data regardless of where it is stored and what communications vehicle is being used, a universal file system is required\.
- That we provide support for a distributed database which allows reporting of data that may reside in differing locations\.
- When a business has systems from several vendors, the need for single image, multiprotocol networking is obvious\. The complexities of accessing different host systems, adhering to different standards and protocols, must be hidden from the GUI application programmer and user\. The ability to view any system as any other system is key in providing a consolidated view of the enterprise information system\.
- When processing becomes distributed into multiple processes, there exists a need for the processes to interact with each other, even across platforms\. If Client/Server is to provide full interprocess communication, to overcome protocol differences between those platforms, then that need would be fulfilled\.
- We must provide a single front\-end application for the user, which manages interactions with data, applications, and services\. A Graphical User Interface front end would satisfy such a single view with its easy\-to\-learn, easy\-to\-use principles, it could enable significant productivity improvements for the enterprise\.
- For users who access multiple systems, a problem encountered is having to enter identification and passwords at each attempt to sign\-on\. In a world where application and data usage is supposed to be viewed as a single image, we have to provide a single system sign\-on facility, where one sign\-on will serve the purpose of verifying access to information throughout the session\. Security services are necessary\.
- In improving productivity further in a world of end\-user data control, significant benefit could be obtained by providing a single print/view facility\. Sending output to a screen and a printer are similar tasks, and there is little reason that application programmers or users should be concerned with the particular output medium in use\.
- If many clients are making requests to a particular server, the user can experience significant delays, the benefits of having a multithreaded server are easily seen\. In performing work that requires server activity, the need for some level of parallelism is apparent\.

Giving the end user control over what data is provided would be supported by providing the appropriate functions in the GUI along with the distributed transparent data support facilities already mentioned\.

In information systems based on Client/Server, the configuration of hardware and software, and the decisions on where to position data and processing are important factors in determining the operating costs\. In satisfying the requirements above, though, the ability to effectively and efficiently manipulate the information system to best suit the enterprise provides advantages by leveraging existing information technology investments\.
