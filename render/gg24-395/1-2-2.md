## 1\.2\.2 Systems Application Architecture Overview

<a id="HDRHSAA100"></a>

The introduction of Systems Application Architecture was a significant

step towards making IBM products more open\. SAA makes it easier for an enterprise to solve its information system needs by improving consistency and connectivity across four major IBM environments: MVS/ESA, VM/ESA, OS/400, and OS/2\.

SAA interfaces consist of three related elements:

- Common User Access \(CUA\)
- Common Programming Interface \(CPI\)
- Common Communications Support \(CCS\)

These elements establish the base for developing SAA applications, either by IBM, software vendors, or customers\.

Through all of these elements \(CUA, CPI, and CCS\), SAA provides a consistent framework upon which enterprises can build a productive and effective enterprise\-wide information system\. Common applications can be developed to provide an integrated systems environment\.
