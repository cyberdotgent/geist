### 3\.3\.4\.1 SNA Overview

Traditional SNA networking is based on the interaction of different types of communications nodes with defined roles\. The architecture is a hierarchical structure, with the mainframe providing the primary role in the network\. VTAM provides the mainframe networking support required for SNA networking, including mainframe\-based application access to the network\. VTAM's role in the traditional SNA network is referred to as the System Services Control Point \(SSCP\)\.

Communication Controllers, also known as Front End Processors, are a key part of SNA networking\. They relieve the mainframe of much of the network processing function in a SNA network\. Communication Controllers are subordinate to the mainframe in the SNA hierarchy\.

Cluster Controllers provide the connection point for end user devices such as terminals and printers in an SNA network\.

The most basic unit in the SNA hierarchy is the Logical Unit \(LU\)\. This unit represents end user devices such as terminals and printers, as well as application programs\.

While the SNA architecture defines the types of nodes within an SNA network, with the advancement of computing capabilities, many SNA networking implementations provide multiple functions\. For example, an intelligent workstation or personal computer, may act as both a Cluster Controller and provide one or more Logical Units\. At the mainframe, VTAM can provide both System Services Control Point \(SSCP\) and Communications Controller roles\.
