### 3\.3\.17\.3 Requirements for VisualLift

There are no special requirements on the host, as all VisualLift software runs on the workstation\. All current VM versions are supported\.

- **Application Development Environment**

A PS/2 \(or compatible\) with 80386 \(or higher\) processor \(80486 recommended\)\. OS/2 Version 2\.1 \(or higher\) with Communications Manager/2 Version 1\.0 \(and 327x adapter card\), pointing device \(such as a mouse\)\.

- **Run Time Environment**

Same requirements as above, except for workstations running MS Windows: MS Windows Version 3\.1 or higher, and Personal Communication/3270 Version 3\.1 or higher \(or equivalent\) for Windows

- **Optional Workstation Software**

If coding of exits is done as part of the application development process, OS/2 Users need: IBM Developers Toolkit for OS/2 Version 2\.1 and IBM C\+\+/2 Compiler Version 2\.1 or higher\. For Windows: Microsoft Windows SDK Version 3\.1 or higher and Microsoft C Compiler Version 6\.0 or higher \(or equivalent\)\.
