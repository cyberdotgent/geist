### 3\.3\.11\.1 Storage Management Services

<a id="HDRHDSM101"></a>

Storage Management Services uses a VM "server" to act as a file backup and archive server for Local Area Networks \(LANs\) and client nodes \(workstations\); therefore, it is a client/server application\. In the ADSM environment, the terms are defined as follows:

A "client" is any node that is defined to ADSM\.

A "server" provides storage resource and administrative services to back up and archive client nodes\.

Storage Management Services is designed to:

- Provide centrally scheduled backup and archive operations or allow the workstation user to initiate backup and archive operations\.
- Provide a policy\-managed backup and archive facility\.
- Extend DFSMS concepts of managing data and storage resources to the distributed environment\.
- Use the VM system for storage and media management to support backup and archive processing\.
- Support existing WDSF/VM clients, facilitating migration to ADSM\.
- Provide a cross\-industry solution to satisfy enterprise data back up and archive needs by supporting multiple clients and protocols\.
- Support nondisruptive installation and new backup and archive clients as the needs of the enterprise grow\.
- Support highly automated operations\.

ADSM has three major components :

- Administrative Client

The administrator controls the ADSM server from an administrative client and also defines the policies which will help protect data\.

- Backup\-Archive Client

The backup\-archive client holds the critical data that needs to be protected\.

- Server

The ADSM Server stores the data sent from the backup\-archive client and uses a database and recovery log to track where the data is stored\.
