### 3\.3\.8\.2 CPI Communications

<a id="HDRHMFF102"></a>

Host Management Facilities/VM uses SAA's Common Programming Interface for Communications to enable OS/2 workstations to communicate with HMF servers located in a VM environment\. It is also available for use by other HMF communications facilities\.
