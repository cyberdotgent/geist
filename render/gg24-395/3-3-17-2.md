### 3\.3\.17\.2 VisualLift Implementation

VisualLift has two parts:

- Run Time Environment \(RTE\), which can run in either OS/2 or Windows
- Application Development Environment \(ADE\), which executes in OS/2

To make VisualLift implementation as easy as possible, both parts are ordered and delivered as a single product on a host tape\. The pricing is based on the host processor, with no restrictions on the number of downloads \(RTE and ADE in any combination\) from the licensed processor\.
