### 2\.2\.1\.4 Application Environment Specification

<a id="HDRHOSF102"></a>

OSF's Application Environment Specification \(AES\) defines the programming interfaces needed to develop portable applications for an Open Systems environment\. Major standards and specifications from other sources, as well as some definitions from OSF, are included\. AES consists of the following components:

- XPG3 and XPG4 \(X/OPEN\)
- ANSI C
- IEEE POSIX
