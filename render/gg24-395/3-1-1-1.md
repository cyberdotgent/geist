### 3\.1\.1\.1 Is Client/Server a Model

Client/Server is not a model\. Client/Server is an implementation of elements of an Open Systems model\. Without conformance to Open Systems standards, a Client/Server implementation will fail to live up to the expectations imposed upon it by today's market forces\. It is true that a Client/Server implementation *need not necessarily* exploit all aspects of Open Systems, but the set of functions from which a Client/Server application draws must be complete enough to meet the demands imposed upon it by the market place for functionality, usability, and transparency\.
