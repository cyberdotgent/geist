### 2\.3\.3\.7 Integration

<a id="HDRHDSS117"></a>

A major goal of the Open Blueprint is to provide a seamless work environment where products can work together by using agreed upon standards\. The end user does not have to do anything unusual and views the network as a single system\. The key items needed to achieve integration are:

- **Single Logon:** This allows users to have one user ID and one password to access all network facilities for which they are authorized\.
- **Network\-wide Security:** This protects the resources on the network using data encryption, user authentication and resource access control\.
- **Network\-wide Directory:** This provides all necessary information about resources within the network\.
- **Global Transparent Access:** This enables users to access data anywhere in the network without having to know where the data resides\.

The Open Blueprint promotes integration by providing services that meet the above criteria\. Through the use of technologies, such as DCE, the Open Blueprint provides interoperability in a multivendor environment\.
