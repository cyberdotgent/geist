### 3\.3\.1\.7 APPC Applications

Many traditional VM applications have been implemented using specific VM Client/Server techniques\. More modern VM applications, such as SFS and DB2/VM, use VM/APPC as their communication vehicle\. Using VM/APPC made these applications automatically available to VM users on other systems, as the APPC network is transparent to the applications\. To enable remote access, the only requirement is setting up ISFC, TSAF or AVS\.

To make using your SNA and APPN network easier and to speed up APPC application development, the APPC Application Suites software feature comes in handy\. It provides the following functions: *APPC File Transfer Protocol \(AFTP\)*: This application enables end users and systems administrators to list and transfer files between systems where AFTP is implemented\. The command line interface is modelled after well known industry standards, such as TCP/IP's FTP and the 3270 file transfer program IND$FILE\. AFTP can also be used from REXX procedures and provides an API for calls from within other applications\. AFTP uses CPI\-C and the CPI\-C security features\. *APPC 3270 Server \(A3270\)*: This server provides a new vehicle for 3270 emulation\. The main advantages being that on the workstation only APPC support functions need to be installed, and the requirement to define and maintain LU type 2 on the host and the workstation is lifted\. *APPC Name Server \(ANAME\)*: With the APPC Name Server, end users can assign nicknames to network resources, such as SNA LU names and APPC transaction programs\. The ANAME server is a VTAM application maintaining a directory that ANAME clients can update and query\. ANAME has a command line interface and an API for calls from within other applications\. By maintaining a central ANAME server, you can have centralized management and control\. *APPC Connectivity Tester \(APING\)*: APING provides a series of functions useful for APPC connectivity testing\. The information provided includes basic performance data, whether or not a session can be activated and extensive error information if the activation fails\.

As the usage of LU 6\.2 becomes more important in a true APPN network, you'll understand that the availability of this LU 6\.2 flavor of above applications is very important\. The APPC Application Suites are intended to become available at base level of all APPC/APPN platforms\.

In the VM and MVS area, APPC Application Suites are available as a no charge feature of *VTAM V4\.2 for MVS, 5695\-117* and as a separate product for other VTAM releases: *APPC Application Suite \- MVS, 5655\-091*, *APPC Application Suite \- VM, 5654\-025*\.

For OS/2, AIX and Windows, APPC Application Suites is included in Communications Manager/2 V1\.11 \(5622\-078\), DeskTop SNA for AIX V1\.1 \(5765\-419\) and Networking Services for Windows V1 \(5622\-575\) respectively\.
