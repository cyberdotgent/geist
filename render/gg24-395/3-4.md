# 3\.4 Chapter 11\. What's Next

<a id="HDRHFUT100"></a>

The introduction of POSIX, DCE, and a native CMS GUI with VM/ESA Version 2 opens VM to exciting new possibilities in distributed computing\. The key benefits of this new function are the ability to interoperate with more platforms, along with the ability to develop and run applications on any platform that supports POSIX\. The question is now, "Where do we go from here?"
