### 2\.2\.5\.3 POSIX 1003\.2

<a id="HDRHEEE104"></a>

POSIX 1003\.2, Shell and Utilities, defines a standard interface and environment for application programmers that require the services of a shell command language interpreter and a set of common utility programs\.

POSIX 1003\.2 is constructed from utilities in three functional areas:

- Execution environment \(for example, change directory\)
- Software development \(for example, create archives\)
- C language development \(for example, use the C compiler\)

Refer to Section ["OpenEdition VM Shell and Utilities Feature" in](<#HDRHPSX104>) [topic 3\.2\.1\.2\.3](<#HDRHPSX104>) for details on how the Shell and Utilities feature is implemented in VM/ESA Version 2\.
