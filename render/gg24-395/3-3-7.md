## 3\.3\.7 NetView

<a id="HDRHNVW100"></a>

<a id="TBLTBLUNIQ13"></a>

![PICTURE 68](68.png)

```
                   NetView (5756-051) is a SystemView product for managing networks
                   and systems through automation.  It provides the SystemView
 |                 automation services for S/370 and S/390 applications.  It can be
 |                 used to collect and analyze the essential information as well as
 |                 to control the system and network resources from a single point.
                   NetView consolidates the collected information and provides a
                   consistent user interface to enable easier management of a
                   complex system environment.
```

The NetView product has versions for all operating systems that run on the System/370 and System/390 systems, including MVS/ESA, MVS/XA, VM/ESA, and VSE/ESA, and includes the functions discussed below\.
