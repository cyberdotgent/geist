### 3\.3\.13\.4 Client Application Enabler Products

<a id="HDRHSQL140"></a>

This section discusses products that could be used in a VM/ESA Client/Server implementation\.

In March 1993, IBM announced a new set of products:

- DB2 Client Application Enabler/2 \(for OS/2 clients\)
- DB2 Client Application Enabler/6000 \(for AIX clients\)
- DB2 Client Application Enabler/DOS \(for DOS workstations, with or without WINDOWS\)

Followed in May 1994 by:

- DB2 Client Application Enabler for HP\-UX
- DB2 Client Application Enabler for the Solaris Operating Environment

These products enable database transparency between OS/2, AIX, DOS, HP\-UX and Solaris platforms\. The CAE/DOS product also includes the Open DataBase Connectivity \(ODBC\) driver to support Windows applications built with the Microsoft Open Database Connectivity Software Development Kit\. With these products, one can use DDCS/6000 to provide the host SQL/DS access from a DOS platform, for example\.
