### 2\.3\.3\.6 Local Operating System Services

<a id="HDRHDSS116"></a>

Local operating system services manage resources that are not

distributed, such as CPU, storage and local devices\.

To maximize the portability of code across platforms, local operating systems will move towards using standard interfaces, such as those documented in X/OPEN's Portability Guide \(see Section ["X/Open" in](2-2-2.md) [topic 2\.2\.2](2-2-2.md)\) and ["OpenEdition VM \- POSIX Support" in topic 3\.2\.1](3-2-1.md)\. In addition, as object technology becomes more entrenched, local operating system services will be accessed through object services, such as those defined by the Object Management Group \(OMG\)\.
