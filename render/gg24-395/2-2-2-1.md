### 2\.2\.2\.1 Common Application Environment

<a id="HDRHXOP101"></a>

Common Application Environment \(CAE\) is a set of standards specified by X/Open to allow the portability and interoperation of applications between conforming systems\. This profile is defined in the current issue of the *X/Open Portability Guide* \(XPG\)\. There are two versions of XPG currently available, XPG3 and XPG4\.
