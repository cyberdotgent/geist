## 3\.3\.11 ADSTAR Distributed Storage Manager

<a id="HDRHDSM100"></a>

<a id="TBLTBLUNIQ17"></a>

![PICTURE 81](81.png)

```
                   The ADSTAR Distributed Storage Manager (ADSM, 5648-020 from the
                   Storage Systems Division) product is an enterprise storage
                   management program that provides storage management and data
                   access services to customers in a multivendor computer
                   environment.  ADSM, previously announced as Data Facility
                   Distributed Storage Manager (DFDSM), is the successor product to
                   the IBM Workstation Data Save Facility/VM (WDSF/VM, 5684-122)
                   program product.
```

ADSM is made up of two components, namely Storage Management Services and Data Access Services\. Data Access Services enables application programs running on a OS/2 Version 2 system to create and use data stored on a remote system under the IBM SAA Distributed Data Management \(DDM\) Architecture\. To use Data Access Services, a system that supports target DDM is required \(the target system is the system where the data resides, and the source system is where the application resides\)\.

Since the Data Access Services is not currently supported in a VM environment, details about this component are not discussed in this publication\.
