### 3\.3\.7\.2 Associated Products

<a id="HDRHNVW109"></a>

There are several complementary products in the NetView family\. Each handles specific functions to enhance the total network environment\. These products include:

- NetView File Transfer Program \(NVFTP\) provides bulk data transfer functions that can be automated by NetView\.
- NetView Distribution Manager \(NVDM\) handles distributed software and microcode distribution\.
- NetView Access Services \(NVAS\) provides network security and multiple logons from a single screen, and can interact with NetView when error situations occur\.
- NetView Performance Monitor \(NPM\) is a performance and accounting product\. It provides real\-time monitor graphics, historical analysis of session and performance data\. It can also alert NetView when error thresholds have been reached\.
- Service Level Reporter \(SLR\), with Network Management Reporting, provides a management reporting system for service levels\.
- SAA Asset Manager assists in the ordering and tracking of resources\.

There are numerous alliances between IBM and other vendors building on the NetView platform to further extend the capabilities in multivendor Network management\.
