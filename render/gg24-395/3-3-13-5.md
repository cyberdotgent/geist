### 3\.3\.13\.5 DRDA as an Open Standard

<a id="HDRHSQL160"></a>

With SQL being the SAA and ANSI standard for relational database access, DRDA compliance has become an attribute for non\-IBM products\. More and more non\-IBM computing firms are supporting DRDA\. Remote Database Access \(RDA\), a subset of DRDA, has recently progressed to an international standard through ISO\. A slightly different version is under development in X/Open\.
