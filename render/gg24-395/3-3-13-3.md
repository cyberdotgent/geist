### 3\.3\.13\.3 Distributed Database Connection Services

<a id="HDRHSQL130"></a>

There are currently four products in this area: DDCS/2 for OS/2, DDCS/6000 for AIX, DDCS for HP\-UX and DDCS for the Solaris enviroment\. They enable DRDA connectivity to data residing in DB2, DB2/VM, and DB2/400 database systems\. As the DRDA protocol is used, the need for any special gateway products on the host is eliminated\.

Not only can applications perform SQL queries against SQL server machines, but also execute utilities through the OS/2 database manager Command\-Line Interface \(CLI\), or use the DBM Export/Import utilities, against DRDA servers such as DB2/VM\.

DDCS also performs message protocol and data format translations, as well as mapping host SQL codes to their local equivalents\.

DDCS services are available to users of the node that installed DDCS, and to workstations connected to such a node, when the workstation installed a Client Application Enabler product\.
