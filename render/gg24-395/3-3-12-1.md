### 3\.3\.12\.1 DataHub Overview

<a id="HDRHDHB101"></a>

DataHub is a data management product that provides a workstation\-based control point, host support components, and a tools feature that enables more effective management of IBM's DB2 relational database family\. DataHub provides a consistent object\-based graphical user interface that associates data with function\. From this designated control point users can:

- Distribute data across the enterprise by copying database objects from one relational database management system to another\.
- Perform database management tasks across multiple homogeneous database management systems\.
- Perform database management tasks across multiple sites\.
- Reduce skill requirements by masking most of the differences among the IBM relational database management systems\.
- Speed up problem detection and minimize downtime\.

The main interface for DataHub users is a control point on OS/2, called DataHub/2\. This is the only place where the database administrator, help desk personnel, or programmer would access DataHub\. On the host, there is a DataHub component; on VM it is called *DataHub Support/VM*\. Connectivity between the DataHub/2 control point and the host is achieved in one of the following ways:

- DRDA architecture is used for processing SQL remotely\.
- Private flows are used to establish SAA CPI\-C sessions between the control point and the host DataHub server\.
- For the OS/2 host, standard Database Base Manager \(DBM\) APIs are used\. When the OS/2 host is remote, Remote Data Services \(RDS\) is used with the DBM APIs\.

The DataHub tools feature provides functions for operations, change, configuration, problem, and security management\. DataHub also provides a set of common services to reduce development efforts and to ensure consistency among tools\. The DataHub tools include the following functions:

- Display status

Display status is an efficient problem detection tool for querying a network of local or remote relational databases without having to log on manually\.

- Manage authorizations

Manage authorizations streamline the security procedures required to manage multiple systems\.

- Copy data

Copy data provides the function to copy objects from one relational database management systems to another\.

- Utilities The utilities process RDBMS at the RDBMS host\. Examples of utilities are REORG TableIndex and UPDATE Statistics\.
- Automation through workflow management

DataHub can interoperate with IBM WorkMark for OS/2, integrating database management in the workflow management\.
