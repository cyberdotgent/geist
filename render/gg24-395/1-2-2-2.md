### 1\.2\.2\.2 Common Programming Interface

<a id="HDRHSAA102"></a>

The Common Programming Interface \(CPI\) covers a broad and consistent set of languages, and services that programmers employ\. By using this interface, developers can create cooperative applications and can write major application components with limited concern about the environments in which they will run\.

The elements of the CPI include:

- **Languages**

C COBOL FORTRAN PL/I REXX RPG Application Generator

- **Services**

Communications Interface Database Interface Dialog Interface Query Interface Presentation Interface PrintManager Interface Resource Recovery Interface Repository Interface

For more detailed information about CPI, refer to Section ["Elements of the](appendix1-2-6.md) [CPI" in topic APPENDIX1\.2\.6](appendix1-2-6.md)\.
