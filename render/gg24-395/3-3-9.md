## 3\.3\.9 LANRES

<a id="HDRHLAN100"></a>

<a id="TBLTBLUNIQ15"></a>

![PICTURE 70](70.png)

```
                   LAN Resource Extension and Services (LANRES) connects NetWare
                   LANs with VM and MVS operating systems, thus allowing the
                   NetWare server to exploit the S/390 resources.  LANRES provides
                   rapid communication between NetWare and the host while remaining
                   transparent to the LAN based clients.

                   By connecting the LAN server to the host, LANRES places S/390
                   DASD at the LAN servers disposal as additional server disk
                   space.  Specifically, it allows NetWare files to be stored on
                   the host and to be accessed by the client without the client
                   knowing (or needing to know) where the files reside.
```

In addition, LANRES provides enhanced print functions to both LAN and host based users\. LANRES allows LAN users to print on host attached printers, and host\-based users to use LAN attached printers\.

Finally, LANRES provides a centralized administration point for multiple LANs, allowing LAN administration and data distribution to be performed from a host\.

A NetWare server running LANRES retains full use of all of its NetWare functions while gaining access to many of the additional services offered by LANRES\. For example, servers can still use the local disks and printers, as well as NetWare monitoring and administration tools\.
