### 2\.2\.5\.2 POSIX 1003\.1

<a id="HDRHEEE102"></a>

The primary agreed upon standard is POSIX 1003\.1\. This standard defines the system call interface and the C language bindings for the portable environment\. The standard defines the interfaces and environment, but does not dictate how it should be implemented\. Thus, regardless of the UNIX\-like nature of the standard, it can be provided on non\-UNIX platforms\.

The following definitions, are used in the IEEE standard: **Process Primitives**

Process creation and execution Process termination Interprocess signalling

**Process Environment**

User identification Process groups Identification of system and terminals Environment variables and time

**Files and Directories**

Directories and their formats File creation and removal File characteristics Configurable path name variables

**Input and Output Primitives**

Read from a file Write to a file Controlling file operation Repositioning within a file

**Device\- and Class\-specific Functions**

Interface characteristics and terminal control General terminal interface control functions

**Language specific Services for C**

C language routines C language functions

**System Databases**

System, user, and group databases

**Data interchange format**

Archive/interchange formats
