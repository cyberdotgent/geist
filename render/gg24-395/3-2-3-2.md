### 3\.2\.3\.2 Native CMS GUI Facility

<a id="HDRHGUI130"></a>

VM, for a long time, was thought of by its end users as one of the best, user\-friendly, interactive computing environments\. By adding a high performance GUI to CMS, VM functions and applications will be integrated on the user's workstation; they will look like native workstation applications\. Using CMS will become very attractive again\. VM's direction is to eliminate the need for 3270 emulation for those users whose host requirements are limited to basic functions\.

The GUI API provided by CMS allows the heart of applications to run on the host, but off\-loads the presentation services to the workstation\. The VM application using this GUI API is independent of the workstation environment\. CMS uses the same technology as ISPF Client/Server\. In VM this technology is referred to as the *VM/ESA Graphical User Interface Facility*\. The X Windows protocol has been an alternative to develop the CMS GUI, but the VM/ESA Graphical User Interface Facility was chosen due to its better performance\. A major difference between X Windows and the VM GUI Facility is that with X, full control over the windows is executed by the application running in the host\. For example, any mouse movement results in an interrupt sent to the host; each character entry costs two host interrupts\. All this leads to high networking traffic and CPU usage, a reason why few host applications use X Windows\. In addition, VM X Windows programs are very large, as all X Windows runtime routines are compiled into the program object\. The VM GUI Facility, on the other hand, leaves most of the window control to the workstation\. It also has some other advantages missing from X Windows: an object\-oriented API, smaller programs, and it can use both SNA and TCP/IP protocols\. The X Windows protocol remains available with TCP/IP and existing X applications will continue to run on VM CMS not only provides the API, but also some functions using it\. The set of functions provided is called the *CMS Desktop*, similar to what other desktop systems, such as OS/2 and Windows, provide\.
