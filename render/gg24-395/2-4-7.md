## 2\.4\.7 Diskless Support Service \(PC Integration\)

<a id="HDRHDCE108"></a>

PC Integration \(PCI\) allows PCs, based on MS\-DOS, to act as a client in the distributed environment and therefore to take advantage of distributed services\. The implementation allows MS\-DOS clients access to the distributed file system by running PC\-NFS for the file and print services\.

Another aspect of PC integration is the support of a diskless terminal\. For reasons of security and cost, it is possible to connect machines without disks to services available across the network\. The diskless machine would be able to locate the kernel required to obtain the configuration\. From there, the diskless machine could use remote servers to access applications and data\. Swapping and paging could also be stored on a remote server\.
