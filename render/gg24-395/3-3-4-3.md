### 3\.3\.4\.3 VTAM

<a id="HDRHVTM101"></a>

In a traditional SNA hierarchical network, VTAM is the centerpiece of the network\. VTAM provides application access and full control of the network function\.

But in an APPN environment, VTAM is simply a peer node in the network, with equality to any other APPN node within the network\. With APPN networking, client server networks can be designed with the mainframe providing server functions, or simply acting as a client accessing other server nodes within the network\.

VTAM provides extensions to the APPN architecture, such as Dependent LU Server, which enables traditional network devices such as 3270 terminals or emulators to communicate with applications while fully exploiting the APPN network capabilities\.

VTAM also has a specialized capability known as Interchange Node, which enables it to bridge traditional SNA networks with APPN networks so that customers may use SNA networking to its fullest capability\. With the Interchange Node capability, APPN network users can access network resources within the traditional SNA network, and traditional SNA network resources may access APPN network resources, all without any specialized network requirements\.

VM/VTAM provides support for both traditional SNA and APPN networks\. Traditional SNA networking support and access to APPN networks using LEN connectivity is provided with all current VM/VTAM releases\. Full APPN networking support is added with VM/VTAM V4R2\.
