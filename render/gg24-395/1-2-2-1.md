### 1\.2\.2\.1 Common User Access

<a id="HDRHSAA101"></a>

The Common User Access \(CUA\) is the definition of user interface components that should be common across all applications\. CUA is based on a set of generally accepted user interface design principles and is optimized for ease of use\. The fundamental objectives of CUA are:

- Usability and consistency within an application
- Consistency across applications

CUA defines two user interface models: entry and graphical\. Entry is the recommended model for the nonprogrammable terminal environment and is best suited for data\-entry\-intensive applications using panels with menus and prompts\. The graphical model is recommended for programmable workstation applications and makes extensive use of windows, action bars with pull\-downs, and standard graphical cues, such as check boxes\. The workplace environment is an extension of the graphical model\. The workplace environment is suitable for integration of applications as objects\. These objects appear as icons on an electronic representation of a real workplace and can be controlled with a mouse\.

The result of CUA is that individuals will find systems and applications easier to learn and use\. They will also find they can easily transfer their skill and knowledge across systems\.
