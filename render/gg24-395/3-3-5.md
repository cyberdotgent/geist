## 3\.3\.5 Networking: RSCS &amp; VM/Pass\-Through

<a id="HDRHRSC100"></a>

For some years, RSCS and VM/Pass\-Through Facility \(PVM\) have been

important players in VM's connectivity with the outside world\. RSCS provides the functions to handle file and message traffic, and PVM provides networking for 3270 terminals\. Both started with basic bisync communications, then were enhanced with SNA support\. Now they include basic TCP/IP support\.
