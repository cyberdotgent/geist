### 3\.2\.3\.4 The API for the CMS GUI

<a id="HDRHGUI170"></a>

Earlier in this chapter, we mentioned that an object model is defined for CMS\. The VM GUI Facility provides an object oriented API for GUI presentation\. People familiar with GUI programming for workstations, such as OS/2 with Presentation Manager, will recognize the terms *Objects*, *Attributes* and *Classes* that are used in the CMS GUI environment\. So writing a C\+\+ program for OS/2 Communication Manager or for the VM GUI facility is not that different\.

On the other hand, people accustomed to writing traditional CMS programs \(for example in REXX\), will not only have to learn the new terminology mentioned above, but must also get acquainted with the different GUI objects as push buttons, list boxes, or combo boxes you find in a typical GUI window\. For readers who fall into this category the next topic will introduce some basics\.
