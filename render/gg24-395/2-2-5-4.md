### 2\.2\.5\.4 Other POSIX Standards

<a id="HDRHEEE103"></a>

Both POSIX 1003\.1 and POSIX 1003\.2 have been approved by ANSI and ISO\. The following list includes additional POSIX standards that are still being developed, with the 1003\.1 and 1003\.2 standards included for completeness\. **1003\.0** A Guide to POSIX\-based Open Systems **1003\.1** System Call Interface and Language bindings for C **1003\.1a** Extensions and Corrections to 1003\.1 **1003\.1c** Threading \(formerly 1003\.4a\) **1003\.2** Shell and Utilities **1003\.2a** User Portability Extensions **1003\.3** POSIX Tests Methods **1003\.4** Real\-time Extensions **1003\.5** Ada **1003\.6** Security **1003\.7** Systems Administration **1003\.8** Networking **1003\.9** Fortran **1003\.10** Supercomputing **1003\.11** Transaction Processing **1003\.12** Protocol Independent Interfaces **1003\.13** Real\-Time Applications Environment Profile \(project of 1003\.4\) **1003\.14** Multiprocessing Applications Environment Profile **1003\.15** Supercomputing Batch Element \(project of 1003\.0\) **1003\.16** C Language Binding **1003\.17** Directory Service API **1003\.18** POSIX Platform Environment Profile \(project of 1003\.1\)
