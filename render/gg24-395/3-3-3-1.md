### 3\.3\.3\.1 Internetworking

<a id="HDRHTCP101"></a>

Internetworking can be defined as:

- resource sharing
- through layered protocols \(modularity\)
- for interprocess communication \(IPC\)
- over logical connections
- using common intermediate representation \(virtualizing\)
- while preserving efficiency and feasibility\.
