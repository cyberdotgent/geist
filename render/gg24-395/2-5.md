# 2\.5 Chapter 7\. Yes, We're Open

<a id="HDRHOOW200"></a>

IBM recognizes that a single vendor cannot define effective Open Systems solutions independently\. Therefore, IBM is actively working with customers, vendors, consortia, and standards organizations to evolve effective business solutions\. IBM continues to make huge investments in the open environment by being an enthusiastic participant in the development of significant industry standards and by contributing to standards bodies around the world\. If a widely accepted industry IT standard exists, IBM intends to actively support it\. For example, the Network File System \(NFS\) from Sun MicroSystems is a widely accepted file system that is supported in TCP/IP\.

If a standard is emerging, IBM will participate in its development\. An example is access to a relational database, which was originated by IBM as the SQL language and adopted by the industry\. Another example is IBM's commitment to such emerging standards as Asynchronous Transfer Mode \(ATM\), which is a networking protocol that allows very high volumes of traffic\.
