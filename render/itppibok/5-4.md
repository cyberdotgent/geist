## 5\.4 What's Next

<a id="HDRCONEND"></a>

After you have identified the logical and physical configurations you want to use to conduct the TPNS test, you may need to generate a TPNS control program or modify the NCP\. You also need to connect TPNS communication lines and links to the system under test\. You can use one of the following three methods to do this:

- External modem and real line
- Modem elimination
- Local attachment cables\.

[Defining TPNS Networks](<DOCNUM/SC31-6008/CCONTENTS>) explains each of these methods\.

You also need to code network definition statements to define the network you want to simulate\. For information about the planning considerations for this task, refer to ["Defining the Simulated Network\."](6-0.md) For information about the actual coding of network definition statements, refer to

[Defining TPNS Networks](<DOCNUM/SC31-6008/CCONTENTS>)\.
