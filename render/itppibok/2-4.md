## 2.4 Defining the Operator Interface Between TPNS and the NetView Program

<a id="HDRNTV"></a>

The operator interface between TPNS and the NetView program enables one <> or more NetView users to operate TPNS at the same time without requiring access to the system console, that is, the host processor console or Multiple Console Support (MCS) console. Most of the operator commands available to regular TPNS users are available to NetView operators. In addition, some TPNS operator commands are available only to NetView terminal users. Some of the operator commands enable you to show full-screen displays, enhancing your ability to perform testing and debugging. You can also write NetView CLISTs, command processors, and exit routines to help automate TPNS operation. If you plan to run TPNS with NetView, you must define the interface to the following: The operating system (MVS or VM) VTAM The NetView program TPNS.
