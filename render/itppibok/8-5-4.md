### 8\.5\.4 Using the Operator Interface between TPNS and the NetView Program

<a id="HDRRUNNET"></a>

The operator interface between TPNS and the NetView program enables one

or more NetView terminal users to operate TPNS at the same time without requiring access to the system console\. With this operator interface, you can operate multiple networks simultaneously\. To use the operator interface, you must define it to the following:

- The operating system
- VTAM
- The NetView program
- TPNS\.

In addition, you must start both TPNS and the NetView program as procedures from the host processor console\. You can do this by invoking the appropriate procedures defined in SYS1\.PROCLIB\. These procedures use the operating system's MODIFY interface\.

Most of the operator commands available to regular TPNS operators are available to NetView operators\. In addition, some TPNS operator commands are available only to NetView terminal users\. You can also write NetView CLISTs, command processors, and exit routines to help automate TPNS operation\.

In addition to providing increased testing capabilities, using the operator interface between TPNS and the NetView program helps makes TPNS easier to use\. You can use help panels to learn about TPNS operator commands and messages\. You can display a menu of TPNS simulated resources and monitor their status or issue TPNS and NetView commands for individual resources or groups of resources\. You can also monitor the screen images of simulated terminals on the NetView operator console\. Finally, you can use TPNS and the NetView program to help manage your communications network; refer to [Appendix D, "Using TPNS for Communication Network](d-0.md) [Management"](d-0.md) for more information\.

You can use two modes of TPNS operation if you are using a NetView terminal: line mode and full\-screen mode\.
