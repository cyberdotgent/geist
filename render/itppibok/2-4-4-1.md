#### 2.4.4.1 Single TPNS Session

<BOOK> When you are operating a single session of TPNS under MVS, you code the <> TNIAPPLS execution parameter on the JCL EXEC statement. When you are <BOOK> operating TPNS under GCS, code it on the TPNS START statement in your GCS command file. The format of the TNIAPPLS execution parameter is the following:

TN`IAPPLS=(xx`xxxxxx,yyyyyyyy) where xxxxxxxx is the name of the TPNS APPL and yyyyyyyy is the name of <BOOK> the NetView APPL. You must specify both names and separate them with a comma. Each name can be from 1 to 8 characters long. The TPNS APPL name <BOOK> must be the name coded on the APPL statement that defines the TPNS side of the interface between the NetView program and TPNS to VTAM. Likewise, the NetView APPL name must be the name coded on the APPL statement that defines the NetView side of the operator interface to VTAM. Using the APPL definitions in ["Defining the Operator Interface to VTAM,"](2-4-2.md) the following statements define to TPNS the interface between the NetView program and TPNS. The following are example JCL statements: //`GO` EX`EC P`G`M=ITPENTER` a // `PARM='TNIAPPLS=(TPNSSIDE,NETVS`IDE)' The following is a sample GCS command file statement: 'T`PNS S`T`ART T`N`IAPPLS=(TPNSSIDE,NETVSIDE)'` <BOOK> <> <> <SC30-3289> <> <TPN [SOP>](#LNK) For more information about TPNS execution parameters, refer to TPNS [<BOOK> <>](#LNK)<> <SC30-3289> <> <TPNSOP> Operation.
