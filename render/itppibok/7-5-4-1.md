#### 7.5.4.1 Obtaining a Trace of System Activity

As indicated in [Figure 15](7-5-4.md#FIGSGU), you can use several methods to obtain a trace of system activity:<BOOK> The NetView Performance Monitor (NPM) captures path information units (PIUs) for selected logical units.- The VTAM Buffer Trace with the Generalized Trace Facility (GTF) traces system activity.also The CCWTRACE option of GTF on OS/VS2 SP 1.3 (or later levels of / OS/VS2) will produce a trace tape of channel activity with an NCP that <BOOK> records all the channel command words (CCWs) executed and their associated data. The data includes buffer pads transferred from the <BOOK> NCP to the host, transmission headers (TH), request or response <BOOK> headers (RH), other headers, control information and messages, and the actual application data.- User-written routines enable you to capture the data sent and received by specific terminals and to save that data in an external data set. The captured data can be in the format needed by ITPSGEN or in a format that can be processed by one of the reformat programs discussed

in the next section. As an alternative, you can define a format for ( the captured data. In this case, you would write your own program to reformat the data so it can be processed by ITPSGEN.
