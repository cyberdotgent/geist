### 2\.3\.3 Authorizing TPNS on VM

<a id="HDRVMAUTH"></a>

TPNS will run on either an authorized or an unauthorized virtual machine\. However, you can improve TPNS performance by authorizing the virtual machine\. Two forms of authorization are useful for TPNS:

- Authorization of a GCS virtual machine

You can authorize a GCS virtual machine when you define the GCS group\. If TPNS runs on an authorized virtual machine, it runs in supervisor state and encounters lower overhead when using system functions\. The *VM/SP Group Control System Guide* explains the authorization procedure\.

- Authorization for real I/O You can authorize TPNS for real I/O by specifying OPTION DIAG98 in the directory for the virtual machine\. When it uses real I/O, TPNS locks the pages it uses for communication controller input and output into storage and presents already translated channel programs to the GCS general I/O interface\. The DIAG98 option is ignored unless TPNS is running on an authorized GCS virtual machine\.
