#### 6\.3\.1\.2 LU Statement

Use the LU statement to define one or more logical unit half\-sessions and to specify the type of half\-session to be simulated\. You can define primary or secondary logical unit half\-sessions\. In addition, you can specify a type of half\-session for secondary half\-sessions\. Any number of LU statements can follow the VTAMAPPL statement\. TPNS simulates each logical unit half\-session as a separate entity \(such as a single display, device, or terminal\) for message generation and message logging\.

Other operands on the LU statement define logical unit half\-session characteristics that are needed to interpret and generate unique data streams associated with products such as 3270 devices, the 3290 Information Panel, and the 8775 Display Terminal\.

The example below shows a TPNS network definition for a VTAM application simulation containing a simulated secondary logical unit\. The network is named VTAMNET, as defined on the NTWRK statement\. INIT=SEC specifies that the simulated secondary logical unit initiates sessions with the system under test\. The TPNS logical unit is known to VTAM as TPNSLU, as defined on the VTAMAPPL statement\. It is known to TPNS as USER1, as defined on the LU statement\. LUTYPE=LU2 specifies that the simulated logical unit is a Type 2 logical unit\. RESOURCE=TSO specifies that the logical unit will initiate a session with TSO in the system under test\.

`VTAMNET NTWRK INIT=SEC TPNSLU VTAMAPPL USER1 LU LUTYPE=LU2 RESOURCE=TSO`
