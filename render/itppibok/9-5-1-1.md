#### 9.5.1.1 Running the Response Time Utility

There are two types of input to the Response Time Utility: the TPNS log data set and the Response Time Utility control commands. The TPNS log data set is created automatically when you run TPNS, unless you specify / MLOG=NO on the NTWRK statement. You can create the file that contains the control commands. These commands specify what time limits to use, which <> lines and terminals to evaluate, how to compute response times, and how to <> generate output reports. As an alternative, you can specify the CONSOLE execution parameter and enter the control commands directly at the TPNS operator console.: You use JCL, a TSO CLIST, or an EXEC to start the utility, to name the input files, and to specify where the reports will be printed.
