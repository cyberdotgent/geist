### 6\.3\.4 Simulating IBM Token\-Ring Network Resources

TPNS can simulate the following resources attached to an IBM Token\-Ring Network:

- PU2, which is a PU Type 2 terminal
- PU21, which is a Type 2\.1 node
- USER, which is any SDLC or high\-level data link control \(HDLC\) terminal that does not use standard SNA headers\.

You use the LPORT and LLS network definition statements to define the simulated token\-ring configuration\. You use the LPORT statement to specify the physical ports on the token ring and the LLS statement to specify the logical link stations associated with each port\.

Each logical link station represents a single terminal or physical unit\. You can map a line to a logical link station by specifying the name of the logical link station on the LINE statement\. When you use such a mapping, only one TERM statement is allowed for the line, and you can specify only terminal types of PU2 and USER\. You can also map a PU21 LINE to a logical link station\.
