## 9.2 Logging Messages

<a id="HDROUTLOG"></a>

When processed by the Loglist Utility, the TPNS log data set is probably the single most valuable tool that you can use to debug your network definition statements and message generation decks. The TPNS log data set contains all data that has been transmitted or received by the <> TPNS-simulated resources in a specified network. You define the name of the message log data set in the LOGDD DD or FILEDEF statements when you run TPNS.* By default, the message logging facility is active for the entire network; however, you can deactivate message logging for the entire network or for a line in the network by specifying MLOG=NO on the NTWRK or LINE statement. You can also code the NTWRKLOG statement when you define a network to specify that a separate log data set be used for that network.
