# 2\.0 Installing TPNS

<a id="HDRINS"></a>

This chapter provides an overview of things you will need to do and questions you will need to answer when installing TPNS\. It is intended to show you what is involved *before* you actually begin\.

TPNS is distributed on three tapes:

1\. The TPNS product tape 2\. Online publications for VM systems 3\. Online publications for MVS systems\.

Each tape you install is a separate task\. You must install the product tape\. You may also elect to install one of the online publications tapes\.

The step\-by\-step instructions you should follow once you are ready to install from tape can be found in the program directory shipped along with the tape\.

If you are migrating to TPNS Version 3 Release 2 from Version 2 Release 4, refer to [Appendix A, "Migrating from Previous Versions of TPNS"](a-0.md) for information about the installation and user considerations you need to take into account\. For detailed information about the TPNS sample data sets included with the TPNS installation tape, see [Appendix B, "TPNS](b-0.md) [Sample Data Set\."](b-0.md) After you have installed TPNS, you can use ITPECHO to test the installation and to ease the learning and planning process\. ITPECHO is VTAM application program supplied with TPNS as a sample routine\. Refer to [TPNS General Utilities](<DOCNUM/SC30-3290/CCONTENTS>) for information about how to use ITPECHO\.
