## 6.3.1 Simulating Logical Units Using the VTAM Application Program Interface

<a id="HDRNETVTAM"></a>

This section discusses the network definition statements that define logical units that access real VTAM applications. These logical units could be terminals or other VTAM applications. For more information about

how TPNS supports VTAM application simulation, refer to ["VTAM Application](5-3-1.md) [<BOOK>](5-3-1.md)<> <> [<SC31-6008> <> <TPNSDF>](#LNK) Simulation" and to Defining TPNS Networks. If you are simulating logical units accessing a VTAM application, you must use both of the following statements: VTAMAPPL statement LU statement.
