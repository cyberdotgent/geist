#### 8.5.4.2 Using Full-Screen Mode

an Full-screen mode uses menus, prompts, and help panels. Three full-screen functions are provided with the operator interface between the NetView program and TPNS: help panels, a simulated device display function, and a resource list function.

Help Panels: Help panels describe all of the TPNS operator commands. Help panels also describe TPNS messages routed to the TPNS operator console and messages associated with the operator interface between the <> NetView program and TPNS. You can access these panels by issuing the HELP command. The HELP command is valid only when you are using the operator interface between TPNS and the NetView program. <> Simulated Device Display Function: The simulated device display function <BOOK> displays the screen image of a simulated 3270 or LU2 device on the NetView terminal. You can invoke this function by using the SHOW command or by using the SHOW statement in a TPNS message generation deck. The SHOW command is valid only when you are using the operator interface between TPNS and the NetView program. Resource List Function: The resource list function displays a list of resources simulated by TPNS and indicates the status of each resource. <> For example, it can indicate whether a network or line has been started and whether a resource is active. The resource list also enables you to issue TPNS or NetView commands that apply to one or more of these <> resources. The panel contains the name of a simulated resource along with its type (such as LINE, DEV, or SSCP) and one or more characters indicating the resource's status. You can enter the desired TPNS or NetView commands next to the resource's status. You invoke the resource <> list function by using the RESLIST command. The RESLIST command is valid only when you are using the operator interface between TPNS and the NetView program.
