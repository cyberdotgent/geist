#### D.1.1.2 Unsolicited Requests

A physical unit simulated by TPNS can send unsolicited requests containing events, statistics, or alerts to the Hardware Monitor component of the <> NetView program or to NPDA. To send these unsolicited requests from a simulated terminal, use the U operator command. This command inserts a user-defined TEXT statement (usually hexadecimal data) as an SNA RU and sends it to the host on the SSCP-PU flow.- You can code three types of RUs to send unsolicited data: NMVT (Network Management Vector Transport), RECMS (Record Maintenance Statistics), and RECFMS (Record Formatted Maintenance Statistics). The bits and bytes in <> these RUs indicate the statistical values or events that occurred. For example, the RUs can send information about the following items: Permanent errors Threshold errors Traffic volume data Hardware errors SDLC protocol errors. The RUs can originate from simulated terminal control units (such as the 3274) or communication controllers. You are responsible for coding and

<> verifying the TEXT statements that define these special RUs. Refer to SNA Formats and Protocols when coding these requests.
