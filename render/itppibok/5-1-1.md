These actual resources make up the ***system*** ***under*** ***test***.<> For example, if you want to conduct a stress test on your MVS system, the simulated resources might consist of a number of terminals. The actual resources (that is, the system under test) might consist of a real host computer running MVS, a real communication controller, and the channel between the host and the communication controller. If you want to simulate users accessing a new VTAM application, the system under test consists of a real host computer running VTAM and the VTAM applications.
