### A.1.2 Migration Checklist for TPNS Version 2 Release 4

Installing TPNS __ Modify your TPNS control program, if necessary. __ If you use a TPNS communication controller, generate a new TPNS control program. Using TPNS* __ Code definitions for Virtual Routes (VRs) in the network definition statements.<> __ Reassemble user exit routines using TPNS Version 3 Release 2 DSECTs as required.: __ Ensure that the TPNS channel end and start I/O appendages specified on the CHEAPP and SIOAPP TPNS execution parameters are the correct appendages for this version of TPNS. __ Ensure that the following operands are not coded in your network definition: ENA MULTROUT LNCP ATRABORT=YES NO COLOR=YES NO LOGDSPY=YES NO.<> __ Ensure that you do not use the Loglist Utility, the Response Time Utility, or the Log Compare Utility from this version of TPNS with log data sets created by an earlier level of TPNS.) __ Ensure that you install Version 1 Release 3 (or later) of the NetView program when you use the interface between TPNS and the NetView program.
