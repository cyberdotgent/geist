## A\.2 Migrating From TPNS Version 3 Release 1

<a id="HDRMIGNEW"></a>

If you are migrating from TPNS Version 3 Release 1 to this version of TPNS, you will need to review the following list of changes from Version 3 Release 1 to Version 3 Release 2\.

- Support for the Interactive Data Capture Utility,
- Support for Airlines Line Control \(ALC\) terminals\.
- Enhancements to the TPNS Structured Translator Language \(STL\)
- Enhancements to TPNS network and terminal simulation capabilities, including the following:

Support for sending and receiving blocked PIUs to and from Type 4 LUs

Support for control\-point to control\-point sessions

Support for IBM Token\-Ring Network lines to be used on cross\-domain links

Support for the Network Asset Management Function product set identification

Support for multiple message generation for LUs

- Enhancements to the TPNS Scripting Language
- Support for additional TPNS usability enhancements, including the following:

New options on the $DATE$ data field option for specifying the format of the date and a date offset

Automatic checking for APF authorization and CHEAPP and SIOAPP appendage levels

The EXTERM \(Exclude Terminal\) command for the Response Time Utility, which allows you to exclude terminals from response time analysis

The EXTERM \(Exclude Terminal\) and EXDEV \(Exclude Device\) commands for the Loglist Utility, which allow you to exclude terminals and devices from processing

Allowing different resources to be compared with the Log Compare Utility\.

- Enhancements to the TPNS/Application Test Processor \(TPNS/ATP\)
- Enhancements to the TPNS user exits:

Support for TPNS\-wide management of user exits New user exit operands added to the NTWRK statement

- Enhancements to TPNS performance, including:

Improved performance for VTAMAPPL simulations when TPNS is running out of an APF\-authorized library

Internal timer management enhancements

- Support for execution in 31\-bit mode in VM/ESA environments
- Other enhancements, including the following:

RTM support for option 4 for 3174 controllers

Enhancements to ITPECHO

Null RUs and data are displayed on LU device queries and Inactivity Reports\.
