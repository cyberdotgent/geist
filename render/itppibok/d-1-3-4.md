#### D\.1\.3\.4 Response Time Utility \<BOOK\>


<pre>
    Response Time Utility
   The TPNS Response Time Utility provides response time statistics and
   graphs for selected terminals or the entire simulated network after the
   simulation is finished.  It provides you with a great deal of flexibility
   in defining the beginning and end of logical transactions, so that you can
   measure particular responses or track system response statistics over
   time.  Refer to <a href="9-5-1.md">"Using the Response Time Utility"</a> and to <a href="#">TPNS General</a>
   <a href="#">Utilities</a> for more information about the Response Time Utility.
</pre>
