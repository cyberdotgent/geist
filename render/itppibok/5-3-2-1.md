#### 5.3.2.1 Using the Link-Attach Configuration

You can use the link-attach configuration, like the VTAMAPPL configuration, to test applications, subsystems, or access methods. In addition, you can use the link-attach configuration to test communication controller hardware or software, new line protocols, or network configurations. Like the VTAMAPPL configuration, you can use the <BOOK> link-attach configuration for stress, performance, regression, function, or capacity planning tests.

[<> Fi](8.png) gure 9 shows TPNS in the same host processor as the system under test. However, you can run TPNS in a different host, as shown in [Figure 5](comments.md#physica). You would use this configuration if you did not want TPNS operation to affect <> the performance of the system under test. This would be the case if you were conducting a stress or performance test, for example.
