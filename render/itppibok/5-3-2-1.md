#### 5.3.2.1 Using the Link-Attach Configuration

[<> Figur](resource:8) e 9 shows TPNS in the same host processor as the system under test. However, you can run TPNS in a different host, as shown in [Figure 5](comments.md). You would use this configuration if you did not want TPNS operation to affect <> the performance of the system under test. This would be the case if you were conducting a stress or performance test, for example.
