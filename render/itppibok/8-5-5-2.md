#### 8.5.5.2 Monitoring TPNS

the following procedures:: Issue Q (Query) operator commands to see what was last transmitted or received and how far into the message generation deck the simulation has progressed: Insert write-to-operator (WTO) statements into your message generation decks or use the STL SAY statement to inform the TPNS operator about the progress of the run. By monitoring the displays during the run with the TPNS Display Monitor Facility, the TPNS operator console is not cluttered with messages or TPNS query responses.
