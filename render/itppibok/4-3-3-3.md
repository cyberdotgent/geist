#### 4.3.3.3 Staffing

<BOOK> The third part of the resources section lists the people needed to conduct / the test. These include the people needed to install TPNS (if necessary), define the network, create the message generation decks, run TPNS, and <> analyze the results. You may not need different people for each of these <> steps, but you should consider each of these tasks as you plan your staffing needs.
