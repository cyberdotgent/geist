## 8.5.5 Using the TPNS Display Monitor Facility

<a id="HDRRUNDMF"></a>

three ways: To develop and debug TPNS scripts for display devices To monitor a test dynamically during operation To show interactions with host applications for user education and product demonstrations. You can use the TPNS Display Monitor Facility with Version 2 Release 1 and later releases of VTAM. The facility runs under MVS and VM. You activate the TPNS Display Monitor Facility when you start TPNS with the DMAPPL execution parameter specified.<> You can use the TPNS Display Monitor Function at any time during a TPNS simulation. Unlike the simulated device display function, which requires / that you re-enter the SHOW command to see another panel, the TPNS Display Monitor Facility shows changes to the screen image during the simulation.
