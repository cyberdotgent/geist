#### 4.3.3.2 Time

<> The second part of the resources section lists the time needed to complete <> the test. This includes the time needed to plan for and conduct the test as well as the time needed to analyze and report the results. If you are using TPNS for the first time, the time section can also include an estimate of the time needed to install TPNS, generate the control programs, and learn to use TPNS.

For an example schedule for a TPNS test, refer to [Figure 2](4-3-5-4.md).
