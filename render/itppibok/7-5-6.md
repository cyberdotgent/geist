### 7\.5\.6 Using TPNS ITPBTS

<a id="HDRMSGBTS"></a>

ITPBTS is a TPNS script conversion program that converts Batch Terminal

Simulator \(BTS\) input decks into TPNS message generation decks\. You normally use these input decks with BTS to test IMS applications in batch mode\. However, you can also use them to create TPNS message generation decks\. This section includes a brief overview of ITPBTS\. For more information about running ITPBTS, refer to [TPNS Script Generating](<DOCNUM/SC30-3453/CCONTENTS>) [Utilities](<DOCNUM/SC30-3453/CCONTENTS>)\. For examples of the input to ITPBTS and the output from TPNS refer to [TPNS Samples](<DOCNUM/SC30-3454/CCONTENTS>)\.
