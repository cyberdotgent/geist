### 9\.1\.3 Using the Monitor Function Report

The TPNS Monitor Function Report prints all text blocks sent or received

by a simulated resource\. It provides an immediate record of the activity on a simulated line for the entire line or a single terminal on the line\. You can use the report to help you debug your message generation decks\. To activate and deactivate the monitor function, use the P operand on the A \(Alter\) operator command\. The monitor function can be active for more than one resource at a time\.

To use the monitor function effectively, you should assign a dedicated printer to TPNS when you run TPNS\. This enables you to view the SYSPRINT output during TPNS operation\. Otherwise, the text blocks are printed to the data set you specified on the SYSPRINT DD or FILEDEF statements\. Note that if you use the monitor function for multiple high\-speed lines, data to be printed may be lost\.
