### 6\.3\.2 Simulating Terminals

<a id="HDRNETTERM"></a>

TPNS can simulate SNA terminals in the same domain as the system under test using either switched or nonswitched Synchronous Data Link Control \(SDLC\) lines\. For this type of simulation, TPNS simulates remote logical units owned by the system under test\. That is, the terminals are secondary logical units \(SLUs\) connected to the system under test by line attachments to a communication controller\. TPNS automatically handles all necessary SDLC line control and SNA session protocols, allowing a simulated SLU to be in session with a component of the system under test\.

You use the following three statements to define the line and terminal configurations:

- LINE statement
- TERM statement
- DEV statement\.

Each of these statements is briefly described in the following sections\.
