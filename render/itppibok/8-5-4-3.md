## 8.5.4.3 Using NetView CLISTs

<a id="HDRRNCLIST"></a>

#### Using NetView CLISTs

When you use the operator interface between TPNS and the NetView program, you can write NetView CLISTs to help automate TPNS operation. For <> instance, you can issue frequently entered commands from a CLIST simply by <BOOK> entering the name of the CLIST on the NetView command line. Likewise, you <> can issue a series of several TPNS operator commands from a single CLIST. <> In addition, you can write CLISTs that will monitor the TPNS messages sent to the NetView operator and issue TPNS commands depending upon the response received. You can also use the NetView Message Automation facility to define to the NetView program CLISTs that are to be executed when particular messages are received at a NetView terminal. By carefully anticipating the TPNS messages that you expect from a simulation run, you can use this facility to automate TPNS operation partially or completely.
