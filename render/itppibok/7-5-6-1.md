#### 7.5.6.1 Using ITPBTS Output

ITPBTS creates one TPNS message generation deck for each BTS input deck. <BOOK> You can use one or more of these decks as input to the TPNS preprocessor; however, you must combine them with a message generation deck that establishes a session with VTAM. Depending on the objectives for your <BOOK> test and the content of the BTS input decks, you may need to provide other message generation decks. You also need to provide the appropriate network definition statements.
