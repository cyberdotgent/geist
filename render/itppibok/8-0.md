# 8\.0 Running the Test

<a id="HDRRUN"></a>

This chapter explains the sequence to follow when you run TPNS\. It discusses the following tasks:

- Running and analyzing a sample test
- Preprocessing the TPNS script
- Estimating storage requirements
- Running TPNS on MVS, TSO, and VM
- Controlling and monitoring TPNS operation
- Running TPNS as a permanent task\.

It also describes what features are available for operation\. For specific information about how to use these features, refer to [TPNS Operation](<DOCNUM/SC30-3289/CCONTENTS>) and

[TPNS General Utilities](<DOCNUM/SC30-3290/CCONTENTS>)\.
