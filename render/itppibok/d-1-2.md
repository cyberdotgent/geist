### D.1.2 Monitoring Availability

You can use TPNS to monitor the availability of applications and hosts in a network of any size. You can use TPNS for many types of monitoring, ranging from partially to completely automatic. TPNS can simulate terminals that connect to various hosts and log on to various applications. You can write TPNS scripts to check the availability of each host and application, possibly by sending requests at <> selected time intervals, and to alert the NetView program, NCCF, or system

<BOOK> <> <> <SC30-3454> [<> <TPNSMP>](#LNK) <BOOK> operator when a problem is detected. Refer to TPNS Samples for a sample TPNS network that monitors system availability. TPNS can also simulate a terminal that logs on to a NetView or NCCF operator console. The TPNS terminal then takes control of the network or a span of the network. By doing this, a TPNS terminal can look for alert <> messages coming in from the entire network so that you do not have to check the console at frequent intervals. The TPNS terminal can even act <BOOK> like a NetView or NCCF operator for some error recovery procedures, such as activating resources or starting system jobs, if the Operator Communication Control Facility (OCCF) is available.
