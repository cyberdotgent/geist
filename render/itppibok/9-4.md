## 9.4 Comparing 3270 Display Records

<a id="HDROUTCOM"></a>

The Log Compare Utility compares 3270 display records from two TPNS log <BOOK> data sets and reports when a difference is detected. You can select the <BOOK> records to be compared and the fields to be compared for each record. You can also request a set of reports that identify the differences found between the display records.
