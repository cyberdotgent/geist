### 7\.5\.2 Using the TPNS Structured Translator Language and the STL Translator

<a id="HDRMSGSTL"></a>

The Structured Translator Language \(STL\) is a high\-level, structured

programming language that you can use to create message generation decks\. Like other structured languages, STL uses constants, variables, expressions, and structured control statements in its programs\. Whether you are a new or experienced TPNS user, you may find it convenient to write new message generation decks using STL\. STL enables you to program using familiar programming structures and conventions\. Because of its similarity to other programming languages, STL is easy to learn and it enables you to write message generation decks quickly and accurately\. If you like, you can incorporate message generation statements into STL programs\. Typically, an STL program is divided into one or more procedures, which are similar to subroutines in other programming languages\. The STL Translator translates STL programs into TPNS message generation decks\. Each message generation deck is equivalent to one STL procedure\. Thus, an STL program can be translated into more than one message generation deck\.
