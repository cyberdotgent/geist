#### 5.3.2.2 Using the ES/9370 with a Token-Ring Adapter

When you want to simulate terminals attached to an IBM Token-Ring Network, you generally use the link-attach configuration and generate a TPNS control program. However, if you are running TPNS on an ES/9370 equipped with a token-ring adapter, you do not need either a communication controller or a TPNS control program. For more information about using an
