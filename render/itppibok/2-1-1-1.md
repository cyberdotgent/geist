#### 2\.1\.1\.1 Disk Storage Space Requirements

On MVS, TPNS requires disk storage space for partitioned data sets that contain the following:

- Network definition statements and message generation decks
- TPNS host processor load modules
- TPNS control program \(CP\) object modules and macros
- TPNS control program load modules \(optional\)
- Network definition statements
- TPNS message generation decks
- Rate tables \(optional\) referenced by network definition statements
- Panels and CLISTs for the TPNS Application Test Processor \(TPNS/ATP\) and for the operator interface between TPNS and the NetView\* program
- Online publications and source files\.

At least 1500 tracks of 3380 DASD is required to use TPNS\. If you plan to log messages to DASD, you may require more disk space for the TPNS log data set\. See [TPNS Operation](<DOCNUM/SC30-3289/CCONTENTS>) for more information about allocating the log data set\.
