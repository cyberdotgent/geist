## 2.4.1 Defining the Operator Interface to the Operating System

<a id="HDRNVOPSYS"></a>

Before you can use the interface between the NetView program and TPNS, you must define the interface to the operating system. You must start both TPNS and the NetView program as procedures from the host processor console. You can do this by invoking the appropriate procedures defined in SYS1.PROCLIB. These procedures use the operating system's MODIFY operator interface.

**Note:** You cannot use the interface between the NetView program and TPNS <> if you start TPNS as a batch job or use a TSO CLIST.
