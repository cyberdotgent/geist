#### 4\.3\.5\.4 Schedule

The final section of the test plan indicates the schedule to follow

during the test\. You should indicate when you plan to begin the TPNS test and how long you expect it to take\. You may want to include target dates by which you will complete each sample test\. [Figure 2](4-3-5-4.md#FIGSCHED) shows an example schedule for a TPNS test that will simulate 60 terminals logging on to TSO\.

<a id="FIGSCHED"></a>

<a id="TBLTBLUNIQ34"></a>

```
   |                                                                        |
   |                                                                        |
   |  _____________________________________________ ______________________  |
   | | TASK                                        |      START DATE      | |
   | |_____________________________________________|______________________| |
   | | Start planning                              |         6/01         | |
   | |_____________________________________________|______________________| |
   | | Test plan completed                         |         7/01         | |
   | |_____________________________________________|______________________| |
   | | Run sample test 1 (one terminal logging on  |         8/01         | |
   | | to TSO)                                     |                      | |
   | |_____________________________________________|______________________| |
   | | Run sample test 2 (several terminals        |         8/08         | |
   | | logging on)                                 |                      | |
   | |_____________________________________________|______________________| |
   | | Run sample test 3 (one terminal logging on  |         8/15         | |
   | | from simulated domain)                      |                      | |
   | |_____________________________________________|______________________| |
   | | Run sample test 4 (60 terminals logging on) |         8/22         | |
   | |_____________________________________________|______________________| |
   | | Run sample test 5 (1 terminal, complicated  |         8/29         | |
   | | logon script)                               |                      | |
   | |_____________________________________________|______________________| |
   | | Run complete simulation (60 terminals       |         9/06         | |
   | | logging on, complicated script)             |                      | |
   | |_____________________________________________|______________________| |
   | | Analyze results and retest (as needed)      |         9/20         | |
   | |_____________________________________________|______________________| |
   | | Report results                              |        10/03         | |
   | |_____________________________________________|______________________| |
   |                                                                        |
```

Figure 2\. Example Schedule for a TPNS Test Note that the amount of time it takes to conduct a TPNS test depends on how complex your test is as well as on how familiar you are with TPNS\. If you are using TPNS for the first time, you should schedule additional time for installation and learning\.
