#### D.1.1.1 Solicited Requests

TPNS supports the Request Maintenance Statistics (REQMS) SNA command, which is generated by the Hardware Monitor component of the NetView program and by NPDA, when it is simulating those IBM physical units that currently support the command. The activate physical unit response generated for a simulated 3600, 3614, 3700, PU1, or PU2 indicates that the command is supported. TPNS generates a Record Formatted Maintenance Statistics (RECFMS) command when it receives a REQMS. All error counts <> contained in the RECFMS generated by TPNS have a value of zero.
