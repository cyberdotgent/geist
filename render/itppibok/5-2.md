The following example illustrates how you can follow these steps.<> Suppose that you work in the computing department of a rapidly growing, medium-sized company and your job involves maintaining and tuning the / company's network of computers. As your company expands, you use TPNS more and more to conduct regular performance tests on the system. The purpose of these tests is to detect problems in interactions and resource contentions before they affect your users.<> Currently, the company uses a multiple-domain network with the following characteristics: There are three domains. Each domain contains a communication controller that is channel attached to the host with a System/370 channel. The communication controllers are interconnected with links.<BOOK> Domain A contains Host A, a 3720 communication controller, and 200 terminals. Domain B contains Host B, a 3745 communication controller, and 200 terminals.<BOOK> Domain C contains Host C, a 3720 communication controller, and 200 terminals. VTAM is installed on each host to control the communication between the terminals and applications running on that host. Each host is using TSO on MVS.

**Note:** For now, you don't need to consider the types of terminals you are using or how they are connected to the communication controllers. However, you will need this information later when you are defining the network with network definition statements.
