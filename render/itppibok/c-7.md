## C\.7 X\.25 Packet\-Switched Network

<a id="HDRTERX25N"></a>

TPNS supports the following start\-stop communication terminals attached to an X\.25 packet\-switched network:

- 3101 Display Terminal \(block mode, half\-duplex mode, break sent but not received\)
- IBM 3161/63 Display Terminal \(3101 Emulation mode\)
- Western Union Model 33/35 TWX Terminal \(half\-duplex mode, break sent but not received\)
