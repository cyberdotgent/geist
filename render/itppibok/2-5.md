## 2\.5 Checklist for Installing TPNS

The following checklist summarizes the steps you follow when installing

TPNS and indicates where you can find instructions for performing each step\.

\_\_ 1\. Plan for installation and system requirements\. For more information, see ["Understanding Installation and System](2-1.md) [Requirements\."](2-1.md)

\_\_ 2\. Install TPNS\. See *TPNS Program Directory* for specific installation instructions\.

\_\_ 3\. Plan for authorization requirements\. For more information, see ["Authorizing TPNS\."](2-3.md)

\_\_ 4\. If you are going to run TPNS with NetView, install the NetView operator interface\.

\_\_ 5\. Verify TPNS installation:

- If you are not using communication controllers, run the sample script named INSTALL1\. See [TPNS Samples](<DOCNUM/SC30-3454/CCONTENTS>) for a listing of this script\.
- If you are using communication controllers:

Generate a TPNS control program\. See [Defining TPNS](<DOCNUM/SC31-6008/CCONTENTS>) [Networks](<DOCNUM/SC31-6008/CCONTENTS>) for information about generating a TPNS control program\.

Run the sample script named INSTALL2\. See [TPNS Samples](<DOCNUM/SC30-3454/CCONTENTS>) for a listing of this script\.

\_\_ 6\. Use the Loglist Utility to analyze the output from running the sample script\. For information about using the Loglist Utility see [TPNS General Utilities](<DOCNUM/SC30-3290/CCONTENTS>)\.
