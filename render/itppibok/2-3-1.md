## 2.3.1 Authorizing TPNS on MVS

<a id="HDRMVSAUTH"></a>

If you will be using communication controllers, you must authorize TPNS <> using the requirements of the authorized program facility (APF). TPNS will also execute more efficiently in the VTAMAPPL environment if it is <> authorized. You may have to follow several steps to provide system authorization for TPNS. For details, check the planning and user documentation for the system on which TPNS will operate. Refer to the

OS/VS2 System Program Library: Initialization and Tuning Guide for program authorization information for MVS. To be authorized, the TPNS load modules must reside in an <> installation-defined authorized library or in a private library that you have created and authorized, such as TPNS.LOAD. To authorize a user / library, you must add its name to the IEAAPF00 member of SYS1.PARMLIB or to the corresponding APF data set indicated in the MVS initialization <> parameters. Below lists sample entries for the IEAAPFxx member in <> SYS1.PARMLIB that are required to authorize TPNS execution on MVS. **Entry** **Explanation** **TPNS.LOAD** yourpack Authorizes the TPNS load module. **SYS1.SSPLIB** yourpack Authorizes the data set that contains the IFLOADRN routines required when performing an IPL on the TPNS communication controller (optional).
