#### 4.3.5.2 Sequence of Sample Tests

As explained in ["Running and Analyzing a Sample Test,"](8-1.md) you should divide the TPNS test into a number of sample tests. These sample tests enable you to test portions of the TPNS script before you run the complete simulation. You can use the test procedure part of the test plan to describe the sequence of sample tests.
