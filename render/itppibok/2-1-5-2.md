#### 2.1.5.2 Link-Attach Configuration

Use start-stop (SS) communications Use binary synchronous communications (BSC) line control Use Synchronous Data Link Control (SDLC) Are connected to an X.25 packet-switched network Are connected to an IBM Token-Ring Network Are connected to an 8100 processor. You can also use the link-attach configuration to simulate entire subareas in other SNA domains. These subareas include system services control points (SSCPs), NCPs, and all the physical and logical units controlled by / the NCPs. In this situation, TPNS enables you to drive cross-domain links from the simulated domains to the system under test. You can also use the link-attach configuration to simulate entire X.25 networks and Type 2.1 nodes. When you use the link-attach configuration, TPNS requires a communication controller. In addition, the system under test may require its own communication controller. The communication controller used for TPNS can be one of the following: 3745 3720 3725 with a minimum of 256 Kb of storage. The TPNS communication controller contains a TPNS control program that you must generate for your configuration using the generation libraries supplied with TPNS. Each line that a simulated resource will use to communicate with the system under test must have an existing communication line or cable connection between the TPNS communication controller and the communication controller allocated to the system under test.
