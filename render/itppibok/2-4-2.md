### 2\.4\.2 Defining the Operator Interface to VTAM

<a id="HDRNTVVTAM"></a>

Several instances or copies of TPNS can be run from the NetView program at the same time\. Each copy of TPNS establishes a separate session with the NetView program through VTAM\.

To define the operator interface between TPNS and the NetView program to VTAM, you must include APPL statements in the VTAMLST data set or file\. They must be activated by VTAM before you start the NetView program and TPNS\. The number of APPL statements needed depends on the number of TPNS sessions \(one for each copy of TPNS\)\.
