#### 2\.4\.2\.2 Multiple TPNS Sessions

For multiple sessions with TPNS, you must code an APPL statement in the network definition for each copy of TPNS that uses the interface between the NetView program and TPNS\. As with the single session, you must code only one APPL statement for the NetView side of the operator interface\.

If the interface between the NetView program and TPNS will be used by two copies of TPNS, you must include APPL statements such as the following:

`TPNSSID1 APPL TPNSSID2 APPL NETVSIDE APPL`

The name you code on the APPL statement for the TPNS side is the session identifier that you use when you issue commands from the NetView side\.
