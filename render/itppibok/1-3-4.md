### 1\.3\.4 Defining the Simulated Network

After you have determined the configuration of your system, you are ready to code the statements that define the configuration of your network\. ["Defining the Simulated Network"](6-0.md) discusses the general planning considerations for coding network definition statements\. [Defining TPNS](<DOCNUM/SC31-6008/CCONTENTS>) [Networks](<DOCNUM/SC31-6008/CCONTENTS>) provides information about coding the statements for a particular simulation\. The [TPNS Language Reference](<DOCNUM/SH20-2489/CCONTENTS>) provides reference information about network definition statements\. In addition, [TPNS Samples](<DOCNUM/SC30-3454/CCONTENTS>) contains sample network definitions that can help you code your own definitions\. Finally, if you want to perform additional processing of data and manipulation of network resources, refer to [TPNS User Exits](<DOCNUM/SC31-6071/CCONTENTS>) for information about coding user exit routines\.
