### 1.3.4 Defining the Simulated Network

After you have determined the configuration of your system, you are ready to code the statements that define the configuration of your network.

["Defining the Simulated Network"](6-0.md) discusses the general planning <BOOK> <> <> <SC31-60 [08> <> <TPNSDF>](#LNK) considerations for coding network definition statements. Defining TPNS [<BOOK> <](#LNK)> <> <SC31-6008> <> <TPNSDF> Networks provides information about coding the statements for a particular <BOOK> <> <> [<SH20-2489> <> <TPNSLG>](#LNK) simulation. The TPNS Language Reference provides reference information <BOOK> <> <> <SC30-3454> [<> <TPNSMP>](#LNK) about network definition statements. In addition, TPNS Samples contains sample network definitions that can help you code your own definitions. Finally, if you want to perform additional processing of data and <BOOK> <> <> <SC31-6 [071> <> <TPNSEX>](#LNK) manipulation of network resources, refer to TPNS User Exits for information about coding user exit routines.
