### 8.5.2 Controlling TPNS From a Console

TPNS uses the MVS MODIFY command interface to receive TPNS operator <> commands you enter at the operator console. A similar interface is built into the VM operator command interface. These interfaces eliminate the and need for write-to-operator-with-reply (WTOR) processing by the main TPNS simulation task. You must use the MODIFY command interface if you want to use the operator interface between TPNS and the NetView program. For more

information about using this interface, refer to ["Using the Operator](8-5-4.md) [<BOOK> <> <> <](8-5-4.md) SC30-328[9> <> <TPNSOP>](#LNK) Interface between TPNS and the NetView Program" and to TPNS Operation. Although you can use the WTOR interface, the system MODIFY command interface is the preferred method of entering commands manually. TPNS uses the WTOR interface if TPNS is started as a batch job. In this case, a time-stamped outstanding WTOR message is issued to enable you to enter TPNS console commands. You must preface each TPNS command with the number of the currently outstanding WTOR.
