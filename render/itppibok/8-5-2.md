### 8.5.2 Controlling TPNS From a Console

information about using this interface, refer to ["Using the Operator](8-5-4.md) [HDRRUNNET](8-5-4.md) <BOOK> <> <> <SC30-328 [9> <> <TPNSOP>](#LNK) Interface between TPNS and the NetView Program" and to TPNS Operation. Although you can use the WTOR interface, the system MODIFY command interface is the preferred method of entering commands manually. TPNS uses the WTOR interface if TPNS is started as a batch job. In this case, a time-stamped outstanding WTOR message is issued to enable you to enter TPNS console commands. You must preface each TPNS command with the number of the currently outstanding WTOR.
