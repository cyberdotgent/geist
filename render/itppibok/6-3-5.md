### 6\.3\.5 Simulating Type 2\.1 Nodes

TPNS supports the following networking functions within Type 2\.1 nodes:

- Data link control role definition
- BIND segmenting
- BIND pacing
- Multiple lines
- Dependent logical unit types 0, 1, 2, 3, and 6\.2
- Independent logical unit type 6\.2
- Adaptive session pacing
- Extended BIND
- Extended UNBIND
- CP\-CP session support from a TPNS end node\.

In addition, TPNS can simulate Type 2\.1 nodes that are channel attached to a communication controller loaded with a control program that supports boundary channel attachment\. Refer to [Defining TPNS Networks](<DOCNUM/SC31-6008/CCONTENTS>) for information about how TPNS supports Type 2\.1 simulations\.

To define a Type 2\.1 node to TPNS, you code the following statements:

- The PU21 statement defines the physical unit for the Type 2\.1 node and the control point node level values\. You can use operands on this statement to specify a boundary channel\-attached Type 2\.1 node\.
- The LU statement defines a logical unit for the Type 2\.1 node\. When it is simulating Type 2\.1 nodes, TPNS supports logical unit types 0, 1, 2, 3, and 6\.2\.
- The ADJNODE, LINE, and PU statements define the attributes of an adjacent link station\.
