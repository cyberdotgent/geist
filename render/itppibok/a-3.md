## A\.3 Installation Considerations

<a id="HDRMIGINST"></a>

The following list summarizes the changes to the installation procedure

that occur with this version of TPNS:

- If you want to preserve your previous TPNS libraries, you must follow the instructions in the TPNS Program Directory\.
- If you use a TPNS communication controller, you need to generate a new TPNS control program\. Refer to [Defining TPNS Networks](<DOCNUM/SC31-6008/CCONTENTS>) for more information\.
