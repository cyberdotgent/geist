# A\.0 Appendix A\. Migrating from Previous Versions of TPNS

<a id="HDRMIG"></a>

If you have been using a previous version of TPNS, there are a few considerations you must remember as you migrate to Version 3 Release 2\. This appendix summarizes these migration considerations\.

If you are migrating from TPNS Version 2 Release 4 to Version 3 Release 2, read the following sections:

1\. ["Migrating from TPNS Version 2 Release 4"](a-1.md) for information about migrating from Version 2 Release 4 to Version 3 Release 1

2\. ["Migrating From TPNS Version 3 Release 1"](a-2.md) for information about migrating from Version 3 Release 1 to Version 3 Release 2

3\. ["Installation Considerations"](a-3.md) for information about installation considerations\.

If you are migrating from TPNS Version 3 Release 1 to Version 3 Release 2, read the following sections:

1\. ["Migrating From TPNS Version 3 Release 1"](a-2.md) for information about migrating from Version 3 Release 1 to Version 3 Release 2

2\. ["Installation Considerations"](a-3.md) for information about installation considerations\.
