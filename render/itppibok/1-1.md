## 1.1 What Is Teleprocessing Network Simulator

<a id="HDRWHATIS"></a>

Teleprocessing Network Simulator (TPNS) is a terminal and network simulation tool. You can use TPNS to determine system performance and response time, to evaluate network design, to perform functional testing, <BOOK> and to automate regression testing. Used as a basic tool in a comprehensive test plan, TPNS increases the effectiveness of system <> testing by providing a structured and systematic approach to all phases of system testing.

TPNS Version 3 Release 2 runs on any IBM host processor that supports:/ MVS/370 (MVS/SP* Version 1 or later)/ MVS/XA* (MVS/SP Version 2 or later)/ MVS/ESA* (MVS/SP Version 3 or later)) Any VM system (with or without High Performance Option) that supports Group Control System (GCS)." In this book, MVS is any environment running MVS/370 or MVS/XA (unless / explicitly stated otherwise). VM is any environment running a VM/SP, / VM/XA*, or VM/ESA* system that supports GCS.

TPNS enables you to test and evaluate teleprocessing systems without needing to have terminals and terminal operators present. You can use TPNS to simulate the actions of a number of different applications, terminals, terminal operators, and network subareas. These simulated resources communicate with the real teleprocessing system (referred to as <BOOK> the system under test) as if they were physically present. No modifications to the system under test are required.
