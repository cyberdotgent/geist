### 8\.4\.3 Using VM

You can operate TPNS on VM without using a guest operating system\. TPNS

uses the functions of the Group Control System \(GCS\), which provides extensive simulation of MVS interfaces\. You can operate the TPNS utility programs in either GCS or Conversational Monitor System \(CMS\) operating environments, although they are typically operated under CMS\. For more information about running the TPNS utilities, refer to ["Using TPNS Output"](9-0.md) and to [TPNS General Utilities](<DOCNUM/SC30-3290/CCONTENTS>)\. TPNS includes a special facility, ITPLGWTR, that enables you to use a separate virtual machine for message logging when you operate TPNS under GCS\. There are two main benefits to using this facility:

- It enables you to log messages to tape\.
- It can improve TPNS performance by reducing the input/output \(I/O\) burden on GCS\. This improvement in performance is realized whether you log the messages to tape or disk\.

You normally start TPNS operation from a GCS command file\. You use the GCS LOADCMD operator command in the command file to define the GCS command for TPNS\. You then use this GCS command whenever you need to start, control, and stop TPNS\.

[TPNS Operation](<DOCNUM/SC30-3289/CCONTENTS>) includes sample command files for running TPNS using a TPNS control program \(link\-attach configuration\), an NCP \(direct\-attach configuration\), or no communication controller \(VTAMAPPL configuration\)\.
