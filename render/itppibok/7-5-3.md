### 7.5.3 Using the TPNS Interactive Data Capture Utility

<> The TPNS Interactive Data Capture Utility (IDC) is a host application that <BOOK> gives you an easy way to interactively capture 3270 device session data <BOOK> and generate TPNS scripts. To use Interactive Data Capture, you simply log on to it, much like any other VTAM application. Then, through Interactive Data Capture, log on to the VTAM application you want to test and perform the actions you want TPNS to simulate. Interactive Data Capture remains transparent to your application while it captures session traffic.<BOOK> When you are done, you tell Interactive Data Capture to generate either TPNS message generation decks or an STL program from the captured data.
