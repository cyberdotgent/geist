#### D\.1\.3\.1 3274 Response Time Monitor

The Response Time Monitor \(RTM\) feature of the IBM 3274 Control Unit

calculates and records response time figures for the 3270 terminals attached to it\. TPNS can simulate a 3274 with the RTM feature and communicate the statistics to the Session Monitor component of the NetView program or to the host application NLDM Release 2\.

Refer to [Defining TPNS Networks](<DOCNUM/SC31-6008/CCONTENTS>) for additional information about defining and using the TPNS RTM feature\.

In addition, TPNS can report the response time statistics for its own simulated terminals to the Session Monitor component of the NetView program or to NLDM\. The terminals may be testing a representative set of application transactions\. Therefore, you can get response statistics for a customized and repeatable set of transactions not normally available in a live production network\.
