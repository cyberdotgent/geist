#### D.1.3.1 3274 Response Time Monitor

<BOOK> <> [<> <SC31-6008> <> <TP](#LNK) NSDF> Refer to Defining TPNS Networks for additional information about defining and using the TPNS RTM feature. In addition, TPNS can report the response time statistics for its own simulated terminals to the Session Monitor component of the NetView program or to NLDM. The terminals may be testing a representative set of application transactions. Therefore, you can get response statistics for a customized and repeatable set of transactions not normally available in a live production network.
