#### D.1.3.2 NetView Performance Monitor

NetView Performance Monitor (NPM) is another product that gathers response <> time data for network logical units. Like the NetView program, NLDM, and RTM, NPM can monitor TPNS simulated terminals that perform a customized and repeated set of transactions. However, in this case, NPM gathers its data without direct communication with the network resources. It simply traces VTAM flows and measures response times with associated time stamp values.
