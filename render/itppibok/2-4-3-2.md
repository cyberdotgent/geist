#### 2\.4\.3\.2 Subtasks

To make the subtask ITPNTDST available, you must define it to the NetView program with a TASK statement\.

Under VM, you must add the following statement to the DSIDMN NCCFLST file:

`TASK MOD=ITPNTDST,TSKID=ITPNTDST,MEM=`*xxxxxxxx*`,PRI=5,INIT=Y`

The MEM=*xxxxxxxx* operand is required so that ITPNTDST will know where to find the names of the NetView\-side APPL defined to VTAM\. *xxxxxxxx* must be the filename of a file containing the APPL names you defined\. The filetype must be NCCFLST\. This file should be a single record file containing the NetView\-side APPL name beginning in column one\. Any information coded on the remainder of the record is ignored\. A sample file, ITPNTMEM NCCFLST, is provided on the installation tape\.

The contents of the sample file are the following:

`NETVSIDE`

Under MVS, you must include the TASK statement defining ITPNTDST in the DSIDMN member of the DSIPARM data set\. The MEM=*xxxxxxxx* operand defines the member name in the DSIPARM data set containing the APPL name\. The format of this member must be the same as that described for VM\. A sample member, ITPNTMEM, is provided on the TPNS installation tape\.
