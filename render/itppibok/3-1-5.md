### 3\.1\.5 Capacity Planning Tests

Capacity planning tests predict how your system will behave when new

resources are brought online\. These tests can also intentionally overuse one or more system resources to determine if the system can perform adequately with a predicted increased workload\. You can use capacity planning tests to answer the question "What will happen if I add this many resources to my system?" For example, you would use capacity planning tests to predict whether your system will perform adequately if you add 20 new terminals or to determine how it would perform if you connected an IBM Token\-Ring Network to it\.

TPNS enables you to drive a system with a higher transaction rate than normal without the need for terminal operators\. You can also verify previous capacity projections with a TPNS simulation\. In addition, some types of capacity planning tests are impossible to conduct without using a testing tool such as TPNS\. TPNS enables you to simulate more terminals or different types of terminals than you have in your production network\. You can also simulate additional SNA domains and use TPNS to model dynamic configurations\.
