#### 2.1.1.2 Access Method and Authorization Requirements

:    TPNS uses QSAM (Queued Sequential Access Method), BSAM (Basic Sequential "    Access Method), or BPAM (Basic Partitioned Access Method) for tape, disk, *    and unit record operations.  It uses VSAM (Virtual Sequential Access -    Method) for TPNS/ATP operations.  You can use any devices supported by <BOOK>    these access methods for TPNS data sets.  If TPNS is to communicate with a         communication controller, you must authorize TPNS using the requirements *    of the authorized program facility (APF).  This is a requirement because /    TPNS uses EXCPVR and must be able to fix pages in real storage.  Refer to

["Authorizing TPNS on MVS"](2-3-1.md) for more information. Authorization is optional when using the VTAM application interface to simulate terminals, but performance will be improved if authorization is <> provided. Such authorization enables TPNS to use the VTAM authorized path facility.
