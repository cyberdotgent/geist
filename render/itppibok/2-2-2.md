### 2\.2\.2 Printing the TPNS Program Directory on VM

To print a copy of the TPNS Program Directory from the distribution product tape in a VM environment, mount the tape and attach the tape drive to your VM ID as device 181\. After you enter the CMS commands shown below, the TPNS Program Directory will be printed at the printer assigned to your terminal\.

`VMFPLC2 FSF 28 VMFPLC2 LOAD PGMDIR LISTING PRINT PGMDIR LISTING`

To print a copy of the TPNS Program Directory from the distribution online publications tape in a VM environment, mount the tape and attach the tape drive to your VM ID as device 181\. After you enter the CMS commands shown below, the TPNS Program Directory will be printed at the printer assigned to your terminal\.

`VMFPLC2 REW VMFPLC2 FSF VMFPLC2 LOAD PUBPGDIR LISTING PRINT PUBPGDIR LISTING`
