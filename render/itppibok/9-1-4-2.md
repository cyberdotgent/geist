#### 9.1.4.2 SIT Trace Report

The SIT Trace Report provides a SIT trace for a specified LINE, LINK, or MCH between the TPNS control program and the system under test. The SIT

trace facility provides information supplied by the communication scanner a processor (CSP). You can trace only one LINE, LINK, or MCH at a time in each communication controller. TPNS can print the trace data in the TPNS <BOOK> log data set or on the online printer. Use the N operator command to <> activate and deactivate the SIT trace facility, to specify the name of the line or link, and to indicate where you want to print the data.

If you specify the name of a communication controller LPORT on the N / operator command, TPNS provides a Token-Ring Interface Coupler (TIC) trace for that IBM Token-Ring Network port. The TIC trace facility provides internal data in the form of medium access control (MAC) frames that appear to have been received by the LPORT. These frames are logged to the <> message log data set as data received. They are not written to the TPNS printer.
