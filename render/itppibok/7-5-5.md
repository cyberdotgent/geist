## 7.5.5 Using the TPNS Application Test Processor

<a id="HDRMSGATP"></a>

The TPNS Application Test Processor Utility (TPNS/ATP) enables you to <> create TPNS message generation decks from Message Format Services (MFS) screen definitions. TPNS/ATP makes it easy for you to test applications that are based on the IBM 3270 Information Display System and the IMS/VS

licensed program. **"** Note: You can use Screen Definition Facility II (SDF II) to create MFS / screen definitions for CICS/Basic Mapping Service (BMS), Interactive <> System Productivity Facility (ISPF), Graphical Data Display Manager an (GDDM*), or Cross System Product (CSP) panels. SDF II uses these other types of panels as input and creates MFS screen definitions. You then use the MFS definitions as input to TPNS/ATP.( Unlike the Script Generator Utility, TPNS/ATP does not depend on the " capture of "live" data. Instead, you use the TPNS/ATP editor to build a transaction testcase that defines a sequence of MFS panels that are transmitted to the system under test and received by TPNS. These testcases are saved in a VSAM data set called the Testcase File. You then use the editor to display each screen image and to define the test data <BOOK> that you want to transmit and that you expect to receive. These screen definitions are saved in a VSAM data set called the Screen Data File. The Testcase File and the Screen Data File comprise the TPNS/ATP data base, <BOOK> which is used as input to the TPNS/ATP script generator to create TPNS message generation decks./ TPNS/ATP is screen-oriented and only supports 3270 displays with screen images up to 62 rows and 160 columns.
