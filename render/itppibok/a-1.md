## A.1 Migrating From TPNS Version 2 Release 4

<a id="HDRMIGOLD"></a>

If you are migrating from TPNS Version 2 Release 4 to this version of TPNS, you will need to review the following list of changes from Version 2 Release 4 to Version 3: Support for the IBM 3745 Communication Controller( Support for token-ring adapters for simulating terminals attached to an IBM Token-Ring Network<> Support for the SNA Extended Subarea Addressing feature, which enables <BOOK> you to specify a maximum subarea address of 65535. In addition, TPNS Version 3 Release 2 now enables you to specify up to 16 Explicit Routes (ERs) per destination subarea.( Support for the simulation of Type 2.1 nodes that are channel attached to a communication controller loaded with a control program that supports boundary channel attachment<BOOK> Enhanced support for 3270-series simulation, reflecting architectural changes and the following additional functions: Support for generating the Summary Query Reply in response to a Read Partition Query structured field<BOOK> Support for the Query List type parameter in a Read Partition structured field

Support for the COPY command in an Outbound 3270DS structured field - Enhanced support for 3270 partitioning in the Loglist Utility and the Script Generator Utility<BOOK> - Limited support for the Trigger field AID in the Script Generator, Utility - Support for Insert and Delete key operation - Support for cursor movement keys - Support for testing field and character attributes on a screen image.* Support for a new TPNS language. You can now use the TPNS Structured ) Translator Language (STL), a high-level language, and the STL Translator to create message generation decks.<> Support for the Log Compare Utility, which compares 3270 display records from two TPNS log data sets<> A new type of requests for exit interface routines to support dynamically allocated save areas Support for additional usability enhancements including the following: - Multiple User Time Intervals (UTIs)<> - New options on the SET statement for assigning values to counters - Extended use of counters<BOOK> - A new MORE operand on the TEXT statement, which enables you to concatenate two TEXT statements<BOOK> - Ability to refer to a user table (UTBL) by name - Dynamic allocation of save areas - Network-level save areas

Larger user areas and save areas.:H3 - Support of screen sizes up to 62 rows and 160 columns for TPNS/ATP - New selections on the UTBL data field option.
