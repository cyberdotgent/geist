### 8.6.2 Using the Online Response-Time Monitor

[HDROUT](9-0.md) <BOOK> <> <> <SC30-328 [9> <> <TPNSOP>](#LNK) online. Refer to "Using TPNS Output" and to TPNS Operation for more information about using the RSTATS feature. For more information about <BOOK> <> <> <SC31-6 [071> <> <TPNSEX>](#LNK) writing user exit routines, refer to TPNS User Exits. You can use the following steps to develop a TPNS network that will monitor response times:* 1. Define a network containing one LINE, one PU, and one LU statement.- 2. Transmit one sample request to the system every few minutes (or at selected time intervals) and measure the time until a response is received. You can perform calculations with RSTATS or with a user exit routine. 3. Maintain running totals and averages internally within TPNS by using counters, save areas, and so on.: 4. Use the W (RSTATS Query) operator command or a user exit routine to display the response times on a real display terminal.) A response-time monitor can be as simple or complex as you want. By <BOOK> combining TPNS scripts, internal logic, and user exit routines, you can <BOOK> locate these custom-made monitors throughout your network with a minimum of overhead. A sample monitor network, which performs functions other than online <BOOK> <> <> <SC30-3454 [> <> <TPNSMP>](#LNK) response-time measurement, is presented in TPNS Samples.
