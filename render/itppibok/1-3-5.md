### 1.3.5 Creating Message Generation Decks

After you define the network you want to simulate with TPNS, you need to create message generation decks. Message generation decks define the messages that the simulated network sends to and receives from the system <> under test. They also enable the simulated network to take action based on the messages received. The content of the message generation decks and the content of the network definition statements can be interdependent. Therefore, as you create the message generation decks, you may need to refer to and refine your network definition statements. You can simplify this task by planning for the
