### 9\.3\.1 Running the Loglist Utility

There are two types of input to the Loglist Utility: the TPNS log data set and the Loglist Utility control commands\. The TPNS log data set is created automatically when you run TPNS, unless you specify MLOG=NO on the NTWRK statement or on all lower\-level resources\. You can create a file containing control commands that control the operation of the Loglist Utility and format the output produced by the utility\. As an alternative, you can specify the CONSOLE execution parameter and enter the control commands directly at the TPNS operator console\.

You use JCL, a TSO CLIST, or an EXEC to start the utility, to name the input files, and to specify where the formatted log will be printed\. For more information about using control commands and running the Loglist Utility, refer to [TPNS General Utilities](<DOCNUM/SC30-3290/CCONTENTS>)\.
