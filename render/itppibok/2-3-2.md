### 2\.3\.2 Authorizing TPNS under TSO

<a id="HDRTSOAUTH"></a>

You take two different steps when you authorize TPNS to run under TSO\.

The following list briefly describes these steps; refer to *OS/VS2 System Programming Library: TSO/E Customization* for complete details\.

1\. If you are installing TPNS under TSO Version 1\.4 or later and the member IKJTSO00 exists in SYS1\.PARMLIB, add the TPNS load module ITPENTER to the list of authorized programs contained in the member IKJTSO00\. There are two places where you need to do this, as shown in the example below\.

`. . . /* */`

`AUTHPGM NAMES( /* AUTHORIZED PROGRAMS */ + IEBCOPY /* */ + ICHDSM00 /* RACF PROGRAMS */ + ICHUT100 /* */ + ICHUT200 /* */ + ICHUT400 /* */ +` **ITPENTER** `/* */ + JMS /* */ + ) /* */ /* */ . . . /* */ AUTHTSF NAMES( /* PROGRAMS TO BE AUTHORIZED */ + /* WHEN CALLED THROUGH THE */ + /* TSO SERVICE FACILITY. */ + IEBCOPY /* */ + JMS /* */ +` **ITPENTER** `/* */ + IKJEFF76) /* */ /* */`

2\. If IKJTSO00 does not exist, add the TPNS load module ITPENTER to the list of authorized programs in the control section \(CSECT\) IKJEFTE8 of the module IKJEFT02\.

**Note:** TSO/E uses the IKJTABLS module instead of IKJEFT02\. The CSECT is still IKJEFTE8\.

You can do this in one of the following ways:

- Zap CSECT IKJEFTE8 of module IKJEFT02 and add the EBCDIC characters for ITPENTER in the next unused entry\.
- Change the source code for CSECT IKJEFTE8 and relink this module\.
- Use an SMP/E USERMOD\.

3\. List the following TPNS data sets as authorized in both the IEAAPFST and the IEAAPF00 members of SYS1\.PARMLIB or the corresponding APF data set indicated in the MVS initialization parameter\. Some of these data sets are optional for certain configurations\.

**TPNS\.LOAD** The load module for TPNS\.

**SYS1\.SSPLIB** The data set containing the IFLOADRN routines required during IPL for the TPNS communication controller\.

**Note:** The SSPLIB in your TPNS TSO logon procedure cannot be concatenated to a non\-authorized library or you will get a 913\-20 authorization ABEND\.

**Notes:**

1\. The Interactive Structured Programming Facility \(ISPF\) does not run as an authorized program under TSO\. If you attempt to start TPNS under ISPF, TPNS will fail with an authorization error in the form of a system ABEND 913\-20\. To run TPNS under ISPF, you must make ISPF an authorized program by adding it to the IEAAPFST and IEAAPF00 members of SYS1\.PARMLIB\.

2\. If you will be using TPNS only for VTAM application simulation, you do not need to authorize TPNS on MVS, but TPNS will execute more efficiently in the VTAMAPPL environment if it is authorized\.
