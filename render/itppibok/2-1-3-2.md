#### 2\.1\.3\.2 Required Authorizations

The ANY option on the Inter\-User Communication Vehicle \(IUCV\) enables GCS

to communicate with the control program and is required for GCS operation\. If you use separate virtual machines for message logging, you must authorize an IUCV connection for them as well\.
