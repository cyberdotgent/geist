### 2\.1\.4 General Requirements

This section describes the general requirements for running TPNS in

either an MVS or a VM environment\. It lists the installation requirements for using the programs, interfaces, and facilities provided with TPNS\.

**Logging Messages** To log the messages sent and received during a TPNS simulation, you need at least one tape drive or disk data set\. Refer to ["Using TPNS Output"](9-0.md) and to [TPNS General Utilities](<DOCNUM/SC30-3290/CCONTENTS>) for information about logging messages and formatting the log data set\. Refer to [TPNS Operation](<DOCNUM/SC30-3289/CCONTENTS>) for information about using operator commands to control message logging\. **Printing Output** To print output from the various TPNS programs, you must have a printer with at least a 132\-character print line\. **Using the VTAM Application Program Interface \(API\)** To use the VTAM Application Program Interface \(API\) to simulate SNA logical unit traffic, you must have any currently supported release of VTAM\. If this is the only type of simulation TPNS will perform, you do not need a communication controller\. In a VM environment, the TPNS virtual machine must be in the same GCS group as VTAM to run as a VTAM application program\. **Using the TPNS Operator Interface to the NetView Program** The operator interface between the NetView program and TPNS enables you to run TPNS from a NetView terminal\. If you want to use this interface, you must define it to the operating system, VTAM, the NetView program, and TPNS\. For a full description of these requirements, refer to ["Running the Test"](8-0.md) and to [TPNS Operation](<DOCNUM/SC30-3289/CCONTENTS>)\. **Using the TPNS Display Monitor Facility** The TPNS Display Monitor Facility enables you to display simulated 3270 screen images on a VTAM\-accessible monitor\. To use the TPNS Display Monitor Facility, you must define it to TPNS by using the DMAPPL execution parameter\. You must define it to VTAM as an APPL in VTAM's VTAMLST\. For a full description of these requirements, refer to [TPNS](<DOCNUM/SC30-3289/CCONTENTS>) [Operation](<DOCNUM/SC30-3289/CCONTENTS>)\. **Using the TPNS Application Test Processor \(TPNS/ATP\)** The TPNS Application Test Processor \(TPNS/ATP\) is a script generating utility provided by TPNS that is designed to help you generate scripts for Information Management System/Virtual Storage \(IMS/VS\) applications\. To use TPNS/ATP, you must satisfy certain requirements for TSO\. Refer to [TPNS Script Generating Utilities](<DOCNUM/SC30-3453/CCONTENTS>) for a complete description of the setup requirements\. **Using the TPNS Interactive Data Capture Utility \(TPNS/IDC\)** The TPNS Interactive Data Capture Utility \(TPNS/IDC\) provides a way to capture data from a 3270 display communicating with a host application program and generate a TPNS script from the captured data\. To use TPNS/IDC, you must define it to VTAM as an APPL in VTAM's VTAMLST\. Refer to [TPNS Script Generating Utilities](<DOCNUM/SC30-3453/CCONTENTS>) for additional information\.
