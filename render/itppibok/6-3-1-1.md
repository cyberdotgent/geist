#### 6.3.1.1 VTAMAPPL Statement

statement. You use the PASSWD operand on the VTAMAPPL statement to specify the password associated with the symbolic name of the VTAM application. The <BOOK> password you specify must match the value of the PRTCT operand on the APPL statement in VTAM. In addition to the APPLID and PASSWD operands, you can specify other <> operands on the VTAMAPPL statement. These operands affect various aspects of the simulation, including message generation, message logging, SNA simulation, display simulation, and 3270 simulation.
