### 1\.3\.7 Using TPNS Output to Analyze the Results

The final step in conducting a TPNS test is to use the TPNS output to analyze the results\. ["Using TPNS Output"](9-0.md) provides planning information about the options available for generating and using TPNS output\. Refer to [TPNS General Utilities](<DOCNUM/SC30-3290/CCONTENTS>) and [TPNS Operation](<DOCNUM/SC30-3289/CCONTENTS>) for information about how to use each of these options\.
