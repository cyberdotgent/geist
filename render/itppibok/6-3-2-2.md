#### 6\.3\.2\.2 TERM Statement

Use the TERM statement to define resources such as cluster controllers, control units, physical units, and general types of terminals\. Some examples of the general types of terminals you can specify are switched and nonswitched Bisynchronous Communications \(BSC\) terminals and SDLC terminals\. TPNS does not equate a TERM statement with a specific terminal; you define specific terminals using DEV statements\. The operand values that you specify on a TERM statement override any values specified for the same operands on the previous LINE or NTWRK statement\. That is, the resource defined by the TERM statement is controlled by the operands on the TERM statement rather than the same operands on the higher\-level statements\.

The following example defines a PU Type 2 terminal with the name TSOTERM\. It specifies an SDLC address of 01 and an intermessage delay value to be used for it and any devices that are defined under it by subsequent DEV statements\.

`TSOTERM TERM TYPE=PU2,ADDR=01,DELAY=A20`
