## PREFACE.1 Who Should Read This Book

<a id="HDRPREWHO"></a>

This book is intended for any TPNS user who: Is responsible for developing TPNS test plans <> Wants a general overview of the tasks performed during TPNS tests Needs to install TPNS.<BOOK> Before using this book, you should be familiar with basic TPNS concepts

which are summarized in TPNS General Information. This book assumes that you are familiar with Systems Network Architecture (SNA) terminology and concepts.
