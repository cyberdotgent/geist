### 1\.2\.1 What Can TPNS Simulate

<a id="HDRGETSIM"></a>

TPNS can simulate the following types of resources:

- SNA logical units running as VTAM application programs
- SNA network resources including terminals, subareas, and domains
- IBM Token\-Ring Network resources
- Type 2\.1 nodes, including boundary channel\-attached Type 2\.1 nodes
- X\.25 packet\-switched network resources
- Specific devices within the above network configurations\.

For a complete list of the specific terminals and line disciplines that you can simulate with TPNS, refer to [Appendix C, "Terminals and Line](c-0.md) [Disciplines Supported\."](c-0.md)
