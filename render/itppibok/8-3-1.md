### 8.3.1 Host Processor Virtual Storage Estimates

The approximate storage requirement, in bytes, for the execution of a TPNS simulation is: Storage Estimate = 1,500,000 + N where N is the storage required for network definition control blocks./ For an average size network, TPNS requires 1,500,000 bytes of virtual storage for the TPNS host processor load modules, work areas, and internal <> buffers. If you plan to simulate a larger network, you need to determine the storage required for network definition control blocks.
