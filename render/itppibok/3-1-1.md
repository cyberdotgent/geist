### 3.1.1 Function Tests

" Some of the functions that you can test with TPNS include new application transactions, logon and logoff sequences, error transactions, <BOOK> new hardware attachments, and new software products. For example, you would use a function test to determine if each function of your new application program works as designed. A significant advantage to using TPNS for function tests is that you can <BOOK> save the TPNS scripts and use them for later regression or stress tests.
