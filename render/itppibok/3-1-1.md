### 3\.1\.1 Function Tests

Use function tests to test a function of your system independently of

other functions\. This type of test answers the question "Does it work right?" Some of the functions that you can test with TPNS include new application transactions, logon and logoff sequences, error transactions, new hardware attachments, and new software products\. For example, you would use a function test to determine if each function of your new application program works as designed\.

A significant advantage to using TPNS for function tests is that you can save the TPNS scripts and use them for later regression or stress tests\.
