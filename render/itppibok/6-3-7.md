### 6\.3\.7 Simulating Specific Devices

In addition to defining different types of networks, network definition statements can define specific types of devices\. As explained in [Defining](<DOCNUM/SC31-6008/CCONTENTS>) [TPNS Networks](<DOCNUM/SC31-6008/CCONTENTS>), when you use network definition statements to define the following devices, you may need to consider special coding requirements:

- IBM 3270 Information Display System
- IBM 1050 Data Communication System
- IBM 2740 Communication Terminal, Models 1 and 2
- IBM 2741 Communication Terminal
- Western Union Model 33/35 TWX Terminal
- IBM 3101 Model 2 Display Terminal
- BSC*x* Terminals
- Airline Line Control \(ALC\) Terminals
- IBM 8775 Display Terminal
- IBM 5250 Display Station
- Model 20 Multileaving Workstation
- TPNS USER Terminal
- IBM 8100 Information System
- IBM Personal Computer \(PC\)\.

These coding requirements can include special considerations for the following:

- Polling and addressing characters
- Conditions for message generation
- Device\-specific special features\.

Refer to [Defining TPNS Networks](<DOCNUM/SC31-6008/CCONTENTS>) and [Creating TPNS Message Generation Decks](<DOCNUM/SC31-6009/CCONTENTS>) for information about the special requirements for specific devices\.
