## 7.5.4.2 Reformatting the Trace Output

<a id="HDRMSGFORM"></a>

#### Reformatting the Trace Output

If the trace of system activity is not in the format required by ITPSGEN, you must reformat it before you can use it to create message generation <BOOK> decks. TPNS provides three programs to help you reformat trace output: ITPVTBRF ITPRFMT ITPTSGRF. For more information about the types of trace records reformatted by each

<BOO [K> <> <> <SC30-3453> <> <TPNSSG>](#LNK) of these programs, refer to TPNS Script Generating Utilities.
