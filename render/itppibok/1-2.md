## 1.2 How Do You Use TPNS

To use TPNS, you write network definition statements that describe the network configuration to be simulated. You also create message generation decks that send and receive messages and enable your simulated terminals

<> traffic. Because your programs and associated hardware are integral parts of the simulation process, TPNS closely approximates a true operating environment. TPNS can generate the same or different messages for multiple terminals. This ability is especially useful in time-sharing environments. TPNS can also simulate multiple networks concurrently to provide messages to drive multiple teleprocessing applications or multiple host processors. You can also use TPNS as an availability monitor. By simulating a terminal that transmits messages to an online system at predetermined intervals and analyzing the response times to these messages, TPNS objectively monitors system availability and transaction response times to ensure service-level requirements are met.
