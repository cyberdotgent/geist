#### 7\.5\.6\.2 Running the Application in Response and Nonresponse Modes

The message generation decks produced by ITPBTS assume that your IMS application is running in response mode\. This means that the keyboard is locked until the simulated terminal receives a response from the IMS application\. Your TPNS script remains synchronized with the application because message generation does not resume until after the keyboard unlocks\.

If you want to run your application in nonresponse mode, you must include a series of IF statements in the converted TPNS message generation decks\. These IF statements help ensure that the TPNS script and the application are synchronized\. See [TPNS Script Generating Utilities](<DOCNUM/SC30-3453/CCONTENTS>) for an example of the IF statements needed to synchronize message generation with an application running in nonresponse mode\.
