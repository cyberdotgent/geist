#### 7.5.5.2 Advantages of Using TPNS/ATP

For applications undergoing initial development, you can create <BOOK> TPNS/ATP testcases as soon as the screen definitions have been completed. Because the screen definitions are generally completed before the application can run in production mode, application testers can write TPNS scripts while programmers are developing the code.<BOOK> For existing applications, you can create TPNS/ATP testcases to replace TPNS scripts that were created by obtaining data traces. Because scripts created from data traces are generated using a specific functional level of the application, changing the application <> may make the script unusable. If this happens, you must retrace the <BOOK> data and regenerate the TPNS script. TPNS/ATP enables you to modify <BOOK> message generation decks easily. If fields on a panel have been moved or if their size has been changed, you simply re-run the TPNS/ATP script generator to create new message generation decks. In both cases, the time saved by application testers increases their productivity and enables them to concentrate on developing application testcases.
