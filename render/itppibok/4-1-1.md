## 4.1.1 Purpose

<a id="HDRPLNPUR"></a>

The first part of your statement of objectives describes the purpose of <>    the test.  For example, suppose you want to determine how well you can <>    make your MVS system work under conditions of typical use.  You want to               adjust system parameters and test the system to find the combination of (    parameters that optimize performance.  To do this, you decide to use TPNS <>    to simulate 60 users logging on to TSO from different domains in your                                                                   network.  You can adjust system parameters such as buffer sizes and            transmission priorities and repeat the tests until performance is ?    optimized.                 Your statement of purpose should identify the type of test you are (    planning to conduct.  The type of test can determine where you run TPNS.                                                                   For example, if you want to conduct a performance or stress test, you                                                                   should run TPNS in a separate host processor to ensure that TPNS operation                                                                   does not affect the performance of the system under test.  Refer to

[<BOOK> "Testing](3-0.md) with TPNS" for a complete discussion of the types of tests and their uses and requirements.
