#### 9\.1\.4\.1 Line Trace Report

The Line Trace Report provides a trace of all characters sent or received

across a specified line \(LINE\), cross\-domain link \(LINK\), or multichannel link \(MCH\) between the TPNS control program and the system under test\. You can trace only one LINE, LINK, or MCH at a time in each communication controller\. TPNS can print the trace data in the TPNS log data set or on a printer\. Use the B operator command to activate and deactivate the line trace facility, to specify the name of the line or link, and to indicate where you want to print the data\.
