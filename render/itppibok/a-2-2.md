### A.2.2 Migration Checklist for TPNS Version 3 Release 1

You can use the following checklist of the items previously described to ensure a smooth transition to this version of TPNS.

Installing TPNS __ Modify your TPNS control program, if necessary. __ If you use a TPNS communication controller, generate a new TPNS control program. Using TPNS: __ Ensure that the TPNS channel end and start I/O appendages specified on the CHEAPP and SIOAPP TPNS execution parameters are the correct appendages for this version of TPNS.<> __ Reassemble user exit routines using TPNS Version 3 Release 2 DSECTs as required.- __ Ensure that LOG BUFFER and LOG SCREEN are changed to LOG DISPLAY.<BOOK> __ Ensure that any INDEX functions on ONIN and ONOUT statements are coded correctly.<BOOK> __ Ensure that the VSAM screen definition file is reformatted to allow <BOOK> 16-byte keys for the TPNS/ATP utility programs.<> __ Ensure that you are not using any BRANCH statements as a delimiter within an EXECUTE deck.* __ Ensure that no STL reserved words are coded as variable names. <> __ Ensure that you do not use the Loglist Utility, the Response Time Utility, or the Log Compare Utility from this version of TPNS with log data sets created by an earlier level of TPNS.) __ Ensure that you install Version 1 Release 3 (or later) of the NetView program when you use the interface between TPNS and the NetView program.
