# D\.0 Appendix D\. Using TPNS for Communication Network Management

<a id="HDRCNM"></a>

This appendix discusses how you can use TPNS to help manage the communication network in your organization\. It describes the features that enable TPNS to simulate alerts, monitor resource availability, and measure system response times\. The basic goals of managing a communication network include the following:

- To centralize and simplify the operation of complex networks
- To promote the identification and resolution of problems or potential problems by retrieving and displaying diagnostic information to a network operator\.
