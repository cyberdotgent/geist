# 4\.0 Creating a Test Plan

<a id="HDRPLN"></a>

This chapter presents a systematic approach to creating a test plan for your TPNS test\. It emphasizes the importance of establishing test objectives *before* you plan for a particular test\. Then, it discusses what you need to design a test plan for TPNS\. Finally, it describes one way you can organize the information in your test plan\.
