### 5\.1\.2 Physical Configuration

<a id="HDRCONUPHY"></a>

The physical configuration describes how the actual hardware and software resources needed for a particular TPNS test are arranged\. These resources include the resources needed to run TPNS and the resources in the system under test\. They can include the following:

- Host processors
- Communication controllers
- System software, including Operating system Access method \(for example, VTAM\) Communication control programs \(for example, NCP\)
- Application software
- Test monitoring programs
- TPNS\.

As part of determining the physical configuration, you identify whether you need to use a communication controller, generate a TPNS control program, or modify your existing NCP\.

The next section of this chapter presents an example that demonstrates how to configure your system for a TPNS test\. The final section of this chapter provides more detail about each of the logical and physical configurations you can use during TPNS tests\.
