### 2.1.5 Communication Controller Requirements

To simulate network resources, you can operate TPNS in the following three physical configurations: VTAMAPPL for simulating VTAM primary and secondary LUs) Link-attach for simulating terminals, Type 2.1 nodes, and link-attached subareas- Direct-attach for simulating subareas and boundary channel-attached Type 2.1 nodes.

["Determining Your System Configuration"](5-0.md) describes these physical configurations in detail and discusses the types of network resources you can simulate with them. Depending on which physical configuration you use, TPNS has specific requirements concerning whether communication controllers are necessary to run the simulation and how the communication controllers must be configured. TPNS Version 3 Release 2 supports the IBM 3745, 3720, and 3725 communication controllers. The following sections describe the communication controller requirements for each type of physical configuration.
