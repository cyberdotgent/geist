### 8.3.2 Storage for the TPNS Control Program

run a TPNS control program. The exact amount of storage required for the TPNS control program depends on the following: The number and types of lines defined in the TPNS control program The number of concurrently active lines The number of terminals and devices simulated on each line The amount of message data resident in the communication controller at any one time. The TPNS control program uses all available storage in the communication controller. If the load module does not consume all the storage, the remaining storage is formatted into buffer pools.
