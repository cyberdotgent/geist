#### 2\.4\.3\.1 The TPNS Load Library

As part of running the NetView program, you must define the TPNS load library, containing the optional NetView subtask and the command processors, to the operating system with a JCL DD statement \(MVS\) or a GCS command file GLOBAL LOADLIB statement \(VM\)\. The following is an example JCL statement:

`//STEPLIB DD DSN=TPNS.LOAD,DISP=SHR`

The following is an example GCS command file statement:

`GLOBAL LOADLIB TPNSLOAD`

Under MVS, you need additional JCL statements to define the data sets containing the CLISTs and panels used by the interface between the NetView program and TPNS\. Add the following two statements to the NetView JCL after the DSICLD and CNMPNL1 DD statements\. These statements concatenate the CLIST and panel data sets to the DSICLD and CNMPNL1 data sets\.

Code the following DD statement after the DSICLD DD statement:

`// DD DSN=TPNS.CLIST,DSP=SHR`

Code the following DD statement after the CNMPNL1 DD statement:

`// DD DSN=TPNS.PANEL,DSP=SHR`

For more information about defining the CNMPNL1 and DSICLD statements to the NetView program, refer to the *NetView Installation and Administration Guide*\.
