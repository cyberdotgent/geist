#### 6.3.2.3 DEV Statement

Use the DEV statement to define the specific type of simulated terminal, workstation, or printer attached to the resource defined by the preceding <> TERM statement. Some examples of specific devices that you can define are the IBM 3270 terminal, the IBM 3767 Communication Terminal, and the IBM <> 3287 printer. The operand values that you specify on a DEV statement override any values specified for the same operands on the previous TERM, LINE, or NTWRK statement. That is, the resource defined by the DEV statement is controlled by the operands on the DEV statement rather than the same operands on the higher-level statements. The following example defines a 3270 LU Type 2 terminal with the name TSODEV and an address of 02.

TS`ODEV` DE`V` TY`PE=LU2,ADDR=02`
