### 9.4.1 Running the Log Compare Utility

There are two types of input to the Log Compare Utility: TPNS log data sets from two TPNS test runs and the Log Compare Utility control commands. The TPNS log data sets are created automatically when you run TPNS, unless you specify MLOG=NO and LOGDSPY=NONE on the NTWRK statement. You can create a file that contains the control commands. These commands specify which records from the log data sets to compare and when and how to <> synchronize the log data sets. As an alternative, you can specify the CONSOLE execution parameter and enter the control commands directly at the TPNS operator console.: You use JCL, a TSO CLIST, or an EXEC to start the utility, to name the input files, and to specify where the reports will be printed.
