#### 2\.4\.2\.1 Single TPNS Session

For a single session, you must code two APPL statements in the VTAM definition statements to define to VTAM the interface between the NetView program and TPNS\. One APPL statement defines the TPNS side of the operator interface and the other defines the NetView side\. The application names coded on the APPL statements can be any valid name that conforms to VTAM naming conventions\. \(Refer to *VTAM Network Implementation Guide* for information about VTAM application naming conventions\.\)

The following is an example of the two APPL statements needed for a single TPNS session:

`TPNSSIDE APPL NETVSIDE APPL`
