#### 6\.3\.2\.1 LINE Statement

Use the LINE statement to define the lines over which TPNS communicates with the system under test and to describe characteristics of the terminals to be simulated on each line\. You can use the LINE statement to define the following types of lines:

**Physical line** For a physical line, the name field or the LINEID operand on the LINE statement specifies the physical address of the line\. This address provides the link between the host containing TPNS and a line definition in the TPNS control program\.

**Logical line mapped onto an X\.25 logical channel \(LCH\)** For a logical line mapped onto an X\.25 logical channel, the LCH operand specifies the name of the X\.25 logical channel \(LCH\) onto which this logical line is mapped\.

**Logical line mapped onto an IBM Token\-Ring Network logical link station \(LLS\)** For a logical line mapped onto an IBM Token\-Ring Network logical link station, the LLS operand specifies the names of the IBM Token\-Ring Network logical link stations onto which this logical line is mapped\.

The LINEID, LCH, and LLS operands are mutually exclusive\.

Other operands on the LINE statement enable you to specify common attributes for the terminals on the line\. These LINE statement operands define values that default to the TERM and DEV statements associated with the line\. The operand values that you specify on a LINE statement override any values specified for the same operands on the NTWRK statement\. That is, the line is controlled by the operands on the LINE statement rather than the same operands on the NTWRK statement\. You specify the characteristics of a physical line when you define the line to the TPNS control program\.

The following example defines a physical line with a name of LINE0021 and a LINEID of 010021\. The PATH operand identifies PATH statements \(numbered 0, 1, and 3\) that specify sequences of message generation decks\. TPNS uses these sequences to generate messages for terminals defined under this LINE statement\.

`LINE0021 LINE LINEID=010021,PATH=(0,1,3)`
