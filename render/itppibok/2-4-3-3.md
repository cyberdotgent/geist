#### 2\.4\.3\.3 The Command Processors and Command Lists

To define the command processors and command lists to the NetView

program, you must add the following statements to the DSICMD member of the DSIPARM data set \(under MVS\) or the file DSICMD NCCFLST \(under VM\)\. The example below shows a sample of CMDMDL statements you use to define the command processors and command lists to the NetView program\.

`*- - - - - - - - - - - - - - - - - - - - -* * NOTE - THE FOLLOWING CMDMDL STATEMENTS DEFINE OPERATOR * * SUBTASK COMMAND PROCESSORS USED BY THE OPERATOR INTERFACE * * BETWEEN TPNS AND THE NETVIEW PROGRAM. * *- - - - - - - - - - - - - - - - - - - - -* ITPNTOST CMDMDL MOD=ITPNTOST,RES=Y ITPNTPS1 CMDMDL MOD=ITPNTPS1,PARSE=N,ECHO=N ITPNTPS2 CMDMDL MOD=ITPNTPS2,PARSE=N,ECHO=N ITPNTMSG CMDMDL MOD=ITPNTMSG,PARSE=N,ECHO=N,RES=Y TPNSIMM CMDMDL MOD=ITPNTIMM,PARSE=Y,ECHO=N,TYPE=I *- - - - - - - - - - - - - - - - - - - - -* * NOTE - THE FOLLOWING CMDMDL STATEMENT DEFINES A CLIST * * REQUIRED BY THE OPERATOR INTERFACE BETWEEN TPNS AND THE * * NETVIEW PROGRAM. * *- - - - - - - - - - - - - - - - - - - - -* TPNS CMDMDL MOD=DSICCP`
