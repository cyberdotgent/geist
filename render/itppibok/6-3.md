## 6\.3 Simulating TPNS Networks

<a id="HDRNETSIM"></a>

The following section provides a brief overview of how TPNS simulates different types of networks\. It describes some of the network definition statements you use to define these networks and network resources to TPNS\. These networks and network resources include the following:

- Logical units \(LUs\) that access real VTAM applications using the VTAM Application Program Interface \(VTAM application simulation\)
- Terminals in the same domain as the system under test \(terminal simulation\)
- Host subareas, NCP subareas, physical units, and logical units in one or more domains in an SNA network \(subarea simulation\)
- IBM Token\-Ring Network resources
- Type 2\.1 nodes
- Boundary channel\-attached Type 2\.1 nodes
- X\.25 packet\-switched networks and resources\.

For complete information about each of these types of simulation, refer to [Defining TPNS Networks](<DOCNUM/SC31-6008/CCONTENTS>)\. For complete information about the syntax of the network definition statements for each type of simulation, refer to the

[TPNS Language Reference](<DOCNUM/SH20-2489/CCONTENTS>)\.
