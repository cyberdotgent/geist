## 2.4.3 Defining the Operator Interface to the NetView Program

<a id="HDRTASK"></a>

three components: 1. A NetView optional subtask (ITPNTDST) 2. NetView operator subtask (OST) command processors 3. A NetView command list (TPNS). The subtask and command processors are loaded from the TPNS load library when you start the NetView program so that they are available to the program at start-up. The command list must be available to the NetView program while the program is running. Therefore, you must define the load library correctly before defining the subtask, command processors, and command lists.
