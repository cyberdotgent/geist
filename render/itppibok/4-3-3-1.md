#### 4.3.3.1 Hardware and Software

The first part of the resources section lists the hardware and software you need to run the test. This includes resources needed to run TPNS as well as the actual resources in the system under test. The types of resources that you would list in this section include the following: Host processors Operating systems Communication controllers Communication control programs TPNS Other telecommunications software such as VTAM or NCP Software applications you will use Data bases or data sets you will access Other monitoring and testing programs.<BOOK> You should specify the model or release level of each resource as well as any other information that would be helpful. For example, this section might indicate that you need an IBM 3745 communication controller for <BOOK> eight hours a day for three weeks and that you will be using TPNS Version 3 Release 2 to test TSO on MVS.
