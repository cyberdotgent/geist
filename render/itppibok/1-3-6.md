### 1\.3\.6 Running the Test

After you have defined the network to be simulated and created the message generation decks, you should run a sample test using a small configuration

and a simple deck\. This process is described in [Creating TPNS Message](<DOCNUM/SC31-6009/CCONTENTS>) [Generation Decks](<DOCNUM/SC31-6009/CCONTENTS>)\. Then, after successfully completing one or more sample tests, you will be ready to run the complete simulation\. ["Running the](8-0.md) [Test"](8-0.md) provides details about the planning considerations for running a

sample test and for operating TPNS\. Refer to [TPNS Operation](<DOCNUM/SC30-3289/CCONTENTS>) for detailed information about starting, monitoring, controlling, and stopping TPNS simulations\. Also refer to [TPNS Messages and Codes](<DOCNUM/SC30-3310/CCONTENTS>) for explanations of the messages and return codes you may encounter during TPNS operation\.
