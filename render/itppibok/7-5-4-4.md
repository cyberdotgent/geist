#### 7.5.4.4 Defining the Network

<BOOK> the syntax of TPNS statements, re [fer to "Preprocessing the TPNS S](8-2.md) cript." ITPSGEN uses the network definition statements to determine the terminal names for which decks are generated. These names, taken from the TERM, DEV, and LU statements in the network definitions, must correspond to the <BOOK> resource names used in the trace data set. For this reason, when you use ITPSGEN, be sure that your network definition statements do not contain duplicate names.
