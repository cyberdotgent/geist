### PREFACE\.2\.1 Terms Used in This Book

<a id="HDRTERMS"></a>

The following is a list of terms that are used frequently throughout this book\.

`Alert` A high\-priority event that warrants immediate attention\. This database record is generated for certain event types that are defined by user\-constructed filters\.

`ECB` Event control block\. A control block used to represent the status of an event\.

`Event` A record indicating irregularities of operation in physical elements of a network\.

`IBM LAN Network Manager` Refers to previous releases of LAN Manager, LAN Network Manager 1\.0, and LAN Network Manager 1\.1\.

`MVS` MVS/XA, MVS/ESA\.

`VM` VM/SP, VM/ESA\.

For more information about the terms and abbreviations used in this book, see the ["Glossary" in topic GLOSSARY](glossary.md)\.
