| 04 | INTV | Intervention required |
| 05 | CUST | Customer-application generated<br>Summary |
| 08 | IMR | Intensive mode recording |
| 09 | AVAL | Availability |
| 0A | NTFY | Notification |
| 0B | ENV | Environment |
| 0C | INST | Installation |
| 0D | PROC | Operation/procedure |
| 0E | SCUR | Security |
| 0F | DLRC | Delayed, then recovered |
| 10 | PAFF | Permanent affected |
| 11 | IMPD | Impending problem |
| 12 | UNKN | Unknown |
