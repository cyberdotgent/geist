## PREFACE\.2 How to Use This Book

<a id="HDRHOWTO"></a>

This book supplies online alerts and field descriptions for supported resources\. Use the ["Block ID Index" in topic 1\.1](1-1.md) to find the block ID of the product with which you have a problem\. Each block ID has a table listing its action codes, event types, and associated text for each code\. When an alert is received, it is in the format *XXXYY*, where *XXX* is the block ID and *YY* is the action code\. These tables are in [Chapter 2,](2-0.md) ["Resource Alerts" in topic 2\.0](2-0.md)\.

Use the event code tables in [Chapter 3, "Event Qualifiers" in topic 3\.0](3-0.md) with your external log record to gather the definitions for qualifier 1, qualifier 2, and qualifier 3 to assist in diagnosing your network resource problem\. The qualifiers are names of devices that pinpoint the origin of your problem\.
