## PREFACE\.1 Who Should Use This Book

System programmers who are familiar with network problem determination can use this book as a detailed reference for resource alerts\. They can also use this book to find information that has been logged in the database from a particular resource\. NetView program users can use this book to isolate a problem reported to NetView, classify the specific type of problem, and then accurately describe it, based upon the information found in NetView databases\.
