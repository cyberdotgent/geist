## 1\.1 Advantages of BookServer


```text
   FLOW P 3 3
   Compared to storage of documents as HTML and GIF files in a WWW library,
   BookServer offers many significant advantages:
   FLOW UL 3 3
       For the information provider:
   FLOW LI 3 7
   °   Much more content (up to 10 times more) can be stored on the same
       amount of server disk space.
   FLOW LI 3 7
   °   Each electronic book is a single readily portable and self-contained
       file, rather than a large number of separate HTML and GIF files.
   FLOW LI 3 7
   °   The same electronic book format can be distributed unchanged across
       media types (diskette, CD-ROM and WWW) and across operating systems
       (OS/2, Windows, AIX, DOS, MVS, VM, OS/400 and CICS).
   FLOW LI 3 7
   °   The wide variety of supported content input sources for BookManager:
       many popular word processors, SGML, and BookMaster.
   FLOW LI 3 7
   °   Remote access to BookManager libraries from WWW browsers across every
       platform.
   FLOW LI 3 7
   °   A single server can serve books, bookshelves and bookcases from its
       own or from multiple remote file systems.  The actual location is not
       part of the URL of a document and is transparent to readers.
       Therefore the server administrator can move files around, e.g., from
       mainframe to OS/2 or vice-versa, without affecting how readers access
       books.  (Note:  Appropriate remote file system support is needed for
       this, e.g.  Network File System, Andrew File System or LAN File
       Services/ESA.  These products are not included with BookServer.)
   FLOW LI 3 7
   °   Support for the rich set of BookManager document elements, including
       those not directly supported in HTML 2.0, such as complex tables.
   FLOW UL 3 3
       For the reader, improved function and usability:
   FLOW LI 3 7
   °   Fuzzy and morphological full-text searching across entire documents
       and bookshelves (not just of the currently loaded HTML file)
   FLOW LI 3 7
   °   Easier navigation within documents, via a automatically generated
       button bar with intuitive iconic buttons
   FLOW H2 3 3
```
