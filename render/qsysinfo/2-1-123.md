### 2.1.123 SC41-9875, TCP/IP Guide

0 Transmission Control Protocol/Internet Protocol Guide 0 TCP/IP Guide Publication Description: *TCP/IP* *Guide* provides information about how the AS/400 system carries out TCP/IP. This guide describes how to use and / configure TCP/IP and the TCP/IP applications of FTP, SMTP, and TELNET. It also provides information about the relationship of TCP/IP to other AS/400 communications protocols and the OfficeVision/400 licensed program. *375* *pp.* Related Publications: None Intended Audience: Application programmer, system programmer, end user Distribution Information: Included with program 5738-TC1, in binder 78; $27.50 for additional copies.
