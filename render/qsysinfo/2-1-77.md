### 2\.1\.77 SC41\-8189, Communications: Advanced Program\-to\-Program Communications

*Programmer's Guide*

*Publication Description*: *APPC Programmer's Guide* provides information about the APPC support provided by the AS/400 system\. It is a guide for developing application programs that use APPC and for defining the communications environment for APPC communications\. Included in this guide are application program considerations, configuration requirements and commands, problem management for APPC, and general networking considerations\. *325 pp\.*

*Related Publications*: *Communications: Intersystem Communications Function Programmer's Guide*, SC41\-9590; *Communications: Operating System/400\* Communications Configuration Reference*, SC41\-0001; *Systems Application Architecture\* Common Programming Interface Communications Reference*, SC26\-4399

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8006, in binder 18; $25\.00 for additional copies\.
