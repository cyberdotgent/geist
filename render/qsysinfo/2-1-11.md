### 2\.1\.11 LY44\-0597, Service: Diagnostic Aids \- Volume 1

*Publication Description*: This volume provides information about error logs, dumps, traces, and other service tools and procedures needed to determine, isolate, and solve programming problems occurring with the OS/400\* licensed program and vertical licensed internal code \(VLIC\), as well as other hardware and software failures\. It also provides information about problem management, resource and configuration management, and the initial program load \(IPL\) phases of the AS/400 system\. This manual should be used to help solve service problems that occur after normal problem analysis and resolution procedures fail\. *800 pp\.*

*Related Publications*: *Service: Diagnostic Aids \- Volume 2*, LY44\-0598

*Intended Audience*: Service representative, AS/400 users qualified to solve software problems

*Distribution Information*: Included with program 5738\-SS1, feature 8019, in binder 39; $359\.00 for additional copies\.
