### 2\.1\.45 SC09\-1416, Application Development Tools: Report Layout Utility User's

*Guide and Reference*

*Publication Description*: *RLU User's Guide and Reference* provides information on how to use the report layout utility \(RLU\)\. This manual includes information on developing and printing sample reports and generating data description specifications \(DDS\) source to create the report from a high\-level language\. *250 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer, system programmer

*Distribution Information*: Included with program 5738\-PW1, in binder 52; $22\.50 for additional copies\.
