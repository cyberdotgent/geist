### 2\.1\.129 SL23\-0187, OSI Communications Subsystem/400 Configuration and

*Administration Guide*

*Publication Description*: *OSI Communications Subsystem/400 Configuration and Administration Guide* tells how to gather information needed to identify the local node in the surrounding OSI environment, and communicate with the desired destination nodes, using relay nodes, if necessary\. It provides worksheets for gathering this information, and instructs users on how to enter the information interactively using the Administrative Facility menu, list, and prompt panels, or using CL configuration commands\. *500 pp\.*

*Related Publications*: *OSI Communications Subsystem/400 Operation*, SL23\-0189

*Intended Audience*: System programmer, network specialist, system administrator

*Distribution Information*: Included with program 5738\-OS1, in binder 81; $60\.00 for additional copies\.
