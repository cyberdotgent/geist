### 2.1.70 SC41-8083, Security Concepts and Planning

0 Security Concepts and Planning 0 Security Concepts and Planning Publication Description: *Security* *Concepts* *and* *Planning* provides information about system security concepts, planning for security, and setting up security on the system. This manual does not describe security for specific licensed programs, languages, and utilities. This manual tells how system security support can be used to protect the system and the data from being used by people who do not have the proper authorization, protect the data from intentional or unintentional damage or destruction, keep security information up-to-date, and set up security *on?* *the* system. 375 pp. Related Publications: None Intended Audience: Application programmer, system programmer Distribution Information: Included with program 5738-SS1, feature 8001, in binder 3; $35.00 for additional copies.
