### 2\.1\.22 SC09\-1160, Languages: System/36\-Compatible COBOL User's Guide and

*Reference* *Publication Description*: *System/36\-Compatible COBOL User's Guide and Reference* provides information about using COBOL in the System/36 environment on the AS/400 system\. It provides information on how to program in COBOL in the System/36 environment of the AS/400 system and how to use existing System/36 COBOL programs\.

The reference material in this manual is based on and supports the 1974 ANSI COBOL standard\. *600 pp\.*

*Related Publications*: *Languages: System/36\-Compatible COBOL Reference Summary*, SX09\-1047

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-CB1, feature 7021, in binder 63; $55\.00 for additional copies\.
