## APPENDIX1\.5\.2 Version 1 to Version 2 DBCS Information Cross Reference

The AS/400 library for Version 2 Release 1 \(V2R1\) is quite similar to that for Version 1 Release 3 \(V1R3\), with some important exceptions:

- The covers are different \(colors distinguish user environments\)
- Most of the order numbers were changed
- Some of the titles were changed
- Some manuals were replaced by new ones or consolidated into other existing ones
- Some totally new manuals were added to describe new system products or to support customer requirements
