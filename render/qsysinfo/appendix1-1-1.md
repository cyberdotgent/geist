### APPENDIX1\.1\.1 Manuals Significantly Reorganized in V2R1

The following manuals still exist for V2R1, but with considerable content added or moved to other manuals:

- *Attaching Cables* split into:

*AS/400\* 9402 Attaching Workstation and Communications Cables*, SA41\-0005 \(new\)

*9404 Attaching Workstation and Communications Cables*, SA41\-0004 \(new\)

*9406 Attaching Workstation and Communications Cables*, SA41\-9957

- *Communications and Systems Management User's Guide* redesigned and renamed; DHCF information moved to *Remote Work Station Guide*, SC41\-0002 \(new\)
- *CL Reference* now includes only OS/400 commands; reduced to 3 volumes
- *Data Management Guide* split into:

*Data Management Guide*, SC41\-9658

*Guide to Programming Displays*, SC41\-0011 \(new\)

*Guide to Programming for Printing*, SC41\-8194

*Guide to Programming for Tape and Diskette*, SC41\-0012 \(new\)

- *Diagnostic Aids* split into:

*Diagnostic Aids \- Volume 1*, LY44\-0597

*Diagnostic Aids \- Volume 2*, LY44\-0598 \(new\)

- *PC Support Common Tasks and Commands* split into:

*PC Support/400 DOS Common Tasks and Commands*, SX41\-9069

*PC Support/400 OS/2 Common Tasks and Commands*, SX41\-0001 \(new\)

- *PC Support Technical Reference for DOS and OS/2*: API information moved into *PC Support/400 API Reference*, SC41\-8254
