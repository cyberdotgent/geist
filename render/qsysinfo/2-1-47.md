### 2.1.47 SC24-5552, Programming:  Procedures Language 400/REXX Reference

0 Programming: Procedures Language 400/REXX Reference 0 Procedures Language (REXX) Reference Publication Description: *Procedures* *Language* *(REXX)* *Reference* provides information on writing programs for the AS/400 system using the Procedures Language 400/REXX programming language. This manual includes an overview of the Procedures Language 400/REXX concepts, information on using keyword instructions syntax, function syntax, numerics and arithmetic. Also included is information on understanding conditions and condition trapping, using input and output streams, testing, and double-byte character set (DBCS) support information. *200* *pp.* Related *Publications*: Programming: *Procedures* *Language* *400/REXX* *Programmer's* *Guide*, SC24-5553 Intended Audience: System programmer Distribution Information: Included with program 5738-SS1, feature 8016, in binder 36; $20.00 for additional copies.
