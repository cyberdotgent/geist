### 2\.1\.60 SC41\-0027, System Programmer's Communications Interface Guide

*Publication Description*: *System Programmer's Communications Interface Guide* provides information about the communications application program interface, which allows users to communicate with other systems using various protocols and architectures\. *250 pp\.*

*Related Publications*: *System Programmer's Interface Reference*, SC41\-8223

*Intended Audience*: Application programmer, system programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8012, in binder 30; $50\.00 for additional copies\.
