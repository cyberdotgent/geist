### 2.1.93 SC41-9594, Communications:  SNA Upline Facility Programmer's Guide

0 Communications: SNA Upline Facility Programmer's Guide 0 SNA Upline Facility Programmer's Guide Publication Description: The *SNA* *Upline* *Facility* *Programmer's* *Guide* programming information for using the OS/400 Systems Network Architecture (SNA) upline facility (SNUF) support with the AS/400 system. This guide describes how to use SNUF support, how to write application programs for SNUF support, and the return codes that SNUF support can send to a program. This guide is intended for AS/400 programmers who are writing communications programs that communicate with Customer Information Control System (CICS) or Information Management System/Virtual Storage (IMS/VS) on a remote system. It also contains programming considerations that both the remote programmer and the AS/400 programmer need when the systems are communicating. This guide provides information on developing SNUF communications application programs that use the OS/400 intersystem communications function (OS/400-ICF). This guide also provides information on the 3720 SNA programming interface. *150* *pp.* Related Publications: *Communications:* *Intersystem* *Communications* *Function* *Programmer's* *Guide*, SC41-9590 Intended Audience: Application programmer, system programmer Distribution Information: Included with program 5738-SS1, feature 8006, in binder 18; $22.50 for additional copies.
