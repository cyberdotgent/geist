- *Communications User's Guide* split into:

*Communications Management Guide*, SC41\-0024 \(new\)

*Local Area Network Guide*, SC41\-0004 \(new\)

*OS/400\* Communications Configuration Reference*, SC41\-0001 \(new\)

*Remote Work Station Guide*, SC41\-0002 \(new\)

*X\.25 Network Guide*, SC41\-0005 \(new\)

- *Keyboard Templates*: keyboard information included in *Using OfficeVision/400\**, SC41\-9616
- *Online Education Administering Guide*: incorporated into the *Operator's Guide*, SC41\-8082
- *Operational Assistant Administrator's Guide*: incorporated into the *Operator's Guide*, SC41\-8082
- *Operational Assistant User's Guide*: incorporated into the *New User's Guide*, SC41\-8211

- *PC Support Messages and Problem Analysis Guide for DOS and OS/2*: is now online information
- *PC Support Planning and Installation Guide for DOS* and *PC Support Operations Reference for DOS*: combined into the *PC Support/400 DOS Installation and Administration Guide*, SC41\-0006 \(new\)
- *PC Support Planning and Installation Guide for OS/2* and *PC Support Operations Reference for OS/2*: combined into the *PC Support/400 OS/2 Installation and Administration Guide*, SC41\-0007 \(new\)
- *Command Reference Summary*: incorporated into the *Programming Reference Summary*, SX41\-0028 \(new\)
- *Removable Storage User's Guide*: incorporated into the *Operator's Guide*, SC41\-8082
- *System Reference Summary*: incorporated into the *Programming Reference Summary*, SX41\-0028 \(new\)
- *System/36\-to\-AS/400 Information Cross\-Reference* and *System/38\-to\-AS/400 Information Cross\-Reference*: incorporated into the *Publications Guide*, SC41\-9678
- *System/38\-to\-AS/400 Commands Cross\-Reference*: discontinued
- *Uninterruptible Power Supply Planning Guide*: incorporated into the *Physical Planning Guide and Reference*, GA41\-9571
