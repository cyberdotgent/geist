### 2\.1\.146 SX41\-8209, Programming: System/36 Commands to AS/400\* Commands

*Cross\-Reference* *Publication Description*: This pocket\-sized booklet maps the System/36 OCL commands and statements to the functionally equivalent AS/400 CL commands\. Each AS/400 command name is followed by a description of the AS/400 function associated with that command\. An appendix lists the AS/400 command abbreviations as well as the spelled\-out names for those CL commands\. *75 pp\., 3 5/8" x 7 3/4" stapled*

*Related Publications*: *Programming: Control Language Reference*, SC41\-0030

*Intended Audience*: System/36 programmers, system operators

*Distribution Information*: Included with program 5738\-SS1, feature 7014; $7\.50 for additional copies\.
