### 2.1.153 S544-3698, Systems Application Architecture* Common Programming Interface PrintManager Reference

*PrintManager* *Reference* 0 Systems Application Architecture* Common Programming Interface PrintManager Reference 0 SAA* CPI PrintManager Reference Publication Description: The *SAA** *CPI* *PrintManager* *Reference* provides information the user needs to develop AS/400-based print applications that will place print options and data on the spool. These applications will be portable to other SAA environments with minimum modification. The print jobs produced by these applications can be printed in other SAA environments when the proper distributed-print components are present. *225* *pp.* Related Publications: None Intended Audience: Application programmer Distribution Information: Included with program 5738-SS1, feature 8012, in binder 31; $10.00 for additional copies.
