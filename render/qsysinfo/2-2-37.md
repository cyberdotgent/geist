### 2.2.37 GG22-9445, System/36 and System/38 to AS/400 Migration Planning Forms

This publication is a time-saving tool when assisting the AS/400 user with the steps to be considered when migrating from either the System/36 or System/38 to the AS/400 system. These forms should be used with the

System/36 Planning Guide, GC21-9623, the System/38 Planning Guide GC21-9624, the System/36 Migration Aid User's Guide and Reference / SC09-1166, and the System/38 User's Guide and Reference, SC09-1165. These forms should not be used as a substitute for the migration planning guides *or* these manuals. 75 *pp.*
