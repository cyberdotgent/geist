### 2.1.114 SC41-9759, System/38 Compatibility:  Text Management/38 User's Guide and Reference

Reference 0 System/38 Compatibility: Text Management/38 User's Guide and Reference 0 Text Management/38 User's Guide and Reference Publication Description: *Text* *Management/38* *User's* *Guide* *and* *Reference* provides all users with information about using the functions available with Text Management/38. These functions include printing documents, creating form documents, using Text Management/38 with the database, using print control commands, and using dictionary functions. The manual also describes each Text Management/38 display in detail. *350* *pp.* Related Publications: None Intended Audience: End user Distribution Information: Included with program 5738-DB1, in binder 73; $30.00 for additional copies.
