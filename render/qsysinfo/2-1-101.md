### 2\.1\.101 SC41\-9617, Systems Application Architecture\* OfficeVision/400\*: Learning

*about OfficeVision/400 Word Processing*

*Publication Description*: *Learning about OfficeVision/400\* Word Processing* provides information to help users learn how to use the word processing functions of OfficeVision/400\. This manual also contains examples of several documents that can be created using OfficeVision/400\. This manual does not cover all the word processing functions available, but provides examples that can be used for practice or as guides for actual office applications\. *275 pp\.*

*Related Publications*: *Systems Application Architecture\* OfficeVision/400\*: Using OfficeVision/400 Word Processing*, SC41\-9618; *Systems Application Architecture\* OfficeVision/400\*: OfficeVision/400 Common Tasks*, SX41\-9868

*Intended Audience*: All OfficeVision/400 users

*Distribution Information*: Included with program 5738\-WP1, in binder 48; $30\.00 for additional copies\.
