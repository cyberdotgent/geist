### 2.2.103 SC26-4359, Systems Application Architecture:  Common Programming Interface Presentation Reference

This manual provides the application programmer or system analyst with a description of the Systems Application Architecture Presentation Interface, which provides programmers and users with a comprehensive set of functions that allow information to be displayed or printed in the most effective manner. *500* *pp.*
