### 2.2.43 GG22-9483, Transaction Processing Performance Council Benchmark - a Full Disclosure Report AS/400

Selected AS/400 models were measured using the TPC Benchmark A Standard Specification. The TPC Benchmark A Standard Specification was developed by the Transaction Processing Performance Council (TPC) and released November 10, 1989. These measurements were audited by an independent auditor, Codd and Date, Inc. A Full Disclosure Report documenting details of the benchmark testing is to be produced and filed with the TPC Benchmark A Administrator according to the specification. This publication contains a copy of the AS/400 TPC Benchmark A Full Disclosure Report (Section I) and the Independent Auditor's Report (Section II).

*150* *pp.*
