### 2.1.24 SC09-1168, Communications:  Remote Job Entry User's Guide and Reference

0 Communications: Remote Job Entry User's Guide and Reference 0 RJE User's Guide and Reference Publication Description: *RJE* *User's* *Guide* *and* *Reference* provides information about using the Communications Utilities remote job entry (RJE) to submit jobs to an IBM host processor. This manual contains information for both the programmer who is using an RJE system and the user who is operating a remote job entry session through the functions of RJE. *200* *pp.* Related Publications: None Intended Audience: System operator, application programmer, programmer Distribution Information: Included with program 5738-CM1, in binder 76; $20.00 for additional copies.
