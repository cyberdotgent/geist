### 2.1.61 SC41-0030, Programming:  Control Language Reference

0 Programming: Control Language Reference 0 CL Reference Publication Description: The *CL* *Reference* provides a description of all the AS/400 control language (CL) and its OS/400 commands. It also provides an overview of *all* the CL commands for the AS/400 system, and it describes the syntax rules needed to code them. *2250* *pp.* Related Publications: *Programming:* *Reference* *Summary*, SX41-0028; *Programming:* *Control* *Language* *Programmer's* *Guide*, SC41-8077 Intended Audience: System programmer Distribution Information: Included with program 5738-SS1, feature 8011, in binders 24-26; $250.00 for additional copies.
