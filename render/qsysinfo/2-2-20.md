### 2.2.20 GC21-8183, Examples of Advanced Program-to Program Communications Between the Application System/400 and CICS

This manual contains two extended examples of advanced program-to-program communications (APPC) between the AS/400 system and a System/370 running customer information control system (CICS). The AS/400 programs are written in RPG/400, whereas the CICS programs are written in COBOL. The first example provides listings for an AS/400 source program communicating via APPC with a CICS target, along with supporting intersystem communications function (ICF) and display file listings. The second example shows listings for a CICS source program, an AS/400 target, and the supporting CICS map and AS/400 ICF file. The appendixes include listings of the AS/400 and System/370* configurations used to support the examples, a listing of a subprogram used to compare local and remote database retrieval times and a cross-reference table comparing APPC

operations to their CICS equivalents. *100* *pp.*
