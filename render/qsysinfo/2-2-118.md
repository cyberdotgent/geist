### 2\.2\.118 SV32\-0610, Getting Ready to Install AS/400

This videotape gives an overview of the AS/400 Release 1\.2 installation process\. It presents the tasks that must be performed along with some tips for installing the release without errors\. The tape is intended to make AS/400 customers familiar with the installation process and is designed for any AS/400 customer who has Release 1\.0 and plans to install Release 1\.2\.

**Note:** This videotape was created for use in the United States\. For technical reasons, it may not be possible to view it in other countries\. *1/2 inch, VHS, NTSC, 46 minutes\.*
