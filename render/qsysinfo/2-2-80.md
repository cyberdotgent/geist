### 2\.2\.80 G321\-5366, A New Development Rhythm for AS/400 Software

Synchronizing the software development process with hardware development and user involvement programs yielded a product offering that met the user requirements with a significantly reduced development cycle\. This paper emphasizes the key elements of the Application System/400 \(AS/400\) software development that contributed to synchronization and project success\. It is intended to produce an awareness of the elements that set this project apart from most others\. *From the IBM Systems Journal, Vol\. 28, No\. 3, 1 pp\.*
