### 2\.2\.28 GC26\-4675, Systems Application Architecture Common Programming Interface Summary

This manual provides information for managers and technical personnel on evaluating the Common Programming Interface \(CPI\) portion of IBM's Systems Application Architecture \(SAA\) standard, and do some high\-level planning for its implementation\. It shows the contents of each of the CPIs and the scope of the current implementation\. *100 pp\.*
