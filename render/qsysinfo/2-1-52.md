### 2.1.52 SC41-0003, Communications:  Integrated Services Digital Network Guide

0 Communications: Integrated Services Digital Network Guide 0 ISDN Guide Publication Description: The *ISDN* *Guide* provides information about configuring and using ISDN. A conceptual description of ISDN is given, as well as a description of the AS/400 implementation of ISDN. Also discussed are ISDN performance, network-specific parameters, and differences. Examples provide configuration references for ISDN network types. *75* *pp.* Related Publications: *Communications:* *Operating* *System/400** *Communications* *Configuration* *Reference*, SC41-0001 Intended Audience: System programmer, service personnel Distribution Information: Included with program 5738-SS1, feature 8005, in binder 16; $17.50 for additional copies.
