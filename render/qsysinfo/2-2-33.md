### 2\.2\.33 GG22\-9441, AS/400 Office: Application Programming Interface Presentation Guide

This guide provides information on some of the OfficeVision/400 capabilities and introduces the control language \(CL\) commands provided on the AS/400 system that relate to OfficeVision/400 functions\. Several application integration examples are provided\. *200 pp\.*
