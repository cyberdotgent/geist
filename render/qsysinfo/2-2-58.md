### 2\.2\.58 GG24\-3336, AS/400 \- S/370 Connectivity

This manual provides systems engineers with information about the connectivity options when the AS/400 system is connected to a System/370 host system\. The manual also provides information relative to migrating from a System/36 or System/38 to the AS/400 system in a System/370 environment\. *250 pp\.*
