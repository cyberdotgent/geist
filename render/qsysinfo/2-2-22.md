### 2\.2\.22 GC21\-8246, PC Support/400 Router API Programming Example

This manual describes cooperative processing in a PS/2 environment using the PC Support/400 router application programming interface \(API\), which provides connectivity between the programmable work station program and the AS/400 program\. *50 pp\.*
