### 2\.2\.95 SC09\-1286, Systems Application Architecture: Common Programming Interface RPG Reference

This manual provides the application programmer or system analyst with a description of Systems Application Architecture RPG\. The manual describes the RPG interface that can be moved across the System/370, the AS/400 system, and IBM personal computer environments\. *400 pp\.*
