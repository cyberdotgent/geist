### 2.2.65 GG24-3446, AS/400 PC Support/400 OS/2 Extended Edition Version 1.2

This manual describes how to plan and install the AS/400 PC Support/400 licensed program on a personal computer using Operating System/2 (OS/2) Extended Edition Version 1.2. This manual does not cover the OS/2 program in detail and you should have some knowledge of the OS/2 program before

using this manual. *350* *pp.*
