### 2.1.115 SC41-9844, Languages:  Systems Application Architecture* FORTRAN/400* Reference

Reference 0 Languages: Systems Application Architecture* FORTRAN/400* Reference 0 FORTRAN/400* Reference Publication Description: *FORTRAN/400** *Reference* provides information on using the FORTRAN/400 programming language. This manual includes information on FORTRAN characters, names, lines, statements, and execution sequences. Also included are data types and constants, variables, arrays, character substrings, expressions, control statements, program units and procedures. This manual also includes information on input/output statements, formatting, and compiler directives. *175* *pp.* Related Publications: *Languages:* *Systems* *Application* *Architecture** *FORTRAN/400** *User's* *Guide*, SC41-9845 Intended Audience: Application programmer Distribution Information: Included with program 5738-FT1, in binder 70; $20.00 for additional copies.
