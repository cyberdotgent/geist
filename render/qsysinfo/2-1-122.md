### 2.1.122 SC41-9868, Point-of-Sale Communications Utility/400 Programmer's Guide

0 Point-of-Sale Communications Utility/400 Programmer's Guide 0 Point-of-Sale Communications Utility/400 Programmer's Guide Publication Description: *Point-of-Sale* *Communications* *Utility/400* *Programmer's* *Guide* provides information needed to use the AS/400 retail communications in an Advanced Data Communication for Stores (ADCS) environment. This guide describes how to enable the AS/400 host system or in-store processor to communicate with retail controllers. This guide is for use with the *Communications:* *Retail* *Communications* *Programmer's* *Guide*, SC41-9858, which describes retail communications support on which the point-of-sale applications are built. *125* *pp.* Related Publications: *Communications:* *Retail* *Communications* *Programmer's* *Guide*, SC41-9858; *Communications:* *Intersystem* *Communications* *Function* *Programmer's* *Guide*, SC41-9590 Intended Audience: Application programmer, system operator Distribution Information: Included with program 5738-CF1, in binder 77; $15.00 for additional copies.
