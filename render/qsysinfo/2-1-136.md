### 2\.1\.136 SL23\-0202, OSI Communications Subsystem C Language Examples

*Publication Description*: *OSI Communications Subsystem C Language Examples* provides examples to help the user in understanding a C language OSI communications subsystem application, use of syncrhonization points, quarantining to control the processing of transactions, token passing, and use of presentation layer services\. *225 pp\.*

*Related Publications*: *OSI Communications Subsystem Programming Reference* SL23\-0190; *OSI Communications Subsystem Programming Concepts and Guide* SL23\-0191; *OSI Communications Subsystem Abstract Syntax Checker Reference*, SL23\-0192; *OSI Communications Subsystem Programming with the Starter Set*, SL23\-0193

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-OS1, in binder 83; $22\.50 for additional copies\.
