### 2.2.24 GC21-9805, System Overview, Installation and Planning Guide

This guide provides information processing managers, managers of information systems, application developers, and others involved in making decisions about integrating the features of AS/400 telephony support with data processing applications an overview of telephony support. This guide also contains a description of the components of telephony support, a discussion of the uses of telephony support, information on the planning needed for hardware installation, and the procedures used to install the hardware. *75* *pp.*
