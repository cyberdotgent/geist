### 2.2.99 SC26-4355, Systems Application Architecture:  Common Programming Interface Application Generator Reference

This manual provides the application programmer or system analyst with a description of Systems Application Architecture Application Generator, which is an application development tool that can provide support across systems. Its two-part organization, an application development (AD) portion and an application processing (AP) portion, allows an application to be built on one system and to be easily run on another (where the AE functions are installed). *375* *pp.*
