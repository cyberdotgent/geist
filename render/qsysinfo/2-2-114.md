### 2\.2\.114 SV32\-0606, Database Concepts

This videotape provides the programmer with information about the basic parts of the AS/400 database management system\. This includes a definition of the AS/400 database, and information about data integrity, recovery, auditability, data independence, security, associations, and ways to access the data\. The instructor in the videotape uses comparisons between database and file management systems to explain the concepts\. *1/2 inch, VHS, NTSC, 57 minutes\.*
