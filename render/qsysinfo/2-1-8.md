### 2\.1\.8 GC41\-9802, System Concepts

*Publication Description*: *System Concepts* provides a general understanding of the concepts related to the overall design and use of the AS/400 system and its operating system\. This manual includes general information about AS/400 features such as user interface, object management, work management, system management, data management, database, communications, environments, and architecture\. *225 pp\., selfbound*

*Related Publications*: *System Introduction*, GC41\-9766; *Master Index*, SC41\-8204

*Intended Audience*: Application programmer, system programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8002, in binder 6; $25\.00 for additional copies\.
