### 2.1.62 SC41-0036, Basic Backup and Recovery Guide

0 Basic Backup and Recovery Guide 0 Basic Backup and Recovery Guide Publication Description: The *Basic* *Backup* *and* *Recovery* *Guide* contains a subset of the information found in the *Backup* *and* *Recovery* *Guide*, SC41-8079. The manual contains information about planning a backup and recovery strategy, the different types of media available to save and restore system data, save and restore procedures, and disk recovery procedures. It also describes how to install the system again from backup. *375* *pp.* Related Publications: *Backup* *and* *Recovery* *Guide*, SC41-8079 Intended Audience: System programmer, system operator Distribution Information: Included with program 5738-SS1, in binder 2; $30.00 for additional copies.
