### 2\.2\.49 GG24\-3253, AS/400 Communications Migration

This manual provides planning information for anyone who is responsible for installing an AS/400 system in a peer communication environment\. The manual explains migration concepts and support, and the migration of applications and configurations\. The manual also provides tips and hints, and listings of configurations, procedures, programs, and data description specifications \(DDS\)\. *225 pp\.*
