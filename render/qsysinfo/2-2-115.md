### 2\.2\.115 SV32\-0607, AS/400 Architecture

This videotape provides the programmer with information about the advanced architecture of the AS/400 system\. This includes information about the high\-level machine, single\-level storage, object orientation, and capability\-based addressing\. The instructor in the videotape uses comparisons between traditional system architectures and the AS/400 system to explain the concepts\. *1/2 inch, VHS, NTSC, 54 minutes\.*
