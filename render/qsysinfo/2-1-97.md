### 2.1.97 SC41-9609, Systems Application Architecture* Structured Query Language/400 Programmer's Guide

*Programmer's* *Guide* 0 Systems Application Architecture* Structured Query Language/400 Programmer's Guide 0 SQL/400* Programmer's Guide Publication Description: The *SQL/400** *Programmer's* *Guide* provides an overview of how to design, write, run, and test SQL/400 statements. It also describes interactive Structured Query Language (SQL). The manual provides examples of how to write SQL statements in COBOL, RPG, C, FORTRAN and PL/I programs. *300* *pp.* Related Publications: *Systems* *Application* *Architecture** *Structured* *Query* *Language/400* *Reference*, SC41-9608 Intended Audience: Application programmer, system programmer, database administrator Distribution Information: Included with program 5738-ST1, in binder 71; $27.50 for additional copies.
