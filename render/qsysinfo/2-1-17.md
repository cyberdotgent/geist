### 2\.1\.17 SA41\-9944, Twinaxial Workstation Controller Port Tester User's Guide

*Publication Description*: *Twinaxial Workstation Controller Port Tester User's Guide* provides information about using the IBM workstation controller port tester to help isolate cabling and port problems on AS/400 systems\. *25 pp\.*

*Related Publications*: None

*Intended Audience*: System operator, service personnel

*Distribution Information*: Shipped with the 9402, 9404, and 9406 system units\. $12\.50 for additional copies\.
