### 2.2.41 GG22-9465, AS/400 Inform Series:  AS/400 Data Security Concepts

This text is intended to help company, functional, and data processing managers who need guidance in developing a program to improve information or data security within their organizations. It discusses some protective measures to reduce the risks associated with hazards to which computer installations may be subjected during day-to-day operations. It is intended as a reminder of some of the factors that should be considered

when planning or designing a security system. *100* *pp.*
