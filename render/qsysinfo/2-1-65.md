### 2.1.65 SC41-8077, Programming:  Control Language Programmer's Guide

0 Programming: Control Language Programmer's Guide 0 CL Programmer's Guide Publication Description: The *CL* *Programmer's* *Guide* provides a wide-ranging discussion of AS/400 programming topics, including a general discussion of objects and libraries, CL programming, controlling flow and communicating between programs, working with objects in CL programs, and creating CL programs. Other topics include predefined and impromptu messages and message handling, defining and creating user-defined commands and menus, application testing, including debug mode, breakpoints, traces, *and* display functions. *375* pp. Related *Publications*: Programming: *Control* *Language* *Reference*, SC41-0030; *Programming:* *Reference* *Summary*, SX41-0028 Intended Audience: Application programmer, system programmer Distribution Information: Included with program 5738-SS1, feature 8002, in binder 7; $40.00 for additional copies.
