### 2.2.39 GG22-9454, AS/400 Distributed Systems Implementation Guide, Volume 2

This manual outlines a number of planning considerations important to be aware of when implementing a network of AS/400 systems in a System/370 host-controlled and centrally managed environment. It is intended for the project manager and lead network implementer responsible for installing a network of AS/400 systems. Knowledge of basic AS/400 system operations and facilities is necessary. Topics included are a discussion of the phases of an implementation plan, project management considerations, an overview of communications and systems management (C & SM) on the AS/400 system and corresponding host network management tools, replication hints and tips and host System/370 and AS/400 system sample definitions.

*150* *pp.*
