### 2\.1\.87 SC41\-8226, Machine Interface Functional Reference

*Publication Description*: The *MI Functional Reference* describes the machine interface instruction set\. It describes the functions that can be performed by each instruction and also the necessary information to code each instruction\. *728 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer, program support representative

*Distribution Information*: Included with program 5738\-SS1, feature 8013, in binder 32; $250\.00 for additional copies\.
