### 2\.1\.49 SC26\-4399, Systems Application Architecture\* Common Programming Interface

*Communications Reference*

*Publication Description*: The *SAA\* CPI Communications Reference* provides information about writing applications that adhere to the Systems Application Architecture \(SAA\) Communications interface\. The manual defines the elements of the SAA Communications Common Programming Interface \(CPI\), which provides a programming interface that allows program\-to\-program communications using IBM's Systems Network Architecture \(SNA\) logical unit 6\.2 \(LU6\.2\)\. *300 pp\.*

*Related Publications*: *Communications: Advanced Program\-to\-Program Communications Programmer's Guide*, SC41\-8189

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8006, in binder 18; $12\.50 for additional copies\.
