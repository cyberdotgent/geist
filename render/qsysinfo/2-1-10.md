### 2.1.10 GC41-9877, National Language Support Planning Guide

0 National Language Support Planning Guide 0 National Language Support Planning Guide Publication Description: *National* *Language* *Support* *Planning* *Guide* provides information required to understand and use the national language support function on the AS/400 system. This manual prepares the AS/400 user for planning and using the national language support (NLS) and the multilingual support of the AS/400 system. It also provides an explanation of the database management of multilingual data and application considerations for a multilingual system. *150* *pp.,* *selfbound* Related Publications: *System* *Introduction*, GC41-9766; *System* *Concepts*, GC41-9802 Intended Audience: Data processing manager, system programmer, application programmer Distribution Information: Included with program 5738-SS1, feature 8002, in binder 6; $15.00 for additional copies.
