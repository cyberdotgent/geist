### 2\.1\.106 SC41\-9657, Utilities: Interactive Data Definition Utility User's Guide

*Publication Description*: *IDDU User's Guide* describes how to use AS/400 interactive data definition utility \(IDDU\) to describe data dictionaries, files, and records to the system\. It includes:

- An introduction to computer file and data definition concepts
- An introduction to the use of IDDU to describe the data used in queries and documents
- Representative tasks related to creating, maintaining, and using data dictionaries, files, record formats, and fields
- Advanced information about using IDDU to work with files created on other systems and information about error recovery and problem prevention\.

*150 pp\.*

*Related Publications*: None

*Intended Audience*: Administrative secretary, business professional, application programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8009, in binder 21; $17\.50 for additional copies\.
