### 2\.1\.9 GC41\-9861, Network Planning Guide

*Publication Description*: *Network Planning Guide* provides information about planning for a communications network\. It is intended to assist the user in identifying which communications application programs may be of use in the creation of a communications network\. This guide also provides an overview of network planning tasks and directs the user to other manuals for specific information\. *175 pp\., selfbound*

*Related Publications*: *Physical Planning Guide and Reference*, GA41\-9571; *New Products Planning Information for Version 2 Release 1*, GA41\-0007

*Intended Audience*: System programmer, data processing manager

*Distribution Information*: Available from marketing representative; $10\.00 for additional copies\.
