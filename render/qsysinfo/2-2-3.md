### 2\.2\.3 GA19\-5486, AS/400 Systems Handbook

This manual is an introduction to the AS/400 system and a memory aid\. It contains a concise description of all aspects of the AS/400 system including system concepts and architecture, hardware components, operating system, and associated licensed programs\. *100 pp\.*
