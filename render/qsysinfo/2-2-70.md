### 2\.2\.70 GG24\-3465, OfficeVision/400 Implementation and Performance

This manual is for the experienced OfficeVision/400 user and administrator who is responsible for installing and maintaining the OfficeVision/400 environment on the AS/400 system\. This manual includes information on the Release 2\.0 functions for nonprogrammable work stations\. It then discusses how to install and customize OfficeVision/2 and OfficeVision/400 to exchange mail\. Finally, it provides some tips on performance measurements and systems management\. *150 pp\.*
