### 2\.1\.99 SC41\-9615, Systems Application Architecture\* OfficeVision/400\*: Learning

*about OfficeVision/400*

*Related Publications*: *Systems Application Architecture\* OfficeVision/400\*: Using OfficeVision/400*, SC41\-9616; *Systems Application Architecture\* OfficeVision/400\*: OfficeVision/400 Common Tasks*, SX41\-9868
