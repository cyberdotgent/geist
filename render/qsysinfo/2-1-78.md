### 2.1.78 SC41-8192, Programming:  Query Management/400 Programmer's Guide

0 Programming: Query Management/400 Programmer's Guide 0 Query Management/400 Programmer's Guide Publication Description: *Query* *Management/400* *Programmer's* *Guide* provides information on how to determine the database files to be queried for a report, define a structured query language (SQL) query definition, define a report form definition, and use and write procedures that use query management commands. This manual also includes information on how to use the query management global variable support and understand the relationship between the OS/400 query management and the Query/400 licensed program. *200* *pp.* Related *Publications*: Programming: *Query* *Management/400* *Reference*, SC41-8193 Intended Audience: Application programmer Distribution Information: Included with program 5738-SS1, feature 8009, in binder 21; $22.50 for additional copies.
