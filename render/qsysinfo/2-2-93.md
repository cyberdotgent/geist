### 2\.2\.93 SC09\-1166, System/36 to AS/400 Migration Aid User's Guide and Reference

This manual provides the system operator, application programmer, system programmer, and data processing manager with information about using the System/36 to AS/400 Migration Aid to move System/36 items to the AS/400 system using menus and displays or commands\. This manual describes moving System/36 items to tape, diskette, file or the migration data link, and restoring these items to the AS/400 system\. It provides reference information for items requiring modification before use on the AS/400 system\. *850 pp\.*
