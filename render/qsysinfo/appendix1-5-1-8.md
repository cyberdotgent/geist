### APPENDIX1\.5\.1\.8 SC18\-0133, Advanced Function Printing Simplified Chinese Font Catalog

*Publication Description*: *Advanced Function Printing Simplified Chinese Font Catalog* provides information on the font pattern and code for the Simplified Chinese font licensed program \(5730\-FN1\)\. The font can be used for the printers with advanced function printing \(AFP\)\. *130 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer, system programmer, system administrator
