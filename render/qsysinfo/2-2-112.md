### 2.2.112 SV32-0604, System Operations for the System/36 Operator

This videotape provides the System/36 operator with a basic operational overview of the AS/400 system and the OS/400 operating system. It also helps familiarize the System/36 operator with the computer, and shows how

to get more detailed sources of information on the AS/400 system. *1/2* *inch,* *VHS,* *NTSC,* *37* *minutes.*
