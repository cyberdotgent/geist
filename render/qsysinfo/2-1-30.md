### 2.1.30 SC09-1294, Programming:  Extended Program Model User's Guide and Reference

0 Programming: Extended Program Model User's Guide and Reference 0 Extended Program Model User's Guide and Reference Publication Description: *Extended* *Program* *Model* *User's* *Guide* *and* *Reference* provides information about the extended program model (EPM). The EPM works with the OS/400 program to provide some additional functions. These functions include a common run-time environment, debugging tools, application library routines, an exception handler, and a session manager. *150* *pp.* Related Publications: *Languages:* *Systems* *Application* *Architecture**
