### 2\.2\.92 SC09\-1165, System/38 to AS/400 Migration Aid User's Guide and Reference

This publication provides the system operator, application programmer, system programmer, and data processing manager with information about using the System/38 to AS/400 Migration Aid to move System/38 objects to the AS/400 system using menus and displays or commands\. This publication contains three parts\. Part 1 describes how to move System/38 objects to tape, diskette, save files, or the migration data link\. Part 2 describes how to restore these objects to the AS/400 system\. Part 3 provides reference information for those objects that require modification to be used on the AS/400 system\. *500 pp\.*
