### 2.1.66 SC41-8078, Programming:  Work Management Guide

0 Programming: Work Management Guide 0 Work Management Guide Publication Description: *Work* *Management* *Guide* provides information about how to create and change a work management environment. Other topics include a description of tuning the system, collecting performance data including information on record formats and contents of the data being collected, working with system values to control or change the overall operation of the system, and a description of how to gather data to determine who is using the system and what resources are being used. *375* *pp.* Related Publications: None Intended Audience: Application programmer, system programmer Distribution Information: Included with program 5738-SS1, feature 8001, in binder 3; $40.00 for additional copies.
