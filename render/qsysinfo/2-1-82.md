### 2\.1\.82 SC41\-8200, PC Support/400 User's Guide for OS/2

*Publication Description*: *PC Support/400 User's Guide for OS/2* provides concepts and examples of how to use the PC Support/400 functions\. It assumes that the PC Support/400 product is already installed and set up\. This manual is intended for users of personal computers using the OS/2 operating system\. *225 pp\.*

*Related Publications*: *PC Support/400: OS/2 Common Tasks and Commands*, SX41\-0001

*Intended Audience*: PC Support user

*Distribution Information*: Included with program 5738\-PC1, feature 7025, in binder 44; $20\.00 for additional copies\.
