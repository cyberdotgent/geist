### 2\.1\.148 SX41\-9069, PC Support/400 DOS Common Tasks and Commands

*Publication Description*: *PC Support/400 DOS Common Tasks and Commands* provides an overview of PC Support/400 and summarizes the PC Support/400 commands\. This reference card is intended for users of personal computers using the DOS operating system\. *25 pp\., 3 5/8" x 7 3/4" stapled*

*Related Publications*: *PC Support/400: DOS User's Guide*, SC41\-8199

*Intended Audience*: All PC Support users

*Distribution Information*: Included with program 5738\-PC1; $2\.50 for additional copies\.
