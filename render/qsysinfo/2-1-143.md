### 2\.1\.143 SX09\-1217, Languages: Systems Application Architecture\* C/400\* Reference

*Summary*

*Publication Description*: *C/400\* Reference Summary* provides a summary of information on the related control language \(CL\) commands, and on C language elements\. It also provides the function prototypes for all functions that comprise the C/400 and extended program model library\. *50 pp\., 5 1/2" x 8 1/2" wire bound*

*Related Publications*: *Systems Application Architecture\* Common Programming Interface C Reference \- Level 2*, SC09\-1308; *Programming: Extended Program Model User's Guide and Reference*, SC09\-1294

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-CX1; $5\.00 for additional copies\.
