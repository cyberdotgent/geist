### APPENDIX1\.5\.1\.5 SBO9\-1421, Advanced Function Printing Korean Font Catalog

*Publication Description*: The *Advanced Function Printing Korean Font Catalog* provides information about the font pattern and code for the Korean font licensed program \(5730\-FN1\)\. The font can be used for the printers with advanced function printing \(AFP\)\. *168 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer, system programmer, system administrator
