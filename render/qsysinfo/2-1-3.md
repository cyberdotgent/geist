### 2.1.3 GA41-9571, Physical Planning Guide and Reference

0 Physical Planning Guide and Reference 0 Physical Planning Guide and Reference Publication Description: *Physical* *Planning* *Guide* *and* *Reference* provides information for planning to set up the AS/400 system. It also includes information on cable considerations, physical specifications, electronic customer support, and unpacking considerations. Using this information, planning for the AS/400 hardware can begin before the system arrives. This manual also describes how to identify which communications feature type has been ordered, how to order telephone lines from a common carrier, order modems from a modem supplier, and how to gather communications configuration information. *275* *pp.,* *selfbound* Related Publications: *Network* *Planning* *Guide*, GC41-9861; *Physical* / *Planning* *Guide*, GA41-0001; *New* *Products* *Planning* *Information* *for* *Version* *2* *Release* *1*, GA41-0007 Intended Audience: Data processing manager, system administrator, installation planning representative Distribution Information: Available from marketing representative; $10.00 for additional copies.
