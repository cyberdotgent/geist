### 2\.1\.113 SC41\-9758, Office Services Concepts and Programmer's Guide

*Publication Description*: *Office Services Concepts and Programmer's Guide* provides information about writing applications that use OfficeVision/400 functions\. This manual also includes an overview of directory services, document distribution services, document library services, document and folder save and restore and storage management, security services, word processing services, and information on finding new ways to integrate your applications with OfficeVision/400\. *550 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8012, in binder 30; $100\.00 for additional copies\.
