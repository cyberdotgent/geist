### 2.1.98 SC41-9614, Query/400 User's Guide

0 Query/400 User's Guide 0 Query/400 User's Guide Publication Description: The *Query/400* *User's* *Guide* describes how to use AS/400 Query to get data from any database file. It describes how to sign on to Query, and how to define and run queries to create reports containing the selected data. This manual describes all the tasks for defining the query of one or more files, the way the report is to look when the query is run, and whether the report is to be displayed, printed, or put in a database file. *250* *pp.* Related Publications: None Intended Audience: Administrative secretary, business professional, application programmer Distribution Information: Included with program 5738-QU1, in binder 46; $25.00 for additional copies.
