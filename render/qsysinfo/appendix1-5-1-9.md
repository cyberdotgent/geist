### APPENDIX1\.5\.1\.9 SC18\-0137, Advanced Function Printing Thai Font Catalog

*Publication Description*: The *Advanced Function Printing Thai Font Catalog* provides information on the font pattern and code for the Thai font licensed program \(5730\-FN1\)\. The font can be used for the printers with advanced function printing \(AFP\)\. *48 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer, system programmer, system administrator
