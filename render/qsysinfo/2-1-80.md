### 2\.1\.80 SC41\-8194, Guide to Programming for Printing

*Publication Description*: *Guide to Programming for Printing* provides information to help you understand and control printing\. It provides specific information on printing elements and concepts of the AS/400 system, printer file and print spooling support for printing operations, and printer connectivity\.

This manual also includes considerations for using personal computers, other printing functions such as Business Graphics Utility \(BGU\), advanced function printing \(AFP\), and examples of working with the AS/400 system printing elements such as how to move spooled output files from one output queue to a different output queue\. It also includes an appendix of control language \(CL\) commands used to manage printing workload\. *400 pp\.*

*Related Publications*: *Data Management Guide*, SC41\-9658

*Intended Audience*: Application or system programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8003, in binder 9; $35\.00 for additional copies\.
