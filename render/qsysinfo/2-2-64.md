### 2\.2\.64 GG24\-3442, AS/400 TCP/IP Configuration and Operation

This manual describes the Transmission Control Protocol/Internet Protocol for the OS/400 licensed program\. It is intended for customers who need to configure and use the licensed program without having special AS/400 TCP/IP skills\. This manual also provides additional considerations for those who want to get to know the licensed program in more detail\. This manual is for those who are familiar with the basic operation of the AS/400 system\. *250 pp\.*
