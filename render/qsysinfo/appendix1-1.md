## APPENDIX1.1 Appendix A.  Version 1 to Version 2 Information Cross-Reference

<a id="HDRAPPA"></a>

The AS/400 library for Version 2 Release 1 (V2R1) is quite similar to that for Version 1 Release 3 (V1R3), with some important exceptions: The covers are different (colors distinguish user environments) Most of the order numbers were changed Some of the titles were changed Some manuals were replaced by new ones or consolidated into other existing ones Some totally new manuals were added to describe new system products or to support customer requirements

The Library Structure Poster, G325-6009, shows graphically which manuals are included in the respective user environments (the environments are described in [Part 1](#HDRINTO)). [Table 1 in topic APPENDIX1.1.4](#TBLSTAT) shows the new V2R1 order numbers and any revised titles for each V1R3 manual; it also indicates whether the manual was updated for V2R1. The V1R3 manuals are listed in alphabetic order by short title. [Appendix E](appendix1-5.md) describes changes to the DBCS part of the AS/400 library. The following sections describe reorganized, replaced, and new manuals.
