### 2\.1\.86 SC41\-8223, System Programmer's Interface Reference

*Publication Description*: The *System Programmer's Interface Reference* provides information on how to create, use, and delete objects that help manage system performance, use spooling efficiently, and maintain database files efficiently\. This manual also includes information on creating and maintaining the programs for system objects and retrieving OS/400 information by working with objects, database files, jobs and spooling\. *450 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer, system programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8012, in binder 29; $325\.00 for additional copies\.
