### 2\.1\.76 SC41\-8188, Communications: Advanced Peer\-to\-Peer Networking Guide

*Publication Description*: *APPN Guide* provides information about the advanced peer\-to\-peer networking \(APPN\) support provided by the AS/400 system\. It describes the APPN concepts, functions, and features as carried out on the AS/400 system\. It contains information for configuring an APPN network and also presents considerations when using APPN\. *400 pp\.*

*Related Publications*: *Communications: Advanced Program\-to\-Program Communications Programmer's Guide*, SC41\-8189; *Communications: Operating System/400\* Communications Configuration Reference*, SC41\-0001

*Intended Audience*: System programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8005, in binder 15; $40\.00 for additional copies\.
