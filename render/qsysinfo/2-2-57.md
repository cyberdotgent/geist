### 2.2.57 GG24-3321, Structured Query Language/400:  a Guide for Implementation, OS/400

This manual provides experienced programmers, analysts, and those responsible for creating and maintaining application programs on the AS/400 system information on implementation considerations for SQL/400. Subjects include high-level language (HLL) integration, performance, recovery, and portability. *275* *pp.*
