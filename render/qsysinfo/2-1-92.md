### 2\.1\.92 SC41\-9593, Communications: BSC Equivalence Link Programmer's Guide

*Publication Description*: The *BSC Equivalence Link Programmer's Guide* provides the information needed to write programs that use binary synchronous communications equivalence link \(BSCEL\) to communicate with a remote system\. It also contains information about other systems and devices that communicate with BSCEL on the AS/400 system\. This guide describes how to set up BSCEL and how to run application programs that use BSCEL\.

This guide provides information on developing BSCEL communications application programs that use the OS/400 intersystem communications function \(OS/400\-ICF\)\. *175 pp\.*

*Related Publications*: *Communications: Intersystem Communications Function Programmer's Guide*, SC41\-9590

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8006, in binder 18; $25\.00 for additional copies\.
