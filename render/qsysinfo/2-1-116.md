### 2\.1\.116 SC41\-9845, Languages: Systems Application Architecture\* FORTRAN/400\*

*User's Guide*

*Publication Description*: *FORTRAN/400\* User's Guide* provides information about entering and coding a FORTRAN/400 program, compiling a source program, performing input/output operations, running and debugging the program, and using interprogram communication in the FORTRAN environment\. *250 pp\.*

*Related Publications*: *Languages: Systems Application Architecture\* FORTRAN/400\* Reference*, SC41\-9844; *Programming: Extended Program Model User's Guide and Reference*, SC09\-1294

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-FT1, in binder 70; $25\.00 for additional copies\.
