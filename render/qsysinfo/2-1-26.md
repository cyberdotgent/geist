### 2\.1\.26 SC09\-1209, Languages: Pascal User's Guide

*Publication Description*: *Pascal User's Guide* provides information about how to use the AS/400 Pascal compiler\. The manual explains how to enter, compile, run, and debug AS/400 Pascal programs\. It also describes how to use input and output \(I/O\) function and storage\. *250 pp\.*

*Related Publications*: *Languages: Pascal Reference*, SC09\-1210; *Programming: Extended Program Model User's Guide and Reference*, SC09\-1294

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-PS1, in binder 69; $25\.00 for additional copies\.
