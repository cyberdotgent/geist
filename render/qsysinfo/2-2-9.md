### 2\.2\.9 GA34\-2084, 3816 PagePrinter Programming Reference for AS/400, System/36, and System/38 Attachments


```text
   This publication describes how to use the 3816 PagePrinter when attached
   to an AS/400 system, System/36, or System/38.  It is intended for
   operators, application programmers, system administrators, or anyone using
   a 3816 PagePrinter attached to an AS/400 system, System/36 or System/38.
   75 pp.
```
