### 2\.1\.119 SC41\-9864, Communications: Intrasystem Communications Programmer's Guide

*Publication Description*: *Intrasystem Communications Programmer's Guide* provides information about interactive communications between two application programs on the same AS/400 system\. This guide describes the communications operations that can be coded into a program that uses intrasystem communications support to communicate with another program\. It also provides information on developing intrasystem communications application programs that use the OS/400 intersystem communications function \(OS/400\-ICF\)\. *150 pp\.*

*Related Publications*: *Communications: Intersystem Communications Function Programmer's Guide*, SC41\-9590

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8006, in binder 17; $17\.50 for additional copies\.
