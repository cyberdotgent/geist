### 2\.2\.119 SV32\-0611, Application System/400: Database Design

This videotape provides information on database design for the AS/400 system as a relational database management system\. The approach used is normalization as defined in relational database theory\. *1/2 inch, VHS, NTSC, 46 minutes\.*
