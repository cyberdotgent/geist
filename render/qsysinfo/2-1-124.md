### 2\.1\.124 SC41\-9878, Licensed Programs and New Release Installation Guide

*Publication Description*: *Licensed Programs and New Release Installation Guide* provides step\-by\-step procedures for initial install, installing licensed programs, program temporary fixes \(PTFs\), and secondary languages from IBM\.

This manual is also for users who already have an AS/400 system with an installed release and want to install a new release\. *200 pp\.*

*Related Publications*: *System Operator's Guide*, SC41\-8082; *Backup and Recovery Guide*, SC41\-8079; *Automatic Installation Guide*, SX41\-9072

*Intended Audience*: System operator, system administrator

*Distribution Information*: Included with program 5738\-SS1, in binder 2; $20\.00 for additional copies\.
