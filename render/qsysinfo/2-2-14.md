### 2\.2\.14 GC21\-8172, AS/400 Usability Newsletter: Tips Techniques and Overview of System Topics

This newsletter provides the systems engineer or end user with information about the AS/400 system\. It is a collection of articles ranging from system help, system operations to customer support, migration, and several others\. These articles provide an overview, insight and helpful hints on using the AS/400 system\. *125 pp\.*
