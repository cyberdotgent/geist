<a id="HDRWHO"></a>

#### User Tasks

(General environment) Planning: Making decisions about the options the hardware or programs offer. (System and application support environment) Installation: Preparing the system to do useful work such as installing hardware and programs. (System and application support environment) Administering Data Resources: Managing (designing, defining, allocating, protecting, monitoring) data resources, including databases, data files, data relationships, data declarations, and data definitions. (System and application support environment) Administering Network Resources: Managing (designing, defining, allocating, protecting, monitoring) network resources, including terminals, lines, and control units. (System and application support environment) Administering System Resources: Managing (designing, defining, allocating, protecting, monitoring) system resources, including programs,

processor cycles, and input/output paths. (System and application support environment) Operating: Starting and stopping the system, checking and controlling programs, and recording system status. (System use environment; also sometimes system and application support environment) Customizing: Enhancing or extending the system to further benefit the user. (System and application support environment) Application Programming: Designing, coding, compiling, running, debugging, and testing programs. (Application development environment) Diagnosing: Identifying the source of a system problem, describing the problem, reporting a new problem, and correcting the problem. (Hardware and software service environment) End Use: Using the system and its programs to achieve its purpose. (System use environment)
