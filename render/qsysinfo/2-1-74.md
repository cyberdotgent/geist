### 2.1.74 SC41-8099, Communications:  Finance Communications Programmer's Guide

0 Communications: Finance Communications Programmer's Guide 0 Finance Communications Programmer's Guide Publication Description: *Finance* *Communications* *Programmer's* *Guide* describes how finance support communicates with a controller and how to set up finance support. It provides information for writing application programs to communicate with application programs on the finance controller. This guide also includes coding examples to refer to when developing application programs including new commands and functions, as well as intersystem communications function (ICF) finance support. It provides information on developing finance communications application programs that use the OS/400 intersystem communications function (OS/400-ICF). *200* *pp.* Related Publications: *Communications:* *Intersystem* *Communications* *Function* *Programmer's* *Guide*, SC41-9590 Intended Audience: Application programmer, system operator, system administrator Distribution Information: Included with program 5738-SS1, feature 8008, in binder 20; $25.00 for additional copies.
