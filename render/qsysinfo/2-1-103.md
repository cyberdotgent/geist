### 2\.1\.103 SC41\-9620, Data Description Specifications Reference

*Publication Description*: The *DDS Reference* provides detailed descriptions of the entries and keywords needed to describe database files \(both logical and physical\) and certain device files \(for displays, printers, and intersystem communications function \(ICF\)\) external to the user's programs\. *675 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8003, in binder 11; $65\.00 for additional copies\.
