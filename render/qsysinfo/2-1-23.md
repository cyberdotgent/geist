### 2.1.23 SC09-1162, Languages:  System/36-Compatible RPG II User's Guide and Reference

Reference 0 Languages: System/36-Compatible RPG II User's Guide and Reference / 0 System/36-Compatible RPG II User's Guide and Reference Publication Description: *System/36-Compatible* *RPG* *II* *User's* *Guide* *and* *Reference* provides information about the RPG II language on the AS/400 system. This manual explains how to design, code, enter, compile, test, and run RPG II programs. The manual includes the RPG program cycle, the valid entries for each column of each RPG specification form and the differences between the way RPG II programs run on System/36 and the way they run on the AS/400 system. In addition, differences between compiling in the System/36 environment and the AS/400 environment are identified at the compiler level only. *975* *pp.* Related Publications: *Languages:* *RPG* *Reference* *Summary*, SX09-1164 Intended Audience: Application programmer Distribution Information: Included with program 5738-RG1, feature 7030, in binder 60; $85.00 for additional copies.
