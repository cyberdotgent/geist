### 2.1.111 SC41-9663, Programming:  Concepts and Programmer's Guide for the System/36 Environment

*Environment*) 0 Concepts and Programmer's Guide for the System/36 Environment ___ 0 Programming: Concepts and Programmer's Guide for the System/36 Environment Publication Description: *Concepts* *and* *Programmer's* *Guide* *for* *the* *System/36* *Environment* provides information identifying the differences in the applications process in the System/36 environment on the AS/400 system. It helps the user understand the functional and operational differences (from a System/36 perspective) when processing in the System/36 environment on the AS/400 system. This includes an environment functional overview, considerations for migration, programming, communications, security, and coexistence. *400* *pp.*

Related Publications: *Programming:* *System* *Reference* *for* *the* *System/36* *Environment*, SC41-9662 Intended Audience: Application programmer, system programmer Distribution Information: Included with program 5738-SS1, feature 7014, in binder 33; $55.00 for additional copies.
