### 2.1.95 SC41-9602, Communications:  3270 Device Emulation Guide

0 Communications: 3270 Device Emulation Guide 0 3270 Device Emulation Guide Publication Description: The *3270* *Device* *Emulation* *Guide* provides 3270 device emulation information for users of OS/400 binary synchronous communications (BSC) and Systems Network Architecture (SNA). Device emulation is available for both display stations and printers. This guide provides information about using 3270 device emulation, configuring the system for 3270 device emulation and setting up 3270 printer emulation, and creating system device configuration on the host system. *200* *pp.* Related Publications: *Communications:* *Operating* *System/400** *Communications* *Configuration* *Reference*, SC41-0001 Intended Audience: Display station operator, system programmer Distribution Information: Included with program 5738-SS1, feature 7004, in binder 13; $22.50 for additional copies.
