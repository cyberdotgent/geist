### 2\.2\.102 SC26\-4358, Systems Application Architecture: Common Programming Interface Procedures Language Reference

This manual provides the application programmer or system analyst with a description of the Systems Application Architecture Procedures Language, which allows users to write programs in a clear, organized way\. This manual describes the Procedures Language interface that can be moved across the System/370, the AS/400 system, and the IBM personal computer environments\. *200 pp\.*
