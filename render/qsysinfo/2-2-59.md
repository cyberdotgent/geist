### 2\.2\.59 GG24\-3420, AS/400, System/38, and Personal System/2 As T\.21 Nodes in a Subarea Network


```text
   This manual provides information on the implementation of advanced
   peer-to-peer networking (APPN) in a network consisting of an AS/400
   system, System/38, Personal System/2*, and System/370 Systems Network
   Architecture (SNA) subarea network.  This manual also includes some of the
   considerations which need to be made when a switched line, leased line, or
   token-ring connection is used in this type of network.  375 pp.
```
