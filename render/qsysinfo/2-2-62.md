### 2.2.62 GG24-3438, Writing SAA Applications for AS/400

This publication describes design and programming techniques that can be used to implement SAA applications on the AS/400 system today. As SAA application goals vary between organizations, both SAA and non-SAA programming practices are discussed as well as the merits of using each. This publication illustrates programming methods that can be used to conform to the SAA Common User Access (CUA). It is intended for business partners, customers, and systems engineering representatives who need to know how to develop or advise others how to develop SAA applications on the AS/400 system. The purpose of this publication is to assist with the development of SAA applications, as this is a new area for many. A knowledge of either RPG/400 or COBOL/400*, as well as CL programming and

DDS definition is assumed. *325* *pp.*
