### APPENDIX1.5.1.6 SC09-1170, Application Development Tools:  Character Generator Utility User's Guide

Publication Description: *CGU* *User's* *Guide* provides information about using the application development tools character generator utility (CGU) to create and maintain a double-byte character set (DBCS) on the AS/400 system. It also provides step-by-step examples that show how to use some *of* *the* CGU functions. 88 pp. Related Publications: None Intended Audience: Application programmer, system programmer
