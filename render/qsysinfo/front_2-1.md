## FRONT_2.1 How This Guide Is Arranged

This guide is divided as follows:

Part 1, Introduction to AS/400 Information Sources: Includes an overview of the typical user environments, tasks, and roles on which the design of the AS/400 library is based; a summary of the different types of information that are available; and information on how to access the various types. Part 2, Publication Descriptions: Provides descriptions of all the publications available to you in the AS/400 library. It also describes other information about the AS/400 system published by IBM (such as newsletters, technical reports, and videotapes). Publication descriptions include such information as intended audience, tasks covered, and size (pages and dimensions). Part 3, Appendixes: Provides cross-reference information between the Version 2 Release 1 AS/400 library and the publications in the Version 1 AS/400, System/36, and System/38 libraries. Another appendix describes how the library is distributed and how to order additional publications. Information on DBCS publications (descriptions and cross-reference from Version 1) is presented in a separate appendix. Glossary: Includes definitions of the AS/400 products and functions described by the publications. Index: Includes entries for order numbers and titles as well as for topics and tasks.
