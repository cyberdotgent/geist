### 2.1.64 SC41-0537, Programming:  GDDM Programming Reference

0 Programming: GDDM Programming Reference 0 GDDM Programming Reference Publication Description: *GDDM* *Programming* *Reference* provides information about using OS/400 graphical data display manager (GDDM) to write graphics application programs. This manual provides detailed descriptions of all graphics routines available in GDDM. It also provides information about high-level language interfaces to GDDM. *375* *pp.* Related Publications: *Programming:* *GDDM* *Programming* *Guide*, SC41-0536 Intended Audience: Application programmer Distribution Information: Included with program 5738-SS1, feature 8017, in binder 37; $35.00 for additional copies.
