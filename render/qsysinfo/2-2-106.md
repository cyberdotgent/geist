### 2\.2\.106 SC26\-4582, Systems Application Architecture: Common User Access Advanced Interface Design Guide

This manual is for software designers and developers of Operating System/2\* \(OS/2\*\) applications\. The manual describes user interface principles, techniques, and components that apply to a variety of software applications\. In addition to describing what the components look like and how they work, the manual provides guidelines on when to use them and what benefit they provide users\. *200 pp\.*
