### 2\.2\.104 SC26\-4362, Systems Application Architecture: Writing Applications: A Design Guide

This manual provides the application programmer or system analyst with guidance on developing application programs that are consistent and portable across the Systems Application Architecture environments\. These applications will use the common programming interfaces and the common user access specification\. *200 pp\.*
