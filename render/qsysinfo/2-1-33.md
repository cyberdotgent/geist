### 2.1.33 SC09-1339, Application Development Tools:  Programming Development Manager User's Guide and Reference

*User's* *Guide* *and* *Reference* 0 Application Development Tools: Programming Development Manager User's Guide and Reference 0 PDM User's Guide and Reference Publication Description: *PDM* *User's* *Guide* *and* *Reference* provides information about using the Application Development Tools programming development manager (PDM) to work with lists of libraries, objects, members, and user-defined options to easily do such operations as copy, delete, and rename. This manual contains activities and reference material to help the user learn PDM. The most commonly used operations and function keys are explained in detail using examples. *250* *pp.* Related Publications: None Intended Audience: Application programmer, system programmer Distribution Information: Included with program 5738-PW1, in binder 51; $22.50 for additional copies.
