### 2.1.117 SC41-9852, Application Development By Example

0 Application Development by Example 0 Application Development by Example Publication Description: *Application* *Development* *by* *Example* provides information needed to understand the relationships of some of the various programmer tools and utilities on the AS/400 system that can be used to produce an application. It presents a hypothetical mailing list application that illustrates how to design and run applications on the AS/400 system. *325* *pp.* Related Publications: *New* *User's* *Guide*, SC41-8211; *System* *Introduction*, GC41-9766, *System* *Concepts*, GC41-9802 Intended Audience: Application programmer Distribution Information: Included with program 5738-SS1, feature 8003, in binder 8; $30.00 for additional copies.
