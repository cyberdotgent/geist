### 2.1.81 SC41-8199, PC Support/400:  DOS User's Guide

0 PC Support/400: DOS User's Guide 0 PC Support/400 User's Guide for DOS Publication Description: *PC* *Support/400* *User's* *Guide* *for* *DOS* provides concepts and examples of how to use the PC Support/400 functions. It assumes that the PC Support/400 product is already installed and set up. This manual is intended for users of personal computers using the DOS operating system. *300* *pp.** Related Publications: *PC* *Support/400:* *DOS* *Common* *Tasks* *and* *Commands*, SX41-9069 Intended Audience: PC Support user Distribution Information: Included with program 5738-PC1, in binder 43; $20.00 for additional copies.
