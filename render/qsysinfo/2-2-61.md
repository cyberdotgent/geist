### 2\.2\.61 GG24\-3434, AS/400 C Language Introduction

This manual provides information on the C/400 licensed program \(5728\-CX1\)\. It also has introductory planning information for those considering using the C compiler on the AS/400 system\. It also helps evaluate the use of C/400 and run time environment\. A basic knowledge of C and the AS/400 system is helpful to understand and read this publication\. *150 pp\.*
