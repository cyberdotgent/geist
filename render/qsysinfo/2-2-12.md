### 2\.2\.12 GC21\-8163, Programming: Defining Compatible Displays Using Data Description Specifications

This manual provides the application programmer responsible for designing and programming applications for the end user with information on how to create an application user interface that closely resembles the user interface on the AS/400 system\. This manual contains information about the format of the basic display types in the AS/400 user interface, describes the standard user interactions with each display type, and shows how the basic display types can be described using data description specifications \(DDS\)\. *100 pp\.*
