#### 1.2.4.2 Additional IBM Online Education

IBM produces other education courses, known as Discover/Education for the (    AS/400 system, which you can order separately.  These courses cover many           of the same topics as Tutorial System Support, but at a more advanced         level.  The additional IBM courses are intended for the same types of ?    AS/400 users as Tutorial System Support.

**Note:** For some of these courses, you need a personal computer with PC Support/400 using shared folders on the AS/400 system.
