### 2\.2\.44 GG22\-9491, Starting with OfficeVision/400\* User's Guide

This manual is an implementation aid that provides an abbreviated set of instructions for enrolling users into OfficeVision/400 quickly\. It also provides a set of simplified study guide exercises to introduce the new user to OfficeVision/400\. *250 pp\.*
