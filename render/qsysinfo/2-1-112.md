### 2.1.112 SC41-9755, Programming:  System/38 Environment Programmer's Guide and Reference

Reference 0 Programming: System/38 Environment Programmer's Guide and Reference 0 System/38 Environment Programmer's Guide/Reference Publication Description: *System/38* *Environment* *Programmer's* *Guide/Reference* provides the information needed to migrate from a System/38, convert to an AS/400 system, and coexist in a network. It contains migration and conversion to AS/400 system overview information, a detailed list of changes for migration, and descriptions of coexistence with an AS/400 system in a network. Also included is information on maintenance of System/38 applications on an AS/400 system and a command list. *225* *pp.* Related Publications: None Intended Audience: Application programmer, system programmer Distribution Information: Included with program 5738-SS1, feature 7015, in binder 35; $30.00 for additional copies.
