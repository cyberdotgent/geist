### 2\.1\.90 SC41\-9590, Communications: Intersystem Communications Function

*Programmer's Guide*

*Publication Description*: This guide provides information needed to write application programs that use AS/400 communications and the OS/400 intersystem communications function \(OS/400\-ICF\)\. This guide also contains information on data description specifications \(DDS\) keywords, system\-supplied formats, return codes, file transfer support, and program examples\. *425 pp\.*

*Related Publications*:

- *Communications: Asynchronous Communications Programmer's Guide*, SC41\-9592
- *Communications: BSC Equivalence Link Programmer's Guide*, SC41\-9593
- *Communications: SNA Upline Facility Programmer's Guide*, SC41\-9594
- *Communications: Retail Communications Programmer's Guide*, SC41\-9858
- *Communications: Intrasystem Communications Programmer's Guide*, SC41\-9864
- *Communications: Advanced Program\-to\-Program Communications Programmer's Guide*, SC41\-8189
- *Communications: Finance Communications Programmer's Guide*, SC41\-8099

*Intended Audience*: Application programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8006, in binder 17; $55\.00 for additional copies\.
