### 2.1.108 SC41-9659, Database Guide

0 Database Guide 0 Database Guide Publication Description: The *Database* *Guide* provides a detailed discussion of the AS/400 database organization, including information on how to create, describe, and update database files on the system. This manual also describes how to define files to the system using OS/400 data description specifications (DDS) keywords. *250* *pp.* Related Publications: None Intended Audience: Application programmer, system programmer Distribution Information: Included with program 5738-SS1, feature 8003, in binder 9; $27.50 for additional copies.
