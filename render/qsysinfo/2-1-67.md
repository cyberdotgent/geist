### 2.1.67 SC41-8079, Backup and Recovery Guide

0 Backup and Recovery Guide 0 Backup and Recovery Guide Publication Description: *Backup* *and* *Recovery* *Guide* provides information about planning a backup and recovery strategy, the different types of media available to save and restore system data, as well as a description of how to record changes made to database files using journaling and how that information can be used for system recovery. This manual describes how to plan for and set up user auxiliary storage pools (ASPs), mirrored protection, and checksums along with other availability recovery topics. It also describes how to install the system again from backup. *825* *pp.* Related Publications: None Intended Audience: System programmer, application programmer Distribution Information: Included with program 5738-SS1, feature 8001, in binder 4; $50.00 for additional copies.
