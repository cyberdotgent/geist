### 2.1.134 SL23-0193, OSI Communications Subsystem Programming with the Starter Set

0 OSI Communications Subsystem Programming with the Starter Set Publication Description: *OSI* *Communications* *Subsystem* *Programming* *with* *the* *Starter* *Set* helps the user develop application programs that use a subset of the callable services provided by the OSI communications subsystem programming interface. It contains information about this subset, called the starter set. The starter set consists only of documentation; there is no separately identifiable subsystem component. *175* *pp.* Related Publications: *OSI* *Communications* *Subsystem* *Programming* *Reference* SL23-0190; *OSI* *Communications* *Subsystem* *Programming* *Concepts* *and* *Guide*, SL23-0191; *OSI* *Communications* *Subsystem* *Abstract* *Syntax* *Checker* *Reference* SL23-0192; *OSI* *Communications* *Subsystem* *COBOL* *Language* *Examples* SL23-0201; *OSI* *Communications* *Subsystem* *C* *Language* *Examples*, SL23-0202 Intended Audience: Application programmer Distribution Information: Included with program 5738-OS1, in binder 83; $12.50 for additional copies.
