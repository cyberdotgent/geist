### 2\.1\.89 SC41\-9588, Communications: Distribution Services Network Guide

*Publication Description*: The *Distribution Services Network Guide* provides information about configuring a network for Systems Network Architecture distribution services \(SNADS\) and the Virtual Machine/Multiple Virtual Storage \(VM/MVS\) bridge\. In addition, object distribution functions, document library services, and system distribution directory services are discussed\. *250 pp\.*

*Related Publications*: *Systems Application Architecture\* OfficeVision/400\*: Planning For and Setting Up OfficeVision/400* SC41\-9626; *Systems Application Architecture\* OfficeVision/400\*: Managing OfficeVision/400*, SC41\-9627; *Communications: Remote Job Entry Installation Guide*, SC09\-1201

*Intended Audience*: System operator, system administrator

*Distribution Information*: Included with program 5738\-SS1, feature 8005, in binder 15; $30\.00 for additional copies\.
