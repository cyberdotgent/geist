### 2\.1\.51 SC41\-0002, Communications: Remote Work Station Guide

*Publication Description*: The *Remote Work Station Guide* provides information on how to set up and use remote work station support, such as display station pass\-through, distributed host command facility, and 3270 remote attachment\. *150 pp\.*

*Related Publications*: *Communications: Operating System/400\* Communications Configuration Reference*, SC41\-0001

*Intended Audience*: System operator, application programmer, system programmer, service personnel

*Distribution Information*: Included with program 5738\-SS1, feature 7004, in binder 13; $15\.00 for additional copies\.
