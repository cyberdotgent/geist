### APPENDIX1\.5\.1\.15 SC41\-2414, PC Support/400: DOS User's Guide \(PS/55\)

*Publication Description*: *PC Support/400 User's Guide for DOS* provides concepts and examples of how to use the PC Support functions with DOS\. It assumes that the PC Support/400 product is already installed and set up\. This manual is intended for users with PS/55 \(double\-byte character set\) personal computers using the DOS operating system\. *200 pp\.*

*Related Publications*: *PC Support/400: DOS Common Tasks and Commands \(PS/55\)*, SX41\-0005

*Intended Audience*: Personal computer operator, administrative secretary
