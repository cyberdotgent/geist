### 2.1.25 SC09-1201, Communications:  Remote Job Entry Installation Guide

0 Communications: Remote Job Entry Installation Guide 0 RJE Installation Guide Publication Description: *RJE* *Installation* *Guide* provides information about using the Communications Utilities remote job entry (RJE) to extend the functions of a large host system to remote locations through the use of data communications. RJE enables the AS/400 system to submit jobs to an IBM host processor. This manual explains the activities necessary to install, define, and operate RJE. *225* *pp.* Related Publications: *Communications:* *Distribution* *Services* *Network* *Guide*, SC41-9588 Intended Audience: System operator Distribution Information: Included with program 5738-CM1, in binder 76; $25.00 for additional copies.
