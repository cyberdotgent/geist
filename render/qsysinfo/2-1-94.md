### 2\.1\.94 SC41\-9600, Distributed Data Management Guide

*Publication Description*: The *DDM Guide* provides information about remote file processing\. It describes how to define a remote file to OS/400 distributed data management \(DDM\), how to create a DDM file, what file utilities are supported through DDM, and the requirements of OS/400 DDM as related to other systems\. *200 pp\.*

*Related Publications*: None

*Intended Audience*: Application programmer, system programmer

*Distribution Information*: Included with program 5738\-SS1, feature 8009, in binder 22; $25\.00 for additional copies\.
