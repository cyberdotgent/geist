### 2.2.107 SC26-4583, Systems Application Architecture:  Common User Access

This manual provides designers and developers of software applications that run in the Systems Application Architecture (SAA) operating environments of the System/370 and the AS/400 system with a description of the SAA Common User Access (CUA) basic interface for software applications developed to run on nonprogrammable work stations in the previously mentioned operating environments. This manual also describes user interface principles, techniques, and components that apply to a variety of applications. In addition to describing what the components look like and how they work, this manual provides guidelines on when to use them and what benefit they provide users. *300* *pp.*
