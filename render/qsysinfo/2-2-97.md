### 2.2.97 SC26-4348, Systems Application Architecture:  Common Programming Interface Database Reference

This manual provides the application programmer or system analyst with a description of Systems Application Architecture Database Interface, which allows the user to access a database through Structured Query Language (SQL). It describes how to define, retrieve, and manipulate information in a relational database. *200* *pp.*
