### APPENDIX1\.5\.1\.19 SX41\-0007, PC Support/400: OS/2 Common Tasks and Commands \(PS/55\)

*Publication Description*: *PC Support/400 OS/2 Common Tasks and Commands \(PS/55\)* provides an overview of PC Support and summarizes the PC Support/400 commands\. This reference card is intended for users with PS/55 \(double\-byte character set\) personal computers using the OS/2 operating system\. *18 pp\., 3 5/8" X 7 1/4"\., folded\.*

*Related Publications*: *PC Support/400: OS/2 Common Tasks and Commands* SX41\-0001; *PC Support/400: OS/2 User's Guide \(PS/55\)*, SC41\-2415

*Intended Audience*: All PC Support users
