### 2\.1\.2 GA41\-0007, New Products Planning Information for Version 2 Release 1

*Publication Description*: *New Products Planning Information for Version 2 Release 1* provides information to be used in planning for how new products being added to the system will affect current applications and installations\. *175 pp\., selfbound*

*Related Publications*: *Physical Planning Guide and Reference*, GA41\-9571; *Network Planning Guide*, GC41\-9861

*Intended Audience*: System programmers, application programmers, data processing manager

*Distribution Information*: Available from marketing representative; $8\.00 for additional copies\.
