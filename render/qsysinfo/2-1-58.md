### 2.1.58 SC41-0012, Guide to Programming for Tape and Diskette

0 Guide to Programming for Tape and Diskette 0 Guide to Programming for Tape and Diskette Publication Description: *Guide* *to* *Programming* *for* *Tape* *and* *Diskette* provides information to help users develop and support programs that use tape and diskette drives for I/O. It includes information on device files and descriptions for tape and diskette devices, as well as spooling for diskette devices. *50* *pp.* Related Publications: *Data* *Management* *Guide*, SC41-9658 Intended Audience: Application programmer Distribution Information: Included with program 5738-SS1, feature 8003, in binder 8; $10.00 for additional copies.
