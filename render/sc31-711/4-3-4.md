### 4\.3\.4 6611 Redirected Traps

<a id="MSG"></a>

This section lists the traps that are generated by the SNMP agent residing in the IBM 6611 Network Processor and then resent by the bridge application\. These traps are defined under the 1\.3\.6\.1\.4\.1\.2\.6\.21\.5\.1 enterprise ID, which is associated with LNM for AIX\. The traps are listed according to specific trap number and are sent to AIX NetView/6000\.

<a id="MSG 1"></a>

- **1** — **Description:** Link Alarm **LNM** **for** **AIX** **Response:** Forward to AIX NetView/6000 with resource name\.

<a id="MSG 2"></a>

- **2** — **Description:** Test incorrectly requested at DSU/CSU **LNM** **for** **AIX** **Response:** Forward to AIX NetView/6000 with resource name\.

<a id="MSG 3"></a>

- **3** — **Description:** Loss of signal **LNM** **for** **AIX** **Response:** Forward to AIX NetView/6000 with resource name\.

<a id="MSG 4"></a>

- **4** — **Description:** Out of frame error **LNM** **for** **AIX** **Response:** Forward to AIX NetView/6000 with resource name\.

<a id="MSG 5"></a>

<a id="MSG 6"></a>

<a id="MSG 7"></a>
