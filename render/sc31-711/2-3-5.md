### 2\.3\.5 Hub Manager Integration Problems

<a id="HDRHUBPRB"></a>

If you experience problems integrating Hub Manager with LNM for AIX follow the general problem determination suggestions in ["Gathering Problem](2-1.md) [Information" in topic 2\.1](2-1.md)\. Next, check the following sources of information:

\_\_ Ensure that you have defined Hub Manager as an application to be started on the SMIT Applications to be Started When LNM for AIX Starts menu\.

\_\_ Verify that AIX NetView/6000 has discovered the hub\.

\_\_ Ensure that lnmhubint is running using the **lnmstatus** command\.

\_\_ Ensure that iubd is running using the **ovstatus** command\.

\_\_ If Hub Manager is running when you started LNM for AIX, ensure that you have selected **Start Coupling with LNM for AIX** from the Hub Manager SMIT Control menu\.

\_\_ nettl log \(see ["Checking the nettl Log" in topic 2\.1\.2](2-1-2.md)\) and trapd log\.

\_\_ Execute lnmstatus to determine the state of the hub manager application\. Refer to the man page for lnmstatus for a description of the exit statuses provided by lnmstatus\.

\_\_ Save formatted nettl logs\.

\_\_ Save the core image or output from the dbx command\.

\_\_ Execute `ps -ef | grep lnm` to ensure that the following conditions exist:

- lnmhubint is running and is a child of the lnmd process\.
- lnmd is running\. The Hub Manager integration fails if lnmd is not running\.
- lnmtopod is running\. The Hub Manager integration fails if lnmtopod is not running\.
- LNM for AIX processes are not direct children of the init process\.
