### 4\.1\.2 LNM OS/2 Agent Application\-Generated Traps

<a id="MSG"></a>

This section lists the traps that can be sent by the LNM OS/2 agent application and suggested actions\.

The traps in this section are defined under the 1\.2\.3\.1\.4\.1\.2\.6\.21\.1\.2 enterprise ID, which is associated with LNM for AIX\.

<a id="MSG bridgeHistoryDataComplete"></a>

- **bridgeHistoryDataComplete** — **Description:** A time period for collecting bridge history data has expired\. This trap is issued only if history data is being collected\. **Action:** None

<a id="MSG segHistoryDataComplete"></a>

- **segHistoryDataComplete** — **Description:** A time period for collecting segment history data has expired\. This trap is issued only if history data is being collected\. **Action:** None

<a id="MSG LNMOS2AgentSocketError"></a>

- **LNMOS2AgentSocketError** — **Description:** The socket connection between LNM for AIX and the LNM OS/2 agent has failed\. **Action:** The socket connection between LNM for AIX and the LNM OS/2 agent has failed\. Check the nettl log for any socket\-related messages logged by LNM for AIX\. Also verify the state of the LNM OS/2 agent\. You may need to do one or more of the following: Restart the machine that is running the LNM OS/2 agent\. Restart the LNM OS/2 agent\. Stop and restart LNM for AIX\.

<a id="MSG LNMOS2AgentSocketClosed"></a>

- **LNMOS2AgentSocketClosed** — **Description:** The socket connection between LNM for AIX and the LNM OS/2 agent is closed\. **Action:** The socket connection between LNM for AIX and the LNM OS/2 agent has closed unexpectedly\. Verify the state of the LNM OS/2 agent\. You may need to either restart the machine that is running the LNM OS/2 agent or restart the LNM OS/2 agent\.

<a id="MSG LNMOS2AgentNotResponding"></a>

- **LNMOS2AgentNotResponding** — **Description:** The LNM OS/2 agent is not responding to requests for information from LNM for AIX\. **Action:** The LNM OS/2 agent is no longer able to respond to run command requests\. Verify the state of the LNM OS/2 agent\. You may need to either restart the machine that is running the LNM OS/2 agent or restart the LNM OS/2 agent\.
