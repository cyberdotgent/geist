## 1\.1 LNM for AIX Files

<a id="HDRFILES"></a>

<pre>
   When the installation process is complete, the LNM for AIX product files
   are installed in the following directories:
   Directory                Type of Files
   /usr/ebt/lnm             Online DynaText** books
   /usr/lpp/lnm             Root directory of the LNM for AIX product
                            subtree.  It contains README and product ID
                            files, as well as the following subdirectories.
   /usr/lpp/lnm/app-defaults
                            Application default X resource definitions
   /usr/lpp/lnm/backgrounds Device-specific background maps
   /usr/lpp/lnm/bin         Executable files
   /usr/lpp/lnm/bitmaps/C   LNM for AIX icons
   /usr/lpp/lnm/conf        Configuration files
   /usr/lpp/lnm/databases   Databases or data flat files
   /usr/lpp/lnm/help        Help text
   /usr/lpp/lnm/fields      LNM for AIX fields
   /usr/lpp/lnm/filters     Filter strings
   /usr/lpp/lnm/gifs        GIF files
   /usr/lpp/lnm/man         Manual page entries
   /usr/lpp/lnm/nls         Message catalogs
   /usr/lpp/lnm/registration
                            Registration files
   /usr/lpp/lnm/reports     Files related to report generation, including
                            history files
   /usr/lpp/lnm/sockets     Sockets for interprocess communication
   /usr/lpp/lnm/symbols/C   Symbol files
</pre>
