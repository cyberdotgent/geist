### 4\.3\.2 SNMP Bridge Application\-Generated Traps

<a id="MSG"></a>

This section lists the traps that are generated by the bridge application\. These traps are defined under the 1\.3\.6\.1\.4\.1\.2\.6\.21\.3\.2 enterprise ID, which is associated with LNM for AIX\. The traps are listed according to specific trap number\.

<a id="MSG 256 (snmp_br_dot1dStpPortState)"></a>

- **256** **\(snmp\_br\_dot1dStpPortState\)** — **Description:** Indicates that there is a change in the value of dotldStpPortState\. **LNM** **for** **AIX** **Response:** Set new status\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 257 (snmp_br_dot1dStpPortEnable)"></a>

- **257** **\(snmp\_br\_dot1dStpPortEnable\)** — **Description:** Indicates that there is a change in the value of dotldStpPortEnable\. **LNM** **for** **AIX** **Response:** Set new status\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 258 (snmp_br_ifStatus)"></a>

- **258** **\(snmp\_br\_ifStatus\)** — **Description:** Indicates that there is a change in the value of ifOperStatus, ifAdminStatus, or both\. **LNM** **for** **AIX** **Response:** Set new status\. Forward to AIX NetView/6000 with resource name\.
