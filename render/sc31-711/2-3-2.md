### 2\.3\.2 SNMP Token\-Ring Application Problems

<a id="HDRSTRPRB"></a>

If you experience problems that seem to be associated with the SNMP Token\-Ring application, follow the general problem determination suggestions in ["Gathering Problem Information" in topic 2\.1](2-1.md)\. Next, check the following sources of information:

\_\_ nettl log \(see ["Checking the nettl Log" in topic 2\.1\.2](2-1-2.md)\) and trapd log

\_\_ Execute lnmstatus to determine the state of the SNMP Token\-Ring monitor program\. Refer to the man page for lnmstatus for a description of the exit statuses provided by lnmstatus\.

\_\_ Save formatted nettl logs and the trapd\.log\.

\_\_ Save the core image or output from the dbx command\.

\_\_ Execute `ps -ef | grep lnm` to ensure that the following conditions exist:

- lnmtrmon is running and is a child of the lnmd process\.
- lnmtrmgr is running\. Attempting to bring up a window will restart lnmtrmgr\.
- lnmd is running\. The SNMP Token\-Ring application fails if lnmd is not running\.
- lnmtopod is running\. The SNMP Token\-Ring application fails if lnmtopod is not running\.
- LNM for AIX processes are not direct children of the init process\.

\_\_ If the problem is repeatable, tracing files are extremely useful\. You can start tracing on the lnmtrmon daemon\.

Start tracing on lnmtrmon to log the command flow between LNM for AIX and the SNMP Token\-Ring agents\. Refer to ["Using the Tracing](2-1-3.md) [Command" in topic 2\.1\.3](2-1-3.md) for instructions on how to turn tracing on and off for a particular daemon\.
