### 2\.4\.8 AIX NetView/6000 Considerations

\_\_ Which AIX NetView/6000 applications were running at the time of the problem?

\_\_ Which mode was AIX NetView/6000 operating in at the time of the problem? Read or Read\-Write?

\_\_ What is the size of the network you are managing?

- Number of stations
- Number of bridges
- Number of concentrators
- Number of objects in the OVw database \(use the command **ovobjprint \| head**\)
- Number of objects to hold in ovwdb cache
- Number of seconds between storing data to the GTMD database
