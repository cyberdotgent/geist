## PREFACE\.2 How to Use This Book

Read the first chapter of this book to see where the LNM for AIX product files are installed, an explanation of the files used for segment performance data, and descriptions of the LNM for AIX daemons, processes, and executables\.

Read [Chapter 2, "Problem Determination" in topic 2\.0](2-0.md) to help you resolve problems you encounter when using LNM for AIX to monitor and manage your network\.

[Chapter 3, "Understanding Logs, Traps, and Filters" in topic 3\.0](3-0.md) explains how LNM for AIX handles logging, traps, and event filters\.

[Chapter 4, "Traps" in topic 4\.0](4-0.md) list the traps that can be sent by LNM for AIX and the actions that the LNM for AIX takes when these traps are received\. Traps are listed according to the LNM for AIX application at which they originate\.

Refer to [Chapter 5, "Messages" in topic 5\.0](5-0.md) to look up an LNM for AIX message\. This chapter lists messages you can receive while using LNM for AIX and includes an explanation of the meaning of the message and a recommended action you can take to resolve the situation\.

This book also contains a glossary, a bibliography, and an index\.

<a id="HDRAIXHIGH"></a>

**Highlighting and Operation Naming Conventions**

The following highlighting conventions are used in this book with the noted exceptions:

**Bold** Identifies menu choices, pushbuttons, commands, and shell script paths \(except in reference information\), default values, user selections, daemon paths \(on first occurrence\), and flags \(in parameter lists\)\.

*Italics* Identifies parameters whose actual names or values are to be supplied by the user, and terms that are defined in the following text\.

`Monospace` Identifies subjects of examples, messages in text, examples of portions of program code, examples of text you might see displayed, information you should actually type, and examples used as teaching aids\.

<a id="HDRAIXTERM"></a>

**Terms and Abbreviations**

This book uses the following terms:

heterogeneous network A network with multiple management protocols

internet A series of connected networks that use the Internet protocol

Internet A world\-wide network of TCP/IP\-based networks

multivendor network A network that contains products \(software/hardware\) from more than one vendor

RFC An abbreviation for Internet Request for Comments documents
