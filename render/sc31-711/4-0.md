# 4\.0 Chapter 4\. Traps

<a id="HDRALLTRP"></a>

This chapter contains a list of the traps that can be sent by LNM for AIX and the actions that LNM for AIX takes when these traps are received\. Each trap is logged by AIX NetView/6000\. The traps in this chapter are listed by trap number or name and organized by sections according to the LNM for AIX application at which they originate\.

When the LNM for AIX Response for a trap indicates that there is a change in the status for a resource, the status for the resource is changed to this status, unless a more severe status already exists\.
