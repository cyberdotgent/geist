### 2\.2\.1 Agent Discovery

If you attempt to manually discover an agent but an icon representing the subnet that the agent manages does not appear on the LAN submap, or the icon that represents the agent is blue, look at the nettl log for information about the problem, and ensure that the agent program is running\.
