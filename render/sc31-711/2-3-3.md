### 2\.3\.3 SNMP Bridge Application Problems

<a id="HDRSBRPRB"></a>

If you experience problems that seem to be associated with the SNMP bridge application, follow the general problem determination suggestions in ["Gathering Problem Information" in topic 2\.1](2-1.md)\. Next, check the following sources of information:

\_\_ nettl log \(see ["Checking the nettl Log" in topic 2\.1\.2](2-1-2.md)\) The errors logged in the nettl log for the SNMP bridge application include SNMP bridge agent errors that can indicate possible hardware and configuration problems\.

\_\_ Save the core image file

\_\_ MIB browser dump of the MIB

To obtain MIB browser dump of the MIB, follow these steps:

**1\.** Select **MIB browser: SNMP** from the AIX NetView/6000 Tools pull\-down menu\.

**2\.** Select **mgmt** from the Browse MIB window\.

**3\.** Enter the IP address and community name of the bridge\.

**4\.** Select **Start Query**\.

**5\.** Select **Save** to save the output of the dump\.

\_\_ If the problem is repeatable, tracing files are extremely useful\. You can start tracing on the lnmbrmon daemons\.

Start tracing on lnmbrmon to log the command flow between LNM for AIX and the SNMP bridge agents\. Refer to ["Using the Tracing](2-1-3.md) [Command" in topic 2\.1\.3](2-1-3.md) for instructions on how to turn tracing on and off for a particular daemon\.
