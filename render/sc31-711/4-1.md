## 4\.1 LNM OS/2 Agent Application Traps

<a id="HDRLMATRP"></a>

The following types of traps are processed by the LNM OS/2 agent application:

- Generic traps
- Traps generated by the LNM OS/2 agent application
- Traps generated by the LNM OS/2 agent program

If you are checking the trapd log for traps that have originated from an LNM OS/2 agent program, be aware that there are times when the first instance of a trap contains unreadable information because the data is represented in hexadecimal format\. Due to the way that AIX NetView/6000 records trap information, if each character in the string is a legitimate ASCII value, the value is recorded as an ASCII string, including special characters\. However, if one or more of the characters in the string is not an ASCII value, the value is represented in hexadecimal format\.

For example, the hexadecimal value of `21 22 23 24` is recorded as `! " # $` in the first instance of the trap in the trapd log\. LNM for AIX converts hexadecimal values to meaningful ASCII values, so that `21 22 23 24` is represented as `21 22 23 24` in the second instance of the trap, which LNM for AIX sends to AIX NetView/6000 after processing\.
