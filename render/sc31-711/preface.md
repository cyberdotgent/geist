# PREFACE About This Book

This book is designed as a reference manual for the IBM LAN Network Manager for AIX program \(hereafter referred to as LNM for AIX\)\.

LNM for AIX works with the AIX SystemView\* NetView/6000 program to enable you to monitor and manage the local area network \(LAN\) resources of your network more effectively\. LNM for AIX gives you the capability to manage both logical link control \(LLC\) and simple network management protocol \(SNMP\)\-based token\-ring LAN segments, fiber distributed data interface \(FDDI\) segments, and SNMP\-managed bridges\. It also shows you connectivity to other LAN and WAN segment types, such as Ethernet, X\.25, and frame\-relay\.
