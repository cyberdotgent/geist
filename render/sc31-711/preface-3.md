## PREFACE\.3 Where to Find More Information

This section lists the publications that are included with the LNM for AIX program\. Other sources of information that can be helpful when using LNM for AIX are listed in ["Bibliography" in topic BACK\_1](back_1.md)\.

You can request IBM publications from your IBM representative or the IBM branch office serving your region\. You can also contact the place where you purchased the LNM for AIX program\.

The following publications are included with the LNM for AIX program:

- *Getting Started with LAN Network Manager for AIX*, SC31\-7109
- *Using LAN Network Manager for AIX*, SC31\-7110
- *LAN Network Manager for AIX Reference*, SC31\-7111
