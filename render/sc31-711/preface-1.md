## PREFACE\.1 Who Should Use This Book

You should read this book if you are a network administrator, planner, or operator who will use LNM for AIX\. You should use this book as reference when solving problems with LNM for AIX and to find additional information about LNM for AIX messages and traps\.

Before reading this book, you should have a general understanding of network management, the AIX\* operating system, and the AIX NetView/6000 program\.
