## 2\.1 Gathering Problem Information

<a id="HDRHOWTSL"></a>

If you experience problems with the LNM for AIX program, the following tools might help you or IBM Technical Support Center personnel identify the problem:

- lnmstatus command
- nettl log
- kill \-30 command
- Clearing the LNM for AIX databases
