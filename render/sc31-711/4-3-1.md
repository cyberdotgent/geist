### 4\.3\.1 Generic Traps

The section lists the generic traps that are processed by the bridge application\. However, these traps are not processed by LNM for AIX for correlation information and are not sent back to AIX NetView/6000 for display with the event cards\.

<a id="MSG 0"></a>

- **0** — **Description:** Agent Cold start **LNM** **for** **AIX** **Response:** Rediscover the agent and reset the polling interval\.

<a id="MSG 1"></a>

- **1** — **Description:** Agent Warm start **LNM** **for** **AIX** **Response:** Rediscover the agent and reset the polling interval\.

<a id="MSG 2"></a>

- **2** — **Description:** Agent link down **LNM** **for** **AIX** **Response:** Mark bridge as down and attempt to rediscover the agent\.

<a id="MSG 3"></a>

- **3** — **Description:** Agent link up **LNM** **for** **AIX** **Response:** Rediscover the agent and reset the polling interval\.

<a id="MSG 4"></a>

- **4** — **Description:** Incorrect CommunityName **LNM** **for** **AIX** **Response:** Log trap in nettl log\.

<a id="MSG 5"></a>

- **5** — **Description:** egpNeighborLoss **LNM** **for** **AIX** **Response:** Log trap in nettl log\.
