## 4\.4 FDDI SNMP Proxy Agent Traps

<a id="MSG"></a>

<a id="HDRFDDITRP"></a>

This section lists the traps that can be sent by the FDDI SNMP Proxy Agent, and the actions that LNM for AIX takes when these traps are received\. For more information about the data associated with each of these traps, refer to IBM FDDI SNMP Proxy Agent User's Guide\.

<a id="MSG 1 (fddiRPUNoResponse)"></a>

- **1** **\(fddiRPUNoResponse\)** — **Description:** This trap is generated when an rpuNotify LLC Type 1 notification is received indicating that no response was received from the station specified by the rpuLoaderAddress attribute\. **LNM** **for** **AIX** **Response:** rpuNoResponse set in the 8240 concentrator\. The status of the resource is set to marginal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 2 (fddiRPULoaderNoResponse)"></a>

- **2** **\(fddiRPULoaderNoResponse\)** — **Description:** This trap is generated when an no response has been received from an Remote Program Upload \(RPU\) Loader\. This could indicate that the specified RPU file could not be found by the station performing the RPU Loader function\. **LNM** **for** **AIX** **Response:** rpuLoaderNoResponse set in the 8240 concentrator\. The status of the resource is set to marginal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 3 (fddiRPULoadUnavailable)"></a>

- **3** **\(fddiRPULoadUnavailable\)** — **Description:** This trap is generated when an rpuNotify LLC Type 1 notification is received indicating that the load file was not available from the station specified by the rpuLoaderAddress attribute\. **LNM** **for** **AIX** **Response:** rpuLoadUnavailable set in the 8240 concentrator\. The status of the resource is set to marginal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 4 (fddiRPUBadLoadReceived)"></a>

- **4** **\(fddiRPUBadLoadReceived\)** — **Description:** This trap is generated when an rpuNotify LLC Type 1 notification is received indicating that the load file received was incorrect or corrupted\. **LNM** **for** **AIX** **Response:** rpuBadLoadReceived set in the 8240 concentrator\. The status of the resource is set to marginal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 5 (fddiRPUUnknownFailure)"></a>

- **5** **\(fddiRPUUnknownFailure\)** — **Description:** This trap is generated when an rpuNotify LLC Type 1 notification is received indicating that the RPU process failed for an unknown reason\. **LNM** **for** **AIX** **Response:** rpuUnknownFailure set in the 8240 concentrator\. The status of the resource is set to marginal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 6 (fddiFanUnitError)"></a>

- **6** **\(fddiFanUnitError\)** — **Description:** The concentrator has detected a fan unit error\. A fan speed has fallen below 1900 rpm, and the power supply is shut off\. **LNM** **for** **AIX** **Response:** fanUnitError set in the 8240 concentrator\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 7 (fddiControlCartridgeError)"></a>

- **7** **\(fddiControlCartridgeError\)** — **Description:** The concentrator has detected a control cartridge error\. The control cartridge contains the concentrator main control function\. **LNM** **for** **AIX** **Response:** controlCartridgeError set in the 8240 concentrator\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 8 (fddiRingInterfaceCartridgeError)"></a>

- **8** **\(fddiRingInterfaceCartridgeError\)** — **Description:** The concentrator has detected a ring interface cartridge error\. The ring interface cartridge connects the concentrator to the FDDI ring\. **LNM** **for** **AIX** **Response:** ringInterfaceCartridgeError set in the 8240 concentrator\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 9 (fddiMotherBoardError)"></a>

- **9** **\(fddiMotherBoardError\)** — **Description:** The concentrator has detected a mother board error\. **LNM** **for** **AIX** **Response:** motherBoardError set in the 8240 concentrator\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 10 (fddiStationInterfaceCartridgeError)"></a>

- **10** **\(fddiStationInterfaceCartridgeError\)** — **Description:** The concentrator has detected a station interface cartridge error\. **LNM** **for** **AIX** **Response:** stationInterfaceCartridgeError set in the 8240 concentrator\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 11 (fddiConfigFilledSISlotListChanged)"></a>

- **11** **\(fddiConfigFilledSISlotListChanged\)** — **Description:** This trap is generated when an Event is received indicating that the value of snmpFddiConcentratorFilledStationSlotList has changed\. This indicates that the slots currently containing a Station Interface Cartridge has changed\. **LNM** **for** **AIX** **Response:** The appropriate SICs are added and/or deleted\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 12 (fddiConfigAvailableSISlotListChanged)"></a>

- **12** **\(fddiConfigAvailableSISlotListChanged\)** — **Description:** This trap is generated when an Event is received indicating that the value of snmpFddiConcentratorAvailableStationSlotList has changed\. This indicates that the slots currently available for Station Interface Cartridge insertion has changed\. **LNM** **for** **AIX** **Response:** The appropriate SICs are added and/or deleted\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 13 (fddiConfigCartridgeAvailabilityStatusChanged)"></a>

- **13** **\(fddiConfigCartridgeAvailabilityStatusChanged\)** — **Description:** This trap is generated when an Event is received indicating that the Availability Status of a Station Interface cartridge has changed\. **LNM** **for** **AIX** **Response:** SICActive is either set or cleared, depending on the value of the snmpFddiCartridgeAvailabilityStatus field in the trap\. The status of the resource is set to normal or critical, depending on the value of the snmpFddiCartridgeAvailabilityStatus field in the trap\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 14 (fddiConfigCartridgePortIndexListChanged)"></a>

- **14** **\(fddiConfigCartridgePortIndexListChanged\)** — **Description:** This trap is generated when an Event is received indicating that the list of ports associated with this Station Interface cartridge has changed\. The new list of ports is reported in this trap\. **LNM** **for** **AIX** **Response:** The dynamic indices of the ports contained in this SIC are changed to their new values\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 15 (fddiRPUComplete)"></a>

- **15** **\(fddiRPUComplete\)** — **Description:** This trap is generated when a notification has been received from an 8240 indicating RPU Complete\. **LNM** **for** **AIX** **Response:** rpuLoaderNoResponse cleared in the 8240 concentrator\. rpuNoResponse cleared in the 8240 concentrator\. rpuLoadUnavailable cleared in the 8240 concentrator\. rpuBadLoadReceived cleared in the 8240 concentrator\. rpuUnknownFailure cleared in the 8240 concentrator\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1073741824 (fddiMACFrameErrorCondition)"></a>

- **1073741824** **\(fddiMACFrameErrorCondition\)** — **Description:** This trap is generated when the fddiMACFrameErrorThreshold defined in SMT has been exceeded\. The trap is generated on the first notification that a station has detected this condition\. Subsequent SRF reports indicating that the condition continues to persist do NOT cause another trap to be generated\. **LNM** **for** **AIX** **Response:** macFrameError is set in MAC\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1073741825 (fddiPORTLerCondition)"></a>

- **1073741825** **\(fddiPORTLerCondition\)** — **Description:** This trap is generated when an SRF frame is received from a station indicating that the value of fddiPORTLer\-Estimate is less than or equal to fddiPORTLer\-Alarm\. Subsequent SRF reports from the same station indicating that the condition continues to persist do NOT cause another trap to be generated\. **LNM** **for** **AIX** **Response:** LERCondition is set in Port\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1073741826 (fddiMACFrameNotCopiedCondition)"></a>

- **1073741826** **\(fddiMACFrameNotCopiedCondition\)** — **Description:** This trap is generated when an SRF frame is received from a station indicating that the fddiMACNotCopiedThreshold has been exceeded\. Subsequent SRF reports from the same station indicating that the condition continues to persist do NOT cause another trap to be generated\. **LNM** **for** **AIX** **Response:** frameNotCopiedCondition is set in MAC\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1073741827 (fddiPORTEBCondition)"></a>

- **1073741827** **\(fddiPORTEBCondition\)** — **Description:** This trap is generated when an SRF frame is received from a station indicating that the Elasticity Buffer error count has incremented during a station's sampling period\. Subsequent SRF reports from the same station indicating that the condition continues to persist do NOT cause another trap to be generated\. **LNM** **for** **AIX** **Response:** EBCondition set in Port\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048229 (fddiConfigUNAChange)"></a>

- **1879048229** **\(fddiConfigUNAChange\)** — **Description:** This trap is generated when it is determined that the upstream neighbor of an FDDI station has changed\. **LNM** **for** **AIX** **Response:** For new station insertion: Add the appropriate stations to the ring map\. Connections are changed appropriately\. For old station reinsertion: macInactive cleared in MAC\. Connections are changed, if necessary\. For station deinsertion: macInactive set in MAC\. For dual\-homed switchover: The appropriate concentrator, and all attached stations, are moved to their new location on the segment\. Connections are changed appropriately\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048231 (fddiConfigStateChange)"></a>

- **1879048231** **\(fddiConfigStateChange\)** — **Description:** This trap is generated when an SRF frame is received indicating that the CF state has changed for an FDDI station\. It is based on an analysis of the fddiSMTConfigurationChgEvent SRF frame\. **LNM** **for** **AIX** **Response:** Wrapped set or cleared in Port, according the the ConfigState data in the trap\. The status of the resource is set to normal or critical, depending on the port wrap state\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048232 (fddiConfigReportingOff)"></a>

- **1879048232** **\(fddiConfigReportingOff\)** — **Description:** This trap is generated when the snmpFddiConfigReportingActive MIB variable is changed from a value of active to inactive\. It is intended to inform each Manager that traps for UNA Changes are no longer sent\. **LNM** **for** **AIX** **Response:** Message 300 informing the operator about this condition is posted\. This variable must be manually turned back on\. After a UNA trap is received \(indicating that ConfigReporting has been turned on\) is received, a resynchronization is performed\. Note that station status changes continue here\. However, should a station leave or enter the segment, this is no longer be noted, so station status is not guaranteed to be correct\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048233 (fddiMACFrameErrorConditionResolved)"></a>

- **1879048233** **\(fddiMACFrameErrorConditionResolved\)** — **Description:** This trap is generated when an SRF deassertion notification is received for a MAC Frame Error Condition\. **LNM** **for** **AIX** **Response:** frameErrorCondition cleared in MAC\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048234 (fddiPORTLerConditionResolved)"></a>

- **1879048234** **\(fddiPORTLerConditionResolved\)** — **Description:** This trap is generated when an SRF deassertion notification is received for a PORT Link Eror Rate \(LER\) Condtion\. **LNM** **for** **AIX** **Response:** LERCondition cleared in Port\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048235 (fddiMACFrameNotCopiedConditionResolved)"></a>

- **1879048235** **\(fddiMACFrameNotCopiedConditionResolved\)** — **Description:** This trap is generated when an SRF deassertion notification is received for a MAC Frame Not Copied Condition\. **LNM** **for** **AIX** **Response:** frameNotCopiedCondition cleared in MAC\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048236 (fddiMACDuplicateAddressConditionResolved)"></a>

- **1879048236** **\(fddiMACDuplicateAddressConditionResolved\)** — **Description:** This trap is generated when an SRF deassertion notification is received for a MAC Duplicate Address Condition\. **LNM** **for** **AIX** **Response:** duplicateAddress cleared in segment\. Segment is resynchronized\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048237 (fddiPORTEBConditionResolved)"></a>

- **1879048237** **\(fddiPORTEBConditionResolved\)** — **Description:** This trap is generated when an SRF deassertion notification is received for a PORT Elasticity Buffer Condition\. **LNM** **for** **AIX** **Response:** EBCondition set in Port\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048238 (fddiPeerWrapConditionResolved)"></a>

- **1879048238** **\(fddiPeerWrapConditionResolved\)** — **Description:** This trap is generated when an SRF deassertion notification is received for a Peer Wrap Condition\. **LNM** **for** **AIX** **Response:** Wrapped cleared in Port\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048239 (fddiHoldConditionResolved)"></a>

- **1879048239** **\(fddiHoldConditionResolved\)** — **Description:** This trap is generated when an SRF deassertion notification is received for a Hold Condition\. **LNM** **for** **AIX** **Response:** If the hold was on the managed ring segmentHeld cleared in segment\. All stations on the ring are reset to their previous status, including the holding station\(s\)\. Otherwise no action is taken\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048240 (fddiIndexReassigned)"></a>

- **1879048240** **\(fddiIndexReassigned\)** — **Description:** This trap is generated when an index associated with an FDDI resource such as SMT, PORT, or MAC has reached its maximum value, and therefore caused the index values to be reassigned\. This notifies the Manager that current relationships between resources and their associated index values may have changed\. **LNM** **for** **AIX** **Response:** lnmfddimon walks the SMT table and reassigns the SMTIndex of each node, where necessary\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 1879048246 (fddiRingInoperativeResolved)"></a>

- **1879048246** **\(fddiRingInoperativeResolved\)** — **Description:** This trap is generated when the FDDI ring becomes operational after having been in an inoperative state\. **LNM** **for** **AIX** **Response:** ringInoperative cleared in segment\. All stations on the ring are reset to their previous status, including the stations in the fault domain\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 805306369 (fddiUndesireableConnection)"></a>

- **805306369** **\(fddiUndesireableConnection\)** — **Description:** An undesirable or illegal connection attempt has been made\. **LNM** **for** **AIX** **Response:** None\. Not applicable in a logical view\.

<a id="MSG 805306370 (fddiMACDuplicateAddressCondition)"></a>

- **805306370** **\(fddiMACDuplicateAddressCondition\)** — **Description:** This trap is generated when an SRF frame is received from a station indicating that a Duplicate Address condition has been detected in one of the MAC's addresses or in the MAC's upstream neighbor\. Subsequent SRF reports from the same station indicating that the condition continues to persist do NOT cause another trap to be generated\. **LNM** **for** **AIX** **Response:** duplicateAddress set in segment\. Status of duplicate MAC\(s\) changed to critical\. lnmfddimon stops building and updating the ring map\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 805306371 (fddiPeerWrapCondition)"></a>

- **805306371** **\(fddiPeerWrapCondition\)** — **Description:** This trap is generated when an SRF frame is received from a station indicating that a dual\-attachment node is wrapped with a Peer mode connection\. **LNM** **for** **AIX** **Response:** Wrapped set in Port\. The status of the resource is set to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 805306372 (fddiHoldCondition)"></a>

- **805306372** **\(fddiHoldCondition\)** — **Description:** This trap is generated when a primary or secondary ring holding status is detected\. **Note:** This optional Hold policy prevents a dual ring from wrapping when a fault is detected on one ring\. **LNM** **for** **AIX** **Response:** If the managed ring is holding segmentHeld set in segment\. Status of all stations changed to unknown\. Status of holding station changed to critical\. Otherwise, no action is taken\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 805306373 (fddiRingInoperative)"></a>

- **805306373** **\(fddiRingInoperative\)** — **Description:** This trap is generated when it is determined that a beaconing condition has not been recovered and that the FDDI ring is in an inoperative state\. This trap can only be sent to the management station if a physical transport path other than the inoperative FDDI ring is available\. **LNM** **for** **AIX** **Response:** ringInoperative set in segment\. Status of all stations changed to unknown\. Status of fault domain stations changed to critical\. Forward to AIX NetView/6000 with resource name\.

<a id="MSG 805306374 (fddiBeaconingDetected)"></a>

- **805306374** **\(fddiBeaconingDetected\)** — **Description:** This trap is generated when it is determined that a directed beaconing condition has occurred on the ring\. **LNM** **for** **AIX** **Response:** None\. This trap is not reported until the directed beaconing condition has cleared\. The status of the resource is set to normal\. Forward to AIX NetView/6000 with resource name\.
