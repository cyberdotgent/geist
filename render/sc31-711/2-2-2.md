### 2\.2\.2 Not Receiving Traps

If you are not receiving traps from an agent program in your network, begin by looking for a mismatch between community names and ensure you have activated the LNM for AIX filter\. *Mismatched Community Names*: For LNM for AIX to receive traps properly, the community name specified at the agent workstation must match the community name defined for that agent in AIX NetView/6000\. To ensure that trap authentication is correctly configured check the following:

- Verify that the community name on the agent workstation matches that on AIX NetView/6000\.

If they do not match, you can change the agent community name to match the default community name defined in AIX NetView/6000, or you can define a node\-specific community name for the agent on the SNMP Configuration window in AIX NetView/6000\.

- Verify that the SNMP password file exists on the agent workstation\.

*Inactive Filter*: If you are receiving agent traps but they are not being displayed in the AIX NetView/6000 event display, you may need to activate the LNM for AIX filter file\. This filter specifies which LNM for AIX traps are to be displayed in the event display\.

To activate the LNM for AIX filter, follow these steps:

**1\.** Select **Filter control** from the Operations pull\-down menu on the AIX NetView/6000 event card display\. The Filter Control window is displayed\.

**2\.** Select the **File List** push button\. The File Selection window is displayed\.

**3\.** Select **/usr/OV/filters/lnm\.filter** from the Files list and select the **OK** push button\. When you are returned to the Filter Control window, the lnmCustomer filter is listed in the Available Filters in File list box\.

**4\.** Select **lnmCustomer** from the list and then select the **Activate** push button\. The lnmCustomer filter is moved to the Active Filters List and is immediately activated\.

**5\.** Select the **Close** push button to close the window and apply the changes\.

You can deactivate the filter by selecting the filter on the Filter Control window and selecting the **Deactivate** push button\.
