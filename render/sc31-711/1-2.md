## 1\.2 LNM for AIX Files Installed in AIX NetView/6000 Directories

<a id="HDRNVFILES"></a>

```text
   LNM for AIX product files are also installed in the following AIX
   NetView/6000 directories:
   Directory           Type of Files
   /usr/OV/bitmaps/C   LNM for AIX bitmaps used by OVW
   /usr/OV/backgrounds LNM for AIX backgrounds used by OVW
   /usr/OV/conf/C      Contains the lnm.oid_to_sym file modified by LNM for
                       AIX
   /usr/OV/fields/C    LNM for AIX fields used by OVW
   /usr/OV/filters     LNM for AIX filters used by OVW
   /usr/OV/registration/C
                       LNM for AIX registration files
   /usr/OV/snmp_mibs   LNM for AIX SNMP MIB definitions
   /usr/OV/symbols/C   LNM for AIX symbols used by OVW
   /usr/OV/help/C/lnm  LNM for AIX help files
```
