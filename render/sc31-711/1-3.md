## 1\.3 LNM for AIX Daemons and Executables

<a id="HDRDAEMS"></a>

<pre>
   The LNM for AIX program invokes several daemons and executables (shell
   scripts and compiled programs).  These daemons and executables are stored
   in the /usr/lpp/lnm/bin directory.  The following list briefly describes
   the daemons and executables.  For more detailed information, refer to the
   online man page for the specific daemon or executable.  To display a man
   page, type:
     man topic
   Where topic is the name of the daemon or executable for which you want
   more information.
   Process Name   Description
   lnmd           Manages lnmtopod and the monitoring applications that are
                  part of LNM for AIX and provides a communication channel
                  for the LNM for AIX command line interface.
   lnm_agent_found Initiates the discovery of a specified agent.
   lnm_agent_remove Stops monitoring an agent.
   lnmexport      Converts current week performance data collected by the LNM
                  OS/2 agent to a spreadsheet-readable delimited format.
   lnmfddimgr     Manages the LNM for AIX FDDI application.
   lnmfddimon     FDDI SNMP Proxy Agent monitor process.
   lnmlnmeint     Manages the sending of run command requests to the LNM OS/2
                  Agents from LNM for AIX and the receiving of the run
                  command responses from the LNM OS/2 Agents by LNM for AIX.
   lnmlnmemgr     Manages the LNM for AIX LLC token-ring application.
   lnmlnmemon     LNM OS/2 agent monitor process.
   lnmstart       Starts the LNM for AIX daemon processes.
   lnmstop        Stops the LNM for AIX daemon processes.
   lnmstatus      Displays the status of the LNM for AIX daemon processes.
   lnmtopod       Provide monitoring and management support by integrating
                  multiprotocol networks into a single LAN interconnect
                  topology hierarchy.
   lnmbrmon       SNMP Bridge monitor process.
   lnmbrmgr       Manages the LNM for AIX SNMP bridge application.
   lnmtrmon       SNMP token-ring monitor process.
   lnmtrmgr       Manages the LNM for AIX SNMP token-ring application.
   lnmtrexec      Displays and manages the SNMP Concentrator view.
   lnmhubint      Communicates with the Hub Manager iubd daemon to manage the
                  LNM for AIX Hub Manager integration function.
</pre>
