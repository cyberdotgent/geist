## BACK\_1\.1 LAN Network Manager for AIX Publications

The following paragraphs briefly describe the library for Version 1 of the LAN Network Manager \(LNM\) for AIX program:

Getting Started with LAN Network Manager for AIX \(SC31\-7109\)

This book is intended for beginning users\. It describes hardware and software requirements for the LNM for AIX installation\. It also explains how to install the program and define network agents, stations, bridges, and concentrators\. Information about getting started, navigation, and resource management is included\.

Using LAN Network Manager for AIX \(SC31\-7110\)

The information provided in this book can help readers monitor and manage LLC and SNMP token\-ring LAN segments, fiber distributed data interface \(FDDI\) segments, and SNMP bridges\.

LAN Network Manager for AIX Reference \(SC31\-7111\)

The reference information in this book helps readers solve network management problems and provides a list of messages and traps sent by LNM for AIX\. It also describes the files that are used for segment performance data, daemons, processes, and executables\.
