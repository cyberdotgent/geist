### 4\.2\.2 SNMP Token\-Ring Application\-Generated Traps

<a id="MSG"></a>

<a id="HDRSNTRAP"></a>

This section lists the traps that are generated by the SNMP token\-ring application\. The traps are listed according to specific trap number\.

<a id="MSG 1"></a>

- **1** — **Description:** The operational status of the concentrator backup path was changed\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 2"></a>

- **2** — **Description:** The concentrator Wrap status has changed\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 3"></a>

- **3** — **Description:** Concentrator Internal error detected\. **LNM** **for** **AIX** **Response:** Change the segment and concentrator status depending on the error and send the trap to AIX NetView/6000\.

<a id="MSG 4"></a>

- **4** — **Description:** The status of an attachment module of the concentrator has changed\. **LNM** **for** **AIX** **Response:** Change the concentrator graphical view to display the current status and send the trap to AIX NetView/6000\.

<a id="MSG 5"></a>

- **5** — **Description:** The status of a port of an attachment module of the concentrator has changed\. **LNM** **for** **AIX** **Response:** Change the concentrator graphical view to display the current status and send the trap to AIX NetView/6000\.

<a id="MSG 6"></a>

- **6** — **Description:** A forced remove command was received and ignored by the concentrator\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 8"></a>

- **8** — **Description:** The configuration of a port of an attachment module of the concentrator has changed\. **LNM** **for** **AIX** **Response:** Change the concentrator graphical view to display the current configuration and send the trap to AIX NetView/6000\.

<a id="MSG 9"></a>

- **9** — **Description:** The code update for a concentrator has completed successfully\. **LNM** **for** **AIX** **Response:** Display a message box and send the trap to AIX NetView/6000\.

<a id="MSG 10"></a>

- **10** — **Description:** An attachment module of a concentrator was removed\. **LNM** **for** **AIX** **Response:** Removes the corresponding attachment module from the concentrator graphical view and send the trap to AIX NetView/6000\.

<a id="MSG 512"></a>

- **512** — **Description:** Access control function has removed a station that was inserted in the segment\. **LNM** **for** **AIX** **Response:** Remove the station from the segment and send the trap to AIX NetView/6000 with the resource name\.

<a id="MSG 513"></a>

- **513** — **Description:** A monitored resource is off of the segment\. **LNM** **for** **AIX** **Response:** Change the station status to marginal and send the trap to AIX NetView/6000 with the resource name of the station\.

<a id="MSG 514"></a>

- **514** — **Description:** A monitored resource that was off has returned to the segment\. **LNM** **for** **AIX** **Response:** Change the station status and send the trap to AIX NetView/6000\.

<a id="MSG 515"></a>

- **515** — **Description:** Access control function has disabled a port of a concentrator because an unauthorized station was inserted in the segment\. **LNM** **for** **AIX** **Response:** Disable the port on the concentrator and send the trap to AIX NetView/6000\.

<a id="MSG 1879048257"></a>

- **1879048257** — **Description:** Impending\-soft\-error threshold exceeded\. **LNM** **for** **AIX** **Response:** Change segment status to marginal and send the trap to AIX NetView/6000\.

<a id="MSG 1879048259"></a>

- **1879048259** — **Description:** Excessive\-soft\-error threshold exceeded\. **LNM** **for** **AIX** **Response:** Change segment status to marginal and send the trap to AIX NetView/6000\.

<a id="MSG 1879048263"></a>

- **1879048263** — **Description:** Total number of Lost Frames exceeds the threshold value\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048264"></a>

- **1879048264** — **Description:** Total number of Receiver Congestion errors exceeds the threshold value\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048265"></a>

- **1879048265** — **Description:** Total number of Frame Copied errors exceeds the threshold value\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048266"></a>

- **1879048266** — **Description:** Total number of Frequency errors exceeds the threshold value\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048267"></a>

- **1879048267** — **Description:** Total number of Token errors exceeds the threshold value\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048268"></a>

- **1879048268** — **Description:** Total number of Table Full errors exceeds the threshold value\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048269"></a>

- **1879048269** — **Description:** Total number of Minimum Decrement errors exceeds the threshold value\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048270"></a>

- **1879048270** — **Description:** Total number of Receiver Congestion and Table Full errors exceeds the threshold value\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048271"></a>

- **1879048271** — **Description:** Soft error report MAC frames received\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048272"></a>

- **1879048272** — **Description:** Neighbor notification incomplete frames\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048273"></a>

- **1879048273** — **Description:** Report active monitor error frames\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 1879048274"></a>

- **1879048274** — **Description:** The beaconing condition existed on the segment has recovered\. **LNM** **for** **AIX** **Response:** Change segment status to normal and send the trap to AIX NetView/6000\.

<a id="MSG 1879048275"></a>

- **1879048275** — **Description:** A station is no longer experiencing excessive congestion\. **LNM** **for** **AIX** **Response:** Change segment status to normal and send the trap to AIX NetView/6000\.

<a id="MSG 805306378"></a>

- **805306378** — **Description:** Beaconing condition detected on the segment\. **LNM** **for** **AIX** **Response:** Change segment status to critical and send the trap to AIX NetView/6000\.

<a id="MSG 805306379"></a>

- **805306379** — **Description:** Temporary beaconing condition existed on the segment but it recovered\. **LNM** **for** **AIX** **Response:** Send the trap to AIX NetView/6000\.

<a id="MSG 805306380"></a>

- **805306380** — **Description:** A station is experiencing excessive congestion\. **LNM** **for** **AIX** **Response:** Change segment status to marginal and send the trap to AIX NetView/6000\.
