#### 4\.3\.6 Rebuild the Executable MODULEs

<a id="HDRXCMSEX"></a>

[Table 4\-15](<#TBLXCMSXBL>) describes the build lists used to rebuild executable MODULEs\.

<a id="TBLXCMSXBL"></a>

```
        ____________________________________________________________________
       | Table  4-15. Build Lists for Rebuilding Executable MODULEs         |
       |________________ __________________________________ ________________|
       | Build List     | Description                      | Test/Production|
       |                |                                  | Disk           |
       |________________|__________________________________|________________|
       | CMSMLOAD       | Build list for CMS MODULEs that  | 490/190        |
       |                | reside on the system disk.       |                |
       |________________|__________________________________|________________|
       | CMSXLOAD       | Build list for CMS MODULEs that  | 493/193        |
       |                | reside on the system tools disk. |                |
       |________________|__________________________________|________________|
       | IOCPLOAD       | Build list for IOCP MODULEs that | 490/190        |
       |                | reside on the system disk.       |                |
       |________________|__________________________________|________________|
       | SERVLOAD       | Build list for SFS server        | 493/193        |
       |                | MODULEs that reside on the BASE  |                |
       |                | disk.                            |                |
       |________________|__________________________________|________________|
 |     | DMSBLPRP       | Build list the PROPLIB LOADLIB.  | 490/190        |
       |________________|__________________________________|________________|
```

**1\.** For each build list in [Table 4\-15](<#TBLXCMSXBL>) that has MODULEs that have been serviced, enter the VMFBLD command to rebuild the serviced modules:

**Note:** If you have SQL/DS or ISPF or both, and are using the CMS Pipelines interfaces to these applications you must enter the GLOBAL command to identify the text libraries containing the interface files before running VMFBLD\.

`global txtlib` *pipsql*

*pipsql* is the file name of the TXTLIB containing the SQL/DS interface files, ISPF interface files, or both\.

For more information on how the TXTLIB is created, and where it is located, see the *VM/ESA: Planning and Administration* book\.

<a id="TBLTBLUNIQ315"></a>

```
                                                  bldlist is the file name of one of the
   vmfbld ppf esa cms bldlist (serviced           build lists from Table 4-15.
                                                  After each VMFBLD command, review the build
                                                  message log (as described in the next step)
                                                  before you proceed to the next.
```

**Notes:**

a\. If you receive the following message:

`DMSLIO201W The following names are undefined: DMSUSRX1 and DMSUSRX2`

disregard it, because the undefined names are user exits\.

b\. If you receive the following messages:

`DMSLIO201W The following names are undefined: ISPLINK1 and ARIPRDI`

disregard it, because they are interface files for ISPF and Sequel\.

c\. If, while building the DMSCUT or DMSDFT MODULEs, you get a return code of 4 with this message, you can disregard it\.

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ317"></a>

```
   vmfview build
```

**3\.** [Table 4\-16](<#TBLXCMSTXT>) contains a CMS build list and MODULE that may need to be rebuilt, which requires special processing\.

<a id="TBLXCMSTXT"></a>

```
        __________________________________________________________________________________________________
       | Table  4-16. CMS Build Lists and MODULEs to Be Rebuilt                                           |
       |___________________________ __________________________________________ ___________________________|
       | Build List                | MODULE to Be Rebuilt                     | Test/Production           |
       |___________________________|__________________________________________|___________________________|
       | DMSBLASM                  | ASSEMBLE MODULE                          | 490/190                   |
       |___________________________|__________________________________________|___________________________|
```

Enter the VMFBLD command for each build list in [Table 4\-16](<#TBLXCMSTXT>) to create the updated level of the text decks, and determine if any of the files in the build list have been serviced\.

<a id="TBLTBLUNIQ318"></a>

```
 |                                                Message VMFBDC2180I indicates that files in
 | vmfbld ppf esa cms dmsblasm (serviced          the build list have been serviced.
```

**4\.** If any of the files in the DMSBLASM build list has been serviced, enter the following commands to rebuild the MODULE:

<a id="TBLTBLUNIQ319"></a>

```
 |                                                When you rebuild the ASSEMBLE MODULE,
 | access 490 a                                   access the 490 disk as A before you issue
 | asmgend                                        the ASMGEND command.
 |                                                When ASMGEND prompts you for a file mode,
 |                                                press  ENTER .
```

**5\.** After you rebuild all of the serviced MODULEs, restore the original access order\.

<a id="TBLTBLUNIQ320"></a>

```
   access 191 a
   vmfsetup esa cms
```
