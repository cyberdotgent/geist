### 1\.2\.5 Building New Levels

The build task is accomplished by using the appropriate command or set of commands to generate a serviced level of an object on a build disk\. When you run any build command, all local and service disks must be accessed to ensure that the highest level parts are used to generate an object\. The generated object is placed on a build disk\.
