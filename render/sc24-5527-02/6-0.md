# 6.0 Chapter 6.  Using the Service Level Inventory

<a id="HDRSRVL"></a>

This chapter identifies a number of common uses of the service level inventories generated by VMSES/E and shows how to use the VMFSIM command to manage these inventories. This chapter is organized to show what information is available after service has been received, applied, and built. The service level inventory consists of a number of tables that contain the following information about PTFs installed for a product or component. Requisite relationships between PTFs The status of the PTFs installed The level of each part of the product serviced The status of objects built for the product. This information is contained in a set of tables generated by VMSES/E when servicing a product. Following is a description of each table and the information provided. **Table** **Type** **Content** **Requisite** **Table** This table contains the PTF requisite relationships defined between PTFs received for the product or component and the mapping of PTF numbers to APAR numbers.
