#### 4\.4\.9 Rebuild the CP Nucleus

<a id="HDRXCPPRB"></a>

```
 |  ___ Note _______________________________________________________________
   |                                                                        |
 | | If you would like to change the default system national language for   |
 | | CP you must rebuild the CP nucleus to contain the language.  To do     |
 | | this, follow the steps in Appendix C, "Changing System National        |
 | | Language including UCENG" in topic C.0.                                |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Define 24 megabytes of virtual storage and re\-IPL CMS\.

<a id="TBLTBLUNIQ357"></a>

```
 |
 | set machine xa
 | define storage 24m

 |                                                Defining storage causes a system reset.
 | STORAGE CLEARED - SYSTEM RESET

 |                                                After receiving the version identification,
 | ipl 190 clear                                  press ENTER.
 | VM/ESA Release 2.0 mm/dd/yy hh:mm:ss
```

**2\.** Build the nucleus\.

<a id="TBLTBLUNIQ358"></a>

```
 |
 | vmfbld ppf esa cp cpload (all setup

 |                                                cpload is the CP load list.
```

\|  \_\_\_ **Note** \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_ 

\| \| If you want the CP nucleus built as a punch text specify `punch` and \| \| \| the nucleus will be placed in your reader provided you have \| \| \| spooled your punch to your reader\. \|

<a id="TBLTBLUNIQ359"></a>

```
       |                                                                    |
       |                                                                    |
 |     |                                                                    |
 |     | vmfbld ppf esa cp cpload * nuctarg punch (all setup                |
       |                                                                    |

       |                                                                    |
       |                                                                    |
```

**3\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ361"></a>

```
 |
 | vmfview build
```

**4\.** Access the test system tools disk \(493\)\. The CP load map file \(CPLOAD MAP\) is on MAINT's 191 disk\.

<a id="TBLTBLUNIQ362"></a>

```
 |
 | copyfile cpload map a cpload map fm-493 (replace pack
 | erase cpload map a
```

**5\.** Examine the load map for unresolved symbols\. Unresolved symbols sometimes, but not always, indicate an error\. Make sure that you understand the reason for any unresolved symbols you find before going on\.

<a id="TBLTBLUNIQ363"></a>

```
 |                                                This response means that no unresolved
 | xedit cpload map                               symbols were found.
 | set case mixed ignore
 | ====> all/unresol/
 | DMSXDC546E Target not found

 |                                                This response means that no undefined
 | ====> all/undefin/                             symbols were found.
 | DMSXDC546E Target not found

 |
 | ====> qquit
```

**6\.** Release the test system tools disk\.

```
    ___ Note _______________________________________________________________
   |                                                                        |
 | | You have now finished the detailed build steps for CP.  Go to "Rebuild |
 | | the HELP Files in Uppercase (Optional)" in topic 3.9.4.5 and complete  |
 | | the rest of the service steps for this component.                      |
   |                                                                        |
   |________________________________________________________________________|
```
