#### 6\.1\.7 Determine Receive Status of All PTFs Containing a Specific APAR

To determine the receive status of all PTFs containing a specific APAR you must first query the SRVREQT table to obtain a list of PTFs that contain the APAR in question and then use the results of that query to obtain the status of the PTF\. The following VMFSIM QUERY commands would be issued to obtain the status\.

<a id="TBLTBLUNIQ439"></a>

```
   vmfsim query tblfn srvreqt * tdata :aparnum vm29997 (file ptfrecs
   vmfsim query tblfn srvrecs * file ptfrecs
   VMFSIP2480I RESULTS FOR
               TDATA :PTF UM18082 :APARNUM VM47103
   :PTF UM18082
      :STAT RECEIVED.09/16/92.14:54:22.MAINT
```

The first query of the APAR from the SRVREQT table will capture the PTF numbers associated with the APAR and save the results in the PTFRECS SIMDATA file\. The second query, using the PTFRECS SIMDATA file as the input data, will return the status of the PTFs from the SRVRECS table\. The net result of these two queries is the status of all PTFs that contained the APARs specified\.

**Note:** Ignore the informational messages displayed in the second Query\.

The second query returns the following data:

**Field Data Definition**

**:PTF** This field contains the PTF number received\.

**:STAT** This field contains the status of the PTF followed by a number of qualifiers that identify the date and time the PTF was received, and the user ID used to receive the PTF\.
