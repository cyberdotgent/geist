#### 6.4.1 Query the Status of an Object

The Build Status table (SRVBLDS) has a list of build lists and objects that have been serviced and/or built for the product or component. To determine the build status of a specific object the following VMFSIM QUERY command would be issued against the

table.

<a id="TBLTBLUNIQ451"></a>

| VMFSIP2480I RESULTS FOR | TDATA :OBJECT DDR | :BLDLIST HCPMLOAD |
| --- | --- | --- |


**Field** **Data** **Definition** **:****BLDLIST** This field contains the name of the build list that contained the object. **:****OBJECT** This field contains the name of an object that is contained in the build list. A build list can contain one or more objects. **:****STAT** This field contains the status of the object followed by a number of qualifiers that identify the date and time the object was built, and the user ID used to build the object.
