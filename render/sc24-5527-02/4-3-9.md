#### 4\.3\.9 Rebuild the CMS Nucleus

<a id="HDRXCMBLN"></a>

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Parts of the REXX/VM component are contained in the CMS nucleus and    |
   | the GCS nucleus.  You must receive, apply and build any REXX/VM        |
   | service before you build either nucleus.  If you have applied REXX/VM  |
   | service, and there is no service for CMS or GCS, you must still        |
   | rebuild the CMS nucleus and, if you have installed GCS, the GCS        |
   | nucleus.  For information on rebuilding the GCS nucleus, see "Rebuild  |
   | the GCS Nucleus" in topic 4.5.7.                                       |
   |                                                                        |
   |________________________________________________________________________|
 |  ___ Note _______________________________________________________________
   |                                                                        |
 | | If you would like to change the default system national language for   |
 | | CMS you must rebuild the CMS nucleus to contain the language.  To do   |
 | | this, follow the steps in Appendix C, "Changing System National        |
 | | Language including UCENG" in topic C.0                                 |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** If you make any changes to the DMSNGP ASSEMBLE file, you must use VMFHASM to reassemble the file\.

<a id="TBLTBLUNIQ327"></a>

```
                                                  For more information about the DMSNGP
 | vmfhasm dmsngp esa cms                         ASSEMBLE file, see the VM/ESA: Installation
 |                                                Guide and VM/ESA: Planning and
 |                                                Administration book.

   copyfile dmsngp txtft a = = fm-3C4 (olddate replace
   erase dmsngp txtft a

                                                  The COPYFILE command copies DMSNGP back to
                                                  the LOCALMOD disk.

 |                                                txtft is the text file type.  txtft becomes
 |                                                TXT00000 even if no updates were applied.
```

**2\.** Build the nucleus\.

<a id="TBLTBLUNIQ330"></a>

```
                                                  Spool the printer and punch output to your
   spool prt *                                    virtual reader.
   spool pun *

                                                  cmsload is the build list identified by the
   vmfbld ppf esa cms cmsload (all                VMFBDNUC entry in the :BLD section of the
                                                  component PPF, unless you use your own
                                                  override file.

                                                  The punch file containing the nucleus is
   LOAD LIST:  $$$TLL$$ EXEC     A1 (MNT191)      spooled to your reader.
   RDR FILE 0025 SENT FROM MAINT    PUN WAS 0025
       RECS 043K CPY  001 A NOHOLD NOKEEP
```

**3\.** Check the results of the build\. Use VMFVIEW to examine the $VMFBLD $MSGLOG file to verify that the correct levels of the text decks were loaded into the nucleus\.

<a id="TBLTBLUNIQ331"></a>

```
   vmfview build
```

**4\.** Verify that the new nucleus is in your reader\. Note the spool ID for use in later commands\.

<a id="TBLTBLUNIQ332"></a>

```
   query rdr * all
   ORIGINID FILE CLASS RECORDS  CPY HOLD DATE  TIME     NAME      TYPE     DIST
   MAINT    0025 A PUN 00043417 001 NONE 05/30 14:39:14 $$$TLL$$  IPL      SYSPROG
```

**5\.** Make the file that contains the new nucleus the first file in your reader\.

<a id="TBLTBLUNIQ333"></a>

```
                                                  spoolid is the spool ID of the nucleus file
   order rdr spoolid                              that you recorded earlier.  In the previous
                                                  example, the spool ID was 0025.
```

**6\.** Set up the correct virtual machine environment and IPL the new nucleus\.

<a id="TBLTBLUNIQ334"></a>

```
   set machine xa
   System reset.
   System = XA

   define storage 24m
   STORAGE =      24M

                                                  Ensure that the nucleus gets loaded to the
   define 190 590                                 test CMS system disk, and does not overlay
                                                  your production nucleus.

   define 490 190                                  ___ Note ________________________________
                                                  |                                         |
                                                  | The 490 disk is defined as 190 because  |
                                                  | the default address in DMSNGP for the   |
                                                  | nucleus is 190.  If you have changed    |
                                                  | DMSNGP, define 490 as the address coded |
                                                  | in your DMSNGP file.                    |
                                                  |                                         |
                                                  |_________________________________________|

   ipl 00c clear
```

**Note:** At this point, you might receive one or more nucleus generation prompts\. A prompt appears only if a `?` appears as an entry in, or if information is missing from the DMSNGP ASSEMBLE file\. For more information about how to respond to these prompts, see the section of the starter system installation procedure in [VM/ESA: Installation](<DOCNUM/SC24-5526/CCONTENTS>) [Guide](<DOCNUM/SC24-5526/CCONTENTS>) that describes how to build the new CMS nucleus\.

<a id="TBLTBLUNIQ336"></a>

```
                                                  This is the default version ID.  If you
 | VM/ESA Release 2 mm/dd/yy hh:mm:ss             defined your own version ID, it appears
                                                  here and each time you IPL either the CMS
                                                  test system disk (MAINT 490).

                                                  Press ENTER to complete the IPL.
    ENTER
```

**7\.** Save the CMS load map\.

<a id="TBLTBLUNIQ337"></a>

```
                                                  fm is any free file mode.
   access 493 fm

                                                  The CMS load map has been spooled to your
   spool prt nohold                               virtual reader.  Note the spool ID for use
   close prt                                      in the next command.
   RDR FILE 0026 SENT FROM MAINT PRT
       WAS 0026 RECS 8270 CPY  001 A NOHOLD NOKEEP

                                                  Receive the file onto the system tools
   receive spoolid cmsnuc map fm-493 (replace     disk, using the spool ID from the previous
                                                  message.  In the previous example, the
                                                  spool ID was 0026.

   copyfile cmsnuc map fm-493 = = = (replace pack
```

**8\.** XEDIT the CMSNUC MAP and check for unresolved or undefined references\. Unresolved or undefined symbols sometimes, but not always, indicate an error\. Make sure you understand the reason for any unresolved or undefined symbols before going on\.

<a id="TBLTBLUNIQ338"></a>

```
 |                                                This response means that no unresolved
 | xedit cmsnuc map                               symbols were found.
 | set case mixed ignore
 | ====> all/unresol/
 | DMSXDC546E Target not found

 |                                                This response means that no undefined
 | ====> all/undefin/                             symbols were found.
 | DMSXDC546E Target not found

 |
 | ====> qquit
```

**9\.** Redefine the CMS disks back to their original values:

<a id="TBLTBLUNIQ339"></a>

```
   define 190 490
   define 590 190
 | ipl 190 clear
```

```
   |                                                                        |
   | You have now finished the detailed build steps for CMS.  Go to "Test   |
   | the New Level of CMS" in topic 3.8.5 and complete the rest of the      |
   | service steps for this component.                                      |
   |                                                                        |
   |________________________________________________________________________|
```
