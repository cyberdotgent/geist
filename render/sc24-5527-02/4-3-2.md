#### 4\.3\.2 Determine which Build Lists Need to be Processed

<a id="HDRXCMSBST"></a>

**1\.** To determine which build steps you should perform:

<a id="TBLTBLUNIQ305"></a>

```
   vmfview build

                                                  This command will display the names of all
                                                  objects that need to be built.
```
