#### 4\.3\.4 Update the Macro Libraries \(MACLIBs\)

<a id="HDRXCMSMAC"></a>

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | If you already updated the MACLIBs as part of reapplying local service |
   | earlier in this component step, skip this step, and go to "Rebuild the |
   | Text Libraries" in topic 4.3.5.                                        |
   |                                                                        |
   |________________________________________________________________________|
```

[Table 4\-13](<#TBLXCMSMAC>) contains a list of CMS MACLIBs that may need to be rebuilt\.

<a id="TBLXCMSMAC"></a>

```
    ________________________________________________________________________
 | | Table  4-13. CMS MACLIBs to Be Rebuilt                                 |
   |_________________ ____________________________________ _________________|
 | | MACLIB          | Description                        | Target Build    |
 | | (bldlist)       |                                    | Test/Production |
   |_________________|____________________________________|_________________|
 | | DMSOM           | Build list for the DMSOM MACLIB.   | 490/190         |
   |_________________|____________________________________|_________________|
 | | DMSGPI          | Build list for the DMSGPI MACLIB.  | 490/190         |
   |_________________|____________________________________|_________________|
 | | OSMACRO         | Build list for the OSMACRO MACLIB. | 490/190         |
   |_________________|____________________________________|_________________|
 | | OSPSI           | Build list for the OSPSI MACLIB.   | 490/190         |
   |_________________|____________________________________|_________________|
 | | OSMACRO1        | Build list for the OSMACRO1        | 490/190         |
 | |                 | MACLIB.                            |                 |
   |_________________|____________________________________|_________________|
 | | MVSXA           | Build list for the MVSXA MACLIB.   | 490/190         |
   |_________________|____________________________________|_________________|
```

**1\.** Enter the VMFBLD command to rebuild the MACLIB for each build list that needs to be rebuilt\.

<a id="TBLTBLUNIQ309"></a>

```
                                                  bldlist is the name of a MACLIB from
   vmfbld ppf esa cms bldlist (serviced           Table 4-13.
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ311"></a>

```
 |
 | vmfview build
```
