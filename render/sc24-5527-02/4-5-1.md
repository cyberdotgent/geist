#### 4\.5\.1 Prepare to Build

**1\.** Query the disks and record the file modes of the disks listed in [Table 4\-26](<#TBLXGCSDSK>) in the last column of the table\. Unless you have made your own substitutions through PPF overrides, use the default disks listed in the table\.

<a id="TBLTBLUNIQ364"></a>

```
   vmfqmda esa gcs|gcssfs
```
