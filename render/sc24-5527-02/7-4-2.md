## 7.4.2 Step 3b.  Making Source Updates

<a id="HDRLOCLVL"></a>

To make a source update, you must: Generate a source update file that contains your updates. (If you are making a circumventive change, you might obtain this file from IBM.) Generate the new level of the part or object. If needed, rebuild the changed objects.
