#### 4\.8\.4 Rebuild the Load Libraries

<a id="HDRXAVSLOA"></a>

[Table 4\-45](<#TBLXAVSLLS>) lists the AVS load libraries that may need to be rebuilt\.

<a id="TBLXAVSLLS"></a>

```
    ________________________________________________________________________
 | | Table  4-45. AVS Load Libraries                                        |
   |____________________________ ___________________________________________|
 | | Build List                 | libname                                   |
   |____________________________|___________________________________________|
 | | AGWBLUTL                   | AGWUTIL                                   |
   |____________________________|___________________________________________|
 | | AGWBLLIB                   | AGW                                       |
   |____________________________|___________________________________________|
 | | AGWB3LIB                   | AGW370                                    |
   |____________________________|___________________________________________|
```

**1\.** To update the AGWUTIL LOADLIB, enter the following VMFBLD command:

<a id="TBLTBLUNIQ411"></a>

```
 |                                                agwblutl is the build list for the AGWUTIL
 | vmfbld ppf esa avs|avssfs agwblutl (serviced   LOADLIB.
```

**2\.** To update the AGW LOADLIB, enter the following VMFBLD command:

<a id="TBLTBLUNIQ412"></a>

```
 |                                                agwbllib is the build list for the AGW
 | vmfbld ppf esa avs|avssfs agwbllib (serviced   LOADLIB.
```

**3\.** To update the AGW370 LOADLIB, enter the following VMFBLD command:

<a id="TBLTBLUNIQ413"></a>

```
 |                                                agwb3lib is the build list for the AGW370
 | vmfbld ppf esa avs370|avssfs370 agwb3lib (serviLOADLIB.
```

**4\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ415"></a>

```
 |
 | vmfview build
```
