### 1.5.1 Building New Objects

There are three basic build steps that you need to perform after you apply service: Issue VMFBLD with the STATUS option to identify all objects that need to be built, due to the application of service. Issue VMFBLD with the SERVICED option to generate executable objects that need to be built, due to the application of service. Perform post-build tasks for objects that cannot be generated by VMFBLD. VM/ESA provides several functions that support these basic build steps for different parts of the system. The function that is required depends on the type of object being generated and the environment in which it executes.
