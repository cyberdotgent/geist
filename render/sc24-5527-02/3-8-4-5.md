#### 3\.8\.4\.5 Rebuild the Callable Services Libraries \(CSLs\)

<a id="HDRCMSCSL"></a>

[Table 3\-2](<#TBLCSLDSK>) lists the CSLs, and the build lists associated with them\.

<a id="TBLCSLDSK"></a>

```
    ________________________________________________________________________
 | | Table  3-2. CSL Disks                                                  |
   |_________________ __________________ _________________ _________________|
 | | CSL Name        | Build List       | CSLLIB          | Segment         |
 | |                 |                  | Test/Production | Test/Production |
   |_________________|__________________|_________________|_________________|
 | | VMMTLIB         |                  | 490/190         | 490/190         |
 | |                 | DMSBLAEN         |                 |                 |
 | |                 | DMSBLBAS         |                 |                 |
 | |                 | DMSBLVMT         |                 |                 |
   |                 |                  |                 |                 |
   |_________________|__________________|_________________|_________________|
 | | VMLIB           |                  | 490/190         | 493/193         |
 | |                 | CMSSAA           |                 |                 |

 | |                 | DMSBLVMT         |                 |                 |
   |                 |                  |                 |                 |
   |_________________|__________________|_________________|_________________|
```

Use VMFVIEW and the PF5 key to view all status messages and locate message 2180I for any of the objects listed in the build lists from [Table 3\-2](<#TBLCSLDSK>) that have been built\. If any of the objects in the build lists from this table have been built, rebuild the CSL associated with that build list\. If you rebuild both CSLs VMMTLIB and VMLIB, rebuild VMMTLIB first\.

<a id="TBLTBLUNIQ111"></a>

```
 |
 | vmfview build
```

You need to rebuild a CSL only once, no matter how many members have been serviced\.

The VMMTLIB CSLSEG file must be rebuilt anytime its parts are serviced\. Even if VMMTLIB is not saved in a segment, the CMS initialization process uses the VMMTLIB CSLSEG to load the CMS multitasking routines\.

<a id="TBLTBLUNIQ112"></a>

```
 |
 | cslgen seg vmmtlib from vmmtlib (replace to fm2-490
 | cslgen seg vmlib from vmlib (replace to fm2-493

 |                                                Build a CSL that will be loaded into a
 |                                                logical saved segment.  This creates a file
 |                                                called libname CSLSEG.

 |                                                fm2-490 is the file mode of the test disk
 |                                                listed in Table 3-2.  Enter a file mode
 |                                                number of 2.

 |                                                If you rebuilt VMMTLIB then you will see
 |                                                message number DMSLIO202W.  This is not
 |                                                important and can be ignored.

 |
 | cslgen dasd vmmtlib from vmmtlibd (replace to fm2-490
 | cslgen dasd vmlib from vmlib (replace to fm2-490

 |                                                Build a CSL that will be loaded to a
 |                                                minidisk as a MODULE.  This creates a file
 |                                                called libname CSLLIB.

 |                                                fm2-490 is the file mode of the test disk
 |                                                listed in Table 3-2.  Enter a file mode
 |                                                number of 2.

 |                                                For more information about the CSLGEN EXEC,
 |                                                see VM/ESA: CMS Command Reference.
```
