#### 3\.8\.5\.1 Rebuild the HELP Files in Uppercase \(Optional\)

<a id="HDRUPCMS"></a>

If you want serviced HELP files to be uppercase \(for example, NLS purposes\) on the MAINT 402 disk, enter the following commands:

<a id="TBLTBLUNIQ130"></a>

```
                                                  This command will create the UCENG PPF file
   vmfppf uceng cms                               needed to put the HELP files in uppercase.

                                                  This copies all the serviced HELP files to
   vmfbld ppf uceng cms dmsblhlp (serviced setup  the 402 disk and puts them in uppercase.
```
