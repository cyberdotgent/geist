#### 3\.13\.4\.5 Merge Processing

<a id="HDRAVSMRG"></a>

**1\.** Clear the alternate apply disk and move the new service to the intermediate apply disk\. VMFMRDSK will copy the files to the intermediate apply disk and then erase them from the alternate apply disk\. This ensures that service on the intermediate apply disk matches the test build disks \(490 and 493\)\.

<a id="TBLTBLUNIQ253"></a>

```
   vmfmrdsk esa avs|avssfs apply (setup
```

**2\.** Review the merge message log \($VMFMRD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific merge messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>) or use online HELP\.

<a id="TBLTBLUNIQ255"></a>

```
   vmfview merge
```
