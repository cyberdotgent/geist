#### 4\.1\.3 Select and Copy Serviced Files

<a id="HDRXSESCRE"></a>

[Table 4\-3](<#TBLXSESBL>) specifies build lists for VMSES/E that require the select and copy build functions\.

<a id="TBLXSESBL"></a>

```
    ________________________________________________________________________
   | Table  4-3. Build Lists for VMSES/E Select and Copy Functions          |
   |_________________ ____________________________________ _________________|
   | Build List      | Description                        | Test/Production |
   |                 |                                    | Disk            |
   |_________________|____________________________________|_________________|
   | VMFBLSES        | Build list for the 5E6 disk        | 5E6/5E5         |
   |_________________|____________________________________|_________________|
   | VMFBLSYS        | Build list for the S-disk          | 490/190         |
   |_________________|____________________________________|_________________|
 | | VMFBLNON        | Build list for non-VMSES/E files   | 490/190         |
 | |                 | on the S-disk                      |                 |
   |_________________|____________________________________|_________________|
   | VMFBLHLP        | Build list for HELP files.         | 19D/19D         |
   |_________________|____________________________________|_________________|
   | VMFBLSRC        | Build list for source files.       | 493/193         |
   |_________________|____________________________________|_________________|
```

**1\.** Enter the following commands for each build list in [Table 4\-3](<#TBLXSESBL>) that was in the $VMFBLD $MSGLOG\.

<a id="TBLTBLUNIQ287"></a>

```
   vmfbld ppf esa vmses bldlist (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ289"></a>

```
   vmfview build
```
