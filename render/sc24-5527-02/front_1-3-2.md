### FRONT\_1\.3\.2 Additional Changes

Following is a summary of new, changed, and deleted information:

- ***New or changed information:***

Detailed build steps for the COR service procedure have been moved to a separate chapter, since they do not need to be used to service VM/ESA\. By following [Chapter 3, "Using the COR Service](3-0.md) [Procedure" in topic 3\.0](3-0.md), you can build all objects for each component together\. [Chapter 4, "Detailed Component Build Steps"](4-0.md) [in topic 4\.0](4-0.md) is provided for those who would rather build objects individually\.

VM/ESA Control files are provided as an appendix to this book\. They were previously found in the [VM/ESA: VMSES/E Introduction and](<DOCNUM/SC24-5444/CCONTENTS>) [Reference](<DOCNUM/SC24-5444/CCONTENTS>) last release\.

Sample $PPF files are also now found in the appendix of this book\. They were previously found in the [VM/ESA: VMSES/E Introduction and](<DOCNUM/SC24-5444/CCONTENTS>) [Reference](<DOCNUM/SC24-5444/CCONTENTS>) last release\.

- ***Deleted information:***

There is no longer a chapter on processing exceptions for the service procedure\. Improved message text and command capability has eliminated the need for this chapter\. If you need further information when using any VMSES/E commands, refer to the [VM/ESA:](<DOCNUM/SC24-5444/CCONTENTS>) [VMSES/E Introduction and Reference](<DOCNUM/SC24-5444/CCONTENTS>)\.

The appendix on listing CP data areas and control blocks has been removed\. The [VM/ESA: CP Data Areas and Control Blocks](<DOCNUM/LY24-5253/CCONTENTS>) provides this information\.
