#### 4\.4\.5 Rebuild the Executable MODULEs

<a id="HDRXCPEXE"></a>

[Table 4\-23](<#TBLXCPXBL>) describes the build lists used to rebuild executable MODULEs\.

<a id="TBLXCPXBL"></a>

```
        ____________________________________________________________________
       | Table  4-23. Build Lists for Rebuilding Executable MODULEs         |
       |________________ __________________________________ ________________|
       | Build List     | Description                      | Test/Production|
       |                |                                  | Disk           |
       |________________|__________________________________|________________|
       | HCPMLOAD       | Build list for VMFBLD to build   | 490/190        |
       |                | CP MODULEs on the system disk.   |                |
       |________________|__________________________________|________________|
       | HCPXLOAD       | Build list for VMFBLD to build   | 493/193        |
       |                | CP MODULEs on the system tools   |                |
       |                | disk.                            |                |
       |________________|__________________________________|________________|
```

**1\.** For each build list in [Table 4\-23](<#TBLXCPXBL>) that has MODULEs that have been serviced, enter the VMFBLD command to rebuild the serviced MODULEs:

<a id="TBLTBLUNIQ348"></a>

```
                                                  bldlist is the file name of one of the
   vmfbld ppf esa cp bldlist (serviced            build lists from Table 4-23.
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ350"></a>

```
   vmfview build
```
