#### 6.3.4 Determine All Parts Serviced By a Specific APAR

The version vector table consists of the list of PTFs, APARs and optionally updates that are applied to the part of a component at a specific level. To determine all parts affected by an APAR you would query the version vector table as shown as below.

<a id="TBLTBLUNIQ446"></a>

| VMFSIP2480I RESULTS FOR | TDATA :PTF VM47103 |
| --- | --- |


**Field** **Data** **Definition** **:****PART** This field contains the file name and the 3 character file type abbreviation used for a serviced part. **:****PTF** This field contains a list of PTFs that have been applied against the part. The left most entry in the list is the last PTF that was applied to the part and the right most entry is the first PTF that was applied. following each PTF number are a number of qualifiers that identify the APAR that was contained in the PTF and optionally the file type of a source update that was shipped for the part. If the letter 'M' is found following the APAR number, this identifies that the PTF/APAR identified has been merged into the base source file shipped for the part, for example, ASSEMBLE or $EXEC file.
