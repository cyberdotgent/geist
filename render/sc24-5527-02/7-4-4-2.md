#### 7\.4\.4\.2 Removing a Patch

To remove a patch:

**1\.** XEDIT the AUX file that contains the patch and comment out the patch entry\. Add a comment in the AUX file that explains why you are removing the patch\. This comment is added to the nucleus map\.

**2\.** Rebuild the nucleus or module\. Use the procedure in the build step in [Chapter 3, "Using the COR Service Procedure" in topic 3\.0](3-0.md) for the affected component\.
