#### 4\.7\.3 Select and Copy Serviced Files

<a id="HDRXTSFCRE"></a>

[Table 4\-39](<#TBLXTSFBL>) contains build lists for TSAF that require the select and copy build functions\.

<a id="TBLXTSFBL"></a>

```
    ________________________________________________________________________
   | Table  4-39. Build Lists for TSAF Select and Copy Functions            |
   |_________________ ____________________________________ _________________|
   | Build List      | Description                        | Test/Production |
   |                 |                                    | Disk            |
   |_________________|____________________________________|_________________|
   | ATSBLHLP        | Build list for HELP files.         | 19D/19D         |
   |_________________|____________________________________|_________________|
   | ATSBLSRC        | Build list for new/replacement     | 493/193         |
   |                 | source files.                      |                 |
   |_________________|____________________________________|_________________|
   | ATSBLINF        | Build list for TSAF/Dump Viewing   | 493/193         |
   |                 | Facility interface files.          |                 |
   |_________________|____________________________________|_________________|
   | ATSBLMES        | Build list for message text files  | 493/193         |
   |_________________|____________________________________|_________________|
```

**1\.** Enter the following command for each build list in [Table 4\-39](<#TBLXTSFBL>) that ws in the $VMFBLD $MSGLOG\.

<a id="TBLTBLUNIQ398"></a>

```
   vmfbld ppf esa tsaf|tsafsfs bldlist (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. Form information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ400"></a>

```
   vmfview build
```
