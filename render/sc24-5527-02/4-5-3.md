#### 4\.5\.3 Select and Copy Serviced Files

<a id="HDRXGCSCRE"></a>

[Table 4\-29](<#TBLXGCSBL>) contains build lists for GCS that require the select and copy build functions\.

<a id="TBLXGCSBL"></a>

```
    ________________________________________________________________________
   | Table  4-29. Build Lists for GCS Select and Copy Functions             |
   |_________________ ____________________________________ _________________|
   | Build List      | Description                        | Test/Production |
   |                 |                                    | Disk            |
   |_________________|____________________________________|_________________|
   | GCTBLHLP        | Build list for HELP files.         | 19D/19D         |
   |_________________|____________________________________|_________________|
   | GCTBLRST        | Build list for miscellaneous GCS   | 493/193         |
   |                 | files                              |                 |
   |_________________|____________________________________|_________________|
   | GCTBLINF        | Build list for GCS/Dump Viewing    | 493/193         |
   |                 | Facility interface files.          |                 |
   |_________________|____________________________________|_________________|
```

**1\.** Enter the following command for each build list in [Table 4\-29](<#TBLXGCSBL>) that was in the $VMFBLD $MSGLOG\.

<a id="TBLTBLUNIQ366"></a>

```
   vmfbld ppf esa gcs|gcssfs bldlist (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ368"></a>

```
   vmfview build
```
