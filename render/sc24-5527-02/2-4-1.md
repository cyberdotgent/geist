### 2\.4\.1 Receiving Only PTFs from an RSU Tape

<a id="HDRRECPTF"></a>

**1\.** Generate the ESAPTFS PPF file for the component to insure you have the most current level of PPF file: If you have made your own overrides, be sure to incorporate those in the ESAPTFS PPF file\. For information on how to do this, see the [VM/ESA: VMSES/E Introduction and Reference](<DOCNUM/SC24-5526/CCONTENTS>)\.

<a id="TBLTBLUNIQ35"></a>

```
   vmfppf esaptfs compname
```

**2\.** To receive **only** PTFs from the RSU Tape and not the tape files containing the preapplied and prebuilt objects issue the following command:

<a id="TBLTBLUNIQ36"></a>

```
 |                                                Enter the VMFINS command to receive only
 | vmfins install ppf esaptfs compname (nomemo nolthe PTFs for the selected component.

 |
 | VMFREQ2805I Product prodid component compname passed requisite checking
 |             Do You want to create override for ESA compname (prodid prodid)?
 |             Enter 0(NO), 1(YES), or 2(EXIT).
 | 0

 |                                                Enter 0 since an override file is not
 |                                                required.
```

You have now completed the receive of the service files from the VM/ESA RSU Tape for the selected component\. To apply and build the component, use the COR procedure starting at the Apply Service task for the component you are servicing\.
