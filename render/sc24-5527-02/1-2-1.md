### 1\.2\.1 Merging Service

Use the VMFMRDSK command to clear the alternate apply disk before receiving new service\. This allows you to easily remove the new service if a serious problem is found\.

Also, the VMFMRDSK command is used to merge all service to the production delta and apply disks after the new service has been put into production\. For more information about the VMFMRDSK command, see the [VM/ESA: VMSES/E](<DOCNUM/SC24-5444/CCONTENTS>) [Introduction and Reference](<DOCNUM/SC24-5444/CCONTENTS>)\.
