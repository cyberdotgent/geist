#### 4\.2\.4 Update the Macro Libraries \(MACLIBs\)

<a id="HDRXREXMAC"></a>

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | If you already updated the MACLIBs as part of reapplying local service |
   | earlier in this component step, skip this step, and go to "Rebuild the |
   | Nuclei" in topic 4.2.5.                                                |
   |                                                                        |
   |________________________________________________________________________|
```

[Table 4\-9](<#TBLXREXMC>) lists the REXX/VM MACLIB that may need to be rebuilt\.

<a id="TBLXREXMC"></a>

```
    ________________________________________________________________________
 | | Table  4-9. REXX/VM Maclib                                             |
   |_________________ ____________________________________ _________________|
 | | MACLIB          | Description                        | Text/Production |
 | | (bldlist)       |                                    |                 |
   |_________________|____________________________________|_________________|
 | | IXXOM           | Build list for the IXXOM MACLIB.   | 490/190         |
   |_________________|____________________________________|_________________|
```

**1\.** Enter VMFBLD to rebuild the IXXOM MACLIB\.

<a id="TBLTBLUNIQ301"></a>

```
                                                  ixxom is the name of the MACLIB from
   vmfbld ppf esa rexx ixxom (serviced            Table 4-9.
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ303"></a>

```
 |
 | vmfview build
```
