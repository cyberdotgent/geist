### 2\.3\.2 Process Additional Service

<a id="HDRSERVADD"></a>

**1\.** Apply additional service:

The VMFAPPLY command is used to reapply service that was not contained on the refresh tape that was already installed for the component\.

<a id="TBLTBLUNIQ30"></a>

```
                                                  Messages VMFAPP2122E and VMFAPP2109R will
   vmfapply ppf esa compname (setup               be displayed only if you have reach-ahead
                                                  service that needs to be reapplied.

   VMFAPP2122E THE SET OF PTFS IN THE APPLY STATUS TABLE (6VMVMA20 SRVAPPS ) ON THE
               3A4 (H) DISK IS NOT A SUBSET OF THE PTFS IN THE HIGHEST LEVEL APPLY
               STATUS TABLE ON THE 3A6 (G) DISK. THIS IS AN INCONSISTENT STATE
   VMFAPP2109R VMFAPPLY WILL AUTOMATICALLY CORRECT THE PROBLEM IDENTIFIED BY
               MESSAGE 2122E BY INCLUDING THE MISSING PTFS IN THE CURRENT APPLY
               LIST. ENTER (1) TO CONTINUE; (0) TO QUIT.
   1

                                                  If you receive these messages, enter 1 for
                                                  VMFAPPLY to reapply the reach-ahead
                                                  service.
```

**2\.** Check the apply message log \($VMFAPP $MSGLOG\) for warning and error messages\.

<a id="TBLTBLUNIQ31"></a>

```
   vmfview apply
```

**3\.** Reapply ***all*** local service:

If you have any local modification or APAR fixes \(not in VMSES/E format\) for the component, go to [Chapter 7, "Installing Local](7-0.md) [Service,"](7-0.md) and use ["Step 3\. Apply Local Service" in topic 7\.4](7-4.md) to reapply all local service\.
