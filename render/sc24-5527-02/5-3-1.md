#### 5.3.1 Querying the Status of Products or Components Built

The SYSBLDS table contains the status of all the products or components that are built on the system. To determine the build status of all the product(s) or component(s) installed on the system the following VMFSIM command would be used.

<a id="TBLTBLUNIQ424"></a>

| vmfsim query vm sysblds * tdata :ppf :stat | VMFSIP2480I RESULTS FOR |
| --- | --- |
| TDATA :PPF :STAT | :PPF UCENG CMS :STAT BUILT.09/16/92.13:36:29.MAINT<br>:PPF UCENG CP :STAT BUILT.09/16/92.14:11:45.MAINT |


**Field** **Data** **Definition** **:****PPF** This field contains the file name of the PPF that was used to install the product or component and the component name in the PPF that was used. **:****STAT** This field contains the status of the product or component followed by a number of qualifiers that identify the date and time the product or component was built and the user ID used to build the product or component.
