#### 3\.11\.4\.4 Rebuild the HELP Files in Uppercase \(Optional\)

<a id="HDRUPDVF"></a>

If you want serviced HELP files to be uppercase \(for example, NLS purposes\) on the MAINT 402 disk, enter the following commands:

<a id="TBLTBLUNIQ210"></a>

```
                                                  This command will create the UCENG PPF file
   vmfppf uceng dv                                needed to put the HELP files in uppercase.

                                                  This copies all the serviced HELP files to
   vmfbld ppf uceng dv hcsblhlp (serviced setup   the 402 disk and puts them in uppercase.
```
