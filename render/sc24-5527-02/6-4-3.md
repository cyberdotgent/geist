#### 6\.4\.3 Determine What Objects Require Manual Build Processing

The Build Status table has a list of objects that have been serviced for the component\. If VMFBLD can not locate a part that has been serviced it will update the SRVBLDS table with a status of MANUAL for the part\. To determine what parts required manual processing after service has been applied the VMFSIM QUERY command would be issued against the SRVBLDS table searching for objects with a status of MANUAL\. These are the objects that need to be built that require special manual intervention if they are serviced\.

<a id="TBLTBLUNIQ453"></a>

```
   vmfsim query tblfn srvblds * tdata :stat manual :partid
   VMFSIP2480I RESULTS FOR
               TDATA :STAT MANUAL :PARTID
 | :BLDLIST UNKNOWN
 |    :OBJECT BLDLIST
      :STAT MANUAL.09/16/92.12:27:53.MAINT
      :PARTID HCPABC TXT
```

The query returns the following data:

**Field Data Definition**

**:BLDLIST** This field contains the keyword UNKNOWN\. This indicates that the parts identified on the :PARTID tag were not found in any build lists identified in the PPF file\.

**:OBJECT** This field contains the keyword BLDLIST\.

**:STAT** This field contains the status MANUAL followed by a number of qualifiers that identify the date and time the parts identified were processed by VMFBLD and the user ID used\. Because MANUAL was specified as a search argument only those SRVBLDS entries that have this status were returned\.

**:PARTID** This field contains a list of the file name and file type of parts that require manual build processing\.
