#### 6\.3\.3 Determine All Parts Serviced by a Specific PTF

The version vector table consists of the list of PTFs, APARs and optionally updates that are applied to the part of a product or component at a specific level\. To determine all parts affected by a PTF you would query the version vector table as shown as below\.

<a id="TBLTBLUNIQ445"></a>

```
   vmfsim query tblfn vvtvm * tdata :ptf um18135
   VMFSIP2480I RESULTS FOR
               TDATA :PTF UM18135
   :PART HCPXLF TXT
      :PTF UM18135.VM47105.R47105HP
   :PART HCPXLE TXT
      :PTF UM18135.VM47105.R47105HP
   :PART HCPVDI TXT
      :PTF UM18135.VM47105.R47105HP
   :PART HCPREP TXT
      :PTF UM18135.VM47105.R47105HP
   :PART HCPPTU TXT
      :PTF UM18135.VM47105.R47105HP
   :PART HCPMPS TXT
      :PTF UM18135.VM47105.R47105HP
```

The query returns the following data:

**Field Data Definition**

**:PART** This field contains the file name and the 3 character file type abbreviation used for a serviced part\.

**:PTF** This field contains a list of PTFs that have been applied against the part\. The left most entry in the list is the last PTF that was applied to the part and the right most entry is the first PTF that was applied\. Following each PTF number are a number of qualifiers that identify the APAR that was contained in the PTF and optionally the file type of a source update that was shipped for the part\. If the letter 'M' is found following the APAR number, this identifies that the PTF/APAR identified has been merged into the base source file shipped for the part, for example, ASSEMBLE or $EXEC file\.
