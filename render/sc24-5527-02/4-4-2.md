#### 4\.4\.2 Determine which Build Lists Need to be Processed

<a id="HDRXCPBST"></a>

**1\.** To determine which build steps to perform, enter the following command:

<a id="TBLTBLUNIQ341"></a>

```
   vmfview build

                                                  This command will display the names of all
                                                  objects that need to be built.
```
