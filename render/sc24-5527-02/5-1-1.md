#### 5.1.1 Querying the Status of Products or Components Received

The SYSRECS table contains a list of all products or components that are received on the system. To query the status of all products or components installed enter the following VMFSIM command:

<a id="TBLTBLUNIQ419"></a>

|

| \| :PPF ESAINS VMSES * \| :STAT RECEIVED.09/16/92.09:16:01.MAINT.200-9301 | \| :PPF ESAINS CP ) \| :STAT RECEIVED.09/16/92.09:51:48.MAINT.200-9301 | \| :PPF ESAINS DV $ \| :STAT RECEIVED.09/16/92.10:06:18.MAINT.200-9301 |
| --- | --- | --- |


**Field** **Data** **Definition** **:****PPF** This field contains the file name of the PPF that was used to install the product or component, and the component name in the PPF that was used. **:****STAT** This field contains the status of the product or component, followed by a number of qualifiers that identify the date and time that it was received, the user ID used to receive it, and the | service level when it was installed. In this example, the 9301 is | the RSU service level.
