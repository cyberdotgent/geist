## C\.3 Rebuild the GCS Nucleus

<a id="HDRNLSGCS"></a>

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Parts of the REXX/VM component are contained in the GCS nucleus.  You  |
   | must receive and apply REXX/VM service (if any) before you rebuild the |
   | GCS nucleus.                                                           |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Set up the correct machine environment\.

<a id="TBLTBLUNIQ530"></a>

```
                                                  The machine needs to be set to XA to build
   set machine xa                                 a GCS nucleus.

                                                  nnnn must be at least as large as the value
   def storage nnnnM                              you defined for HIGH COMMON END storage
                                                  during the installation procedures.  The
                                                  default is 18M, unless you have changed it.
                                                  For more information, see VM/ESA:
                                                  Installation Guide.
```

<a id="TBLTBLUNIQ532"></a>

```
   ipl 190 clear
```

**2\.** Set up the correct minidisk order:

<a id="TBLTBLUNIQ533"></a>

```
 | vmfsetup ppfname gcs|gcssfs
```

**3\.** Make any other changes that you want to include in the nucleus, such as changes to the GCS configuration file using the GROUP EXEC\. For more information, see [VM/ESA: Installation Guide](<DOCNUM/SC24-5526/CCONTENTS>)\.

**4\.** Build the nucleus\.

<a id="TBLTBLUNIQ535"></a>

```
                                                  Direct the output of the virtual printer
   spool prt *                                    and punch to your virtual reader.
   spool pun *

                                                  gctload is the build list for the GCS
 | vmfbld ppf ppfname gcs|gcssfs gctload (all     nucleus.  If you are not using the default,
                                                  substitute your nucleus name for gctload.

                                                  The punch file containing the nucleus is
   SYSTEM LOAD DECK COMPLETE                      spooled to your reader.  Record the spool
   PUN FILE spoolid TO MAINT COPY 001 NOHOLD      file ID from this message, as it will be
                                                  used to save the nucleus in the saved
                                                  segment.
```

**5\.** Check the results of the build\. Use VMFVIEW to examine the $VMFBLD $MSGLOG file to verify that the correct levels of the text decks were loaded into the nucleus\.

<a id="TBLTBLUNIQ536"></a>

```
   vmfview build
```

**6\.** Make the file that contains the new nucleus the first file in your reader and IPL the new nucleus\.

<a id="TBLTBLUNIQ537"></a>

```
                                                  Give the nucleus a keep status.  This
   order rdr spoolid                              allows the nucleus to be IPLed again
   change reader spoolid keep                     without having to rebuild it in case a
                                                  problem occurs when IPLing from the reader.

   ipl 00c clear                                  Save the nucleus in your saved segment.

                                                  This message indicates that your nucleus
   NAMED SAVED SYSTEM (NSS) GCS                   was successfully saved.
   WAS SUCCESSFULLY SAVED IN FILEID 0100

                                                  Record the spool file ID from this message.
   RDR FILE spoolid SENT FROM MAINT               It identifies the file containing the
                                                  nucleus load map that was spooled to your
                                                  virtual reader.

                                                  Restore your CMS environment.
   ipl 190 clear
```

**7\.** Save the load map on the test system tools disk\.

<a id="TBLTBLUNIQ538"></a>

```
   access 493 e
   receive spoolid gcsnuc map e (olddate replace
 | copyfile gcsnuc map e = = = (replace pack
   release e

                                                  spoolid is the spool file ID of the GCS
                                                  load map that was sent to your reader when
                                                  you built the GCS nucleus.
```

```
   | You have now finished the detailed build steps for GCS.  Go to         |
   | "Rebuild the HELP Files in Uppercase (Optional)" in topic 3.10.4.5 and |
   | complete the rest of the service steps for this component.             |
   |                                                                        |

```
