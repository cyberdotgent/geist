### 8\.1\.1 Removing the Current Service Level after It Has Been Built

If you want to back out the current service level and use only the previous test service level, you must perform the following steps\.

**1\.** Access the service disks required for the component using the VMFSETUP command\.

<a id="TBLTBLUNIQ493"></a>

```
   vmfsetup esa compname
```

**2\.** Copy all $SELECT files from the current service disk to the test service disk\. The $SELECT file will be used by VMFBLD to identify all objects in the component that need to be rebuilt\.

<a id="TBLTBLUNIQ494"></a>

```
   copyfile * $select fm-applyalt = = fm-applyint (olddate replace
```

**3\.** Create a PPF override called ESATEST $PPF that will remove the alternate apply disk from the MDA section\. See the [VM/ESA: VMSES/E](<DOCNUM/SC24-5444/CCONTENTS>) [Introduction and Reference](<DOCNUM/SC24-5444/CCONTENTS>) for details on creating PPF overrides\.

<a id="TBLTBLUNIQ496"></a>

```
   vmfppf esatest compname
```

**4\.** Follow the build steps identified in [Table 7\-4 in topic 7\.5](<#TBLBUILDS>) for the component being processed\. After all build steps have been completed for the component all service that was on the current disk will have been removed\.

If you get the following message during build processing, you must create the base level of the object indicated in the message\.

`VMFBDC2074I OBJECT` *objname* `WAS NOT BUILT BECAUSE IT HAS NEVER BEEN SERVICED`

This can be done in one of the following ways:

- Generate the base level \(no service\) of the part, if it is source maintained, by running VMFHASM for an assemble file, or EXECUPDT for a $ source file, and copy it to the build disk\.
- Load the base level of the part to the build disk from a backup tape containing the object before it was serviced\.
