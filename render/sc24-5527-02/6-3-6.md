#### 6.3.6 Determine the Current Level of a Part

The GETLVL function finds the Current Level of a part using a control file and the version vector tables and optionally AUX files. To determine the current service level of specific part you would issue the VMFSIM GETLVL function specifying the file name of the version vector table and the file name of the control file for the product or component as shown as below.

<a id="TBLTBLUNIQ448"></a>

[Table: TBLTBLUNIQ448]

**File** **Name** **File** **Type** **File** **Name** The first token returned is the file name of the part that was specified on the command.

**File** **Type** The second token is the file type of the part at the highest

service level found in the version vector table. This is determined by locating the last PTF that was applied to the part and appending the 5 character PTF number to the 3 character file type abbreviation for the part. If NO service is found for the part the file type will be returned as 5 question marks ' ' appended to the 3 character file type abbreviation.

**Note:** The GETLVL function does not check for existence of the level found. This would be done by using the state command on the data returned from GETLVL.
