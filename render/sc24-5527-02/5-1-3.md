#### 5.1.3 Determining Product or Component Requisites

Use the SYSREQ function with the system requisite table and system apply status table to return the requisites for the PRODIDs specified. This function would be used to determine if you have all the product or component installed on your system that are required by a product or component you want to install.

<a id="TBLTBLUNIQ421"></a>

[Table: TBLTBLUNIQ421]

**Field** **Data** **Definition** **:****PRODID** This field contains the name of the product or component that was processed. **:****PREREQ** This field contains a list of the product or component, that must be installed before installing this product or component. **:****REQ** This field contains a list of the product or component, that must be installed before running this product or component. :DREQ This field contains **a** **list** of the product or component, that this product or component is a dependent feature of. **:****SUP** This field contains a list of the product or component, that this product or component supersedes, or is a functional replacement of. **:****IFREQ** This field contains a list of the products or components that are required, if the product or component identified in the condition is installed. **:****NPRE** This field contains a list of the products or components that can not be installed if this product or component is installed. **:****SUBREQ** This field contains a list of the product or component that are required to be installed by the requisites identified above. **:****SUBIF** This field contains a list of the product or component, that are required to be installed by the requisites identified above if the product or component identified in the condition is installed. **:****PTFREQS** This field identifies PTFs that must be installed to products or components that are requisites.
