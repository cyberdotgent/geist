## 3.4 Step 2.  Receive the Service Documentation

<a id="HDRPCDOC"></a>

Note This step describes how to receive service documentation from a service tape. If you have received service from ServiceLink that now resides on disk, use [Appendix A, "Receiving COR Service from](a-0.md) [ServiceLink"](a-0.md) to receive service documentation, instead of this step. **1.** Attach a tape drive to your virtual machine (MAINT).

<a id="TBLTBLUNIQ39"></a>

[Table: TBLTBLUNIQ39]

**2.** Mount and ready the COR tape. **3.** If you are receiving service for licensed programs or features, read the product's MEMO or product documentation for procedures to use for service. and skip the rest of the steps in this chapter. **4.** Receive the documentation. VMFREC with the INFO option loads the documentation and displays a list of all products on the tape.

<a id="TBLTBLUNIQ40"></a>

[Table: TBLTBLUNIQ40]

**5.** Check the receive message log ($VMFREC $MSGLOG) for warning and error messages. If necessary, correct any problems before going on. For <BOOK> <> <> <SC24-5529> <ANY> [<HCPC0>](#LNK) information about handling specific receive messages, see VM/ESA: <BOO [K> <> <> <SC24-5529> <ANY](#LNK)> <HCPC0> System Messages and Codes, or use on-line HELP.

<a id="TBLTBLUNIQ42"></a>

[Table: TBLTBLUNIQ42]

**6.** Read the product memo(s) (*prodid* MEMO) before going on. These memos are loaded to the C-disk if it is accessed R/W; otherwise, the memos are loaded to the A-disk which is accessed R/W in ["Step 1. Prepare](3-3.md) [Disks for Service" in topic 3.3](3-3.md).
