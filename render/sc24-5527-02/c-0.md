# C\.0 Appendix C\. Changing System National Language including UCENG

<a id="HDRNLS"></a>

To change the default system language for CP, CMS or GCS you must rebuild the CP, CMS or GCS nuclei to contain the national language files for the language desired\. The following table identifies the national languages supported by CP and CMS and the $PPF \(Product Parameter File\) used to build the new nuclei\. Currently, GCS only supports UCENG\.

<a id="TBLNLSFIL"></a>

```
    ________________________________________________________________________
   | Table  C-1. National Language $PPF files                               |
   |____________________________________ ___________________________________|
   | ppfname $PPF File                  | National Language                 |
   |____________________________________|___________________________________|
   | KANJI                              | Kanji                             |
   |____________________________________|___________________________________|
   | UCENG                              | Uppercase English                 |
   |____________________________________|___________________________________|
   | FRANC                              | French                            |
   |____________________________________|___________________________________|
   | GER                                | German                            |
   |____________________________________|___________________________________|
   | ESPAN                              | Spanish                           |
   |____________________________________|___________________________________|
   | HANZI                              | Chinese Simplified                |
   |____________________________________|___________________________________|
   | CANFR                              | Canadian French                   |
   |____________________________________|___________________________________|
```

Before building the CP, CMS or GCS nuclei, the PPF file must be created for the language\. This is done using the VMFPPF command\.

<a id="TBLTBLUNIQ506"></a>

```
 |                                                Enter the VMFPPF command for CP, CMS or
 | vmfppf ppfname cp|cms|gcs|gcssfs               GCS.
```

After the PPF file is created, the CP, CMS or GCS nucleus needs to be rebuilt\. To rebuild the CMS nucleus see ["Rebuild the CMS Nucleus" in](c-1.md) [topic C\.1](c-1.md)\. To rebuild the CP nucleus see ["Rebuild the CP Nucleus" in](c-2.md) [topic C\.2](c-2.md)\. To rebuild the GCS nucleus see ["Rebuild the GCS Nucleus" in](c-3.md) [topic C\.3](c-3.md)\.

To add an optional language to your system, use the LANGMERG or LANGGEN commands\. For more information, see the [VM/ESA: Installation Guide](<DOCNUM/SC24-5526/CCONTENTS>) and the [VM/ESA: CMS Command Reference](<DOCNUM/SC24-5461/CCONTENTS>)\.
