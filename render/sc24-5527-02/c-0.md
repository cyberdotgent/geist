# C.0 Appendix C.  Changing System National Language Including UCENG

<a id="HDRNLS"></a>

To change the default system language for CP, CMS or GCS you must rebuild | the CP, CMS or GCS nuclei to contain the national language files for the | language desired. The following table identifies the national languages | supported by CP and CMS and the $PPF (Product Parameter File) used to | build the new nuclei. Currently, GCS only supports UCENG.

<a id="NLSFIL"></a>

Table C-1. National Language $PPF files

| ppfname $PPF File | National Language |
| --- | --- |
| KANJI | Kanji |
| UCENG | Uppercase English |
| FRANC | French |
| GER | German |
| ESPAN | Spanish |
