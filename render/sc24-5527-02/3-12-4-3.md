#### 3\.12\.4\.3 Build Serviced Objects

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Use the remainder of this step to build all TSAF objects that were     |
   | serviced.  If you prefer to build TSAF objects individually, then use  |
   | "Detailed Build Steps: TSAF" in topic 4.7 instead of the rest of this  |
   | step.                                                                  |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** To rebuild all serviced parts, enter the following command:

<a id="TBLTBLUNIQ228"></a>

```
   vmfbld ppf esa tsaf|tsafsfs (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ230"></a>

```
   vmfview build
```
