### 2\.3\.1 Receive the Preapplied, Prebuilt Service

<a id="HDRRECRFP"></a>

**1\.** Refresh the selected components' service disks by loading new service from the RSU Tape:

<a id="TBLTBLUNIQ29"></a>

```
   vmfins install ppf esa compname (nomemo nolink

 |
 | VMFREQ2805I Product prodid component compname passed requisite checking
 |             Do You want to create override for ESA compname (prodid prodid)?
 |             Enter 0(NO), 1(YES), or 2(EXIT).
 | 0

 |                                                Enter 0 since an override file is not
 |                                                required.
```

You have now completed the receive of the service files from the VM/ESA RSU Tape for the selected component\. Continue with the next task ["Process Additional Service" in topic 2\.3\.2](2-3-2.md)\.

**Note:** If any new or changed HELP files are loaded to the 19D disk, the HELP saved segment needs to be rebuilt\. You will perform this task when you have serviced all components and need to place the service into production\.
