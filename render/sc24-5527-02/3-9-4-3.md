#### 3\.9\.4\.3 Save the CP Load Map

<a id="HDRLODMP"></a>

**1\.** Access the test system tools disk \(493\)\. The CP load map file \(CPLOAD MAP\) is on MAINT's 191 disk\.

<a id="TBLTBLUNIQ153"></a>

```
 |
 | copyfile cpload map a cpload map fm-493 (replace pack
 | erase cpload map a
```

**2\.** If desired, print a copy of the CP load map\.

**3\.** Examine the load map for unresolved or undefined symbols\. Unresolved or undefined symbols sometimes, but not always, indicate an error\. Make sure that you understand the reason for any unresolved symbols you find before going on\.

<a id="TBLTBLUNIQ154"></a>

```
 |                                                This response means that no unresolved
 | xedit cpload map                               symbols were found.
 | set case mixed ignore
 | ====> all /unresol/
 | DMSXDC546E Target not found

 |                                                This response means that no undefined
 | ====> all /undefin/                            symbols were found.
 | DMSXDC546E Target not found

 |
 | ====> qquit
```
