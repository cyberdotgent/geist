#### 4\.6\.5 Process the Segment Build List

<a id="HDRXDVFHP"></a>

This step updates the build status **only**\. The actual build of the segment is performed during the task ["Step 12\. Placing Your Serviced Components](3-14.md) [into Production" in topic 3\.14](3-14.md)\.

<a id="TBLXDVFHL"></a>

```
    ________________________________________________________________________
 | | Table  4-35. Build List for Processing the Dump Viewing Facility       |
 | |              Segment Build List                                        |
   |_______________________ ________________________________________________|
 | | Build List            | Description                                    |
   |_______________________|________________________________________________|
 | | HCSSBHLP              | Build list for Dump Viewing Facility files     |
 | |                       | that reside on the HELP segment                |
   |_______________________|________________________________________________|
```

**1\.** Enter the following command to process the HELP segment:

<a id="TBLTBLUNIQ394"></a>

```
 |
 | vmfbld ppf esa dv hcssbhlp (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | You have now finished the detailed build steps for Dump Viewing        |
   | Facility.  Go to "Rebuild the HELP Files in Uppercase (Optional)" in   |
   | topic 3.11.4.4 and complete the rest of the service steps for this     |
   | component.                                                             |
   |                                                                        |
   |________________________________________________________________________|
```
