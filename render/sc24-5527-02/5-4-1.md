#### 5.4.1 Determining Default PPFs for Products or Components

The fn PRODPART table contains a list of the default PPFs and their descriptions for Products or Components. To determine all the default PPFs shipped with a product or component the following VMFSIM command would be used.

<a id="TBLTBLUNIQ425"></a>

| VMFSIP2480I RESULTS FOR | TDATA :PPF :DE |
| --- | --- |
| :PRODID 6VMVMB20 |  |


**Field** **Data** **Definition** **:****RECID** This field contains the 7 or 8 character identifier used to locate the product or component on the installation tape. **:****LU** This field contains no data. It is used to identify the start of a block of tags defining the different loadable units contained on the installation tape for the product or component. **:****PPF** This field contains the file name of a default PPF that can be used to install the product or component and the component name in the PPF that represents a specific loadable unit. **:****PRODID** This field contains a unique identifier that is used to define a specific loadable unit. **:****DESC** This field contains a short description of the loadable unit in the product or component. **:****ELU** This field contains no data. It is used to identify the end of a block of tags defining the different loadable units contained on the installation tape for the product or component.
