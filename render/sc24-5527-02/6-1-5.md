#### 6.1.5 Determine Dependent PTFs

Use the

function with the service requisite table and service apply status table to return the dependents for the PTFs specified. Use this function to determine what PTFs are dependent on a specific PTF that you want to remove from the product or component. By definition, a dependent PTF is applied.

<a id="TBLTBLUNIQ437"></a>

[Table: TBLTBLUNIQ437]

function returns the following data:

**Field** **Data** **Definition** **:****PTF** This field contains the PTF number being processed. **:****DEPS** This field contains a list of the PTFs that are dependent on the PTF specified. **:****SUPBY** This field contains a list of the PTFs that supersede this PTF. **:****OUTREQS** This field contains a list of the PTFs in another product or component that are dependent on the PTF specified.
