## 7\.5 Step 4\. Rebuilding Objects

<a id="HDRLOCBLD"></a>

Whenever you generate a new level of a part or object as the result of applying a source update, patch, or zap, removing a PTF, or for any other reason, you must rebuild any object that contains the changed file\.

Go to the build section for the component you are processing and complete that section\. Use the following table to find the appropriate build section\.
