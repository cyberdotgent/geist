### 1\.6\.1 Using the Online HELP Facility

You can receive online information about VMSES/E commands using the VM/ESA\* HELP Facility\. For example, to display a menu of VMSES/E commands, enter:

`help vmses menu`

To display information about a specific VMSES/E command \(VMFREC in this example\), enter:

`help vmses vmfrec`

For more information about using the HELP Facility, see the [VM/ESA: CMS](<DOCNUM/SC24-5460/CCONTENTS>) [User's Guide](<DOCNUM/SC24-5460/CCONTENTS>)\. To display the main HELP Task Menu, enter:

`help`

For more information about the HELP command, see the [VM/ESA: CMS Command](<DOCNUM/SC24-5461/CCONTENTS>) [Reference](<DOCNUM/SC24-5461/CCONTENTS>) or enter:

`help cms help`
