#### 3\.10\.4\.3 Build Serviced Objects

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Use the remainder of this step to build all GCS objects that were      |
   | serviced.  If you prefer to build GCS objects individually, then use   |
   | "Detailed Build Steps: GCS" in topic 4.5 instead of the rest of this   |
   | step.                                                                  |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** To rebuild all serviced parts, enter the following command:

<a id="TBLTBLUNIQ181"></a>

```
   vmfbld ppf esa gcs|gcssfs (serviced
```

**2\.** Use VMFVIEW to review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages](<DOCNUM/SC24-5529/CCONTENTS>) [and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use on\-line HELP\.

<a id="TBLTBLUNIQ183"></a>

```
   vmfview build
```
