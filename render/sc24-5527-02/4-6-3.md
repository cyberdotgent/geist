#### 4\.6\.3 Select and Copy Serviced Files

<a id="HDRXDVFCRE"></a>

[Table 4\-34](<#TBLXDVFBL>) contains build lists for Dump Viewing Facility that require the select and copy build functions\.

<a id="TBLXDVFBL"></a>

```
    ________________________________________________________________________
   | Table  4-34. Build Lists for Dump Viewing Facility Select and Copy     |
   |              Functions                                                 |
   |_________________ ____________________________________ _________________|
   | Build List      | Description                        | Test/Production |
   |                 |                                    | Disk            |
   |_________________|____________________________________|_________________|
   | HCSBLPPF        | Build list for PPF-related         | 493/193         |
   |                 | replacement parts.                 |                 |
   |_________________|____________________________________|_________________|
   | HCSBLHLP        | Build list for HELP files.         | 19D/19D         |
   |_________________|____________________________________|_________________|
   | HCSBL493        | Build list for EXEC/XEDIT/etc.     | 493/193         |
   |                 | files for the 493/193 disks.       |                 |
   |_________________|____________________________________|_________________|
   | HCSBLMSG        | Build list for text files for the  | 493/193         |
   |                 | 493/193 disks                      |                 |
   |_________________|____________________________________|_________________|
   | HCSBLSRC        | Build list for source files.       | 493/193         |
   |_________________|____________________________________|_________________|
```

**1\.** Enter the following command for each build list in [Table 4\-34](<#TBLXDVFBL>) that was in the $VMFBLD $MSGLOG\.

<a id="TBLTBLUNIQ388"></a>

```
   vmfbld ppf esa dv bldlist (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ390"></a>

```
   vmfview build
```
