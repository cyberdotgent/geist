#### 4\.3\.5 Rebuild the Text Libraries

<a id="HDRXCMSCTX"></a>

[Table 4\-14](<#TBLXCMSTLB>) describes the build lists used to rebuild the CMS TXTLIBs\.

<a id="TBLXCMSTLB"></a>

```
    ________________________________________________________________________
 | | Table  4-14. CMS TXTLIBs                                               |
   |_________________ ____________________________________ _________________|
 | | TXTLIB          | Description                        | Test/Production |
 | | (bldlist)       |                                    | Disk            |
   |_________________|____________________________________|_________________|
 | | CMSSAA          | Build files for the CMSSAA TXTLIB. |                 |
   |_________________|____________________________________|_________________|
 | | DMSBLBAS        | Build files for the DMSBASE        |                 |
 | |                 | TXTLIB.                            |                 |
   |_________________|____________________________________|_________________|
 | | DMSBLAEN        | Build files for the DMSAENV        |                 |
 | |                 | TXTLIB.                            |                 |
   |_________________|____________________________________|_________________|
 | | DMSBLAMT        | Build files for the DMSAMT TXTLIB. |                 |
   |_________________|____________________________________|_________________|
 | | DMSBLCEN        | Build files for the DMSCENV        |                 |
 | |                 | TXTLIB.                            |                 |
   |_________________|____________________________________|_________________|
 | | DMSBLCMT        | Build files for the DMSCMT TXTLIB. |                 |
   |_________________|____________________________________|_________________|
```

```
 |  ___ Note _______________________________________________________________
   |                                                                        |
 | | If you have serviced any of the above TXTLIBs then you need to rebuild |
 | | the associated CSLLIB as indicated in "Rebuild the Callable Services   |
 | | Libraries (CSLs)" in topic 4.3.7.                                      |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** For each build list in [Table 4\-14](<#TBLXCMSTLB>) that has been serviced, enter the following command to create the updated level of the TXTLIB associated with it\.

<a id="TBLTBLUNIQ312"></a>

```
                                                  bldlist is the build list in Table 4-14.
 | vmfbld ppf esa cms bldlist (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ314"></a>

```
 |
 | vmfview build
```
