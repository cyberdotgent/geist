## ROADMAP Roadmap for Installing, Servicing, or Migrating VM

<a id="HDRRDMAP"></a>

If you are installing, servicing, or migrating your VM operating system, you should be familiar with the following documents\. You should refer to them in the order they are listed\.

<a id="TBLTBLUNIQ2"></a>

```
    _______________ ________________________________________________________
   | Procedure     | Document                                               |
   |_______________|________________________________________________________|
   | Installation  | 1.  VM/ESA Program Directory:  Contains the latest     |
   |               |     information regarding VM/ESA product installation  |
   |               |     and is shipped with the product tapes.  Helps you  |
   |               |     plan and obtain the information that is required   |
   |               |     during your installation.                          |
   |               |                                                        |
   |               | 2.  VM/ESA: Planning and Administration:  Helps you    |
   |               |     estimate the DASD storage that is required for the |
   |               |     CMS virtual machines, SFS and CRR.                 |
   |               |                                                        |
   |               | 3.  VM/ESA: VMSES/E Introduction and Reference:        |
   |               |     Introduces you to the VMSES/E installation tools   |
   |               |     that are used during a VM/ESA installation and     |
   |               |     provides information on planning and managing      |
   |               |     Software Inventories.  It also contains reference  |
   |               |     information on VMSES/E and a summary of what is    |
   |               |     new in this release.                               |
   |               |                                                        |
   |               | 4.  VM/ESA: Installation Guide: Steps you through how  |
   |               |     to install a VM/ESA Release 2 operating system.    |
   |               |                                                        |
 | |               | 5.  Assembler H: Installation:  Steps you through how  |
 | |               |     to install the Assembler H program product.  You   |
 | |               |     will need this book only if you are planning to    |
 | |               |     install with the four volumes of VM/ESA product    |
 | |               |     tapes.  It is not needed if you are installing the |
 | |               |     VM/ESA system DDR tape.                            |
   |               |                                                        |
 | |               | 6.  VM/ESA: SFS and CRR Planning, Administration, and  |
 | |               |     Operation:  Provides guidance and reference        |
 | |               |     information about planning for and managing the    |
 | |               |     Shared File System (SFS) and the Coordinated       |
 | |               |     Resource Recovery (CRR) facility.  Specific        |
 | |               |     administration and operation commands and start-up |
 | |               |     parameters are discussed.                          |
   |_______________|________________________________________________________|
   | Service       | 1.  VM/ESA: VMSES/E Introduction and Reference:        |
   |               |     Introduces you to the VMSES/E service tools that   |
   |               |     are used while servicing your VM/ESA system and    |
   |               |     provides information on planning and managing      |
   |               |     Software Inventories.  It also contains reference  |
   |               |     information on VMSES/E and a summary of what is    |
   |               |     new in this release.                               |
   |               |                                                        |
   |               | 2.  VM/ESA: Service Guide:  Provides service           |
   |               |     procedures used for VM/ESA components and is       |
   |               |     designed to be used with the VM/ESA: VMSES/E       |
   |               |     Introduction and Reference.  It also shows you how |
   |               |     to manage your Software Inventories while          |
   |               |     servicing VM.  Information on local service and    |
   |               |     removing service is also discussed.                |
   |_______________|________________________________________________________|
   | Migration     | 1.  VM/ESA: Conversion Guide and Notebook for VM/SP,   |
   |               |     VM/SP HPO, and VM/ESA 370 Feature and VM/ESA:      |
   |               |     Conversion Guide and Notebook for VM/XA SP and     |
   |               |     VM/ESA:  Describes strategies for planning your    |
   |               |     conversion and compares the functions in the       |
   |               |     system from which you are converting to the        |
   |               |     functions in VM/ESA Release 2.  It also describes  |
   |               |     differences in installation, service,              |
   |               |     administration, system operation, virtual machine  |
   |               |     operation, application programming, and diagnosis. |
   |               |                                                        |
   |               | 2.  REXX/EXEC Migration Tool for VM/ESA (VM/ESA MIGR): |
   |               |     Helps you plan your migration by estimating the    |
   |               |     amount of effort required to migrate certain types |
   |               |     of files to VM/ESA Release 2 from VM/SP 5, VM/SP   |
   |               |     HPO 5, VM/XA SP2-2.1, VM/ESA Release 1.0 (ESA      |
   |               |     Feature), and VM/ESA Release 1.1.                  |
   |               |                                                        |
   |               | 3.  Installation documentation described above.        |
   |               |                                                        |
   |               | 4.  Service documentation described above.             |
   |               |                                                        |
   |               | 5.  VM/ESA: CMS Application Migration Guide:  Provides |
   |               |     information on new or changed CMS functions you    |
   |               |     need to know about when you migrate your           |
   |               |     applications to the new operating system.          |
   |_______________|________________________________________________________|
```
