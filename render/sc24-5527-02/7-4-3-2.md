#### 7\.4\.3\.2 Reassemble the Updated ASSEMBLE Files

<a id="HDRLOCRASM"></a>

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Complete this procedure if you have any local modifications to         |
   | ASSEMBLE files.                                                        |
   |                                                                        |
   | If you have not yet updated the corresponding component MACLIBs, you   |
   | must do so before reassembling updated assemble files.  See the        |
   | "Update the Macro Libraries" section of the component you are          |
   | servicing for details.                                                 |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Set up the access order\.

<a id="TBLTBLUNIQ477"></a>

```
 |                                                esalcl is the ppfname, unless you use your
 | vmfsetup esalcl compname                       own override file.
                                                  compname is the default component
                                                  identifier, unless you use your own
                                                  override file.  The default component
                                                  identifiers are CMS and CP.  (The other
                                                  VM/ESA components do not have ASSEMBLE
                                                  files.)
```

**2\.** Use the VMFHASM EXEC to generate the text deck\.

**Notes:**

a\. Use VMFHASM for all ASSEMBLE files except DMSTRT*cc* ASSEMBLE, which is handled by VMFNLS in ["Compile National Language Files" in](7-4-3-3.md) [topic 7\.4\.3\.3](7-4-3-3.md)\.

b\. Source files are shipped in packed format and must be unpacked before assembly\.

<a id="TBLTBLUNIQ478"></a>

```
                                                  fn is the file name of the source file.
 | vmfhasm fn esalcl compname                     The file type must be ASSEMBLE.
 |                                                esalcl is the ppfname, unless you use your
                                                  own override file.

                                                  compname is the default component
                                                  identifier, unless you use your own
                                                  override file.
```

**3\.** Move each generated text deck from your A\-disk to the LOCALMOD disk for the component \(see [Table 7\-1 in topic 7\.3](<#TBLLCLDSK>)\)\.

<a id="TBLTBLUNIQ479"></a>

```
                                                  Determine the current file mode of the
   query disk                                     LOCALMOD disk (fm-local) to use in the next
                                                  command.

 | copyfile fn txtmodid a = = fm-local (olddate replace
 | erase fn txtmodid a

                                                  Move the text deck to the LOCALMOD disk.
```
