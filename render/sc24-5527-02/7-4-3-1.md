#### 7\.4\.3\.1 Update the Macro Libraries

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | If you are installing local service to a MACLIB, you must complete     |
   | this procedure.                                                        |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Set up the build access order\.

<a id="TBLTBLUNIQ475"></a>

```
 |                                                esalcl is the ppfname, unless you use your
 | vmfsetup esalcl compname                       own override file.
                                                  compname is the default component
                                                  identifier, unless you use your own
                                                  override file.  The component identifiers
                                                  for VM/ESA components that have MACLIBs are
                                                  REXX, CMS, CP, and GCS.
```

**2\.** Use the VMFBLD EXEC to update each MACLIB that contains a serviced member\.

You need to update a MACLIB only once, no matter how many serviced members it contains\.

<a id="TBLTBLUNIQ476"></a>

```
 |                                                Use VMFQOBJ to determine what MACLIBs need
 | vmfqobj esalcl compname tdata :object fn       to be rebuilt.
 |                                                fn is the file name of the MACRO or COPY
 |                                                file that you modified.

 |                                                bldlist will be the name that you will need
 | :object bldlist.objname.obtype                 in the next command
 |                                                objname is the name of the object.

 |
 | vmfbld ppf esalcl compname bldlist objname (serviced

 |                                                For a list of MACLIBs of EXECs for each
 |                                                component, see Table 7-3.

 |                                                For each MACLIB that was updated, remember
 |                                                to reassemble all modules that use the
 |                                                files that were updated.
```
