#### 3\.6\.4\.3 Build Serviced Objects

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Use the remainder of this step to build all VMSES/E objects that were  |
   | serviced.  If you prefer to build VMSES/E objects individually, then   |
   | use "Detailed Build Steps: VMSES/E" in topic 4.1 instead of the rest   |
   | of this step.                                                          |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** To rebuild all serviced parts, enter the following command:

<a id="TBLTBLUNIQ58"></a>

```
   vmfbld ppf esa vmses (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ60"></a>

```
   vmfview build
```

**3\.** Use the new serviced level of VMSES/E throughout the rest of this procedure by entering the following command:

<a id="TBLTBLUNIQ61"></a>

```
 | access 5e6 b
```
