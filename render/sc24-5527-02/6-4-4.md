#### 6\.4\.4 Update the

SRVBLDS Table After Manual Build Processing SRVBLDS table SRVBLDS table The Build Status table is updated using the VMFSIM QUERY function to retrieve the data from the SRVBLDS file and then use the results as input to VMFSIM\. To update the status of manually processed parts the following VMFSIM commands would be issued\.

<a id="TBLTBLUNIQ454"></a>

```
 | vmfsim modify tblfn srvblds * tdata :bldlist unknown :object bldlist :stat built
 | vmfsim query tblfn srvblds tdata :object bldlist :stat built
   VMFSPC2480I Results for TDATA :STAT BUILT
 |  :BLDLIST UNKNOWN
 |    :OBJECT BLDLIST
      :STAT BUILT.12/08/90.12:11:14.MAINT
      :PARTID. HCPABC TXT MAC

                                                  The VMFSIM MODIFY function is issued with a
                                                  TDATA statement that contains a status of
                                                  BUILT.  The modify function will process
                                                  the input specified and change the status
                                                  to BUILT.  The query shows the modify entry
                                                  in the SRVBLDS table.
```
