### 3\.8\.5 Test the New Level of CMS

<a id="HDRTSLVL"></a>

The VM Callable Services Library \(VMLIB\), Shared File System \(SFS\) modules, the REXX/VM component, and CMS nucleus are all functionally dependent on each other\. Following is a minimal test of CMS to ensure that these functional dependencies are maintained after installing new service\.

**1\.** If you use the Shared File System, prepare an SFS server to be used for testing the new level of CMS\. Otherwise, skip this task\.

<a id="TBLTBLUNIQ123"></a>

```
                                                  Log on to an SFS server user ID.  VMSERVS
   logon userid                                   is the recommended user ID, because it is
                                                  an IBM-supplied server that is only used
                                                  for service installation and maintenance.

                                                  Stop the server.
   stop
                                                  Note:  To use the SFS modules on the test
                                                  system tools disk and not from a saved
                                                  segment, the NOSAVESEGID parameter must be
                                                  specified in the server's start-up
                                                  parameters (DMSPARMS) file.  The DMSPARMS
                                                  files for the IBM-supplied servers
                                                  (VMSERVS, VMSERVR, and VMSERVU) specify
                                                  SAVESEGID CMSFILES.  This parameter must be
                                                  changed to NOSAVESEGID.

                                                  XEDIT the DMSPARMS file for the server.
   xedit userid dmsparms

 |                                                Start at the top of the file.
 | top

 |                                                Insure that the search is not case
 | set case mixed ignore                          significant.

                                                  Locate the SAVESEGID parameter.
   ====> locate/savesegid

                                                  Change the SAVESEGID savesegname parameter
   ====> change/SAVESEGID savesegname/NOSAVESEGID to NOSAVESEGID.

                                                  Save the updated DMSPARMS file.
   ====> file

                                                  Define the production CMS system disk as
   define 190 590                                 590 to allow the user ID to link the test
                                                  CMS system disk as 190.

                                                  Define the production system tools disk as
   define 193 593                                 593 to allow the user ID to link the test
                                                  system tools disk as 193.

                                                  Link the test CMS system disk as 190.
   link maint 490 190 rr

                                                  Link the test system tools disk as 193.
   link maint 493 193 rr

                                                  IPL the new (test) level of CMS without
   ipl 190 clear parm nosprof instseg no          executing the system profile (SYSPROF EXEC)
                                                  and without loading the installation saved
                                                  segment (CMSINST).
```

***\*\* DO NOT press*** ***ENTER******\! \*\****

<a id="TBLTBLUNIQ124"></a>

```
                                                  Bypass the execution of the PROFILE EXEC.
   access (noprof

                                                  Access the test system tools disk.
   access 193 b

                                                  Start the server.
   fileserv start

                                                  Disconnect from the SFS server user ID.
   #cp disconnect
```

**2\.** Prepare a user ID to be used for testing the new level of CMS\.

<a id="TBLTBLUNIQ125"></a>

```
                                                  Log on to the user ID used to test CMS.
   logon userid                                   The MAINT user ID can be used, because it
                                                  uses the VMSERVS server for its SFS
                                                  directories.

                                                  Define the production CMS system disk as
   define 190 590                                 590 to allow the user ID to link the test
                                                  CMS system disk as 190.

                                                  Define the production system tools disk as
   define 193 593                                 593 to allow the user ID to link the test
                                                  system tools disk as 193.

                                                  Link the test CMS system disk as 190.
   link maint 490 190 rr

                                                  Link the test system tools disk as 193.
   link maint 493 193 rr

                                                  IPL the new (test) level of CMS without
   ipl 190 clear parm nosprof instseg no          executing the system profile (SYSPROF EXEC)
                                                  and without loading the installation saved
                                                  segment (CMSINST).
```

**3\.** Test the new level of CMS\.

Test the new level of CMS using your installation's method\. If you are using SFS, include tests using the SFS server prepared with the new \(test\) level of CMS\. Minimally, this should include XEDITing and saving a file on an SFS directory\.

**4\.** Return the user ID used for testing to the old level of CMS\.

<a id="TBLTBLUNIQ126"></a>

```
                                                  Detach the test CMS system disk.
   detach 190

                                                  Detach the test system tools disk.
   detach 193

                                                  Define the production CMS system disk as
   define 590 190                                 190.

                                                  Define the production system tools disk as
   define 593 193                                 193.

                                                  IPL the old (production) level of CMS.
   ipl 190 clear

                                                  Disconnect from the user ID.
   disconnect
```

**5\.** If the Shared File System was used in the test, return the SFS server to the old level of CMS\. Otherwise, skip this task\.

<a id="TBLTBLUNIQ127"></a>

```
                                                  Log on to the SFS server user ID used to
   logon userid                                   test the new level of CMS.

                                                  Stop the server.
   stop

                                                  Detach the test CMS system disk.
   detach 190

                                                  Detach the test system tools disk.
   detach 193

                                                  Define the production CMS system disk as
   define 590 190                                 190.

                                                  Define the production system tools disk as
   define 593 193                                 193.

                                                  IPL the old (production) level of CMS.
   ipl 190 clear
```

***\*\* DO NOT press*** ***ENTER******\! \*\****

<a id="TBLTBLUNIQ128"></a>

```
                                                  Bypass the execution of the PROFILE EXEC.
   access (noprof

                                                  Access the production system tools disk.
   access 193 b

                                                  XEDIT the DMSPARMS file for the server.
   xedit userid dmsparms

 |                                                Start at the top of the file.
 | top

 |                                                Insure that the search is not case
 | set case mixed ignore                          significant.

                                                  Locate the NOSAVESEGID parameter.
   ====> locate/nosavesegid

                                                  Change the NOSAVESEGID parameter to
   ====> change/NOSAVESEGID/SAVESEGID savesegname SAVESEGID savesegname.  If you are using an
                                                  IBM-supplied server (VMSERVS, VMSERVR or
                                                  VMSERVU), savesegname is CMSFILES.

                                                  Save the updated DMSPARMS file.
   ====> file

                                                  Start the server.
   fileserv start

                                                  Disconnect from the SFS server user ID.
   #cp disconnect
```

**6\.** Continue service installation on the MAINT user ID\.

<a id="TBLTBLUNIQ129"></a>

```
                                                  Log on to the MAINT user ID to continue
   logon maint                                    service installation.
```
