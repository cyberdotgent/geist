#### 6\.1\.2 Query the Status of APARs Received

To determine the receive status of the APAR\(s\) you must first query the SRVREQT table to obtain a list of PTF\(s\) that contain the APAR\(s\) in question and then use the results of that query to obtain the status of the PTF\. The following VMFSIM QUERY commands would be issued to obtain the status\.

<a id="TBLTBLUNIQ434"></a>

```
   vmfsim query tblfn srvreqt * tdata :aparnum (file srvapars
   vmfsim query tblfn srvrecs * file srvapars
   VMFSIP2480I RESULTS FOR
               TDATA :PTF UM18082 :APARNUM VM47103
   :PTF UM18082
      :STAT RECEIVED.09/16/92.14:54:22.MAINT
   VMFSIP2480I RESULTS FOR
               TDATA :PTF UM18109 :APARNUM VM47104
   :PTF UM18109
      :STAT RECEIVED.09/16/92.14:54:22.MAINT
   VMFSIP2480I RESULTS FOR
               TDATA :PTF UM18135 :APARNUM VM47105
   :PTF UM18135
      :STAT RECEIVED.09/16/92.14:54:22.MAINT
```

The first query of the APAR from the SRVREQT table will capture the PTF numbers associated with the APAR and save the results in the SRVAPARS SIMDATA file\. The second query, using the SRVAPARS SIMDATA file as the input data, will return the status of the PTFs from the SRVRECS table\. The net result of these two queries is the status of the associated PTF for APARs VM47103, VM47104, and VM47105\.

The second query returns the following data:

**Field Data Definition**

**:PTF** This field contains the PTF number received\.

**:STAT** This field contains the status of the PTF followed by a number of qualifiers that identify the date and time the PTF was received, and the user ID used to receive the PTF\.
