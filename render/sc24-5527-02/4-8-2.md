#### 4\.8\.2 Determine which Build Lists Need to be Processed

<a id="HDRXAVSBST"></a>

**1\.** To determine which build steps need to be performed:

<a id="TBLTBLUNIQ407"></a>

```
   vmfview build

                                                  This command will display the names of all
                                                  objects that need to be built.
```

**2\.** Find the names of the build lists that contain objects that need to be built, as listed in [Table 4\-43](<#TBLXAVSSTA>), and then execute the corresponding build steps in the order that they appear in the table\.

<a id="TBLXAVSSTA"></a>

```
        ____________________________________________________________________
       | Table  4-43. AVS Build Lists                                       |
       |__________________________________ _________________________________|

       |__________________________________|_________________________________|
```
