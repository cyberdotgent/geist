**Notes:** 1. The file type of the source file must begin with a dollar sign ($)

but do not enter the $ in the command.

2. If? the file to be updated is an EXEC or XEDIT macro that is included in the CMS installation saved segment (default name CMSINST), use the NOCOMMENTS option to remove all comments and leading blanks. Then, rebuild the CMS installation saved segment to include the updated file. 3. After updating files and copying them to their test disks, erase them from the A-disk.
