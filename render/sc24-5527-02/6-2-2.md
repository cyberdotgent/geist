#### 6.2.2 Build an APPLY List Containing All Requisites of a PTF

To build an APPLY list containing all requisites required to install a specific PTF is done using the VMFSIM

function. This is useful to determine how much service will be applied before actually applying it. It is not required for VMFAPPLY since VMFAPPLY automatically includes requisites. This function would be used if you wanted to create your own apply list containing only the requisites required to apply a specific PTF you have received.
