#### 6\.2\.2 Build an APPLY List Containing All Requisites of a PTF

To build an APPLY list containing all requisites required to install a specific PTF is done using the VMFSIM SRVREQ function\. This is useful to determine how much service will be applied before actually applying it\. It is not required for VMFAPPLY since VMFAPPLY automatically includes requisites\.

This function would be used if you wanted to create your own apply list containing only the requisites required to apply a specific PTF you have received\.

<a id="TBLTBLUNIQ441"></a>

```
    vmfsim srvreq tblfn srvreqt a tblfn srvapps a tdata :ptf um15010 (applist ptfreqs
   ===== * * * TOP OF FILE * * *                  The VMFSIM SRVREQ function will add an
   ===== UM15010                                  entry to the PTFREQS $APPLIST for every PTF
   ===== UM18538                                  that is not applied and is a requisite of
   ===== UM18583                                  the PTF specified on the command.  The
   ===== UM18598                                  PTFREQS $APPLIST could now be used as input
   ===== * * * END OF FILE * * *                  to the VMFAPPLY command to install a
                                                  specific PTF and all its requisites.  This
                                                  information could also be used to determine
                                                  how many requisites are required to install
                                                  a specific PTF.
```
