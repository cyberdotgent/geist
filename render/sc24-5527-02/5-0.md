# 5\.0 Chapter 5\. Using the System Level Inventory

<a id="HDRSYSL"></a>

This chapter identifies a number of common uses of the system level inventories generated by VMSES/E and shows how to use the VMFSIM command to manage these inventories\. The chapter is organized to show what information is available after products are received, applied, and built by VMFINS\. For more information about the VMFINS command, see the [VM/ESA:](<DOCNUM/SC24-5444/CCONTENTS>) [VMSES/E Introduction and Reference](<DOCNUM/SC24-5444/CCONTENTS>)\.

The system level inventory consists of a number of tables that contain the following information about products or components installed on the system\.

- Requisite relationships between product\(s\) or component\(s\)
- Mapping of product identifier to the name of the $PPF file used during installation
- The status of the product or component on the system
- Mapping of PTF file type abbreviation to real CMS file type\.

This information is contained in a set of tables generated by VMSES/E when installing products\. Following is a description of each table and the information it provides\.

**Table Type Contents Requisite Table** This table contains the requisite relationships between products and components\. The file name and file type of the table are VM SYSREQT\. **Description Table** This table contains the descriptive name for a product or component\. The file name and file type of the table are VM SYSDESCT\. **Receive Status Table** This table contains the relationship between a product and the $PPF file used to install it\. It also identifies what product\(s\) or component\(s\) have been received on the system\. The file name and file type of the table are VM SYSRECS\. **Apply Status Table** This table identifies what product\(s\) or component\(s\) have been applied \(in other words, all requisites that have been satisfied\) to the system and the PPF that was used to apply the product or component\. The file name and file type of the table are VM SYSAPPS\. **Build Status Table** This table identifies what products have been built onto the system\. The file name and file type of the table are VM SYSBLDS\. **File Type Abbreviation Table** This table identifies the mapping between PTF\-numbered file types and the real CMS file type\. The file name and file type of the table are VM SYSABRVT\.

**Notes:**

1\. These are examples and the output may or may not match your system\.

2\. The default file name for all system level inventories tables is VM\. If you have changed this name substitute the name of your system level inventories in the following sections\.
