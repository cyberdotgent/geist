### 8\.1\.2 Removing All Service

If you want to back out all service \(both alternate and intermediate levels\), and use only the production service level, you must remove both the alternate and intermediate APPLY disks from the active access order for the component\.

For example, to remove all service for CP, you must remove the 2A6 and 2A4 disks from the access order, and rebuild all objects that were affected by the service being removed\. The following steps would be performed to accomplish to remove the service\.

**1\.** Access the service disks required for the component using the VMFSETUP command\.

<a id="TBLTBLUNIQ497"></a>

```
   vmfsetup esa compname
```

**2\.** Copy all $SELECT files from the current service disk to the production service disk\. The $SELECT file will be used by VMFBLD to identify all objects in the component that need to be rebuilt\.

<a id="TBLTBLUNIQ498"></a>

```
   copyfile * $select fm-applyalt = = fm-applyprod (olddate replace
```

**3\.** Create a PPF override called ESAPROD $PPF that will remove the alternate apply and intermediate apply disks from the MDA section\. See [VM/ESA: VMSES/E Introduction and Reference](<DOCNUM/SC24-5444/CCONTENTS>) for details on creating PPF overrides\.

<a id="TBLTBLUNIQ500"></a>

```
   vmfppf esaprod compname
```

**4\.** Follow the build steps identified in [Table 7\-4 in topic 7\.5](<#TBLBUILDS>) for the component being processed\. After all build steps have been completed for the component all service that was on the current and test disks will have been removed\.

If you get the following message during build processing, you must create the base level of the object indicated in the message\.

`VMFBDC2074I OBJECT` *objname* `WAS NOT BUILT BECAUSE IT HAS NEVER BEEN SERVICED`

This can be done in one of the following ways:

- Generate the base level \(no service\) of the part, if it is source maintained, by running VMFHASM for an assemble file, or EXECUPDT for a $ source file, and copy it to the build disk\.
- Load the base level of the part to the build disk from a backup tape containing the object before it was serviced\.
