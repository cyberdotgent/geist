#### 3\.13\.4\.3 Build Serviced Objects

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Use the remainder of this step to build all AVS objects that were      |
   | serviced.  If you prefer to build AVS objects individually, then use   |
   | "Detailed Build Steps: AVS" in topic 4.8 instead of the rest of this   |
   | step.                                                                  |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Use the *compname* `avs` or `avssfs` if you have a GCS/XA environment\. Use the *compname* `avs370` or `avssfs370` if you are running AVS in 370 mode GCS\. To rebuild all serviced parts, enter *one of* the following commands:

<a id="TBLTBLUNIQ249"></a>

```
   vmfbld ppf esa avs|avssfs (serviced
 | vmfbld ppf esa avs370|avssfs370 (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ251"></a>

```
   vmfview build
```
