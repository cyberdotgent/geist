#### 6.4.2 Determine What Objects Need to Be Built

The Build Status table has a list of objects that have been serviced for the component. To determine the specific objects that have been serviced and need to be built the VMFSIM QUERY command would be issued against the

table searching for objects with a status of SERVICED. These are the objects that need to be built.

<a id="TBLTBLUNIQ452"></a>

| VMFSIP2480I RESULTS FOR | TDATA :STAT SERVICED | :BLDLIST HCPMLOAD |
| --- | --- | --- |


**Field** **Data** **Definition** **:****BLDLIST** This field contains the name of the build list that contained the object. **:****OBJECT** This field contains the name of an object that is contained in the build list. A build list can contain one or more objects. **:****STAT** This field contains the status of the object followed by a number of qualifiers that identify the date and time the object was built, and the user ID used to build the object. Because SERVICED was specified as a search argument only those objects that have new serviced applied will be returned by the query.
