#### 6\.3\.2 Query the Status of APARs Applied

To determine the apply status of a APARs you must first query the SRVREQT table to obtain a list of PTFs that contain the APAR in question and then use the results of that query to obtain the status of the PTF\. The following VMFSIM QUERY commands would be issued to obtain the status\. The net result of these two queries is the status of the APARs Applied\. Ignore the informational messages displayed in the second Query\.

<a id="TBLTBLUNIQ444"></a>

```
   vmfsim query tblfn srvreqt * tdata :aparnum vm30514 (file srvapars
   vmfsim query tblfn srvapps * file srvapars
   VMFSIP2480I RESULTS FOR
               TDATA :PTF UM18082 :APARNUM VM47103
   :PTF UM18082
      :STAT APPLIED.09/16/92.14:59:04.MAINT
```

The first query of the APAR from the SRVREQT table will capture the PTF numbers associated with the APAR and save the results in the SRVAPARS SIMDATA file\. The second query, using the SRVAPARS SIMDATA file as the input data, will return the status of the PTFs from the SRVAPPS table\. The net result of these two queries is the status of the APARs applied\.

**Note:** Ignore the informational messages displayed in the second Query\.

The second query returns the following data:

**Field Data Definition**

**:PTF** This field contains the PTF number received\.

**:STAT** This field contains the status of the PTF followed by a number of qualifiers that identify the date and time the PTF was applied, and the user ID used to apply the PTF\.
