#### 4\.7\.2 Determine which Build Lists Need to be Processed

<a id="HDRXTSFBST"></a>

**1\.** To determine which build steps need to be performed:

<a id="TBLTBLUNIQ397"></a>

```
   vmfview build

                                                  This command will display the names of all
                                                  objects that need to be built.
```

**2\.** Find the names of the build lists that contain objects that need to be built, as listed in [Table 4\-38](<#TBLXTSFSTA>), and then execute the corresponding build steps in the order that they appear in the table\.

<a id="TBLXTSFSTA"></a>

```
        ____________________________________________________________________
       | Table  4-38. TSAF Build Lists                                      |
       |__________________________________ _________________________________|
       | Build List                       | Build Procedure                 |
       |__________________________________|_________________________________|
       | ATSBLHLP                         | "Select and Copy Serviced       |
       | ATSBLSRC                         | Files" in topic 4.7.3           |
       | ATSBLINF                         |                                 |
       | ATSBLMES                         |                                 |
       |__________________________________|_________________________________|
       | ATSMLOAD                         | "Rebuild the Executable         |
       |                                  | MODULEs" in topic 4.7.4         |
       |__________________________________|_________________________________|
       | ATSSBHLP                         | "Process the Segment Build      |
       |                                  | List" in topic 4.7.5            |
       |__________________________________|_________________________________|
```
