### 3\.12\.1 Prepare to Install Service

**1\.** Set up your access order\.

If you want to use the new level of VMSES/E, access the 5E6 disk\. This will replace the access to the 5E5 disk which contains the older level of VMSES/E\.

<a id="TBLTBLUNIQ214"></a>

```
   access 5e6 b
```

<a id="TBLTBLUNIQ215"></a>

```
                                                  The ppfname is esa, if you are using the
   vmfsetup ppfname compname                      override PPF supplied by IBM for VM/ESA.
                                                  It contains overrides to the base PPF file
                                                  for this component, 6VMVMH20 $PPF.  If you
                                                  have your own PPF override file for this
                                                  component, you should enter your file's
                                                  ppfname here.  The ppfname you enter here
                                                  should be used throughout the rest of this
                                                  step.

                                                  The compname is tsaf|tsafsfs, if you are
                                                  using the override component name within
                                                  the VM/ESA PPF file.  If you specify your
                                                  own ppfname, you should enter the compname
                                                  from that file here.  The compname you
                                                  enter here should be used throughout the
                                                  rest of this step.

                                                  If you have your own PPF override file for
                                                  this component, make sure you have run
                                                  VMFPPF before VMFSETUP to ensure you have
                                                  the appropriate level of PPF.
```

**2\.** Enter the VMFMRDSK command to clear the TSAF alternate apply disk:

<a id="TBLTBLUNIQ216"></a>

```
 | vmfmrdsk esa tsaf|tsafsfs apply
```

**3\.** Make sure that you have the service documentation you need to install service for this component\.

If you have not already received the documentation for the service you are about to perform, do so now\. For more information, see ["Step 2\.](3-4.md) [Receive the Service Documentation" in topic 3\.4](3-4.md)\.

**4\.** Make sure that you have prepared the system for service\.

If you have not already done the activities in ["Step 3\. Prepare the](3-5.md) [System for Service" in topic 3\.5](3-5.md), do so now before continuing\.

**5\.** Make sure that a tape drive is attached to your virtual machine, and that the COR tape is mounted and ready, unless you are receiving service from disk\.
