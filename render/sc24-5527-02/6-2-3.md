#### 6.2.3 Build an EXCLUDE List Containing All Dependents of a PTF

To build an EXCLUDE list containing all PTFs dependent on a specific PTF is done using the VMFSIM

function. This is useful to determine how much service will be excluded before actually excluding it. This function would be used if you wanted to create your own exclude list containing all PTFs that are dependent a specific PTF you do not want to apply.

<a id="TBLTBLUNIQ442"></a>

srvapps * tdata :ptf um15010 (applist ptfdeps

| ===== UM15010 | ===== UM18531 | ===== UM18582 |
| --- | --- | --- |


The VMFSIM

function will add an entry to the PTFDEPS $APPLIST for every PTF that is applied and is dependent on the PTF specified on the command. The PTFDEPS $EXCLIST could now be used as input to the VMFAPPLY command to exclude a specific PTF and all its dependents. This information could also be used to determine how many PTFs are dependent on a specific PTF you do not want to apply.

**Note:** It is not necessary to have all dependent PTFs in the exclude list. VMFAPPLY will automatically exclude all PTFs dependent on a PTF specified in the exclude list.
