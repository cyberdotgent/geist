#### 4\.8\.1 Prepare to Build

Query the disks and record the file modes of the disks listed in [Table 4\-41](<#TBLXAVSDSK>) in the last column of the table\. Unless you have made your own substitutions through PPF overrides, use the default disks listed in the table\.

<a id="TBLTBLUNIQ406"></a>

```
   vmfqmda esa avs|avssfs
```
