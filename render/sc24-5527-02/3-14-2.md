### 3\.14\.2 Build the NLS Segment

The following table identifies the build list for each national language saved segment\. Enter the VMFBLD command with the *segname* for the national language desired\.

<a id="TBLBLNLS"></a>

```
    ________________________________________________________________________
 | | Table  3-3. National Language Segments                                 |
   |____________________________________ ___________________________________|
 | | segname                            | National Language                 |
   |____________________________________|___________________________________|
 | | NLSKANJI                           | Kanji                             |
   |____________________________________|___________________________________|
 | | NLSUCENG                           | Uppercase English                 |
   |____________________________________|___________________________________|
 | | NLSFRANC                           | French                            |
   |____________________________________|___________________________________|
 | | NLSGER                             | German                            |
   |____________________________________|___________________________________|
 | | NLSESPAN                           | Spanish                           |
   |____________________________________|___________________________________|
 | | NLSHANZI                           | Chinese Simplified                |
   |____________________________________|___________________________________|
 | | NLSCANFR                           | Canadian French                   |
   |____________________________________|___________________________________|
```

<a id="TBLTBLUNIQ268"></a>

```
 |
 | vmfbld ppf segbld esa20 segblist segname (serviced
```
