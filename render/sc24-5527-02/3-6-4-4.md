## 3.6.4.4 Rebuild the HELP Files in Uppercase (Optional)

<a id="HDRUPSES"></a>

#### Rebuild the HELP Files in Uppercase (Optional)

If you want serviced HELP files to be uppercase (for example, NLS purposes) on the MAINT 402 disk, enter the following commands:

<a id="TBLTBLUNIQ62"></a>

[Table: This command will create the UCENG PPF file]

vmfppf uceng vmses needed to put the HELP files in uppercase.
