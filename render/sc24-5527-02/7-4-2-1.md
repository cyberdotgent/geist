#### 7\.4\.2\.1 Generating an Update File

To generate an update file, use the following procedure\.

**Note:** Steps [5](7-4-2-1.md) and [6](7-4-2-1.md) describe how to create an update file\. If IBM has supplied the update file, you do not need to complete those steps to create one\.

**1\.** Set up your access order\.

<a id="TBLTBLUNIQ470"></a>

```
 |                                                esalcl is the ppfname, unless you use your
 | vmfsetup esalcl compname                       own override file.
                                                  compname is the default component
                                                  identifier, unless you use your own
                                                  override file.  The default component
                                                  identifiers are VMSES, REXX, CMS, CP, GCS,
                                                  DV, TSAF, and AVS.
```

**2\.** If your control file \(identified in the PPF on the :CNTRL\. tag\) does not contain an AUX record for a local AUX file \(AUXLCL is the default\), XEDIT the control file and insert the appropriate AUX record immediately following the MACS record\.

**3\.** XEDIT the AUX file \(*fn* AUX*xxx*, where *fn* is the name of the module being updated\) and add an entry for the update file\. This entry should have the format:

*updateft svclvl lcmodid comment*

where:

*updateft* is the file type of the update file\.

*svclvl* is a service level indicator\.

*lcmodid* can be 4 to 7 characters long\. The first 2 characters must be LC, followed by the *modid*\. The *modid* begins with an L, and is followed by up to 4 alphanumeric characters that identify the local modifications\. For example, LCLFIX1 is valid\. The *lcmodid* is also used to create the file type of the object generated when the local modification is compiled\.

*comment* is any comment that you want to add\.

**4\.** If the AUX file is new \(that is, if it is on your A\-disk\), copy it to the LOCALMOD disk\.

<a id="LISlocxed"></a>

**5\.** XEDIT the source file with the CTL option\.

<a id="TBLTBLUNIQ471"></a>

```
                                                  fn ft is the file ID of the source file.
   xedit fn ft (ctl ctlfile                       The file name must be the same as the file
                                                  name of the update file.

                                                  ctlfile is the file name of the control
                                                  file.
```

<a id="LISlocfile"></a>

**6\.** Make your changes to the displayed source file\. The original source file is **not** changed; When you issue the FILE command in XEDIT, all of

<a id="ELISlocfile"></a>

your changes are placed in the update file, *fn updateft*\.

**7\.** When you complete your changes, move the update file to the LOCALMOD disk for the component \(see [Table 7\-1 in topic 7\.3](<#TBLLCLDSK>)\)\.

<a id="TBLTBLUNIQ472"></a>

```
   copy fn updateft a = = fm-local (olddate replace
   erase fn updateft a
```
