#### 7.4.2.1 Generating an Update File

To generate an update file, use the following procedure.

Note: Steps [5](7-4-2-1.md) and 6 describe how to create an update file. If IBM has supplied the update file, you do not need to complete those steps to create one. **1.** Set up your access order.

**2.** If your control file (identified in the PPF on the :CNTRL. tag) does not contain an AUX record for a local AUX file (AUXLCL is the default), XEDIT the control file and insert the appropriate AUX record immediately following the MACS record. **3.** XEDIT the AUX file (fn AUXxxx, where fn is the name of the module being updated) and add an entry for the update file. This entry should have the format: updateft svclvl lcmodid comment where: updateft is the file type of the update file. svclvl is a service level indicator. lcmodid can be 4 to 7 characters long. The first 2 characters must be LC, followed by the modid. The modid begins with an L, and is followed by up to 4 alphanumeric characters that identify the local modifications. For example, LCLFIX1 is valid. The lcmodid is also used to create the file type of the object generated when the local modification is compiled. comment is any comment that you want to add. **4.** If the AUX file is new (that is, if it is on your A-disk), copy it to the LOCALMOD disk.
