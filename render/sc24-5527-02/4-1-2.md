#### 4\.1\.2 Determine which Build Lists Need to be Processed

<a id="HDRXSESBST"></a>

**1\.** Determine which build steps need to be performed:

<a id="TBLTBLUNIQ286"></a>

```
   vmfview build

                                                  This command displays the names of all
                                                  objects that need to be built.
```

**2\.** Find the names of the build lists that contain objects that need to be built, as listed in [Table 4\-2](<#TBLXSESSTA>), and then execute the corresponding build steps in the order that they appear in the table\.

<a id="TBLXSESSTA"></a>

```

       |__________________________________ _________________________________|

       | VMFBLSRC                         |                                 |
       |__________________________________|_________________________________|
```
