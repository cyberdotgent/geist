### 5.5 Recovering System Inventories

If for some reason it is necessary to recover the system level inventories the following procedure should be followed. **1.** Recover the SYSREQT and SYSDESCT tables. The SYSREQT and SYSDESCT system inventory tables are created from the fn PRODPART file using the INIT function. To recover these system inventory files use the VMFSIM INIT function to create these tables. To do this requires creating a list of all PRODPART files contained on the system.
