### 5\.5 Recovering System Inventories

If for some reason it is necessary to recover the system level inventories the following procedure should be followed\.

**1\.** Recover the SYSREQT and SYSDESCT tables\.

The SYSREQT and SYSDESCT system inventory tables are created from the *fn* PRODPART file using the INIT function\. To recover these system inventory files use the VMFSIM INIT function to create these tables\. To do this requires creating a list of all PRODPART files contained on the system\.

<a id="TBLTBLUNIQ430"></a>

```
                                                  The VM SYSREQT table will be updated to
   listfile * prodpart * (exec                    reflect all requisite data contained in the
   vmfsim init vm * file cms exec                 PRODPART files processed.
                                                  The VM SYSDESCT table will be updated to
                                                  reflect all default PPFs and the
                                                  descriptions associated with them in the
                                                  PRODPART files processed.
```

**2\.** Recover the system inventory status tables\.

The system inventory status tables are created by using the list of products or components contained in the SYSDESCT as a base list of products or components\. It can be modified to add any additional products or delete products\. To recover the status tables the following procedure should be used\.

**a\.** Create a file containing all the products contained in the SYSDESCT table by using the VMFSIM QUERY command\.

<a id="TBLTBLUNIQ431"></a>

```
   vmfsim query vm sysdesct tdata :ppf (file proddata

                                                  The file PRODDATA SIMDATA will contain a
                                                  list of all product and their descriptions.
                                                  This data will be used as input to the
                                                  VMFSIM MODIFY function.
```

**b\.** Edit the PRODDATA SIMDATA file and add any additional products that have been installed on the system to the file, and delete any product or component that have not been installed\. Also, add any additional $PPF file overrides that you may have created for the products you have installed\.

**c\.** Update the SYSRECS, SYSAPPS and SYSBLDS tables using the PRODDATA SIMDATA file created above\.

<a id="TBLTBLUNIQ432"></a>

```
   vmfsim modify vm sysrecs d file proddata tdata :stat received
   vmfsim modify vm sysapps d file proddata tdata :stat applied
   vmfsim modify vm sysblds d file proddata tdata :stat built

                                                  The file PRODDATA SIMDATA contains a list
                                                  of all product and their descriptions.  The
                                                  TDATA status entered on the command will be
                                                  added to each product or component
                                                  identified in the PRODDATA file.  This will
                                                  result in all the products or components
                                                  identified to be assigned a status of
                                                  received in the SYSRECS table, a status of
                                                  applied in the SYSAPPS table and a status
                                                  of built in the SYSBLDS table.
```
