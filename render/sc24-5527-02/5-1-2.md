#### 5\.1\.2 Query the Description of Products or Components Received

The SYDESCT table contains the descriptive name for all the products or components that are received on the system\. To query the descriptive name of all products or components received on the system enter the following VMFSIM command:

<a id="TBLTBLUNIQ420"></a>

```
   vmfsim query vm sysdesct tdata :ppf
   VMFSIP2480I RESULTS FOR
               TDATA :PPF
   :PPF 6VMVMK20 VMSES
      :PRODID 6VMVMK20
 |    :DESC VMSES component for VM/ESA 2.0
   :PPF 6VMVMB20 CP
      :PRODID 6VMVMB20
 |    :DESC CP component for VM/ESA 2.0
   :PPF 6VMVMI20 DV
      :PRODID 6VMVMI20
 |    :DESC DV component for VM/ESA 2.0
   :PPF 6VMVMA20 CMS
      :PRODID 6VMVMA20
 |    :DESC CMS component for VM/ESA 2.0
   READY; T=0.59/0.67 11:38:55
```

The query returns the following data:

**Field Data Definition**

**:PPF** This field contains the file name of the PPF that was used to install the product or component and the component name in the PPF that was used\. **:DESC** This field contains a short description of the product or component
