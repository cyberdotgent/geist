#### 6\.3\.1 Query the Status of PTFs Applied

The SRVAPPS table consists of the list of PTFs with appropriate status, APPLIED, SUPED or REMOVED\. To get a list of all PTFs in the SRVAPPS table with a status of APPLIED the following VMFSIM command would be used\.

<a id="TBLTBLUNIQ443"></a>

```
   vmfsim query tblfn srvapps * tdata :stat applied
   VMFSIP2480I RESULTS FOR
               TDATA :STAT APPLIED
   :PTF UM18082
      :STAT APPLIED.09/16/92.14:59:04.MAINT
   :PTF UM18109
      :STAT APPLIED.09/16/92.14:59:04.MAINT
```

The query returns the following data:

**Field Data Definition**

**:PTF** This field contains the PTF number received\.

**:STAT** This field contains the status of the PTF followed by a number of qualifiers that identify the date and time the PTF was applied, and the user ID used to apply the PTF\.
