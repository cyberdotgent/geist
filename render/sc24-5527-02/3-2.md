## 3.2 Using Substitute Disks for Default Disks

Many of the commands used in the service procedure steps require you to enter the file mode of a disk. If you have changed any of the default disk addresses, you must substitute the file mode of your disk address for the file mode of the default disk address described in that step. The COR service procedure follows. **Follow** **the** **steps** **in** **order**.
