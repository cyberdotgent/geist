#### 3\.9\.4\.4 Rebuild the Stand\-Alone Dump

<a id="HDRDUMPIT"></a>

**1\.** Use VMFVIEW to see if the object SA\.DUMP was serviced and requires additional build steps\.

<a id="TBLTBLUNIQ155"></a>

```
 |
 | vmfview build
 | BD:VMFBDU2180I HCPBLUTL  SA.DUMP    RUN HCPSADMP EXEC

 |                                                If this message is shown then you need to
 |                                                rebuild the stand-alone dump.
```

**2\.** If necessary, use the HCPSADMP EXEC to rebuild the Stand\-Alone Dump and the re\-IPL CMS\.

<a id="TBLTBLUNIQ156"></a>

```
 |                                                HCPSADMP loads a Disabled Wait State PSW
 | hcpsadmp                                       when it completes.  For more information
 | ipl 190 clear                                  about this exec, see VM/ESA: Planning and
 |                                                Administration.
```
