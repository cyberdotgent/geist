#### 5\.1\.4 Determining Dependent Products or Components

Use the SYSDEP function with the system requisite table and system apply status table to return the dependents for the PRODIDs specified\. Use this function to determine what products or components are dependent on a specific product or component you want to remove from the system\.

<a id="TBLTBLUNIQ422"></a>

```
   vmfsim sysdep vm sysreqt * = sysapps * tdata :prodid 6vmvmk20%vmses
   VMFSIP2480I RESULTS FOR
               TDATA :PRODID 6VMVMK20%VMSES
   :PRODID 6VMVMK20
      :DEPS 6VMVMH20 6VMVMF20 6VMVMI20 6VMVMB20 6VMVMA20
            6VMVML20 6VMVMD20
      :DREQDEPS 6VMVMA20 6VMVML20
      :SUPBY *NONE*
   READY; T=0.57/0.60 11:42:43
```

The SYSDEP function returns the following data:

**Field Data Definition**

**:PRODID** This field contains the name of the product or component that was processed\. **:DEP** This field contains a list of the product or component that are dependent on the product or component specified\. **:DREQDEP** This field contains a list of the product or component that are dependent features of the product or component specified on the command\. **:SUPBY** This field contains the name of a product or component that supersedes this PRODID\.
