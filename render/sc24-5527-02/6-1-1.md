#### 6.1.1 Query the Status of PTFs Received

The

table contains a list of all PTFs that are received for a product or component. To query the status of all PTFs received for a product or component, enter the following VMFSIM command:

<a id="TBLTBLUNIQ433"></a>

| VMFSIP2480I RESULTS FOR | TDATA :PTF | :PTF UM18082 :STAT RECEIVED.09/16/92.14:54:22.MAINT |
| --- | --- | --- |


Use [Table 6-1](6-1-1.md#TBLTBLFN) for this example, and all others that require a table file name.

<a id="TBLTBLFN"></a>

Table 6-1. Table File Names

| Component | tblfn |
| --- | --- |
| VMSES/E | 6VMVMK20 |
| CP | 6VMVMB20 |
| GCS | 6VMVML20 |
| Dump Viewing Facility | 6VMVMI20 |
| TSAF | 6VMVMH20 |
| AVS | 6VMVMD20 |


**Field** **Data** **Definition** **:****PTF** This field contains the PTF number received. **:****STAT** This field contains the status of the PTF followed by a number of qualifiers that identify the date and time the PTF was received, and the user ID used to receive the PTF. Valid statuses are received (PTF has been received), and committed (PTF has been received and parts of the PTF may have been erased from the delta disk.)
