#### 6\.1\.1 Query the Status of PTFs Received

The SRVRECS table contains a list of all PTFs that are received for a product or component\. To query the status of all PTFs received for a product or component, enter the following VMFSIM command:

<a id="TBLTBLUNIQ433"></a>

```
   vmfsim query tblfn srvrecs * tdata :ptf
   VMFSIP2480I RESULTS FOR
               TDATA :PTF
   :PTF UM18082
      :STAT RECEIVED.09/16/92.14:54:22.MAINT
   :PTF UM18109
      :STAT RECEIVED.09/16/92.14:54:22.MAINT
```

Use [Table 6\-1](6-1-1.md#TBLTBLFN) for this example, and all others that require a table file name\.

<a id="TBLTBLFN"></a>

```
    ________________________________________________________________________
   | Table  6-1. Table File Names                                           |
   |____________________________________ ___________________________________|
   | Component                          | tblfn                             |
   |____________________________________|___________________________________|
   | VMSES/E                            | 6VMVMK20                          |
   |____________________________________|___________________________________|
   | REXX/VM                            | 6VMVMF20                          |
   |____________________________________|___________________________________|
   | CMS                                | 6VMVMA20                          |
   |____________________________________|___________________________________|
   | CP                                 | 6VMVMB20                          |
   |____________________________________|___________________________________|
   | GCS                                | 6VMVML20                          |
   |____________________________________|___________________________________|
   | Dump Viewing Facility              | 6VMVMI20                          |
   |____________________________________|___________________________________|
   | TSAF                               | 6VMVMH20                          |
   |____________________________________|___________________________________|
   | AVS                                | 6VMVMD20                          |
   |____________________________________|___________________________________|
```

The query returns the following data:

**Field Data Definition**

**:PTF** This field contains the PTF number received\.

**:STAT** This field contains the status of the PTF followed by a number of qualifiers that identify the date and time the PTF was received, and the user ID used to receive the PTF\. Valid statuses are `received` \(PTF has been received\), and `committed` \(PTF has been received and parts of the PTF may have been erased from the delta disk\.\)
