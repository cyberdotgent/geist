## 7\.3 Step 2\. Receive Local Service

<a id="HDRLOCREC"></a>

Use [Table 7\-1](<#TBLLCLDSK>) as a key to the disks to use in the steps that follow\.

<a id="TBLLCLDSK"></a>

```
    ________________________________________________________________________
 | | Table  7-1. Disks Used for Local Service                               |
   |_________ __________ ____________________ ______________________________|
 | | File    | Symbol   | Meaning            | Description                  |
 | | Mode    |          |                    |                              |
   |_________|__________|____________________|______________________________|
 | |         | fm-local | File mode of disk  | The LOCALMOD disk for CP and |
 | |         |          | 2C4                | the Dump Viewing Facility    |
   |_________|__________|____________________|______________________________|
 | |         | fm-local | File mode of disk  | The LOCALMOD disk for CMS,   |
 | |         |          | 3C4                | and REXX/VM                  |
   |_________|__________|____________________|______________________________|
 | |         | fm-local | File mode of disk  | The LOCALMOD disk for        |
 | |         |          | 5C4                | VMSES/E                      |
   |_________|__________|____________________|______________________________|
 | |         | fm-local | File mode of disk  | The LOCALMOD disk for TSAF   |
 | |         |          | 7C4                | and AVS                      |
   |_________|__________|____________________|______________________________|
 | |         | fm-local | File mode of disk  | The LOCALMOD disk for GCS    |
 | |         |          | 6C4                |                              |
   |_________|__________|____________________|______________________________|
```

To receive service:

**1\.** Establish the appropriate minidisk access order\.

<a id="TBLTBLUNIQ461"></a>

```
 |                                                esalcl will access the source disk, in
 | vmfsetup esalcl compname                       addition to accessing the service disk for
 |                                                a component.
```

**2\.** If the service is emergency service supplied by telephone or as hard copy, your IBM service representative will give you the information you need to install the emergency fix\.

**3\.** If the service is supplied on a magnetic tape, load it onto the LOCALMOD disk \(*fm\-local*\)\.

**a\.** Attach a tape drive to your virtual machine as 181\.

<a id="TBLTBLUNIQ462"></a>

```
                                                  rdev is the real device number of the tape
   attach rdev * 181                              drive.
```

**b\.** Mount and ready the tape\.

**c\.** Determine the file mode of the alternate LOCALMOD disk \(*fm\-local*\)\.

<a id="TBLTBLUNIQ463"></a>

```
   query disk
```

**d\.** Load the service to the alternate LOCALMOD disk\.

<a id="TBLTBLUNIQ464"></a>

```
                                                  The tape file is in VMFPLC2 format.  The
   vmfplc2 load * * fm-local (eot disk            VMFPLC2 command creates a file called TAPE
                                                  MAP A.  The TAPE MAP file lists the file
                                                  names and file types of all of the files
                                                  that were loaded to the LOCALMOD disk.
```

**e\.** Print or rename TAPE MAP A\. You will need to refer to this file throughout the rest of the service procedure\. Renaming the file prevents VMFPLC2 from overwriting it\.

<a id="TBLTBLUNIQ465"></a>

```
   rename tape map a lcl = =
```
