# B\.0 Appendix B\. Receiving Service For Non\-VMSES Envelopes

<a id="HDRSEEN"></a>

```
 |  ___ Note _______________________________________________________________
   |                                                                        |
 | | Substitute this procedure for the Receive Service procedure in the     |
 | | step for the component you are servicing.                              |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Receive the product memos from the documentation envelope NLST*nnnn* SERVLINK\.

<a id="TBLTBLUNIQ504"></a>

```
 |                                                This command resets the logical position to
 | vmfplcd rst env= nlstnnnn servlink fm          the beginning of the envelope.  The GLOBALV
 |                                                will also be updated with the name of the
 |                                                envelope so that the ENV= parameter will
 |                                                not be required for subsequent VMFPLCD
 |                                                commands for that envelope.

 |                                                fm is the file mode of the disk where the
 |                                                envelope exists.  The default is the
 |                                                A-disk.

 |                                                This command receives service documentation
 | vmfplcd load * * a (eod                        for the envelope (COR VMELEDOC, SERVICE
 |                                                DOCUMENT, and COR01 MEDIAMAP).
```

**2\.** Read the memo\-to\-users for each product that you plan to service\.

**3\.** Receive the service for non\-VMSES PTF envelopes NPTF*nnnn* SERVLINK\. These files typically are for products in addition to VM/ESA, such as RSCS, VM Pass\-Through Facility, and DIRMAINT\.

<a id="TBLTBLUNIQ505"></a>

```
 |                                                This command resets the logical position to
 | vmfplcd rst env= nptfnnnn servlink fm          the beginning of the envelope.  The GLOBALV
 |                                                will also be updated with the name of the
 |                                                envelope so that the ENV= parameter will
 |                                                not have to be specified in subsequent
 |                                                VMFPLCD commands.

 |                                                fm is the file mode of the disk where the
 |                                                envelope exists.  The default is the
 |                                                A-disk.

 |                                                Locate the start of service in the envelope
 | vmfplcd scan prodid 010101 (eod                for the product to service.
 |                                                prodid is the product ID for which you want
 |                                                to install service.  The prodid can be
 |                                                obtained from the COR01 MEDIAMAP file,
 |                                                loaded in 1.

 |                                                Receive the service for the product on a
 | vmfplcd load * * fm (disk                      work disk.  Refer to the product
 |                                                documentation for procedures to follow for
 |                                                installing corrective service.

 |                                                fm is the file mode of the work disk that
 |                                                you are using for the product you are
 |                                                installing.
```
