#### 4\.5\.5 Rebuild the Load Libraries

<a id="HDRXGCSLOA"></a>

Use VMFBLD to determine if the GCS PROPMX load library must be rebuilt\.

**1\.** Enter the VMFBLD command to create an updated level of the PROPMX LOADLIB\.

<a id="TBLTBLUNIQ372"></a>

```
   vmfbld ppf esa gcs|gcssfs gctblprp (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ374"></a>

```
 |
 | vmfview build
```
