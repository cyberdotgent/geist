## 2\.3 Prepare to Receive a Component from the RSU Tape

<a id="HDRREFDISK"></a>

**1\.** Determine if you have reach\-ahead service and which PTFs will be installed, using the VMFSIM command:

The following commands check which PTFs you currently have installed on your system, compares them to what you will be receiving, and generates a file, REAPP $APPLIST A\. This file contains a list of all the PTFs that will need to be reapplied\. It will also create another file, NEWSRV $APPLIST A, that contains a list of the new PTFs that will be installed for the component\.

The values for *compname* and *appid* are identified in [Table 2\-1 in](<#TBLCNAPI>) [topic 2\.2](<#TBLCNAPI>)\.

If any of the following is true:

- The number of records in the REAPP $APPLIST A \(PTFs to reapply\) is greater than the number of records in the NEWSRV $APPLIST A \(new PTFs that will be installed\)
- You have a large number of local modifications
- There are PTFs you want excluded

you should follow the alternate receive procedure, ["Alternate Receive](2-4.md) [Procedure for a Component" in topic 2\.4](2-4.md)\. These PTFs must then be installed as corrective service\. Otherwise, use the procedure ["Receive the Preapplied, Prebuilt Service" in topic 2\.3\.1](2-3-1.md)\.
