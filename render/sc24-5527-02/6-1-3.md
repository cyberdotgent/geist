#### 6.1.3 Query the Description of APARs Received

To obtain the description of an APAR, enter the following VMFSIM QUERY command against the

table. The

table contains the description of the APARs received.

<a id="TBLTBLUNIQ435"></a>

| VMFSIP2480I RESULTS FOR | TDATA :APARNUM |
| --- | --- |
| :APARNUM VM47104<br>:APARNUM VM47105 |  |


**Field** **Data** **Definition** **:****APARNUM** This field contains the APAR number received. **:****ABSTRACT** This field contains a short description of the APAR identified on the :APARNUM tag.
