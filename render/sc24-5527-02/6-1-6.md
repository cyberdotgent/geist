#### 6\.1\.6 Determine APARs Contained in PTFs

To determine what APARs are contained in all PTFs currently received the following VMFSIM QUERY command would be issued against the SRVREQT table\. The SRVREQT table contains a list of all APARs contained in PTFs\.

<a id="TBLTBLUNIQ438"></a>

```
   vmfsim query tblfn srvreqt * tdata :aparnum
   VMFSIP2480I RESULTS FOR
               TDATA :APARNUM
   :PTF UM18082
      :APARNUM VM47103
   :PTF UM18109
      :APARNUM VM47104
   :PTF UM18135
      :APARNUM VM47105
```

The query returns the following data:

**Field Data Definition**

**:PTF** This field contains the PTF number\. **:APARNUM** This field contains the list of APARs contained in the PTF field\.
