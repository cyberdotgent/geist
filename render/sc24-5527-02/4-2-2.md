#### 4\.2\.2 Determine which Build Lists Need to be Processed

<a id="HDRXREXBST"></a>

**1\.** To determine which build steps to perform, enter the following command:

<a id="TBLTBLUNIQ297"></a>

```
   vmfview build

                                                  This command will display the names of all
                                                  objects that need to be built with the name
                                                  of the corresponding build list.
```

**2\.** Find the names of the build lists that contain objects that need to be built, as listed in [Table 4\-7](<#TBLXREXSTA>), and then execute the corresponding build steps in the order that they appear in the table\.

<a id="TBLXREXSTA"></a>

```
        ____________________________________________________________________
       | Table  4-7. REXX/VM Build Lists                                    |
       |__________________________________ _________________________________|
       | Build List                       | Build Procedure                 |
       |__________________________________|_________________________________|
       | IXXBLSRC                         | "Select and Copy Serviced       |
       |                                  | Files" in topic 4.2.3           |
       |__________________________________|_________________________________|
       | IXXOM                            | "Update the Macro Libraries     |
       |                                  | (MACLIBs)" in topic 4.2.4       |
       |__________________________________|_________________________________|
       | IXXBLNUC                         | "Rebuild the Nuclei" in         |
       |                                  | topic 4.2.5                     |
       |__________________________________|_________________________________|
```
