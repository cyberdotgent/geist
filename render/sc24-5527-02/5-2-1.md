#### 5\.2\.1 Querying the Status of Products or Components Applied

The SYSAPPS table contains the status of all the products or components that are applied on the system\. To determine the apply status of all the products or components installed on the system, use the following VMFSIM command:

<a id="TBLTBLUNIQ423"></a>

```
   vmfsim query vm sysapps * tdata :ppf :stat
   VMFSIP2480I RESULTS FOR
               TDATA :PPF :STAT
   :PPF ESAINS VMSES
      :STAT APPLIED.09/16/92.09:16:03.MAINT
   :PPF ESAINS CP
      :STAT APPLIED.09/16/92.09:51:50.MAINT
   :PPF ESAINS DV
      :STAT APPLIED.09/16/92.10:06:21.MAINT
   :PPF ESAINS CMS
      :STAT APPLIED.09/16/92.11:27:46.MAINT
   :PPF ESAINS REXX
      :STAT APPLIED.09/16/92.11:50:36.MAINT
   READY; T=0.44/0.48 11:50:43
```

The QUERY function returns the following data:

**Field Data Definition**

**:PPF** This field contains the file name of the PPF that was used to install the product or component and the component name in the PPF that was used\.

**:STAT** This field contains the status of the product or component followed by a number of qualifiers that identify the date and time it was applied, and the user ID used to apply the product or component\.
