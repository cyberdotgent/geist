## 4.7.4 Rebuild the Executable MODULEs

<a id="HDRXTSFEXE"></a>

#### Rebuild the Executable MODULEs

If any TSAF executable MODULEs have been serviced, they must be rebuilt. These MODULEs are listed in the ATSMLOAD build list. **1.** Enter the VMFBLD command to rebuild all of the MODULEs in the build list that contain text decks that have been serviced.
