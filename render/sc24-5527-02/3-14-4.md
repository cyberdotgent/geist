### 3\.14\.4 Place the CP Nucleus into Production

**1\.** Release the primary PARM DISK from CP, link the parm disk with a multiread mode, and access\. Copy the CPLOAD MODULE, which is your CP nucleus, to the primary PARM DISK CF1\. Enter the following commands:

<a id="TBLTBLUNIQ279"></a>

```
 |
 | query cpdisk
 | LABEL   USERID  VDEV MODE STAT VOL-ID RDEV TYPE  STARTLOC  ENDLOC
 | MNTCF1  MAINT   0CF1  A   R/O  ES2RES 0720 ECKD        69      85
 | cprel a

 |                                                When you do a CP release, you lose config
 |                                                files on the CF1 parm disk.  HCPBOX will
 |                                                come up for any new LOGONs.

 |
 | link maint cf1 cf1 mr

 |                                                fm-cf1 is any free file mode.
 | access cf1 fm-cf1

 |
 | copyfile cpload module fm-493 = = fm-cf1 (olddate replace

 |
 | erase cpload module fm-493
```

**2\.** Place the CP nucleus into production by shutting down and re\-IPLing your system\. Enter the following command:

<a id="TBLTBLUNIQ280"></a>

```
 |
 | shutdown reipl
```
