#### 5.4.2 Adding Products or Components to System Inventories

If a product is installed on the system that is not supported by VMSES/E the system inventories can be updated to identify the product. The following procedure should be followed to add the product to the system inventory. **1.** Update the SYSRECS table. The SYSRECS table contains the status of all the products or components that are received on the system. New products or components and status are added to this table by using the VMFSIM MODIFY function.
