#### 5\.4\.2 Adding Products or Components to System Inventories

If a product is installed on the system that is not supported by VMSES/E the system inventories can be updated to identify the product\. The following procedure should be followed to add the product to the system inventory\.

**1\.** Update the SYSRECS table\.

The SYSRECS table contains the status of all the products or components that are received on the system\. New products or components and status are added to this table by using the VMFSIM MODIFY function\.

<a id="TBLTBLUNIQ426"></a>

```
   vmfsim modify vm sysrecs * tdata :ppf 5664188 none :prodid 5664188 :stat received
                                                  The VM SYSRECS table will be updated to
                                                  reflect that product 5664188 has been
                                                  received on the system.
```

**2\.** Update the SYSDESCT table\.

The SYSDESCT table contains a short description of all the products or components that are received on the system\. The new product description is added to this table by using the MODIFY function of VMFSIM\.

<a id="TBLTBLUNIQ427"></a>

```
   vmfsim modify vm sysdesct * tdata :ppf 5664188 none :prodid 5664188 :desc new product
                                                  The VM SYSDESCT table will be updated to
                                                  reflect the description of the product that
                                                  has been installed.
```

**3\.** Update the SYSAPPS table\.

The SYSAPPS table contains the status of all the products or components that are applied on the system\. The new products apply status is added to this table by using the MODIFY function of VMFSIM\.

<a id="TBLTBLUNIQ428"></a>

```
   vmfsim modify vm sysapps * tdata :ppf 5664188 none :prodid 5664188 :stat applied
                                                  The VM SYSAPPS table will be updated to
                                                  reflect that product 5664188 has been
                                                  applied on the system.
```

**4\.** Update the SYSBLDS table\.

The SYSBLDS table contains the status of all the products or components that are built on the system\. The new Products build status is added to this table by using the VMFSIM MODIFY function\.

<a id="TBLTBLUNIQ429"></a>

```
   vmfsim modify vm sysblds * tdata :ppf 5664188 none :prodid 5664188 :stat built
                                                  The VM SYSBLDS table will be updated to
                                                  reflect that product 5664188 has been built
                                                  on the system.
```
