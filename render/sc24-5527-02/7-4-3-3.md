#### 7\.4\.3\.3 Compile National Language Files

<a id="HDRLOCNLS"></a>

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Complete this procedure if you have local modifications to any of the  |
   | following national language files:                                     |
   |                                                                        |
   | °   fn REPOS file                                                      |
   |                                                                        |
   | °   fn DLCS file                                                       |
   |                                                                        |
   | °   DMSTRTcc ASSEMBLE file (where cc is a country code suffix).        |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Set up the access order\.

<a id="TBLTBLUNIQ480"></a>

```
 |                                                esalcl is the ppfname, unless you use your
 | vmfsetup esalcl compname                       own override file.
                                                  compname is the default component
                                                  identifier, unless you use your own
                                                  override file.  The default component
                                                  identifiers are CMS, CP, GCS, DV, TSAF, and
                                                  AVS.  (VMSES/E and REXX/VM do not have
                                                  national language files.)
```

**2\.** Use the VMFNLS EXEC to generate the text deck for each national language file\.

<a id="TBLTBLUNIQ481"></a>

```
                                                  fn and ft are the file name and file type
 | vmfnls fn ft esalcl compname (options          of the source file.
 |                                                esalcl is the ppfname, unless you use your
                                                  own override file.

                                                  compname is the default component
                                                  identifier, unless you use your own
                                                  override file.

                                                  options are any additional options you want
                                                  to use.  For more information about the
                                                  VMFNLS EXEC, see VM/ESA: VMSES/E
                                                  Introduction and Reference.
```

**3\.** Move each generated text deck from your A\-disk to the LOCALMOD disk for the component \(see [Table 7\-1 in topic 7\.3](<#TBLLCLDSK>)\)\.

<a id="TBLTBLUNIQ483"></a>

```
                                                  Determine the current file mode of the
   query disk                                     LOCALMOD disk (fm-local) to use in the next
                                                  command.

                                                  Move the text deck to the LOCALMOD disk.
 | copyfile fn txtmodid a = = fm-local (olddate replace
 | erase fn txtmodid a
```

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | After you have re-installed all of the local service for a component,  |
   | make sure that you rebuild all of the objects that contain these       |
   | updated text decks.  Complete Steps 4 and 5 in the local service       |
   | procedure.                                                             |
   |                                                                        |
   |________________________________________________________________________|
```
