# E.0 Appendix E.  Updating the CP Load List

<a id="HDRLOD"></a>

The CP load list is CPLOAD EXEC. For the CP load list, the order is determined by the HCPMDLAT MACRO, which is processed when assembling source for the HCPLDL module. The load list is created when HCPLDL is assembled. CPLOAD EXEC is shipped when the CP load list is serviced. You must generated the CPLOAD EXEC only if local modifications are made. The modules in CPLOAD EXEC fall into these general categories: Resident modules. These modules are nonpageable. Pageable modules loaded at initialization. These modules may not be paged until system initialization has finished. Thereafter, the modules can be paged out. Other pageable modules. These modules, along with the modules that are resident only during initialization, comprise the part of the system that CP pages in and out of real storage. The CP load list must have fixed-length 80-byte records. If you need to change the load list, do the following: **|** 1. Create a dummy update for HCPLDL ASSEMBLE. **2.** Update the HCPMDLAT MACRO and rebuild HCPGPI MACLIB, using the [HDRLOCSERV](7-0.md) procedures in Chapter 7, "Installing Local Service" in topic 7.0. **|** 3. Assemble HCPLDL. This will generate HCPLDL TXTmodid. **|** 4. Copy HCPLDL TXTmodid to CPLOAD EXCmodid, where modid is the same modid used to update HCPMDLAT MACRO. **5.** Xedit CPLOAD EXCmodid and add an * (asterisk) to the beginning of each line prior to "&CONTROL OFF." **|** 6. Update the local Version Vector Table (VVT) for HCPMDLAT MACRO, HCPLDL [HDRLOCSYS](7-4-1.md) | TXTmodid, and CPLOAD EXCmodid. Follow the instructions in "Step 3a. U [pdate the Local Version Vector Table." in topic 7.4.1.](7-4-1.md) [HDRXCPPRB](4-4-9.md) **7.** Build the CP nucleus, using the procedure in "Rebuild the CP Nucleus" i [n topic 4.4.9.](4-4-9.md)
