#### 3\.8\.4\.4 Rebuild the ASSEMBLE MODULE

[Table 3\-1](<#TBLCMSTXT>) lists the CMS build list and MODULE that may need to be rebuilt\.

<a id="TBLCMSTXT"></a>

```
    __________________________________________________________________________________________________
 | | Table  3-1. CMS Build List and MODULE to be Rebuilt                                              |
   |___________________________ __________________________________________ ___________________________|
   | Build List                | MODULE to Be Rebuilt                     | Test/Production           |
   |___________________________|__________________________________________|___________________________|
 | | DMSBLASM                  | ASSEMBLE MODULE                          | 490/190                   |
   |___________________________|__________________________________________|___________________________|
```

Determine if the ASSEMBLE MODULE requires regeneration:

**1\.** Use VMFVIEW and the PF5 key to view all status messages and locate message 2180I for the DMSBLASM build list\. If any of the objects contained in DMSBLASM have been built, enter the following commands for DMSBLASM to rebuild the MODULE\.

<a id="TBLTBLUNIQ108"></a>

```
 |                                                When you rebuild the ASSEMBLE MODULE,
 | vmfview build                                  access the 490 disk as A before you issue
 | access 490 a                                   the ASMGEND command.
 | asmgend
 |                                                When ASMGEND prompts you for a file mode,
 |                                                press ENTER.
```

**2\.** After you rebuild the serviced MODULE, restore the original access order\.

<a id="TBLTBLUNIQ109"></a>

```
   access 191 a
```

<a id="TBLTBLUNIQ110"></a>

```
   vmfsetup esa cms
```
