### 1\.2\.4 Reapplying Local Service \(If Applicable\)

All local service must be entered into the software inventory to allow VMSES/E to track the changes and build them into the system\. **If a local change is not added to the software inventory, VMSES/E will not build it into the system\.** See ["Step 3a\. Update the Local Version Vector Table\."](7-4-1.md) [in topic 7\.4\.1](7-4-1.md) for instructions on updating the the VVT when applying local service\.
