#### 6\.2\.1 Build an APPLY List of all PTFs Received and Not Applied

The SRVRECS table consists of the list of PTFs that have been received and the SRVAPPS table contains a list of all PTFs already applied\. Comparing these two table will result in an apply list of all PTFs received and not applied\. The file NEW $APPLIST will be generated containing all PTFs not applied\.

This function would be used if you wanted to create your own apply list containing only the new service you have received and not use the apply list shipped on the service tape which may contain PTFs that you already have applied\.

<a id="TBLTBLUNIQ440"></a>

```
   vmfsim comptbl tblfn srvrecs * tblfn srvapps * tdata :PTF (applist new
   ===== * * * TOP OF FILE * * *
   ===== * APPLIST FROM VMFSIM COMPTBL 6VMVMA20 SRVRECS K 6VMVMA20 SRVAPPS A
   ===== UM18537
   ===== UM18538
   ===== UM18583
   ===== UM18598
   ===== * * * END OF FILE * * *
```

The VMFSIM COMPTBL function will compare the PTF entries in the SRVRECS table to the PTF entries in the SRVAPPS table\. Any PTF that is found in the SRVRECS and not in the SRVAPPS table will be added to the NEW $APPLIST\. The NEW $APPLIST could now be used as input to the VMFAPPLY command to install all new PTFs just received\.
