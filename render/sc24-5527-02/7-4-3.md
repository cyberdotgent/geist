### 7\.4\.3 Step 3c\. Generate a Replacement Part

<a id="HDRLOCGEN"></a>

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Complete this procedure only if you have a local modification to a $   |
   | source file.                                                           |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Set up the build access order\.

<a id="TBLTBLUNIQ473"></a>

```
                                                  compname is the default component
 | vmfsetup esalcl compname                       identifier, unless you use your own
                                                  override file.
```

**2\.** Locate the file name of the $ source file in [Appendix G, "$ Source](g-0.md) [File Tables" in topic G\.0](g-0.md)\. Update the file with the EXECUPDT command shown in the table, using the specified options\.

**3\.** Copy the updated file to the disk shown in the table for the component being serviced in [Appendix G, "$ Source File Tables" in topic G\.0](g-0.md)\.

<a id="TBLTBLUNIQ474"></a>

```
   copyfile fn ft fm1 fn ftabbvmodid fm2 (olddate replace
   erase fn ft fm1

                                                  fm1 is the disk containing the updated
                                                  file.  fm2 is the first test disk
                                                  identified in the table.

                                                  The ftabbvmodid consists of the ftabbv and
                                                  the modid.  The ftabbv is the 3 character
                                                  file type abbreviation.  The modid begins
                                                  with an L, followed by the 1-4 characters
                                                  entered in the AUX file.
```
