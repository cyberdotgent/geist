### 3\.12\.3 Apply the Service

<a id="HDRTSFAPP"></a>

**1\.** If your access order has changed since you performed the last task in this component step, enter the following command:

<a id="TBLTBLUNIQ220"></a>

```
   vmfsetup esa tsaf|tsafsfs
```

**2\.** If you have PTFs that you want to exclude, you should add them now to your exclude list\. For instructions about updating your exclude list, see the *VM/ESA: VMSES/E Introduction and Reference*\.

**3\.** Apply the service\.

<a id="TBLTBLUNIQ221"></a>

```
   vmfapply ppf esa tsaf|tsafsfs
```

**4\.** Check the apply message log for warning and error messages\. If necessary, correct any problems before going on\. For information about handling specific apply messages, see [VM/ESA: System Messages](<DOCNUM/SC24-5529/CCONTENTS>) [and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ223"></a>

```
                                                  Note that an RO message indicates an
   vmfview apply                                  out-of-component requisite.  Before you put
                                                  this component into production, you must
                                                  install service for the component indicated
                                                  in the message.
```

**5\.** See ["Sample Queries after Apply Processing" in topic 6\.3](6-3.md) after applying service if you want to view your updated inventories\. In that section, you will find information to help you:

- Query the status of PTFs applied
- Query the status of APARs applied
- Determine all parts serviced by a specific PTF
- Determine all parts serviced by a specific APAR
- Determine all service applied to a specific part
- Determine the current level of a part
- Create an APPLY list from two SRVAPPS tables
- Validate that the AUX files and the Version Vector Table match\.
