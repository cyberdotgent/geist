## D\.1 Building an Object Outside of the Service Process

If you need to build an object outside of the service process you need to perform the following steps\.

**1\.** Access the disks\.

<a id="TBLTBLUNIQ539"></a>

```
 |
 | vmfsetup esa compname
```

**2\.** Locate the object to be built in one of the build lists\. VMFBLD requires that you enter the name of the build list on the VMFBLD command\.

<a id="TBLTBLUNIQ540"></a>

```
 |                                                You can use :partid fn instead of :object
 | vmfqobj esa compname tdata :object objname     objname if you do not know the name of the
 |                                                object but you know the name of the part.
```

**3\.** Issue the VMFBLD command specifying the build list, the name of the object and the ALL option\.

<a id="TBLTBLUNIQ541"></a>

```
 |
 | vmfbld ppf esa compname bldlist objname (all
```
