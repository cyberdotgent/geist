### 7\.4\.4 Step 3d\. Applying and Removing Patches

<a id="HDRLOCPAT"></a>

A patch is an update to object code contained in a text deck The text deck can be used to build a module or can be included in a nucleus\. The patch is applied using the service control structure and is nondestructive\. That is, the patch does not change the text deck and can be backed out\.
