#### 4\.8\.3 Select and Copy Serviced Files

<a id="HDRXAVSCRE"></a>

[Table 4\-44](<#TBLXAVSBL>) contains build lists for AVS that require the select and copy build functions\.

<a id="TBLXAVSBL"></a>

```
    ________________________________________________________________________
   | Table  4-44. Build Lists for AVS Select and Copy Functions             |
   |_________________ ____________________________________ _________________|
   | Build List      | Description                        | Test/Production |
   |                 |                                    | Disk            |
   |_________________|____________________________________|_________________|
   | AGWBLHLP        | Build list for HELP files.         | 19D/19D         |
   |_________________|____________________________________|_________________|
   | AGWBLSRC        | Build list for new/replacement     | 493/193         |
   |                 | source files.                      |                 |
   |_________________|____________________________________|_________________|
   | AGWBLINF        | Build list for AVS/Dump Viewing    | 493/193         |
   |                 | Facility interface files.          |                 |
   |_________________|____________________________________|_________________|
```

**1\.** Enter the following command for each build list in [Table 4\-44](<#TBLXAVSBL>) that was in the $VMFBLD $MSGLOG\.

<a id="TBLTBLUNIQ408"></a>

```
   vmfbld ppf esa avs|avssfs bldlist (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ410"></a>

```
   vmfview build
```
