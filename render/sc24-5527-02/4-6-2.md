#### 4\.6\.2 Determine which Build Lists Need to be Processed

<a id="HDRXDVFBST"></a>

**1\.** To determine which build steps need to be performed:

<a id="TBLTBLUNIQ387"></a>

```
   vmfview build

                                                  This command will display the names of all
                                                  objects that need to be built.
```

**2\.** Find the names of the build lists that contain objects that need to be built, as listed in [Table 4\-33](<#TBLXDVFSTA>), and then execute the corresponding build steps in the order that they appear in the table\.

<a id="TBLXDVFSTA"></a>

```
        ____________________________________________________________________
       | Table  4-33. Dump Viewing Facility Build Lists                     |
       |__________________________________ _________________________________|
       | Build List                       | Build Procedure                 |
       |__________________________________|_________________________________|
       | HCSBLHLP                         | "Select and Copy Serviced       |
       | HCSBL493                         | Files" in topic 4.6.3           |
       | HCSBLMSG                         |                                 |
       | HCSBLSRC                         |                                 |
       |__________________________________|_________________________________|
       | HCSMLOAD                         | "Rebuild the Executable         |
       |                                  | MODULEs" in topic 4.6.4         |
       |__________________________________|_________________________________|
       | HCSSBHLP                         | "Process the Segment Build      |
       |                                  | List" in topic 4.6.5            |
       |__________________________________|_________________________________|
```
