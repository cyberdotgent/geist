#### 3\.9\.4\.1 Update the Build Status Table

<a id="HDRCPBST"></a>

**1\.** If your access order has changed since you performed the last task in this component step, enter the following command:

<a id="TBLTBLUNIQ144"></a>

```
   vmfsetup esa cp
```

**2\.** Update the Build Status Table with serviced parts:

<a id="TBLTBLUNIQ145"></a>

```
                                                  This command will update the Build Status
   vmfbld ppf esa cp (status                      Table with a status of serviced for each
                                                  object that needs to be built.
```

**3\.** If the $PPF files have been serviced then you get the following prompt:

<a id="TBLTBLUNIQ146"></a>

```
   VMFBLD2185R The following source product parameter files have been serviced:
   VMFBLD2185R 6VMVMB20 $PPF
   VMFBLD2185R When source product parameter files are serviced, all product
               parameter files built from them must be recompiled using VMFPPF
               before VMFBLD can be run.
   VMFBLD2185R Enter zero (0) to have the serviced source product parameter files
               built to your A-disk and exit VMFBLD so you can recompile your
               product parameter files with VMFPPF
   VMFBLD2185R Enter one (1) to continue only if you have already recompiled your
               product parameter files with VMFPPF

                                                  Enter 0 and complete the following steps
   0                                              before you continue.

   VMFBLD2188I Building 6VMVMB20 $PPF on 191 (A) from level $PFnnnnn
   vmfppf esa cp
   copy 6vmvmb20 $ppf a = = fm-51d (olddate replace
   erase 6vmvmb20 $ppf a

                                                  Enter VMFSETUP to ensure correct access
   vmfsetup esa cp                                order.

                                                  Re-issue VMFBLD to complete updating the
   vmfbld ppf esa cp (status                      build status table.  When you receive the
   1                                              prompt that was previously displayed, enter
                                                  1 to continue.
```

**4\.** Use VMFVIEW to review the build status messages, and see what objects need to be rebuilt:

<a id="TBLTBLUNIQ147"></a>

```
   vmfview build
```
