### 7\.4\.5 Step 3e\.  Applying Zaps

<a id="HDRLOCZAP"></a>
<a id="TBLTBLUNIQ486"></a>
<a id="TBLTBLUNIQ491"></a>
<a id="TBLTBLUNIQ492"></a>

```text
   A zap is a direct change to object code in a text deck.  There are two
   types of zaps:
   °   The ZAP command changes or dumps MODULE, TXTLIB, and LOADLIB files.
       The changes or instructions are supplied to ZAP through input control
       records.
   °   The ZAPTEXT EXEC changes or dumps individual text decks.  ZAPTEXT uses
       the same input control records that ZAP uses, as well as the EXPAND
       control record.
    ___ Note _______________________________________________________________
   |                                                                        |
   | ZAP and ZAPTEXT changes cannot be removed from the modified text deck. |
   |                                                                        |
   |________________________________________________________________________|
   1.  Set up the access order.
 |                                                esalcl is the ppfname, unless you use your
 | vmfsetup esalcl compname                       own override file.
                                                  compname is the default component
                                                  identifier, unless you use your own
                                                  override file.  The default component
                                                  identifiers are VMSES, REXX, CMS, CP, GCS,
                                                  DV, TSAF, and AVS.
   2.  Create the control records.
c.cc 4
 |  ------------------ For Modules, TXTLIBs and LOADLIBs -------------------
       Create the ZAP input control records to define your changes.  For more
                  <BOOK> <> <> <SC24-5444> <ANY> <HCPA3>
       information about creating these records, see VM/ESA: VMSES/E
                 <BOOK> <> <> <SC24-5444> <ANY> <HCPA3>
       Introduction and Reference.
       Issue the ZAP command.  For information about the format of this
                  <BOOK> <> <> <SC24-5444> <ANY> <HCPA3>
       command, see VM/ESA: VMSES/E Introduction and Reference.
   |--------------- End of For Modules, TXTLIBs and LOADLIBs ---------------|
c.cc 4
    ---------------------------- For Text Decks ----------------------------
       Create the ZAPTEXT input control records to define your changes.  For
                  <BOOK> <> <> <SC24-5444> <ANY> <HCPA3>
       more information about creating these records, see VM/ESA: VMSES/E
                 <BOOK> <> <> <SC24-5444> <ANY> <HCPA3>
       Introduction and Reference.
       Issue the ZAPTEXT command.  For information about the format of this
                  <BOOK> <> <> <SC24-5444> <ANY> <HCPA3>
       command, see VM/ESA: VMSES/E Introduction and Reference.
   |------------------------ End of For Text Decks -------------------------|
   3.  Copy the modified object to the LOCALMOD disk.
 |
```
