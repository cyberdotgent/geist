### 1\.2\.3 Applying Service

The VMFAPPLY command updates the version vector table \(VVT\), which identifies the service level of all serviced parts\. In addition, AUX files are generated from the VVT for parts which require them\. VMFAPPLY only modifies the alternate apply disk\. All lower level apply disks are unaffected\.
