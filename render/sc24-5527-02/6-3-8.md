#### 6\.3\.8 Validate that the AUX Files and Version Vector Table Match

The CHKLVL function is used to verify the CNTRL/AUX structure for a specific module matches the corresponding levels of the version vector table\. This function would mainly be used for the following purposes:

- To validate that all service applied to a part is contained in the AUX files for that part\.
- To validate that any local modification contained in AUX files are also identified in the corresponding version vector table\.
- To validate that any local version vector table entries are also identified in local AUX files for the part\.

To use the VMFSIM CHKLVL function, enter:

<a id="TBLTBLUNIQ450"></a>

```
 | vmfsim chklvl ppfname compname tdata :part hcprda
   VMFSIP2471W MISMATCH BETWEEN AUX FILE HCPRDA AUXVM H1 FOR FILE HCPRDA TXT IN
               VERSION VECTOR 6VMVMB20 VVTVM H1
   =================== 6VMVMB20 VVTVM H1 HCPRDA TXT ===================
   LAST MATCH R47104HP --- UM18109
   MISMATCH R47103HP --- UM18082
   ------------------- HCPRDA AUXVM H1
   LAST MATCH R47104HP --- UM18109
   MISMATCH - * * * END OF FILE * * *
```

The VMFSIM CHKLVL function reads each version vector table and AUX file level identified in the control file and compares the entries for a specific part\. If a level is found that does not match, a message will be issued to identify the last entries that matched and the failing entries\. If all levels match then a message will be issued indicating that all levels have been checked\.
