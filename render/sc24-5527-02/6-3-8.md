#### 6.3.8 Validate That the AUX Files and Version Vector Table Match

The CHKLVL function is used to verify the CNTRL/AUX structure for a specific module matches the corresponding levels of the version vector table. This function would mainly be used for the following purposes: To validate that all service applied to a part is contained in the AUX files for that part. To validate that any local modification contained in AUX files are also identified in the corresponding version vector table.
