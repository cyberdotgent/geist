#### 4\.4\.8 Process the Segment Build Lists

<a id="HDRXCPHP"></a>

This step updates the build status **only**\. The actual build of the segment is performed during the task ["Step 12\. Placing Your Serviced Components](3-14.md) [into Production" in topic 3\.14](3-14.md)\.

<a id="TBLXCPHL"></a>

```
    ________________________________________________________________________
 | | Table  4-25. Build Lists for Processing the CP Segment Build Lists     |
   |_______________________ ________________________________________________|
 | | Build List            | Description                                    |
   |_______________________|________________________________________________|
 | | HCPSBHLP              | Build list for CP files that reside on the     |
 | |                       | HELP segment                                   |
   |_______________________|________________________________________________|
 | | HCPSBKAN              | Build list for national language Kanji         |
   |_______________________|________________________________________________|
 | | HCPSBUCE              | Build list for national language Uppercase     |
 | |                       | English                                        |
   |_______________________|________________________________________________|
 | | HCPSBFRA              | Build list for national language French        |
   |_______________________|________________________________________________|
 | | HCPSBGER              | Build list for national language German        |
   |_______________________|________________________________________________|
 | | HCPSBESP              | Build list for national language Spanish       |
   |_______________________|________________________________________________|
 | | HCPSBHAN              | Build list for national language Chinese       |
 | |                       | Simplified                                     |
   |_______________________|________________________________________________|
 | | HCPSBCAN              | Build list for national language Canadian      |
 | |                       | French                                         |
   |_______________________|________________________________________________|
```

**1\.** Enter the following command for each segment build list, if it has been serviced:

<a id="TBLTBLUNIQ355"></a>

```
 |                                                bldlist is a build list from Table 4-25.
 | vmfbld ppf esa cp bldlist (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.
