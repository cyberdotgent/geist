### 2.4.3 Determine RSU Service Level

| Use the VMFSIM command to determine the current RSU Tape Service Level. | In the example, 9301 is the RSU service level. Use this level when | ordering corrective service. The VM SYSRECS table contains a list of all | products or components that are received on the system. | To query the status of all products or components installed using the | ESAPTFS PPF enter the following VMFSIM command:

<a id="TBLTBLUNIQ37"></a>

|

| \| :PPF ESAPTFS VMSES - \| :STAT RECEIVED.09/16/92/.09:16:01.MAINT.200-9301 | \| :PPF ESAPTFS CP / \| :STAT RECEIVED.09/16/92/.09:51:48.MAINT.200-9301 | \| :PPF ESAPTFS DV ) \| :STAT RECEIVED.09/16/92/.10:06:18.MAINT.200-9301 |
| --- | --- | --- |


| **Field** **Data** **Definition**

| :PPF This field contains the file name of the PPF that was used to

| install the product or component, and the component name in the **|** **PPF** that was used. **|** **:ST**AT This field contains the status of the product or component, followed by a number of qualifiers that identify the date and time that it was received, the user ID used to receive it, and the service level when it was installed. In this example, the 9301 is the RSU service level. Note You have now reached the end of the Product Service Upgrade procedure.
