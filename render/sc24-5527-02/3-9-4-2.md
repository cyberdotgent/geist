#### 3\.9\.4\.2 Build Serviced Objects

```
    ___ Note _______________________________________________________________
   |                                                                        |
   | Use the remainder of this step to build all CP objects that were       |
   | serviced.  If you prefer to build CP objects individually, then use    |
   | "Detailed Build Steps: CP" in topic 4.4 instead of the rest of this    |
   | step.                                                                  |
   |                                                                        |
   |________________________________________________________________________|
```

**1\.** Define your virtual storage and re\-IPL CMS\.

<a id="TBLTBLUNIQ148"></a>

```
 |                                                Define the storage to the maximum allowed
 | set machine xa                                 for your user ID; a minimum of 24m is
 | define storage 24m                             required.  Defining storage causes a system
 | STORAGE CLEARED - SYSTEM RESET                 reset.

 |                                                After receiving the version identification,
 | ipl 190 clear                                  press ENTER.
 | VM/ESA Release 2.0 mm/dd/yy hh:mm:ss
```

**2\.** Enter VMFSETUP to ensure correct access order:

<a id="TBLTBLUNIQ149"></a>

```
   vmfsetup esa cp
```

**3\.** To rebuild all serviced parts, enter the following command:

<a id="TBLTBLUNIQ150"></a>

```
   vmfbld ppf esa cp (serviced
```

```
 |      ___ Note ___________________________________________________________
       |                                                                    |
 |     | If you would like to change the default system national language   |
 |     | for CP you must rebuild the CP nucleus to contain the language.    |
 |     | To do this, follow the steps in Appendix C, "Changing System       |
 |     | National Language including UCENG" in topic C.0.                   |
       |                                                                    |
       |____________________________________________________________________|
```

**4\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use on\-line HELP\.

<a id="TBLTBLUNIQ152"></a>

```
   vmfview build
```
