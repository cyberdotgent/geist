#### 4\.3\.3 Select and Copy Serviced Files

<a id="HDRXCMSCRE"></a>

[Table 4\-12](<#TBLXCMSBL>) specifies build lists for CMS that require the select and copy build functions\.

<a id="TBLXCMSBL"></a>

```
    ________________________________________________________________________
   | Table  4-12. Build Lists for CMS Select and Copy Functions             |
   |_________________ ____________________________________ _________________|
   | Build List      | Description                        | Test/Production |
   |                 |                                    | Disk            |
   |_________________|____________________________________|_________________|
   | DMSBLHLP        | Build list for HELP files.         | 19D/19D         |
   |_________________|____________________________________|_________________|
   | DMSBLSRC        | Build list for new/replacement     | 493/193         |
   |                 | source files.                      |                 |
   |_________________|____________________________________|_________________|
   | DMSBL493        | Build list for EXEC/XEDIT/etc.     | 493/193         |
   |                 | files for the 493/193 disks.       |                 |
   |_________________|____________________________________|_________________|
   | DMSBLINF        | Build list for CMS/Dump Viewing    | 493/193         |
   |                 | Facility interface files.          |                 |
   |_________________|____________________________________|_________________|
   | DMSBL490        | Build list for EXEC/XEDIT/etc.     | 490/190         |
   |                 | files for the 490/190 disks.       |                 |
   |_________________|____________________________________|_________________|
   | DMSBLDOS        | Build list for CMS text decks used | 493/193         |
   |                 | by CMSDOS and CMSBAM.              |                 |
   |_________________|____________________________________|_________________|
```

**1\.** Enter the following command for each build list in [Table 4\-12](<#TBLXCMSBL>) that was identified in the $VMFBLD $MSGLOG\.

<a id="TBLTBLUNIQ306"></a>

```
   vmfbld ppf esa cms bldlist (serviced
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>), or use online HELP\.

<a id="TBLTBLUNIQ308"></a>

```
   vmfview build
```
