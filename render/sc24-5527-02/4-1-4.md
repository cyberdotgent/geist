#### 4\.1\.4 Rebuild the Executable MODULEs

<a id="HDRXSESEX"></a>

[Table 4\-4](<#TBLXSESXBL>) describes the build lists used to rebuild executable MODULEs\.

<a id="TBLXSESXBL"></a>

```
    ________________________________________________________________________
   | Table  4-4. Build Lists for Rebuilding Executable MODULEs              |
   |_________________ ____________________________________ _________________|
   | Build List      | Description                        | Test/Production |
   |                 |                                    | Disk            |
   |_________________|____________________________________|_________________|
   | VMFSLOAD        | Build list for VMSES/E MODULEs     | 490/190         |
   |                 | that reside on the system disk.    |                 |
   |_________________|____________________________________|_________________|
   | VMFMLOAD        | Build list for VMSES/E MODULEs     | 5E6/5E5         |
   |                 | that reside on the 5E5 disk.       |                 |
   |_________________|____________________________________|_________________|
```

For each of the build lists in [Table 4\-4](<#TBLXSESXBL>), complete these tasks:

**1\.** If any of the files in the build list have been serviced, enter the VMFBLD command to rebuild all of the serviced MODULEs in that build list:

<a id="TBLTBLUNIQ290"></a>

```
                                                  bldlist is the file name of one of the
   vmfbld ppf esa vmses bldlist (serviced         build lists in Table 4-4.
```

**2\.** Review the build message log \($VMFBLD $MSGLOG\)\. If necessary, correct any problems before going on\. For information about handling specific build messages, see [VM/ESA: System Messages and Codes](<DOCNUM/SC24-5529/CCONTENTS>) or use online HELP\.

<a id="TBLTBLUNIQ292"></a>

```
   vmfview build
```
