## 3.1.10 Diagnosing Scheduled SVC Dumps

<a id="HDRSCHED"></a>

For a scheduled SVC dump, you would not analyze the TCB/RB structure to | find an error. Often the software error percolates to a TCB in a | scheduled SVC dump. Use the SUMMARY FORMAT TCBERROR report to determine

if this is the case. See Problem Determination Guide for more information about diagnosing scheduled SVC dumps.
