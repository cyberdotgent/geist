The IPCS Utility Menu panel [Figure 4-9](4-3-7.md#UTIL1)) provides three options for copying data. To invoke it, select option 5 (Utility) from the IPCS Primary Option Menu panel. The following describes each utility option: 1 COPYDDIR: Use the COPYDDIR option to copy dump directory data from one dump directory data set into the current dump directory. This option provides the same function as the COPYDDIR subcommand. 2 COPYDUMP: Use the COPYDUMP option to copy the contents of an existing dump data set into a data set you specify. This option provides the same function as the COPYDUMP subcommand. 3 COPYTRC: Use the COPYTRC option to copy trace data from one or more dump or trace data sets into a data set you specify. This option provides the same function as the COPYTRC subcommand. For more information, press PF1 or type HELP to invoke the online help or

reference the corresponding subcommand in the IPCS Command Reference.
