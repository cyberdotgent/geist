## 7.7 Writing IPCS REXX Execs

There are four basic rules for writing an IPCS REXX exec: | 1. Change the host command environment to IPCS with the ADDRESS IPCS | instruction. | 2. Retrieve data from a dump using the EVALUATE subcommand, and store the | data in a REXX variable. | 3. Check the return codes from each subcommand invocation. | 4. Use the NOTE subcommand for output from the REXX exec. | The sections that follow describe each rule in detail.
