## 7.6.1 Retrieving Data From a Dump

| subcommands.

<a id="TBLUNIQ25"></a>

<a id="TBLTBLUNIQ25"></a>

| Subcommand | Purpose | Sample CLIST |
| --- | --- | --- |
| EVALDEF | Retrieve the SETDEF-defined defaults. | BLSCSETD |
| EVALDUMP | Retrieve a dump's description from the<br>dump directory. | BLSCEDUM |
| EVALMAP | Retrieve an entry from the IPCS storage | BLSCEMAP |
| EVALSYM | Retrieve an entry from the IPCS symbol | BLSCESYM |


| See IPCS Command Reference for more information about each subcommand.
