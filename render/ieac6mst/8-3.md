## 8.3 Copying and Clearing Dumps in Batch Mode

<a id="HDRCPY1"></a>

It is sometimes necessary to copy dump tapes to supply another location with a copy of the dump. It is particularly useful to be able to supply a dump tape with an authorized program analysis report (APAR). There are several methods, such as the IEBGENER utility program, that can

be used to copy a dump from one tape to another. [Figure 8-3](8-3.md#BATCP) shows how to use the IPCS COPYDUMP subcommand to copy a dump. Note that this job specifies IPCS NOPARM, to avoid accessing SYS1.PARMLIB.

<a id="BATCP"></a>

> `//IP`CS`JOB` `JOB 'acctinfo','I`P`CSU1 output',MSGLEVEL=(`1,1), // MSGC`LASS=A,CLASS=J,NOTIFY=IPCSU1` `//IPCS` `EXEC` `PGM=IKJEFT01,REGION=600K` /* `//IP`C`SD`D`IR DD DSN=IPCSU1.DUMP.DIR,DISP`=(SHR) addr`es`s `// DCB=(DSORG=PS,RECFM=FBS,BLKSIZE=29120,`LRECL=4160) addr`ess` `//`T`APEOUT DD UNIT=TAPE,LABEL=(2,NL),VOL=`SER=DMPOUT, addr`es`s `// DCB=(DSORG=PS,RECFM=FBS,BLKSIZE=29120,`LRECL=4160) `//SYSTSPRT` `DD` `SYSOUT=*` //SY`STSIN DD` `IPCS` `NOPARM` END /* Figure 8-3. Running the COPYDUMP Subcommand in Batch Mode.
