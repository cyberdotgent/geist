### 2.7.1 Address Processing Keywords

Not shown in the initial SETDEF display [Figure 2-3 in topic 2.7](2-7.md#SETD)) are the address processing keywords, ASID and CPU. The ASID and CPU keywords are null until you specify a dump data set. When you specify a dump and access it with a dump analysis subcommand, that subcommand sets the ASID and CPU keywords to describe an address space contained in that dump. If the dump contains multiple address spaces or if it is a stand-alone dump, the ASID keyword is set to the master scheduler's address space, . ASID(X'0001'). If it is a virtual dump of a single address space, the ASID keyword is set to the address space identifier of the address space in the dump. If the dump is a stand-alone dump and if a store status operation was performed, the CPU keyword is set to the IPLed central processor number. Otherwise, the CPU keyword is set to another processor in the configuration or NOCPU is used. SETDEF rejects any attempt to set these keywords before you specify a dump.
