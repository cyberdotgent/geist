### 4.4.1 Selection and Data Entry Panels

[Figure 4-4 in topic 4.3.4](4-3-4.md) is an example of a selection panel. On this panel select from a list of options by entering its number on the . COMMAND/OPTION [line. Figure 4-2 in topic](comments.md) 4.3.2 is an example of a data entry panel. On this panel, supply parameters by filling in labeled fields. Many fields retain previous values. The following table summarizes the primary commands and PF keys that can be used on the selection and data entry panels.

<a id="P1"></a>

<a id="P1"></a>

| When You Want to | Enter ===> | or Use PF Key |
| --- | --- | --- |
| Get help. | HELP | PF1 or 13 |
| Split the screen. | SPLIT | PF2 or 14 |
| End or cancel. | END | PF3 or 15 |
| Return to the previous screen. | RETURN | PF4 or 16 |
| Swap screens. | SWAP | PF9 or 21 |
| Move the cursor to the | CURSOR | PF12 or 24 |
| Invoke an IPCS subcommand, CLIST, | IPCS | ----------<br>or REXX exec. |
