## 2\.2 Alternative Methods for Accessing IPCS

<a id="HDRALTER"></a>

There are many ways to access IPCS\. Each method depends upon you or your installation's desire to change the default allocations and customize the access to IPCS\.

IPCS has several files which you can manually allocate to customize your session\. [Figure 2\-1](2-2.md#IPCSFIL) summarizes these files:

<a id="FIGIPCSFIL"></a>

<a id="TBLIPCSFIL"></a>

```

   |_____________________ ____________ ________________ ______________________|
 | | Data Set            | File       | Default        | More Information     |
   |_____________________|____________|________________|______________________|
 | | Dump directory      | IPCSDDIR   | userid.DDIR    | "Preparing a Dump    |
 | |                     |            |                | Directory" in        |
 | |                     |            |                | topic 5.1            |
```

The following procedure gives an alternative method for accessing IPCS\. This procedure shows the proper sequence for allocating the optional IPCS files and gives an example of how to perform each step using a TSO/E command\. ["Using a TSO/E Logon Procedure to Access IPCS" in topic 2\.5](2-5.md) and ["Using a CLIST to Access IPCS" in topic 2\.6](2-6.md) give other examples of how to access IPCS\. Remember that the procedure you should follow to access IPCS depends on the extent that you or your installation has customized the procedure\.

1\. **Logon to TSO/E\.**

2\. **Concatenate IPCS libraries**\. This step can be done anytime before step [10](2-2.md)\.

`ALLOCATE FILE(SYSPROC) DSN('SYS1.SBLSCLI0') SHR ALLOCATE FILE(ISPTLIB) DSN('SYS1.SBLSTBL0') SHR ALLOCATE FILE(ISPSLIB) DSN('SYS1.SBLSKEL0') SHR ALLOCATE FILE(ISPPLIB) DSN('SYS1.SBLSPNL0') SHR ALLOCATE FILE(ISPMLIB) DSN('SYS1.SBLSMSG0') SHR`

**Note:** If you receive a "FILE IN USE" message on the allocate, you will need to either free that file using the FREE command or specify the REUSE option on the ALLOCATE command\.

<a id="LIScvsam"></a>

3\. **Create your dump directory VSAM data set**, using the TSO/E DEFINE command\. If you already have a dump directory, skip to step [5](2-2.md)

`DEFINE CLUSTER(NAME('userid.DDIR') VOLUMES(VSAMnn) ) INDEX(NAME('userid.DDIR.I') TRACKS(1 1) ) DATA(NAME('userid.DDIR.D') CYLINDERS(1 1) KEYS(128 0) RECORDSIZE(384 3072) )`

See [Chapter 5, "Using the IPCS Dump Directory" in topic 5\.0](5-0.md) for more information\.

<a id="LISinitdir"></a>

4\. **Initialize the dump directory data set** you just created using the TSO/E IPCSDDIR command:

`IPCSDDIR 'userid.DDIR'`

See [Chapter 5, "Using the IPCS Dump Directory" in topic 5\.0](5-0.md) for more information\.

<a id="LISalcdir"></a>

5\. **Allocate the dump directory data set** by entering the following TSO/E command:

`ALLOCATE DDNAME(IPCSDDIR) DATASET('userid.DDIR') SHR`

See [Chapter 5, "Using the IPCS Dump Directory" in topic 5\.0](5-0.md) for more information\.

<a id="LISalcprt"></a>

6\. **Allocate a print file** if you plan on printing any IPCS output\. You can assign a data set or a SYSOUT class:

`ALLOCATE DDNAME(IPCSPRNT) SYSOUT(A)`

See ["Print and Table of Contents Files" in topic 9\.1](9-1.md) for instructions on creating and using the print file\.

<a id="LISal"></a>

7\. **Allocate a table of contents file** if you plan on printing any IPCS output and want a table of contents of the output\. You can assign a data set or a SYSOUT class:

`ALLOCATE DDNAME(IPCSTOC) SYSOUT(A)`

See ["Print and Table of Contents Files" in topic 9\.1](9-1.md) for instructions on creating and using the table of contents file\.

8\. **Allocate a parmlib data set** if you want to use something other than SYS1\.PARMLIB\.

`ALLOCATE DDNAME(IPCSPARM) DSN('DEPTXYZ.PARMLIB' 'SYS1.PARMLIB') SHR`

See ["Providing Format and Analysis Support" in topic 1\.2\.4](1-2-4.md) for more information\.

9\. **Start an IPCS line mode session**, by entering the TSO/E IPCS command\.

`IPCS`

See ["Specifying Parameters on the IPCS Command" in topic 2\.3](2-3.md) for information on specifying parameters on the IPCS command\.

<a id="LISstdia"></a>

10\. **Start the IPCS dialog\.** You can either go into ISPF to invoke the IPCS dialog or enter the following TSO/E command:

`ISPSTART PGM(BLSG) NEWAPPL(BLSG) PASSLIB PARM(PANEL(BLSPPRIM))`

See ["Starting the IPCS Dialog" in topic 2\.4](2-4.md) for more information\.
