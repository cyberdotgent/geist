## 7.4 Using IPCS-Supplied CLISTs to Print Dump Analysis Reports

| IPCS provides a set of CLISTs to print dump analysis reports.  The CLISTs

in the following sections must be invoked from TSO/E. (See ["Using](7-3.md) [IPCS-Supplied CLISTs to Analyze Dumps" in topic 7.3](7-3.md) to submit these | reports from an IPCS session.) They are designed to be submitted as batch | jobs using the cataloged procedure BLSJIPCS, alias IPCS. You can print | these reports from SYSOUT or send the reports directly to IPCSPRNT file. For more information, see [Chapter 8, "Using IPCS in Batch Mode" in](8-0.md) [topic 8.0](8-0.md).
