## 5\.4 Using the Storage Map

<a id="HDRSTRMAP"></a>

IPCS maintains a map of the dumped storage in the dump directory\. IPCS creates the storage map as you enter subcommands\. The storage map contains information that makes future references to that dump faster and more efficient\.

The storage map is a list of dump addresses and data types\. IPCS organizes the storage map for a dump by addresses in ascending order, then by address space, address within the address space, and data type\. The data type describes the contents of the storage area at the address with which the data type is associated\. The storage area can contain a control block, a module, or an area of storage such as an I/O buffer\.

Each storage map entry contains a pointer to the dump records that contain the corresponding storage\. An entry is added to the storage map whenever a name is specified with the STRUCTURE keyword \(indicating a control block\), the MODULE keyword \(indicating a module\), or the AREA keyword \(indicating an area in storage\) on subcommands that accept these data description operands\.

**Note:** IPCS does not create a storage map when you process live storage \(specified by the ACTIVE, MAIN, or STORAGE keyword\)\.
