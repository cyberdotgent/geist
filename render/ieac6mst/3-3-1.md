| When You Want to | Use this Subcommand |
| --- | --- |
| Check resource contention | ANALYZE |
| Display access register data | ARCHECK |
| Display ASCB-related data areas | ASCBEXIT |
| Format selected control blocks | CBFORMAT |
| Check the status of a control block or | CBSTAT<br>unit of work |
| Search for a module by name | FINDMOD |
| Search for a UCB | FINDUCB |
| Display a map of the link pack area | LPAMAP |
| Retrieve a name/token pair | NAMETOKN |
| Identify address spaces satisfying | SELECT<br>specified selection criteria |
| Display system status at the time of the | STATUS<br>dump |
| Display formatted control blocks | SUMMARY |
| Display TCB-related data areas | TCBEXIT |
| Identify area(s) containing a given | WHERE |
