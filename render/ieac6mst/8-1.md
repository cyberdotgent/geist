## 8.1 Running CLISTs and REXX Execs in Batch Mode

<a id="HDRBATCLRX"></a>

[Figure 8-1](8-1.md) gives the JCL needed to run the BLSCSCAN CLIST, which formats a problem screening report for a stand-alone dump. Note the following: The batch job allocates the dump directory, IPCSU1.DUMP.DIR, assuming that an existing dump directory data set is created and initialized. IPCSPARM is needed only if you or your installation has its own IPCS exit routines or specifies other IPCS initialization parameters. If IPCSPARM is omitted, the IPCS parameters from SYS1.PARMLIB are dynamically allocated. You can substitute %BLSCSCAN with another CLIST or REXX exec. | However, ensure that the CLIST or REXX exec is identified through the SYSPROC DD statement.
