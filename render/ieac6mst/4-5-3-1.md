#### 4.5.3.1 Scrolling Through the Storage Panel

Several techniques can be used for scrolling: Scrolling can be accomplished using the UP and DOWN primary commands that are entered manually or by using PF keys. Selection codes % an**d** c**a**n be used to scroll to storage addressed by a word of formatted storage. The LOCATE primary command can be used to scroll to an address.
