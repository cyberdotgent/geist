## 5.1 Preparing a Dump Directory

ST| Preparing a Dump Directory | Preparing a dump directory for an IPCS session is a three-step process: | 1. Create a VSAM data set. | 2. Initialize the VSAM data set as a dump directory. | 3. Allocate the VSAM data set to file IPCSDDIR. | IPCS provides the BLSCDDIR CLIST in SYS1.SBLSCLI0 to automate these three

| steps. See ["Using the BLSCDDIR CLIST" in topic 5.1.](5-1-5.md) 5. The IPCS command | automatically invokes BLSCDDIR to prepare a dump directory using the | defaults in BLSCDDIR. If you want to customize your own dump directory, | the following sections detail the steps to preparing a dump directory.
