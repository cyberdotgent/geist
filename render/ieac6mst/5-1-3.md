### 5.1.3 Initializing the Dump Directory

IPC`SDDIR 'u`s`erid.DDIR'`

**Note:** You do not need to initialize your dump directory for each IPCS session. If the initialization is successful, the system displays the following message:

REA`DY` The IPCSDDIR command writes two records to the dump directory: one with a . key of binary zeros (0) and the other with a key of binary ones (1).
