## 2\.1 Quick Method for Accessing IPCS

<a id="HDRQUICK2"></a>

<pre>
 | This method is recommended only if you or your installation has not
 | customized access to IPCS.  This method uses the IPCS defaults for
 | creating a dump directory and allocating IPCS files.  This method does not
 | allocate the IPCS print data set or activate the problem and data set
 | management functions.  See <a href="2-2.md">"Alternative Methods for Accessing IPCS" in</a>
 | <a href="2-2.md">topic 2.2</a> for more information.
 | To start IPCS, do the following:
 | 1.  Logon to TSO/E
 | 2.  Add SYS1.SBLSCLI0 or a copy of it to your SYSPROC data set
 |     concatenation. The ALLOCATE command is one way of doing this; your
 |     installation may have another command to add data sets to the SYSPROC
 |     concatenation.
 |        ALLOCATE FILE(SYSPROC) DSN('SYS1.SBLSCLI0') SHR REUSE
 |     Note:  If your installation has applied the IPCS support for REXX
 |     execs and the TSO/E ALTLIB command (APAR OY46507), use the ALTLIB
 |     command instead of ALLOCATE, as follows:
 |        ALTLIB ACTIVATE APPLICATION(CLIST) DA('SYS1.SBLSCLI0')
 | 3.  Start an IPCS session by entering the TSO/E command:
 |        IPCS NOPARM
 |     NOPARM indicates that you will not use the IPCS problem management and
 |     data set functions during this session.
 |     The IPCS command invokes the BLSCDDIR CLIST in SYS1.SBLSCLI0.
 |     BLSCDDIR allocates your dump directory data set.  The following
 |     messages appear at your terminal:
 |        Dump directory name 'userid.DDIR' will be used
 |        ALLOCATE FILE(IPCSDDIR) REUSE DSNAME('userid.DDIR') SHR
 |        Dump directory 'userid.DDIR' allocated to FILE(IPCSDDIR)
 |        IPCS
 |     If you do not already have a dump directory, BLSCDDIR defines and
 |     initializes one before allocating it.  The following messages appear
 |     at your terminal:
 |        Dump directory name 'userid.DDIR' will be used
 |        Dump directory space will be allocated in units of 5000 records
 |        Dump directory space will be allocated on volume VSAM01
 |        DEFINE CLUSTER(NAME('userid.DDIR') VOLUME(VSAM01) INDEXED REUSE SHAREOPTIONS(1,3)
         ) INDEX(NAME('userid.DDIR.I') RECORDS(10,10) CISZ(2048)) DATA(NAME('userid.DDIR.D')
 |       RECORDS(5000,5000) CISZ(4096) KEYS(128,0) RECORDSIZE(384 3072))
 |        IDC0508I DATA ALLOCATION STATUS FOR VOLUME VSAM01 IS 0
 |        IDC0509I INDEX ALLOCATION STATUS FOR VOLUME VSAM01 IS 0
 |        IPCSDDIR 'userid.DDIR'
 |        ALLOCATE FILE(IPCSDDIR) REUSE DSNAME('userid.DDIR') SHR
 |        Dump directory 'userid.DDIR' allocated to FILE(IPCSDDIR)
 |        IPCS
 |     An "IPCS" prompt replaces the READY prompt.  The IPCS prompt indicates
 |     that IPCS line mode is active.  You can proceed to the IPCS dialog or
 |     use IPCS in line mode.  If you would like to use IPCS line mode, see
 |     <a href="2-7.md">"Setting Session Defaults" in topic 2.7</a> to establish the defaults for
 |     your IPCS session.
 | 4.  Start the ISPF dialog by entering the following at the IPCS prompt:
 |        ISPF
 |     Note:  Do not use the subcommand "TSO ISPF" when invoking ISPF.  See
 |     <a href="2-4-1.md">"Invoking ISPF under IPCS" in topic 2.4.1</a> for information about
 |     invoking ISPF in any other way.
 |     Successful processing displays the ISPF/PDF Primary Option Menu (or
 |     installation-provided menu).
 | 5.  Choose option 6 or TSO commands from the ISPF menu:
        __________________________________________________________________________________
       |                                                                                  |
 |     | -------------------- ISPF PRIMARY OPTION MENU --------------------               |
 |     |  OPTION  ===&gt; 6                                                                  |
       |                                                                                  |
 | 6.  Start the IPCS dialog by enterning the following command at the
 |     prompt:
 |        EX 'SYS1.SBLSCLI0(BLSCLIBD)'
 |     The BLSCLIBD CLIST starts the IPCS dialog.
</pre>
