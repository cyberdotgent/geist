# 8.0 Chapter 8.  Using IPCS in Batch Mode

<a id="HDRBATACC"></a>

IPCS can be used under the TSO/E terminal monitor program (TMP) in a batch job. Consider submitting a batch job when you:

| Perform time-consuming dump analysis with long REXX execs and CLISTs Use IPCS subcommands to print selected portions of a dump Load or unload system dump data sets from tape or mass storage Some IPCS subcommands have restrictions when using IPCS in batch mode. These restrictions are documented with the applicable subcommand. TSO/E, which is recommended for batch job processing, removes most restrictions and permits interactive and batch use of IPCS to be almost completely interchangeable. | A batch job can run IPCS with either TSO/E or the TSO base. However, the | TSO base does not support REXX exec or CLIST processing. The system must | have TSO/E to run IPCS REXX execs and CLISTs. | When you submit IPCS batch jobs, the job gets exclusive access to a dump | directory. The reports go the held output queue or IPCS print data set. | You cannot use the dump display reporter panel to browse the results. | Printing the analysis results is optional. You might want to write the | results to an IPCS print data set and browse the results. [Chapter 2, "Accessing IPCS" in topic 2.0](2-0.md) explains the methods for accessing IPCS and [Chapter 9, "Printing IPCS Reports" in topic 9.0](9-0.md)| explains how to direct output from an IPCS session. They also give the | files that must be allocated for any IPCS session. These conventions | should be followed when coding the JCL. [Figure 8-1 in topic 8.1](8-1.md#BATBLSC) through [Figure 8-3 in topic 8.3](8-3.md#BATCP) provide the JCL needed to run IPCS in batch mode. They are examples of how to perform dump analysis, dump formatting, and utility functions respectively.
