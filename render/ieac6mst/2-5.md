## 2.5 Using a TSO/E Logon Procedure to Access IPCS

<a id="HDRINSTAL"></a>

Some installations provide a TSO/E logon procedure to concatenate IPCS

libraries. IPCS Customization gives an example of how to do this. If the logon procedure concatenates the necessary data sets, all you have to do is enter the IPCS command from the READY prompt: `IPCS` `NOPARM` This command indicates that the IPCS session is for problem analysis only. See ["Specifying Parameters on the IPCS Command" in topic 2.3](2-3.md) for information on specifying parameters on the IPCS command. To access the IPCS dialog, see ["Starting the IPCS Dialog" in topic 2.4](2-4.md). If you would like to use IPCS in line mode, see ["Setting Session Defaults"](2-7.md) [in topic 2.7](2-7.md) to establish your session and report defaults.
