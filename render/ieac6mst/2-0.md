# 2\.0 Chapter 2\. Accessing IPCS

<a id="HDRACCESS"></a>

This section explains how to start the IPCS dialog in your TSO/E session\. If you want to use IPCS in line mode, follow the instructions until the IPCS prompt replaces the READY prompt from your TSO/E session\.

There are many different ways to access IPCS\. This section gives two methods\. The first method assumes that you or your installation has not provided some customized process for accessing IPCS\. It should work every time; however, your installation may not recommend using this method\. The second method details every possible step for beginning an IPCS session\. You can see all of the steps covered up by the automatic procedures used in the first method\.
