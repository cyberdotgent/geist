### 3\.4\.2 End an IPCS Session

End an IPCS session with the END subcommand\. To end your IPCS session, enter:

`end`

END requires no parameters\. It closes any data sets opened during the session and frees any files allocated by IPCS initialization\. It then ends the IPCS session and returns you to the terminal monitor program \(TMP\)\.

Unless you want to use them later in your TSO/E session, free the following data sets that you allocated to the session:

- Your dump directory, FILE\(IPCSDDIR\)
- Your print and table of contents data sets
- Your dump data sets that you allocated for access by file name
