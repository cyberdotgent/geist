### 5\.1\.5 Using the BLSCDDIR CLIST

<a id="HDRUSEBLSD"></a>

IPCS supplies the BLSCDDIR CLIST to create or modify a dump directory\. Use this CLIST to:

- Create a dump directory when accessing IPCS
- Create dump directories to satisfy special needs
- Create multiple dump directories \-\- for example, to use for simultaneous interactive and batch processing

When you start an IPCS session, the IPCS command invokes BLSCDDIR automatically\. BLSCDDIR uses installation\-defined defaults for data set name, size, volume, and associated file name\. The system programmer at your installation determines the size and volume default values that best suit your installation's needs using information found in *IPCS Customization*\.

You can create a dump directory for your own special uses by passing parameters on the CLIST invocation\. See the BLSCDDIR CLIST in *IPCS Command Reference* for a description of those parameters\.
