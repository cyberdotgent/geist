# 7.0 Chapter 7.  Using IPCS REXX Execs and CLISTs

ST| Chapter 7. Using IPCS REXX Execs and CLISTs | IPCS subcommands can be entered from a REXX exec or CLIST. IPCS supplies

| IPCS allow you to: | Obtain a standard set of dump analysis reports | Print system storage areas | Customize an IPCS session | Write your own IPCS REXX execs and CLISTs. | The system must have TSO/E to run IPCS REXX execs and CLISTs. The TSO | base does not support REXX exec or CLIST processing. The system also must | have the PTFs associated with APAR OY46507 to run REXX execs and use the | TSO/E ALTLIB command in IPCS. | This chapter explains how to do the following: | Invoke a REXX exec or CLIST from an IPCS session | Use some of the REXX execs and CLISTs provided with IPCS | Write IPCS REXX execs and CLISTs | Use IPCS subcommands in REXX execs and CLISTs.
