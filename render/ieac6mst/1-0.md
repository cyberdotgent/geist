# 1\.0 Chapter 1\. Introduction to IPCS

<a id="HDRIPCSINT"></a>

The interactive problem control system \(IPCS\) is a tool provided with MVS/System Product [\(\*\)](<#FTNFTNUNIQ2>) \(SP\) to aid in diagnosing software failures\. IPCS provides formatting and analysis support for dumps and traces produced by MVS/SP and other program products and applications that run on MVS/SP\.

This book only describes how to use IPCS to diagnose software problems\. It does not try to explain MVS/SP system concepts, such as error recovery or dumping and tracing services\. Instead you should reference the following books for that information:

- *Planning: Problem Determination and Recovery* describes how to obtain dumps and traces and how to plan for running IPCS on MVS/ESA SP Version 4 systems\.
- *Problem Determination Guide* gives procedures for diagnosing problems on MVS/ESA SP Version 4 systems\.
