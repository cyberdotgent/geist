## B.2 Example of JCL to Print, Copy, and Clear a Dump Data Set

```text
   Many users of PRDMP previously ran a job that would do the following:

   ° Perform specified analysis on the SYS1.DUMPnn data set.

   ° Copy the dump to either another data set, a generation data group
   ° (GDG) data set or a tape.

   ° Clear the SYS1.DUMPxx source data set so that it is available to the
   ° system for the next dump request.

   ° The following JCL shows an example of how to accomplish the above
   ° functions using IPCS:
```
