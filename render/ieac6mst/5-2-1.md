### 5\.2\.1 Processing Sources Both in Batch and Interactively

If you ask IPCS to use a dump directory that is being used by another IPCS session, IPCS responds with this message:

`BLS21101I Dump directory ipcsu1.dir is in use -- try later`

If you submit a background job that initiates an IPCS session, and another IPCS session is using the dump directory required by the background job, IPCS waits for the dump directory to become available to process the job\.

If you want to process a dump or trace interactively without tying up or waiting for the dump directory from the batch IPCS session, you must use a different dump directory\.

The following procedure explains how to copy the description of a dump or trace from the dump directory used in the batch IPCS session to the current dump directory\. In this example, SYS1\.DDIR is the name of the dump directory used for batch processing\.

1\. From the IPCS Primary Option Menu, choose option 5\.1 \(COPYDDIR\)\.

2\. Specify the source data set name or file name and the name of the dump directory used in batch\.

```
        __________________________________________________________________________________
       |                                                                                  |
 |     |  ----------------------------- Copy Dump Directory Data -----------------------  |
 |     |  COMMAND  ===>                                                                   |
       |                                                                                  |
 |     |  Enter or verify the parameters to copy data to your current dump directory.     |
 |     |  Use ENTER to copy data, END to terminate.                                       |
       |                                                                                  |
 |     |  Copy these DUMP DESCRIPTIONS (specify one or both of the following):            |
 |     |     DSNAMEs ===> 'D46IPCS.DUMP.SVCVER4'                                          |
 |     |     DDNAMEs ===>                                                                 |
       |                                                                                  |
 |     |  From this DUMP DIRECTORY ===> 'SYS1.DDIR'                                       |
       |                                                                                  |
       |__________________________________________________________________________________|
```

3\. Press Enter\. IPCS displays the following output:

`Description of Dump Records Bytes DSNAME('D46IPCS.DUMP.SVCVER4') . . . . . . . . . . . 506 . . . . . 141,881 1 dump description copied`

4\. Press PF3 to return to option 5\.1, which tells you that the copy function is complete:

```
        __________________________________________________________________________________
       |                                                                                  |
 |     |  ----------------------------- Copy Dump Directory Data --------- COPY COMPLETE  |
 |     |  COMMAND  ===>                                                                   |
       |                                                                                  |
 |     |  Enter or verify the parameters to copy data to your current dump directory.     |
 |     |  Use ENTER to copy data, END to terminate.                                       |
       |                                                                                  |
 |     |  Copy these DUMP DESCRIPTIONS (specify one or both of the following):            |
 |     |     DSNAMEs ===> 'D46IPCS.DUMP.SVCVER4'                                          |
 |     |     DDNAMEs ===>                                                                 |
       |                                                                                  |
 |     |  From this DUMP DIRECTORY ===> 'SYS1.DDIR'                                       |
       |                                                                                  |
       |__________________________________________________________________________________|
```
