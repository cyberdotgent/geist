## B.1 Sample of JCL for Printing Dumps Using IPCS

```text
   The following JCL prints a dump, using IPCS, from the system dump data
   set:
```

<a id="IPCSJOB"></a>

`//SUMDUMP` `JOB` //S `EXE`C `PGM`=`IKJEFT01,DYNAMNBR=20,REGION=1500K` `//DUMP` `DD` `DSN=SYS1.DUMP02,DISP=SHR` `//SYSPROC` `DD` `DSN=SYS1.SBLSCLI0,DISP=SHR` `//SYSTSPRT` `DD` `SYSOUT=A` `//IPCSPRNT` `DD` `SYSOUT=A` `//IPCSTOC` `DD` `SYSOUT=A` `//SYSUDUMP` `DD` `SYSOUT=A`

`PROFILE` `MSGID` `%BLSCDDIR` `VOLUME` `(vsampk)` `IPCS` `NOPARM` `SETDEF` `DSN('SYS1.DUMP02')` `NOCONFIRM` `VERBEXIT` `SUMDUMP` /* Figure B-1. Example JCL to Print a Dump with IPCS.

```text
    ________________________________________________________________________ 
   |                                                                                  |
   |                                                                                  |
    _____________________________________________________________ 
   |   //SYSTSIN DD *                                                                 |
```

vsampk is any VSAM volume. You may also replace VERBEXIT SUMDUMP with SUMMARY FORMAT, or %BLSCBSVB, or other IPCS commands, or CLISTS.
