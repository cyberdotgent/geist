### 5\.1\.2 Creating a Dump Directory VSAM Data Set

Use the DEFINE command to create the VSAM data set\.

`DEFINE CLUSTER(NAME('userid.DDIR') VOLUMES(VSAMnn) REUSE) INDEX(NAME('userid.DDIR.I') TRACKS(1 1) ) DATA(NAME('userid.DDIR.D') CYLINDERS(1 1) KEYS(128 0) RECORDSIZE(384 3072) )`

If the creation is successful, the system displays the following messages:

`IDC0508I DATA ALLOCATION STATUS FOR VOLUME VSAMnn IS 0 IDC0509I INDEX ALLOCATION STATUS FOR VOLUME VSAMnn IS 0 READY`

The DEFINE command creates three data sets:

*userid*\.DDIR *userid*\.DDIR\.I *userid*\.DDIR\.D

The dump directory is a VSAM key\-sequenced cluster with the characteristic SHAREOPTIONS\(1\)\. SHAREOPTIONS\(1\) data sets cannot be open for concurrent update by multiple users \(or a user and that user's own batch jobs\)\. Only one IPCS session can use a dump directory at a given time\.

**Notes:**

1\. You can replace *userid*\.DDIR with data set names meaningful to you if you prefer\.

2\. Use a continuation character for each line as appropriate\.

3\. Check with your installation data base administrator regarding the specification of VSAM volumes\. To promote consistent practices within your installation, you might be asked to use an installation\-supplied CLIST that creates and initializes your dump directory\. See ["Using](5-1-5.md) [the BLSCDDIR CLIST" in topic 5\.1\.5](5-1-5.md)\.
