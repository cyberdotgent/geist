## 3.4.5 Invoking TSO/E Commands During an IPCS Session

<a id="HDRTSOE"></a>

Use the TSO subcommand to do any of the following while in IPCS: Enter TSO/E mode Invoke a TSO/E command Invoke a CLIST or REXX exec containing TSO/E commands CLISTs and REXX execs containing TSO/E commands can also be invoked

without using the TSO subcommand. See [Chapter 7, "Using IPCS REXX Execs](7-0.md) [and CLISTs" in topic 7.0](7-0.md) for more information. Enter TSO/E Mode: In line mode or batch mode IPCS, you can enter the TSO | subcommand without a command or CLIST or REXX exec invocation to suspend IPCS subcommand processing and enter TSO/E mode. Then, commands entered in TSO/E mode are processed as TSO/E commands until END is entered to resume IPCS processing. When the END subcommand is entered, the highest return code from the TSO/E command processing is returned. Invoke a TSO/E Command: Use the TSO subcommand to enter TSO/E commands whose names are identical to IPCS subcommands *except* *when* *invoking* *ISPF*. See ["Invoking ISPF under IPCS" in topic 2.4.1](2-4-1.md) for information about running ISPF under IPCS. For example, to request the display of status for all batch jobs whose job name begins with your TSO/E userid, enter: ts`o s`t`atus` If you do not precede the STATUS command with TSO, the IPCS STATUS subcommand is processed. If TSO/E Release 2 is installed, you may enter installation-defined authorized commands, as well as authorized TSO/E commands, such as TRANSMIT and RECEIVE (as determined by your installation). Otherwise, such commands end abnormally. Invoke a CLIST or REXX Exec Containing TSO/E Commands: You can use the | TSO subcommand to invoke a CLIST or REXX exec containing TSO/E commands. | You can do this in any of the three IPCS processing modes. A CLIST or | REXX exec invoked with the TSO subcommand can contain any or all of the following: TSO/E commands whose names are identical to IPCS subcommands. Using the TSO subcommand ensures that the TSO/E command is invoked instead of an IPCS subcommand of the same name. Any TSO/E command. Any TSO/E command can be included in a CLIST invoked using the TSO subcommand. c.cp 999 TSO/E authorized commands in conjunction with a TSO/E function such as SYSOUTTRAP.
