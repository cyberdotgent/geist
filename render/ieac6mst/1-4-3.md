### 1\.4\.3 IPCS Messages and User Completion Codes

IPCS issues its own set of TSO/E messages\. These messages identify problems with the IPCS session or problems with the data in a dump or trace data set\. See *Dump Output Messages* for explanations\.

If an abend occurs during IPCS processing, IPCS ends with a completion code\. You can find these codes and the procedure for diagnosing the problems in *Diagnosis: Component Reference*\.
