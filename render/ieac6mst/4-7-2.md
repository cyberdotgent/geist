### 4\.7\.2 Entering Dialog Commands

IPCS uses dialog commands in the same manner as ISPF uses them\. Consisting of primary commands and line commands, dialog commands provide browsing and editing capabilities when viewing dump data in full\-screen mode\.

Enter primary commands on the COMMAND/OPTION line of a panel\. Enter line commands by typing the command at the beginning of the output line\.

IPCS defines a set of dialog commands for its own use\. However, ISPF primary commands, such as CURSOR, HELP, SPLIT, and SWAP, can also be used\. ["IPCS Dialog Panels" in topic 4\.4](4-4.md) summarizes the valid IPCS and ISPF dialog commands\.
