The IPCS primary option menu panel [Figure 4-1](4-3.md#BLSPRIM)) first appears when you access the IPCS dialog. (To access the IPCS dialog, see ["Accessing the](4-2.md) [IPCS Dialog" in topic 4.2](4-2.md).) This panel organizes all the features of the IPCS dialog into the following options: 0 DEFAULTS: Use the Defaults option to review and update IPCS default values. See ["Option 0 -- DEFAULTS" in topic 4.3.2](4-3-2.md). 1 BROWSE: Use the Browse option to display a requested dump in full-screen mode. See ["Option 1 -- BROWSE" in topic 4.3.3](4-3-3.md). 2 ANALYSIS: Use the Analysis option to analyze the status of the MVS system and its components as they are represented in an MVS dump data set. See ["Option 2 -- ANALYSIS" in topic 4.3.4](4-3-4.md). 3 SUBMIT: Use the Submit option to submit problem analysis jobs for batch processing. See ["Option 3 -- SUBMIT" in topic 4.3.5](4-3-5.md).

4 COMMAND: Use the Command option to enter subcommands, CLISTs, or REXX | execs directly on the IPCS command entry panel. By using the COMMAND option, IPCS can display the output of subcommands, CLISTs, or REXX execs

on a dump display reporter panel. See ["Option 4 -- COMMAND" in](4-3-6.md) [topic 4.3.6](4-3-6.md). 5 UTILITY: Use the Utility option to copy dump directory information from an existing dump directory to the current dump directory, to copy dump data from one dump data set to another, or to copy trace data from one data set to another. See ["Option 5 -- UTILITY" in topic 4.3.7](4-3-7.md). 6 DUMPS: Use the Dumps option to review and manage the list of dumps in the IPCS dump directory. See ["Option 6 -- DUMPS" in topic 4.3.8](4-3-8.md). T TUTORIAL: Use the Tutorial option to see online instruction in the use of the IPCS dialog. You can view the tutorial sequentially from beginning to end, or randomly by selecting topics from its table of contents. You can also use the ISPF HELP command from any panel in the IPCS dialog. The HELP command is normally associated with program function (PF) keys 1 or 13. See ["Option T -- TUTORIAL" in topic 4.3.9](4-3-9.md). X EXIT: Use the Exit option to leave the IPCS dialog. If you entered the IPCS dialog directly when you activated ISPF, ISPF also ends. Note that ISPF uses its defaults regarding the disposition of LIST and LOG data sets without prompting you. The **END** primary command also ends the IPCS dialog. If you entered the IPCS dialog directly when you activated ISPF, ISPF also ends (as it does with EXIT), but ISPF prompts you to decide how to dispose of LIST and LOG data sets used during the ISPF session.
