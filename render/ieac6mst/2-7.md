## 2.7 Setting Session Defaults

<a id="HDRCTLSETD"></a>

Now that you have successfully accessed IPCS, you need to identify to IPCS the source that you want to examine. If you are using IPCS for the first time or if you just created and initialized a new dump directory, specify the source through the SETDEF subcommand. For example, to tell IPCS to use dump data set d83dump.sys220sv.sv30036 as the current source, specify:

SETD`EF DSN`A`ME('d83dump.sys220sv.sv30036')` Unless changed during your IPCS session, the next time that you access IPCS, d83dump.sys220sv.sv30036 will still be in effect. SETDEF remembers the current source and other subcommand default keywords as well.

**Note:** You can use option 0 (DEFAULTS) of the IPCS dialog to set many of the SETDEF defaults.

When you begin an IPCS session, IPCS establishes these SETDEF-defined default values that remain in effect until you explicitly change them. IPCS sets these values from the session parameters member (IPCSPRxx) and from saved SETDEF values obtained from the dump directory or IPCS standard values of the SETDEF subcommand keywords. By taking the time to set up the default keywords with the SETDEF subcommand when you first begin your IPCS session, you save yourself the trouble of specifying them on each subcommand to which they apply. The IPCS Command Reference has grouped all the SETDEF-defined keywords in the syntax diagrams, thereby identifying those keywords unique to a subcommand. See IPCS Command Reference for an explanation of the SETDEF-defined keywords.
