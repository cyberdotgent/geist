### 1\.4\.2 Running Different Levels of IPCS

<a id="HDRSPMIX"></a>

The release level of IPCS must match the release level of the system that produced the dump\. You must use the MVS/ESA SP Version 4\.2\.0 libraries of IPCS code, for example, to analyze a dump or trace produced by the MVS/ESA SP Version 4\.2\.0 system\.

Although IPCS and the dump or trace must have matching release levels, you can run IPCS on different release levels of the system\. The IPCS code shipped with any release of MVS/ESA SP Version 4 can run on any MVS/ESA SP Version 3 or MVS/XA Version 2 system\. For example, if your system is at the MVS/SP Version 4 level, you can run an MVS/SP Version 3 level of IPCS on your MVS/SP Version 4 system\. This allows you to analyze software problems from MVS/SP Version 3 systems without having to maintain an MVS/SP Version 3 system\. See *IPCS Customization*\. for requirements on running IPCS on different release levels of MVS\.
