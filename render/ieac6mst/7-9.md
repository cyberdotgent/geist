 | When writing CLISTs that contain TSO/E commands, you must consider the
 | environment in which the CLIST will run when designing the CLIST.  This is
 | especially important when designing CLISTs that contain both TSO/E
 | commands and IPCS subcommands.
 | When you invoke a CLIST from the IPCS dialog, the CLIST can use IPCS
 | subcommands to place information in ISPF function pool dialog variables
 | and can use the ISPEXEC subcommand to request dialog services that use the
 | dialog variables.  If TSO/E Release 2 is not installed, ISPF has no
 | knowledge of any CLIST variables used in a CLIST initiated through this
 | panel.  Therefore, such CLISTs cannot reference ISPF variables.
 | Given this flexibility, the functions that can be used in a CLIST are
 | dependent on the environment from which you invoke the CLIST.  Before you
 | write the CLIST, decide what environment you will typically invoke the
 | CLIST from.  Then review Figure 7-13 for restrictions.
