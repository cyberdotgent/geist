### 5\.3\.3 Subcommands for Maintaining The Symbol Table

IPCS provides five subcommands to maintain the symbol table:

<a id="FIGTBLUNIQ16"></a>

<a id="TBLTBLUNIQ16"></a>

```
    ____________________________________________ _____________________________
   | When You Want to                           | Use this Subcommand         |
   |____________________________________________|_____________________________|
   | Delete symbols from the symbol table       | DROPSYM                     |
   |____________________________________________|_____________________________|
   | Create a symbol with a user-defined name   | EQUATE                      |
   |____________________________________________|_____________________________|
   | List symbols and their attributes in the   | LISTSYM                     |
   | symbol table                               |                             |
   |____________________________________________|_____________________________|
   | Renumber all stack symbols in the symbol   | RENUM                       |
   | table                                      |                             |
   |____________________________________________|_____________________________|
   | Add a pointer (symbol Znnnnn) to the IPCS  | STACK                       |
   | pointer stack                              |                             |
   |____________________________________________|_____________________________|
```

```
    ___ Reference __________________________________________________________
   |                                                                        |
   | See IPCS Command Reference for the syntax and examples of each         |
   | subcommand.                                                            |
   |                                                                        |
   |________________________________________________________________________|
```
