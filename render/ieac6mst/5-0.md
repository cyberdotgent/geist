# 5\.0 Chapter 5\. Using the IPCS Dump Directory

<a id="HDRDDIRINT"></a>

An IPCS dump directory is a VSAM data set that contains information about a dump, a trace, or any other source that IPCS processes\. IPCS uses the dump directory to process sources efficiently\.

A dump directory consists of the following:

- A table of symbols representing control blocks and other data areas
- A mapping of the dump storage
- Other records used by IPCS to describe dump and trace data sets and retain defaults between IPCS sessions\.

The symbol table provides a convenient way to reference a location in a dump using a label instead of an address\. The storage map shows which control blocks, modules, and storage areas fall within a section of storage\. The other records contain, among other things, pointers to the dump records that contain the storage associated with a map entry or a symbol\.

A dump directory is allocated when you access IPCS\. See [Chapter 2,](2-0.md) ["Accessing IPCS" in topic 2\.0](2-0.md) for more information about how this is done\. You can use only one dump directory at a time during an IPCS session\.

Each IPCS user should have their own dump directory\. That way, users can establish defaults for their own IPCS sessions\. IPCS records the defaults in the dump directory when the user sets them and reinstates the defaults at the beginning of the user's next IPCS session\.

This chapter explains how to change the dump directory and gives more details about the contents of the dump directory\.

*Using Multiple Dump Directories for Problem Management*: IPCS supports alternate strategies for dump directories\. You can define a different dump directory for each dump or for groups of dumps\. Multiple dump directories allow you to use one directory when processing problems in one group and another directory when processing problems in another group\. For ease in assigning and reassigning problems, you might want a separate dump directory for each problem\. See [Appendix C, "Managing Problems and](c-0.md) [Data Sets" in topic C\.0](c-0.md) for more information\.
