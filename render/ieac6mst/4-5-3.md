### 4\.5\.3 Storage Panel

Through both the entry panel and the pointer panel of the Browse option, you can request to display source data\. \(See ["Displaying the Dump Data"](4-5-2-2.md) [in topic 4\.5\.2\.2](4-5-2-2.md) and ["Specifying the Address of Storage" in topic 4\.5\.1](4-5-1.md)\.\)

In response to a storage display request, IPCS displays a storage panel similar to the one shown in [Figure 4\-23](4.png)

<a id="FIGSTAC"></a>

![PICTURE 4](4.png)

*Figure 4\-23\. IPCS Storage Panel Browse Option Pointer Panel*

The storage panel provides both a hexadecimal and an EBCDIC representation of the source data\. Each line of the storage display represents either 16 or 32 bytes of storage, depending on the size of the terminal display screen\.
