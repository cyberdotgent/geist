### 3\.1\.4 Finding the Time and Type of Dump

The IPCS subcommand STATUS SYSTEM identifies the time of the dump and the program requesting the dump\. The IPCS dialog does not have a menu option for STATUS SYSTEM\. Instead you must enter the subcommand\.

[Figure 3\-2](3-1-4.md#FIGSTATUS) is an example of a STATUS SYSTEM report\. If the program requesting the dump is IEAVTSDT, then the dump is a scheduled SVC dump\. The analysis of a scheduled dump is slightly different from that of a synchronous dump\. See ["Diagnosing Scheduled SVC Dumps" in topic 3\.1\.10](3-1-10.md)\. If the program requesting the dump is anything but IEAVTSDT, the dump is a synchronous SVC dump\.
