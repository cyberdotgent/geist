## 4.6 Getting Online Help in the IPCS Dialog

<a id="HDRGETHELP"></a>

The IPCS dialog supports an extensive online help facility. Tutorial and help panels provide information on the following topics: Using IPCS dialog panels and commands Entering IPCS subcommands Reading formatted dump reports on a dump display reporter panel Choosing an option from the Dump Component Data Analysis menu Use the online help facilities to get quick answers to problems in these areas.
