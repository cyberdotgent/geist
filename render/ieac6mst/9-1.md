## 9\.1 Print and Table of Contents Files

<a id="HDRDSPRT"></a>

A print file contains the output produced when you enter IPCS subcommands with the PRINT keyword\.

A table of contents \(TOC\) file contains the entries produced by the IPCS table of contents exit service when output is written to the print file\. These entries identify major portions of IPCS output as they are written to the print file\.

Both data sets are sequential and contain blocked variable\-length records with American National Standards Institute \(ANSI\) control characters\. You should allocate these data sets before you enter an IPCS subcommand that routes its display to the print data set\.

**Note:** You can use the print data set without allocating a TOC data set\. The TOC and print files should be different for both files to contain correct data\.

You can control the printer font for the printed output from your print or TOC data sets\. See ["Controlling the Print Font" in topic 9\.1\.3](9-1-3.md)\.
