#### 4\.5\.3\.2 Selecting Words from the Storage Panel

<a id="HDRSPWORD"></a>

The selection codes, L, H, %, or ? can be used to request the addition of an entry to the pointer stack on the pointer panel\. To request scrolling to the storage addressed by a word use selection codes % or ?\.

The following table presents a description of the selection codes\.

<a id="FIGTBLUNIQ13"></a>

<a id="TBLTBLUNIQ13"></a>

```
    ______________ ___________________________________________________________
   | Selection    | Explanation                                               |
   | Code         |                                                           |
   |______________|___________________________________________________________|
   | L            | The word is to be interpreted as a low-precision (24-bit) |
   |              | address of storage in the current address space.  An      |
   |              | appropriate pointer is placed in the pointer stack on the |
   |              | pointer panel.                                            |
   |______________|___________________________________________________________|
   | H            | The word is to be interpreted as a high-precision         |
   |              | (31-bit) address of storage in the current address space. |
   |              | An appropriate pointer is placed in the pointer stack on  |
   |              | the pointer panel.                                        |
   |______________|___________________________________________________________|
   | %            | The word is to be interpreted as a low-precision (24-bit) |
   |              | address of storage in the current address space.  An      |
   |              | appropriate pointer is placed in the pointer stack on the |
   |              | pointer panel and the addressed storage is immediately    |
   |              | displayed.  If more than one % is entered, the first one  |
   |              | (topmost and leftmost in the display) is used for the     |
   |              | origin of the next display, and the rest are treated as   |
   |              | though an L had been entered.                             |
   |______________|___________________________________________________________|
   | ?            | The word is to be interpreted as a high-precision         |
   |              | (31-bit) address of storage in the current address space. |
   |              | An appropriate pointer is placed in the pointer stack on  |
   |              | the pointer panel and the addressed storage is            |
   |              | immediately displayed.  As with selection code %,         |
   |              | multiple selection codes ? beyond the first one are       |
   |              | treated as code H.                                        |
   |______________|___________________________________________________________|
   | Note:  If an incorrect selection code is entered, IPCS intensifies the   |
   | error field and displays a message in the upper-right-corner of the      |
   | display panel.                                                           |
   |__________________________________________________________________________|
```

These selection codes perform what is known as a *fast stack*\. They provide the same function as the STACK subcommand in a simpler form\.

After ENTER is pressed on the preceding panel, the Browse option scrolls to the requested address of storage \(as indicated by the % selection code\) and adds stack entries to the pointer stack \(as indicated by the %, H, and L selection codes\)\. [Figure 4\-25](4-5-3-2.md#FIGSTPNL4) and [Figure 4\-26](4-5-3-2.md#FIGSTAE) show the results of processing selection codes, %, H, and L\.

[Figure 4\-25](4-5-3-2.md#FIGSTPNL4) illustrates how the selection code, %, scrolled to the requested address of storage \(00000000\)\. [Figure 4\-26](4-5-3-2.md#FIGSTAE) shows the results of processing the %, H, and L selection codes\. Notice the addition of three new pointer entries:

- Pointer 00006 is added to the pointer stack with address 00000000 for address space 1\.
- Pointer 00007 is added to the pointer stack with address 00FCDFE4 for address space 1\.
- Pointer 00008 is added to the pointer stack with address 01001428 for address space 1\.
