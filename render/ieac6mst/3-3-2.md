## 3.3.2 Subcommands for Viewing Dump Data

<a id="HDRUSEVIW"></a>

<a id="TBLUNIQ6"></a>

<a id="TBLTBLUNIQ6"></a>

| When You Want to | Use this Subcommand |
| --- | --- |
| Locate data in a dump | FIND |
| Display storage | LIST |
| Display the eligible device table (EDT) | LISTEDT |
| Display one or more UCBs | LISTUCB |
