## 4.5.2.1 Working From the Pointer Stack

<a id="HDRPPWORK"></a>

#### Working from the Pointer Stack

All the pointer fields in the stack can be edited or displayed. You select a pointer for processing by entering a 1-character selection code in the field at the left of the pointer panel display. c.cp 999 IPCS supports the following selection codes:

<a id="TBLUNIQ12"></a>

<a id="TBLTBLUNIQ12"></a>

| Selection | Explanation |
| --- | --- |


You can select multiple pointers in a single transaction; they are processed in order of appearance on the screen. If any of the entries in the scrollable area of the pointer panel are not valid, IPCS highlights the error field and displays a message in the upper-right corner of the display panel. After you correct the error, IPCS displays the pointer table again (unless you enter CANCEL).

**Note:** Creating a new pointer also adds a new symbol to the symbol table.
