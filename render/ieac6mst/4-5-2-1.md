#### 4\.5\.2\.1 Working from the Pointer Stack

<a id="HDRPPWORK"></a>

All the pointer fields in the stack can be edited or displayed\. You select a pointer for processing by entering a 1\-character selection code in the field at the left of the pointer panel display\.

IPCS supports the following selection codes:

<a id="FIGTBLUNIQ12"></a>

<a id="TBLTBLUNIQ12"></a>

```
    ______________ ___________________________________________________________
   | Selection    | Explanation                                               |
   | Code         |                                                           |
   |______________|___________________________________________________________|
   | S            | Selects the storage addressed by the chosen pointer for   |
   |              | display. See "Displaying the Dump Data" in topic 4.5.2.2  |
   |______________|___________________________________________________________|
   | D            | Deletes the chosen pointer from the stack on the pointer  |
   |              | panel.  You can delete a specific number of pointers by   |
   |              | typing a number immediately after this selection code.    |
   |              | After deleting pointers, use the RENUM primary command to |
   |              | renumber the remaining pointers in the stack.             |
   |______________|___________________________________________________________|
   | I            | Inserts a pointer describing location 0 in the default    |
   |              | address space after the chosen pointer.  You can insert a |
   |              | specific number of pointers by typing a number            |
   |              | immediately after this selection code.  This code might   |
   |              | renumber existing pointers.                               |
   |______________|___________________________________________________________|
   | R            | Replicates the chosen pointer.  The duplicate pointer     |
   |              | appears in the stack immediately following the chosen     |
   |              | pointer.  This code might renumber existing pointers.     |
   |              | You can replicate a specific number of pointers by typing |
   |              | a number immediately after the selection code.            |
   |______________|___________________________________________________________|
   | E            | Selects the chosen pointer for editing the address,       |
   |              | address space, data type, and remark.                     |
   |______________|___________________________________________________________|
   | F            | Formats and displays the structure described by the       |
   |              | chosen pointer.  The formatted report appears on a dump   |
   |              | display reporter panel.                                   |
   |______________|___________________________________________________________|
   | Note:  Only the S selection code can be entered on the command line of   |
   | the display.                                                             |
   |__________________________________________________________________________|
```

You can select multiple pointers in a single transaction; they are processed in order of appearance on the screen\.

If any of the entries in the scrollable area of the pointer panel are not valid, IPCS highlights the error field and displays a message in the upper\-right corner of the display panel\. After you correct the error, IPCS displays the pointer table again \(unless you enter CANCEL\)\.

**Note:** Creating a new pointer also adds a new symbol to the symbol table\. See ["Adding and Deleting Symbols from the Pointer Stack" in topic 5\.3\.8](5-3-8.md) for more information\.

**Example: Using selection codes**

[Figure 4\-19](4-5-2-1.md#FIGINC) shows that selection codes I and R are entered in the pointer stack\.

```
    __________________________________________________________________________________ 
   |                                                                                  |
   | DSNAME('D83DUMP.DUMPC.PB00465') POINTERS -----------------------------------     |
   | COMMAND ===>                                               SCROLL ===> CSR       |
   | PTR   Address  Address space                        Data type                    |
   | 00001 00000000 HEADER                               AREA                         |
   |       Remarks: COMMENT 1                                                         |
   | i0002 00FCE210 ASID(X'0029')                        AREA                         |
   |       Remarks: COMMENT 2                                                         |
   | 00003 00000DB0 ASID(X'0008')                        AREA                         |
   |       Remarks:                                                                   |
   | r2004 00F9AC68 ASID(X'0029')                        AREA                         |
   |       Remarks:                                                                   |
   | 00005 00FCE1F8 ASID(X'0001')                        STRUCTURE(CVT)               |
   |       Remarks: COMMUNICATIONS VECTOR TABLE                                       |
   | ******************************* BOTTOM OF DATA *****************************     |
   |                                                                                  |
   |__________________________________________________________________________________|
```

*Figure 4\-19\. Entering Selection Codes in the Pointer Stack of the Browse Option Pointer Panel*

[Figure 4\-20](4-5-2-1.md#FIGIND) shows the result of processing selection codes I and R\. Processing of selection code I created a new pointer \(00003\)\. The new pointer does not supply an address \(00000000\); it is assigned to ASID\(X'0029'\)\. Processing of selection code R \(followed by the number 2\) created two new pointers \(00006 and 00007\), each of which is identical to the original pointer\. Note that inserting and replicating these pointers renumbered the pointer stack\.
