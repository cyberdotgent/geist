*Figure 4\-5\. IPCS MVS Dump Component Data Analysis Panel*

The IPCS Dump Component Data Analysis panel \([Figure 4\-5](4-3-4-1.md#FIGPNLCOMP)\) displays a menu of diagnostic reports associated with individual components\. Invoke this panel by selecting option 6 \(COMPONENT\) from the Analysis of Dump Contents panel or by entering option 2\.6 from the IPCS Primary Option Menu panel\.

Use the component analysis panel to request one of these component reports\. IPCS processes the request for the current default dump source and displays the requested data on the dump display reporter panel \(see ["Dump Display Reporter Panel" in topic 4\.4\.3](4-4-3.md)\)\.

**Note:** [Figure 4\-5](4-3-4-1.md#FIGPNLCOMP) does not show all the available options\. When viewing this panel online, press PF7 and PF8 to scroll through the list\. You may not see the options exactly as pictured, depending on the mix of products used at your installation\.

See [Figure 4\-12 in topic 4\.4\.1](4-4-1.md#P1) for a list of the valid commands and PF keys accepted on this panel\. After selecting an option and while viewing the report on the dump display reporter panel, see [Figure 4\-15 in](4-4-3.md#P3) [topic 4\.4\.3](4-4-3.md#P3) for a list of the valid commands and PF keys accepted on that panel\.
