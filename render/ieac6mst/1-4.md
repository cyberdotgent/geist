## 1\.4 How IPCS Works as a TSO/E Application

IPCS is a problem\-state, key 8 program that runs in a TSO/E user's address space\.

The base of IPCS is a TSO/E command processor\. The TSO/E command "IPCS" activates the IPCS command processor\. All commands used to perform IPCS functions are "subcommands" of the IPCS command\. You can use IPCS functions from any TSO/E line mode session\.

In MVS/Extended Architecture SP Version 2 Release 1\.2 IPCS added ISPF dialog support to run as an interactive, full\-screen application\. This application, known as the "IPCS dialog", still uses the IPCS command processor\. [Figure 1\-2](2.png) shows where the IPCS command processor and IPCS dialog fit in the system\.
