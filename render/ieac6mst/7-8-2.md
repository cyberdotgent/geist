### 7\.8\.2 Following a Pointer Chain

[Figure 7\-9](7-8-2.md#FIGRXCHAIN) gives a recursive function for following a chain of task control blocks \(TCB\)\. The function, CheckTCB, invokes Obtain\_Data \(see [Figure 7\-5 in topic 7\.7\.2](7-7-2.md#FIGRXRETR)\) to retrieve the TCB pointers from the dump and Put \(see [Figure 7\-6 in topic 7\.7\.4](7-7-4.md#FIGRXNOTE)\) to display the addresses\.

<a id="FIGRXCHAIN"></a>

```
    ________________________________________________________________________ 
   |                                                                        |
   |                                                                        |
 | |   CheckTCB: Procedure expose storage.                                  |
 | |   TCBADDR= ARG(1)                                                      |
 | |   GEN$ = " "                                                           |
 | |   Call Put                                                             |
 | |   Gen$ = "TCB at address "TCBADDR                                      |
 | |   Call Put                                                             |
 | |   TCBNTC   = Obtain_Data(TCBADDR,128,4)                                |
 | |   TCBLTC   = Obtain_Data(TCBADDR,136,4)                                |
 | |   TCBRTWA  = Obtain_Data(TCBADDR,224,4)                                |
 | |   TCBCMP   = Obtain_Data(TCBADDR,16,4)                                 |
 | |   Gen$ = " TCBntc...."TCBNTC                                           |
 | |   Call Put                                                             |
 | |   Gen$ = " TCBltc...."TCBLTC                                           |
 | |   Call Put                                                             |
 | |   Gen$ = " TCBrtwa..."TCBRTWA                                          |
 | |   Call Put                                                             |
 | |   Gen$ = " TCBcmp...."TCBCMP                                           |
 | |   Call Put                                                             |
 | |   /*************************************/                              |
 | |   If TCBLTC ¬= "00000000"                                              |
 | |     Then                                                               |
 | |       Call CheckTCB TCBLTC                                             |
 | |   If TCBNTC ¬= "00000000"                                              |
 | |     Then                                                               |
 | |       Call CheckTCB TCBNTC                                             |
 | |   Return                                                               |
   |                                                                        |
   |                                                                        |
   |________________________________________________________________________|
```

*Figure 7\-9\. Example of a REXX Exec Function to Follow a TCB Structure*

If X'00F78400' is the address of a TCB, you would invoke this function as follows:

`CheckTCB 00F78400`

This simple function can be coded more efficiently using the RUNCHAIN subcommand to follow a chain of control blocks\. A REXX function, however, allows you to customize the analysis of the control block chain\. See ["Customizing Control Block Analysis" in topic 7\.8\.4](7-8-4.md) for an example of customizing the CheckTCB function\.
