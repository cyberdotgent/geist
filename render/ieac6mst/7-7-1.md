### 7.7.1 ADDRESS IPCS Instruction

To enter subcommands from a REXX exec, use the ADDRESS IPCS instruction. | ADDRESS IPCS changes the host command environment to IPCS. The IPCS host | command environment is available only when you run the exec from an IPCS | session.

[Figure 7-3](7-7-1.md#RXADDR) is a simple REXX exec that shows how to change the host command | environment to IPCS.

<a id="RXADDR"></a>

| `/*` `REXX` `*/` | `Address` `IPCS` `'STATU`S'

`if` `rc` `>` `0` `then` `signal` `Exit`

`'LIST` `0.` `LENGTH(100)'`

|

`Exit:` `exit` | Figure 7-3. Changing the Host Command Environment to IPCS for All | Commands.

