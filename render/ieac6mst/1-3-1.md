### 1.3.1 Reblocking Dump Data Sets

```text
   Reblocking a dump data set obsoletes the dump's description in the dump
   directory.  If you reblock a dump, use the DROPDUMP subcommand to erase
   the dump's description.  IPCS will reinitialize the dump the first time
   you enter a subcommand to process the dump.

   You can copy a dump using the COPYDUMP subcommand.  To prevent reblocking,
   create and allocate the output data set before performing the COPYDUMP.

   Otherwise, COPYDUMP creates a dump data set with the name specified on
   OUTDATASET and the defaults RECFM=F and BLKSIZE=4160.
```
