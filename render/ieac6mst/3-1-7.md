### 3\.1\.7 Examining the LOGREC buffer

Use the IPCS subcommand VERBEXIT LOGDATA to view the LOGREC buffer in a dump\. This report repeats much of the information contained in the STATUS FAILDATA report, but it helps to identify occasions when multiple error events caused the software failure\.

The example in [Figure 3\-7](3-1-7.md#FIGLOGDATA) shows how multiple errors can appear in the LOGREC buffer\. Abend X'0D5' is the first abend and X'058' is the second\. Always check for multiple errors in the VERBEXIT LOGDATA report\.

*Figure 3\-7\. Sample Output from the VERBEXIT LOGDATA Subcommand*

When viewing the VERBEXIT LOGDATA report, skip the hardware records to view the software records\. Enter "FIND SOFTWARE" to scroll to the first software record\. The field "ERRORID=" gives the error identifier for the software failure\. The error identifier consists of the sequence number, ASID, and time of the abend\. By matching this identifier with error identifiers from other reports, you can tell if this is the same abend you have been analyzing or if it is a different abend\.
