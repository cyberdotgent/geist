### 3.4.4 Format Integers

Use INTEGER to format integers that are retrieved from the dump by using other subcommands. With INTEGER, you can display the data you have retrieved in the form you prefer to use while debugging (decimal, hexadecimal, or EBCDIC). INTEGER is also useful for formatting integers so that they fit into a report column of a particular size.
