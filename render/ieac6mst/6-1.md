## 6\.1 Specifying Data Description Operands

<a id="HDRSPECDDO"></a>

The syntax diagrams for IPCS subcommands in the *IPCS Command Reference* specifies data description operands as follows:

`data-descr`

This indicates that data description keywords are acceptable on a particular subcommand\. Several subcommands place additional restrictions on the use of data description operands\. These restrictions are indicated in the list of keyword descriptions\.
