## 5.3 Using the Symbol Table

<a id="HDRSYMTBL"></a>

references to a dump faster and more efficient. When you process a dump for the first time, IPCS creates an entry for the dump in the dump directory. IPCS reads the dump and initializes the symbol table for the dump. A symbol in IPCS is a label associated with a location in a dump. IPCS automatically creates some symbols for you. You can create your own symbols for areas of the dump using the EQUATE subcommand. The symbol table is a list of symbol names, dump addresses, and symbol attributes. The attributes can include any one of the data description operands, such as an address space identifier (ASID), CPU, and length (see [Chapter 6, "Describing Storage in a Dump" in topic 6.0](6-0.md)). The symbol can also have the DROP or NODROP attribute.
