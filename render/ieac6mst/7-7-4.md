### 7\.7\.4 Displaying Output from an IPCS REXX Exec

Use the NOTE subcommand to display the results of your REXX exec\. The NOTE subcommand allows you to control the output using the PRINT and TERMINAL keywords\. As with any IPCS subcommand, your exec should check the return codes from each NOTE subcommand \(see ["Checking Subcommand](7-7-3.md) [Return Codes" in topic 7\.7\.3](7-7-3.md)\)\.

If your REXX exec uses NOTE more than once to display output, consider creating an internal function to invoke NOTE\. [Figure 7\-6](7-7-4.md#FIGRXNOTE) is an example of such a function\.

<a id="FIGRXNOTE"></a>

```
    ________________________________________________________________________ 
   |                                                                        |
   |                                                                        |
 | |   Put: procedure expose GEN$                                           |
 | |   /*-----------------------------------------------------------*/      |
 | |   /* Function:  Put                                            */      |
 | |   /*                                                           */      |
 | |   /*            Invoke the IPCS NOTE subcommand to transmit    */      |
 | |   /*            data to the terminal, IPCS print file or both, */      |
 | |   /*            depending on the IPCS message routing default. */      |
 | |   /*                                                           */      |
 | |   /* Input:     Data to transmit.                              */      |
 | |   /*                                                           */      |
 | |   /* Output:    Data is transmitted.                           */      |
 | |   /*-----------------------------------------------------------*/      |
   |                                                                        |
 | |   "NOTE '"GEN$"' ASIS"                                                 |
 | |   if rc>0 then Signal Put_Error                                        |
 | |   return                                                               |
   |                                                                        |
   |                                                                        |
   |________________________________________________________________________|
```

*Figure 7\-6\. Example of a REXX Function to Display Output*

To handle any error from NOTE processing, a REXX exec needs the following lines in addition to the Put function:

`Put_Error: nop Retc = 16 Signal Exit`

`Exit: exit Retc`

To invoke Put, the exec should set the variable GEN$ equal to the output it wants to display\. For example:

`GEN$ = 'The dump data set name is 'data_set_name Call Put`

For more information about displaying IPCS output, see ["Controlling Output](7-10.md) [from REXX Execs and CLISTs" in topic 7\.10](7-10.md)\.
