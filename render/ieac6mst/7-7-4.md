### 7.7.4 Displaying Output From an IPCS REXX Exec

Use the NOTE subcommand to display the results of your REXX exec. The | NOTE subcommand allows you to control the output using the PRINT and | TERMINAL keywords. As with any IPCS subcommand, your exec should check

the return codes from each NOTE subcommand (see ["Checking Subcommand](7-7-3.md) [Return Codes" in topic 7.7.3](7-7-3.md)). | If your REXX exec uses NOTE more than once to display output, consider creating an internal function to invoke NOTE.
