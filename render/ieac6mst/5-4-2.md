### 5\.4\.2 Subcommands for Maintaining the Storage Map

IPCS provides these subcommands to maintain and query the storage map:

<a id="FIGTBLUNIQ20"></a>

<a id="TBLTBLUNIQ20"></a>

```
    ____________________________________________ _____________________________
   | When You Want to                           | Use this Subcommand         |
   |____________________________________________|_____________________________|
   | Delete storage map entries                 | DROPMAP                     |
   |____________________________________________|_____________________________|
   | List storage map entries                   | LISTMAP                     |
   |____________________________________________|_____________________________|
   | Validate control blocks                    | SCAN                        |
   |____________________________________________|_____________________________|
   | Create storage map entries for address     | SELECT subcommand           |
   | spaces satisfying certain selection        |                             |
   | criteria                                   |                             |
   |____________________________________________|_____________________________|
```

```
    ___ Reference __________________________________________________________
   |                                                                        |
   | See IPCS Command Reference for syntax and examples of each subcommand. |
   |                                                                        |
   |________________________________________________________________________|
```
