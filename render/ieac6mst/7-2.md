## 7.2 Starting an IPCS Session From a REXX Exec or CLIST

<a id="HDRCLRXINI"></a>

You can enter the TSO/E IPCS command from a REXX exec to start an IPCS | session. The exec remains active during the IPCS session. The exec | continues to the next instruction following the IPCS command only after | you enter the END subcommand to end the IPCS session. | You cannot enter subcommands after the IPCS command in a REXX exec. The

exec must queue the subcommands to the REXX data stack before entering the | IPCS command. IPCS pulls any subcommands from the data stack after it | starts the session. Therefore, do not address the IPCS host command

environment when you enter the IPCS command from a REXX exec. [Figure 7-1](7-2.md#RXQUEUE)| shows how to start an IPCS session and enter subcommands from a REXX exec.
