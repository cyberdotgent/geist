## 2.7.2 Using the SETDEF Subcommand

<a id="HDRUSESET"></a>

The defaults specified with SETDEF can be overridden on many subcommands      by specifying the corresponding keyword on that subcommand.  The override            will be in effect for the subcommand on which it is entered; the override ?    will not change the value specified with SETDEF.

**Note:** Although you can use SETDEF to establish a dump data set as the current data set, you can also use the DEFAULT keyword on the ADDDSN, COPYDUMP, MODDSN, and OPEN subcommands.
