## 3\.4 Using IPCS Subcommands for Perform Utility Functions

<a id="HDRUSEUTL"></a>

While using IPCS, there are some actions you can perform that do not involve IPCS dump analysis\. These actions are sometimes referred to as utility functions or "housekeeping" or "clean up" operations\. For instance, copying data from one target to another, opening and closing data sets, or generating notes, are kinds of utility functions\.

IPCS provides several subcommands to perform utility functions:

<a id="FIGTBLUNIQ9"></a>

<a id="TBLTBLUNIQ9"></a>

```
    ____________________________________________ _____________________________
   | When You Want to                           | Use this Subcommand         |
   |____________________________________________|_____________________________|
   | End the use of resources by IPCS           | CLOSE                       |
   |____________________________________________|_____________________________|
   | Perform logical data comparisons           | COMPARE                     |
   |____________________________________________|_____________________________|
   | Copy dump data from one data set to        | COPYDUMP                    |
   | another                                    |                             |
   |____________________________________________|_____________________________|
   | Copy trace data from one data set to       | COPYTRC                     |
   | another                                    |                             |
   |____________________________________________|_____________________________|
   | End an IPCS session                        | END                         |
   |____________________________________________|_____________________________|
   | Obtain descriptive information about the   | HELP                        |
   | IPCS command and its subcommands           |                             |
   |____________________________________________|_____________________________|
   | Format an integer using decimal digits,    | INTEGER                     |
   | hexadecimal digits, or four EBCDIC         |                             |
   | characters                                 |                             |
   |____________________________________________|_____________________________|
   | Produce messages and control spacing and   | NOTE                        |
   | pagination                                 |                             |
   |____________________________________________|_____________________________|
   | Prepare resources for use by IPCS          | OPEN                        |
   |____________________________________________|_____________________________|
   | Control session output format              | PROFILE                     |
   |____________________________________________|_____________________________|
   | Set, change, and display IPCS session      | SETDEF                      |
   | defaults                                   |                             |
   |____________________________________________|_____________________________|
   | Transfer system management facility (SMF)  | SMFDATA                     |
   | records to a previously allocated SMF      |                             |
   | (VSAM) data set                            |                             |
   |____________________________________________|_____________________________|
   | Invoke a TSO/E command                     | TSO                         |
   |____________________________________________|_____________________________|
```

**Note:** [Chapter 8, "Using IPCS in Batch Mode"](8-0.md) contains examples of the COPYDUMP and COPYTRC subcommands\.
