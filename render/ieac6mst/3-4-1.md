### 3\.4\.1 Perform Logical Data Comparisons

Compare two data items with the COMPARE subcommand\. The following example compares two pieces of data, sets a return code, and, optionally, displays a message:

`compare value(x'c1d2f3') with(address(1a3564.) length(3))`

The subcommand compares C1D2F3 with three bytes of data at location X'1A3564' and sets the return code to indicate the results\. In this example, there is no display of a message at your terminal because the LIST keyword is omitted\.
