### 3.4.1 Perform Logical Data Comparisons

Compare two data items with the COMPARE subcommand. The following example compares two pieces of data, sets a return code, and, optionally, displays a message:

// `c`o`mpare value(x'c1`d`2f3') with(address(1a`3`564.) leng`th(3)) The subcommand compares C1D2F3 with three bytes of data at location X'1A3564' and sets the return code to indicate the results. In this example, there is no display of a message at your terminal because the LIST keyword is omitted.
