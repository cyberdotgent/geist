*Figure 4\-10\. IPCS Dump Inventory Panel*

The IPCS Dump Inventory panel \([Figure 4\-10](4-3-8.md#FIGDMPINV)\) helps you review and manage the dump sources described by your dump directory\. Invoke this panel by selecting option 6 \(DUMPS\) from the IPCS Primary Option Menu panel\.

To use this panel, enter a 2\-character command code to the left of the desired dump source in the list, as you would an IPCS line command\. These commands let you take immediate actions directly from this panel\. IPCS responds to your request by updating the 'Status' column, activating the IPCS Browse option, or displaying a report describing the dump you selected\. You can scroll through the dump sources using the UP, DOWN, and LOCATE primary commands\. The following table shows the valid 2\-character command codes:

<a id="TBLTBLUNIQ11"></a>

```
    ______________ ___________________________________________________________
   | Code         | Function Performed                                        |
   |______________|___________________________________________________________|

   |              | Browse option pointer panel, without having to go through |
   |              | the Browse option entry panel first.                      |
   |______________|___________________________________________________________|
```
