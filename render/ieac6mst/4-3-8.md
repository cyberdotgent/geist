The IPCS Dump Inventory panel [Figure 4-10](4-3-8.md#DMPINV)) helps you review and manage the dump sources described by your dump directory. Invoke this panel by selecting option 6 (DUMPS) from the IPCS Primary Option Menu panel. To use this panel, enter a 2-character command code to the left of the desired dump source in the list, as you would an IPCS line command. These commands let you take immediate actions directly from this panel. IPCS responds to your request by updating the 'Status' column, activating the IPCS Browse option, or displaying a report describing the dump you selected. You can scroll through the dump sources using the UP, DOWN, and LOCATE primary commands.
