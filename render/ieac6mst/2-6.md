## 2.6 Using a CLIST to Access IPCS

<a id="HDRCLIST"></a>

One easy way to accessing IPCS is to put all the TSO/E commands into a CLIST. Then, to perform all the steps you would simply need to run the CLIST. Some installations provide a CLIST for their IPCS users. IPCS comes with the CLIST BLSCDDIR in the SYS1.SBLSCLI0 library. If you want to write one, the CLIST needs to put the correct IPCS data sets into data set concatenation with corresponding ISPF files.

[Figure 2-2](2-6.md) gives a sample CLIST that: Allocates the necessary IPCS and ISPF data sets, Invokes the IPCS command to start an IPCS line mode session Starts the IPCS dialog.

**Note:** The names of the data sets in this example depend on your installation.

<a id="ALLO"></a>

`PROC` `0` `CONTROL` `LIST` `DATASET(` `+` `'SYS1.SBLSCLI0')` `+` SHR REUSE /* CLISTS AND `R`E`XX EXE`C`S` *`/` `ALLOCATE` `FILE(ISPMLIB)` `+` `DATASET('ISR.V220.ISRMLIB'` `+` `'SYS1.SBLSMSG0')` `+` SHR REUSE /* MESSAGES */ `ALLOCATE` `FILE(ISPPLIB)` `+` `DATASET('ISR.V220.ISRPLIB'` `+` `'SYS1.SBLSPNL0')` `+` SHR REUSE /* PANELS */ `ALLOCATE` `FILE(ISPSLIB)` `+` `DATASET('ISR.V220.ISRSLIB'` `+` `'SYS1.SBLSKEL0')` `+` SHR REUSE /* SKELETONS */ `ALLOCATE` `FILE(ISPTLIB)` `+` `DATASET('ISR.V220.ISRTLIB'` `+` `'SYS1.SBLSTBL0')` `+` SHR REUSE /* TABLES */ `ALLOCATE` `FILE(ISPLLIB)` `+` `DATASET('SYS1.MIGLIB')` `+` SHR REUSE /* CODE */ `ALLOCATE` `FILE(SYSHELP)` `+` `DATASET('SYS1.HELP')` `+` SHR REUSE /* HELP TEXT */ `IPCS` `NOPARM` `/*` `IPCS` `LINE` `MODE` `*/` `ISPSTART` `PGM(BLSG)` `NEWAPPL(BLSG)` `+`

`PASSLIB` `PARM(PANEL(BLSPPRIM))` `/*` `IPCS` `DIALOG` `*/`
