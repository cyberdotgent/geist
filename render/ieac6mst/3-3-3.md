### 3\.3\.3 Subcommands for Viewing Trace Data

<a id="HDRUSETRC"></a>

<a id="FIGTBLUNIQ7"></a>

<a id="TBLTBLUNIQ7"></a>

```
    ____________________________________________ _____________________________
   | When You Want to                           | Use this Subcommand         |
   |____________________________________________|_____________________________|
   | Display console-initiated loop trace data  | CPUTRACE                    |
   |____________________________________________|_____________________________|
   | Display component trace data               | CTRACE                      |
   |____________________________________________|_____________________________|
   | Display data-in-virtual trace data         | DIVDATA                     |
   |____________________________________________|_____________________________|
   | Display GTF trace data                     | GTFTRACE                    |
   |____________________________________________|_____________________________|
   | Merge trace data                           | MERGE                       |
   |____________________________________________|_____________________________|
   | Display trace data in the master trace     | VERBEXIT MTRACE             |
   | table                                      |                             |
   |____________________________________________|_____________________________|
   | Display trace entries                      | VERBEXIT TRACE              |
   |____________________________________________|_____________________________|
```
