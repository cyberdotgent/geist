### 5.4.3 Deleting Storage Map Entries

Delete storage map entries with the DROPMAP subcommand when the space allocated to your dump directory is depleted or the dump that the storage map entries represent is no longer associated with a problem on which you are working (the dump may still be associated with a problem on which another user is working). The DROPMAP subcommand can delete some or all of the storage map entries for a dump. For example, to delete all storage map entries for the current dump that originate between the virtual addresses X'0' and X'50000' inclusive, enter:

dro`pmap ra`n`ge(0.:500``00.)`
