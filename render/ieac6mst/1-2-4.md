### 1\.2\.4 Providing Format and Analysis Support

<a id="HDRDSPARM"></a>

By default the system allocates SYS1\.PARMLIB to file IPCSPARM for an IPCS session\. IPCS uses two members of SYS1\.PARMLIB to control its processing\.

*IPCSPRxx Parmlib Member*: IPCS has a set of parameters that control the problem management and data set management functions and the default print file sizes to be used during the IPCS session\. The IPCSPRxx parmlib members contain defaults for these parameters\.

IPCSPR00, the IBM\-supplied member, suppresses the use of problem and data set management through the NODSD and NOPDR parameters\. To use these facilities, create new IPCSPRxx members and specify the DSD and PDR parameters\.

*BLSCECT Parmlib Member*: BLSCECT, the exit control member, defines the dump analysis and formatting models and verb exit routines that are available to IPCS\. See *MVS Initialization and Tuning Reference* for the syntax of these parmlib members\.

BLSCECT also imbeds parmlib members that provide additional formatting and analysis support to IPCS\. These imbedded members must be located in SYS1\.PARMLIB for IPCS to work correctly\. See *MVS Conversion Notebook* for information about new imbedded parmlib members for a release\.

*BLSCUSER Parmlib Member*: IBM recommends that instead of creating and modifying a new version of BLSCECT, you create a member named BLSCUSER in your own data set for defining installation\-supplied exits\. BLSCECT imbeds BLSCUSER automatically\. Otherwise you will need to allocate the modified parmlib member to the file IPCSPARM when you start an IPCS session, and it becomes more difficult to carry installation modifications over to the next release\.

For example, if you have any installation\-defined dump exits that were previously in MVS/XA SP load module AMDPRECT, you should add them to BLSCUSER\.
