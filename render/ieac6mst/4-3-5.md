The IPCS Dump Batch Job Option Menu panel ( [Figure 4-7](4-3-5.md)) offers three types of dump processing (options 1 through 3) and any additional batch processing (option 4). Invoke this panel by selecting option 3 (SUBMIT) from the IPCS Primary Option Menu panel. Use this panel to select the type of batch job to submit and to set up the job statement to be used with the job. **Notes:** 1. When you submit a batch job from any one of these panels, IPCS requires exclusive use of your dump directory. Either submit the batch job using a different dump directory than the one currently in use or free the dump directory for the batch job to run. 2. The job submission dialog assumes that SYS1.CMDLIB is in the system LNKLST concatenation. For quick turn-around, run your job with the output directed to a hold queue. When the job completes, view the output online. Using the TSO/E OUTPUT command, copy the output into a TSO/E data set and then use the PDF BROWSE option. 1 SADUMP: Use the SADUMP option to prepare a stand-alone dump that is on **tape** for dump analysis. It submits a job that copies the dump to DASD and invokes the BLSCSCAN CLIST to generate an initial dump analysis screening report. **Note:** If the stand-alone dump is already on DASD, use SUPPLEMENT. 2 SVCDUMP: Use the SVCDUMP option to prepare an SVC dump for dump analysis. It submits a job that invokes the BLSCBSVB CLIST to generate a diagnostic screening report., c.cp 3 SYSMDUMP: Use the SYSMDUMP option to prepare a SYSMDUMP dump for problem analysis. It submits a job that invokes the BLSCBSYB CLIST to generate a diagnostic screening report. 4 SUPPLEMENT: Use the SUPPLEMENT option to enter an IPCS subcommand, | CLIST, or REXX exec to be processed as a batch job against a designated dump. To use this option to prepare a stand-alone dump that is on **DASD** for dump analysis, specify BLSCSCAN as the CLIST to be invoked. The IPCS dialog provides online help for specifying the parameters of each job. Press PF1 or type HELP to access the online help. See IPCS Command Reference for more information about the CLISTs that this option invokes.
