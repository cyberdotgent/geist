### 4.7.3 Using Program Function (PF) Keys

Program function (PF) keys invoke specific IPCS and ISPF primary commands.

To display the current PF key definitions, type KEYS on the command line and press Enter. To change the PF key assignments, see ["Modifying the](4-8.md) [IPCS Dialog" in topic 4.8](4-8.md).
