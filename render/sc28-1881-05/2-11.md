## 2.11 CHANGE.STREAM Command

Use the CHANGE.STREAM command to: Change whether the terminal's audible alarm is to sound when information enters a stream Erase all of the information in a stream (Use the QUERY.STREAMS command to display the names and attributes of all of the streams.)

<a id="FIGUNIQ299 - CHANGE.STREAM stream-name C S ALARM ( YES ) CLEAR NO "></a>

stream-name The name of the stream to be changed. ALARM( {YES} {NO } specifies whether the terminal's audible alarm is to sound when information enters the stream. The stream does not have to be currently displayed for the alarm to sound. Note**: If** your terminal does not have an audible alarm, the Session Manager still accepts this operand. It has no way of knowing whether your terminal has an alarm. CLEAR erases all of the information in the stream. The stream itself is not erased.
