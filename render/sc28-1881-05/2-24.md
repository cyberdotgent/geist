## 2\.24 SNAPSHOT Command

Use the SNAPSHOT command to copy a display screen of information into a stream\. You can then use the SMCOPY command to print the stream or copy it into a data set\.

<a id="FIGFIGUNIQ328"></a>

```
    →→ _SNAPSHOT_ ___stream-name_ ________ __→
      |_S________|               |_FORMAT_|
```

`stream-name` The name of the stream where the information is to go\. `FORMAT` specifies that carriage control information is to be included in the copy of the information for printing on a system printer\. Highlighted lines on the screen appear darker in the printed copy\.

**Note:** If the copied information contains the carriage control characters, you must use the PREFORMAT operand of the SMCOPY command when printing it\.
