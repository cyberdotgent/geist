## 2.21 RESTORE Command

Use the RESTORE command to restore the definitions of the program function (PF) keys, screen layout, or windows previously saved via the SAVE command. If only one set of definitions exists on the stack, it is not removed. If more than one set of definitions has been saved, you must issue the RESTORE command as many times as you issued the SAVE command to get to the definitions you want.

PFKS specifies that the Session Manager is to restore the program function (PF) key definitions. SCREEN specifies that the Session Manager is to restore the screen layout. The following items are included in each screen stack element: A description of the screen layout The location of the cursor The value indicating how long the keyboard is to remain locked while a command is executing (as set using the CHANGE.TERMINAL command) The name of the default window The name and attributes of each window. WINDOW specifies that the Session Manager is to restore the window definitions.
