## 2.25 UNLOCK Command

Use the UNLOCK command to unlock a window.

<a id="FIGUNIQ330"></a>

default window NEWEST N RESUME R .

```text
    ________________________________________________________________________ 
   |_____________________________|
```

HERE causes the Session Manager to unlock the specified window at its current position. NEWEST causes the Session Manager to display the newest information in the stream, then unlocks it. RESUME causes the Session Manager to display the information the window was viewing before being locked, then unlocks the window. window-name The name of the window to be unlocked.
