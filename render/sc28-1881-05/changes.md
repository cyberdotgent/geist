The following summarizes the changes to that information. The following commands were added: ALTLIB -- Used to define alternative libraries of REXX execs and CLISTs or to exclude libraries from being searched. EXECUTIL -- Used to change various characteristics that control how REXX execs run in the TSO/E address space only. OUTDES -- Used to create or reuse a dynamic output descriptor. VLFNOTE -- Used to notify the virtual lookaside facility (VLF) that you have made changes to data that has been identified to VLF. The following operands were added to existing commands: An operand, ASIS, was added to the CALL command to prevent the translation of a parameter list to uppercase. An operand, OUTDES, was added to the FREE command to specify a list of output descriptor names (defined by the OUTDES command) to be freed. An operand, NORECONNECT, was added to the LOGON command to specify that you do not want automatic reconnect in effect. The operands, ARFROM, ARTO, ALETFROM, and ALETTO, were added to the AND, OR, and COPY subcommands of the TEST command to allow the use of access registers in addressing. The operands, ALET and AR, were added to the ASSIGNMENT function of the TEST command and the EQUATE and LIST subcommands of TEST so that storage in alternate address/data spaces can be changed or displayed. An operand, ASCMODE, was added to the GO, CALL, and RUN subcommands of the TEST command to specify the PSW mode in which a program executes. The operands CLIST and EXEC were added to the EXEC command so the command can be used to execute both CLISTs and REXX execs.
