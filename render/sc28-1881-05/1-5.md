## 1.5 ALTLIB Command

<a id="HDRALTLIB"></a>

Use the ALTLIB command to: Define alternative application-level libraries of REXX execs or CLISTs. Indicate that user-, application-, and system-level libraries of REXX execs and CLISTs are being searched. Exclude one or more library levels (user, application, system) from being searched. Reset the search order to the system level. Obtain a display of the search order that is in effect. TSO/E searches the user, application, and system level libraries for REXX execs or CLISTs that are executed implicitly or when searching for REXX external functions or subroutines. For more information about implicitly

executing execs and CLISTs, see ["EXEC Command" in topic 1.13](1-13.md). For more <BOOK> <> <> <SC28-18 [83> <06> <IKJA300>](#LNK) information about REXX external functions, see TSO/E V2 REXX/MVS [<BOOK> <>](#LNK)<> <SC28-1883> <06> <IKJA300> Reference.
