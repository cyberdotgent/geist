## 1.44 TIME Command

Use the TIME command to obtain the following information: Cumulative CPU time (from LOGON) Cumulative session time (from LOGON) Total service units used, which includes: CPU service units - A measure of task execution time. I/O service units - A measure of SMF data set activity. Storage service units - A measure of the page frame usage. Local time of day Refers to the time of execution for this command. It is displayed as follows: `local` `time` `of` `day` `in` `hours(HH),` `minutes(MM),` `and` `seconds(SS),`

`(am` `or` `pm` `is` `also` `displayed)`

Today's date. To enter the command while a program is executing, you must first cause an attention interruption. The TIME command has no effect on the executing program.
