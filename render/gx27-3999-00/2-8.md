## 2.8 Changing Adapter Configuration

If, after installation is complete, you wish to change your configuration, use the following procedure:

- 1. From the Main Menu of the Reference Diskette, select the item that allows you to set the configuration. (See ["Updating the Backup Copy](2-2.md) [of Your Reference Diskette" in topic 2.2](2-2.md) for instructions about using the Reference Diskette.)
- 2. On the Set Configuration Menu, select Change Configuration.
- 3. Modify the parameters that you want to change. (The Help facility provides descriptions and valid choices for parameters.)
- 4. Save the changes and record them on page [2.5](#SPTCHART).
