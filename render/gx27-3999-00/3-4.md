## 3\.4 Testing the Adapter

<a id="HDRTEST"></a>

Use the following procedure to test the Dual EtherStreamer MC 32 Adapter:

<a id="LISuplug"></a>

1. If your adapter is connected to the network, unplug the adapter cables

<a id="ELISuplug"></a>

from the wall outlets\.

2. Replace the adapter cables with known good cables\.
3. If your computer is already switched on and the Main Menu of your Reference Diskette is displayed, continue with step [4](3-4.md)\.

Otherwise, insert the backup copy of your computer's Reference Diskette in the A: drive and switch the computer ON\. Follow the instructions that appear on the panels until you see the Main Menu\. If your reference diskette is stored on the hard drive, press and hold the **Ctrl**, **Alt**, and **Delete** keys\. When the cursor appears in the upper right\-hand corner of your computer's display, press and hold the **Ctrl**, **Alt**, and **Insert** keys to load the Reference Diskette\.

For more information about menu selections, use the Help facility on the Reference Diskette\.

<a id="LISadvd"></a>

4. From the Main Menu, press and hold the **Ctrl** key and then press the **A**

<a id="ELISadvd"></a>

key to display the Advanced Diagnostics Menu\.

5. From the Advanced Diagnostic Menu, select **System checkout\.** A list of installed devices is displayed\.
6. If the Dual EtherStreamer MC 32 Adapter appears in the list, enter **Y** to confirm that the list is correct and continue with step [7](3-4.md)\.

If the Dual EtherStreamer MC 32 Adapter does not appear in the list, make sure that all of the steps under ["Placing the Adapter in an](2-3.md) [Expansion Slot" in topic 2\.3](2-3.md) and ["Configuring the Adapter" in](2-5.md) [topic 2\.5](2-5.md) were performed correctly\. Then, return to step [1](3-4.md)\. If the Dual EtherStreamer MC 32 Adapter still does not appear in the list, have your computer serviced\.

> **Note:** Parameters for the Adapter Address \(the unique 12\-character hexadecimal address\) and Code Level \(the microcode version\) are displayed only during step [7](3-4.md) of this procedure\. When they are displayed, record them in the worksheet on page [2\.5](2-5.md)\.

<a id="LISprams"></a>

7. From the Test Selection Menu, select the option that allows you to run the tests one time\. The list of installed devices reappears\. Select the Dual EtherStreamer MC 32 Adapter from the list and follow the directions that appear on the display panel to begin testing the

<a id="ELISprams"></a>

adapter\.

8. Verify that the values recorded in the chart match those shown on the display panel\.

- If the values recorded in the chart match those on the display panel, continue with [9](3-4.md)\.
- If the values recorded in the chart do not match those on the display panel, make sure that all the steps under ["Configuring the](2-5.md) [Adapter" in topic 2\.5](2-5.md) were performed correctly\. Then, return to step [1](3-4.md) of this procedure\. If the values still do not match, have your computer serviced\.

<a id="LISexit"></a>

9. If the test runs without errors, exit the diagnostic menu and follow the directions for reactivating the system\.

If an error occurs, record any messages that appear and go to ["Solving](3-5.md) [Problems During Adapter Installation" in topic 3\.5](3-5.md) for more information\.

<a id="ELISexit"></a>
