## 3.5 Solving Problems During Adapter Installation

<a id="HDRPSOLV"></a>

Use this section if you suspect a problem with the adapter during installation.

- **1.** If your ports are connected to the network, unplug the adapter cables from the network faceplate (wall outlet).
- 2. Follow the instructions under ["Testing the Adapter" in topic 3.4](3-4.md) to begin testing the adapter.

If an error occurs with the adapter, refer to the following error codes for explanations.

**Error** **Codes:**

The format of the 8-digit error codes on the display panel is 0281nnx0, where:

- The first and last digit is always 0
- 281 is the decimal equivalent of the device ID
- *nn* represents the type of error
- x repres*e*nts the slot number of the adapter in error.

The values for nn are given in [Table 3-3](#TBLERRLIST).

If the test continues to return an error code, check that the following conditions have been met before having the computer serviced:

- The cables are firmly attached to the adapter.
- The adapter is firmly seated in the option slot.
- You have correctly configured the adapter so that no conflicts exist except for the interrupt level parameter, which should be set to the same values. Conflicts are displayed with an asterisk (*) on the View or Change Configuration panels.
- You have correctly followed all the instructions for updating your backup copy of the Reference Diskette for the computer.

If any of the above conditions have not been met, correct any problems and run the test again, starting with the first step under ["Testing](3-4.md) [the Adapter" in topic 3.4](3-4.md).

- **3.** If the test does not return an error code, but you are having problems with the adapter, contact your network administrator to determine further action, such as having the computer, adapter, or adapter cable serviced.
