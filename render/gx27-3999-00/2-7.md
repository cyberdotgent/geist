## 2.7 When You Are Finished Configuring

<a id="HDRMOUSE"></a>

When you have successfully completed the configuration of both adapter ports, you must see your network documentation for updating the network server for the B port configuration. For example, if you have LAN Services, you would start that program and perform advanced installation and configuration, remembering that the program considers the B port to be a second adapter (logically).
