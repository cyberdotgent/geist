## 2.6 Installing the Adapter Drivers and Protocol Drivers

<a id="HDRDRIVER"></a>

This section contains the instructions for installing the adapter driver and one or more protocol drivers that the adapter needs for communication over an Ethernet network and with network software running on the computer. If you are installing drivers for more than one adapter in the same computer, complete all of the installation steps for the first adapter before installing additional ones, because testing the first adapter by itself will help in problem determination.

The instructions in this chapter involve using network operating systems and network applications that provide software that automates the installation of adapter and protocol drivers.
