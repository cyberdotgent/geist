## 3.3 Solving an Adapter Communication Problem

<a id="HDRCOMMPD"></a>

Use the following procedure if the adapter is unable to communicate on the network but other stations on the network are able to communicate:

- **1.** Verify that the appropriate adapter cables are connected to the adapter and to the network.
- **2.** Replace the adapter cables with known good cables.
- **3.** Verify that the adapter is firmly seated in the expansion slot.
- **4.** Verify that the network application or other network software is operating correctly on the computer in which the Dual EtherStreamer MC 32 Adapter is installed.
- [HDRTEST](3-4.md) **5.** See "Testing the Adapter" in topic 3.4 to run the adapter diagnostics. If the tests are completed successfully, but problems remain, contact the network administrator.
