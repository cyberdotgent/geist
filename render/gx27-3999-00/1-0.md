# 1\.0 Chapter 1\. Introduction

This manual contains the information you need to install, use, and solve problems with the IBM\* Dual EtherStreamer\* MC 32 Adapter\. You should be familiar with the computer in which the adapter will be installed and with the computer's operating system and network software\.

This adapter allows you to attach IBM Personal System/2\* \(PS/2\*\) computers \(or compatible computers\) equipped with a 386 or better processor and Micro Channel\* architecture to an Ethernet Network\.

The Dual EtherStreamer MC 32 Adapter transmits and receives data at a rate of 10 Mbps over IEEE 802\.3 Standard 10BASE\-T media\. There are **two** connection ports, and either port can be used independently\.

Special features of the adapter include:

- Support for a variety of network operating systems and network applications\.
- Support for up to four Dual EtherStreamer MC 32 Adapters in a single computer \(provided that you have the available slots and Micro Channel resources in your computer\)\. This makes for a total of eight ports\. These maximums are reduced if the protocol driver supports fewer adapters\.
