# PREFACE About This Manual

Use this manual when installing, testing, or generally working with Dual EtherStreamer MC 32 Adapters\. This adapter belongs to the Streamer family of adapters, which includes the IBM LANStreamer MC 16, the IBM LANStreamer MC 32, the IBM Auto LANStreamer MC 32, and the IBM EtherStreamer\* MC 32\. Keep this manual for reference when you are done with it\.
