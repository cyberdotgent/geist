## 1.3 Network Software

<a id="HDRNOS"></a>

The Dual EtherStreamer MC 32 Adapter can be used in a Micro Channel computer equipped with a network operating system or network application that uses the Network Driver Interface Specification (NDIS), IEEE 802.2 Logical Link Control (LLC), NetBIOS, or NetWare Open Data-Link Interface (ODI). [Table 1-1](#TBLNOSENVI) describes the network environments that are compatible with the Dual EtherStreamer MC 32 Adapter. Verify that you have each of the required software items listed under the appropriate environment for your computer system.
