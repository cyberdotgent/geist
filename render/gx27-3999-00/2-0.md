# 2.0 Chapter 2.  Installing the Adapter

<a id="HDRINST"></a>

This chapter contains instructions for installing a Dual EtherStreamer MC 32 Adapter in a Micro Channel computer. Installation involves performing the following steps in sequence:

- 1. Backing Up the Option/Driver Diskette
- 2. Updating the backup copy of your Reference Diskette with files from the Option/Driver Diskette
- 3. Placing the adapter in the expansion slot
- 4. Configuring the adapter
- 5. Installing the adapter drivers and protocol drivers

**Note:** If you are installing more than one adapter, install the first one and be sure it is working before installing the next adapter.

For information about NDIS MAC driver parameters, see [Appendix A, "NDIS](a-0.md) [MAC Driver Parameters" in topic A.0](a-0.md).

To install the adapter, you will need the Dual EtherStreamer MC 32 Adapter kit and the materials listed in ["Collecting the Materials You Need" in](1-2.md) [topic 1.2](1-2.md). Ensure that you have those materials before you begin the installation.
