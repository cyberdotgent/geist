## 3\.1 Start of Troubleshooting Process

<a id="HDRSTART"></a>

If you were not able to successfully complete the installation procedures in ["Installing the Adapter Drivers and Protocol Drivers" in topic 2\.6](2-6.md), or if a Dual EtherStreamer MC 32 Adapter is not operating correctly, use the following steps to start the troubleshooting process:

1. In [Table 3\-1](<#TBLTROUBT>), locate the symptom that best describes the problem\.
2. Go to the section that contains the recommended actions for resolving the problem and follow that procedure\.

<a id="TBLTROUBT"></a>

Table  3\-1\. Symptoms and Recommended Procedures

| Symptom | Go To |
| --- | --- |
| Problem with<br>loading the drivers | ["Solving Problems with Driver Installation" in](3-2.md)<br>[topic 3\.2](3-2.md) |
| The adapter cannot<br>communicate on the<br>network, but other<br>stations on the<br>network can<br>communicate | "Solving an Adapter Communication Problem" in<br>[topic 3\.3](3-3.md) |
| Problem with the<br>adapter's operation | ["Testing the Adapter" in topic 3\.4](3-4.md) |
