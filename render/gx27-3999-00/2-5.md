## 2\.5 Configuring the Adapter

   When you configure the adapter, you configure the base port, which is
   identified as A on the label on the adapter.  Configuration for the second
   port, which is identified as B, will be based upon the configuration for
   A.  A change to your CONFIG.SYS file will be required (and other changes
   to other files may also be required, as instructed).
   1.  If the Reference Diskette is on the hard drive, switch the computer
       ON; or, if the Reference Diskette is on diskette, insert it into the
       A: drive and switch the computer ON.
       During initialization, you may receive one or more adapter
       configuration messages.  This is normal when installing a new adapter,
       because your system has not been re-configured yet.
   2.  Review step <a href="2-5.md">6</a> for information about parameter settings and defaults to
       determine if you should modify the parameters or allow automatic
       configuration.  Enter Y (Yes) for automatic configuration or enter N
       (No) for manual configuration.
       If you entered Y, follow the instructions on the screen, and go to
       step <a href="2-5.md">12</a> when finished.
       If you entered N, continue with step <a href="2-5.md">3</a>.
   3.  From the Main Menu, select the choice that allows you to set the
       configuration.  (For more information about menu selections, use the
       Help facility.)
   4.  From the Set Configuration Menu, select Change Configuration.
   5.  On the Change Configuration panel, ensure that the slot number that
       you used and the adapter name (IBM Dual LANStreamer MC 32 Adapter) are
       correct.  You may have to scroll forward to find this adapter.
       °   If the slot number and adapter name are correct, continue with
           step <a href="2-5.md">6</a>.
       °   If the adapter name does not appear or the slot number is
           incorrect:
           a.  Make sure that all the steps under <a href="2-2.md">"Updating the Backup Copy</a>
               <a href="2-2.md">of Your Reference Diskette" in topic 2.2</a>, and <a href="2-3.md">"Placing the</a>
               <a href="2-3.md">Adapter in an Expansion Slot" in topic 2.3</a> were performed
               correctly.  For example, make sure that the adapter is
               properly inserted into the slot.
           b.  Return to step 1 of this procedure (<a href="2-5.md">"Configuring the</a>
               <a href="2-5.md">Adapter"</a>).
           If the adapter name and slot number are still not correct when
           they are displayed, see <a href="3-0.md">Chapter 3, "Problem Solving" in topic 3.0</a>.
   6.  Check the other parameters to ensure that they are correct for your
       operating environment, based on the following information.
           Interrupt Level:  If you have more than one IBM Streamer Family
           Adapter installed in your computer, the value for the Interrupt
           Level must be the same for each of the adapters installed.  The
           default is 3.  Other valid levels are 2, 10, and 11.
           Adapter I/O Address:  This adapter requires that you select the
           address ranges for the Micro Channel I/O.
           Streaming Data Select:  This enables the adapter to operate with
           data streaming.  For maximum performance, select Enabled.
           Fairness:  This establishes whether the adapter will share the bus
           with other devices or retain control of the bus as needed.  Under
           normal conditions, Fairness On is preferable.
           Arbitration Level:  This parameter selects the arbitration levels
           on which the adapter will operate.
           Parity Enable/Monitor Feedback:  This parameter is for selecting
           whether parity checking and monitoring are on or off.  Using this
           parameter, the adapter will check data and address parity and can
           monitor a controlled device's selected feedback return exception
           signals during direct memory access operations.  The defaults are
           off/off.
   7.  To change any of the other adapter parameters, select the parameter
       you want to change and then use the function keys to select the next
       or previous choice.  (The Help facility provides descriptions and
       valid choices for the parameters.)
   8.  Record the values for the parameters on page <a href="2-5.md">2.5</a>.  (You will need this
       information later if problems arise with the adapter installation.)
       The adapter address is on the label on the adapter, and the code level
       can be viewed through the advanced diagnostics program.
   9.  Press the function key that allows you to save the new configuration.
   10. Select Save, and then Exit the Change Configuration panel.
   11. Exit the Set Configuration Menu, and follow the directions on the
       panel for activating the new configuration.
   12. If the Reference Diskette is in the A: drive, remove it when the
       reference configuration is complete and press Enter to restart the
       computer.
       If you are replacing an adapter, you may receive one or more error
       codes and messages.  This is because configuration for the new adapter
       is not complete and your system is still anticipating a different
       adapter set.  Therefore, even though you are receiving error messages,
       you may not have a problem; likewise, the error codes you are
       receiving may be for the adapter that you replaced (until you have
       successfully configured the Dual EtherStreamer MC 32 Adapter).
       Go to <a href="2-6.md">"Installing the Adapter Drivers and Protocol Drivers" in</a>
       <a href="2-6.md">topic 2.6</a>.
