## 2.2 Updating the Backup Copy of Your Reference Diskette

<a id="HDRUDRD"></a>

Before installing the Dual EtherStreamer MC 32 Adapter in your computer, you ***must*** update your backup copy of the Reference Diskette (see your network administrator if you have any questions about the Reference Diskette). If a Reference Diskette came with your computer, update your backup copy of the Reference Diskette -- not the original (if you do not have a backup copy of the Reference Diskette, make a copy using the Backup the Reference Diskette selection on the Reference Diskette menu).

To update your Reference Diskette, begin with step [1](2-2.md) if it is on diskette; begin with step [3](2-2.md) if it is on the hard drive:

<a id="ELISamy"></a>


<a id="LISamy"></a>

- **1.** If your computer is switched on, switch it OFF.
- **2.** If you made a backup copy of your Reference Diskette, insert it in the A: drive and switch the computer ON. Go to step 4 [.](2-2.md)

<a id="LISbrown"></a>

- **3.** If your reference diskette is stored on the hard drive, press and hold the **Ctrl**, **Alt**, and **Delete** keys. For a few seconds, the cursor will appear in the upper right-hand corner of your computer's display. Press and hold the **Ctrl**, **Alt**, and **Insert** keys to load the Reference Diskette. Then, release the keys. The IBM logo and copyright screen will appear. If you do not see this screen within a few seconds,

repeat this step.

<a id="LISblack"></a>

- **4.** Select the choice from the Main Menu that allows you to copy an option diskette, and follow the instructions presented, using your backup Option/Driver Diskette. Do ***not*** use the DISKCOPY command for this activity.

This operation copies files from the backup Option/Driver Diskette

onto the backup copy of the Reference Diskette.

- **5.** When copying is complete, switch the computer OFF and continue with " [Placing the Adapter in an Expansion Slot" in topic 2.3.](2-3.md)
