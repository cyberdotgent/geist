   This appendix contains messages that can be received from the NDIS MAC
   driver.  The messages are either displayed or logged to a file.
   The term Slot nn appears in several messages.  It is used to identify an
   adapter in the computer based on its slot location and to identify the
   port on the adapter.  Therefore, the first n refers to the slot and the
   second n refers to the port.  The port is identified as either A or B
   (shown on the label located in the center of the adapter interface).  For
   example, 1A corresponds to port A on the adapter in the first slot of the
   computer.
   __________________________________________________________________________
   LTC0008 The value specified for the parameter xx in PROTOCOL.INI is not
          the correct character type.
          Explanation:  The value provided for the parameter in the IBMMPC
          module in PROTOCOL.INI is not the correct type.
          User Action:  Edit the PROTOCOL.INI file to change the value for
          the parameter.  See Table A-1 in topic A.0 for a description of the
          valid values for each NDIS MAC driver parameter.
   __________________________________________________________________________
   LTC0009 An unrecoverable error occurred in the IBM Streamer Family adapter
          NDIS device driver program.
          Explanation:  An internal software error occurred.
          User Action:  Contact your customer service center.
   __________________________________________________________________________
   LTC0010 All IBM Streamer Family adapters must be set to the same interrupt
          level.
          Explanation:  One or more IBM Streamer Family adapters is set to a
          different interrupt level.  To function correctly, these adapters
          must all be set to the same interrupt level.
          User Action:  Use the backup Reference Diskette to change the
          system interrupt level to the same value for each of the Streamer
          Family adapters installed in the computer.
   __________________________________________________________________________

          Explanation:  This is an information message.
          User Action:  No action is required.

          Explanation:  This is an information message.

   LTC0014 The parameter values have forced the control-block size to exceed
          the allowable limit.
          Explanation:  The parameter values specified in the PROTOCOL.INI
          file require more space for processing than can be handled.
          User Action:  Reduce the value specified for either the
          MaxTransmits, MinRcvBuffs, or the MulticastNum parameters to reduce
          the amount of storage required for the control blocks.
          The control-block area can be computed using the following formula:
              1698 + (192 × MaxTransmits) +
                 (256 × MinRcvBuffs) + (16 × MulticastNum)

          driver section in the file.

   __________________________________________________________________________
   LTC0025 Duplicate device driver statements exist in CONFIG.SYS.
          Explanation:  There are more than the required number of Device
          statements for the NDIS MAC driver (IBMMPC) in the CONFIG.SYS file.
          Only one occurrence of the Device statement is required to support
          all of the installed IBM Streamer Family adapters.  Additional
          occurrences of the Device statement will be ignored.
          User Action:  Edit the CONFIG.SYS file to remove the duplicate
          Device statement that loads the NDIS MAC driver.
   __________________________________________________________________________
   LTC0026 The required parameter DRIVERNAME was not found in the
          PROTOCOL.INI file.
          Explanation:  The Drivername parameter was not found in the NDIS
          MAC driver section of the PROTOCOL.INI file.
          User Action:  Edit the PROTOCOL.INI file to add the statement
          Drivername = IBMMPC$ after the NDIS MAC driver (IBMMPC) section
          name.
   __________________________________________________________________________
   LTC0027 The Protocol Manager could not be opened.
          Explanation:  An unexpected error occurred when the program
          attempted to open the Protocol Manager.  The NDIS MAC driver has
          been removed.
          User Action:  Search the hard disk for the Protocol Manager
          (PROTMAN.OS2).  Note the path where the module was found.  Edit the
          CONFIG.SYS file to change the Device statement for the Protocol
          Manager to specify the path where the module was found.
   __________________________________________________________________________
   LTC0028 An unrecoverable error occurred while attempting to register the
          IBM Streamer Family adapter NDIS device driver program with the
          Protocol Manager.
          Explanation:  The device driver was unable to register with the
          protocol manager (PROTMAN.OS2).
          User Action:  Re-install the Protocol Manager and try the operation
          again.  If you still receive an error, call your customer service
          center.
   __________________________________________________________________________
   LTC0029 No adapter that is supported by this device driver was found in
          the system.
          Explanation:  A Dual EtherStreamer MC 32 Adapter was not found in
          this computer.  The Dual EtherStreamer MC 32 Adapter is required to
          run the NDIS MAC driver.
          User Action:  Install a Dual EtherStreamer MC 32 Adapter in this
          computer or remove the Device statement for IBMMPC from the
          CONFIG.SYS file.
   __________________________________________________________________________
   LTC0030 The unrecognized parameter xx was found in the PROTOCOL.INI file.
          Explanation:  An unrecognized parameter was found while processing
          the NDIS MAC driver section of the PROTOCOL.INI file.
          User Action:  Edit the PROTOCOL.INI file to remove the parameter or
          change the parameter to a valid name.  See Table A-1 in topic A.0
          for an explanation of the supported parameters.
   __________________________________________________________________________
   LTC0031 The value specified for network address in PROTOCOL.INI is not
          valid.  The universal address will be substituted.
          Explanation:  The value specified for the network address parameter
          (NetAddress) in the NDIS MAC section of the PROTOCOL.INI file is
          not valid for one of the following reasons:
          °   Local station address not valid
          °   Address too long
          °   Address too short
          °   Contains non-hexadecimal digits
          °   Not enclosed in double quotes
          User Action:  Edit the PROTOCOL.INI file to remove or correct the
          NetAddress parameter.  A valid value for this parameter is 12
          hexadecimal digits and is enclosed in double quotes (" ").  The
          address must be in the range X'020000000000' to X'FEFFFFFFFFFF'.
          This range is not contiguous.

   LTC0039 Initialization proceeding for section xx in PROTOCOL.INI.
          Explanation:  This is an information message.
          User Action:  No action is required.
   __________________________________________________________________________
   LTC0040 Slot nn:  Using local transmit buffers to access data above 16
          megabytes.
          Explanation:  The device driver has detected more than 16 megabytes
          of RAM in the computer, and the adapter is either a 16-bit adapter
          or is located in a 16-bit system slot.  The device driver will copy
          any frame data located above the 16 MB address limit to local
          transmit buffers.
          OS/2 2.0 Users:  Early versions of OS/2 2.0 will only indicate that
          at least 16 MB of RAM exist in the computer.  If your computer has
          exactly 16 MB of RAM, you will see this message.  However, there
          will never be any data above the 16 MB addressing limit to copy
          into local buffers.
          User Action:  This is an informational message only.  No action is
          necessary.
   __________________________________________________________________________
   LTC0041 Slot nn:  Overriding MAXTRANSMITS in PROTOCOL.INI with a value of
          xx.
          Explanation:  The amount of local memory needed to hold all
          possible queued transmit frames, MAXTRANSMITS * MAXTXFRAMESIZE, is
          greater than 128 KB.  The device driver has reduced the
          MAXTRANSMITS value to allow the maximum number of transmit frames
          to fit within the default 128 KB of local buffer space.
          User Action:  Ensure that the values specified for MAXTRANSMITS and
          MAXTXFRAMESIZE are accurately specified in PROTOCOL.INI.  If not
          specified, they should both be added with appropriate values.
          The default values for these parameters in OS/2 are MAXTRANSMITS =
          31 and MAXTXFRAMESIZE = 18000, which exceeds the 128 kilobytes
          allocated by the device driver for the local transmit buffer space.
          These local transmit buffers are needed when more than 16 megabytes
          of system memory is detected, and this IBM Streamer Family adapter
          is unable to access above 16 MB.
          A new PROTOCOL.INI parameter (for example, LOCALBUFFSEGCNT = 4) can
          be used to change the amount of storage used for the local transmit
          buffers.  It can be set from 1 to 16, and defaults to 2 if not
          specified.  Note that 64 KB of system memory are used for each
          local buffer segment configured with this parameter.
   __________________________________________________________________________
   LTC0042 OEMHLP could not be accessed.
          Explanation:  The IBM Streamer Family adapter device driver was
          unable to determine the amount of system RAM in the computer.
          User Action:  Contact your customer service center.
   __________________________________________________________________________
   LTC0044 The configuration values have forced the control-block size to
          exceed the available memory.
          Explanation:  The configuration parameters specified require more
          space for processing than can be handled with the available system
          memory.
          User Action:  Reduce the value specified for either the
          MaxTransmits, MinRcvBuffs, or MulticastNum parameters to reduce the
          amount of storage required.
          The following formula can be used to compute the maximum value:
              H(i) = RCVAREA(i) + ALLOCSIZECB(i)
          Where:
              H is the value computed for each Dual EtherStreamer MC 32
              Adapter.  The sum of all H(i) values must be less than 1 MB.
              i is the total number of Dual EtherStreamer MC 32 Adapters
              installed in your computer.
              RCVAREA = MinRcvBuffs × SizWorkBuf
              ALLOCSIZECB = 1698 + (192 × MaxTransmits) +
         14
                  (256 × MinRcvBuffs) + (16 × MulticastNum)
              The value of ALLOCSIZECB(i) must be less than 64 KB.
              If you need to change the value of any of the parameters in the
              formula, edit the PROTOCOL.INI file.  Change the parameter
              values in the NDIS MAC driver section for the adapter.
   __________________________________________________________________________
   LTC0047 Could not determine the system I/O bus type.
          Explanation:  The Dual EtherStreamer MC 32 Adapter NDIS MAC driver
          was unable to determine the type of I/O bus designed into the
          computer system.  It is looking for a Micro Channel bus.
          User Action:  Make sure your system is based on a Micro Channel bus
          and contains an industry standard BIOS.  Contact your customer
          service center.
   __________________________________________________________________________
   LTC0053 Slot nn:  IBM Streamer Family opened for:  Ethernet, UTP.
          Explanation:  This is an information message.
          User Action:  No action is required.
