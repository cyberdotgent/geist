## 3\.2 Solving Problems with Driver Installation

<a id="HDRDDPD"></a>

If you have problems loading the adapter drivers and you performed the procedures in ["Installing the Adapter Drivers and Protocol Drivers" in](2-6.md) [topic 2\.6](2-6.md) correctly, locate the row in [Table 3\-2](<#TBLNOSENV2>) that describes your system and perform the action\.

| ![PICTURE 17](17.png) | Check LAPSHIST\.LOG in the<br>subdirectory OS2\\INSTALL<br>and LANTRAN\.LOG in the<br>subdirectory \\IBMCOM for<br>messages\.<br>For message prefix LTC<br>or reference to<br>IBMMPC, see<br>[Appendix B\.](b-0.md)<br>[For LAPS messages, see](b-0.md)<br>[the manual provided](b-0.md)<br>[with the LAPS program\.](b-0.md) |
| ![PICTURE 18](18.png) | Check the Microsoft<br>LANManager log,<br>LANMAN\\LOGS\\NET\.ERR,<br>for error messages\.<br>Use the LANManager net<br>error command to<br>obtain explanations\.<br>Verify that the<br>adapter has not been<br>configured for both<br>LANManager and LAN<br>Support Program or<br>LAPS\.
