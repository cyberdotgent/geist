# A\.0 Appendix A\. NDIS MAC Driver Parameters

<a id="HDRMANUAL"></a>

This appendix provides a typical PROTOCOL\.INI file for an OS/2 station and gives explanations of the parameters used in PROTOCOL\.INI\. Refer to this appendix for fine tuning your configuration, or use this appendix for OS/2 installations that are not covered in the driver installation sections of [Chapter 2, "Installing the Adapter" in topic 2\.0](2-0.md)\.

It is important to note that in [Figure A\-1](a-0.md#FIGPROTOS2), not all required lines are shown\. In addition, some of the parameters in the PROTOCOL\.INI are for token\-ring networks\. Therefore, some of the descriptions in [Table A\-1](<#TBLMPROKEY>), do not apply\.

<a id="TBLMPROKEY"></a>

```
    ________________________________________________________________________
   | Table  A-1. NDIS MAC Driver Parameters in PROTOCOL.INI                 |
   |_____________________________________ __________________________________|
   | Parameter                           | Explanation                      |
   |_____________________________________|__________________________________|
   | NetAddress                          | Use this parameter to specify a  |
   |                                     | locally administered address for |
   |                                     | the adapter.  The address must   |
   |                                     | be enclosed in double quotes     |
   |                                     | (" ") and be unique among all    |
   |                                     | the addresses on the network.    |
   |                                     |                                  |
   |                                     | The adapter can be known on the  |
   |                                     | network by its universally       |
   |                                     | administered address (the        |
   |                                     | address encoded in the adapter   |
   |                                     | memory at the factory) or a      |
   |                                     | locally administered address (a  |
   |                                     | unique user-assigned address).   |
   |                                     |                                  |
   |                                     | This is an optional parameter.   |
   |                                     | The universally administered     |
   |                                     | address is the default value.    |
   |                                     | See Figure 1-1 in topic 1.1 for  |
   |                                     | an illustration.                 |
   |                                     |                                  |
   |                                     | Valid values:  X'400000000000'   |
   |                                     | to X'7FFFFFFFFFFF' in canonical  |
   |                                     | format, which is X'020000000000' |
   |                                     | to X'FEFFFFFFFFFF' in            |
   |                                     | non-canonical format.            |
   |_____________________________________|__________________________________|
   | MaxTransmits                        | This parameter specifies the     |
   |                                     | maximum number of transmit queue |
   |                                     | entries.  The value should be    |
   |                                     | set high enough to accommodate   |
   |                                     | the sum of all MaxTransmits for  |
   |                                     | all protocol drivers using the   |
   |                                     | Dual EtherStreamer MC 32 Adapter |
   |                                     | concurrently.                    |
   |                                     |                                  |
   |                                     | Valid values:  2 to 512          |
   |_____________________________________|__________________________________|
   | MaxTxFrameSize                      | This parameter specifies the     |
   |                                     | maximum frame size that can be   |
   |                                     | transmitted on the LAN.  The     |
   |                                     | parameter value serves as an     |
   |                                     | upper limit.  The actual maximum |
   |                                     | frame size may be smaller.  The  |
   |                                     | maximum frame size supported by  |
   |                                     | the NDIS MAC driver is the least |
   |                                     | of the following values:         |
   |                                     |                                  |
   |                                     | °   The value of this            |
   |                                     |     MaxTxFrameSize parameter     |
   |                                     |                                  |
   |                                     | °   Total Receive Buffer Area    |
   |                                     |     less 4 bytes for cyclic      |
   |                                     |     redundancy check (CRC)       |
   |                                     |                                  |
   |                                     | °   The physical frame size      |
   |                                     |     capacity of the network      |
   |                                     |     (4500 bytes for 4-Mbps token |
   |                                     |     rings, 18 000 bytes for      |
   |                                     |     16-Mbps token rings, and     |
   |                                     |     1514 bytes for Ethernet      |
   |                                     |     networks)                    |
   |                                     |                                  |
   |                                     | Do not count the 4 bytes of CRC  |
   |                                     | defined for a frame when setting |
   |                                     | this parameter value.            |
   |                                     |                                  |
   |                                     | Valid values:  14 to 18 000      |
   |_____________________________________|__________________________________|
   | MinRcvBuffs                         | This parameter specifies the     |
   |                                     | minimum number of receive        |
   |                                     | buffers that are allocated.  The |
   |                                     | Total Receive Buffer Area for    |
   |                                     | the adapter is calculated using  |
   |                                     | the following formula:           |
   |                                     |                                  |
   |                                     | Total Receive Buffer Area =  MinR|vBuffs × SizWorkBuf
   |                                     |                                  |
   |                                     | Note:  To receive the maximum    |
   |                                     | length frame that is supported   |
   |                                     | by the attached network, the     |
   |                                     | Total Receive Buffer Area must   |
   |                                     | be larger than the maximum frame |
   |                                     | size (including the 4 bytes of   |
   |                                     | CRC) that is allowed for the     |
   |                                     | network, which is 4504 bytes for |
   |                                     | 4-Mbps token rings, 18 004 bytes |
   |                                     | for 16-Mbps token rings, and     |
   |                                     | 1518 bytes for Ethernet.         |
   |                                     |                                  |
   |                                     | A smaller Total Receive Buffer   |
   |                                     | Area will use less system memory |
   |                                     | but will reduce correspondingly  |
   |                                     | the size of the largest frame    |
   |                                     | that can be received by the NDIS |
   |                                     | MAC driver.  The maximum frame   |
   |                                     | size supported by the driver can |
   |                                     | be further limited by the        |
   |                                     | MaxTxFrameSize parameter.        |
   |                                     |                                  |
   |                                     | Valid values:  2 to 512          |
   |_____________________________________|__________________________________|
   | SizWorkBuf                          | This parameter specifies the     |
   |                                     | size of each receive buffer.  If |
   |                                     | this parameter is not specified  |
   |                                     | or if the value for the          |
   |                                     | parameter is not valid, a        |
   |                                     | default value of 2048 bytes will |
   |                                     | be assigned for OS/2 systems.    |
   |                                     |                                  |
   |                                     | Valid values:  96 to 18 000      |
   |_____________________________________|__________________________________|
   | MulticastNum                        | This parameter specifies the     |
   |                                     | maximum number of multicast      |
   |                                     | addresses supported by the NDIS  |
   |                                     | MAC driver.  Approximately 16    |
   |                                     | bytes of system memory are       |
   |                                     | required for each multicast      |
   |                                     | address.                         |
   |                                     |                                  |
   |                                     | For token-ring networks, a       |
   |                                     | multicast address implies an     |
   |                                     | IEEE 802.5 group address.        |
   |                                     |                                  |
   |                                     | Valid values:  1 to 256          |
   |_____________________________________|__________________________________|
   | EnableTxEofInt                      | This parameter specifies whether |
   |                                     | the Transmit End of Frame        |
   |                                     | Interrupt is enabled.            |
   |                                     |                                  |
   |                                     | Valid values:                    |
   |                                     |                                  |
   |                                     | Yes  Indicates that the          |
   |                                     |      interrupt will be           |
   |                                     |      recognized by the interrupt |
   |                                     |      handler.                    |
   |                                     |                                  |
   |                                     | No   Indicates that the          |
   |                                     |      interrupt will not be       |
   |                                     |      recognized by the interrupt |
   |                                     |      handler.  This value may be |
   |                                     |      preferable in some          |
   |                                     |      environments (such as a     |
   |                                     |      server environment) to      |
   |                                     |      reduce the number of times  |
   |                                     |      the interrupt handler is    |
   |                                     |      invoked.                    |
   |_____________________________________|__________________________________|
   | Enet20UTP                           | This parameter enables the 20    |
   |                                     | Mbps full-duplex mode for        |
   |                                     | Ethernet operation.  It is not   |
   |                                     | used for token-ring networks.    |
   |                                     |                                  |
   |                                     | Valid values:                    |
   |                                     |                                  |
   |                                     | Yes  Enables the adapter port    |
   |                                     |      for full-duplex operation.  |
   |                                     |      Note that the adapter must  |
   |                                     |      be connected with a         |
   |                                     |      10BASE-T (UTP) cable to a   |
   |                                     |      switched Ethernet           |
   |                                     |      concentrator that supports  |
   |                                     |      full-duplex operation.      |
   |                                     |                                  |
   |                                     | No   Does not allow the adapter  |
   |                                     |      port to operate in          |
   |                                     |      full-duplex mode.           |
   |_____________________________________|__________________________________|
   | LoopBack                            | This parameter determines        |
   |                                     | whether the adapter or the       |
   |                                     | protocol will handle loopback.   |
   |                                     | A frame transmitted by the       |
   |                                     | adapter may contain the          |
   |                                     | adapter's MAC, group, or         |
   |                                     | broadcast address in the         |
   |                                     | destination field of the frame.  |
   |                                     | The value of the loopback        |
   |                                     | parameter determines how the     |
   |                                     | frame should be handled.         |
   |                                     |                                  |
   |                                     | For the loopback parameter to    |
   |                                     | appear in the protocol, you must |
   |                                     | override the default setting.    |
   |                                     | The device driver will select    |
   |                                     | the loopback value mode for your |
   |                                     | system environment.  You can     |
   |                                     | override the default by          |
   |                                     | specifying a value for the       |
   |                                     | loopback parameter in LAPs.      |
   |                                     |                                  |
   |                                     | Valid values:                    |
   |                                     |                                  |
   |                                     | Yes  Indicates that transmit     |
   |                                     |      frames whose destination is |
   |                                     |      the adapter will be         |
   |                                     |      transmitted and then        |
   |                                     |      received by the adapter.    |
   |                                     |      When attaching to a 4-Mbps  |
   |                                     |      token ring, loopback will   |
   |                                     |      default to Yes.             |
   |                                     |                                  |
   |                                     | No   Indicates that transmit     |
   |                                     |      frames whose destination is |
   |                                     |      the adapter must be looped  |
   |                                     |      back by the protocol.       |
   |_____________________________________|__________________________________|
   | EnableHiPriTx                       | This parameter specifies whether |
   |                                     | the high-priority transmit       |
   |                                     | channel should be enabled.  The  |
   |                                     | default value is No.  This       |
   |                                     | parameter is enabled only for    |
   |                                     | token-rings; it is ignored in    |
   |                                     | Ethernet networks.               |
   |                                     |                                  |
   |                                     | Valid values:                    |
   |                                     |                                  |
   |                                     | Yes  Indicates that the channel  |
   |                                     |      will be enabled.  The       |
   |                                     |      HiPriTxAccess (Maximum      |
   |                                     |      High-Priority Transmit      |
   |                                     |      Channel Priority) and the   |
   |                                     |      HiPriTxThresh               |
   |                                     |      (High-Priority Transmit     |
   |                                     |      Channel Threshold)          |
   |                                     |      parameters will be used to  |
   |                                     |      further configure the       |
   |                                     |      operation of the channel.   |
   |                                     |                                  |
   |                                     |      An example where this would |
   |                                     |      be configured with a Yes is |
   |                                     |      when time-critical          |
   |                                     |      information is sent using a |
   |                                     |      higher priority level than  |
   |                                     |      the normal traffic (the     |
   |                                     |      high priority transmit      |
   |                                     |      channel is used in the      |
   |                                     |      adapter).                   |
   |                                     |                                  |
   |                                     | No   Indicates that the          |
   |                                     |      high-priority transmit      |
   |                                     |      channel will not be         |
   |                                     |      enabled.                    |
   |_____________________________________|__________________________________|
   | HiPriTxAccess                       | This parameter specifies the     |
   |                                     | value of the maximum token       |
   |                                     | access priority allowed for      |
   |                                     | frames transmitted on the        |
   |                                     | high-priority transmit channel.  |
   |                                     | High-priority transmit frames    |
   |                                     | whose Frame Control priority     |
   |                                     | value exceeds the value of this  |
   |                                     | parameter will have their token  |
   |                                     | access priority reduced to the   |
   |                                     | value specified by this          |
   |                                     | parameter.  Frame Control is a   |
   |                                     | field in the IEEE 802.2 Logical  |
   |                                     | Link Control (LLC) header.       |
   |                                     |                                  |
   |                                     | This parameter is ignored if the |
   |                                     | high-priority channel is not     |
   |                                     | enabled.                         |
   |                                     |                                  |
   |                                     | Valid values: 0 to 5             |
   |_____________________________________|__________________________________|
   | HiPriTxThresh                       | This parameter specifies the     |
   |                                     | frame priority value for         |
   |                                     | transmitting on the adapter's    |
   |                                     | high-priority transmit queue.    |
   |                                     | IEEE 802.2 LLC frames that       |
   |                                     | contain a frame priority setting |
   |                                     | (in the Frame Control field)     |
   |                                     | equal to or greater than the     |
   |                                     | value of this parameter are      |
   |                                     | treated as high-priority frames. |
   |                                     |                                  |
   |                                     | This parameter is ignored if the |
   |                                     | high-priority channel is not     |
   |                                     | enabled.                         |
   |                                     |                                  |
   |                                     | Valid values: 1 to 5             |
   |_____________________________________|__________________________________|
```
