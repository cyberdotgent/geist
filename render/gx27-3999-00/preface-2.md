## PREFACE.2 Prerequisite Publications

You should have access to the following manuals:

- Microsoft LANManager** Installation and Configuration Guide (if you are using that program)
- IBM LAN Adapter and Protocol Support Configuration Guide (if you are using that program)

The following publications are related reading for the use of this adapter:

- IBM Local Area Network Technical Reference, SC30-3383
- IBM Local Area Network Administrator's Guide, GA27-3748
