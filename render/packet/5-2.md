## 5.2 BPQCODE

****BPQ**CODE**, otherwise just called the BPQ Packet **Engine**, is the / aforementioned MS-DOS BPQ AX.25 stack. This provides basic NET/ROM s*upport,* and not much else.

While BPQCODE does provide KISS interface support, it also supports the ***BPQETHER*** interface -- this was described in the Linux AX.25 section. Do, however, note that BPQETHER requires the installation of *an* *additional* [FTNFTNUNIQ61](#FTNFTNUNIQ61) *network* *stack!* (48)
