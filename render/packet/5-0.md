# 5.0 BPQ Packet Engine

( John Wiseman, G8BPQ, has a long-standing history of influencing packet *radio i*n several important ways; his most profound contributio**n i**s the BPQ **Packet** **Engine** (which has undergone several name changes over the course of its life).

There are several versions of BPQ: **BPQCODE, for MS-DOS** **LinBPQ, for Linux** **BPQ32, for 32-bit Windows** **! First, we will discuss LinBPQ (since it is rather likely that you, as a ham radio operator, have plenty of Linux machines sitting around)**.

BPQ does, however, have stellar implementations of:

- APRS
- A mail system/PMS

A chat server Note conversely that BPQ does not have:

- TCP/IP
- A configuration GUI
- LinBPQ
- BPQCODE
