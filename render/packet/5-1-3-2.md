#### 5.1.3.2 Telnet

To access the BPQ Telnet socket, simply connect to the TCPPORT value in the Telnet port configuration section: % telnet 127.0.0.1 7300 Trying 127.0.0.1... Connected to 127.0.0.1. Escape character is '^]'. callsign:n4ham password: Connected to MYBPQ:WA4XYZ-8 Enter for list of commands a -- MYBPQ:WA4XYZ-8} BBS CHAT SHELL CONNECT BYE INFO NODES PORTS ROUTES USERS MHEARD bye *** Disconnected from Stream 2 Connection closed by foreign host. % All the same commands apply as shown in the **QtTermTCP** section above!
