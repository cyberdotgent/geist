# GLOSSARY Glossary

<a id="GLS"></a>

```text
       ___
      | C |
      |___|
      Constellation Diagram
   FLOW GD 3 3
   Constellation  Diagram.   A  diagram that displays amplitude and phase for
   various digital modulation modes, including PSK and QAM.
      CSS
   FLOW GD 3 3
   CSS.  Chirp Spread-Spectrum, a modulation mode often  used  for  ISM  band
   devices
       ___
      | I |
      |___|
      ISM Band
   FLOW GD 3 3
   ISM  Band.   Various  unlicensed  radio  bands  that permit some amount of
   transmit power, but barely any; almost all of them (except for the 40  MHz
   band in most countries) overlap amateur radio bands.
       ___
      | L |
      |___|
      LoRa
   FLOW GD 3 3
   LoRa.  "Long Range," a CSS modulation mode with very good SNR
       ___
      | O |
      |___|
      OSI Model
   FLOW GD 3 3
   OSI  Model.   A  reference  model  for a network stack also called the OSI
   Stack, which is often applied to other protocols. The layers are physical,
   data-link, network, transport, session, presentation, application
       ___
      | P |
      |___|
      PSK
   FLOW GD 3 3
   PSK.  "Phase-Shift Keying," a data modulation mode in which the  phase  of
   the signal is modulated
       ___
      | Q |
      |___|
      QAM
   FLOW GD 3 3
   QAM.   "Quadrature Amplitude Modulation," a data modulation mode where the
   amplitude and phase of the modulated analog waveform is varied
       ___
      | S |
      |___|
      SNR
   FLOW GD 3 3
   SNR.  "Signal-to-Noise Ratio," a ratio of the signal strength to the noise
   strength
```
