# 6\.0 XRouter

Despite being closed\-source, [\(50\)](<#FTNFTNUNIQ63>) XRouter is probably the best packet radio stack on the market\. It features all manner of beautiful user interfaces, advanced protocol support, and other such things\. A short list of XRouter features includes:

- Full IPv4 support *\(with NAT and RIP routing\)*
- APRS support [\(51\)](<#FTNFTNUNIQ64>)
- FTP, SMTP, Finger, Telnet, and other TCP services
- INP3 \(Inter\-Node Protocol 3\), a NET/ROM distance vector determination protocol
- An advanced PBS and chat server
- Support for colored user interfaces everywhere [\(52\)](<#FTNFTNUNIQ65>)
- Feature\-rich HTTP \(web\) server

<a id="FTNFTNUNIQ63"></a>

\(50\) There are several explanations for this, with the most popular one being that "XRouter is a combination of BPQ, NOS, and TheNet," but the stated reason is that the package's author does not wish to use Git *\(which is a very valid reason\)\.*
