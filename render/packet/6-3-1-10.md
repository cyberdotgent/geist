#### 6.3.1.10 Ethernet LAN Interface

This allows XRouter to hook into a LAN with the libpcap library; note that

this is for actual Ethernet card interfaces and NOT tun/tap devices!

INTERFACE=7

TYPE=EXTERNAL

PROTOCOL=ETHERNET

ID=eth0

MTU=1500

ENDINTERFACE
