##### 2.4.5 TCP and UDP

As mentioned before, TCP and UDP are the most common protocols that run on * top of IP (besides ICMP); these are the protocols that applications actually use to transfer data between hosts. Since it would not make sense

to only allow one connection between two hosts, TCP and UDP provide a port

multiplexing method wherein program listen on various port numbers; the other side, which wishes to connect to a host listening on some port, ( simply opens a connection to that port! Some ports are reserved for specific application protocols; here are some common ports:
