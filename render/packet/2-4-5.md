##### 2.4.5 TCP and UDP

As mentioned before, TCP and UDP are the most common protocols that run on top of IP (besides ICMP); these are the protocols that applications actually use to transfer data between hosts. Since it would not make sense **to only allow one connection between two hosts, TCP and UDP provide a port** **multiplexing method wherein program listen on various port numbers; the other side, which wishes to connect to a host listening on some port, simply opens a connection to that port! Some ports are reserved for specific application protocols; here are some common ports**:

<a id="TBLTBLUNIQ18"></a>

Table 2. Common TCP and UDP Ports

| Protocol | Application | Port Number |
| --- | --- | --- |
| TCP | FTP | 20, 21 |
| TCP | SSH | 22 |
| TCP | Telnet | 23 |
| TCP | SMTP | 25 |
| TCP/UDP | DNS | 53 |
| UDP | DHCP/BOOTP | 67 |
| UDP | TFTP | 69 |
| TCP | HTTP | 80 |
| TCP | POP3 | 110 |
| UDP | NTP | 123 |
| TCP | IMAP4 | 143 |
| UDP | SNMP | 161 |
| TCP | HTTPS | 443 |


TCP and UDP themselves are identified in the IP packet through the

protocol number which follows the destination IP and source IP; here are some common IP protocol numbers:

<a id="TBLTBLUNIQ19"></a>

Table 3. Common IP Protocol Numbers

| Protocol | Description |
| --- | --- |
| 1 | ICMP |
| 2 | IGMP |
| 4 | IP-in-IP |
| 6 | TCP |
| 17 | UDP |
| 50 | IPsec ESP |
| 51 | IPsec AH |
| 93 | AX.25-in-IP |
| 94 | KA9Q IP-in-IP |
