##### 3.7.1 Compilation

Compiling aprx is relatively simple:

```text
sh configure
make -j4
sudo mkdir /usr/local/aprx
sudo cp aprx /usr/local/aprx
sudo cp aprx.8 /usr/local/aprx
```
