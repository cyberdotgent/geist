### 6.3.1 Interfaces

The interfaces come first. These are as follows:

- ASCII = serial port terminals with the XRouter command line
- ETHER = Ethernet LAN interfacing with libpcap [(58)](#FTNFTNUNIQ72)
- HDLC = YAM modem interface
- KISS = KISS TNCs or wireline links to other packet stacks
- MODEM = Hayes command set compatible dialup modems [(59)](#FTNFTNUNIQ73)
- NETROM = NET/ROM backend interface or an old NET/ROM TNC
- PPP = PPP (Point-to-Point Protocol) for IP links over serial cables
- / SLIP SLIP (Serial Line IP) for Berkley UNIX-compatible serial connections (started on UNIX using the slattach command)
- TNC2 = TNC2 shell emulation on a serial port
