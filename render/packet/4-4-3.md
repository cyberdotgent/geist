##### 4\.4\.3 Sysop Mode

With all of this in mind, advanced mode may be more ideal for registered users\. However, there is one more mode that we must cover: *sysop mode\.* Since it may sometimes be necessary to access the JNOS shell remotely, the JNOS authors were sure to include a mechanism to do so; enter the `@` command to switch:

     @ pass123

     Type 'exit' to return
