### 5.1.1 Installation

Note that the following dependencies are required to compile LinBPQ:

libconfig

libpca

LinBPQ can be compiled without too much difficulty. Clone the source code from GitHub as follows, then compile it:

$ $ git clone https://github.com/g8bpq/linbpq

$ cd linbpq

$ make

Once the compilation has completed successfully, you may start configuring

it. Inevitably, you will want to relocate thelinbpq binary to some other run directory; if this is a multiuser system and you would like to ensure its security, ensure that the directory permissions disallow world-write

(and world-read if you like). (43)
