Linux has two ways of identifying AX.25 ports: The port* nam*e*, a *textual name that the AX.25 commands use The inter*face name*, *the *name that the Linux kernel knows the network device by <a id="fnref-FTNFTNUNIQ21"></a>[(12)](#FTNFTNUNIQ21)

= To define an AX.25 port, edit /etc/ax25/axports, and, use tabs for

# name callsign speed paclen window description #----- -------- ----- ------ ------ ----------- radio WA4XYZ-1 1200 256 7 Real TNC

Each field is as follows: name: a descriptive name of the port (the "port name" described above) <a id="fnref-FTNFTNUNIQ22"></a>[FTNFTNUNIQ22](#FTNFTNUNIQ22)

callsign: the unique callsign and SSID used for the port (13) <a id="fnref-FTNFTNUNIQ23"></a>[FTNFTNUNIQ23](#FTNFTNUNIQ23)

speed: the baud rate used on the interface's serial link (14) paclen: the packet length, 256 is standard for VHF/UHF links window: the window size for the port (see the above notes in the AX.25 section) description: a bit of text for your convinence = For*** NET/RO***M ports, you want to edit /etc/ax25/nrports (again, use tabs
