##### 3.2.1 Starting Ports and Daemons

After you have defined all of those ports, you now need to start them. In this day and age, most Linux distributions do not automatically load the

Linux kernel modules for packet radio, so load them yourself: [(16)](#FTNFTNUNIQ25) # ``m`odprobe` `ax25` # ``m`odprobe` `netrom` # ``m`odprobe` `rose`
