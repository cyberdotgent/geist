#### 6.3.1.14 AXTCP Client Interface

For calling out to remote AXTCP sockets:

```text
INTERFACE=5
TYPE=AXTCP
MTU=1300
CONFIG=XR1 1.2.3.4 9393
ENDINTERFACE
```

CONFIG has three fields:

- 1. The remote node name
- 2. The IP address or hostname of the remote server
- 3. The remote port (corresponding to INTNUM)
