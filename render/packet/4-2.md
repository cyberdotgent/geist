### 4.2 Compilation

To actually compile JNOS, you need to retrieve the source code from VE4KLM's website: [(30)](#FTNFTNUNIQ42)

$ ``r`sync` `-a` `www.langelaa`r`.net:`:`official` `jnos`

You now need to configure the program: $ ``c`d` `jnos` `$` `./configure` $ ``m`ake` `-j8` # ```m`kdir`` /jnos # ``c`p` `-rv` `jnos` `jnospwmgr` ``usage`` /jnos

With that last command being ran, JNOS has been installed. You may now proceed to configuration.
