### 4.2 Compilation

To actually compile JNOS, you need to retrieve the source code from

[VE4KLM's website: (30)](4-2.md)

$ rsync -a www.langelaar.net::official jnos

You now need to configure the program: $ cd jnos $ ./configure $ make -j8 # mkdir /jnos # cp -rv jnos jnospwmgr usage /jnos

! With that last command being ran, JNOS has been installed. You may now proceed to configuration.
