# 2.0 Surveying the Landscape: Protocols and Stacks

When discussing packet radio, it helps to have an understanding of the numerable protocols found on the air:

AX.25

KISS

NET/ROM

ROSE

TCP/IP

APRS

Before we get carried away, it is a good idea to familiarize oneself with

these protocols:

- AX.25 (and KISS)
- NET/ROM
- ROSE
- Internet Protocol
- TexNet
