- **ADY001I** **THE** **DAE** **PARAMETER** **RECORD** **IN** **MEMBER** **mem** **HAS** **A** **SYNTAX** **ERROR** **ERROR** **=** prm: text — text **is** **one** **of** **the** **following:** THIS IS AN INVALID DAE VERB THIS IS AN INVALID KEYWORD AN EXPECTED LEFT PARENTHESIS WAS NOT FOUND THIS IS AN INVALID RECORD NUMBER OR A RIGHT PARENTHESIS IS MISSING THIS IS AN INVALID DELIMITER THIS KEYWORD VALUE WAS SPECIFIED MORE THAN ONCE THIS IS AN INVALID KEYWORD VALUE **Explanation:** While processing a SET DAE operator command, dump analysis and elimination \(DAE\) encountered an error in a parameter in the ADYSETxx parmlib member\. In the message text: mem The parmlib member name\. prm The parameter in error\. THIS IS AN INVALID DAE VERB The first text that is not a comment was not DAE=, as required\. THIS IS AN INVALID KEYWORD The keyword is not one of the keyword parameters defined for DAE\. AN EXPECTED LEFT PARENTHESIS WAS NOT FOUND The value following the keyword was not enclosed in parentheses, as required\. THIS IS AN INVALID RECORD NUMBER OR A RIGHT PARENTHESIS IS MISSING The value was not a decimal number of 1 to 4 digits followed by a right parenthesis\. THIS IS AN INVALID DELIMITER The keyword parameter was not delimited by commas or the keyword value was not enclosed in parentheses\. THIS KEYWORD VALUE WAS SPECIFIED MORE THAN ONCE The SYSMDUMP or SVCDUMP keyword specified one of the following values more than once: MATCH SUPPRESS UPDATE THIS IS AN INVALID KEYWORD VALUE The SYSMDUMP or SVCDUMP keyword contained a value other than the following: MATCH SUPPRESS UPDATE **Source:** Dump analysis and elimination \(DAE\) **System** **Action:** The system does not process the SET DAE command\. **Operator** **Response:** Correct the error in the ADYSETxx parmlib member and enter the SET DAE command, or contact the system programmer\. **System** **Programmer** **Response:** Correct the error in the ADYSETxx parmlib member\. Request the operator to enter the SET DAE command\.

- **ADY012I** **THE** **FOLLOWING** **DAE** **OPTIONS** **ARE** **IN** **EFFECT:** **text** — text **is** **one** **of** **the** **following:** START SVCDUMP = subparameters SYSMDUMP = subparameters RECORDS = nnn **Explanation:** The system started dump analysis and elimination \(DAE\) with the following options: START DAE started successfully and is now active\. SVCDUMP = subparameters SYSMDUMP = subparameters DAE analyzes SVC dumps or SYSMDUMP dumps according to the subparameters, as follows: MATCH Specifies that DAE should determine which dumps are duplicates by comparing their symptoms against symptoms in the temporary records kept in virtual storage\. These temporary records contain symptoms copied from the DAE data set and symptoms that have occurred since DAE was started\. SUPPRESS Specifies that DAE should suppress duplicate dumps\. UPDATE Specifies that DAE should update the DAE data set with the results from matching\. RECORDS = nnn nnn The maximum number of symptom records, in decimal, that can be placed in virtual storage\. **Source:** Dump analysis and elimination \(DAE\) **System** **Action:** DAE analyzes the specified dumps according to the indicated options\. DAE eliminates a dump only if the SUPPRESS option was specified for that dump and all suppression criteria are met\. **Operator** **Response:** Check if the options listed are the options desired\. To change options, start DAE with the correct parmlib member\.

- **ADY013I** **DAE** **COULD** **NOT** **FREE** **nnn** **BYTES** **OF** **FIXED** **COMMON** **STORAGE** — **Explanation:** Processing for a DAE STOP command could not free cell pool storage occupied by the symptom queue\. In the message text: nnn The number of bytes of storage\. **Source:** Dump analysis and elimination \(DAE\) **System** **Action:** DAE abandons the cell pool storage from the fixed system queue area \(SQA\)\. When the number of cell pools that are not freed reaches a threshold, DAE cannot be started again\. **Operator** **Response:** If requested by the system programmer, enter a SET DAE command\. **System** **Programmer** **Response:** Look for an incomplete SVC dump or SYSMDUMP dump\. The problem occurred during processing for this dump\. Request the operator to enter a SET DAE command\.
