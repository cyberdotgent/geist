## PREFACE\.4 Where to Find More Information

Many message descriptions refer to:

- **Data areas and control blocks**: See *Diagnosis: Data Areas*\.
- **Dumps**: For examples of ABEND, stand\-alone, and SVC dumps and how to read them, see *Diagnosis: Using Dumps and Traces*\. For examples of component output from dumps and how to read and request it, see *Diagnosis: Component Reference*\.
- **Identification of a component, subsystem, or product**: See the *Problem Determination Guide* to identify the component, subsystem, or product from the name of an IBM module or for a macro\. The module prefix and macro tables give the program identifier to be used in a PIDS symptom in a search argument\.
- **System completion and wait state codes**: See *System Codes*\.
- **SYS1\.LOGREC error records**:

For the formatted software records, see *Diagnosis: Using Dumps and Traces*\. For all records, see *SYS1\.LOGREC Error Recording*\.

- **Trace output**: For the formats and the meaning of the information in the generalized trace facility \(GTF\) trace, instruction address trace, master trace, and system trace, see *Diagnosis: Using Dumps and Traces*\. For information about component traces, see *Diagnosis: Component Reference*\.

The following tables list books that contain information related to the information contained in the *System Messages* books\. For the titles and order numbers of books not in the tables, see the *Library Guide*\.

Use the appropriate *Principles of Operation* book for the hardware you have installed\.

When the *System Messages* books reference information in other books, the shortened version of the book title is used\. The following tables show the shortened titles, complete titles, and order numbers of the books that you might need while you are using the *System Messages* books\.
