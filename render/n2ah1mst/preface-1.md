## PREFACE.1 Who Should Use These Books

The System Messages books are for all people who receive messages from the system. Usually, these people are system operators, system programmers, and application programmers who do any of the following tasks: Initialize the operating system and its subsystems Monitor system activity Keep the system running correctly Diagnose and correct system problems Diagnose and correct errors in problem programs
