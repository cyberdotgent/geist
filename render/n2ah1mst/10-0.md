 |        Source:  Advanced Program-to-Program Communication (APPC)

 |        System Programmer Response:  If the system previously issued

 |        preceding message.

 | ATB003I START APPC SYNTAX IS INCORRECT. COMMAND IGNORED.
 |        Explanation:  The value assigned to the APPC keyword on the START

 |        Source:  Advanced Program-to-Program Communication (APPC)
 |        System Action:  The system rejects the START command.
 |        Operator Response:  Correct the syntax and enter the START command

   __________________________________________________________________________

 |        Explanation:  An attempt was made to start Advanced

 |        Source:  Advanced Program-to-Program Communication (APPC)
 |        System Action:  The system rejects the subsequent START command.
 |        The APPC address space already active continues processing.
 |        Operator Response:  If you do not want the existing APPC address
 |        space, cancel it with the CANCEL command.  See System Commands for
 |        more information.
 |        Once APPC has ended (indicated by message ATB002I), a new APPC
 |        address space can be started using the START APPC command.
   __________________________________________________________________________

 |        Explanation:  Advanced Program-to-Program Communication (APPC)
 |        abnormally ended while initializing or while processing APPC work.
 |        The system is attempting to restart APPC.
 |        In the message text:
 |        rc        An internal reason code associated with the error.
 |        Source:  Advanced Program-to-Program Communication (APPC)
 |        System Action:  APPC services are temporarily unavailable.  The
 |        system issues message ATB007I when APPC becomes active again.  APPC
 |        will restart with the same environment that existed before the
 |        error, with the following exceptions:
 |        °   The system rejects any work that was not completed when the
 |            error occurred and notifies the requestor.
 |        °   An APPC component trace that was started before the error
 |            occurs will no longer be active after the restart.
 |        Operator Response:  After APPC becomes active, reenter any commands
 |        that were rejected, if you still want the system to process them.
 |        If component trace was active before APPC abnormally ended, it will
 |        no longer be active following restart.  To restart component trace,
 |        see Diagnosis: Component Reference.
 |        System Programmer Response:  Search problem reporting data bases
 |        for a fix for the problem.  If no fix exists, contact the IBM
 |        Support Center.  Provide the SVC dump and reason code issued with
 |        this message.
   __________________________________________________________________________

 |        Explanation:  Advanced Program-to-Program Communication (APPC)
 |        abnormally ended while initializing or while processing APPC work.
 |        APPC will not attempt to restart itself.
 |        In the message text:
 |        rc        An internal reason code associated with the error.
 |        Source:  Advanced Program-to-Program Communication (APPC)
 |        System Action:  APPC services are unavailable.  The system rejects
 |        all incoming APPC work.  Work already running on the system
 |        completes or ends.  When APPC has ended, normally or abnormally,

 |        °   If the system does not issue message ATB002I, APPC has hung in

 |        °   If the system still does not issue message ATB002I after you
 |            issue the FORCE command, the only way to start APPC is to
 |            re-IPL the system.
 |        System Programmer Response:  Identify the problem using the SVC
 |        dump and the APPC component trace records.  APPC may have
 |        abnormally ended due to the frequency of abends (two abends within

 |        abends may be unrelated.
 |        If the problem persists, search problem reporting data bases for a
 |        fix for the problem.  If no fix exists, contact the IBM Support

 |        message.

 |        Source:  Advanced Program-to-Program Communication (APPC)

 |        Source:  Advanced Program-to-Program Communication (APPC)
 |        System Action:  APPC services are unavailable.  The system writes

 |        Operator Response:  Do not send any work to APPC.  Notify the
