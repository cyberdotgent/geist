### 1.2.2 Messages Sent to MCS Consoles

<a id="TBLTBLUNIQ10"></a>

| hh.mm.ss sysname jobname message | hh.mm.ss sysname message |
| --- | --- |


' Messages sent to JES3 consoles (attached to JES3 global processors only) appear in the format:

<a id="TBLTBLUNIQ11"></a>

[Table: TBLTBLUNIQ11]

hh.mm.ss hhmmsst from Time stamp: the hour (00-23), minute (00-59), second (00-59), and, for JES3, tenth of a second (0-9). sysname System name for the system that issued the message. jobname Job name for the task that issued the message. This field is blank if a task did not issue the message. i Indicator from the JES3 spool access method (JSAM). f A screen character to indicate the status of certain messages, as follows:( | The operator can delete the message. The operator has performed the action required for the message.( The message is for information only; no operator action is required. The message was issued by the system or by a problem program. The message requires specific operator action and was issued by an authorized program. The message has a descriptor code of 1, 2, or 11. @ The message requires specific operator action and was issued by a problem program. The message has a descriptor code of 1, 2, or 11. + The message requires no specific operator action and was issued by a problem program using a WTO macro.) ## The message requires an operator reply and was issued by a WTOR macro. blank The message requires no specific operator action.

**Note:** See the Routing and Descriptor Codes book for the descriptor codes.

message Reply identifier, message identifier, and text.
