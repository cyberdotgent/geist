## 6\.2 Help Information for a Field

Typing data in the entry fields of system displays is one of the ways you interact with the computer\.

Occasionally, you may come across a field that you don't understand\. When this happens, you can use the help information provided for that field to answer your question\.

To see help information for a field, you move the cursor to the field in question, then press the Help key\. This gives you help information that provides an explanation of that field\.

```
    ___ Fields _____________________________________________________________
   |                                                                        |
   | Previously, we just discussed entry fields.  There are actually other  |
   | fields on displays.  These fields, which are not input fields, are     |
   | just defined areas on the displays that have their own help.  These    |
   | areas may be horizontally or vertically defined based on the           |
   | information shown on the display.  You'll begin to understand this as  |
 | | we talk about help information for fields.                             |
   |                                                                        |
   |________________________________________________________________________|
```

The type of system display \(menu, entry, list, or information\) determines the type of help information that is given for a field\. *Menu Displays*: Help for fields on menu displays provides information about each option listed on the menu\.

Help information for a particular option on system menus can be obtained in two ways:

- By typing the option number on the menu option line and pressing the Help key
- By placing the cursor anywhere on the line that contains the option number and description, and pressing the Help key

Let's go back to the Operational Assistant menu and give it a try\. Remember that you just press the F3 key repeatedly until the AS/400 Operational Assistant menu is displayed\.

*List Displays*: Help for fields on list displays provides information on the meaning of each column\. You put the cursor in the column of information and press the Help key to get help about that specific column\.

```
    ___ Extended Help ______________________________________________________
   |                                                                        |
 | | From the Help display for most menu, entry, and list displays, you can |
 | | use the F2 key to get extended help.  Extended help gives you          |
 | | information about the entire display.                                  |
   |                                                                        |
   |________________________________________________________________________|
```

*Information Displays*: Help is not available for specific fields on information displays, because there is no need for information about information\.

However, if you press the Help key while at an information display, extended help \(the general information about that display\) appears\. If you press the Help key again, with the cursor positioned anywhere on the extended help display, another level of help information appears with a title of **How to Use Help**\. This is the same help information that is available from option **1** of the User Support and Education menu\.

```
    ___ So... ______________________________________________________________
   |                                                                        |
   |  The AS/400 system provides three ways to get help for fields:         |
   |                                                                        |
   | °   On an entry display, place your cursor anywhere within an input    |
   |     field and press the Help key.                                      |
   |                                                                        |
 | | °   On a menu display, type an option number on the menu option line   |
 | |     and press the Help key.                                            |
   |                                                                        |
   |     You can also do this by putting the cursor on the same line with   |
   |     any menu option and pressing the Help key.                         |
   |                                                                        |
   | °   On a list display, put the cursor in the column for which you want |
   |     information and press the Help key.                                |
   |                                                                        |
   |________________________________________________________________________|
```
