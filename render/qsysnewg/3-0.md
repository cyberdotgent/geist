# 3\.0 Chapter 3\. Your Keyboard

<a id="HDRKEYBD"></a>

<a id="FIGFIGUNIQ19"></a>

![PICTURE 22](22.png)

The versatility of the AS/400 system allows it to be hooked up to many kinds of display stations\. It feels perfectly comfortable communicating with a personal computer, a highly complex graphics display, or something left over from another system\.

They all work well, but the keys might not be labeled the same\. This chapter will help you learn which key does what\.
