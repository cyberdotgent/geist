# 3.0 Chapter 3.  Your Keyboard

<a id="HDRKEYBD"></a>

<a id="FIGUNIQ19"></a>

![Resource 22](22.png)

PICTURE 22.

The versatility of the AS/400 system allows it to be hooked up to many kinds of display stations. It feels perfectly comfortable communicating with a personal computer, a highly complex graphics display, or something left over from another system. They all work well, but the keys might not be labeled the same. This chapter will help you learn which key does what.

**Please** **Note:**

Because there are so many possible display station/keyboard combinations that work with the AS/400 system, you may have to check [Appendix E, "AS/400 Keyboards"](e-0.md) for specific differences on your keyboard. If you still have questions (pa*rticularly i*f *y*o*u're u*s*ing a* *personal* *computer* keyboard), refer to your display station or *keyboard* manual, or see your system administrator.
