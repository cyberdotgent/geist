## D\.2 Type\-Ahead Function

There is a 32\-keystroke storage function available for display stations that are not personal computers\. This type\-ahead function allows you to type commands or data while the Input Inhibited light is on\. These keystrokes are held in the display station's storage until the system is ready for input and the Input Inhibited light is off\. The keystrokes that were saved in storage are then displayed and processed\.

If you attempt to save more than 32 keystrokes, an alarm sounds for each key that is pressed and cannot be stored\.

To clear all the keystrokes that have been stored, press the Reset key or the System Request key\.
