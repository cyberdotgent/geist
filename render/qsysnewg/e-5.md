## E.5 Using the ASCII Keyboards

<a id="HDRACSII"></a>

Using the work station function, you can have an ASCII keyboard attached to your AS/400 system. The following keyboards are available: 3101 keyboard. See " [Using the 3101 ASCII Keyboard" in topic E.5.1.](e-5-1.md) 3151 keyboards (with or without the numeric key pad). See ["Using the](e-5-2.md) 3 [151 ASCII Keyboards" in topic E.5.2.](e-5-2.md) 3160 keyboards. See " [Using the 3161 ASCII Keyboard" in topic E.5.3.](e-5-3.md)
