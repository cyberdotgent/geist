## E.5.3 Using the 3161 ASCII Keyboard

<a id="HDR3160"></a>

The 3160 ASCII keyboard is shown below.

<a id="RSLN503"></a>

![Resource 88](88.png)

Figure E-12. Work Station Function with the 3160 ASCII Keyboard.

To use function keys F1 through F12 (F1 through F12): Press the appropriate function key located at the top of the keyboard. To use function keys 13 through 24 (F13 through F24): 1. Press and hold the Shift key. 2. Press the appropriate top row function key. For example, the F1 key is used as F13, the F2 key is used as F14, the F3 key is used as F15, or the F12 key is used as F24.
