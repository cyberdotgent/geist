## 8.1 Batch Jobs

| Any work done by the system is referred to as a **job**. A job can be started | by: | Typing a command Running a program | A **batch** **job** is any job that doesn't require continuous interaction between | the system and the user after it has been submitted to be processed (run). | A user submits the job (for example, Frieda prints a sales report), and it | is sent to a **job** **queue**, where it remains until it can be run. The | computer needs no further information from the user once the job has been | submitted because all the information for the job is stored in data files | on the system. | Frequently, users submit batch jobs at about the same time. In such | cases, jobs are temporarily placed in a **job** **queue** in the order that they | were submitted (which could involve a difference of only a fraction of a | second). As the system finishes one batch job, it searches the job queue for more work. Batch jobs, therefore, actually start from a job queue.
