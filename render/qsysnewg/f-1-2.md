### F\.1\.2 Function Key Differences on Help Displays

<a id="HDRHELPDIF"></a>

A help display is shown when you press the Help key on the system displays of the AS/400 system, the System/36, or the System/38\.

<a id="FIGTBLUNIQ105"></a>
