#### 7\.7\.2\.1 Messages from People

In the case of a message sent by another user, the reply can be one word, one phrase, or anything up to 60 characters long\. Let's suppose that Norbert had sent Teresa an inquiry message\. Teresa's message queue on the Work with Messages display would look like this:

```
    __________________________________________________________________________________
   |                                                                                  |
 | |                                Work with Messages                                |
 | |                                                              System:   RCH38360  |
 | |  Messages for:   TGREEN                                                          |
   |                                                                                  |
 | |  Type options below, then press Enter.                                           |
 | |    4=Remove   5=Display details and reply                                        |
   |                                                                                  |
 | |  Opt   Message                                                                   |
 | |                             Messages needing a reply                             |
 | |   _    ===> TGREEN: Dear Teresa, isn't it my turn tomorrow to be the quality     |
 | |          control person on the doughnut line?                                    |
 | |          From  . . :   NORBERT        11/02/90   16:38:16                        |
   |                                                                                  |
 | |                           Messages not needing a reply                           |
 | |        (No messages available)                                                   |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
 | |                                                                          Bottom  |
 | |  F1=Help   F3=Exit   F5=Refresh   F6=Display system operator messages            |
 | |  F16=Remove messages not needing a reply   F17=Top   F24=More keys               |
   |                                                                                  |
   |                                                                                  |
   |__________________________________________________________________________________|
```

To reply to an inquiry message sent by another person, place the cursor in front of it, type option **5** \(Display details and reply\), and press the Enter key\. The Additional Message Information display appears\.

```
    __________________________________________________________________________________
   |                                                                                  |
 | |                          Additional Message Information                          |
 | |  Message ID  . . . . . . :   CPA5335          Severity . . . . . . :   99        |
 | |  Message type  . . . . . :   INQUIRY                                             |
 | |  Job . . :   REPRT01        User . . :   TGREEN         Number . . :   027799    |
 | |  Date sent . . . . . . . :   11/27/90         Time sent  . . . . . :   08:31:42  |
 | |  From program  . . . . . :   QWPXPRMA         Instruction  . . . . :   0000      |
   |                                                                                  |
 | |  Message . . . . :   ===> TGREEN: Dear Teresa, isn't it my turn tomorrow to be   |
 | |    the quality control person on the doughnut line?                              |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
 | |                                                                         Bottom   |
 | |  Type reply, press Enter.                                                        |
 | |    Reply . . .   Sorry, production drops when you're on the doughnut line!_____  |
   |                                                                                  |
 | |  F3=Exit           F12=Cancel                                                    |
   |                                                                                  |
   |                                                                                  |
   |__________________________________________________________________________________|
```

As you can see, Norbert's message is also shown on this display, located above the reply line\. And, oh look, Teresa has already typed in her reply\. How efficient she is\!

It's easy to send a reply to a message\. Your cursor will already be at the correct place on the reply field\. You just type in your reply and press the Enter key\. Your reply is automatically sent back to the person who sent you the inquiry message\. If we were to look at Norbert's message queue, we would see that Teresa's reply has indeed made the trip\.
