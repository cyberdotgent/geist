### 4\.1\.2 Intermediate Assistance Level

This assistance level uses displays that support all of the tasks that can be done on the AS/400 system\. It uses computer terminology to describe the options and functions available from each display, as well as the tasks that can be done\. This assistance level allows very complex tasks to be performed with greater flexibility\.
