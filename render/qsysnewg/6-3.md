## 6.3 Index Search Information

<a id="FIGUNIQ75"></a>

![Resource 59](59.png)

PICTURE 59.

| A different kind of help information is provided by an | AS/400 function called **index** **search**. If you take a little time now to learn and practice using this tool, you will save yourself a lot of time in the future. Rather than paging through books you can stay right at your keyboard to find the information you need. Index search is an addition to the help information that is provided for each system display. While help information is specific to a display or an area of a display, the index | search topics are specific to a task or a concept. For | example, index search is very helpful in finding out how to | perform a particular task. Typically, index search topics are: Brief, how-to-do-it summaries of a task or a category of work Expanded definitions of terms or concepts similar to those found in a glossary | To get to index search from any Help display, press F11 (Search index). The following Search Help Index display is the first display shown when you request index search:

<a id="FIGUNIQ76"></a>

```text
|                                Search Help Index|
|  Index Search allows you to tell the system to search for specific|
|  information.  To use Index Search, do the following:|
|    1.  Type the phrase or words to search for.|
|    2.  Press Enter.|
|  When you press Enter, the system searches for topics related to the|
|  words you supplied and displays a list of topics found.|
|  If you press Enter without typing anything, the system displays a list|
|  of all available topics.|
|  Type words to search for, press Enter.|
|    ____________________________________________________________________________|
|  F3=Exit help   F5=All topics   F12=Cancel   F13=User support|
```

Once you have the Search Help Index display on your screen, you can ask for information on anything that is giving you trouble. As you can see, the display provides you with brief instructions about the procedure. At the bottom of the display is an entry line where you type your search | request. The advantage of index search is that you can use your own words to ask for information. | Index search matches the word, words, or phrase in your request with synonym tables. When a match is found (within a matter of seconds), the system presents a list of topics from which you can choose to get specific information.
