## D.1 System Request Function

You can use the system request function to start an alternative interactive job (session) at your display station. Then you can use the System Request key to switch back and forth between the primary and alternative job. An alternative job can be particularly useful for doing another task or viewing information without having to end your work. The System Request menu provides easy access to the options available through the system request function.

| **Importan**t! | The interactive job you're in when you press the System Request key is | temporarily suspended (all work within that job stops) while you work | in the second interactive job session. Work in the first interactive | session does not begin again until the System Request key is pressed | again, which in turn causes the second interactive session to be | suspended. To use the system request function, do the following: 1. Press and hold the Shift or Alt key, and press the System Request (Sys [HDRKBDS](e-0.md) / Req or Sys Rq) key. (See Appendix E, "AS/400 Keyboards" if you're not sure which key to press.) An entry line appears at the bottom of the display. 2. Press the Enter key. The System Request menu is displayed and your first job is interrupted temporarily while you work with the second job. You can do the following from the System Request menu: Use option 1 to start a second interactive job or transfer to the other interactive job if you have already interrupted one. Use option 2 to end the previous request. Use option 3 to display information about your current interactive job. Use option 4 to display messages on the display station message queue, your message queue, or another user-specified queue. Use option 5 to send a message to another user or display station. Use option 6 to display messages sent to the system operator's message queue (QSYSOPR). | Use option 7 to display information about the current user. Use option 80 to temporarily sign off (you can return later). Use option 90 to sign off, or sign off and transfer to the other interactive job.
