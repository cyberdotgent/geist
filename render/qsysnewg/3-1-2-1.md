#### 3.1.2.1 Using the F Keys

The following keyboard descriptions will help you use the function keys on

some of the most popular keyboards; however, if you don't find your keyboard mentioned, you may have to refer to [Appendix E, "AS/400](e-0.md) [Keyboards."](e-0.md) Just match up the illustration in the appendix and the name of the keyboard with your keyboard.

**Personal** **Computer** **Keyboards** To use function keys 1 through 10 (F1-F10), press the function key that

corresponds to the number you want to use. To use function keys 11 through 20 (F11-F20): 1. Press and hold the Shift key. 2. Press the function key that corresponds to the number you want to use. For example, F1 is used as F11, F2 is used as F12, F10 is used as F20, and so on. To use function keys 21 through 24 (F21 through F24): 1. Press and hold the Alternative (Alt) key. 2. Press the function key that corresponds to the number you want to use. For example, F1 is used as F21, F2 is used as F22, F3 is used as F23, and F4 is used as F24.

Press the top row key that corresponds to the number of the desired key. For example, the F1 key is used as F13, the F2 key is used as F14, the F3 key is used as F15, and the F12 key is used as F24.

**5250** **Keyboard**

To use function keys 1 through 12: 1. Press and release the Command (Cmd) key. 2. Press the top row key that corresponds to the number of the desired function key. For example, the 1 key is used as function key 1, the 0 key is used as function key 10, the - (minus) key is used as function key 11, and the = (equal) key is used as function key 12. To use function keys 13 through 24: 1. Press and release the Command (Cmd) key. 2. Press and hold the Shift key. 3. Press the top row key that corresponds to the number of the desired function key. For example, the 1 key is used as function key 13, the 0 key is used as function key 22, the - (minus) key is used as function key 23, and the = (equal) key is used as function key 24.
