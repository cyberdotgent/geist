## 6.1 Extended Help Information for a Display

Extended help provides the following help information about displays: What the display does How to use the display Which function keys can be used, c.cp To get the extended help information, you do the following: 1. Put your cursor on: Any part of the display's title line | A blank menu option line A completely blank line on the display Any instruction A blank selection line 2. Then, press the Help key. Extended help information is displayed. If the extended help information is longer than one display, page up or page down to move through the information.
