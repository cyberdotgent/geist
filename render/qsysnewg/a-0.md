# A\.0 Appendix A\. Using Control Language Commands

<a id="HDRCL"></a>

As you work with the AS/400 system, you'll constantly be working with commands\. You command the computer through the use of F keys or the selection of options from a menu\. Depending upon your user profile, you may also have the ability to directly control the computer by typing control language commands\.

<a id="FIGFIGUNIQ89"></a>

![PICTURE 70](70.png)

For instance, instead of typing a number on a menu option line, you can type a command along with specific **parameters** that give the computer explicit instructions\. This method is often faster because it is more direct\.

An understanding of the language the computer recognizes, **control language** or **CL**, can help you use the AS/400 system more efficiently\. It is the language that you use to interact with the operating system\.

**Note:** To use control language, you must have access to either the F9 \(Command line\) key from an Operational Assistant display, or the command line provided on an intermediate assistance level display\. If you don't have access to either of these, then you haven't been given the authority necessary to use control language\.
