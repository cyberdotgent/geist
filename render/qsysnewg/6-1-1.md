### 6.1.1 Let's Get Help

| For this demonstration, go to the Documentation and Problem Handling menu.

| To get there from the Operational Assistant menu, select option **75** | (Documentation and problem handling).

<a id="FIGUNIQ63"></a>

```text
|  USERHELP              Documentation and Problem Handling|
|                                                              System:   RCH38360|
|  To select one of the following, type its number below and press Enter:|
|       1. How to use help|
|       2. AS/400 publications|
|       3. Display work station user|
|      10. Save information to help resolve a problem|
|      80. Temporary sign-off|
|  Type a menu option below|
|       __|
|  F1=Help   F3=Exit   F9=Command line    F12=Cancel|
|  (C) COPYRIGHT IBM CORP. 1980, 1991.|
```

| Extended help information can be used to help you find out what to do with | this menu. | To get extended help information about the Documentation and Problem | Handling menu, either leave the cursor on the menu option line or place it | on the title line, and then press the Help key.

After the option | information, the active function keys for the Documentation and Problem | Handling menu are explained.

The User Support and Education menu provides many different options for | using the system, solving problems, and learning about the system. In particular, notice option **1** (How to use help). You can use this option as a refresher after you finish this chapter. | You can also get to the How to Use Help display by pressing the F1 (Help) | key while currently on any Help display.
