### E.6.1 Using the Special-Character Keyboard Set Function

To use the special-character keyboard set function, press and hold the Alt            key while you press the Shift key and then release both keys.  This action         makes available the special-character keyboard set function and changes ???????????????????????????????????????????????????????????????    the function of some of the keys on your keyboard.    You can type only one special character when you activate the            special-character keyboard set function.  After you have typed one special       character, return to the previous functions of your keyboard, and activate          the special-character keyboard set function again to type another special ?    character.

**Note:** When you are in the special-character keyboard set function and an error code appears when you press a key that is not active, reset the error condition and continue with the function.
