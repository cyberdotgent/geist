## F\.1 Function Key Differences

The AS/400 function keys are assigned to do different tasks on the operating system on the AS/400 system, the System/36, and the System/38\. If you are using an application program on any of these systems, the function key differences listed below may or may not be correct\.

<a id="FIGTBLUNIQ103"></a>
