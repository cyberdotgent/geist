## F\.3 System Request Menu Differences

<a id="HDRSYSRDIF"></a>

When you press the Shift or Alt key and the system request \(Sys Req or Sys Rq\) key and then press the Enter key on the AS/400 system or the System/38, the System Request menu is shown\. To do many of the same functions on System/36, press the Attn key to display the Inquiry Options menu\. These differences are shown in the table below\.
