### A\.1\.1 Parameters

We'll look at some AS/400 commands to see how the action and object are combined\. Each command starts a program in the system that performs the functions indicated by the command\. The program performs a general function\. For example, CRTLIB creates a library\. However, you don't want to create just any library; you want to be more specific about the library by including additional information with the command name\. That is done with **parameters**\. In addition to the command name, every CL command also contains zero, one, or several parameters\.

The format for a CL command is:

`command parameter parameter parameter`

For example, one of the parameters in a CRTLIB command must contain the name of the library to be created\. The system needs to know which parameter contains that information\. The method used to describe each parameter to the system is to specify its parameter **keyword** and its parameter **value**\.
