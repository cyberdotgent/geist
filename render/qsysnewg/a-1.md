## A.1 CL Structure

parts: Command name Parameters The commands are abbreviations. To make these abbreviations easier to understand, they have been standardized so a user can tell what major function (action) each command performs and what item (object) the function is performed on. Here are some examples of the **action** portion of commands: **Function** **(verb)** **Command** **(prefix)** **Create** CRT... **Display** DSP... **Change** CHG... **Work** **with** WRK... **Start** STR... A CL command name also identifies the **object** you are working on. The object part of the name (suffix) is also abbreviated and easy to recognize. For example: **Action/Object** **Command** **Display** **Library** DSPLIB **Create** **Physical** **File** CRTPF **Add** **Job** **Queue** **Entry** ADDJOBQE **Work** **with** **Message** **Queue** WRKMSGQ
