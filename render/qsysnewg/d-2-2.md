### D.2.2 Verifying the Keyboard State for the Type-Ahead Function

You can verify the state of the keyboard by: 1. Entering the hexadecimal environment by pressing and holding the Alt key while you press the Hex key. If you do not have a key labeled Hex, press and release the command (Cmd) key and then press the key to the left of the 1 key on the top row of keys on the keyboard. 2. Pressing the M key.

If **1111** is displayed on the error line, the type-ahead function is active. If **9999** is displayed on the error line, the type-ahead function is not active.

**Note:** The message may be different if you are using a personal computer. Press the Error Reset key to remove any flashing numbers on the message line of the display and to resume normal operation (the keyboard is locked until it is reset).
