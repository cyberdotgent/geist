## 5.3 List Displays

A list display is simply a list of **objects**. To the computer, an object can be a job, file, library, or several other things. Information requested by you is gathered from within the system and displayed in columns. The Work with Jobs display is an example of a list display. Let's go take a look at this display now. From the AS/400 Operational Assistant menu,

select **2**, for the Work with jobs option. Press the Enter key and, as you might have guessed, the Work with Jobs display appears.

The information is arranged in columns, each with a short title. At the left of each item is an input field where an option number may be typed. This input field column is identified as Opt or Option. The options available are shown in the upper part of the display. These options vary | depending on the purpose of the display and your user authority. Use your Field Advance and Field Backspace keys (or cursor movement keys) to move up and down the column. You then type the option number on the blank input line. More.**..** A list may contain more items than can be displayed on a single list display. In that case, Mo**re... a**ppears in the lower right corner of all but the last list display. The word Bo**ttom a**ppears in the lower right corner of the last list display. The Page Up and Page Down keys are used to move from one display to another. Always check for the Mo**re... o**n your screen to make sure you're not missing anything. List displays are usually shown in response to a request for system information. They are sometimes called **Work** **with** displays because you can do several types of work with the items on the list by typing one or more option numbers. The list items that you type option numbers in front of are processed by the system in top-to-bottom order.

Occasionally, you might run across an **Extended** **list** display. The information on this type of list display does not fit within the width of the screen. Don't worry! There may be a function key available (usually F11) that lets you shift the text to the right or left on the screen, allowing you to read all of the information available.
