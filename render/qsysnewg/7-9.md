## 7.9 Message Summary

**Informational** **messages** don't need a reply.

| **Inquiry** **messages** need a reply.

Both informational and inquiry messages are found in your **message**

**queue**, which can be viewed from the Work with Messages display. Messages can come from three sources: - The system - Application programs - Other users Messages can be displayed in three ways: - Message line - Break message display - Work with Messages display

You send messages from the **Send** **a** **Message** display.

**Break** **messages** (interrupt user messages) should be sent only when necessary.
