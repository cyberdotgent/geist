### F\.1\.3 Function Key Differences on System Menus

<a id="HDRMENUDIF"></a>

Some displays allow you to select tasks from a list of menu items\. On system menus, the following functions are available\.

<a id="FIGTBLUNIQ106"></a>

<a id="TBLTBLUNIQ106"></a>

```
    ________________________________________________________________________
   | Figure  F-4. Function Key Differences on System Menus                  |
   |____________ ____________ ____________ ____________ ____________________|
   | Name of    |            |            |            |                    |
   | Function   |            |            |            |                    |
   | for        | AS/400     | System/36  | System/38  |                    |
   | System     | Function   | Function   | Function   | Function           |
   | Menus      | Key        | Key        | Key        | Description        |
   |____________|____________|____________|____________|____________________|
   | User       | F13        | Not        | Not        | Displays the User  |
   | Support    |            | supported  | supported  | Support menu       |
   | menu       |            |            |            |                    |
   |____________|____________|____________|____________|____________________|
   | System     | F16        | Cmd5       | Not        | Displays the       |
   | main menu  |            |            | supported  | AS/400 Main Menu   |
   |____________|____________|____________|____________|____________________|
   | Set        | F23        | Cmd23 for  | Not        | Sets the current   |
   | initial    |            | user menu  | supported  | menu as the first  |
   | menu       |            | and Cmd24  |            | menu you see when  |
   |            |            | for system |            | you sign on the    |
   |            |            | menus      |            | system             |
   |____________|____________|____________|____________|____________________|
   | Go to      | Home       | Home       | Not        | Displays the first |
   | initial    |            |            | supported  | menu you see when  |
   | menu       |            |            |            | you sign on the    |
   |            |            |            |            | system             |
   |____________|____________|____________|____________|____________________|
```

**Note:** If you are using an application program on any of these systems, the common function keys described here and their descriptions on system menus may or may not be the same\.
