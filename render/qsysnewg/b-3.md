## B\.3 Commonly Used Menu IDs

<a id="HDRGOC"></a>

<pre>
shb.3
ST| Commonly Used Menu IDs
 | The following is a partial list of menu IDs that represent various AS/400
 | system menus.  Using the advanced menu planning techniques, you can go
 | directly to one of the following menus.
 |
 | AS/400 Operational Assistant Menus
 | Menu           Description
 | ASSIST         AS/400 Operational Assistant
 | BACKUP         Backup Tasks
 | CLEANUP        Cleanup Tasks
 | DEVICESTS      Device Status
 | MANAGESYS      Manage Your System, Users, and Devices
 | POWER          Power On and Off Tasks
 | SETUP          Set Up Your System
 | TECHHELP       Technical Support Menu
 | USERHELP       Documentation and Problem Handling
 |
 | Other Commonly Used AS/400 System Menus
   Menu           Description
   DATA           Files, Libraries, and Folders
   DEFINE         Define or Change the System
   DEVICE         Device Operations (printer, tape, and diskette)
   DISKETTE       Diskette
   DOCUMENT       Documents
   FILE           Files (IDDU, SQL, Query)
   FILE2          Files (DDM, System/36)
   FOLDER         Folders
   JOB            Jobs
   LIBRARY        Libraries
   MAIN           AS/400 Main Menu
   MAJOR          Major Command Groups
   MESSAGE        Messages
   OFCTSK         Office Tasks
   PCSTSK         Configure AS/400 for PC Support (PC Support tasks)
   PRINTER        Printer
   SUPPORT        User Support and Education
   SYSTEM         General System Tasks
   USER           User Tasks
   USER2          User Tasks (remote jobs, Q and A, System/36 environment)
</pre>
