## 2.5 Accessing Operational Assistant

To perform the basic AS/400 tasks presented in this guide, it is necessary | to start from the AS/400 Operational Assistant menu.

<a id="FIGUNIQ18"></a>

```text
    __________________________________________________________________________________ 
   |                                                                                  |
 | |  ASSIST                   AS/400 Operational Assistant                           |
   |_____________________________________________________________|
 | |                                                              System:   RCH38360  |
 | |  To select one of the following, type its number below and press Enter:          |
   |                                                                                  |
   |_____________________________________________________________|
 | |       1. Work with printer output                                                |
   |__________________|
 | |       2. Work with jobs                                                          |
   |__________________|
 | |       3. Work with messages                                                      |
   |__________________|
 | |       4. Send messages                                                           |
   |_____________________________________________________________|
 | |       5. Change your password                                                    |
   |                                                                                  |
 | |      75. Documentation and problem handling                                      |
   |                                                                                  |
 | |      80. Temporary sign-off                                                      |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |_____________________________________________________________|
 | |  Type a menu option below                                                        |
 | |       __                                                                         |
   |                                                                                  |
 | |  F1=Help   F3=Exit   F9=Command line   F12=Cancel                                |
 | |  (C) COPYRIGHT IBM CORP. 1980, 1991.                                             |
   |                                                                                  |
   |__________________________________________________________________________________|
```

How you arrive at this display depends on how your system has been set up. | It may be your initial menu after you've signed on the system. However, | if it isn't the initial menu, you should be able to access it in one of | the following ways: | By pressing the Attention (Attn) key. | By selecting an option from your application menu(s).

By typing `go` `assist` on a command line.
