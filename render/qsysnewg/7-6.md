## 7\.6 Sending Messages

<a id="FIGFIGUNIQ81"></a>

![PICTURE 62](62.png)

The display you use to send messages to other people is appropriately named the Send a Message display\. Let's take a look at the Send a Message display\. To get there from the AS/400 Operational Assistant menu, select option **4** \(Send a message\)\.

```
    __________________________________________________________________________________
   |                                                                                  |
 | |                                  Send a Message                                  |
   |                                                                                  |
 | |  Type information below, then press F10 to send.                                 |
   |                                                                                  |
 | |    Message needs reply  . . . . . .   N            Y=Yes, N=No                   |
   |                                                                                  |
 | |    Interrupt user . . . . . . . . .   N            Y=Yes, N=No                   |
   |                                                                                  |
 | |    Message text . . . . . . . . . .   _________________________________________  |
 | | _______________________________________________________________________________  |
 | | _______________________________________________________________________________  |
 | | _______________________________________________________________________________  |
 | | _______________________________________________________________________________  |
 | | _______________________________________________________________________________  |
 | | ____________________________________________________                             |
   |                                                                                  |
 | |    Send to  . . . . . . .             __________   Name, F4 for list             |
 | |                                       __________                                 |
 | |                                       __________                                 |
 | |                                       __________                                 |
 | |                                       __________                                 |
   |                                                                                  |
 | |  F1=Help   F3=Exit   F10=Send   F12=Cancel                                       |
   |                                                                                  |
   |                                                                                  |
   |__________________________________________________________________________________|
```

*Message needs reply*: Use this field to specify whether you are sending a message that you want someone to reply to\.

Choose **N** to send a message that does not need a reply \(informational message\)\. Choose **Y** to send a message that needs a reply \(inquiry message\)\.

*Interrupt user*: Use this field to specify whether you want to send a break message, which temporarily interrupts the task being performed by the person you are sending the message to\.

Choose **N** if you don't want to interrupt the person receiving the message; the message is then sent directly to their message queue\. Choose **Y** if you want the message to interrupt the person who is receiving it\.

**Note:** Use break messages with care\. You should send this type of message only when it requires the immediate attention of a display station user, because it interrupts the user's activity and can result in lost keystrokes\.

*Message text*: You can enter the text of your message \(up to 494 characters\) on the lines of this field\. You don't need to press a Return key at the end of a line, just continue typing and let that text wrap down onto the next line\. Don't be concerned that some of the words may appear to be split between lines; when the message is sent, the system automatically moves any words that do not fit completely on a given line to the next line\.

*Send to*: You can enter the user names of the people you want to send your message to on the lines of this field \(one name per line\)\. You can enter the user names of individuals or, if you have the proper authority, you can enter a value that represents entire groups of people\. Here are a couple of examples of user names that represent groups of people:

**\*ALL** Represents all users enrolled on the system

**\*ALLACT** Represents all users that are currently signed on to the system

If you forget someone's user name, all you have to do is place the cursor on one of the lines of this field and press the F4 \(List\) key\. A list of all user names that are recognized by the system appears\.

*Function Keys*: In addition to the F4 \(List\) key, there are two other keys that you use frequently when sending messages: the F10 \(Send\) key and the F12 \(Cancel\) key\.

You press the F10 key to send a message after you have filled in all fields on the Send a Message display\.

You can press the F12 key to cancel a message that you have decided not to send\.
