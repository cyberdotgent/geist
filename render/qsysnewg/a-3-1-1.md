**Note:** The preceding discussion led you through the steps for getting information about individual command parameters. You can get help for the entire command by placing your cursor up on the title line or down in the blank area of the display and pressing the Help key. The advantage of letting the computer help you enter commands by using a prompt display is that you do not need to remember the parameters of a command because all: Parameters are displayed for the requested command. (Required parameter lines are highlighted.) Optional parameters are filled in with default values when a value is needed. You should use the prompt method when you are:

Not familiar with the AS/400 commands Working with infrequently used CL commands A Prompting Aid: The system allows you to temporarily customize your prompt display to remind you what the actual keywords are. To use this aid, you'll have to remember that **F11** is the Keywords key; it's not listed at the bottom of your display. (Or, you can press F24 to list more keys.) By pressing F11, you can display the keywords used for the parameters. The parameter entry field moves to the right and the keywords are shown in the middle column. (The possible choices for the parameter values aren't shown when the keywords are shown.)
