### A.3.2 Using the Free Format Method

the commands and their parameters. If you want to enter a command you are familiar with, using the prompt method takes a little more time because: Extra displays are shown. Response time is needed for each display. Therefore, the system offers another method: **free** **format**. That is, the command and its parameters are entered on a command line as a string of characters.

**Command** **Tips**

| Don't forget that you can find a list of command names by pressing | F4 on any blank command line as discussed earlier. Also, don't forget about Index Search Information. And finally...you can find out what a command means by typing it on a command line and pressing the Help key. Oops, one more thing: The F13 key (How to use this display) gives you a lot more information about using a prompt display. Use it for advanced work. As you have seen from earlier examples, there is a correct form: Space between parameters Parentheses around values These commands with all their parameters can look kind of complicated. For example, the Create Library command, which you learned about in the last section, looks like this if you use all of the possible parameters.

computer | CRTLIB LIB(MYLIB) TYPE(*PROD) AUT(*LIBCRTAUT) CRTAUT(*SYSVAL) ASP(1) TEXT(*BLANK) Impressive You needn't feel intimidated by this long string. You already know about each of its parts. Let's take it apart.

CRTLIB is the Create Library command itself. | There? are six parameters: LIB Library TYPE Type: production or test TEXT Text description AUT Authority | **A**SP Auxiliary storage pool ID | **CRTA**UT Create authority | Five of the six have default values. One (LIB) needs you to fill in a name. Now for some good news... | You don't have to type the parameters with default values. The computer | automatically selects its own choices, so unless you need to pick others, | you just type the required values. Life is truly great sometimes. | This is how the command would look on the AS/400 Main Menu command line if | you chose to enter only the required Library (LIB) parameter. (You really don't even have to enter the LIB keyword; just CRTLIB MYLIB would do it.) The command would be processed if you pressed the Enter key.
