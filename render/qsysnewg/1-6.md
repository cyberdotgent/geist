## 1\.6 The Processor

The processor is the electronic circuitry that processes the data\. These are examples of processor functions:

- Move data from one area of storage to another
- Compare two names and indicate which one is first in alphabetical order
- Perform arithmetic functions \(addition, subtraction, multiplication, division\)
- Edit text \(as a word processor\)

It's the processor that reads each instruction of the program and acts on it\. The instructions must be in main storage\. It's also the processor that decides which instruction to perform next\.

The processor consists of one or more computer chips\. Because computer chips operate at electronic speeds, one processor can keep up with many input, output, and storage devices\.
