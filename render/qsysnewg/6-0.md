# 6\.0 Chapter 6\. Using Online Information

<a id="HDRHELP"></a>

You've used the Help key a couple of times already, especially while working with the prompt help displays\. In this chapter we'll review that information and show you some other ways you can use the computer to help you use the computer\. Does that make sense

<a id="FIGFIGUNIQ62"></a>

![PICTURE 56](56.png)

The Help key is your link to the help information on the AS/400 system\.

There are three kinds of **online help** available to you:

- Extended help information for a display
- Help information for a field
- Index search information
