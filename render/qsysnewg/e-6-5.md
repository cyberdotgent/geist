### E.6.5 Special Characters Shown Differently for Some Display Stations

Four characters are shown differently if you have a 5251, 5291, 5292, 3180 Model 2, 3179 Model 2, 3196, or 3197 display station. The following table lists the four characters that are shown differently on these display stations.

<a id="TBLUNIQ102"></a>

<a id="TBLTBLUNIQ102"></a>

.

| Template | Station |
| --- | --- |
| Multiplication sign | Double underline |
| Copyright symbol | Florin symbol |
| Superscript 1 | Dotless i |


Some of the characters available in the special-character keyboard set may not be available in the code set for the personal computer you are using. If your display station is an IBM Personal Computer and you are using the PC Support work station function, you must request the special-character keyboard set function when running the configuration program CFGWSF.EXE.
