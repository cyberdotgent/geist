## 2\.7 Signing Off the Computer

Even though you have just gotten on the computer, you will now learn how to get yourself signed off\. Don't worry about signing on and off repeatedly; the computer doesn't mind\.

You can sign off your AS/400 session in one of the following ways:

- Using the sign off option from an application display
- Using option 80 \(Temporary sign off\) from the AS/400 Operational Assistant menu
- Using option 90 \(Sign off\) from the AS/400 Main Menu

When signing off from an application display or the AS/400 Main Menu, simply select the appropriate option and press the Enter key\.
