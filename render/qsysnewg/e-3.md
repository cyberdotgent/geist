### E\.3 Using the 5250 Keyboard

Shown below is the 5250 keyboard\.

<a id="FIGRV2C165"></a>

![PICTURE 79](79.png)

*Figure E\-3\. Using a 5250 Keyboard\.*

To use function keys 1 through 12:

1\. Press and release the Command \(Cmd\) key\.

2\. Press the top row key that corresponds to the number of the desired function key\. For example, the 1 key is used as function key 1, the 0 key is used as function key 10, the \- \(minus\) key is used as function key 11, and the = \(equal\) key is used as function key 12\.

To use function keys 13 through 24: 1\. Press and release the Command \(Cmd\) key\.

2\. Press and hold the Shift key\.

3\. Press the top row key that corresponds to the number of the desired function key\. For example, the 1 key is used as function key 13, the 0 key is used as function key 22, the \- \(minus\) key is used as function key 23, and the = \(equal\) key is used as function key 24\.
