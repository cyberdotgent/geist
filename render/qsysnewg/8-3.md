## 8\.3 Controlling Jobs

Generally, all users can control their jobs from the Work with Jobs display\. However, the system security officer can restrict the degree of authority allowed each user\. In other words, your system security officer controls your level of control\. For now, let's assume that you have the authority to control \(hold, release, or delete\) your batch jobs\.

To get to the Work with Jobs display from the AS/400 Operational Assistant menu, select option 2 \(Work with jobs\) and press the Enter key\.

```
 | |    3=Hold   4=Delete (End)   6=Release   7=Display message                       |
```

This display gives information about whether your jobs are waiting in the job queue, running, or finished running and simply waiting to have output printed\. If there are more jobs than a single display can show, you can page up or page down to view the rest of them\. The word **Bottom** appears in the lower right corner of this display when there are no more jobs to be displayed\.

Occasionally, you'll see a comment in parentheses following the status information for a job\. Some of these comments inform you of the particular option or function key you would normally use to change the current status of the job\. They are only suggestions; you can use other options or function keys if you choose\.

If you've been given the proper authority, you can view other jobs on the system\. Just press F14 \(Select other jobs\) and the Select Other Jobs window appears\. From this window, you determine which jobs you want to see by specifying any of the following criteria and pressing the Enter key:

- User name
- Job status

Another easy way to see the jobs of other users \(again, depending on whether you've been given the proper authority\) is to place your cursor on the user name field, and press the F4 key\. A list of user names appears that you can select from\. When you make your selection, the Work with Jobs display changes to show the new user name in the user field, along with the jobs belonging to that user\.

This display shows the status of each job\. The options available for working with your jobs appear near the top of your display:

**Option Description**

**3=Hold** This allows you to temporarily stop a job from running\. You might want to do this to delay a job from running so that a more important job can run and print sooner\. Once you hold a job, you must release it before it can run\.

**4=Delete \(End\)** This allows you to remove a job from the system\. For example, if you've prepared a report with the wrong input data, you can use option 4 to prevent it from running\. This option simply removes the job from the job queue, it does not delete any data from the file you've submitted\. This option also causes any job that is currently running to end\.

**6=Release** This allows you to release a job that has been held \(temporarily stopped\)\.

**7=Display message** This allows you to display and respond to messages concerning a job that was submitted\.

**8=Work with printer output** This allows you to work with the printer output that has been created by a job\. You could then use this information to determine the status of your job \(how much remains to be printed\)\. The Work with Job Printer Output display that appears when this option is selected is the same as the Work with Printer Output display that you will use to work with your printer output, except that it is specific to a single batch job\.

To perform one of these options, simply type its number in the ***Opt*** column to the left of the selected job and press the Enter key\.

Let's say you're ready to submit your job, **TNYREPRT**, to be run, when your manager hints that her job, BIGREPRT, should be run right away\. You can make her very happy by holding TNYREPRT from running\. To do this, simply type **3** in the ***Opt*** column in front of TNYREPRT and press the Enter key\. The **Waiting to run** \(ready\) status changes to **\*Held \(use F5\)** for the job TNYREPRT\.

Perhaps you've held, and now want to release, the job **INVENTRY**\. Just type **6** in front of INVENTRY, press the Enter key, and the status goes to **\*Released \(use F5\)**\.

If you no longer want the job **PARTLIST** to be run, type **4** in front of it and press the Enter key\. When you choose to delete \(End\) a job, the Confirm Delete \(End\) of Jobs display appears, which gives you a chance to change your mind\.

```

 | |                           Confirm Delete (End) of Jobs                           |

 | |  To confirm your choices for 4=Delete (End), press Enter.                        |
 | |  To return to change your choices, press F12.                                    |
   |                                                                                  |
 | |       Job Queue/                                                                 |
 | |  Opt    Job         Status                                                       |
 | |   4     PARTLIST    Waiting to run                                               |
   |                                                                                  |

   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |

 | |  F1=Help   F11=Display dates/times   F12=Cancel                                  |
   |                                                                                  |
   |                                                                                  |
   |__________________________________________________________________________________|
```

You can either press the Enter key to confirm that you want to delete \(end\) the PARTLIST job, or press F12 to return to the Work with Jobs display without ending the job\. Generally, if you delete a job, it is removed from the system and no longer appears on the display\. However, if your job has printer output that is waiting to print, it does not disappear from the Work with Jobs display until either its output has been printed, or you've used option 8 to delete its printer output\.

Now, press F5 to refresh the display so you can view the updated statuses for all remaining jobs\.
