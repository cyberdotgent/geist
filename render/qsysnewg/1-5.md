## 1.5 Storage Devices

Once data has been turned into electronic signals by an input device, it | has to be stored someplace. This is done by a storage device. The four

| most commonly used types are: Main storage Magnetic disk Diskettes Magnetic tape One valued characteristic of storage devices is speed. Some storage devices are much faster than others. This greatly affects the speed with which programs run. If data is stored on a fast device, then programs that use that data complete their tasks more quickly.
