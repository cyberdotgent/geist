## 8.1.1 Job Name

has three parts:

Job Number: A six-digit number assigned by the system. This number helps to differentiate between two or more jobs that have been submitted by the same user and given the same user-defined name.

User Name: This identifies the user who submitted the job. The computer automatically determines this for you.

. User-Defined Job Name: The unique user-defined name of the job. (Frieda

used **SALSREPT** for her sales report batch job.) This name may be defined ahead of time for you by a programmer. When displaying your job queues using the basic assistance level, two or more jobs having the same user-defined name will appear to be identical.
