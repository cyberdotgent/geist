### E.6.3 Normal Keys That Can Be Used and Cause You to Exit the Function

The following keys cause you to exit from the special-character keyboard             set function, and no special-character keyboard set function takes place.

**Note:** You may not have some of the following keys on your keyboard. Attention Immediate Reset Clear Local Select Mode Cmd PageDown End PageUp Enter PC print Erase End of Line PFn (Any PF key) Erase Input Record Backspace Help Roll Down Home Roll Up HostPrint Sysreq Hex TestReq Also, pressing and holding the Alt key and pressing the Shift key causes you to exit from the special-character keyboard set function.
