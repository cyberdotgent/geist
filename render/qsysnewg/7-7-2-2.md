#### 7\.7\.2\.2 Messages from the Computer

The system sometimes sends you error messages that require you to choose a response option code\. Based on the option codes given \(always in parentheses\), this is generally a one\-character response\.

For example, notice the five response option codes for this message:

`Verify alignment on device PRT01. (I C G N R)`

Messages of this kind with response option codes most often appear on the system operator message queue\. However, under certain circumstances, they can also appear on your own message queue\.

Let's say you have finished a report and want to print it\. You go through the steps to send it to the printer, but it doesn't print\. You check your message queue and find the following message:

```
    __________________________________________________________________________________
   |                                                                                  |
 | |                                Work with Messages                                |
 | |                                                              System:   RCH38360  |
 | |  Messages for:   NORBERT                                                         |
   |                                                                                  |
 | |  Type options below, then press Enter.                                           |
 | |    4=Remove   5=Display details and reply                                        |
   |                                                                                  |
 | |  Opt   Message                                                                   |
 | |                             Messages needing a reply                             |
 | |   _    End of forms on printer PRT01. (C H I PAGE 1-99999)                       |
   |                                                                                  |
 | |                           Messages not needing a reply                           |
 | |        (No messages available)                                                   |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
 | |                                                                          Bottom  |
 | |  F1=Help   F3=Exit   F5=Refresh   F6=Display system operator messages            |
 | |  F16=Remove messages not needing a reply   F17=Top   F24=More keys               |
   |                                                                                  |
   |                                                                                  |
   |__________________________________________________________________________________|
```

The computer wants you to reply, using one of the four options shown **\(C H I PAGE 1\-99999\)**\. You aren't expected to know or remember the meanings of the numbers or letters in any response option code\. The Additional Message Information display provides information about these option codes\. In addition, this display also provides a reply line on which you can type your reply \(if a reply is needed\)\.

To get to the Additional Message Information display from the Work with Messages display, position the cursor on the option line in front of the message you want to respond to, and select option **5** \(Display details and reply\)\. When the Display Details and Reply display appears, page down through the information to find the option you need\.

```
    __________________________________________________________________________________
   |                                                                                  |
 | |                          Additional Message Information                          |
 | |  Message ID  . . . . . . :   CPA5335          Severity . . . . . . :   99        |
 | |  Message type  . . . . . :   INQUIRY                                             |
 | |  Job . . :   REPRT01        User . . :   NORBERT        Number . . :   027799    |
 | |  Date sent . . . . . . . :   11/27/90         Time sent  . . . . . :   08:31:42  |
 | |  From program  . . . . . :   QWPXPRMA         Instruction  . . . . :   0000      |
   |                                                                                  |
 | |    H -- To hold the file,                                                        |
 | |      1. Press Stop only if Start and Stop are two separate keys.                 |
 | |      2. Load the new forms.                                                      |
 | |      3. Press Cancel.                                                            |
 | |      4. Press Stop and Start, or press Start/Stop.                               |
 | |      5. Type an H.                                                               |
 | |    I -- To continue printing starting with the next line of the file,            |
 | |      1. Press Stop only if Start and Stop are two separate keys.                 |
 | |      2. Load the new forms.                                                      |
 | |      3. Press Start or Start/Stop.                                               |
 | |      4. Type an I.                                                               |
 | |                                                                         More...  |
 | |  Type reply, press Enter.                                                        |
 | |    Reply . . .   ____________________________________________________________    |
   |                                                                                  |
 | |  F3=Exit           F12=Cancel                                                    |
   |                                                                                  |
   |                                                                                  |
   |__________________________________________________________________________________|
```

In this situation, option I looks like it is just what you need to get the printer going again\. So, you would follow the instructions listed under option I, and then send a response to this inquiry message by typing an **I** on the *Reply* field, and pressing the Enter key\. You're back in business\!
