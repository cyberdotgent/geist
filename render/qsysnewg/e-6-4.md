### E.6.4 Special Character Positions for Different Keyboards

```text
   There are slight differences in the character positions of the
   special-character keyboard set between the United States and other
   keyboards.  Both keyboard versions are contained in the Special-Character
   Keyboard Set template package, SX21-9950.  The action needed to use the
   special characters is the same for both keyboard versions:  press and hold
   the Alt key while you press the Shift key and then release both keys.
```
