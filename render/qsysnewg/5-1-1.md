### 5\.1\.1 Back to Operational Assistant

Let's take another quick look at the AS/400 Operational Assistant display and identify its six main parts:

<a id="FIGFIGUNIQ52"></a>

```
    __________________________________________________________________________________ 
   |                                                                                  |
 | |  ASSIST 2            1AS/400 Operational Assistant                               |
 | |                                                              System:   RCH38360  |
 | |  To select one of the following, type its number below and press Enter:          |
   |                                                                                  |
 | |   3 1. Work with printer output                                                  |
 | |       2. Work with jobs                                                          |
 | |       3. Work with messages                                                      |
 | |       4. Send messages                                                           |
 | |       5. Change your password                                                    |
   |                                                                                  |
 | |      75. Documentation and problem handling                                      |
   |                                                                                  |
 | |      80. Temporary sign-off                                                      |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
 | |  Type a menu option below                                                        |
 | |   4 __                                                                           |
   |                                                                                  |
 | |  F1=Help   F3=Exit   F9=Command line   F12=Cancel 5                              |
 | |  (C) COPYRIGHT IBM CORP. 1980, 1991. 6                                           |
   |                                                                                  |
   |__________________________________________________________________________________|
```

**1** The **title** is in the middle of the top line\.

**2** The **menu ID** is in the upper left corner\. Menus are the only type of display that have IDs\.

**3** The **list of options** includes the number and option description\.

**Note:** If your menus have missing option numbers, don't panic; nothing is wrong\. Your administrator may have eliminated some options to simplify your job\.

**4** The **input area** is the menu option line near the bottom of the display, just below the statement

`Type a menu option below`

**5** Below the menu option line is a list of **function keys** that apply to the current display\. Such function keys are referred to as the **active function keys** for the display\. Remember that the active function keys will differ from display to display\. If there are more active function keys than can be shown on a single display, F24 \(More keys\) will display these additional keys\.

**6** The **message line** is located below the list of active function keys\. Normally, the message line either displays copyright information or is completely blank\. If the computer needs to communicate with you, a message appears here\.
