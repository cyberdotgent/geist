## 6\.4 Online Information Summary

- **Extended help information** is general help for displays, that can tell you:

What the display does How to use the display What each function key does

- Help information for a field explains a specific input or output field\.
- **Hypertext Information** is a network of information displays that are linked by key words or phrases called reference phrases\. When a reference phrase is selected, a display providing more specific information about that word or phrase appears\.
- **Index search information** allows you to find information about specific tasks or concepts\. Typically, index search topics are:

Brief, how\-to\-do\-it summaries of a task or a category of work Expanded definitions of terms or concepts similar to those found in a glossary
