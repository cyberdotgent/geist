### 2.2.2 Let's Intentionally Make a Mistake

```text
   First, type some extra letters after your user name.  Then move the cursor
   back to the beginning of the line with the Backspace key.  Erase a few
   | letters of your user name with the spacebar.  Now type your user name
   | again and, finally, erase any extra letters with the spacebar.

   | Check to make sure your user name is spelled correctly.  You don't have to
   | worry about uppercase or lowercase letters; the computer accepts either in
   | any combination.  If you need to make changes or just want to practice, go
   right ahead.  Use the Backspace key to move the cursor to the left and the
   spacebar to erase.
```
