## E\.6 Using the Special\-Character Keyboard Set

<a id="HDRSPECKYB"></a>

You can use accents and special characters with the following keyboards when you use the special\-character keyboard set function:

IBM enhanced Personal Computer\-1 \(PC\-1\) Personal Computer AT \(PC AT\)

These accents and special characters are shown on a special template for your keyboard\. Your template is contained in the Special\-Character Keyboard Set template package, SX21\-9950\.
