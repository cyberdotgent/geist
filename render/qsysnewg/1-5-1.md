### 1.5.1 Main Storage

<a id="FIGUNIQ5"></a>

![Resource 5](resource:5)

PICTURE 5.

Main storage is the fastest type of storage in a computer system. It is normally in the form of an electronic When the computer is switched off, the contents of main storage are lost. You cannot permanently store any data in main storage. The processor can perform only program instructions which are in main storage. Before a program instruction can be performed, it has to be copied into main storage from another device.
