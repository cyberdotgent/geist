# 8.0 Chapter 8.  Managing Your Work

<a id="HDROPUT"></a>

<a id="FIGUNIQ84"></a>

![Resource 65](65.png)

PICTURE 65.

One of the most versatile aspects of the AS/400 system is its ability to | help you to manage your work. Many people can use the computer at the same time, and the computer can use many printers at the same time. | Combinations of these variables could potentially result in confusion. The AS/400 system is designed to prevent this from happening. | All systems use different methods to manage their work. They use | different terms to describe their various functions. The AS/400 system is | no exception. You need to know how the system manages its work, and the | terminology used for its functions, in order to make better use of the | system. | How the system manages work varies according to how much it relies on you | to get the work done. For this reason, the work that the system does is one of two types: | Interactive processing | Batch processing | **Interactive** **processing** requires continual two-way communication between a | display station user and the system. Throughout the duration of the task | being performed, the computer occasionally requires information from you. | An example of interactive processing is your current AS/400 session. This | session began when you signed on the system; the system requested sign-on | information, you replied by providing the necessary information, and the | computer responded by displaying a menu of options for you to choose from. | This pattern of system request, user reply, and system response is | repeated until you end the interactive session by signing off the system. | In contrast, **batch** **processing** requires only that you send the information | for processing. After processing is initiated, the system needs no | further information from the user to complete the task, leaving both the | user and the display station free to do other things.
