#### A.1.1.3 Required and Optional Parameters

Such parameters are called **required** parameters. They are highlighted and are always listed first in the command. Other parameters, called **optional** **parameters**, don't require you to specify a value; the system can use a default value instead. Optional parameters, like required parameters, can have a list of possible choices; these choices can be system-defined values and/or user-defined values. One of the system-defined values may be the default value. The default value, if any, is always shown first. The system uses the default value unless the user specifies a different value.
