## B.1 Using Go Commands

<a id="FIGUNIQ99"></a>

![Resource 74](74.png)

| PICTURE 74.

| The first method of getting to a specific menu quickly uses the **GO** | command. On any command line you can type **go** followed by a menu name. | You probably can't remember the name of a menu right now, so why don't you | use our old favorite-- Documentation and Problem Handling menu. | But... | There is one catch to this procedure: You can't type the real menu title; | you have to type the **menu** **ID**. The menu ID for the Documentation and | Problem Handling menu is **USERHELP**. Type **userhelp** after the word go | (leaving a blank space between). Press the Enter key to go directly to | the Documentation and Problem Handling menu. | This is a good method to use if you want to get to your task quickly, | avoiding unnecessary menus. You'll be taken directly to the menu you | want. | Come on, let's try it! On the command line of the Documentation and | Problem Handling menu, type **go** **assist**. The next thing you should see is | the AS/400 Operational Assistant Menu. Neat! | **Another** **Neat** **Thing!** | If you can't remember the exact menu name, type **go**, the first letter | of the menu you want, and an asterisk. For example, if you type **go** | **m***, you get a list of menus that start with **M**. | **Note:** If GO commands don't work for you, see your system administrator. | Your user profile or the system's security level might limit your | ability to use the command line.
