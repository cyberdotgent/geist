## 5.1 Menu Displays

<a id="FIGUNIQ51"></a>

![Resource 50](50.png)

PICTURE 50.

The purpose of a menu is to provide a convenient way to select the work to be done. Using menus is easier than entering a long string of commands each time you want to get a particular program or file, because you don't have to remember any command names.
