## A.4 Control Language Summary

<a id="FIGUNIQ98"></a>

![Resource 73](resource:73)

PICTURE 73.

Command prompting is used: When entering an unfamiliar command When additional assistance is required for a known command You use the free format method by entering the command and its parameters as a string of characters on a command line. This method is used when entering familiar commands.
