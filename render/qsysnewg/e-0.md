# E.0 Appendix E.  AS/400 Keyboards

<a id="HDRKBDS"></a>

PC Support/400 work station function (for DOS) OS/2* EE 5250 Work Station Feature System 36/38 work station emulation Enhanced 5250 emulation 5208 Model 1 Link Protocol Converter Not only can you have a variety of display stations and personal computers attached to the system, but you can also select the keyboard you want to use with your display station. Keyboards attached to your display station or personal computer can have from 10 to 24 function keys. The kind of keyboard you have and the program you are running determine the way you use your function keys.
