### A\.2\.2 Command Entry Display

The Command Entry display is specifically designed for entering commands\. Its functions allow you to efficiently enter commands, view previously entered commands, duplicate commands for reuse, and receive additional error message assistance\.

```
    ___ Will You Need to Use It? ___________________________________________
   |                                                                        |
   | You may never have a reason to use the Command Entry display.  This    |
   | display is used when you want to list or keep track of several         |
   | commands at one time.  Most people find the simple command line on     |
   | menus to be good enough.                                               |
   |                                                                        |
   |________________________________________________________________________|
```

To get the Command Entry display, type **call qcmd** on any display command line\.

<a id="FIGFIGUNIQ90"></a>

```
    __________________________________________________________________________________ 
   |                                                                                  |
 | |                                  Command Entry                         RCH38360  |
   |                                                            Request level:   4    |
   |  Previous commands and messages:                                                 |
   |     > dsplib lib(mylib)                                                          |
   |     > DSPMSG                                                                     |
   |     > CALL PCM(ORDER)                                                            |
   |     > DSPOBJD OBJ(QGPL/INVOICE) OBJTYPE(*FILE)                                   |
   |     > STRQST                                                                     |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                                  |
   |                                                                          Bottom  |
   |  Type command, press Enter.                                                      |
 | |  ===> __________________________________________________________________________ |
 | | ________________________________________________________________________________ |
 | | ________________________________________________________________________________ |
 | | _______________________________________________________________________________  |
   |  F3=Exit   F4=Prompt   F9=Retrieve   F10=Include detailed messages               |
   |  F11=Display full      F12=Cancel    F13=User support   F16=System main menu     |
   |                                                                                  |
   |__________________________________________________________________________________|
```

This Command Entry display has some previously entered commands in the **history area** of the display\. \(Your display will probably not have any commands shown\.\) One advantage of the Command Entry display over a plain menu command line is that you can go back and review which commands you have been using\.

You can also reuse one of the commands by pressing F9 \(Retrieve\) to repeatedly bring back previous commands to the command line\. This is often faster than entering the command again\. The F9 key can also be used along with the menu command line\.

Now you know where to enter the commands\. Let's find out a little more about **how** to use them\.

**Note:** You can find more information about using the Command Entry display in the *Programming: Control Language Programmer's Guide*, SC41\-8077\.
