### A.2.2 Command Entry Display

error message assistance.

**Will** **You** **Need** **to** **Use** **It?**

You may never have a reason to use the Command Entry display. This display is used when you want to list or keep track of several commands at one time. Most people find the simple command line on menus to be good enough. To get the Command Entry display, type **call** **qcmd** on any display command line.

One advantage of the Command Entry display over a plain menu command line is that you can go back and review which commands you have been using. You can also reuse one of the commands by pressing F9 (Retrieve) to repeatedly bring back previous commands to the command line. This is often faster than entering the command again. The F9 key can also be used along with the menu command line. Now you know where to enter the commands.
