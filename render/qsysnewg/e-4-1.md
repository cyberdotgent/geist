## E.4.1 Using a Personal Computer or Personal Computer AT Style Keyboard

<a id="HDRPCSTYLE"></a>

#### Using a Personal Computer or Personal Computer AT Style Keyboard

Using the work station function, you can have a personal computer keyboard emulate or act like a personal computer style keyboard as shown below.

<a id="RV2C166"></a>

![Resource 80](resource:80)

shown below.

<a id="RSLN517"></a>

![Resource 81](resource:81)

Figure E-5. Using the Work Station Function in AT Style on an AT Keyboard.

Shift 1. Press and hold the Shift key. 2. Press the function key that corresponds to the number you want to use. For example, F1 is used as F11, F2 is used as F12, F10 is used as F20, and so on. To use function keys 21 through 24 (F21 through F24): Shift 1. Press and hold the Alternative (Alt) key. 2. Press the function key that corresponds to the number you want to use. For example, F1 is used as F21, F2 is used as F22, F3 is used as F23, and F4 is used as F24.
