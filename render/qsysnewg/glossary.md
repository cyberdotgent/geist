# GLOSSARY Glossary

This glossary includes terms and definitions from:

- The *American National Dictionary for Information Processing Systems*, copyright 1982 by the Computer and Business Equipment Manufacturers Association \(CBEMA\)\. Copies may be purchased from the American National Standards Institute, 1430 Broadway, New York, New York 10018\. Definitions are identified by the symbol \(A\) after the definition\.
- The *Information Technology Vocabulary*, developed by Subcommittee 1, Joint Technical Committee 1, of the International Organization for Standardization and the International Electrotechnical Committee \(ISO/IEC JTC1/SC1\)\. Definitions of published segments of the vocabularies are identified by the symbol \(I\) after the definition; definitions from draft international standards, draft proposals, and working papers in development by the ISO/IEC JTC1/SC1 vocabulary subcommittee are identified by the symbol \(T\) after the definition, indicating final agreement has not yet been reached among participating members\.

<a id="GLS access"></a>

**access**\. \(1\) To read\. \(2\) The ability to use or read\.

<a id="GLS advanced assistance level"></a>

**advanced assistance level**\. The type of displays that provide the same functions as the intermediate assistance level\. However, the displays contain as much information as possible by not displaying the allowed function keys and options\.

<a id="GLS application"></a>

**application**\. A particular business task, such as inventory control or accounts receivable\.

<a id="GLS application program"></a>

**application program**\. A program used to perform a particular data processing task, such as inventory control or payroll\.

<a id="GLS assistance level"></a>

**assistance level**\. The type of displays that a user selects to interact with the system\. The three levels of assistance available are basic, intermediate, and advanced\.

<a id="GLS attribute"></a>

**attribute**\. A characteristic or trait of one or more items\.

<a id="GLS authorize"></a>

**authorize**\. To permit or give authority to\.

<a id="GLS basic assistance level"></a>

**basic assistance level**\. The type of displays that provides the most assistance\. Basic assistance level supports the more common user and operator tasks, and does not use computer terminology\.

<a id="GLS batch"></a>

**batch**\. Pertaining to a group of jobs to be run on a computer sequentially with the same program with little or no operator action\. Contrast with *interactive*\.

<a id="GLS batch job"></a>

**batch job**\. A predefined group of processing actions submitted to the system to be performed with little or no interaction between the user and the system\. Contrast with *interactive job*\.

<a id="GLS character"></a>

**character**\. Any letter, number, or other symbol in the data character set that is part of the organization, control, or representation of data\.

<a id="GLS configuration"></a>

**configuration**\. The physical and logical arrangement of devices and programs that make up a data processing system\.

<a id="GLS control language ( CL )"></a>

**control language \(CL\)**\. The set of all commands with which a user requests system functions\.

<a id="GLS cursor"></a>

**cursor**\. A movable symbol, often a blinking or solid block of light, that tells the display station user where to type, or identifies a choice to select\.

<a id="GLS database"></a>

**database**\. All the data files stored in the system\.

<a id="GLS default"></a>

**default**\. A value that is automatically supplied or assumed by the system or program when no value is specified by the user\.

<a id="GLS default printer"></a>

**default printer**\. A printer that is assigned to a system or user and accepts all the printed output from that system or user, if no other printer is specified\.

<a id="GLS diagnostic message"></a>

**diagnostic message**\. A message that contains information about errors or possible errors\. This message is generally followed by an escape message\.

<a id="GLS disk"></a>

**disk**\. A direct\-access storage medium with magnetically recorded data\.

<a id="GLS disk drive"></a>

**disk drive**\. A device for moving and controlling the disk\.

<a id="GLS diskette"></a>

**diskette**\. A thin, removable magnetic disk in a protective jacket\.

<a id="GLS diskette drive"></a>

**diskette drive**\. The device used to rotate the diskette in the jacket, and to read or write the data\.

<a id="GLS display screen"></a>

**display screen**\. The part of the display device, which is similar to a television \(TV\) picture tube, used to display information entered or received at a display station\.

<a id="GLS display station"></a>

**display station**\. A device that includes a keyboard from which an operator can send information to the system and a display screen on which an operator can see the information sent to or the information received from the system\.

<a id="GLS field"></a>

**field**\. A group of related bytes \(such as name or amount\) that is treated as a unit in a record\.

<a id="GLS file"></a>

**file**\. A generic term for the object type that refers to a database file, a device file, or a save file\. The system\-recognized identifier for the object type is \*FILE\.

<a id="GLS form type"></a>

**form type**\. A 10\-character identifier, assigned by the user, that identifies each type of form used for printed output\.

<a id="GLS function"></a>

**function**\. Any instruction or set of related instructions that perform a specific operation\.

<a id="GLS function key"></a>

**function key**\. A keyboard key that allows the user to select keyboard functions or programmer functions\.

<a id="GLS generic"></a>

**generic**\. Relating to, or characteristic of, a whole group or class\.

<a id="GLS hardware"></a>

**hardware**\. Physical equipment, rather than programs, procedures, rules, and associated information\.

<a id="GLS hexadecimal"></a>

**hexadecimal**\. Pertaining to a numbering system with a base of 16\.

<a id="GLS IBM Operating System / 400 Version 2 ( OS / 400 )"></a>

**IBM Operating System/400 Version 2 \(OS/400\)**\. Pertaining to the IBM licensed program that can be used as the operating system for the AS/400 system\.

<a id="GLS index search"></a>

**index search**\. A searchable part of the online help information that provides "how\-to" and explanatory topics to supplement the help for specific displays\. The system\-recognized identifier for the object type is \*SCHIDX\.

<a id="GLS initial program"></a>

**initial program**\. A user\-profile program that runs when the user signs on and after the command processor program QCMD is started\. QCMD calls the first program\.

<a id="GLS input field"></a>

**input field**\. A field specified in a display file or database file that is reserved for information supplied by a user\.

<a id="GLS input / output"></a>

**input/output**\. Data provided to the computer or data resulting from computer processing\.

<a id="GLS inquiry message"></a>

**inquiry message**\. A message that gives information and requests a reply\.

<a id="GLS insert mode"></a>

**insert mode**\. The typing operation where text to the right of the cursor is moved to the right instead of replaced\.

<a id="GLS interactive"></a>

**interactive**\. Pertaining to the dialog\-like exchange of information between people and a computer\. Contrast with *batch*\.

<a id="GLS interactive job"></a>

**interactive job**\. A job started for a person who signs on to a work station\. Contrast with *batch job*\.

<a id="GLS intermediate assistance level"></a>

**intermediate assistance level**\. The type of displays that supports all system tasks and uses computer terminology\. Complicated tasks can be done using the intermediate assistance level\.

<a id="GLS job"></a>

**job**\. A unit of work to be done by a computer\.

<a id="GLS job log"></a>

**job log**\. A record of requests submitted to the system by a job, the messages related to the requests, and the actions performed by the system on the job\. The job log is maintained by the system program\.

<a id="GLS job name"></a>

**job name**\. The name of the job as identified to the system\. For an interactive job, the job is assigned the name of the work station at which the job was started; for a batch job, the name is specified in the command used to submit the job\.

<a id="GLS job queue"></a>

**job queue**\. An object that contains a list of batch jobs waiting to be processed by the system\. The system\-recognized identifier for the object type is \*JOBQ\.

<a id="GLS keyboard type"></a>

**keyboard type**\. The physical key arrangement and assignments for the keyboard shipped from the factory\.

<a id="GLS keyword"></a>

**keyword**\. A name that identifies a parameter in a command\.

<a id="GLS library"></a>

**library**\. A system object that serves as a directory to other objects\. A library groups related objects, and allows the user to find objects by name\. The system\-recognized identifier for the object type is \*LIB\.

<a id="GLS licensed program"></a>

**licensed program**\. A separately orderable program, supplied by IBM, that performs functions related to processing user data\. Examples of licensed programs are PC Support/400, SAA COBOL/400\*, AS/400 Application Development Tools, SAA OfficeVision/400, and so on\.

<a id="GLS line"></a>

**line**\. The physical path in data transmission\.

<a id="GLS load"></a>

**load**\. \(1\) To move data or programs into storage\. \(2\) To place a diskette into a diskette unit\. \(3\) To insert paper into a printer\. \(4\) To put a tape reel or a tape cartridge into a tape unit\.

<a id="GLS locked keyboard"></a>

**locked keyboard**\. A keyboard condition where the display station accepts no input\.

<a id="GLS magnetic tape unit"></a>

**magnetic tape unit**\. A device for reading or writing data from or to magnetic tape\.

<a id="GLS main storage"></a>

**main storage**\. All addressable storage where programs are run\.

<a id="GLS menu"></a>

**menu**\. A displayed list of items from which a user can make a selection\. The system\-recognized identifier for the object type is \*MENU\.

<a id="GLS message line"></a>

**message line**\. An area on the display where messages are displayed\.

<a id="GLS message queue"></a>

**message queue**\. A list on which messages are placed when they are sent to a user ID or device description\. The system\-recognized identifier for the object type is \*MSGQ\.

<a id="GLS notify delivery"></a>

**notify delivery**\. The method of delivering messages to a message queue in which the work station user is notified that a message arrived\. The signal is a light or an audible alarm\.

<a id="GLS object"></a>

**object**\. A named storage space that consists of a set of characteristics that describe itself and, in some cases, data\. An object is anything that exists in and occupies space in storage and on which operations can be performed\. Some examples of objects are programs, files, libraries, and folders\.

<a id="GLS object owner"></a>

**object owner**\. A user who creates an object or to whom the ownership of an object was reassigned\. The object owner has complete control over the object\.

<a id="GLS online"></a>

**online**\. Pertaining to the operation of a functional unit that is under the continual control of the system\.

<a id="GLS online information"></a>

**online information**\. Information on the display screen that explains displays, messages, and programs\.

<a id="GLS operating system"></a>

**operating system**\. A collection of system programs that control the overall operation of a computer system\.

<a id="GLS Operational Assistant"></a>

**Operational Assistant**\. A part of the operating system that provides a set of menus and displays for end users to do commonly performed tasks, such as working with printer output, messages, and batch jobs\.

<a id="GLS OS / 400"></a>

**OS/400**\. See *IBM Operating System/400 Version 2 \(OS/400\)*\.

<a id="GLS output"></a>

**output**\. Information or data received from a computer that is shown on a display, printed on the printer, or stored on disk, diskette, or tape\.

<a id="GLS output queue"></a>

**output queue**\. An object that contains a list of spooled files to be written to an output device, such as a printer or a diskette\. The system\-recognized identifier for the object type is \*OUTQ\.

<a id="GLS owner"></a>

**owner**\. The user who creates an object \(or is named the owner of an object\)\.

<a id="GLS page down"></a>

**page down**\. To move up the data shown on the display, which allows the user to move toward the end of the data\. Contrast with *page up*\.

<a id="GLS page up"></a>

**page up**\. To move down the data shown on the display, which allows the user to move toward the beginning of the data\. Contrast with *page down*\.

<a id="GLS pending"></a>

**pending**\. Pertaining to a request that was submitted and that is awaiting processing\.

<a id="GLS printer file"></a>

**printer file**\. A device file that determines what attributes printed output will have\. A particular printer may or may not support all of the attributes specified in a printer file\.

<a id="GLS printer ID"></a>

**printer ID**\. The identification code assigned to printers\.

<a id="GLS printer writer"></a>

**printer writer**\. A system program that writes spooled files to a printer\.

<a id="GLS processing"></a>

**processing**\. The action of performing operations and calculations on data\.

<a id="GLS profile"></a>

**profile**\. Data that describes the characteristics of a user, program, device, or remote location\.

<a id="GLS prompt"></a>

**prompt**\. A reminder or a displayed request for information or user action\. The user must respond to allow the program to proceed\.

<a id="GLS queue"></a>

**queue**\. A list of messages, jobs, files, or requests waiting to be read, processed, printed, or distributed in a predetermined order\.

<a id="GLS security officer"></a>

**security officer**\. A person assigned to control all of the security authorizations provided with the system\. A security officer can, for example, remove password or resource security; or add, change, or remove security information about any system user\.

<a id="GLS selective prompting"></a>

**selective prompting**\. A function of the operating system that allows the user to tailor command prompts at a parameter level\.

<a id="GLS severity code"></a>

**severity code**\. A number that indicates how important a message is\. The higher the number, the more serious the condition\.

<a id="GLS shift"></a>

**shift**\. A keyboard action to allow uppercase or other characters to be entered\.

<a id="GLS spool"></a>

**spool**\. The system function of putting files or jobs into disk storage for later processing or printing\.

<a id="GLS spooled file"></a>

**spooled file**\. A file that holds output data waiting to be processed, such as information waiting to be printed\. Also known as *spooled output file*\.

<a id="GLS subsystem"></a>

**subsystem**\. An operating environment, defined by a subsystem description, where the system coordinates processing and resources\.

<a id="GLS system security"></a>

**system security**\. A system function that restricts the use of files, libraries, folders, and devices to certain users\.

<a id="GLS tape drive"></a>

**tape drive**\. A device used to move the tape and read and write information on magnetic tapes\.

<a id="GLS toggle"></a>

**toggle**\. Pertaining to a switching device, such as a toggle key on a keyboard, that allows a user to switch between two types of operations\.

<a id="GLS user ID"></a>

**user ID**\. See *user identification \(user ID\)*\.

<a id="GLS user identification ( user ID )"></a>

**user identification \(user ID\)**\. The name used to associate the user profile with a user when a user signs on the system\. See also *user profile name*\.

<a id="GLS user message queue"></a>

**user message queue**\. A user\-created object used to receive messages sent from the system, other users, and application programs\.

<a id="GLS user password"></a>

**user password**\. A unique string of characters that a system user must enter to identify himself to the system, if the system resources are secured\.

<a id="GLS user profile"></a>

**user profile**\. An object with a unique name that contains the user's password, the list of special authorities assigned to a user, and the objects the user owns\. The system\-recognized identifier for the object type is \*USRPRF\.

<a id="GLS user profile name"></a>

**user profile name**\. The name or code that the system associates with a user when he or she signs on the system\. Also known as user ID\. See also *user identification \(user ID\)*\.

<a id="GLS variable"></a>

**variable**\. A name used to represent data whose value can be changed while the program is running by referring to the name of the variable\.

<a id="GLS work station"></a>

**work station**\. A device used to transmit information to or receive information from a computer; for example, a display station or printer\.

<a id="GLS work station user profile"></a>

**work station user profile**\. The system\-supplied user profile that has the authority required by work station operators\. Named QUSER\.
