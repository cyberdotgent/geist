### E.6.2 Normal Keys That Can Be Used But Do Not Cause You to Exit the Function

The following keys are allowed while the special-character keyboard set function is being used. They are not counted as special characters and will not cause you to exit from the special-character keyboard set function. Alt keys Fld Plus Backtab Insert Backspace NewLine CapsLock NumLock Cursor movement Reset Delete

Shift keys Dup ShiftLock Fld Exit Tab Fld Minus
