### F\.1\.1 Function Key Differences on Command Prompt Displays

<a id="HDRCMDPDIF"></a>

When you type a command name on a command line and press F4 \(Prompt\) on the AS/400 system or the System/38, or press the Help key on System/36, a command prompt display \(the AS/400 system or System/38\) or Command Entry display \(System/36\) is shown\.
