#### A.1.1.2 More on Values

The value of a parameter can be a: User-defined value

System-defined value A value defined by the user can be a name, someone's initials, your dog's favorite food, just about anything. However, it's best to make the value name descriptive of the purpose of the parameter. | For example, th`e LIB(Smit`h) parameter's purpose is to name the library you | are creating. Logically, then, because it's going to be your library, you | should probably use your last name or your initials. You can tell the difference between a user-defined value and a system-defined value by appearance. A system-defined value has an asterisk as its first character.
