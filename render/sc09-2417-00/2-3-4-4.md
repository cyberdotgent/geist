## 2.3.4.4 Avoid Percolating Exceptions

<a id="HDRPERCEX"></a>

Try to handle an exception in the place it occurs. There is some processing overhead incurred with exception percolation. See [Chapter 14,](4-3.md) [[ "Handling Exceptions" in topi](4-3.md) c 4.3 for information on handling exceptions.
