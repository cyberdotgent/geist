### 2\.3\.6\.7 Use Stream Input and Output Functions

<a id="HDRSIOF"></a>

The default for C or C\+\+ stream I/O is integrated file system enabled\. Also, the integrated file system C or C\+\+ stream I/O is more efficient that C data management stream I/O\. If you must use C data management stream I/O, this section describes what to consider\.

Use the macro version of `getc()` instead of `fgetc()` to read characters from a file\. See ["Reduce the Number of Function Calls and Function Arguments"](2-3-5-1.md) [in topic 2\.3\.5\.1](2-3-5-1.md)\. The macro version of getc reads all the characters in the buffer until the buffer is empty\. At this point, `getc()` calls `fgetc()` to get the next record\.

Use `putc()` instead of `fputc()`\. The macro version of `putc()` writes all the characters in the buffer until the buffer is full\. At this point, `putc()` calls `fputc()` to write the record into the file\.

Since the implementation of most data management stream I/O functions are very call intensive, reducing their use in your program improves performance\.
