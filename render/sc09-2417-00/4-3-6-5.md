### 4\.3\.6\.5 Record Input and Output Error Macro to Exception Mapping

<a id="HDRRIOERR"></a>

[Table 28](<#TBLREXCP>) describes what occurs if the signal `SIGIO` is raised\. It also describes the `errno` settings and the `_EXCP_MSGID` setting after an AS/400 system exception\. This is only for `*ESCAPE`, `*NOTIFY` and `*STATUS` messages\.

<a id="TBLREXCP"></a>

```
    ________________________________________________________________________
   | Table 28. Record Input and Output Error Macro to Exception Mapping¹    |
   |_______________________ __________________________ _____________________|
   | Description           | Messages                 | errno setting       |
   |_______________________|__________________________|_____________________|
   | *STATUS and *NOTIFY   | CPF4001 to CPF40FF,      | errno is not set, a |
   |                       | CPF4401 to CPF44FF,      | default reply is    |
   |                       | CPF4901 to CPF49FF       | returned to the     |
   |                       |                          | AS/400 operating    |
   |                       |                          | system.             |
   |_______________________|__________________________|_____________________|
   | Recoverable I/O error | CPF4701 to CPF47FF,      | EIORECERR           |
   |                       | CPF4801 to CPF48FF,      |                     |
   |                       | CPF5001 to CPF50FF       |                     |
   |_______________________|__________________________|_____________________|
   | Nonrecoverable I/O    | CPF4101 to CPF41FF,      | EIOERROR            |
   | error²                | CPF4201 to CPF42FF,      |                     |
   |                       | CPF4301 to CPF43FF,      |                     |
   |                       | CPF4501 to CPF45FF,      |                     |
   |                       | CPF4601 to CPF46FF,      |                     |
   |                       | CPF5101 to CPF51FF,      |                     |
   |                       | CPF5201 to CPF52FF,      |                     |
   |                       | CPF5301 to CPF53FF,      |                     |
   |                       | CPF5401 to CPF54FF,      |                     |
   |                       | CPF5501 to CPF55FF,      |                     |
   |                       | CPF5601 to CPF56FF       |                     |
   |_______________________|__________________________|_____________________|
   | Truncation occurred   | C2M3003                  | ETRUNC              |
   | at I/O operation      |                          |                     |
   |_______________________|__________________________|_____________________|
   | File is not opened    | C2M3004                  | ENOTOPEN            |
   |_______________________|__________________________|_____________________|
   | File is not opened    | C2M3005                  | ENOTREAD            |
   | for read operations   |                          |                     |
   |_______________________|__________________________|_____________________|
   | File is not opened    | C2M3009                  | ENOTWRITE           |
   | for write operations  |                          |                     |
   |_______________________|__________________________|_____________________|
   | Bad file name         | C2M3014                  | EBADNAME            |
   | specified             |                          |                     |
   |_______________________|__________________________|_____________________|
   | The file mode         | C2M3015                  | EBADMODE            |
   | specified is not      |                          |                     |
   | valid                 |                          |                     |
   |_______________________|__________________________|_____________________|
   | File is not opened    | C2M3041                  | ENOTUPD             |
   | for update operations |                          |                     |
   |_______________________|__________________________|_____________________|
   | File is not opened    | C2M3042                  | ENOTDLT             |
   | for delete operations |                          |                     |
   |_______________________|__________________________|_____________________|
   | The key length        | C2M3044                  | EBADKEYLN           |
   | specified is not      |                          |                     |
   | valid                 |                          |                     |
   |_______________________|__________________________|_____________________|
   | A nonrecoverable I/O  | C2M3101                  | EIOERROR            |
   | error occurred        |                          |                     |
   |_______________________|__________________________|_____________________|
   | A recoverable I/O     | C2M3102                  | EIORECERR           |
   | error occurred        |                          |                     |
   |_______________________|__________________________|_____________________|
   | Note:                                                                  |
   |                                                                        |
   |        ¹         Since the error is percolated to you, your direct     |
   |                  monitor handlers, ILE condition handlers, and signal  |
   |                  handler may get control. The initial setting for      |
   |                  SIGIO is SIG_IGN.                                     |
   |                                                                        |
   |        ²         The type of device determines whether the error is    |
   |                  recoverable or nonrecoverable.  These IBM             |
   |                  publications contain information about recoverable    |
   |                  and nonrecoverable AS/400 system exceptions for each  |
   |                  specific file type:                                   |
   |                                                                        |
   |                  °   ICF Programming                                   |

   |                  °   ADTS/400: Advanced Printer Function               |
   |                                                                        |
   |                  °   Application Display Programming                   |
   |                                                                        |
   |                  °   SQL Database Programming                          |
   |                                                                        |
   |                  °   Tape and Diskette Device Programming              |
```
