## 3\.5\.5 Categories Used in a Locale

<a id="HDRLOCVAR"></a>

```text
   FLOW P 3 3
   A locale and its definition source member contain these categories:
   FLOW DL 3 3
   Category  Purpose
   FLOW DT 3 13
   LC_COLLATE
             Defines the collation relations among the characters. Affects
             the behavior of the collating functions strcoll, strxfrm,
             wcscoll and wcsxfrm.
   FLOW DT 3 13
   LC_CTYPE  Defines character types, such as upper-case, lower-case, space,
             digit, and punct. Affects the behavior of character handling
             functions.
   FLOW DT 3 13
   LC_MESSAGES
             Defines the format and values for responses from the program.
   FLOW DT 3 13
   LC_MONETARY
             Defines the monetary names, symbols, punctuation, and other
             details.  Affects monetary information returned by localeconv
   FLOW DT 3 13
   LC_NUMERIC
             Defines the decimal-point (radix) character for the formatted
             input/output and string conversion functions, and the
             non-monetary formatting information returned by localeconv.
   FLOW DT 3 13
   LC_TIME   Defines the date and time conventions, such as calendar used,
             time zone, and days of the week. Affects the behavior of time
             display functions.
   FLOW DT 3 13
   LC_TOD    Defines time zone difference, time zone name, and Daylight
             Savings Time start and end.
               Setting an Active Locale for Your Program
               Using Environment Variables to Set the Active Locale
   FLOW H3 3 3
```
