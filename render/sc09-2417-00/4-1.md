## 4.1 Chapter 12.  Calling Conventions

<a id="HDRHCALL"></a>

[ You can call OPM, EPM or ILE programs from C++ using program calls. A ++ program call is a call made to a program ob`ject` (*PGM). Unlike OPM and EPM programs, ILE programs are not limited to using program calls. ILE programs can use static procedure calls or procedure pointer calls to call other procedures.
