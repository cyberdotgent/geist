C++ Source File T2123ICC

The source for the ILE C++ module `T2123ICC` shows the variable `TAXRATE` is exported from this module to be used by ILE COBOL and ILE RPG procedures.

**Note:** Weak definitions (EXTERNALs from COBOL) cannot be exported out of a

service program to a strong definition language like C or C++, while C or C++ can export to COBOL. The choice of language for `TAXRATE` is C++.

