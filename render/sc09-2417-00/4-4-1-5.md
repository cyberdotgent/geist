## 4.4.1.5 Name Mangling

<a id="HDRNMANG"></a>

All C++ function names are mangled to enable function overloading. You receive an undefined names error when you bind ILE C functions with < mangled names, for exam`ple, LocateSpaces`__FPc. In ILE C the service program name is `LocateSpace`.

If you are porting ILE C code and you want to stop function name mangling then use `extern` `"C"` around the function name.
