### 2\.3\.12\.3 Choosing Compiler Options

<a id="HDRPRFCOOP"></a>

[Table 3](<#TBLOPTTAB>) describes different compiler options to make your program run faster, and to make your compile program smaller\. Note that sometimes you have to decide which is more important to you, program size or program speed\. In some cases optimizing for one aspect means the other suffers\.

Use the guidelines in [Table 3](<#TBLOPTTAB>), except where they are contradicted\. Intrinsic functions may improve performance, but they increase the size of your module\. Unless noted, these options are not set by default\.
