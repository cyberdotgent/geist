### 2\.3\.7\.2 Pointer Comparisons

<a id="HDRPTRCMP"></a>

Since pointers take up 16 bytes of space, pointer comparisons on AS/400 are less efficient than comparisons using other data types\. You may want to replace pointer comparisons with comparisons using other data types, such as `int`\.

This is a program that constructs a linked list, processes all the elements in the list, and finally frees the linked list\. Each element in the link list holds one record from a file:

```
     #include <string.h>
     #include <stdlib.h>
     #include <recio.h>

     #define MAX_LEN 80

     struct link
     {
       struct link *next;
       char record[MAX_LEN];
     };

     int main(void)
     {

     fp = _Ropen("MY_LIB/MY_FILE", "rr, blkrcd = Y");

     start->next = NULL;
     ptr = start;

In the preceeding program, pointer comparisons are used when processing elements and freeing the linked list\. The program can be rewritten using a `short` type member to indicate the end of the link list\. As a result, you change pointer comparisons to integer comparisons:

```
      #include <string.h>
      #include <stdlib.h>
      #include <recio.h>

      #define MAX_LEN 80
     int i;

      struct link
      {
        struct link *next;
        short last;
        char record[MAX_LEN];
      };

      {
