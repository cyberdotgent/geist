### 3\.1\.4\.4 Level Check

<a id="HDRCHKLVL"></a>

Level\-check information produced on a device file when it is opened is the same information that is produced on a database file when it is opened\. See ["Level Check" in topic 3\.1\.3\.5](3-1-3-5.md) for information on this option\.
