## 4.3.6.4 Checking the AS/400 System Exceptions for C Stream Files

<a id="HDRCYSEXP"></a>

In addition to checking the return value of a function or the e`rrno` value, you can check the major and minor return codes to detect C stream file errors. If your program processes display files, ICF files, or printer files as C stream files, you can check the external variable `> _C_Maj_M`in_rc, which is define`d in <std`io.h>. The definition of this structure is:


The Data Management contains information about major and minor return codes.

Stream I/O functions trap the `SIGIO` signal.

**Note:** Signal handlers registered for SIGIO are not called for exceptions generated when processing stream files.

These `errno` macros indicate an AS/400 system exception:

- `EIOERROR`: a nonrecoverable I/O error has occurred
- `EIORECERR`: a recoverable I/O error has occurred
