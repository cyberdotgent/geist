## 4.1.4.2 Using Default Parameter Passing Styles

<a id="HDRDEFAULT"></a>

ILE C++ uses the same calling mechanisms for calling any ILE HLL program

or procedure: `extern` linkage specification. ILE C++ passes and receives parameters using three passing methods: by value directly, by value indirectly, and by reference. Other ILE languages may have different methods of passing data. See [Table 8](#TBLARGPASS).


**by** **value,** **directly** The value of the data object is placed directly into the argument list. ******by** val**ue,** indirectly The value of the data object is copied to a temporary location. The address of the copy, a pointer, is placed into the argument list. **by** **reference** A pointer to the data object is placed into the argument list. Changes made by the called procedure to the argument are reflected in the calling procedure.

[Table 8](#TBLARGPASS) shows the common parameter-passing methods for the ILE programs.

<a id="ARGPASS"></a>

Table 8. Default Argument Passing Style for ILE Programs

| ILE HLL | Pass Argument | Receive Argument |
| --- | --- | --- |
| ILE C | by value, directly or<br>by reference | by value, directly or<br>by reference |
| ILE C++ | by value, directly or<br>by value, indirectly<br>or by reference | by value, directly,<br>or by value,<br>indirectly or by<br>reference |
| ILE COBOL | by reference or by<br>value, indirectly | by reference or by<br>value, indirectly |
| by reference | by reference |  |
| ILE CL | by reference | by reference |


[Table 9](#TBLARGPROC) shows the common parameter passing methods for the ILE procedures.

<a id="ARGPROC"></a>

Table 9. Default Argument Passing Style for ILE Procedures

| ILE HLL | Pass Argument | Receive Argument |
| --- | --- | --- |
| ILE C | by value, directly | by value, directly |
| ILE C++ | by value, directly or<br>by value, indirectly<br>or by reference | by value, directly,<br>or by value,<br>indirectly or by<br>reference |
| ILE COBOL | by reference or by<br>value, indirectly | by reference |
| ILE RPG | by reference | by reference |
| ILE CL | by reference | by reference |


To pass or receive parameters to or from procedure calls involving other ILE languages, especially ILE C, ILE RPG, or ILE COBOL, you must ensure that the other procedure is set up to accept data by reference.
