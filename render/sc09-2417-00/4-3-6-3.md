### 4\.3\.6\.3 Errno Macros

<a id="HDREMACRO"></a>

[Table 26](<#TBLERRNOM>) lists the `error` macros that the C library functions can set `errno` to:

<a id="TBLERRNOM"></a>

```
SI errno macros, list of
    ________________________________________________________________________
   | Table 26. Errno Macros                                                 |
   |_______________________ ________________________ _______________________|
   | Error Macro           | Description            | Set by Function       |
   |_______________________|________________________|_______________________|
   | EBADDATA              | The message data is    | perror, strerror      |
   |                       | not valid              |                       |
   |_______________________|________________________|_______________________|
   | EBADKEYLN             | The key length         | _Rreadk, _Rlocate     |
   |                       | specified is not valid |                       |
   |_______________________|________________________|_______________________|
   | EBADMODE              | The file mode          | fopen, freopen,       |
   |                       | specified is not valid | _Ropen                |
   |_______________________|________________________|_______________________|
   | EBADNAME              | Bad file name          | fopen, freopen,       |
   |                       | specified              | _Ropen                |
   |_______________________|________________________|_______________________|
   | EBADPOS               | The position specified | fsetpos               |
   |                       | is not valid           |                       |
   |_______________________|________________________|_______________________|
   | EBADSEEK              | Bad offset for a seek  | fgetpos, fseek        |
   |                       | operation              |                       |
   |_______________________|________________________|_______________________|
   | EBUSY                 | The record or file is  | perror, strerror      |
   |                       | in use                 |                       |
   |_______________________|________________________|_______________________|
   | EDOM                  | Domain error in math   | acos, asin, atan2,    |
   |                       | function               | cos, exp, fmod,       |
   |                       |                        | gamma, hypot, j0, j1, |
   |                       |                        | jn, y0, y1, yn, log,  |
   |                       |                        | log10, pow, sin,      |
   |                       |                        | strtol, strtoul,      |
   |                       |                        | sqrt, tan             |
   |_______________________|________________________|_______________________|
   | EGETANDPUT            | An illegal read        | fgetc, fread, getc,   |
   |                       | operation occurred     | getchar               |
   |                       | after a write          |                       |
   |                       | operation              |                       |
   |_______________________|________________________|_______________________|
   | EINVAL                | The signal is not      | signal                |
   |                       | valid                  |                       |
   |_______________________|________________________|_______________________|
   | EIO                   | Consecutive calls of   | I/O                   |
   |                       | I/O occurred           |                       |
   |_______________________|________________________|_______________________|
   | EIOERROR              | A nonrecoverable I/O   | All I/O functions     |
   |                       | error occurred         |                       |
   |_______________________|________________________|_______________________|
   | EIORECERR             | A recoverable I/O      | All I/O functions     |
   |                       | error occurred         |                       |
   |_______________________|________________________|_______________________|
   | ENODEV                | Operation attempted on | fgetpos, fsetpos,     |
   |                       | a wrong device         | fseek, ftell, rewind  |
   |_______________________|________________________|_______________________|
   | ENOENT                | File or library is not | perror, strerror      |
   |                       | found                  |                       |
   |_______________________|________________________|_______________________|
   | ENOPOS                | No record at specified | fsetpos               |
   |                       | position               |                       |
   |_______________________|________________________|_______________________|
   | ENOREC                | Record not found       | fread, perror,        |
   |                       |                        | strerror              |
   |_______________________|________________________|_______________________|
   | ENOTDLT               | File is not opened for | _Rdelete              |
   |                       | delete operations      |                       |
   |_______________________|________________________|_______________________|
   | ENOTOPEN              | File is not opened     | clearerr, fclose,     |
   |                       |                        | fflush, fgetpos,      |
   |                       |                        | fopen, freopen,       |
   |                       |                        | fseek, ftell, setbuf, |
   |                       |                        | setvbuf, _Ropen,      |
   |                       |                        | _Rclose               |
   |_______________________|________________________|_______________________|
   | ENOTREAD              | File is not opened for | fgetc, fread, ungetc, |
   |                       | read operations        | _Rreadd, _Rreadf,     |
   |                       |                        | _Rreadindv, _Rreadk,  |
   |                       |                        | _Rreadl, _Rreadn,     |
   |                       |                        | _Rreadnc, _Rreadp,    |
   |                       |                        | _Rreads, _Rlocate     |
   |_______________________|________________________|_______________________|
   | ENOTUPD               | File is not opened for | _Rrlslck, _Rupdate    |
   |                       | update operations      |                       |
   |_______________________|________________________|_______________________|
   | ENOTWRITE             | File is not opened for | fputc, fwrite,        |
   |                       | write operations       | _Rwrite, _Rwrited,    |
   |                       |                        | _Rwriterd             |
   |_______________________|________________________|_______________________|
   | ENUMMBRS              | More than one member   | ftell                 |
   |_______________________|________________________|_______________________|
   | ENUMRECS              | Too many records       | ftell                 |
   |_______________________|________________________|_______________________|
   | EPAD                  | Padding occurred on a  | fwrite                |
   |                       | write operation        |                       |
   |_______________________|________________________|_______________________|
   | EPERM                 | Insufficient           | perror, strerror      |
   |                       | authorization for      |                       |
   |                       | access                 |                       |
   |_______________________|________________________|_______________________|
   | EPUTANDGET            | An illegal write       | fputc, fwrite, fputs, |
   |                       | operation occurred     | putc, putchar         |
   |                       | after a read operation |                       |
   |_______________________|________________________|_______________________|
   | ERANGE                | Range error in math    | cos, cosh, gamma,     |
   |                       | function               | exp, j0, j1, jn, y0,  |
   |                       |                        | y1, yn, log, log10,   |
   |                       |                        | ldexp, pow, sin,      |
   |                       |                        | sinh, strtod, strtol, |
   |                       |                        | strtoul, tan          |
   |_______________________|________________________|_______________________|
   | ERECIO                | File is opened for     | fgetc, fgetpos,       |
   |                       | record I/O, so         | fputc, fread, fseek,  |
   |                       | character-at-a-time    | fsetpos, ftell        |
   |                       | processing functions   |                       |
   |                       | cannot be used         |                       |
   |_______________________|________________________|_______________________|
   | ESTDERR               | stderr cannot be       | fgetpos, fputc,       |
   |                       | opened                 | fseek, fsetpos,       |
   |                       |                        | ftell, fwrite         |
   |_______________________|________________________|_______________________|
   | ESTDIN                | stdin cannot be opened | fgetc, fgetpos,       |
   |                       |                        | fread, fseek,         |
   |                       |                        | fsetpos, ftell        |
   |_______________________|________________________|_______________________|
   | ESTDOUT               | stdout cannot be       | fgetpos, fputc,       |
   |                       | opened                 | fseek, fsetpos,       |
   |                       |                        | ftell, fwrite         |
   |_______________________|________________________|_______________________|
   | ETRUNC                | Truncation occurred on | Any I/O function that |
   |                       | I/O operation          | reads or writes a     |
   |                       |                        | record sets errno to  |
   |                       |                        | ETRUNC                |
   |_______________________|________________________|_______________________|
```
