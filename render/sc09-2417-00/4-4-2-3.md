### 4\.4\.2\.3 Inter\-Language Calls

<a id="HDRCILC"></a>

VisualAge C\+\+ for Windows code containing inter\-language and system calls must be modified before being used with VisualAge for C\+\+ for AS/400 as these are system dependant\.
