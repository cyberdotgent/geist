## 2.3.11.2 Use Cheaper Operators

<a id="HDRCHEAPO"></a>

The C++ language has many features that other languages do not provide [ which can be used to improve your C++ program's performance:

- Instead of dividing an integer by 2 sup n shift the integer right by n bits
- Instead of using the remainder operator for number 2 sup n (`x` `%` `32;`), use the bitwise-and operator `&` `0x0000001F;`
