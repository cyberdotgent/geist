## 3.4.1 Introducing AS/400 Pointer Types

<a id="HDRPTRTYPE"></a>

In ANSI C++ a `pointer` type is a type that is derived from a `function` type a `data` `object` type, or an `incomplete` type. AS/400 pointer types can also << be derived from other AS/400 entities such as system objects (programs), code labels, and process objects. These pointer types are referred to as


`Open` Can hold any of the other pointer types `Space` Generic pointers to data objects `Function` System pointers to program objects or procedure pointers to bound ILE procedures `System` Pointers to system objects such as queues, indexes, libraries, and program objects `Label` Pointers to fixed locations within the executable code of a procedure or function `Invocation` Pointers to process objects for procedure (function) calls under ILE, or program calls under EPM or OPM `Suspend` Pointers to the location in a procedure where control is suspended

These pointer types, as well as pointers to data objects and incomplete types, are not data-type-compatible (assignment or comparison) with each other. A variable declared as a pointer to a data object cannot be assigned the value of a `function` pointer or `system` pointer, and a `system` pointer cannot be compared for equality with an `invocation` pointer or pointer to a data object. The above is not true for `open` pointers. **Notes:**
