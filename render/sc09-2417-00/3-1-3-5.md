## 3.1.3.5 Level Check

<a id="HDRLVLCHK"></a>

If you specify the `lvlchk` option on the #pragma mapinc directive, the

To generate information needed to perform a level check during an open operation, use statements like these in your program:

```text
#pragma mapinc("ORDERFILE",                     \
[                     "MYLIB/ORDERL(ORDHDR ORDDTL)",   \
"key lvlchk",                    \
"_P"                             \
)
#include "ORDERFILE"
```

The DDS source for the physical file `ORDHDR` is:

```text
A          R ORDHDR
A            ITEM_NAME     20A
A            ITEM_NUM      10S
A            UNIT_PRICE     5B 2
A            ITEM_DESC     50A
A          K ITEM_NUM
```

The DDS source for the physical file `ORDDTL` is:

```text
A          R ORDDTL
A            ITEM_NUM      10S
A            ORDER_NUM      8S
A            CUST_NAME     20A
A            CUST_PHONE    10A
A            CUST_ADDR     30A
A            QUANTITY       3B 0
A            TOT_PRICE      7B 2
A            ORDER_DATE      L
A
SHIP_DATE       L
```

The DDS source for the logical file is:

```text
A          R ORDHDR                    PFILE(ORDHDR)
A            ITEM_NAME
A            ITEM_NUM
A            UNIT_PRICE
A          K ITEM_NUM
A*
A          R ORDDTL                    PFILE(ORDDTL)
A            ITEM_NUM
A            ORDER_NUM
A            QUANTITY
A            TOT_PRICE
```
