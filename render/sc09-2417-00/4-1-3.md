## 4\.1\.3 Calling an ILE Procedure Using a Linkage Specification

<a id="HDRILEPR"></a>

```text
   FLOW P 3 3
   Unlike OPM programs, ILE programs are not limited to using dynamic program
   calls. ILE programs can also use static procedure calls or procedure
   pointer calls.
   Notes:
   FLOW NOTEL 3 3
   FLOW LI 3 7
   1.  ILE procedures within an activated ILE program can be accessed using
       static procedure calls or procedure pointer calls. New ILE programs
       that have not been activated yet must be called by a dynamic program
       call. There are other situations in which dynamic calls occur.
   FLOW LI 3 7
   2.  EPM C and Pascal procedures or functions cannot call C++ procedures.
   FLOW LI 3 7
   3.  The term procedure in ILE is similar to the term function in C++.  A
       C++ function is an ILE procedure.
   FLOW P 3 3
   C++ provides a linkage specification to enable procedure calls and the
   sharing of data between the C++ caller and the called procedure.  See
   "Calling a Program Using a Linkage Specification" in topic 4.1.2 for the
   syntax.
   FLOW P 3 3
   The valid string literals for the linkage specification to call ILE
   procedures are:
   FLOW DL 3 3
   Linkage Specification Type of Procedure Called
   FLOW DT 3 13
   "C++"     ILE C++ procedure (default)
   FLOW DT 3 13
   "C"       ILE C procedure
   FLOW DT 3 13
   "C nowiden"
             ILE C procedure without widened parameters
   FLOW DT 3 13
   "RPG"     ILE RPG procedure
   FLOW DT 3 13
   "COBOL"   ILE COBOL procedure
   FLOW DT 3 13
   "CL"      ILE CL procedure
   FLOW DT 3 13
   "ILE"     General ILE function call
   FLOW DT 3 13
   "ILE nowiden"
             ILE function call without widened parameters
   FLOW DT 3 13
   "VREF"    ILE function call with pointers in temporary storage. (Behaves
             the same as a regular call although parameters are passed to the
             function as if they were by reference.)
   FLOW DT 3 13
   "VREF nowiden"
             Same as "VREF" without widened parameters
   FLOW H2 3 3
```
