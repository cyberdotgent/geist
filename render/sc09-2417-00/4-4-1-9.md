## 4.4.1.9 String Literals

<a id="HDRSTRLIT"></a>

] In ILE C strings are placed into read/write memory by default. In ILE C++ you must use the #pragma strings directive to place strings into read/write memory. The syntax of this pragma is: writeable are >> # pragma strings ( readonly ) ><
