## 4\.1\.2 Calling a Program Using a Linkage Specification

<a id="HDRCPGM"></a>

```text
   FLOW P 3 3
   You can call OPM, ILE, or EPM programs from a C++ program. OPM, ILE or EPM
   programs can also call a C++ program. See Table 1 in topic 1.2.1 for a
   list of AS/400 programming languages you can call.
   FLOW P 3 3
   C++ provides a linkage specification to enable program calls and sharing
   of data between them. The syntax is:
   >>__extern__"string-literal"__{ declaration-list }______________________><
   >>__extern__"string-literal"__declaration_______________________________><
   FLOW P 3 3
   The "string-literal" is used to specify the linkage associated with a
   particular function. The string literals used in linkage specifications
   are case-insensitive. The valid string literals for the linkage
   specification to call programs are:
   FLOW DL 3 3
   FLOW DT 3 13
   "OS"      OS linkage call
   FLOW DT 3 13
   "OS nowiden"
             OS linkage call without widened parameters. See "OS Linkage" in
             topic 4.1.4.1 for details.
   FLOW P 3 3
   If you want a C++ program to call an ILE, OPM, or EPM program (*PGM), use
   the extern "OS" linkage specification in your C++ source to tell the
   compiler that the called program is an external program, not a bound ILE
   procedure. For example, if you want a C++ program to call an OPM COBOL
   program (*PGM) this extern "OS" linkage specification in your C++ source
   tells the compiler that COBOL_PGM is an external program, not a bound ILE
   procedure.
     extern "OS" void COBOL_PGM(void);
   FLOW P 3 3
   If you want an ILE, OPM or EPM program to call a C++ program, use the ILE,
   OPM, or EPM language-specific call statement.
   FLOW H2 3 3
```
