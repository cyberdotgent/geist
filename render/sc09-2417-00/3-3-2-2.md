## 3.3.2.2 Opening As Record Files

<a id="HDRRECOPN"></a>

<< To open an AS/400 tape file, diskette file or save file as a record file use the `_Ropen()` function with a mode of `rr`, `wr`, and optional keyword parameters lrecl, secure, and riofb. In addition, the optional keyword parameter `blksize` can be used to open an AS/400 tape file or diskette ] file. As well, the `mo`de ab can be used when you open an AS/400 tape file or save file.
