### 4\.4\.2\.2 Correspondence Between Windows and OS/400 Objects

<a id="HDROBJCMP"></a>

The following table shows the correspondence between Windows and OS/400 objects:

<a id="TBLTERMDIF"></a>

Table 31\. Correspondence between Windows and OS/400 Objects and  
Concepts

| Windows | OS/400 |
| --- | --- |
| Object module \(\.OBJ\) | Module object \(\*MODULE\) |
| Executable \(\.EXE\) | Program object \(\*PGM\) |
| Dynamic link library \(\.DLL\) | Service program \(\*SRVPGM\) |
| Library \(\.LIB\) | N/A |
| Help file \(\.HLP\) | N/A |
| Directory | Library \(\*LIB\) |
| Linker | Binder |
