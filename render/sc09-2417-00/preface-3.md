## PREFACE.3 C++ Language Standards and Portability

<a id="HDRPORT"></a>

At this time, there is no universal standard for the C++ language comparable to C standards. However, an ANSI committee is developing a C++ language standard. Its September 17, 1992 working paper, Draft Proposed ++ American National Standard for Information Systems - Programming Language ] C++ X3J16/92-0060, was used as a base document for developing the < VisualAge for C++ for AS/400 C++ compiler. The VisualAge for C++ for [ AS/400 C++ compiler will continue to change its design in accordance with the ANSI standard as it evolves. If you plan to develop portable code, follow this working paper. Do not use the extensions specific to the [HDRANSIIMP](appendix1-1.md) compiler as described in C++ Language Reference. See Appendix A, "ANSI [Notes on Implementation-Defined Behavior" in topic APPENDIX1.1](appendix1-1.md) for information on the C++ working paper.
