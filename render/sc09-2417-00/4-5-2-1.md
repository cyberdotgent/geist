### 4\.5\.2\.1 The Dynamic\_cast Operator

<a id="HDRDYNCAST"></a>

```text
    The dynamic_cast Operator
   FLOW P 3 3
   A dynamic cast expression is used to cast a base class pointer to a
   derived class pointer. This is referred to as downcasting.
   FLOW P 3 3
   The dynamic_cast operator makes downcasting much safer than conventional
   static casting. It obtains a pointer to an object of a derived class that
   is given a pointer to a base class of that object. The operator
   dynamic_cast returns the pointer only if the specific derived class
   actually exists.  If not, it returns zero.
   FLOW P 3 3
   Dynamic casts have the form:
   >>__dynamic_cast__<__type_name__>__(__expression__)_____________________><
   FLOW P 3 3
   The operator converts the expression to the desired type type_name. The
   type_name can be a pointer or a reference to a class type. If the cast to
   type_name fails, the value of the expression is zero.
   FLOW H3 3 3
```
