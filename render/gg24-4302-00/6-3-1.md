### 6.3.1 Terminology

environment is: The terminal or LU6.2 remote program sends a message to the orig**inating sys**tem, which is also called the loca**l sys**tem. An inte**rmediate sys**tem is one that routes messages between the local and remote systems. The remo**te sys**tem is the system where the remote transaction executes. APPC/IMS MSC support allows several new types of multisystem operation: Remote transaction processing Program-to-program switch to a remote transaction program Message switch.
