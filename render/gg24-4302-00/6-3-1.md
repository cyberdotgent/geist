### 6.3.1 Terminology

The terminology used to define the different IMS systems in an MSC environment is: The terminal or LU6.2 remote program sends a message to the

**originating** system, **which** is also called the local system. An inte**rmediate sys**tem is one that routes messages between the local and remote systems. The remo**te sys**tem is the system where the remote transaction executes. APPC/IMS MSC support allows several new types of multisystem operation: Remote transaction processing Program-to-program switch to a remote transaction program Message switch.
