## 7.4 Change to /DISPLAY AREA Command

<a id="HDRDISAREA"></a>

In ["POS Call and IOVF Statistics" in topic 3.2.15.2](#HDRIOVFPOS) we explain that the count of available IOVF CIs is no longer maintained in storage but is measured by reading all of the space maps. In previous releases of IMS, this value was included in the response to a /DISPLAY AREA command. In IMS 5.1, an additional command parameter, IOVF, is required if the IOVF statistics are to be shown.
