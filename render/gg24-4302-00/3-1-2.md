### 3.1.2 Value

```text
   The value of running IMS 5.1 in a sysplex is twofold:

   ° The system can grow to exceed the limits of a single system without
   ° sacrificing data currency and without data replication (and the
   ° attendant problems of that technique)
   ° Smaller building blocks for the aggregate system can be used; this is
   ° particularly useful for the 9672 PTS machines.

   ° IMS n-way data sharing in a 9672 PTS significantly reduces the cost per
   ° transaction while providing extremely high service levels in terms of
   ° availability, integrity, reliability, and performance.  For value
   ° conscious customers IMS is the transaction manager of choice!
   ° c.cc 12
```
