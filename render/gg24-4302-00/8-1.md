## 8.1 IMS Performance

The IMS Transaction Manager is noted for its high performance and low cost per transaction. Clearly, performance is most apparent when using IMS Fast Path, but full function message processing with access to DB2 data still achieves very high levels of performance. IMS TM performs so well for many reasons, some of which are summarized in the sections that follow..
