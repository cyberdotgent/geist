## 7.1 Enhanced Database Access Security

<a id="HDRDBRACF"></a>

In this section, the many references to RACF should be interpreted to mean "RACF or an equivalent security product." Before IMS 5.1, online IMS systems (TM or DBCTL) did not perform any authorization check when opening a VSAM data set (full function DL/1 or Fast Path DEDB). Online IMS systems invoked RACF when opening an OSAM data set and used RACF for all databases in offline batch. This anomaly is addressed in IMS 5.1, which now always performs a security check at data set open time for all database types in all environments.
