### 3.2.1 Virtual Storage Option

to MSDBs for holding data in memory. VSO is specified in DBRC for a DEDB area. It causes that area to be loaded from DASD into virtual storage using an MVS data space. Subsequent reads are done from the data space without I/O. Updates are written at application syncpoint time to the data space. Periodically, IMS copies updated CIs from the data space to the area data sets on DASD..
