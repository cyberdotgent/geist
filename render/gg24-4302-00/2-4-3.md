### 2.4.3 Enhanced APPC/IMS

The APPC/IMS support introduced in IMS 4.1 has been enhanced in IMS 5.1 as follows: Transactions entered through APPC can make full use of the IMS MSC facilities. The transaction can be processed in a remote IMS system, or if the transaction is local it can use an alternate PCB to send a message through MSC to a remote system. A reply to the IOPCB in a remote system will be routed back to the originating LU6.2 application. In other words, all of the restrictions in IMS 4.1 have been removed. The functions of the LU6.2 Destination Exit (DFSLULU0) have been implemented in the MCEE (DFSCMUX0). The LU6.2 Destination Exit (DFSLULU0) no longer exists in IMS 5.1. c.cc 8 The Terminal Routing Exit (DFSCMTR0) is functionally replaced by the

new Input Message Routing Exit (DFSNPRT0), which is called for all input messages, including those originating from an LU6.2 terminal.

Qualified Network LU names are now supported in inbound LU6.2 conversations. There is a new message mapping facility. The LU6.1 adapter is no longer supported.
