### 5.5.1 Overview

```text
   Each release of IMS on an MVS system requires a unique type 2 SVC.  The
   installation of this IMS SVC has previously required an MVS IPL.  IMS 5.1
   includes a new utility to install an IMS SVC without an MVS IPL.
```
