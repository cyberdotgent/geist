## 11.1 Reasons to Use N-Way Data Sharing

N-way data sharing can lead to substantial benefits in many different scenarios. Some of these scenarios are subtle and need explanation. The primary scenarios are: 1. Capacity greater than a single system Need single system image Need data consistency Need future growth 2. Continuous operation 3. Conflicting performance requirements by workload Batch buffering versus online Dataspace or hyperspace usage 4. Phased change control 5. Backup (redundant components) 6. Increased availability 7. Flexible operation 8. Operational error avoidance 9. System managed processing.-

The redbook Using IMS 5.1 with the Parallel Transaction Server, GG24-4303 gives a detailed examination of the features and implementation of the parallel sysplex environment.
