### 6.4.1 LTERM Name Support

By default, the IOPCB LTERM field contains the LUname for APPC input.

However, an LTERM name can be included in the first SEND of the inbound conversation and be extracted by the DFSLUEE0 LU6.2 user exit. This LTERM name will be placed in the IOPCB. The application program can then use the LTERM name to determine which processing to perform. The nams is also commonly used to determine the destination for any output messages to non-LU6.2 devices such as printers.
