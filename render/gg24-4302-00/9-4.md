## 9.4 Mandatory Migration Items

Migrating DBRC to IMS 5.1 is exactly as in previous IMS migrations. The basic steps are: Install and thoroughly test DBRC migration maintenance on current IMS

systems (IMS 3.1 or 4.1). Back up existing RECONs using the current system. Install IMS 5.1.

Execute the IMS 5.1 RECON Upgrade Utility. Should this fail, recover RECONs from the backup copy before trying again. Delete and redefine discarded RECONs. Almost all of the RECON records have changed, but, as in IMS 4.1, mapping macros are shipped with the IMS code..
