## 9.3 Discontinued Support

Local DL/1 for CICS. All users of CICS Local DL/1 must convert to DBCTL to use IMS 5.1. Discussion of the ways of achieving conversion can be found in IMS/ESA 4.1 Migration Guide, GG24-4150. LU6.2 adapter There is no support for the adapter, although the code is still shipped with IMS 5.1. Users of the adapter who do not need MSC support for LU 6.2 should convert to using native APPC/IMS support before migrating to IMS 5.1. If MSC is needed for LU6.2 devices, the conversion from the adapter to APPC/IMS can be deferred as necessary. More information can be found in ["LU6.1 Adapter for LU6.2](7-6-2.md) A [pplications" in topic 7.6.2.](7-6-2.md)
