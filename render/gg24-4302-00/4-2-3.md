For full function databases, the allocation information has to be read in from RESLIB. In IMS 5.1, the NODBALLOC parameter can be specified on the /START DATABASE and /START DATAGROUP commands. It is *only* *applicable* *to* *full* *function* *databases* and is ignored for any DEDBs or areas in a data group. NODBALLOC causes the allocation and the associated I/Os to be deferred until data set open time and so expedites the command processing. For example: /STAR`T DATA`B`ASE name`1`,name2,name3,.....
