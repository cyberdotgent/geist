### 8.5.6 IMS Client Server Object Manager

object-oriented API. Client application programs use the common interface of the Object Management Group's Persistent Object Service to manipulate objects. This interface features a set of classes and methods that the client application program uses and builds on. Client application programmers can develop applications with little or no knowledge of the host environment. On the workstation server tier, IMS CSOM maintains and manages a recoverable database of persistent objects that can be accessed and changed by clients of the server. IMS CSOM requests data objects from the IMS hosts and routes the objects to the server as requested. The benefits of using IMS CSOM are: Access to IMS data through an object-oriented, insdustry standard API Ability to develop workstation applications using object-oriented techniques and software while retaining a safe, secure, and reliable data store Control of data access performance by caching frequently used data in the server tier near the workstation Flexibility in future software usage. c.cc 20
