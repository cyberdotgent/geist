### 6.3.4 Value

Customers who with IMS 4.1 were unable to use native APPC/IMS support because they used MSC will now be able to implement APPC/IMS. The only restriction is that new explicit mode (CPI/C driven) transactions will not be able to exploit any MSC facilities. An IMS system can be the entry point for all LU6.2 conversations. Only one APPC/MVS system needs to be implemented.
