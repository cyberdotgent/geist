## 5.3 Enhanced Message Error Handling

<a id="HDRMCEE"></a>

should be viewed as mandatory for MSC systems requiring high link availability. It is highly recommended in all other environments. The changes in IMS 5.1 build upon the original IMS 4.1 implementation and consolidate a variety of message traffic error conditions into a single point of control. This simplifies operational complexity and allows for more system managed function while allowing the right action to be taken based on the customer environment..
