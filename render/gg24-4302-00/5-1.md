## 5.1 Remote Site Recovery Feature

The RSR feature of IMS 5.1 is a separately priced component that provides

a disaster backup (remote site) capability for an IMS system. It replaces

the RRDF product used with IMS 4.1 and provides a very different solution,

which is much broader in its scope and capability.

Only IMS databases are protected by RSR. Other system resources, such as

MVS catalogs, nondatabase data sets, DB2 tables, and application load

module libraries, are not covered by RSR and must be copied to the remote

site by other means..
