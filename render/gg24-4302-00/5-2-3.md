### 5.2.3 Migration

```text
   No user effort is required to implement the new timestamp recovery.  The
   only point to be aware of is that the new timestamp recovery utility will
   only exploit the USID facility when no logs from a previous release are
   included.

   There is no change to the Recovery Utility JCL or SYSIN data as a result
   of this enhancement.
```
