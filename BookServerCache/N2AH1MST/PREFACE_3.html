PREFACE.3 Message Translation




   Through the MVS message service (MMS), you can translate MVS system
   messages into other languages. Messages that cannot be translated include
   the following:


   °   Initialization messages
   °   MVS/DFP (*) messages
   °   Some complicated multiple-line messages


   See Planning: Operations and Assembler Programming Guide for information
   about using the MMS.
(*) MVS/DFP is a registered trademark of the IBM Corporation.
