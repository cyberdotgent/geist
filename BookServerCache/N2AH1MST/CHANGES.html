CHANGES Summary of Changes


   Summary of Changes for GC28-1656-1
   MVS/ESA System Product Version 4 Release 2.0


   This major revision consists of changes to support MVS/ESA System Product
   Version 4 Release 2.0.


   New Information:


   °   The following are the two new sections of messages for this MVS/ESA
       release:


       ATB messages
           The system issues these messages for Advanced Program-to-Program
           Communications (APPC) information.


       ASB messages
           The system issues these messages for APPC/MVS transaction
           scheduler information.


   °   The following are the 74 new messages for this MVS/ESA release,
       including a portion of the message text and an explanation of when the
       message is issued:


       AMD083I AMDSADMP: STAND-ALONE DUMP status
           The system issues this message to illustrate the current status of
           the stand-alone dump program.  See page 6.0.


       AMD085I STORE STATUS IS MISSING OR INVALID FOR PROCESSOR cpuid
           The system issues this message when required STORE STATUS
           information is either missing or incorrect.  See page 6.0.


       AMD086I ALL OF STORAGE CONTAINED BINARY ZEROES....
           The system found that all of central storage was cleared to binary
           zeroes.  See page 6.0.


       AMD087I DUMP OF A PREVIOUS STAND-ALONE DUMP PROGRAM NOW status
           The system issues this message when it detects data that was used
           by a previous dump.  See page 6.0.


       AMD088D REPLY 'T' TO TERMINATE, OR 'U' TO CONTINUE...
           The system issues this message after the stand-alone dump program
           dumped storage used by a previous IPL.  See page 6.0.


       AMD089I DUMP TERMINATED DUE TO reason
           The system issues this message after the stand-alone dump program
           loaded an ending wait state code.  See page 6.0.


       AMD090I UNABLE TO CONTINUE USING THE SYSTEM CONSOLE
           The system issues this message when the stand-alone dump program
           can no longer use the system console.  See page 6.0.


       AMD095I BUFFERS WRITTEN=xxxxxxxx
           The system issues this message to display the number of buffers
           written.  See page 6.0.


       BLS002E BLSQPRMI CAN ONLY BE INVOKED FROM A JOB INITIATED BY THE
           OPERATOR START COMMAND
           The system issues this message when IPCS program BLSQPRMI is not
           invoked from a job initiated by the operator START command.  See
           page 12.0.


       CBDA800I IOS message queue open error, return code = return code.
           The system issues this message when an error occurs during an open
           of the IOS message queue.  See page 14.0.


       CBDA801I No I/O configuration information could be obtained...
           The system issues this message when an error occurs while trying
           to obtain the I/O configuration information area.  See page 14.0.


       CBDA802I Unrecognizable I/O configuration information, activation...
           The system issues this message when an error occurs after
           obtaining unrecognizable information from the I/O configuration
           area.  See page 14.0.


       CBDA803I An MVSCP configuration was used for IPL, activation is...
           The system issues this message when an IPL was performed with an
           MVSCP configuration and dynamic reconfiguration is not possible.
           See page 14.0.


       CBDA804I Activation in progress, please wait ....
           The system issues this message when the activation of a new I/O
           configuration has started.  See page 14.0.


       CBDA805I IODF dsname is not a Production-IODF.
           The system issues this message when the dynamic configuration is
           not possible because the IODF is not correct.  See page 14.0.


       CBDA806I Recovery is recommended, specify either RECOVER or SOFT.
           The system issues this message when a failure occurs in a previous
           dynamic configuration change, leaving HCD in an inconsistent
           state.  See page 14.0.


       CBDA807I Recovery data not available, activation restricted ...
           The system issues this message when an unsuccessful recovery
           attempt was made.  See page 14.0.


       CBDA808I Processor proc_id not found in IODF ...
           The system issues this message when the specified processor cannot
           be found in the IODF.  See page 14.0.


       CBDA809I IOCDS iocds for processor proc_id ...
           The system issues this message when the IOCDS name cannot be found
           in the IODF for the indicated processor.  See page 14.0.


       CBDA810I Processor proc_id not found in dsname.
           The system issues this message when the specified processor cannot
           be found in the IODF.  See page 14.0.


       CBDA811I Configuration ID config id not found in dsname.
           The system issues this message when the configuration definition
           cannot be found in the IODF.  See page 14.0.


       CBDA812I EDT edt_id of configuration ID config_id not found in dsname.
           The system issues this message when the EDT cannot be found in the
           IODF.  See page 14.0.


       CBDA813I Configuration ID required for dsname.
           The system issues this message when the required configuration ID
           was not specified for the target IODF.  See page 14.0.


       CBDA814I EDT ID required for dsname.
           The system issues this message when the required EDT ID was not
           specified for the target IODF.  See page 14.0.


       CBDA815I Processor ID is required.
           The system issues this message because the processor ID is
           required for a full dynamic configuration change or a 'software
           only' change.  See page 14.0.


       CBDA816I Currently active I/O definition does not match IODF...
           The system issues this message when the currently active I/O
           definition does not match the IODF that should be current.  See
           page 14.0.


       CBDA817I Processors proc_id1 and proc_id2 are different processor
           models.
           The system issues this message when the target processor is not
           the same as the source processor.  See page 14.0.


       CBDA818I Processors proc_id1 and proc_id2 are in different mode.
           The system issues this message when the target processor is not in
           the same mode as the source processor.  See page 14.0.


       CBDA819I Only software changes are allowed, specify SOFT for
           confirmation.
           The system issues this message when system conditions restrict an
           activation to software changes only.  See page 14.0.


       CBDA820I Processor proc_id not found in current IODF,...
           The system issues this message when the specified processor does
           not exist in the currently active IODF.  See page 14.0.


       CBDA821I Processor definition proc_id in current IODF...
           The system issues this message when the currently active IODF does
           not match the current hardware configuration.  See page 14.0.


       CBDA822I Processor definition proc_id in IODF ...
           The system issues this message when a recovery attempt failed
           because the indicated processor was involved in a configuration
           change.  See page 14.0.


       CBDA823I Request conflict - Software only changes and hardware ...
           The system issues this message when both software only changes and
           hardware deletes are requested.  See page 14.0.


       CBDA824I Request conflict - Test activation only and hardware ...
           The system issues this message when both test of activation only
           and hardware deletes are requested.  See page 14.0.


       CBDA825I Request conflict - Test activation only and IOCDS related
           process ...
           The system issues this message when test of activation only and
           write or switch of the IOCDS have been requested.  See page 14.0.


       CBDA826I Not enough storage to perform the activation request.
           The system issues this message when it finds there is not enough
           storage to build the CCB.  See page 14.0.


       CBDA827I No channel paths defined for processor proc_id ...
           The system issues this message when there are no channel paths
           defined for the processor.  See page 14.0.


       CBDA828I Keyword keyword not allowed, only software ...
           The system issues this message when the specified keyword is not
           permitted due to 'software only' restrictions.  See page 14.0.


       CBDA829I Keyword keyword not allowed for this activation.
           The system issues this message when the specified keyword is not
           allowed for the current activation.  See page 14.0.


       CBDA830I ACTIVATE command syntax error.
           The system issues this message when the ACTIVATE command string
           has an incorrect syntax.  See page 14.0.


       CBDA832I ACTIVATE command syntax error, keyword keyword ...
           The system issues this message when the specified keyword is not
           valid in the ACTIVATE command string.  See page 14.0.


       CBDA833I ACTIVATE command syntax error, keyword keyword ...
           The system issues this message when the specified keyword is
           duplicated in the ACTIVATE command string.  See page 14.0.


       CBDA834I ACTIVATE command syntax error, value for keyword ...
           The system issues this message when the specified keyword has an
           incorrect value in the ACTIVATE command string.  See page 14.0.


       CBDA835I ACTIVATE command syntax error, keywords keyword1 and keyword2
           ...
           The system issues this message when the specified keywords are
           requested concurrently in the ACTIVATE command string.  See page
           14.0.


       CBDA836I IODF data set name dsname1 is not comparable ...
           The system issues this message when the IODF currently in access
           by HCD is not comparable to the IODF used for IPL.  See page 14.0.


       CBDA837I Key word keyword not allowed, no validation ...
           The system issues this message when there is no processor in the
           currently active IODF that matches the hardware I/O configuration.
           See page 14.0.


       CBDA839I An IOCDS member selection is required.
           The system issues this message when a write or a switch of the
           IOCDS has been requested without an IOCDS member specified.  See
           page 14.0.


       CBDA840I Currently active IODF dsname not found, ...
           The system issues this message when the currently active IODF
           cannot be found.  See page 14.0.


       CBDA841I IODF dsname not found, activation rejected.
           The system issues this message when the specified IODF cannot be
           found.  See page 14.0.


       CBDA842I No hardware configuration data available.
           The system issues this message when the hardware configuration
           data could not be retrieved.  See page 14.0.


       CBDA843I Hardware does not support the dynamic reconfiguration
           capability.
           The system issues this message when the hardware processor does
           not support dynamic I/O reconfiguration.  See page 14.0.


       CBDA844I A configuration change is currently in progress.
           The system issues this message when an activation is being
           processed in another partition.  See page 14.0.


       CBDA845I An IOCDS with wrong format is active.
           The system issues this message when an IOCDS has been used for
           power-on.  See page 14.0.


       CBDA846I A previous activation failed and could not be backed-out.
           The system issues this message when an activation was unsuccessful
           and could not be backed-out.  See page 14.0.


       CBDA847I Partition partition missing, not defined for...
           The system issues this message when the partition is not defined
           for the new processor to be activated.  See page 14.0.


       CBDA848I Invalid partition partition defined for CHPID chpid.
           The system issues this message when an IODF to be activated
           contains an incorrect partition defined for a channel path.  See
           page 14.0.


       CBDA849I Duplicate use of serial number in the same IODF detected ...
           The system issues this message when a serial number is duplicated
           in an IODF.  See page 14.0.


       CBDA850I Illegal logical control unit split detected between the...
           The system issues this message when a logical control unit is
           split.  See page 14.0.


       CBDA851I Illegal logical control unit merge detected between the...
           The system issues this message when a logical control unit is
           merged.  See page 14.0.


       CBR0028I Error pinning UCB at address address for device...
           The system issues this message when a request to "pin" the UCB at
           the specified address was unsuccessful.  See page 16.0.


       CBR0029I Error unpinning UCB at address address for device...
           The system issues this message when a request to "unpin" the UCB
           at the specified address was unsuccessful.  See page 16.0.


       CBR1073I Command rejected.  OSMC is not active.
           The system issues this message when a command is entered that must
           be processed by OSMC, but OSMC is not active.  See page 16.0.


       CBR3256I Cartridge jammed in library library-name between the gripper
           ...
           The system issues this message when a cartridge is jammed between
           the gripper and the specified drive.  See page 16.0.


       CBR5722I Channel speed set to channel-speed.
           The system issues this message when the 8232 control units set the
           channel data transfer rate.  See page 16.0.


       CBR9918I The Auto-Delete Installation Exit failed. ...
           The system issues this message when the auto-delete installation
           exit ends abnormally.  See page 16.0.


       COF529I UNABLE TO DISPLAY DLF STATUS ON THIS DEVICE.
           The system issues this message when it cannot display the DLF
           status on a console.  See page 18.0.


       ERB107I sid: RMF CANNOT BE STARTED DUE TO DYNAMIC ...
           The system issues this message when RMF cannot build its internal
           configuration tables due to a dynamic I/O configuration update.
           See page 21.0.


       ERB108I sid: RMF MONITOR I {DEVICE|I/O QUEUING}...
           The system issues this message when a dynamic I/O configuration
           update occurs and either RMF cannot build its internal data block
           structure, or RMF cannot use its internal configuration table.
           See page 21.0.


       ERB109I sid:RMF MONITOR III DATA GATHERER CANNOT ...
           The system issues this message when RMF cannot build its internal
           UCB address table due to a dynamic I/O configuration update.  See
           page 21.0.


       ERB110I CRITICAL ERROR DURING DYNAMIC CONFIGURATION CHANGE.
           The system issues this message when an unresolvable error occurs
           during a RMF dynamic configuration change.  See page 21.0.


       ERB294I sid: RMF IS NOT ABLE TO REACT ON DYNAMIC I/O UPDATES.
           The system issues this message when RMF is not able to activate a
           listen exit to check for dynamic I/O updates.  See page 21.0.


       ERB295I sid: NOT ENOUGH CMB DATA SLOTS AVAILABLE. ...
           The system issues this message when RMF cannot obtain a CMB slot
           to start collecting the hardware measurements for the specified
           device. See page 21.0.


       IAR011I RSM COMPONENT TRACE EXTERNAL WRITER MAY HAVE LOST ENTRIES
           The system issues this message when the system may have lost some
           RSM component trace entries while writing them to a trace data
           set.  See page 22.0.


       IDC0254I CANCEL COMMAND WAS EXECUTED
           The system issues this message when an IDCAMS CANCEL command is
           entered to end the current job step.  See page 28.0.
