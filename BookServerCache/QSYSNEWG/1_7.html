1.7 The Operating System




   The computer and various input, output, and storage devices being used by
   all of the people connected to the computer would get pretty messed up if
   there were no method of control.  There is control, however; that's the
   job of the operating system.


   The operating system consists of a group of programs which help to manage
   the use of system resources (printers, display stations, disk and tape
   drives).


   For example, two people might want to use a printer at the same time.
   It's the operating system that determines which person goes first.


   Or, it can decide which program uses the processor at any given moment.
   It does this so quickly that users of a program don't usually notice the
   delay that is caused by other programs using the processor.


   The operating system allows the computer to:


   °   Run more than one program at a time
   °   Handle printed output
   °   Schedule work
   °   Communicate with the user
