1.3 Input Devices






            






   An input device is any device that takes data in a form that has been
   created outside the computer system and changes it to electronic signals
   that the computer can understand.


   The most common input device is the keyboard.  Other examples of input
   devices are:


   °   Bar code scanner:  Used at supermarket checkout counters.  The scanner
       recognizes the pattern of lines in the product code and transfers the
       information to a computer.


   °   Magnetic card reader:  Used at banks in automated teller machines.
       The card reader reads the details of your account from the magnetic
       pattern on the bank card.


   °   Push button telephone:  Used to provide services from your own home.
       The computer recognizes the tone associated with the button you push.
