PREFACE.3 How This Manual Is Organized

 



   This manual is organized as follows:


   °   Chapter 1 describes how to use the calendar functions included with
 |     OfficeVision/400.


   °   Chapter 2 describes how to use the mail functions included with
 |     OfficeVision/400.


   °   Chapter 3 describes how to send and receive messages using
 |     OfficeVision/400.


 | °   Chapter 4 describes the note function of OfficeVision/400.


 | °   Chapter 5 describes how to handle filed documents using the documents
 |     and folders function of OfficeVision/400.


 | °   Chapter 6 describes how to use the directories and distribution lists
 |     functions of OfficeVision/400.


 | °   Chapter 7 describes how a user that is not an administrator can use
 |     the administrative functions of OfficeVision/400.


 | °   Appendix A describes the differences between OfficeVision/400 and
       Personal Services/36.


 | °   Appendix B describes the differences between OfficeVision/400 and
       Personal Services/38.


 | °   Appendix C lists the double-byte input capable prompts for the
 |     calendar, system distribution directory, and administration functions
 |     of OfficeVision/400.


 | In the back of this manual is a glossary and an index.  Use the glossary
 | to find the meaning of an unfamiliar term.  Use the index to look up a
 | topic and to see on which pages the topic is covered.
