PREFACE.4 How This Manual Has Changed




   The following major changes were made since the previous edition of this
   manual:


 | °   Information has been added to Chapter 1 on searching remote calendars,
 |     adding a meeting notice to your calendar, and working with temporary
 |     groups.


 |     Chapter 1 has been extensively updated to reflect the following
 |     changes to the calendar function:


 |     -   Information has been added about the Position to Today's date
 |         function


 |     -   Information has been added about the new security levels on many
 |         calendar displays (personal, unclassified, confidential)


 |     -   Formats on many calendar displays have changed to include new
 |         prompts and function keys


 |     -   Information has been added about deleting multiple occurrences of
 |         a meeting


 | °   Information about the department function and directory search
 |     function has been added to Chapter 6.


 | °   Information about working with owned objects has been added to
 |     Chapter 7.


 | °   Appendix C has been added.  This appendix lists the double-byte input
 |     capable prompts for the calendar, system distribution directory, and
 |     administration functions of OfficeVision/400.


   Changes since the previous edition of this manual are indicated by a
   vertical line to the left of the change.
