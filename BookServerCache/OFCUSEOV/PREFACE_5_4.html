PREFACE.5.4 Question-and-Answer Function




   The question-and-answer (Q & A) function provides answers to questions you
   may have about using the AS/400 system.  To use the Q & A function, press
   F13 (User support) on any system menu to show the User Support and
   Education menu.  Then select the option to use the Q & A function.  You
   can also use the Q & A function by entering the Start Question and Answer
   (STRQST) command on any command line.
