1.2 Selecting a Calendar Task

 



   To do a calendar task, you must press the function key for the task you
   want to do or type the appropriate function code for the Function prompt
   on a calendar display.


   To select a calendar task by pressing a function key, do the following:


   1.  On the Daily, Weekly, Group, Composite, or Six Month Calendar display,
       press a function key shown at the bottom of the display.  For example,
       to add a calendar item, press F6 (Add item).  The Add Item display
 |     appears on the bottom of the display.


       |                                                                                  |
       |                                      Add Item                                    |
       |                                                                                  |
       |   Type choices, press Enter.                                                     |
       |     Type of item . . . . . . . .    1      1=Event (single calendar)             |
       |                                            2=Meeting (multiple calendars)        |
       |                                            3=Reminder                            |

       |                                            5=Procedure (S/36)                    |

       |                                                                                  |

   2.  Complete the display for the function you selected as described in
       this chapter or press F3 (Exit).


   To select a calendar task by typing the appropriate function code, do the
   following:


   1.  Press F4 (Prompt) with the cursor in the Function prompt at the top of
       the Daily, Weekly, Group, Composite, or Six Month Calendar display.
       The Select Function display appears.


       Note:  When the Function prompt is shown on a calendar-related
              display, you can type a function code to do a calendar function
              or, with the cursor in the Function prompt, press F4 for a list
              of the function codes.




   2.  On the Select Function display, for the Function prompt, type the
       function code for the task to be done.  For example, to add an item to
       your calendar, type an A (Add an item) and press the Enter key.
