PREFACE.6 Related Printed Information

 



 | The manuals below are listed with their full title and base order number.
 | When these manuals are referred to in this manual, a shortened version of
 | the title is used.  If you need more information, refer to the following
   IBM AS/400 manuals:


 | °   Communications:  Distribution Services Network Administrator's Guide,
 |     SC21-9588, contains information about the function and administration
 |     of a system distribution directory and related distribution lists.


   °   Information Directory, GC21-9678, has information about all the
       documentation for the AS/400 system.


 | °   Office:  Learning about OfficeVision/400, SC21-9615, introduces the
 |     different functions of OfficeVision/400 and contains exercises that
 |     show the user how to do many of the tasks associated with the product.
 |     This guide is for the new OfficeVision/400 user or for someone who
 |     needs a quick review before using OfficeVision/400 again.


 | °   Office:  Learning about OfficeVision/400 Word Processing, SC21-9617,
 |     contains introductory information about using the word processing
 |     function for the AS/400 system.


 | °   Office:  Managing OfficeVision/400, SC21-9627, contains detailed
 |     enrollment information for an administrator.


   °   Office:  OfficeVision/400 Common Tasks, GX21-9868, describes how to do
       common office tasks and contains information about using the function
       keys.


 | °   Office:  Using OfficeVision/400 Adapted Word Processing Function,
 |     SC21-9879, has detailed information about using the adapted word
 |     processing function.


 | °   Office:  Using OfficeVision/400 Word Processing, SC21-9618, contains
 |     detailed information about using the word processing function of
 |     OfficeVision/400 and describes how to do additional word processing
 |     tasks not described in the Learning about OfficeVision/400 Word
 |     Processing manual.


   °   Programming:  Control Language Reference, SBOF-0481, describes the
       commands and structure of the AS/400 control language.


 | °   Programming:  Security Concepts and Planning, SC21-8083, provides
 |     additional information on working with owned objects on the system.


   °   Programming:  System Reference for the System/36 Environment,
       SC21-9662, describes what System/36 procedures, commands, and operator
       control language (OCL) statements are supported in the System/36
       environment on the AS/400 system.
