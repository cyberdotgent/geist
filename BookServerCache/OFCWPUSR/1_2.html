1.2 Using Commands to Work with Documents and Folders




   You can use menus to work with documents and folders, or you can use
   commands.  Typing commands with parameters can be a real time-saver.
   However, because remembering which parameters go with which commands can
   be difficult, you can type the command and press F4 (Prompt) to be
   prompted for the necessary parameters.
