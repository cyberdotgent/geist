PREFACE.6 Related Printed Information




   The manuals below are listed with their full title and base order number.
   When these manuals are referred to in this manual, a shortened version of
   the title is used.


   If you need more information, refer to the following AS/400 office
   manuals:


 | °   Office:  Planning For and Setting Up OfficeVision/400, SC21-9626.
 |     This manual has information on how to plan and set up your office
 |     environment.


 | °   Office:  Managing OfficeVision/400, SC21-9627.  This manual has
 |     information to set up, enroll users, and administer OfficeVision/400
 |     to best use the different functions.


 | °   Office:  Learning about OfficeVision/400 Word Processing, SC21-9617.
 |     This manual provides office users with information to help them learn
 |     how to use the word processing functions of OfficeVision/400.


 | °   Office:  OfficeVision/400 Common Tasks, GX21-9868.  This manual
 |     briefly describes word processing and office tasks.  It can be used as
 |     quick reference information.


 | °   Office:  Using OfficeVision/400 Adapted Word Processing Function,
 |     SC21-9879 provides the user with information on how to do word
 |     processing tasks with the adapted word processing function of
 |     OfficeVision/400.


   °   Programming:  Office Services Concepts and Programmer's Guide,
       SC21-9758.  This manual describes word processing concepts and offers
       suggestions for programmers.


   For more information about the system, refer to the following AS/400
   manuals:


   °   Information Directory, GC21-9678.  This manual contains information
       about all manuals for the AS/400 system.


   °   Programming:  Command Reference Summary, SC21-8076.  This manual is
       designed to help the programmer quickly refer to the AS/400 command
       syntax.  This manual contains an alphabetic list of all AS/400
       commands.


   °   Programming:  Control Language Reference, SBOF-0481.  This manual
       describes the AS/400 control language (CL) commands.  Each command is
       defined, including its syntax diagram, parameters, default values, and
       keywords.


   °   System Operations:  New User's Guide, GC21-8211.  This manual has
       information about using your system and display station, including
       using function keys, displays, menus, messages, and help information.


 | °   Programming:  Guide to Printing, SC21-8194.  This manual has
 |     information about how printer files are used.


   °   Utilities:  Business Graphics Utility User's Guide and Reference,
       SC09-1167.  The Business Graphics Utility (BGU) allows you to create
       various types of charts.


   °   Utilities:  Interactive Data Definition Utility User's Guide,
       SC21-9657.  This manual contains detailed information on how to use
       the interactive data definition utility (IDDU) to describe data
       dictionaries, files, and records to your system.


   °   Query:  User's Guide, SC21-9614.  This manual contains detailed
       guidance information and task-oriented reference information that
       describes the functions and operations of AS/400 Query.  It describes
       the tasks used to define and run queries.


   °   Application Development Tools:  Screen Design Aid User's Guide and
       Reference, SC09-1171.  The screen design aid (SDA) allows you to
       design, create, and maintain display formats and menus.


   °   Application Programming:  Application Development by Example,
       SC21-9852.


 | °   Communications:  Communications and Systems Management User's Guide,
 |     SC21-9661. This manual contains information about keyboard mapping.

   specific release and modification level of the OS/400 licensed program and
   may not discuss all the functions available on your AS/400 system.
