1.1.4 Softcopy Library




   Most of the AS/400 library publications are also available in softcopy
   format so you can search for and browse topics online.  You can access
   information by searching a single manual, a library list, or the entire
   library for topics and quickly display the references.  You can also
   choose topics from a table of contents for a single manual or from the
   index of a manual.  Books in the softcopy library are organized within
   categories called bookshelves.


   The softcopy manuals come on a compact disk read-only memory (CD-ROM)
   platter containing the printed version in a softcopy format. To use the
   AS/400 softcopy library, you need a personal computer, DOS or OS/2*
   operating system, a CD-ROM drive, and BookManager* READ software.


   The AS/400 softcopy library consists of two separately orderable products;
   BookManager is a licensed program product and the AS/400 softcopy library
   is a separately orderable feature of the OS/400* program.  See Appendix D
   for ordering information.


   Frequently used manuals can be copied from the CD-ROM to shared folders on
   the host system or from shared folders to hard files using PC Support/400.
   Then, the manuals can be accessed either from the CD-ROM disk, from the
   hard file of a personal computer, or from a shared folder on an AS/400
   system.  A licensed copy of BookManager must reside on each personal
   computer that accesses these files.  PC Support/400 users can toggle
   between searches in the library and tasks on the host system.
