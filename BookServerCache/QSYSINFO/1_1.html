1.1 AS/400 Library Overview

 



   The AS/400 system library consists of the publications that can be ordered
   with the hardware products and licensed programs (these are the manuals
   described in "AS/400 Library Publications" in topic 2.1.  See the overview
   poster, Application System/400* Library Structure, S325-6009, for a
   graphic view of the library design.


   The library design takes into consideration the various environments in
   which users interact with the AS/400 system, the universal tasks that
   users do with computer systems, and the responsibilities of typical users.
