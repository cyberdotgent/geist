1.2.1.1 Help for PC Support/400 Menus and Displays




   When F1 (Help) and F2 (Extended help) are shown on a PC Support display,
   you can display online help information.  Using F1 (Help), you can display
   specific help for an item on the display.  F2 (Extended help) displays
   general information for the function you are using.  You can also display
   help by going to the action list, if help is listed as an item on the
   action list.


   Within the online help information, highlighted words, commands, phrases,
   and related topics indicate that more information is available about that
   topic.  To view the information, move the cursor to the highlighted item
   and press the Enter key.  You will get the following kinds of information:


   Single word
       A definition of the word is displayed, usually with an example of how
       it applies to PC Support/400.


   Command
       A syntax diagram is displayed with examples and parameters.


   Prompt
       An explanation of how the prompt is used in PC Support/400.


   Phrase or topic
       An explanation of the topic is displayed.  For example, from the
       introductory topic of shared folders, you can select system drives,
       folder drives, and strategies for using shared folders.


   Using the Shift key with F6 (View help list), you can display a list of
   all the topics you have selected.  You can move the cursor to any topic
   within the list and press the Enter key to display the topic.


   Using F11 (Help index), you can display the index of all the topics within
   the part on which you are working.  You can move the cursor to any topic
   within the index list and press the Enter key to display the topic.
