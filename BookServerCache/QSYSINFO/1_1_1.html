1.1.1 User Environments




   The publications in the library are grouped to be used in different user
   environments.  The color of the design on the covers of the publications
   (as well as the color on the binder spine labels) indicates which
   environment is represented.  The environments are:


   General (Yellow Design):  In this environment, users are seeking general
   information about the system or the library (like this Guide).


   System Use (Blue Design):  People in this environment simply use the
   AS/400 system as a tool to do their job.  Typically these users are
   executives, supervisors, business or technical professionals, secretaries,
   and clerks who use applications  on the system to prepare documents and
   reports, maintain calendars, do inquiries, and other daily tasks.  This
   environment also includes some basic system administration and management
   tasks.  But programming is not a part of this environment.


   Application Development (Green Design):  Programmers in this environment
   use languages, tools, and other system functions to develop business
   applications for the users in the "blue" environment.


   System and Application Support (Red Design):  The main activity in this
   environment is to keep the AS/400 system, its networks, and its
   applications running effectively so the people who develop and use the
   applications can do their jobs.


   Hardware and Software Service (Black Design):  This is the environment in
   which service personnel identify, analyze, and fix problems with the
   AS/400 hardware or licensed programs.
