1.2.3 User Tool Library (QUSRTOOL)




   Many of the examples in the AS/400 library are contained in the optionally
   installable library, QUSRTOOL.


   The purpose of this library is to provide you access to various example
   programs that are discussed in some of the manuals.  This will enable you
   to use or revise (for your use) the examples discussed in the manuals
   without requiring you to rekey the source code for the examples.


   Library QUSRTOOL only contains the source for these examples.  The
   creation and management of the objects is left to you as the user.  If you
   modify the source, it is recommended that you first copy the source to a
   user library.  This will ensure that your modifications are preserved when
   the QUSRTOOL contents are changed by IBM.


   See member AAAMAP in source physical file QATTINFO in library QUSRTOOL for
   more information about this library.
