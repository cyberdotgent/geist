PREFACE.2 How to Use This Book

 

   This book contains information from many of the books in the library for
   TPNS Version 3 Release 2 and provides a comprehensive, task-oriented
   approach to planning.  It also describes the requirements for installing
   TPNS on your system.  The sequence of topics in this book parallels the
   order of the tasks you perform as you plan for and conduct TPNS tests.
   This means that information about installing TPNS is presented first,
   followed by information about determining the type of test and its
   objectives, configuring your system, defining the network and messages to
   be simulated, running the test, and using TPNS output.


   This book is designed to be the first book you use during TPNS testing.
   If you are a new TPNS user, you should read the entire book and develop a
   test plan before you conduct your first TPNS test.  Then, refer to
   individual chapters as needed to modify and refine your test plan.  If you
   are an experienced TPNS user, you should first refer to Appendix A,
   "Migrating from Previous Versions of TPNS" and then skim through the rest
   of this book before you use TPNS Version 3 Release 2.  Pay special
   attention to sections that describe the planning considerations for using
   new or changed features.  Finally, if you are responsible for installing
   TPNS, concentrate on "Installing TPNS," which describes the installation
   and system requirements for TPNS.


   This book includes the following chapters and appendixes:


   °   "Getting Started with TPNS" provides an overview of TPNS, describes
       the general process used in TPNS testing, and explains how you should
       use the other books in the TPNS library.


   °   "Installing TPNS" describes the installation and system requirements
       for using TPNS.


   °   "Testing with TPNS" describes five types of tests and explains how you
       can benefit by testing with TPNS.


   °   "Creating a Test Plan" presents a systematic approach to determining
       test objectives and to designing and writing a test plan for a TPNS
       test.


   °   "Determining Your System Configuration" discusses how to configure the
       network you want to simulate and the real system used to run TPNS.


   °   "Defining the Simulated Network" summarizes the planning
       considerations for coding the network definition statements that
       define the network to be simulated.


   °   "Creating TPNS Message Generation Decks" summarizes what you need to
       know to plan the message generation decks that generate messages for
       the simulated network.


   °   "Running the Test" explains the sequence for running TPNS tests and
       describes the various tools available for operation.


   °   "Using TPNS Output" explains the tools and utilities available for
       analyzing the data produced by the TPNS test.


   °   The following appendixes provide additional information that you may
       need as you use TPNS Version 3 Release 2:


       -   Appendix A, "Migrating from Previous Versions of TPNS"


       -   Appendix B, "TPNS Sample Data Set"


       -   Appendix C, "Terminals and Line Disciplines Supported"


       -   Appendix D, "Using TPNS for Communication Network Management"


       -   Appendix E, "Summary of Logical Unit (LU) Types."
