1.3.2 Planning


   Before you conduct a TPNS test, you need to define the objectives of your
   test and write a comprehensive test plan.  This book explains what you
   need to create a test plan and describes the various utilities, options,
   and features that are available with TPNS.  Read "Testing with TPNS" to
   learn about the types of tests you can conduct with TPNS.  Then refer to
   "Creating a Test Plan" for more information about designing and writing a
   test plan for TPNS tests.


   Planning is an extremely important part of TPNS testing.  In many cases,
   the success or failure of a TPNS test hinges on how carefully it is
   planned in advance.  You should view planning as an ongoing task and be
   prepared to refine your test plan until you obtain the desired results.
   When beginning to use TPNS, you should start with a small network
   definition and a simple message generation deck.  For example, your first
   TPNS test might simulate a single terminal logging on to the operating
   system.  Then you can gradually add more terminals and use more complex
   message generation decks until you are simulating the complete network you
   plan to test.
