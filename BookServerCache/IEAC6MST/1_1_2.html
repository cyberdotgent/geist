1.1.2 Analyzing Traces




   MVS/SP has a number of tracing facilities.  The system saves these traces
   in storage buffers.  For generalized tracing facility (GTF) or component
   traces, the system can also write these traces out to data sets using an
   external writer program.


   Using IPCS you can format the entries of any trace in a dump or trace data
   set.  You can also do the following with GTF and component trace entries:


   °   Selectively format entries without deleting the unformatted data from
       the buffer or dump


   °   Find the system and time stamp for each entry.


   °   Mix formatted GTF and component trace entries without combining the
       unformatted data.


   °   Reduce the number of entries in a trace data set


   °   Extract trace buffers from dumps to trace data sets


   °   Combine a GTF or component trace's entries into a single data set from
       multiple trace data sets.
